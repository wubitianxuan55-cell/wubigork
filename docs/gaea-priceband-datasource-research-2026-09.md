## 1. 需求重述与现状核实

**需求假设**(市场调研):广联达询比价印证了外部行情数据的价值;gaea 组价已有
价格带(v4.191),但「价格从哪来」悬置。

**现状核实**(代码证据):价格带数据面基础设施**已完整在产**——

| 环节 | 现状 | 位置 |
| --- | --- | --- |
| 数据模型 | `CostEntry` 一等字段 Source(定额/市场询价/历史项目)、Region(价格三要素之一)、PriceType(出厂价/到场价/安装综合价)、PriceDate | `internal/gaea/cost/cost.go:43-46` |
| 价格带统计 | `ComputePriceBand` 纯函数:相似条目 P25-P75/中位数/离散度/离群/置信度(≥8 高/4-7 中/1-3 低),证据链带 Source/Region/PriceDate 快照 | `internal/gaea/cost/priceband.go` |
| 导入链 | 文件导入 Preview→Apply(整批事务)、AI 解析(`GaeaCostImportAIParse`)、视觉导入(`GaeaCostImportVisionPreview`) | `internal/app/gaea_cost_import*.go` |
| 询价飞轮 | OCR 报价单(pdf_text/pdf_scan/image)自动按 (title,spec,source,supplier) 幂等写入询价库——「每张报价单自动变数据点」(v4.6 反向接线) | `gaea_cost_import.go:324` 注释 |
| 组价消费 | `GaeaCostCompose` 检索→价格带推荐→LLM 拆解→确认回写;缺相似样本时诚实回退(band null,checks 空) | `internal/app/gaea_cost_compose.go` |

**结论前提**:「手动/半自动导入外部价格数据」这条路**今天就能走**——用户把当地
造价信息网发布的信息价(Excel/PDF)拖进造价数据库导入,Source/Region/PriceDate
落字段,价格带统计自动吃进(样本数与置信度随之上升)。系统不缺管道,缺的只是
「数据从世上到用户手里的方式」。

## 2. 外部自动化接入评估(四路)

| 路 | 形态 | 评估 | 建议 |
| --- | --- | --- | --- |
| A. 手动/半自动导入 | 用户从当地造价信息网下载信息价 Excel/PDF → 既有导入链入库 | 零新增依赖、零合规风险、数据主权在用户;**管道已在产** | ✅ 既定路径,无需开发 |
| B. 公开信息价网站定向抓取 | 定时抓各省/市造价信息网月度信息价 | 各市格式互异且常改版(脆弱,维护成本永久化);反爬/频控风险;批量抓取政府公开数据的合规边界灰 | ❌ 不建议(脆弱+灰区+与个人级定位不符) |
| C. 商业行情 API | 我的钢铁/慧讯/广材等付费 API | 面向企业收费、账号/授权体系;「询比价/企业协同」已拍板不做,商业行情 API 是其上游供给 | ❌ 不做(同拍板口径) |
| D. LLM 在线检索参考 | 模型带搜索时让 LLM 查行情 | 上游不可验证,不能作价格计算基线;只能作「询价线索」展示 | ➖ 不作基线;现有 AI 解析导入已是其可靠形态 |
