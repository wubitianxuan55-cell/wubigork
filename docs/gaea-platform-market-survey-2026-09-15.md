## 1. 大厂 agent 接口形态（任务接口 × 技能接口）

### 1.1 任务形态：持久化已是红海，「统一收件箱」是空白

- **Anthropic**：Claude Cowork 2026-01-12 research preview（macOS，授权文件夹进
  VM 沙箱，"Claude Code for the rest of your work"）→ 02-10 Windows → 02-24
  插件市场（Skills/Connectors/Sub-agents 三类）→ 08-26 内置浏览器。产品口径
  「桌面发起、手机接力、云端继续、定时周期无人值守」。Claude Code 2026-05
  （W20）出 **agent view：单一屏幕管理所有 session**；08（W32）sessions 互发消息。
- **OpenAI**：2026-07-09 **ChatGPT Work** 发布——桌面应用重组为
  **Chat / Work / Codex 三顶层模式**（旧应用更名 Classic），Work = 跨应用长时
  agent（直接产出表格/幻灯/文档/网页应用）+ **Scheduled Tasks**（一次性/定时/
  事件触发/监控四类）+ 跨设备接力；同日 **Atlas 宣布收缩**（能力转 Chrome 扩展）。
- **Google**：2026-05-04 Project Mariner 停止；I/O 2026 出 **Antigravity 2.0**
  （独立桌面应用，按 **project** 而非仓库组织，异步任务/Scheduled Tasks//goal
  持续执行）+ **Gemini Spark**（24/7 云端个人 agent，关机后云端继续）+
  **Daily Brief**（晨间简报 agent）。官方口径：任务由自然语言创建、短信/邮件
  推进，**未提集中任务列表 UI**。
- **Microsoft**：**Copilot Cowork** 2026-06-16 全球 GA——M365 Copilot 应用内
  一个 toggle 切入的长时多步任务系统；云端托管（关机继续）、light/medium/heavy
  三档计费、三级预算。Agent 365（2026-05-01 GA，$15/用户/月）是治理控制平面。
- **形态结论**：「任务=跨越设备/时间的持久单元」四家同时兑现（红海）；
  「顶层界面按工作模式而非应用重组」部分兑现（OpenAI 三模式/MS toggle/
  Antigravity 按 project）；**「语音/IM/命令面板多入口汇入统一任务收件箱」与
  「应用板块降级为任务视图」无人发布**（空白）。

### 1.2 技能形态：SKILL.md 成事实标准，「自动结晶」无人发布

- **SKILL.md 标准化**：Anthropic 2025-10-16 Agent Skills → 2025-12-18 开放标准
  （agentskills.io）→ 2026-06 约 **40 个兼容产品**（Codex/Gemini CLI/Cursor/
  Crush 等）；微软 Build 2026 重建 Copilot Studio 时**直接采用 SKILL.md 模式**
  并支持导入 Claude Code / GitHub Copilot 技能。
- **「演示→技能」已发布**：Anthropic Cowork **Record a Skill**（2026-07-21，
  录屏+口述→合成可复用技能）；OpenAI Codex **Record & Replay**（2026-06-18，
  演示工作流→可检查可编辑 Skill）；Google Mariner Teach & Repeat（随 Mariner
  2026-05 停止）。
- **「历史→技能」无人发布**：没有任何大厂做「从用户审批/操作历史自动挖掘蒸馏
  技能」。最接近的是微软 Copilot Studio **Memory 表面**（Build 2026 预览，
  "remember interactions, workflows and context"）——产出是记忆层，不是可导出
  的 SKILL.md。社区有 Claude Code 自行增改技能的非官方报告。
- **对 gaea 的含义**：①gaea 的 skills/*/SKILL.md 选型（frontmatter+applies_to）
  已被市场充分背书，格式层零风险；②「技能结晶」方向的市场验证度=格式红海、
  演示式已被两家兑现、**历史挖掘式仍空白**——gaea 若做，差异化在
  「journal 审批链自动蒸馏」，且演示式录制（Record a Skill 形态）应作为
  低门槛入口一起做（已验证形态，不是 gaea 发明）。

## 2. 本地优先：工作台 × 记忆 × 路由

### 2.1 LM Studio Bionic（最直接竞品信号，基线后快速演化）

- 2026-07-16 发布（独立 agent 应用）：本地文件夹 inline diff 编辑、沙箱+
  自动 checkpoint、文档/deck/表格生成、原生 web search、系统级语音输入；
  三算力=本地/Secure Cloud/LM Link。**8-17 上线 Skills**；8-27 Auto Review。
  一个月 8 个小版本。
- 缺口（口碑+实测）：**无记忆、无 BYOK**（不能接第三方 API）、无本地 web
  search、账单只有总量**无单任务成本归因**（s5labs 一月实测 2026-08-17）、
  闭源与「开源模型 agent」定位冲突被 HN 质疑。
- 定价：Free（本地）/ Bionic+ $20（私有云托管 OSS 模型）/ Pro $100。

### 2.2 Letta Code App（程序性记忆最近身位）

- 2026-03-16 转型：全公司押 Letta Code，架构转客户端，记忆落 **MemFS**
  （git-backed 记忆文件库）；2026-04-06 桌面应用（macOS/Win/Linux）：
  持久记忆（可导入 Claude Code/Codex 旧会话、记忆子 agent 定期整理）、
  记忆与模型解耦、技能安装与版本化、免费起步。
- 2026-06-24 **Mods**：「harness-as-memory」——agent 自我修改运行时（加工具/
  加命令/改上下文投递），/mods learn 学习回路。**程序性记忆最激进的工程实现，
  但困在自家编码 harness 内**。
- 其他：Ollama 2026-07-09 融资 $88M（890 万开发者，`ollama launch` 一键跑
  agent 工具链——本地推理入口 commodity 化）；Jan 无大动作；Aider 半停滞；
  Cursor 本地模式最弱不可全离线；Zed 本地模型一等公民但无记忆层。
- **对 gaea 的含义**：桌面级「本地 agent+文件真编辑+持久记忆」三合一只有
  Letta 最接近（编辑弱）；「真编辑三件套×记忆×功能级绑定」组合仍无人占。

### 2.3 记忆层：程序性记忆被立为方向，工具早期

- **Mem0**：2026-05 时间推理；2026-08-04 **Dream：后台记忆固化**
  （merge/supersede/synthesize，不删数据、生命周期可审计）；《State of AI
  Agent Memory 2026》明确把**程序性记忆列为第三类记忆**并承认工具「仍处早期」。
- **基准转向**：LoCoMo/LongMemEval 趋饱和，**BEAM**（ICLR 2026，1M/10M token
  规模）成新硬基准；**LongMemEval-V2**（arXiv 2605.12493）把考察点从「会话
  记忆」转向「**习得未来任务所需经验**」（=经验/程序性方向）。
- **Zep**：2026-06 大版本（Context Graph 平台/Observations 自动发现模式）；
  2026-08 Memory MCP Server GA（跨 Claude/ChatGPT 统一记忆）——记忆正被
  **云端平台层收编**。Supermemory 2026-09-10 砍产品线聚焦核心引擎（收缩信号）。
- **对 gaea 的含义**：①记忆质量可评测（在册开放增量）的对齐物从 LongMemEval
  升级为 **BEAM/LongMemEval-V2**，且 V2 方向（经验习得）与技能结晶同一问题域
  ——评测可两用；②「本地、可审计、跨应用的程序性记忆」无玩家；③云端收编
  反证本地口径的差异化仍在。

### 2.4 模型路由：已产品化但都不含本地模型

- OpenRouter 新 **Auto Router**（用数百万用户总支出做隐式反馈，按 cost_tier
  路由，免费）；**Morph Router**（数百万真实编码会话训练，~180ms/$0.005，
  只返回推荐）；Not Diamond/RouteLLM 先行。
- **关键限制**：全部 prompt 文本分类 + 云端 provider 池，**不路由到用户本地
  模型**；叠加 2026-08 定价战（DeepSeek V4 Flash $0.13-0.28/M、GPT-5.6 Luna
  $1.20、Anthropic 降价 67%）——「省钱」不再构成路由卖点。
- **对 gaea 的含义**：「功能级绑定+本地遥测学习+本地模型参与统一路由」无
  产品实现（事实空白）；但卖点必须从省钱改为**可解释/可归因/单任务成本**
  （Bionic 被批无归因正是反例印证）。

### 2.5 MCP 温度计（佐证既有拍板）

- 治理权 2025-12 移交 Linux 基金会；registry 3,012 server、SDK 月下载 9,700 万，
  但**仅 41% 部署进生产**；82% server 有路径遍历漏洞；NSA/DoD 出安全指南、
  OWASP 出 MCP Top 10；**Perplexity CTO 2026-03 宣布内部弃用 MCP 改直接
  API/CLI**。
- **对 gaea 的含义**：「不做 MCP 大全」拍板获市场佐证（大全路线的隐性成本
  有数据），「少而深的一等公民集成」是市场情绪支持位。

## 3. 中文侧：创作 × 陪伴 × 图像 × 监管

### 3.1 网文：检测常态化制造「降 AI 味+一致性」刚需

- **平台政策**：16 平台反洗稿自律公约（2025-04）；起点 2026-04 非真人自动化
  创作管理公告，**「AI 占比超 10% 即下榜」**、单月处置约 100 本均订过万 AI 书
  （2026-08）；番茄 2026-06 单月拒签低质书 11.27 万本、49 位金番作者被罚；
  **纯人工作者被误判限流争议发酵**（检测逻辑=句式工整/词汇安全/情绪平滑）。
  第三方「AI 质检/降 AI 味」工具品类出现（ailv.run 类，按平台规则适配）。
- **工具面**：阅文 2026-07-23 发布 Buddy 三件（NovelBuddy 剧情梳理+人物设定，
  全端；DramaBuddy 漫剧；IPBuddy 版权）；此前阅文 Claw 工具**桌面端部署、
  按作品挂载技能**（北京科委 2026-03-16 报道）——中文侧离 gaea「桌面+技能」
  形态最近的身位，但绑定阅文生态。墨狐有「剧情树」（静态分支图）；彩云小梦
  多模型续写；笔灵转向公文；**星火写作 2025-11-30 停运**（商业化困难信号）。
- **对 gaea 的含义**：①中文市场**无任何产品**做角色状态机/伏笔管理/确定性
  一致性闸门——基线「书长一致性全行业未解」在中文侧更空；②平台检测高压把
  gaea 已有的确定性 AI 味引擎/文风指纹从「写作辅助」升格为**发表生存工具**；
  「可自证创作过程/人机边界记录」是新卖点候选（见 §7）。

### 3.2 陪伴：监管重锤后，本地形态踩在承接位

- **《人工智能拟人化互动服务管理暂行办法》**：2026-04-10 五部门公布、
  **2026-07-15 施行**——禁向未成年人提供虚拟伴侣；连续使用 2 小时强制提醒；
  检测到情感依赖须显著警告；**注册破 100 万或月活破 10 万须安全评估备案**。
- **大厂集体阉割**：豆包智能体 2026-07-15 下线（导流猫箱）；通义千问智能体
  停止；腾讯元宝 2026-06-30 关停自建角色；X Eva 2025-11-30 全线停服；猫箱
  未成年人模式仅剩 4 个教育角色；筑梦岛被约谈一年后仍被央广网点「擦边」。
- **本地承接显性化**：SillyTavern ~33k stars；B 站手机端酒馆教程单视频 22.4 万
  播放，「保姆级/白嫖」是关键词；Chub 热门角色卡百万下载但免费层收缩至
  20 条/天。
- **对 gaea 的含义**：监管周期显性放大「本地人格记忆+不受平台限制」需求，
  gaea 轻语本地形态正踩承接位；纯本地个人工具的义务链与云服务不同（不触发
  备案线），口径知悉即可，不动架构。维持「闲庭陪聊不写进办公」既有纪律。

### 3.3 图像：资本验证双后端与资产化路线

### 3.4 成人向：刑事执法活跃期（风险记录）

- **对 gaea 的含义**：gaea 为私有单机个人工具（不分发/无社区/无变现），
  与上述打击形态不同面；但原罪板块**永远不碰分发/社区/变现**应作为硬边界

## 4. 新威胁清单（按紧迫度）

1. **Letta Code App + Mods**：程序性记忆最近身位，免费+跨平台+全公司押注；
   但编码向、编辑弱、无真编辑三件套。
2. **LM Studio Bionic 迭代速度**：月 8 版已上 Skills/checkpoint/Auto Review，
   缺记忆与 BYOK——补齐只是时间问题。
3. **阅文 Claw**：「桌面端+按作品挂载技能」中文侧最近身位，绑定阅文生态。
4. **Ollama $88M**：本地推理入口 commodity 化——对模型中心是威胁也是可借
   底座（gaea 已支持本地引擎接入）。
5. **记忆云端收编**（Zep MCP Server/Mem0 跨 agent 共享）：平台层叙事挤压
   本地记忆的独占性故事。

## 5. 新空位清单（基线未覆盖、有事实支撑）

1. **本地可审计的程序性记忆（审批历史→SKILL.md 自动结晶）**：Mem0 自认
   工具早期、Letta 困在自家 harness、大厂无人发布历史挖掘式。
2. **多入口统一任务收件箱+板块降级为任务视图**：四家做了任务持久化但无人
   做收件箱形态（与「不做昼夜运转/后台长跑」拍板正交——收件箱是同步形态）。
3. **本地模型参与统一路由+单任务成本归因**：Morph/OpenRouter 均不路由本地
   模型；Bionic 被批无归因。
4. **中文长篇确定性一致性**：无中文对位产品（NovelBuddy 仅梳理+设定）。
5. **平台检测高压下的「可自证创作过程」**：人机边界记录/创作留痕导出——
   新品类（第三方降 AI 味工具是它的浅层形态）。
6. **「可审计主权」隐私叙事**：Bionic「零数据保留」被嘲 trust me bro——
   本地可验证审计链是「本地+隐私已非卖点」之后的再差异化角度（gaea 证据链/
   journal 现成）。

## 6. 与既有规划的校准点（不替用户宣布）

- **任务空间制**：市场验证度=部分验证。「任务持久化/后台执行/跨设备」是
  红海且与「不需要昼夜运转」拍板冲突——**不追**；收窄为「多入口统一收件箱
  +板块降级为任务视图」的同步形态，恰是无人做的空白。
- **技能结晶**：验证度强（SKILL.md 标准+三家演示式+Mem0/Letta 布局程序性
  记忆）。建议双入口：演示式录制（已验证形态）+ journal 历史挖掘（差异化）。
- **路由学习**：空位在，卖点改「可解释/可归因/含本地模型」。
- **记忆质量可评测**：对齐物升级为 BEAM/LongMemEval-V2；V2 与技能结晶同域，
  评测基建可两用。
- **闲庭**：轻语踩监管承接位（口径知悉）；小说一致性+降 AI 味是中文空位+
  发表生存刚需；绘梦按画室规格走（技术选型已有共识）。
- **MCP**：不做大全的拍板获数据佐证，维持。
