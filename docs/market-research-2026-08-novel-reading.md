# 市场调研：小说阅读器功能全景（移动端 × 桌面端 × AI 伴读），2026-08

> 目的：为 gaea 小说板块「阅读体验」下一轮优化提供设计依据。承接本轮已落地的
> 阅读模式增强（字号/行距/版宽、段落排版、进度条、章节位置记忆、键盘导航），
> 本轮调研市场主流小说阅读产品（微信读书/番茄小说/起点读书/掌阅/Kindle）与
> 桌面/开源阅读器（Readest/Alexandria/Calibre/ReadAny/AI-Reader），梳理功能全景
> 与 AI 时代增量，映射到 gaea 现状与差距。来源为 2026 年公开资料与产品介绍。

## 0. 一句话结论

小说阅读器的功能可以分成四层：**排版与显示**（字号/主题/翻页/字体）、**进度与
批注**（书签/划线/笔记/位置恢复）、**社区与激励**（本章说/排行/云同步）、以及
2025-2026 年快速起量的 **AI 伴读**（听书同步高亮、划线即问、章节总结、人物关系
图谱）。移动端产品把前两层做到极致、靠后两层拉留存；桌面端（Readest/Calibre）
把「批注 + 管理」作为标配。gaea 已有 TTS 听书、角色库、关系图谱、AI 引擎等现成
资产，最短路径是补齐 **P0：阅读主题（夜间/护眼）+ 书签 + 划线笔记**，再上
**P1：AI 伴读**（章节摘要 + 划线即问 + 当前章节人物卡）——后者是差异化而非跟随。

## 1. 功能全景（按维度，标注代表产品）

### 1.1 排版与显示（基础刚需，所有产品都有，卷的是细节）
| 功能 | 代表产品 | 说明 |
|---|---|---|
| 字号/行距/段距/页边距 | 番茄、掌阅、Kindle、Readova | 番茄五档字号；Kindle 支持边距/对齐/方向 |
| 字体选择与导入 | Kindle（9+ 字体）、掌阅、悠然小说 | 衬线/无衬线/楷体/圆体；桌面可导入本地字体 |
| 阅读主题 | 番茄、Kindle、青页、悠然 | 日间/夜间/护眼，背景预设（米黄/浅灰/墨绿/深蓝），亮度可调 |
| 翻页方式 | 番茄、书途、morealm | 仿真翻页（贝塞尔卷边）/覆盖/平移/上下滚动/无动画；自动翻页 |
| 阅读方向 | Kindle | 纵向/横向、从左向右翻页或连续滚动 |
| 布局 | Kindle、Alexandria、微信读书鸿蒙 | 单栏/双栏、大屏双页阅读、连续滚动 |
| 标点挤压/字间距/简繁 | 掌阅、青页 | 中文排版细节 |
| 全屏沉浸 | 各移动端 | 隐藏状态栏/工具栏 |

### 1.2 进度与批注（阅读器的“半条命”，桌面端尤其重视）
| 功能 | 代表产品 | 说明 |
|---|---|---|
| 阅读位置恢复 | 全部 | 移动端是段落级；gaea 目前是章节级 |
| 书签 | Kindle、掌阅 | 点书签跳回 |
| 划线/高亮/笔记 | 微信读书、Readest、Calibre、Reeden | 多色高亮、写想法、按章节分组浏览标注（Calibre 标注浏览器）、导出/生成海报分享（Reeden） |
| 进度显示 | 微信读书 | 阅读百分比 + 剩余分钟估算 |
| 目录/全文搜索 | Readest、Calibre、掌阅 | 章节跳转 + 全文检索 |
| 阅读时长统计 | 微信读书 | 每周/年度报告、好友排行 |
| 私密阅读 | 微信读书 | 隐藏阅读动态 |

### 1.3 社区与激励（网文平台的留存引擎）
| 功能 | 代表产品 | 说明 |
|---|---|---|
| 本章说/段评/划线评论 | 起点、番茄、微信读书 | 针对段落/句子的评论与点赞，可开关 |
| 书评/书友圈/打赏投票 | 起点 | 作家说、彩蛋章、书单献花 |
| 好友书架/排行榜 | 微信读书 | 阅读时长 PK、每周战绩 |

| 多端云同步 | 微信读书、起点、Kindle | 书架/进度/书签/笔记 |
| 离线缓存 | 番茄 | 整本预载 |
| 断更预警/剧情图谱/社区共读 | 番茄 | 平台运营向 |

### 1.4 AI 伴读（2025-2026 最大增量，差异化机会）
| 功能 | 代表产品 | 说明 |
|---|---|---|
| AI 听书 | 番茄（火山语音）、青页、微信读书 | 多音色、男/女/多角色对话模式、0.5-3x 倍速、后台播放、定时关闭；**朗读同步高亮当前句并自动翻页**（青页） |
| 划线即问 | 微信读书鸿蒙「AI问书」、EasyReadAI、Calibre Ask AI | 长按选文 → AI 拆解/翻译，无需切 App |
| 章节/全书总结 | Reeden、ReadAny、Lemniscate | 要点卡片、章节摘要、金句提取 |
| 人物/概念图谱 | AI-Reader-V2、ReadAny | 角色关系图谱、地理地图、时间线、百科全书（本地/云端 LLM） |
| 生僻字注音/批注版 | 天天读书 | 古籍生僻字语音注释、《诡秘之主》AI 批注版 |
| AI 指令/Skill | 微信读书鸿蒙（Skill）、ReadAny（技能系统） | 搜书、整理热门划线、导出笔记、阅读数据分析 |
| 语义搜索/对话 | ReadAny | RAG：读完问书、找内容 |

## 3. gaea 现状盘点（基于代码，2026-08-16）

### 已具备
- 阅读/编辑双模式；阅读模式为滚动式衬线排版（首行缩进、两端对齐、章节标题、场景分隔）
- 排版面板 Aa：字号 A−/A+（14-24）、行距（紧凑/标准/宽松）、版宽（窄/标准/铺满），全局持久化
- 顶部阅读进度条（本章阅读百分比）+ 每章滚动位置记忆（切换章节/退出/重开自动恢复）
- 键盘导航：←/→ 上一章/下一章、Esc 退出、F11 专注（收起左右 zone）
- 章节级「最后阅读章节」恢复（readingProgress）+ 左侧大纲树目录导航
- TTSPlayer 听书组件（编辑栏已有，可朗读当前章节文本）
- 角色库 + RelationGraph 关系图谱 + AI 引擎/ask 管线（办公与小说侧都在用）

### 差距
1. **无阅读主题**：只有跟随系统的明暗，无「夜间/护眼（米黄/绿/深蓝）」与独立亮度——小说阅读刚需
2. **无书签**：只有滚动位置记忆，不能手动标记关键位置
3. **无划线/高亮/笔记**：桌面阅读器标配，也是「读后复用」的入口
4. **无朗读同步**：TTSPlayer 存在，但朗读时不高亮当前句、不自动滚动
5. **无全文搜索**：只有大纲目录
6. **无 AI 伴读**：章节摘要、划线即问、人物卡都没接（但引擎/资产都在）
7. **无阅读统计**：阅读时长/进度报告
8. **翻页模式单一**：只有滚动；无分页视图/自动滚屏

## 4. 落地建议（按优先级）

### P0（工作量小、体验提升大）
- **P0-1 阅读主题**：日间/夜间/护眼（米黄、绿、深蓝预设）+ 手动亮度，持久化；
  夜间模式与系统深色联动（CSS vars 一层切换，改动集中在阅读容器）
- **P0-2 书签**：阅读滚动位置打书签（章节 + 偏移），底部工具栏/悬浮按钮 + 书签列表
  跳转；与现有滚动记忆共用 localStorage 模式
- **P0-3 自动滚屏**：番茄式定时滚动（速度 1-5 档），暂停/恢复，键盘或工具栏触发

### P1（中等工作量，拉开差距）
- **P1-1 划线/高亮/笔记**：选中文本 → 高亮（多色）+ 写想法；按章节分组的管理侧栏
  （参考 Calibre 标注浏览器）；持久化到本地 JSON，后续可导出
- **P1-2 AI 伴读第一档**：章节开头「AI 摘要」折叠卡（复用 office ask 管线）；
  **划线即问**：选中文本 → 弹出 AI 问答；答案卡片可收起
- **P1-3 朗读同步**：TTSPlayer 升级为朗读时高亮当前句 + 自动滚动跟随 + 倍速
  （复用现有 TTS 引擎）
- **P1-4 全文搜索**：按章节标题 + 正文关键字搜索，结果列表点击跳转章节定位

### P2（后续演进，差异化）
- **P2-1 当前章节人物卡**：识别当前章节出现的人物 → 悬浮/侧栏角色卡（复用角色库 +
  RelationGraph），点击进角色档案
- **P2-2 阅读统计**：每章阅读时长/整本书进度报告
- **P2-3 字体与分栏**：内置字体切换（衬线/黑体/圆体）、双栏/大屏布局
- **P2-4 分页视图**：仿真/覆盖翻页（桌面端可选，滚动仍为默认）
