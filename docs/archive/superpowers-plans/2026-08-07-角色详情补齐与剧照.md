# 角色详情：一键随机补齐 + 生成剧照 Implementation Plan

**Goal:** 详情档案视图支持「随机补齐空缺内容」与「生成剧照」，均以全局角色库为作用域、不依赖小说项目。
**Architecture:** 后端新增 `CharacterGenerateFill`（LLM 只填空合并）与 `CharacterGeneratePortrait`（角色字段 → 智能 prompt → 复用图片管线）；前端在详情组件加两个按钮，结果仅回填表单，由用户保存。
**Spec:** `docs/superpowers/specs/2026-08-07-角色详情补齐与剧照-design.md`

## Self-Review

- **库作用域**：两个新方法挂在 App/角色库域，不依赖项目；有项目时仅借用题材与世界观。
- **数据安全**：补齐只填空不覆盖；剧照不自动落库，保存由用户确认。
- **复用**：剧照复用 `GenerateFreeImage` 全部异常处理；LLM 走 novel 功能级路由（与角色 Agent 一致）。
