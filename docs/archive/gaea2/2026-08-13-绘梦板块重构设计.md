# 绘梦板块 UI 重构设计

> 版本：v1（研究 + 方向提案，暂不进入实现）
> 日期：2026-08-13

## 1. 现状判断

当前绘梦页的问题不是“颜色不漂亮”，而是信息架构不符合 AI 绘图的典型工作流：

1. 右侧历史区独立、固定、窄，但空态时几乎不产生价值；
2. 左侧控制面板把所有参数平铺，视觉和认知负担高；
3. 中景画布缺少强的“任务中心”属性，历史、队列、结果三者状态分散；
4. 颜色自成一套深黑方案，与 gaea 其他板块的玻璃 HUD 不一致。

## 2. 市场调研结论

### 2.1 主流范式

| 工具 | 界面范式 | 可借鉴点 |
|---|---|---|
| Leonardo | 画布优先 + 左侧创作入口 | 画布是第一对象，控制项按需展开 |
| Krea | 实时画布 + 双栏 | 左侧输入，右侧实时结果；参数少、反馈快 |
| Ideogram | 提示词优先 + 布局/格式强约束 | 面向任务预设，不暴露底层参数 |
| Midjourney | 命令式输入 | 极度简化，适合快速生成，不适合专业参数 |
| ComfyUI | 节点工作流 | 强大但学习成本高，不应成为默认视图 |
| A1111/Forge | 表单式 | 熟悉但信息密度过高，容易像“控制台” |

### 2.2 关键结论

- 绘梦不是 ComfyUI，不需要把底层参数全部暴露。
- 好的 AI 绘图工具会把“画布/结果”放在视觉中心，把参数做渐进式披露。
- 队列、历史、结果、模板应围绕同一个任务流组织，而不是分成互不相关的三块。
- 颜色和玻璃材质应继承 gaea 现有设计系统，保持跨板块一致性。

## 3. 设计原则

1. **画布优先**：中间区域始终是最大、最稳定的视觉锚点。
2. **渐进式披露**：高频参数默认可见，高级参数默认折叠。
3. **一个任务流**：待执行、执行中、已完成、历史结果在同一时间线/面板中表达。
4. **与 gaea 一致**：使用现有玻璃 HUD、边框、圆角、字体与明暗主题 token。
5. **少即是多**：默认界面只保留完成一次生成所需的最小操作集。

## 4. 目标信息架构

```text
┌────────────────────────────────────────────────────────────┐
│ Header：绘梦 / 当前后端与模型状态 / 目录快捷入口             │
├────────────────────────────────────────────────────────────┤
│ Mode：文生图 · 图生图 · 文生视频 · 图表                    │
├───────────────┬────────────────────────────┬───────────────┤
│ 控制面板      │ Canvas / Result Stage      │ Inspector     │
│ 可折叠        │ 结果预览 / 空态 / 生成中     │ 队列 / 历史   │
│               │                            │ / 资产        │
│ 基础设置      │                            │               │
│ 模型与引擎    │                            │               │
│ 高级参数      │                            │               │
└───────────────┴────────────────────────────┴───────────────┘
│ 底部生成栏：主生成按钮 / 取消 / 队列摘要                    │
└────────────────────────────────────────────────────────────┘
```

## 5. 分阶段实施计划

### Phase 1：布局重构成型

- 左栏固定宽度约 300px，使用可折叠 Section。
- 中栏画布成为主要区域。
- 右侧 Inspector 由“历史”升级为“任务中心”：队列、最近结果、模板资产三个 Tab。
- 底部 sticky 生成栏，主操作不被滚动带走。

### Phase 2：参数信息架构

- 高频：提示词、负向提示、模式、主模型、画幅。
- 中频：种子、数量、温度/步数等，按模式显示。
- 低频：LoRA、ComfyUI 启动、后端地址等，默认折叠。

### Phase 3：状态与反馈

- 队列状态列表与最近结果合并展示，避免左右信息重复。
- 生成中/失败/取消状态统一反馈。
- 历史元数据保留，但不再作为默认主视图。

### Phase 4：视觉统一

- 移除独立深黑配色，改用 gaea 玻璃 HUD 和当前明暗主题。
- 统一圆角、阴影、边框、间距和按钮体系。
- 响应式断点：宽屏三栏，中等屏两栏，窄屏上下堆叠。

## 6. 验收标准

- 用户不滚动也能完成一次基础文生图。
- 高级参数默认折叠后，左栏高度显著下降。
- 队列、历史、结果在同一任务中心中可追踪。
- 明暗主题切换下对比度和可读性都通过。
- 不破坏现有后端切换、LoRA、取消、ComfyUI 进度、模板和剧照设置功能。
