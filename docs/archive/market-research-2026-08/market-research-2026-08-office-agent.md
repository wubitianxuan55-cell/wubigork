# 市场调研：通用办公 AI 智能体（同类产品对比），2026-08

> 目的：为 gaea「通用办公」板块的强化与优化提供设计依据。调研对象为 2026 年公开资料，覆盖四类对标产品：大厂 AI 办公套件（WorkBuddy / 千问办公 / 豆包专业版 / 飞书 aily / WPS 灵犀 / Microsoft 365 Copilot / DuMate / 纳米Work）、桌面 AI 客户端（Cherry Studio / LobeChat）、标书方案垂直工具（钛投标 / 广联达 / 小飞标书 / 云境AI），以及行业市场报告（易观 / IDC / 艾媒 / 中信证券）。

> **定位声明（2026-08 确认）**：gaea 是**个人生产力工具**——不做团队协作、不做商业化。一切增强围绕两个指标展开：**性能**（快、稳、省：本地执行速度、大文件处理、启动与内存占用、流式低延迟）与**便捷**（少步骤、少交代、少复制粘贴：拖拽即用、粘贴即数据、原地呼出、记忆免重复、成果直达可编辑文件）。竞品中企业协同、计费、权限管控等能力仅作背景参考，不进入 gaea 路线。

## 1. 行业格局：2026 年是办公 Agent 爆发年

- **访问量爆发**：2026 年上半年国内桌面端 AI 办公智能体从 3 月约 2000 万月访问量增长到 6 月 6000 万+（17 款产品合计，翻 3 倍）；腾讯 WorkBuddy 单款 6 月访问量 2097 万，腾讯系合计 3262 万、字节系约 1441 万、阿里系约 919 万（[易观《2026 Q2 中国办公智能体平台市场洞察报告》](https://www.thepaper.cn/newsDetail_forward_33243266)）
- **十天收网**：7 月 20 日腾讯 QClaw 并入 WorkBuddy；7 月 27 日阿里把 QoderWork / 悟空 / MuleRun 三合一；8 月 3 日千问办公正式公测（搭载 Qwen3.8：2.4T MoE / 95B 激活 / 100 万上下文，重点强化 Coding 与 Cowork）；字节把飞书产品团队并入豆包（[钛媒体](https://www.tmtpost.com/8094048.html)）
- **市场空间**：IDC 预计 2026 年办公智能体市场 449 亿元、2028 年 33% 企业软件渗透率；中信证券测算中国通用办公 Agent 市场 3-5 年成熟后年化空间中枢约 390 亿元、乐观情形千亿；艾媒预计 2030 年国内 AI 智能体整体市场 6968 亿元
- **现实落差**：仅 17%-18% 中国企业把智能体纳入核心业务流（IDC / Gartner）；超 70% AI 项目未进入生产环境；2025 年全球因员工使用生成式 AI 导致的企业数据泄露事件超 1200 起（同比 +200%）。行业共识是"上半场比能力，下半场比交付与安全"——谁能真正把活干完、让企业敢授权（[36氪](https://www.36kr.com/p/3929118195472001)）

## 3. 行业共识：办公 Agent 的六项核心能力

易观将办公智能体平台的能力收敛为六大体系：**系统集成、业务理解、自主进化、成果交付、开放生态、安全合规**（[易观报告解读](https://finance.itbear.com.cn/html/2026-06/415596.html)）。横向调研验证并补充如下：

1. **成果交付 = 从"内容供应商"到"办公搭子"的分水岭**。DuMate 实测展示了行业范式：先做"统一事实底稿"（标注【已确认】【推断】【待确认】+ 来源），再基于同一套底稿交付 Word/PPT/网站/Excel——多形态交付物彼此一致、可留存、可复用（[雷峰网测评](https://www.leiphone.com/category/industrynews/XwxzXl7mJVCNfRzh.html)）。"复制粘贴到 Office"是拦住落地的最后一道门槛。
2. **记忆与自主进化**。WPS 灵犀四层记忆（个人/专家/团队/自进化），空闲时段自动归纳对话与文件做摘要、压缩、结构化整理（[AI 星球测评](https://www.aixq.cc/58766.html)）；千问办公把资深员工的执行路径（筛选信息/识别风险/判断升级）封装为组织级 Skill，形成"工作方法论"壁垒。
3. **原生文档深度处理**。WPS 原生级处理格式排版/表格公式/PPT 动效；Copilot Agent Mode 理解 Excel 透视表、PPT 动画；广联达对接 CAD/工程量清单。纯"文本生成 + 转格式"无法替代专业排版。
4. **垂直规则引擎**。标书场景铁律：垂直工具用专门实体识别 + 行业规则引擎解析招标文件，300+ 校验规则红黄分级预警、定位原文并给整改建议；通用大模型在废标风控上几乎为零（[阿里云技术解析](https://developer.aliyun.com/article/1752396)）。
5. **开放生态与系统集成**。千问办公 30 连接器；Coze 可视化工作流编排 + 多智能体；飞书 aily 上百预置专业 Agent + 第三方/自建 Agent 接入 + 多 Agent 组队。连接器数量不是重点，**"任务能在软件之间闭环"**才是。
6. **安全合规与权限审计**。360"原生安全、出厂内置"（AI 沙箱、全程留痕）；钛投标军工保密/国密/私有化断网；企业版统一账号、成员用量管控、权限边界。安全是比能力更难建立的护城河。

## 4. 用户与市场特征（易观）

- 核心用户：25-39 岁职场白领与技术从业者，超七成保持高频使用
- 场景迁移：从信息检索、文档处理等轻量化任务向高价值工作流深水区拓展；编程、项目管理等深度场景渗透率仍低
- 选型三要素：**数据安全 > 系统兼容性 > 自主执行能力**
- 三大痛点：指令理解偏差、产出质量不稳定、长任务执行中断
- 付费：市场尚处萌芽期，多数依赖免费版；免费增值模式接受度高；企业采购与个人订阅是主要付费形态
- 形态结论：网页端低门槛引流，**桌面端因深度系统交互能力成为复杂任务首选平台**

## 5. gaea 通用办公现状盘点

gaea 是 Wails 桌面应用（Go + React），个人本地优先使用，办公板块为独立二级导航，含「通用办公」与「方案编写」两个模块：

### 5.1 通用办公（GaeaPage）

- **入口形态**：对话区 + 左侧 Sidebar + 右侧面板（gaeaW 原生版面），欢迎页 6 个能力卡（文档撰写/表格处理/格式转换/图表生成/报告拼装/知识沉淀）+ 内置技能 chips
- **17 个核心内置工具**（v2.4.3 按调研结论从 38 个精简而来）：
  - 文件与命令 7：read_file / write_file / ls / bash / bash_output / kill_shell / wait
  - 网络 2：web_search / web_fetch
  - 任务 2：todo_write / complete_step
  - 记忆与知识 3：memory_search / knowledge_add / knowledge_search
  - 技能 1：read_skill
  - 办公引擎 2：format_convert（docx/xlsx/pdf→Markdown）/ chart_gen
- **内置子代理技能 3**：format-convert / chart-builder / doc-assemble；另安装 ModelScope 文档技能 docx / pdf / xlsx（SKILL.md + scripts/schemas/templates，同时写入 ~/.codex/skills 与 .gaea/skills）
- **已有底座**：三脑记忆（memory）、知识库（knowledge）、权限与沙箱（permission/sandbox）、审计（audit）、事件（event）、后台任务（bgjobs/jobs）、插件热加载（plugin）、多模型路由（模型中心）、本地 TTS、微信助手

### 5.2 方案编写（OfficePage）

- 五段流水线：招标解析 → 大纲生成 → 文本编制 → 全面检查 → 排版导出，带阶段闸门与一键流水线
- 已有能力：招标解析（含进度事件、原文来源定位）、大纲生成（评标办法/格式/参考三策略 + 目录导入）、批量生成/润色、检查摘要（failed/warnings + 来源定位）、docx 导出（封面/目录开关）、素材库（业绩/人员/设备/段落）、项目事实基线、复核清单

## 7. 设计决策与强化清单（映射到 gaea）

gaea 强化目标：**性能**（快、稳、省）与**便捷**（少步骤、少交代、少复制粘贴）。所有能力最终都服务于"个人更快拿到可直接用的成果"。

### P0 通用办公提效核心（个人使用，先做）

1. **多形态成果交付（一稿多用）**：在通用办公引入"任务 → 统一事实底稿 → 多形态交付"的默认工作流。落地：① 新增 pptx 生成能力（复用 docx/xlsx 技能模式，用 python-pptx 或 LibreOffice）；② 通用办公对话交付物默认支持 docx 排版导出（复用 ProposalExportDocx 的排版引擎）；③ 事实底稿作为中间产物可复用、可回看，后续交付物保持一致。收益：省掉"复制粘贴到 Office"这一步
2. **记忆与自进化**：在现有 memory/knowledge 之上补"个人画像 + 空闲自整理"——偏好、项目背景、踩过的坑自动沉淀（agent 的 compact/compress 基础设施已具备，空闲归纳对话/文件做摘要、压缩、结构化入库）。收益：越用越懂你，不用反复交代上下文
3. **便捷入口**：把"bash/read_file/write_file"等代码词汇翻译为办公动作——拖拽文件即上下文、粘贴表格即数据、全局快捷键/原地呼出、常用任务快捷模板（欢迎页 6 能力卡已有雏形，继续深化）。收益：操作步骤从"找路径/敲命令"变成"拖进来就用"
4. **长任务后台化**：利用已有 bgjobs，补"后台任务进度面板 + 完成通知 + 中断恢复"。收益：百页标书、批量转换这类大任务不用盯屏

### P1 性能专项与垂直深化

5. **性能专项**：本地 format_convert/chart_gen/文档生成速度、大文件（百页 docx/千行 xlsx）处理、启动与内存占用、流式低延迟与缓存命中（模型中心已有 Vulkan/GGUF 加速与缓存基建，扩展应用到办公引擎）。性能是个人工具的留存底线
6. **技能/工作流沉淀闭环**：把"一次成功的复杂任务"一键封装为可复用技能（对标 WPS 自定义技能）。gaea 已有 skill/plugin/agent 体系，缺"录制 → 封装 → 复用"的用户闭环。收益：重复工作流一劳永逸
7. **方案校验规则引擎**：把方案编写的"LLM 检查"升级为"规则库 + 原文定位 + 红黄分级 + 整改建议"：沉淀废标红线/实质性响应/格式规范等结构化规则（对标钛投标 300+ 规则）。个人做标书同样需要，避免废标
8. **连接器最小集（按需）**：只加个人高频的——剪贴板/OCR（截图已有，补文字提取）、浏览器操作（web_fetch/websearch 已有，可补整页操作）、微信助手深化（已有）

### P2 明确不做/远期

- 团队协作（共享技能/记忆/资产/权限）：**明确不做**
- 计费与额度公示：**明确不做**
- 主动工作/云端 7×24 常驻：不做云端形态；个人场景可选本地定时任务/提醒（本地自动化，性价比高时再议）

## 8. 落地优先级建议

- **本轮优先（P0）**：① 多形态成果交付（docx 排版 + PPT + 事实底稿）；② 便捷入口（拖拽/粘贴/快捷指令/原地呼出）；③ 记忆与自进化（个人画像 + 空闲自整理）；④ 长任务后台化（进度 + 通知 + 恢复）
- **其次（P1）**：性能专项（转换/图表/文档生成速度、大文件、启动内存）、技能沉淀闭环、方案校验规则引擎、连接器最小集
- **明确不做**：团队协作、计费、云端 7×24 常驻

## 9. 结论

2026 年办公 Agent 竞争已经从"更聪明的对话框"转向"端到端把活干完"。gaea 定位**个人生产力工具**，强化目标 = **性能与便捷**：对标竞品最该补的四块是**多形态成果交付（一稿多用）、便捷入口（少步骤）、记忆与自进化（少交代）、长任务后台化（少盯屏）**，性能专项作为持续基线；本地优先 + 多模型自由 + 自带方案编写垂直流水线仍是差异化立足点，团队协作与商业化能力明确不进路线。
