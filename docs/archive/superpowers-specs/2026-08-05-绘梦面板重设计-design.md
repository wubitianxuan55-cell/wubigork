# 绘梦面板重设计 — Studio Console 设计文档

> 日期：2026-08-05 ｜ 状态：已批准 ｜ 方向：Studio Console（方案 A）

## 1. 目标与范围

将「AI 绘梦」页面从当前「玻璃卡堆叠 + emoji 标签 + 微缩字体」的通用样式，重构为面向重度用户的 AI 创作工作台（Studio Console），视觉对齐 Runway / Magnific 一类专业工具，同时完整保留现有功能与信息架构。

范围：
- 重构 `frontend/src/pages/ImageGenPage.tsx` 的渲染层。
- 新增/重写子组件：控制面板（提示词/参数/引擎/系统/生成）、结果舞台、历史胶片。
- 全页面统一视觉语言（颜色/字体/圆角/状态/动效），补全加载/空/错误态。
- 不改变任何后端调用、状态管理契约与功能点。

非目标：不改三栏信息架构；不迁移框架；不引入新依赖；不改动其他页面。

## 2. 现状审计结论

- 颜色：控件硬编码靛蓝 `rgba(99,102,241,...)`，与主题主色（默认翡翠青）冲突。
- 文字：emoji 当图标；系统默认字体；标签 10-11px 过小。
- 表面：满屏玻璃卡 + 1px 描边，无层级；左栏 350px 单卡塞入全部控件。
- 组件：4 组相同 chip；无 hover/按压反馈；结果网格与历史条朴素。
- 状态：仅转圈；antd 默认空态；无错误态。
- 布局骨架（左控制 + 中画布 + 右历史）合理，予以保留。

## 3. 信息架构与布局

保留三栏工作台，左面板重组为 5 个分区：

1. **提示词**：prompt 5 行放大输入、负面提示折叠入口、模板快捷行 + 模板库入口。
2. **参数**：模型 / LoRA / 尺寸 / 种子 / 数量，分组选择器。
3. **引擎**：后端选择（xai/comfyui/herdsman/ollama）+ 连接状态 + 启停按钮。
4. **系统**（仅 ComfyUI）：CPU / 内存 / GPU 迷你指标条。
5. **生成**：主按钮常驻面板底部，含秒数与估算。

中间为结果舞台（响应式画廊，按宽度自适应列数）；右侧历史胶片 176px。

## 4. 视觉语言

- **主色**：统一 `var(--md-sys-color-primary)`（主题动态）；删除硬编码靛蓝；状态用主题 success/warning/danger 令牌。
- **图标**：全部改用 @ant-design/icons，移除 emoji 标签；状态圆点用 CSS。
- **字体层级**：标题 18px/600；分区标题 11px/500 + 字距；控件标签 12px；输入 13-14px。
- **表面**：控制面板一层玻璃底，内部控件用 `surface-container`/`-high` 嵌套层级；面板 16px、内控件 10px、主按钮全圆角。
- **圆角规范**：面板 16 / 内控件 10 / 胶囊按钮（一处规范全页贯穿）。

## 5. 组件设计

- **ControlPanel**：`components/imagegen/ControlPanel.tsx`，聚合提示词/参数/引擎/系统/生成 5 个区块。
- **PromptSection**：prompt TextArea（5 行、focus 高亮）、负面折叠、模板快捷行。
- **ParamsSection**：模型/尺寸/数量图标分组选择器（选中=主色填充+按压反馈）；LoRA 多选 chip + 已选计数；自定义宽高。
- **EngineSection**：后端卡片组（图标+文字），连接状态圆点 + 启停。
- **StatsSection**：CPU/内存/GPU 迷你条，主题令牌着色。
- **ActionSection**：大号主按钮（渐变+光晕），生成中秒数 + 进度环，估算时间。
- **ResultStage**：结果卡片 hover 上浮 + 底部操作条（预览/下载/复用/删除）；耗时徽章；生成中骨架屏；空态引导；错误横幅。
- **HistoryRail**：计数 + 清空 + 选中高亮。
- **Lightbox / 模板弹窗**：保留结构与功能，统一圆角与按钮规范。

## 6. 状态与动效

- 加载：与目标比例一致的骨架屏；生成按钮内嵌进度。
- 空/错误：空态构图引导；错误横幅（含摘要 + 重试）。
- 微交互：chip/按钮 hover 背景变化 + active `scale(0.98)`；结果卡 hover 上浮；分区入场错落淡入。
- 动效仅用 transform/opacity + cubic-bezier(0.32,0.72,0,1)；动画类名纳入 `gaea-raf-degraded` 禁用清单，降级模式即时显示。

## 7. 技术实现

- 文件：
  - 重构：`frontend/src/pages/ImageGenPage.tsx`
  - 新增：`frontend/src/components/imagegen/ControlPanel.tsx`、`ResultStage.tsx`、`HistoryRail.tsx`（以及各 Section 子组件）
  - 修改：`frontend/src/index.css`（新增入场动画类与降级禁用规则）
- 状态/API 契约不变：`generateImage`、`getComfyUILoras`、引擎启停、系统状态轮询、模板/灯箱数据流。
- 样式沿用内联样式 + CSS 变量体系；无新依赖。
- 验证：`tsc -b`、`vite build`、`wails build`；CDP 全流程（生成/下载/复用/删除/模板/引擎启停）；降级模式回归。

## 8. 验收标准

- 页面无 emoji 标签、无硬编码靛蓝；三栏布局与全部功能保留。
- 加载/空/错误三态齐全；交互有 hover/press/focus 反馈。
- `tsc` 0 错误；构建产物可运行；CDP 全流程通过。
