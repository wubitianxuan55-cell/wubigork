# 众神殿 V2 优化规划(2026-11-03)

> 依据:pan_1793681319746(9 轮,26 条发言,四席代码级核验+外部研究交叉)讨论全文提炼。
> 该场结论与 2026-11-03 已落的「议事质量五刀」(839c5c68)互补:五刀治 prompt 层,
> 本规划是四席收敛出的**机制层**共识,按证据强度与依赖排序。

## 主线判断(四席多轮收敛,无一席反对)

校正、留异议、收口是三件不同的事;当前实现把三者都压在「自然语言发言流+末端汇总」上,
结构化只发生在最后一刻,不回灌轮次。外部研究(Codex r9 双源复核+仓内
docs/gaea-pantheon-market-research-2026-10-29.md 交叉):**自由多轮辩论不稳定优于
独立作答+集成**——辩论轮的价值在证据校正,不在多聊。

## P0 真相单源化(其余一切的字段都会记在被覆盖的视图上)

四席用两场实弹+代码链钉死的三层同族病:

1. **席位状态冻结**:seatstate 终态只许自环(单次 attempt 正确),但 Participant 对象
   跨轮复用→第二轮起 running/failed 写不进,Status 永远 finished;Gaps 只读 Status
   →末轮 1/4 席在场仍报「无缺口」,Partial 用累计 successful→false,签注指纹覆盖不到缺席。
   12 轮场实证:58 条状态拒绝 warning,zcode 缺席 11 轮、汇总选了空结果的 zcode。
2. **假门与插话擦除**:五个人类入口(插话/门/问/答/解门)各自 get-copy-save,活循环
   高频保存点秒级擦掉它们;手动 OpenGate 改磁盘副本活循环看不见;ResolveGate 无活跑
   守卫+cancel 覆盖→**双活循环并发写同一会话**(zcode r6 静态推演,守卫缺失是代码事实)。
3. **修法共识(zcode r6 e + grok r8 b + codex r9 a)**:
   - 事件投影纯函数:按 CallID 重放 agent_started/output/error/skipped 现算
     started/succeeded/failed/skipped/not-started,签注时必填,不落第二份字段;
   - 挂账队列+交付收据:五入口只投队列,run 循环在停车点 drain 进 history,每个贡献
     ID 记交付收据;结案门=收据覆盖全部挂账,未消费插话 ID 进签注哈希;
   - 轮边界具名控制动作(OriginLauncher+抬 Incarnation),不放宽转移表、不复用
     rebindSeatLocked(那是 OriginUser 通道,grok r8/codex r9 双确认);
   - 前置:session.json 单写者+版本检查持久化(原子写只防半截 JSON,不防旧对象
     覆盖新事件——codex r9)。

## P1 收口机制改造(治「永不收口/收口失真」)

1. **分歧台账**:按分歧点(非席位)记账 `{issue_id, 主张方, 异议方, 证据句柄, 翻转条件,
   状态, 是否阻塞, 下一步核验, 去向}`(codex r9 b 收窄为「只影响推荐的主张」,不全量);
   每轮注入、逐条闭合、默认保留开放项,不因汇总没复述就消失;用户插话进同一账本。
2. **翻转举证**:共识信号翻转必须附「被哪条证据说服」,否则记 conformity 不算共识
   进展(外部:Not All Flips Are Conformity 等,多 agent 翻转多是从众)。
3. **停机判据**:「剩余分歧≠无」进停机条件(现 consensusMarker 只认共识行,「自报一致+
   正文藏分歧」可同时成立且测试已固化为预期——grok r2 实测);继续/停止由「有无下一轮
   实际减少不确定性的核验动作(DID)」决定,dsh r4:unresolved 是主张状态不是续跑决策。
4. **收口检查并行隔离**(grok r4):末轮问「若现在签注你是否会签」而非「是否同意」,
   复用第 1 轮并行隔离形态——逼出「方向同意但这条不敢签」的保留。
