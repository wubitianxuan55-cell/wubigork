## 一、板块总评

横切面的结论只有一句话：**gaea 的问题不是「某个文件太大」，而是「同一件事有 N 份实现在跑」，且没有任何机器守卫阻止 N 继续变大。**

三档历史审计（optimization-direction / whisper-deadcode-survey / backend-perf-survey）把「重复实现」列为 P1-3、把「死码口径」列为 P1-6，方向完全正确；但 v4.451.0 的现场是：截断函数从审计时记的 8 份涨到 **41 个定义**（主编现场 grep 复核），分词器 6 份、原子写样板 22 处、图片后端 switch 5 份、GenUI 白名单 3 份、成本写路径 3 份、编排 3 套、BM25 3 套。**没有一处收敛动作配了 CI 门禁**，所以每一次「收敛」都在下一版被重新复制回去。同理，死代码不是散件而是整条路径（whisper 桌面助手 2/3 条路由、`internal/visual` 全包、`validateGenuiSpec` 整条前端校验通道、`SpawnPolicy` 全族）。

复发型缺陷（heredoc 转义 5 犯、Windows unlinkat 3 犯、`*core` 嵌入 nil panic 3 犯、gen_bindings 重生成噪音）之所以反复，根因与上面完全一致：**AGENTS 的 7 条防复发规约只落成文字，`frontend/eslint-rules` 至今只有 `index.js` 与 `no-raw-hex.js` 两个文件（主编现场核实）**。

## 五、观察项 / 未定论

- **W1（主编现场复核所得，重要）**：单元 JSON 记录的 `internal/app` 规模（235 文件 / ≈54.3k 行 / 5 个文件 >800 行）与主编在写稿时对工作树的实测**不一致**。实测：`internal/app` 非测试 `.go` 文件 236 个、合计约 50,247 行；`>800` 行者 3 个（`gaea_ui_extra.go` 994、`image_handler.go` 945、`whisper_handler.go` 867）。单元 JSON 记的 `gaea_ui_extra.go` 1188 行、`image_handler.go` 1095 行、`whisper_handler.go` 943 行、`create_chapter_handler.go` 864 行、`characterlib_gen_handler.go` 820 行均高于现场值（现场 `create_chapter_handler.go` 795 行）。可能原因：单元审计基于的行数工具口径不同（含空行/末尾行），或快照与工作树存在版本差。**结论取向**：X1-05 的「规模反涨、验收线未达」判断仍然成立（现场 3 个文件仍超 800 行线），但**具体数字与文件清单需以 W1 实测替换后才可作为验收基准**。同类差异另见 `app.go`（单元 746 vs 现场 663）、`whisper/orchestrator.go`（1033 vs 857）、`gaea/control/controller.go`（963 vs 882）、`grep.go`（201 vs 185）、`CHANGELOG.md`（单元 6987 行、1.28MB）、`.gaea/AGENTS.md`（单元 136 vs 现场 122）。
- **W2**：`P1-1` 的「单文件 ≤800 行」是否仍为有效验收线需用户确认——v4.436 用的是 `>50KB` 字节口径（拆了 5 件并宣布破防线归零），两条口径并存；本分册按审计档原文的行数线判定为「未达」。
- **W3**：`frontend/package.json` 版本 `4.128.0` 是否属刻意与产品版本解耦（前端包版本 ≠ 产品版本）需确认；若属刻意，X1-10 该条应改为「文档说明」而非「漂移」。
- **W4**：`281` 个同名遮蔽绑定的当前实数未复算（需跑 `go run ./scripts/gen_bindings -names`，属禁止的构建类命令）；本分册只核实到生成器已改为显式告警 + `shadow-diag` 脚本入库 86 行。
- **W5**：whisper「全仓零引用 7 文件 550 行」与「仅测试引用若干」无法在只读且禁跑 `deadcode` 的前提下复核；只能以 ackem 标记数（实测 226 处 / IN4 记 228 处）与文件规模间接说明。X1-04（`ConfirmSvc`/`DeliveryCoord`）已由主编现场 grep 独立确认零读取。
- **W6**：`P2-1` 甘特库 spike 与 `P1-4` 效果验证闭环（技能结晶复用率 / 路由建议采纳 / 录制复跑）属产品决策与真机走查，无当前代码证据可判，未计入 findings。
- **W7**：`docs/AGENTS` 在本仓不存在（只有根 `CHANGELOG.md` 与 `.gaea/AGENTS.md`、`.gaea/progress.md`），足迹里的「docs/AGENTS」按 `.gaea/AGENTS.md` 理解并据此对账。
