## 2. P1 对话流（本轮落地）

- 变更：`chat` 板块 manifest.space `shared → play`（Go + TS 同构），注释
  「§10.3 对话降为对话流：工位对话在办公工作台（gaea 任务台）内，乐园=会客厅
  沉浸对话」。
- 效果：工位 rail/首页不再出现「聊天」独立板块；乐园 rail/首页保留
  （会客厅）。NAVIGATE 事件白名单叠加空间校验自动生效（play-only）。
- 验收：space/launcher 单测同步；工位工作台（GaeaPage）对话功能不受影响。

- 微信任务入口 → v4.4。
- 记忆侧栏进一步内聚 → 随工位工作台演进（现状已实质达成）。
