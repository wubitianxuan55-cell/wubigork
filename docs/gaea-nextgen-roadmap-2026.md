## 读前一分钟（大白话）

> 下一代 gaea = **同一台电脑里的两间房，中间有墙，互不干扰**（用户拍板）。

- 🏢 **工位（工作）**：一个管家 + 一个任务工作台。你说"把这 12 份报表算成报告"，他自动
  取资料、调工具、干给你看；每一步可查、可回退；记得你的项目。里面是：办公、造价、编程、资料与工作记忆。
- 🏖️ **乐园（娱乐）**：会客厅（轻语陪伴）+ 书房（小说）+ 画室（绘梦）+ 阅读。沉浸、私有、
  记得你的角色。**不掺和工作**——陪聊时它绝口不提你的报表，你干活时它不来打扰。
- **共享的只有家底**：一个安装、模型设置（工位/乐园可各绑各的策略）、本地文件。
- **跨一次门**：只有你主动说（"把乐园画的封面放进报告"）才发生，默认不通。
- **版本**：v4.0 双空间外壳 → v4.1 办公信任链 → v4.2 造价 AI 化 → v4.3 乐园做深 → v4.4 触点（微信/语音/离线）。

## 0. 总览 · 一句话

行业已收敛到「**agentic 委托 + 规划-审阅-执行**」这一共识治理范式；同时「**记忆即操作系统**」
」和「**本地执行权（数据不出机）**」成为 2026 真正的分水岭。gaea 的独特生态位是：
**唯一把「本地优先的桌面办公 agent + 个人长期记忆 + 造价垂直数据库 + 创作/陪伴模块」装进
一个本地应用**。这既是护城河，也是风险（每个单项都有更强的专才对手）。
**用户拍板：工位 / 乐园双空间隔离——工作与娱乐分开、互不干扰（见 §10）。**
下一跃不靠堆功能，而靠把 gaea 从「对话工具」升级为 **「有记忆、会生长、可审计的本机个人 AI 操作系统」**。

### 全局范式迁移（决定所有板块上限）
1. **记忆从「存储」→「操作系统」**：分页/固化/遗忘/冲突消解（MemOS / Letta / Zep-Graphiti 路线），分层 + 后台固化 + 图谱化关联。
2. **上下文工程取代 prompt 工程**：长程 agent 四件套（compaction、structured note-taking、sub-agent、just-in-time context）；上下文成为按任务「编译」的产物。
3. **本地-云端分层智能**：按 质量/成本/隐私 三目标动态路由，语义缓存 + prompt 前缀缓存（省 50–90% 输入成本）。
4. **MCP 工具生态事实标准**（2026 进入主流采纳期）+ 多 agent 并行。
5. **多模态成为桌面默认入口**：语音/视觉/文件感知（Windows Copilot 方向）。

### 全局革命性能力（底座层，所有板块受益）
- **统一记忆语义图谱**（三脑孤岛 → 图谱记忆网格）
- **上下文编译引擎（Context Compiler）**
- **本地-云端自动路由 + 成本仪表**
- **MCP 工具生态 + 多智能体并行会话与产物回流记忆**
- **「做梦 2.0」= sleep-time compute 式自愈/预取**

## 1. 通用办公（核心价值板块）

### 市场格局
- **Microsoft 365 Copilot Agent Mode**：把 Word/Excel 推向「vibe working」（受控自主建表/改文档/跑分析，每步可暂停）。强：Excel 引擎深度耦合、企业治理。缺：云端绑定、中文文书规范弱。
- **Google Workspace Gemini**：Deep Research 直引 Drive/邮件做长报告，打通「研究→文档」。缺：不做细粒度文件编辑。
- **WPS AI / 灵犀**：国内覆盖最广（活跃设备 6.78 亿）、红头套红公文排版生态。2026-07 升级为独立 AI 办公 Agent「**灵犀专业版**」（见 §12）。缺：能力多为功能点而非长程任务编排。
- **Manus**：通用数字员工，文件精度与审阅机制粗。**Kimi Work**：月之暗面「知识工作者的通用型本地 Agent」+ 中国职场任务（办公桌面双雄之一），缺 Office 结构级编辑与持久项目记忆。
- **腾讯云 WorkBuddy**：CodeBuddy 旗下全场景 AI 办公工作台（见 §12），首发「人机双写」，从「接管」转向「协作」。
- **飞书 Aily / 通义 C 端 / Notion AI / ChatExcel / Claude 桌面 + MCP**（桌面接管 + 文件 diff 编辑）。

### 范式迁移
1. 对话改文件 → **委托式完成**（目标+约束，人退验收位）。
2. 文件即结果 → **文件即工作空间**（把用户资料当上下文）。
3. 会话即丢弃 → **记忆即操作系统**（跨会话项目连续性 = 分水岭）。
4. 治理收敛到「**规划→审阅→执行**」（已行业共识，非差异化；新护城河在**审阅之后**：可追溯/回滚/复核）。
5. 接管 → **人机双写**（保留人的在场感）。
6. **本地执行权**成为桌面新战场（镜像位置对位云端巨头）。

### 革命性跃升
1. **可追溯证据链 + 事务日志（Apply→Verify→Journal 三段式）**：每次变更绑定证据卡（来源文件/单元格/检索片段/模型+时间戳），一键回滚、审计导出。巨头云端做不了本机留痕。
2. **自动复核闭环（Verifier Agent）**：Apply 后双通道复核（公式重算/引用完整性 + LibreOffice 无头渲染 PDF 与原文视觉 diff），pass/warn/fail，失败回 Plan。
3. **多文件任务图（DAG）编排**：「读 12 份报表→透视→嵌图表→生成 Word→统一导 PDF」跨格式任务图，每节点单独 steer/重跑/验收。
4. **记忆驱动的项目本体**：三脑记忆 →「项目事实表」（口径/模板/命名规范/历史决策），Plan 显式注入「依据第 N 次会话决策」。
5. **中文文书规范引擎**：GB/T 9704 红头、盖章位、造价/工程表式做成可校验「规范包」（lint + 排版模板 + 体检报告），补 WPS 教程生态与通用 Agent 都未产品化的强合规缺口。

### 优先级
- **现在（0–3 月）**：证据链 + 复核闭环（把 Plan→Apply 先发变「可审计、可回滚」护城河）。
- **下个（3–6 月）**：多文件 DAG 编排 + 项目本体记忆（对齐编排潮流，守「本地工作空间」差异化）。
- **愿景（6–12 月）**：中文规范包生态 + 本地优先品牌（政务/造价/工程刚性付费）。

## 2. 造价数据库（垂直蓝海 · 最可防御）

### 市场格局
- **全国龙头**：广联达（GCCP7.0 市场化计价 + 算量 GTJ + 指标网/广材助手 = 国内最大数据池；AI+数据范式；license→云订阅）。
- **区域强手**：斯维尔（清华系 + DeepSeek 智能建造大脑 + 自动套定额专利）、品茗、鲁班（BIM+云指标库）、新点、鹏业/宏业、湘源。小厂 AI 化 = 接 DeepSeek + 单点专利。
- **价格大数据层**：造价通（中建普联）信息价/厂商报价/指数，数据层与工具层分离。
- **企业成本 AI**：新中大「成本测算大模型智能体」。
- **壁垒本质**：不是功能，而是**数据闭环**（定额库 × 历史项目价格 × 持续报价流）。
- **国际对标**：Togal.AI / Kreo / ConstructConnect AI 算量；RSMeans 被当 AI 检索库；Procore vs ACC 平台级成本管理。验证两条路：**成本数据库 = AI 可检索知识** + **估算 AI 化**。

### 范式迁移（政策拐点）
2025 年 GB/T 50500-2024 新清单落地，定调「告别定额依赖、价格由市场说了算」——计价依据从**政府标尺转市场罗盘**。四级跳：①单机→云协同；②人工组价→**AI 组价**（描述/图纸→清单→人材机→价格带）；③静态指标→**动态指标知识库**（实时价×私有数据归因）；④项目内算账→**全过程成本 + 数据资产化**。大模型机会集中：组价、询价、指标归因、风险预警四个「数据密集+判断密集」环节。

### 革命性跃升（记录系统 → 生成+预测系统）
1. **AI 组价引擎（记录→生成）**：清单描述/图纸/报价单 → 分类定位→相似清单检索→人材机拆解→价格带推荐（P25–P75+置信度+证据链）→一键确认回写。现有溯源字段天然是证据格式——对手没有的先天优势。
2. **动态价格大脑 + 智能询价（静态→时序）**：信息价+OCR 报价+供应商比价三源融合→异常检测、到期预警、自动调差、短期预测；每张 OCR 报价单自动变询价库数据点，反向生成询价单——**询价数据飞轮**。
3. **成本知识图谱 + 归因式对标（树→图）**：专业→分部→清单→定额→工料机升维为图谱；对标从「P50 差多少」进化到「**为什么差**」。
4. **全过程成本动态（快照→生命周期）**：测算容器+版本快照延伸到**五算对比**（估概预结决）与动态成本（已发生+完工预测），复盘笔记 AI 自动生成偏差诊断与风险预警。
5. **企业定额自生成 · 数据资产化（外部库→私有资产）**：多项目结算反推企业真实工料机消耗，自动形成「企业定额」——广联达有公共数据但没你的私有真相，自进化飞轮即私有壁垒。

### 优先级
- **现在（0–3 月）**：AI 组价 MVP + 价格时序化（命中 24 清单市场询价痛点，全复用现有溯源字段）。
- **下个（3–9 月）**：知识图谱+归因对标；OCR→比价→询价 agent 闭环；五算对比容器。
- **愿景（9 月+）**：企业定额自生成、全自动组价（人审例外）、新项目成本预测分布、脱敏指标共享生态。

## 3. AI 底座（对话 + 记忆/知识库 + 模型中心）· 全局天花板

### 市场/技术格局
- **客户端**：Cherry Studio（多供应商+MCP+知识库）、LobeChat（生态化 + MCP Market）、Jan/LM Studio/AnythingLLM（本地模型+本地知识库）。趋势：客户端从「聊天窗口」→「模型×工具×知识」编排壳。
- **路由**：OpenRouter（统一 API + fallback + 最低价）、Not Diamond（可训练按难度路由）、RouteLLM；三类降级（预算/质量/可用性 fallback）。
- **记忆**：Mem0（省 91% token）、Letta/MemGPT（self-editing memory + sleep-time）、Zep/Graphiti（时序知识图谱）、LangMem（formation→retrieval→consolidation）、MemOS（记忆操作系统，明文/激活/参数三类调度）；ChatGPT/Claude 消费级记忆。
- **RAG**：NotebookLM（源绑定）、GraphRAG/Neo4j（多跳图谱）、Dify/AnythingLLM（工程化）；共识 = 向量+BM25+rerank 标配，前沿转向图谱多跳与 agentic 检索。

### 范式迁移
记忆从「存储」→「操作系统」；上下文工程取代 prompt 工程；latency/成本分层；MCP 化；多模态默认入口。

### 革命性跃升
1. **统一记忆操作系统：三脑 → 语义图谱记忆网格**。升级为 Zep/Graphiti 式时序知识图谱 + MemOS 式分层调度；[MEM:name] 从名字寻址 → 图节点寻址（实体/事件/来源三向边）；90 天保留变图谱上的「固化-衰减-归档」生命周期引擎。**落地：以现有事件日志为唯一事实源投影出图（SQLite+向量列+邻接表即可起步，不必先上 Neo4j）——日志即真相使图谱可随时重建，gaea 独有优势。**
2. **上下文工程引擎（Context Compiler）**：32KB 预算 + 3 层渐进披露从静态规则 → 按任务意图编译：意图分类→预算调度器（memory/files/tools/examples 配额）→前缀稳定排序（命中供应商 prompt cache 省 50-90%）→装配产物可 diff 可回放。
3. **本地-云端分层智能自动路由**：从「办公默认本地」→ 三目标（质量/成本/隐私）动态路由：本地小模型先答，置信度低/任务难自动 escalate 云端，sensitive-local 硬约束不变；失败降级 + hedging（多供应商竞速）；每条消息显示「由谁回答、为何、花了多少」。
4. **MCP 工具生态 + 多智能体并行会话**：gaea 作 MCP host 接入开放工具生态；深度研究/编码任务拆发子代理，产物自动回流记忆库成可引用节点。
5. **记忆驱动自愈 + 「做梦 2.0」**：指纹去重 no-op → sleep-time compute：后台合并冲突记忆、生成缺失摘要、对话前主动召回（prefetch），检测「回答与记忆矛盾」触发自愈。

### 优先级
- **现在（0–3 月）**：Context Compiler MVP + MCP host client（先 tools 后 resources）+ 蒸馏 no-op 转真实合并与主动预取。
- **下个（3–9 月）**：记忆语义图谱、路由策略 v2（难度分类器+成本仪表+escalate+hedging）、多智能体并行会话与产物回流。
- **愿景（9–18 月）**：完整记忆操作系统（跨设备可移植记忆包、遗忘权、生命周期图谱化）；多模态桌面入口 + 全离线；自愈闭环（记忆-路由-工具三层联动）。

## 4. 编程板块

### 市场格局
- **IDE 内置**：GitHub Copilot（agent mode→coding agent 自主开 PR）、Cursor/Windsurf/Claude Code/Antigravity；国内 Trae、通义灵码、腾讯 CodeBuddy 爆发（IDC 确认中国 AI Coding 陡增）。
- **独立自主 agent**：Claude Code 2.0（checkpoints/subagents/hooks）、OpenAI Codex、Devin（Cognition 并购 Windsurf 双形态）。
- **本地/自托管开源**：OpenCode、OpenHands、Aider、Continue、Cline（模型自由+可审计）。
- **内嵌形态**：Claude Desktop 以 MCP host 内嵌 agent。gaea「iframe 嵌 DSH」目前**有壳无融**（agent 与桌面能力/其他板块零互通）。

### 范式迁移
补全→码头级自主（任务书进、测试/PR 出）；单上下文→仓库级+子代理并行（仓库即知识图谱检索层）；直接改盘→**沙箱试运行**；黑盒→**轨迹可观测**（harness 是编码 agent 性能核心变量）；工具面 MCP 标准化；多 agent 团队。

### 革命性跃升
1. **从「内嵌一个 Web」到「原生编程工作台 + MCP 板块总线」**：短中期保留 DSH（harness 成熟），Wails 做原生壳消灭 iframe 割裂；关键杠杆 = **Wails v3 原生 MCP service**——把办公区/知识库/记忆各包成 MCP server 喂给 DSH，agent 即可「读需求文档→写代码→把产出写回办公区」。**这是 Claude Code/Cursor 结构上做不到的（无办公/知识板块），gaea 独有护城河（共享记忆被验证为编码 agent 刚需）**。自研内核仅在 DSH 无法承载总线时启动（重造沙箱/审批/上下文管理成本极高）。
2. **子代理并行驾驶舱**：把 DSH 的后台 agents/审批/轨迹/任务提为 Wails 原生侧栏（多 agent 看板、checkpoint 回放、diff 审批卡）。
3. **沙箱试运行 + 权限分级默认化**：改动先落 Docker 试跑，测试绿才落主工作区；权限四档（只读→工作区写→命令执行→网络）。
4. **本地模型离线编码模式**：Ollama/vLLM 跑 Qwen3-Coder/GLM，满足「数据不出域」刚需（云端竞品盲区）。

### 优先级
- **现在（0–1 月）**：iframe 体验加固（断连自愈/外链唤醒/徽标语义化）+ 挂第一个只读 MCP server（知识库）。
- **下个（1–3 月）**：原生侧栏驾驶舱 + Docker 沙箱试运行 + 权限分级 + 记忆共享接入。
- **愿景（3–12 月）**：Wails v3 原生窗口 + 反向 MCP 工具（窗口/通知/文件对话框反哺 agent）；本地模型模式；多 agent 流水线模板（需求→编码→测试→评审，跨板块拉知识库/办公）。

## 5. 小说创作

### 市场格局
- **AI 长文工具**：Sudowrite（Story Bible + Chapter Continuity 跨章一致性，卖点「活过第 25 章」）、NovelAI（长文续写+角色卡）；开源极客侧 graphify-novel（知识图谱一致性审稿）、novel-agent（story bible 桌面工作区）。Claude/GPT/Gemini 靠超长上下文切万字连贯，但无结构化世界观管理——**「长上下文」≠「创作约束」**。
- **中国平台内**：阅文作家助手·妙笔（千万字理解）、番茄作家助手（章节风险提示/AI 味检测）。**平台强反制**：晋江 2025 反 AI「三道安全线」、「一键生成」小说批量下架；「删 300 字 AI 套路完读率反升 22%」。
- **互动/伴读**：AI Dungeon、Character 类角色扮演；中文伴读/推文 AI 空缺。

### 范式迁移
逐章生成 → **一致性世界模型**：学术收敛于「动态分层大纲+记忆增强」/「认知分层多智能体长篇生成」/「图基叙事架构」/「长短时记忆世界模型」。**共识：超长上下文只解决"读得下"，结构化设定库+实体状态跟踪+一致性校验才解决"写得对"**。中国市场特殊性把矛头指向「**文风**」（连载节奏/爽点钩子/断章是硬通货），而「AI 味」已成平台判定红线。

### 革命性跃升
1. **Story Graph 世界模型引擎**：设定库从「文档页」→ 知识图谱（人物/地点/物品/规则/时间线 + 关系边）；Go 侧新增 `graph` agent 写图+按子图检索注入；React 侧 react-flow 全书脑图。本地图谱可解释可编辑（别家 Bible 是文档、平台是黑盒）。
2. **伏笔与剧情检查器（Continuity Linter）**：章后抽取实体状态 diff（伤势/持有物/承诺/时间）自动更新；伏笔「登记→埋设→回收」全链路跟踪 + 冲突告警；检查面板 + 回收甘特图。
3. **角色人格一致性记忆**：角色库「记忆隔离」→ 每个角色维护「他知道什么/不知道什么」**视角掩码**，支持多 agent 角色视角推演审稿（A 角色不该知道第 3 章的秘密）。
4. **文风克隆 + AI 味中和**：story-deslop 升级为「文风指纹」（句长分布、口头禅、平台 AI 味套路黑名单），生成后「打分→定点重写」闭环——直接回应晋江/番茄检测现实，gaea 独有的市场对位。

### 优先级
- **现在（0–3 月）**：Continuity Linter MVP + 伏笔登记表（复用 chapter/worldview agent，竞品验证过的最小差异化切口）。
- **下个（3–6 月）**：Story Graph + 全书脑图 + 角色视角掩码（把产品从「生成器」变「一致性编辑器」，长期护城河）。
- **愿景（6–12 月）**：文风指纹体系 + AI 伴读角色扮演 + 分支叙事/互动小说导出 + 本地「创作过程账本」（可追溯 AI 辅助度，对齐平台原创性政策）。

5. **真人记忆迁移（数字分身/纪念模式）**：导入聊天记录/照片/语音构建真人风格人格，用于思念陪伴或自我分身；本地优先+知情同意+情感安全护栏，把桌面端「数据不出机」变成对云端 App 的降维优势。

## 8. 微信助手 + 语音

### 市场格局
- **微信/IM AI**：官方收紧入口（元宝进微信、微信 Agent 灰度、小程序接口首批内测、腾讯元器分发）。个人接入（wechaty/chatgpt-on-wechat）踩非官方协议（iPad/Hook），封号风险高；MuseBot 等多端默认转企业微信/飞书/Telegram。

### 范式迁移
- **IM**：远程对话终端 → **AI 门户/远程任务入口**（微信成为桌面 agent 的遥控器）。
- **语音**：ASR+LLM+TTS 拼接 → **端到端实时语音**（语音进语音出、可打断、带情绪）。gaea 的 Seam 注册表架构是承接两者的插座。

### 革命性跃升
- **微信助手**：① **远程任务入口**（语音条→文字、发图即识别、一句话触发 生图/办公/记忆，返回文本+文件卡片）；② **定时提醒/主动推送**（微信下发定时任务，桌面端执行后回推——官方元宝不做、桌面 agent 独有的「离线代办」）；③ **合规降险**（企业微信/公众号为主通道，ClawBot 仅限个人小号，协议层做成 Seam 可切换）。
- **语音**：① **端到端实时语音对话**（接 Qwen3-Omni/Fun-Audio-Chat 本地或云端 Realtime API，语音进语音出、可打断、<1s 带语气）；② **情感+音色**（CosyVoice2 叠加克隆音色与情感参数，与轻语陪伴打通——陪伴没有情绪就没有灵魂）；③ **语音控制桌面**（JARVIS 模式——「打开 X、生成 Y、读一下屏幕」，语音作 gaea 全模块的免提入口）。

### 优先级
- **现在**：微信任务化改造（语音条/图片/触发已有能力）+ 定时提醒回推（复用幂等/钩子，beta 变真入口）。
- **下个**：端到端实时语音档位（云端 Realtime API 先行）+ 企业微信合规通道（范定型，观望即落后；封号风险须前置规避）。
- **愿景**：本地端到端语音（Qwen3-Omni 级）+ 情感陪伴 + 语音控制全 app。

**一句话**：微信助手从「能聊天」跃升为「**能接活的遥控器**」（合规通道保命），语音从「能出声」跃升为「**能对话、懂情绪、可打断的桌面声音入口**」——两条线汇合于一点：**任何地方、用任何模态，唤起同一个 gaea**。

## 9. 全局定位 · 差异化总战略

### gaea 独有差异化
1. **唯一**把「本地优先办公 agent（plan-then-apply xlsx/docx/pdf）+ 三脑记忆 + 做梦蒸馏」与「创作/陪伴/造价垂直」装进一个本地应用；对手要么 chat+RAG（Cherry/AnythingLLM），要么云端 agent（Manus/Kimi），从不同时具备。
2. **造价数据库** = 真·蓝海：企业级定价的广联达之外，无 AI 原生、个人成本库 + 分位数对标。
3. **跨模块飞轮**：世界观/角色→陪伴；文档→记忆；造价库→办公 agent。
4. **模型无关 + 内嵌编码板**：无订阅锁定、免费本地编码 agent（中国本地 Cowork 替代）。

### 蓝海机会（下一迭代可切入）
1. **造价 prosumer 个人版**：卖给个体造价工程师/咨询人——Excel 与广联达之间的空白。
2. **「个人数据保险柜」定位**：本地优先合规叙事，面向律师/设计院/自由职业者处理敏感文件。
3. **模板/约定市场**：可共享任务模板 + `.gaea/AGENTS.md` 包，形成巨头无法复制的用户生态。
4. **双空间定位（用户拍板 2026）**：不搞「陪伴×办公融合」——**工作（工位）与娱乐（乐园）分开、互不干扰**。工位主打「本地优先 + 可审计 + 记得你的项目」；乐园主打「本地私有 + 沉浸 + 记得你的角色」。比"融合"更可辩护：监管只管乐园、审计只管工位、记忆互不污染。
5. **中国本地「Claude Cowork 替代」**：以「开放、免费、本地优先」营销内嵌编码板 + 模型中心。

### 风险 / 待解
- **单用户、无移动/云同步**：所有大对手都多端，限制触达与留存。
- **广度 vs 深度**：每个模块都面临更强/更专的对手（WPS 文档、猫箱陪伴、广联达造价）。
- **合规**：情感陪伴规则、生成式 AI 备案增加商用成本；微信助手处灰色地带。
- **分发**：零品牌 vs 豆包/Manus 的营销机器；输出质量仍依赖 Grok/DeepSeek API。

## 10. 版本划分重定义：从「板块制」到「任务空间制」（审视版）

> **自省**：本节上一版沿用了现有板块做 T0–T3 排期——那是「重复现状」，不是「审视」。
> 以下为审视后的重定义：先质疑划分本身，再给新版本语义。

### 10.1 三个审视发现（为什么板块制是错的）

1. **板块 = 开发史的效率单位，不是用户价值单位**。10 个板块边界由 2.x 时代逐次加功能
   形成，而不是按用户价值切分。后果是**基建重复**：记忆管线在办公（三脑）、轻语（记忆
   管线）、小说（角色记忆）各造一套；会话管理多套并行；**每次「板块加功能」只让壳变大，
   系统没有变深**。
2. **gaea 是两个产品共用一个壳**。生产型（办公/造价/编程/知识库：度量=结果可信/可追溯/
   效率，原则=克制/确认/审阅）与情感创作型（轻语/小说/绘梦：度量=留存/沉浸/爽感，
   原则=流畅/模糊/情绪化）——两种设计哲学在并列导航里互相拖累。
   **用户拍板（2026）：解法不是融合，而是双空间硬隔离**——工位（工作）与乐园（娱乐）
   分开、互不干扰：各有一套交互哲学、记忆、模型策略与消息面，共享的只有最底层家底。
3. **竞品已集体叛逃板块制**。WorkBuddy 是项目空间（任务/项目/专家），灵犀是项目栏
   （官方原话：解决 AI「反复重新入职」），Claude Cowork 是文件+任务，Copilot Agent Mode
   是目标驱动——下一代组织单位是「**项目/任务空间**」，不是「功能板块」。用户不是
   「带着板块来」，是「带着任务来」：「12 份报表→算成本→做图表→写报告→出封面」是一个
   任务，不该切三个板块。

### 10.2 三轴模型（版本按轴定义，而非按功能并列）

- **空间层（第一分区，用户拍板）**：🏢 **工位**（办公/造价/编程/资料+工作记忆）与
  🏖️ **乐园**（轻语/小说/绘梦/阅读）——两套交互哲学、两套记忆、两套模型策略；
  **默认硬隔离、互不串门**；跨空间只能由用户显式发起（如「把乐园画的封面放进报告」）。
- **内核层（共享家底）**：记忆 OS · 上下文编译 · 分层路由 · 工具总线(MCP) · 事件日志 ——
  一次投入、全部受益；**记忆引擎共用，但工位/乐园各占隔离分区**（工作记忆 vs 角色/关系记忆，互不检索）。
- **领域包**：工位 = 办公包 · 造价包 · 开发包；乐园 = 创作包(小说×绘梦) · 陪伴人格(轻语) ——
  可插拔，按成熟度升级（记录→生成→预测/资产）。
- **触点层（空间感知）**：桌面 · 语音 · 微信/IM · 移动 —— 同内核多入口；微信/语音指令
  默认面向工位，语音闲聊走乐园，互不串扰。

**每次发布 = 一次「层跃升」或「领域包成熟度跃升」，不是功能累加。**

### 10.3 现有板块处置表（生死审视）

| 现有板块 | 归属空间 | 处置 |
|---|---|---|
| 对话 | 共用 | 降为「对话流」：工位=任务台对话 / 乐园=沉浸对话；取消独立导航 |
| 记忆中枢/知识库 | 工位 | 降为工位侧栏「记忆/资料」面板（工作记忆），无独立入口 |
| 模型中心 | 共用 | 降为设置（引擎/资源管理）；**工位与乐园各自绑定模型策略** |
| 通用办公 | 工位 | **升格为工位空间主体**（任务制工作台） |
| 造价数据库 | 工位 | 降为「造价领域包」（工位内数据域+工具） |

- **可反超缺口**：**深度绑定 WPS 云文档，本地散文件 agentic 操作弱**；表格深编辑与审阅制缺失；无本地优先卖点；多 Agent 分工与轨迹可视化浅；**无编程/生图联动**。

### 12.4 反超策略 · 五个革命性跃升
1. **文档即智能体工作空间**：打开的文件即 Agent 画布，修订/批注/单元格全差分预览，Plan→Apply 扩至 docx/pdf，一键回滚——超越 WB 技能式与灵犀"WPS 落地"。
2. **可追溯证据链**：每个修改/结论锚定来源（本地文件页码、知识库条目、网页），一键生成审计报告——两家均无，直击办公信任痛点。
3. **记忆驱动"项目人格"**：做梦蒸馏升级为自动项目记忆（章程、干系人偏好、被否定方案库），跨会话复活上下文——比灵犀更自动、比 WB 更个人。
4. **多文件 DAG 编排 + 审批治理**：任务中心把多文件流水线可视化为可插话的 DAG，GaeaSteer 运行中改向，危险操作分级审批，本地沙箱全程透明。
5. **本地智能中枢**：离线 RAG + 本地记忆蒸馏，"数据永不出机"作政企信任卖点，可选云端模型路由补智力。

### 12.5 优先级
- **现在（0–3 月）**：跃升 1+2（文档即工作空间 + 证据链 v1），**吸收灵犀记忆三分法入三脑记忆**（已确认要求/临时尝试/被否定方案——这是两家验证过的强范式，gaea 直接学）。
- **下个（3–9 月）**：跃升 3+4（项目人格、多文件 DAG + 审批分级），兼容 MCP/Skill 生态标准借力市场教育。
- **愿景（9 月+）**：跃升 5——本地智能中枢 + 小团队多 Agent；商业化"**本地免费 + 云端订阅**"双轨，差异化 WB 纯积分云与灵犀 WPS 绑定。

### 12.6 一句话结论
WB 学「调度/生态/企业叙事」，灵犀学「项目空间/记忆三分法/助理与编辑器分工」；gaea 的反超牌是 **Plan→Apply 审阅制 + 可追溯证据链 + 三脑个人记忆 + 本地优先 + 多板块联动**——以「**能审计、有记忆、不出机、懂你文件的桌面个人 AI OS**」对位两家云端/生态型产品。

## 13. 四层落地设计：后端 / 前端 / UX / UI

> 总判断：双空间**不是换一套 UI，是给数据模型加"空间维度" + 两套壳**。gaea 已有底子
> （事件日志、Seam 注册表、project 包、办公板块完整工作流、三脑与角色记忆分开存储），
> 因此这是**升维 + 整合**，不是推倒重来：约七成能力已存在，缺的是挂到「空间 / 项目」
> 两个新主轴上，外加补掉审计出的地基洞。

### 13.1 后端（Go）：加"空间维度"，不复制两套

| 事项 | 具体做法 | 现状基础 |
|---|---|---|
| **space 维度贯穿** | session / tasks / 产物 / 审计日志 / 配置 全部加 `space_id`（work/play）；DB 加字段，事件日志行加维度 | 事件日志「日志即真相」已存在 → 加字段即可，不重建 |
| **记忆分区（隔离而非删除）** | 检索层之上放「空间隔离器」：work 记忆（三脑/知识库）与 play 记忆（轻语管线/角色记忆/作品设定）互不可见；物理仍在各自现有存储 | 本来就分开存储，缺统一语义：谁允许搜到谁 |
| **模型策略按空间** | 每空间一个 profile（provider + 预算 + 隐私档）：工位=本地办公优先+云端强模型；乐园=情感/创作模型+便宜档 | Seam 注册表已是插拔层，加 per-space 路由 |
| **工具面按空间装配** | 工具 Registry 加空间标签：work=文件写/文档/造价/代码；play=生图/小说/轻语/阅读；跨空间工具默认不可见 | Manifest 驱动 + Registry（借机修「Registry 无锁」审计项） |
| **任务/资源隔离** | 任务调度按空间分账：生图（GPU）与办公（CPU/IO）互不挤占，优先级可配——「不干扰」的工程含义 | jobs/tasks 已有任务表+取消+重试 |
| **审批策略按空间** | 同一权限引擎、两套策略：工位=审阅制（Plan→Apply、权限闸、证据链）；乐园=内容护栏（不弹审批卡，但有生成护栏与人格一致性参数） | permission 纯函数已有，hardAsk 连 yolo 也拦 |
| **MCP 总线** | work：办公区/知识库/记忆包成 MCP server 喂给编程 agent；play：绘图/小说工具外露 | Wails v3 MCP service |
| **前置修补（审计 P0/P1）** | ① 三个 map 竞态 + `-race` CI；② edit_file 层落实（文档即工作空间脊柱）；③ 知识索引缓存；④ 持久化套件统一 | 不做这些，其余全是空中楼阁 |

**关键判断**：选「加维度」不选「复制一套」——两套代码必然漂移更糟；与现有 manifest/注册表化方向一致。

### 13.2 前端（React/TS/AntD）：两套壳，一次重排

1. **壳层**：从「10 板块导航」→ 两种壳视图——**工位壳**（左项目/任务树 + 中对话/轨迹/上下文工作台 + 右过程/产物面板 + 底栏运行状态；把办公板块框架升格为全工位框架）；**乐园壳**（会客厅 + 创作间，氛围化、低信息密度）。
2. **页面重排**：pages/ 十板块页面按新壳归档；`gaea/**`（办公金标准）成为工位主体；轻语/小说/绘梦迁入乐园；**一次性把 i18n 铺满全壳**（现有 502 keys 字典复用，借壳层重写消灭混合语言）。
3. **性能前置（审计 P1）**：keepAlive 轮询门控（活跃空间/visibilityState）、聊天虚拟化+memo、mermaid 动态导入。
4. **接线收敛**：api/* + wailsjsCompat + bridge.ts → bridge 单点 + 按空间分门面（work/play/shared）；types 生成化；巨石组件顺手拆（ChapterPage 优先）。

### 13.3 UX：工位一条主线，乐园一片沉浸

- **工位 UX（任务工作台主线）**：把已有 计划卡 → 轨迹 → 上下文占用 → 审批卡 → 产物面板 →（新增）证据链 整合成一条可感知主线：说任务 → 计划给你看（资料/步骤/待确认）→ 执行中每步可见 → 关键动作你点头 → 完成给复核报告+每条有出处 → 可回退重跑。已有七成，v4.0 做「整合成主线」。
- **乐园 UX**：沉浸优先，不出现「任务/进度/审计」词汇；轻语=对话流+情感节奏（主动关心、语音）；创作间按「作品」组织（书稿/设定/角色/配图）；绘梦参数/工作流折叠进「专家模式」。
- **跨门交互（唯一交叉点，防误操作）**：只能由用户**显式发起**（拖拽/按钮「拿到工位」），带确认提示。
- **不干扰红线（成文）**：通知分开（工作回推 ≠ 乐园闲聊）；历史搜索默认只搜当前空间，搜索框提供「工位/乐园/全部」显式 scope；上下文装配永不跨界。

### 13.4 UI：一套 token，两套「氛围包」

- 沿用 Luminous Glass 体系不推翻，加**空间主题维度**：工位=冷色/玻璃/高信息密度/克制；乐园=暖色/柔和/留白/氛围光。
- **前置**：把现存 **151 个硬编码 hex 清零成 token**（审计已点名；语音设置浅色主题崩坏即此根因）——否则双主题无从谈起。
- 骨架复用现有组件：工位壳用办公板块成熟组件；乐园壳用轻语/小说/绘梦现有页面重排，不重写。

### 13.5 落地顺序与风险控制

1. **前置**（P0 修复 + edit_file + `-race` CI）——否则 v4.0 建在会崩的地基上。
2. **v4.0 双空间**：后端加 space 维度（session/记忆隔离/模型 profile/工具标签/任务分账）→ 前端新壳（两视图 + 页面迁入 + i18n 全铺 + 性能门控）。**渐进迁移，老导航保留一版后删除**，每步独立提交可回退。
3. v4.1 → v4.4 按 §10.4。
4. **最大风险 = 壳层重写** → 渐进迁移；办公板块已是「金标准」（审计确认），升格为工位框架保险系数最高；乐园三块是现成页面重排，风险可控。
