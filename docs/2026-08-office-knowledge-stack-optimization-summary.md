## 2. 检索分层（四库统一，全部本地）

```
SQL/关键词过滤 → 子串召回 →（不足时）bge-m3 语义召回
             → BM25 排序 →（>8 条时）bge-reranker-v2-m3 精排
```

- 语义向量统一存 `semantic_vectors`（Hephaestus.db SchemaV5），
  kind = cost / knowledge / office / file，id = 条目名或相对路径。
- Ensure **内容感知**：向量缺失或正文快照变化才重嵌（编辑过的条目自动刷新，
  不产生陈旧命中）；Stale 清理已删除条目；跨库统一检索（GaeaSemanticSearch）
  与文件语义检索（GaeaFileSemanticSearch）共用同一表。
- 本地模型：Herdsman bge-m3（embedding）/ bge-reranker-v2-m3（精排），
  全部零 token；模型不可用任一层自动降级。

## 3. 设计原则（贯穿各轮）

- **无确认不落库**：导入/AI 提取/价格更新一律预览确认后才写入。
- **来源可溯**：成本 source+期数、知识 source/author/reviewer、记忆
  sourceSession、价格历史与版本历史留档。
- **本地优先、云端统筹**：常规解析/提取/索引/检索走本地模型与本地软件；
  路由不固化，云端大模型按需调度本地工具。
- **增量而非全量**：语义索引、价格抓取、查重均增量/分批，控制开销。

## 4. 本轮新增/升级清单

- 成本库：导入+AI 提取、办公侧编辑/批量、价格源订阅+定时抓取、价格历史、
  异常识别（±20% 跳幅）、检索分层。
- 知识库：导入+AI 提取、批量管理、查重合并、版本历史+审核、批量导出、
  检索分层。
- 办公记忆：两两查重 + 一键合并（textsim 共享相似度）。
- 工作区文件：语义索引（fileindex，含 pptx 无依赖提取）、搜索面板语义模式、
  记忆中枢统一搜索并入文件语义命中、10 分钟自动重建。
- 共享基建：textsim、semantic（内容感知 Ensure）、retrieval（embed/rerank）、
  bm25、fileindex、SchemaV4/V5/V6。
