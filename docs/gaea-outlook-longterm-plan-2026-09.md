## 阶段一 · 接通已有（近）

**入口**：展望已拍；主路径缝已经读到。

目标：不再平行两套管线假装是一个产品。不新造能力。

### 1A 小说主路径（闲庭短腿，平级，不往后拖）

已读：`CreateChapter` → `WriteChapter` blob；`GenerateScene` → `scene.Manager`；`CreateScene` 无页面调用；`RunChapterGate` 不在 `NovelBindings`。

出口：

- 创作生成的章，阅读页 `GetChapterScenes` 有 id，逐场景生成不再报「无绑定 ID」
- 阅读页加场景走 `CreateScene`，不是只改 React 数组
- `RunChapterGate` 若要用：进 `NovelBindings` 并挂检查器；不当每章盖章向导。若不用：从遗留绑定名清掉，避免假门面

不做：全文脑图再造（创作页已有 SVG 弹窗）；GenerationGate 自动修复闭环当主题。

### 1B 两套空间开关 ✅ 出口（2026-09-10 拍板=拆开）

已读：壳层 `switchSpace` 不调 `GaeaSpaceActivate`；`GaeaSpaceActivate` 不重建 controller。

拍板（用户）：切换时不影响现在的工作——办公板块在跑时切到小说，办公照常。
即**拆开**：壳层=导航，引擎空间=办公侧栏另一件事；合并方案（切空间写
`session.space`+安全点重建）作废，「一年后是一个开关」的画面从展望删除。

出口已落：两套开关 UI 说清楚（v4.187.0，title/aria+SpaceChip 提示点名区别）；
展望契约修订（同一场活句改写/一个开关作废/两套为定局）；e-check E26 守卫锁
`switchSpace` 零桥接（实证链=switchSpace 纯 localStorage+React 态、页面卸载只
退订流不 cancel、`GaeaCancel` 只挂显式停止按钮）。

本阶段明确不做：新板块、进度再加深、MCP。

## 阶段二 · 总闸画面（1A/1B 均已出口，**当前阶段**）

已读：模型中心是功能域绑定；`SpaceProfile.Gaea` 在 TOML，boot 装配时能覆盖办公模型。

出口：打开模型中心能看见本机/云端、当前这句话的功能域、书斋/闲庭（或办公引擎空间）绑的策略；失败说人话（分诊已有样板）。各板块仍只消费中心，不私藏引擎表。

不做：折进设置、技能市场。

## 阶段三 · 造价开口（阶段二后，或与二并行若足迹不撞）

已读：agent 有 `cost_search` / `cost_save`（hardAsk）；组价是 `GaeaCostCompose*`，确认进库。未见 `cost_compose` 工具。

出口：开口 → 对上历史 → 确认进工程，不必先把造价页当目的地。实现可以是管家调组价，或会话里拉起同一套 Compose 确认，**不**把组价拆成逐步盖章。

刀路池（survey）继续按「加厚私人记忆」过滤：五算贯通可以；算量/企业云协同不做。

进度：只作为办公产物被 `schedule_*` 引用和导出。不再单独立项做 Project。

## 阶段四 · 闲庭同一人设（小说 1A 出口后）

**读档已毕（2026-09-10，docs/gaea-character-domain-survey-2026-09.md）**：不是
三套人——是**一套资产（全局角色库 SQLite，小说侧+聊天侧+绘梦参考图同一份
Character）+ 一个项目工作副本（characters.json，有意隔离项目内本地编辑）**，
三座桥（导入/合入/章节后对账）已在，编辑不双向流动。真缺口=外观锚点分裂：
章节 prompt 读副本、绘梦参考图读库，两处分别演化后同一角色两边长得不一样。

出口（三小刀，不做自动双向同步）：

- 外观锚点单一来源：绘梦参考槽空时回退读库内 Appearance 文案，不静默空槽
- 副本→库显式回写按钮（按字段合并+用户确认），无后台同步
- 关联即快照语义进 UI（项目内弧线/状态以项目为准）

方向仍是：角色在章节和出图里是同一个人；空房间不加家具；轻语主动开口极稀。

## 一年后怎么验（指导）

能在书斋用办公那张嘴，把文件、自己的造价库、进度图放进同一场活里做完——中间可以打开材料，但不是「请先进入某某板块才能开始」。对话无每步盖章；覆盖库和整计划仍会停。闲庭陪聊不写进办公 AGENTS。切书斋/闲庭切的是导航，管家与在跑的活不受打扰（1B 已拍板：拆开）。小说新章在阅读页是场景。模型中心能切云/本地。

做不到的部分仍在这些阶段里找，不另开品类。
