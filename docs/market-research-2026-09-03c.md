# gaea 市场调研合成：文件交付（2026-09-03c）

> 原始稿：`docs/research-2026-09-03c/agent-delivery.md`（Agent 产品交付物 UX，Claude/ChatGPT/Kimi/Manus/Devin/Genspark/Lovable 等，69 条来源）、`office-delivery.md`（办公文档交付后链路，M365 Copilot/Gemini/Notion/飞书/钉钉/WPS/Gamma/Zapier，101 条来源）。本合成版只做差距分析与方案打包，模式编号引用原始稿清单（A#=agent-delivery，O#=office-delivery）。

## 一、gaea 现状对照（调研确认的已有能力，不重复建设）

交付文件卡（正文+权威登记表合并、缺失态）、会话产物面板、版本时间线+恢复、一键 zip、证据链+回滚、reveal 定位、docx 框选即改+Word 修订制、xlsx Plan→Apply+原生图表+CrossEmbed、md/Word/PDF 导出三出口、任务模板库、本地标准格式落盘（产物主权，O#15 反面教材：Tome 关停）。

## 二、竞品 2026 卷的是什么（两份原始稿的共同结论）

1. **交付确认成了核心循环**：M365 Copilot 把「预览 diff→人工确认→落盘」做成 GA 标杆（词级修订、锚定批注）；Devin 有 Changes 词级 diff+行锚定评论+批注即追问；Codex 是 request revisions。共同语义：**agent 产出不算交付，用户验收才算**。
2. **版本语义从「回滚」进化到「比较+分享」**：Claude Cowork 版本 compare、Claude Code Artifacts「发布时选版本/始终分享最新」、Lovable 发布快照与工作副本分离。
3. **批注回流闭环**：Genspark「多次圈画→Send N edits 批量提交」、Claude 评论线程 @claude、Gamma 批注进 API——用户批注是下一轮 AI 加工的输入，不是终点。
4. **交付后一公里**：投递（Zapier/Make 文件级 I/O、飞书审批→群推送）、模板化复用（Gemini Match doc format「上次成稿=下次模板」、Notion Repeating templates 定时再生）、跨会话产物库（Claude Artifacts 侧栏、Kimi 工作空间）。
5. **信任建设**：Copilot 官方「能力边界诚实条款」、Gamma 导出保真预警、ChatGPT /mnt/data 链接过期被骂——失效检测与保留策略明示是差评驱动的必选项。

## 三、跃升刀候选（模式聚类打包）

### 方案 A：交付验收闭环（推荐主轴）
把「用户验收」做成一等状态机，补齐 agent 产出→用户确认→批注回流→新版本的循环。
- A1（中）：产物验收状态机（待查看/已确认/要求修改，O#10）+ 版本间 diff compare（A#4：md/text 文本 diff、xlsx 单元格变更表、docx 修订汇总，恢复前先看差异）+ 写入前统一 diff 预览与词级修订标记（O#1/O#2 小）。
- A2（中）：预览内批注→「发送给助手」批量修改队列（A#5 Genspark Send N edits + A#6 @agent 回流），处理结果回写为新版本并挂验收状态；证据引用可写入交付文件本体（A#7，与 gaea 证据链天然互补，竞品没有）。
- 依据：两份调研的共同头部结论；gaea 的修订制/证据链/登记表是独家地基，能比竞品做得深。

### 方案 B：交付即流转（最后一公里）
- 交付目的地矩阵（A#14 小-中）：另存指定目录/系统程序打开/复制为纯文本-Markdown；导出后投递动作：本地目录/邮件/webhook（O#8 中）。
- 分享包（本地优先形态，不做云端链接）：自包含只读 HTML 包+版本选择/始终最新双语义（A#1 小）+ 交付快照与工作副本分离（A#2 小）。
- 存为模板/套模板生成（O#4 中、A#17 中）：抽取报告骨架+数据源占位，换数据再生成；与既有任务模板库联动。

### 方案 C：产物库与工程式组织
- 跨会话「产物库」页（A#3 中）：按项目/任务聚合全部登记产物，筛选搜索。
- 产物包语义（A#16 中）：多产物任务聚合为目录树+入口文件标识，zip 升级为包；产物元数据结构化索引（O#5 中）。

### 随刀小件（低量级高感知）
导出保真预警+格式取舍明示（O#11/O#12 小）、产物失效检测徽标+一键重生成（A#15 小，gaea 已有「未生成」，补「路径失效/被移动」）、保留策略明示（A#18 小）、能力边界诚实条款（O#3 小）。

## 四、反面教材（护栏）

- Tome 关停：云端暗格式产物主权风险——gaea 本地标准格式路线坚持不动摇。
- ChatGPT /mnt/data 链接过期：交付物必须有失效检测，不能只给一条会腐烂的路径。
- Gamma PPTX 导出有损口碑：导出能力上线必须配保真预警，否则差评反噬。
- Notion 无 docx 出口/PDF 被评 awful：导出格式覆盖率是办公产品硬门槛。

## 五、建议刀序

A1 → A2（交付验收闭环，两刀）；B/C 与小件按用户拍板插队。每刀沿用全门禁+走查纪律。
