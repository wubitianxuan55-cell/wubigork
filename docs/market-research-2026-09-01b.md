> 2 分模块子代理调研（AI 代理工作台简化模式 / 办公文档工具与生产力软件简化模式），原始稿在
> `docs/research-2026-09-01b/`（agent-workbench-simplify.md · doc-tool-simplify.md），来源随句标注，
> 未核实项在原始稿内单列。目的：为 v4.29「UI 化繁为简」刀供弹药。
> 用户红线（本轮最高约束）：**简化界面 ≠ 删除功能**——只能重组入口、渐进披露、视觉降噪。

## 一、总命题（两线调研共同结论）

被对标产品不是把复杂度删掉，而是：
1. 把复杂度从「常驻视觉空间」迁到「按需检索空间」（命令面板 / slash / 悬停 / 折叠）；
2. 把「何时出现」的决定权半自动化（事件驱动自动开 / 自动收 / 自动合并）；
3. 被藏的功能必须有确定性寻回路径（溢出桶 / 命令面板 / 可重置），「藏」才敢藏深。

**三层原则**（agent 线 §5.4，建议作为 gaea 界面分层的设计准则）：
- **常驻层**：输入框 + 当前活动面板 + 高频校验状态；
- **点开层**：tab 内详情、折叠的过程细节（Cowork 每步默认一行、点开才见 Request JSON）；
- **检索层**：命令面板 + slash + 悬停菜单。任何新功能先放检索层，用出频率再逐层上浮，反向（删功能）永不发生（先例：Codex /goal slash 入口 ↔ 按钮进度行双向打通）。

## 二、关键先例（均已一手核实，详注见原始稿）

- **M365 Copilot 2026 新设计**（官方博客 2026-05-28）：核心原则即 progressive disclosure（"organizes what matters first"）；侧栏管多步任务、段落/单元格/幻灯片内就地唤起轻操作；简化后使用量不降反升（Word +27%/Excel +33%/PPT +43%，微软自述口径）。
- **VS Code**：「藏而不删」范本——万物可 toggle、单点 Customize Layout 溢出、两档占幅（半幅↔最大化）、Reset View Locations 可回滚、布局跨会话持久化。
- **Devin 2026 changelog 群**：Auto-open Agents Tab（面板因事件而开非因布局而开）、文件 tab 去重+版本切换器（tab 数不随时长增长）、Progress tab 合并原始流（原始面板降级为深入入口）、任务头只显一行 active todo。
- **Claude Artifacts/Cowork**：产物面板是生成的副产品自动出现；过程默认一行（"less intimidating default interface"）；右栏关不掉被用户吐槽——「可收起」本身是简化的一部分。
- **Linear**：Display properties 官方原话「只隐藏数据，不删除 issue」＝「简化≠删功能」的官方表述；命令菜单数百动作按当前视图重排；空分组默认隐藏。
- **Notion**：Favorites 首次使用前区块不渲染（空态不出现）；同数据多视图、tab 溢出收进「{#} more...」、每视图独立过滤/属性隐藏。
- **Codex**：22 条 slash 是「复杂度总下水道」（连 /pet /mcp 都只从 composer 可达）；IDE 评审"without an extra navigation pane"，验证结果要点化而非日志面板。
- **WPS AI / Kimi**（国内一手）：功能族翻译成意图入口（「帮我写公式」）；侧栏按产物类型组织（PPT/文档/表格）；问答与任务共用一个输入。

## 三、对 gaea 现状的映射（摸底 2026-09-02）

| gaea 繁点 | 对应先例 | 化简手法（功能不删） |
|---|---|---|
| 顶栏 7 操作钮常驻，导出/Word/PDF 三个低频文字钮占最高层级 | Devin/Linear：新功能只进 Cmd+K 不加按钮；VS Code 顶栏单点溢出 | 低频动作收进「导出 ⌄」菜单（md/Word/PDF 三出口全保留） |
| 右栏 6 个带字 tab 在 340px 基线宽下拥挤 | Notion 视图 tab 可 Icon only/Text only；Devin 侧栏 hideable | 窄栏自适应图标化+tooltip，宽栏恢复文字；6 tab 集合不动 |
| 预览 pane 头部 5 个带边框文字钮 | Codex IDE 内联摘要 "without an extra navigation pane" | 图标化+悬停提示；保存/编辑等状态语义保留文字 |
| 面板零值区块/空分组占位 | Linear 空分组默认隐藏；Notion 首次使用前不渲染 | 空分组/零值过滤条不渲染，保留「有引导动作」的空态 |
| 过程细节/次级信息与主行并列 | Cowork 默认一行、点开展开；Linear 主行四件套 | 次级信息收次行小字/悬停/展开（本轮先做零风险部分，其余记欠账） |

## 四、对刀序的影响（v4.29 收敛建议）

1. **顶栏收拢**：导出三钮 → 单钮下拉菜单（三出口+toast/reveal 行为原样）；顶栏回到「信息区+布局开关区」两组。
2. **右栏 tab 自适应**：容器宽度阈值以下图标化（title/aria 保留全名），宽栏恢复；数量锁 6 不变。
3. **预览头部降噪**：FilePreview 头部按钮图标化，编辑/保存状态文字保留。
4. **零值隐藏**：右栏面板空分组/零值区块不渲染；空态只留「引导性空态」。
5. **记欠账（不做）**：产物自动置前徽标、列表行悬停次行化、命令面板吸附右栏面板项、按会话重排 palette 优先级、半幅↔最大化预览两档。
