# 市场调研：AI 办公「记忆与自进化」，2026-08

> 目的：为 gaea 通用办公的「记忆与自进化」提供设计依据，承接第一份调研中的 P0
> 项（记忆与自进化：个人画像 + 空闲自整理）。gaea 已具备文档记忆（AGENTS.md 分层）、
> 事实底座（facts）、remember/knowledge、会话压缩与记忆面板，本轮重点蒸馏竞品如何
> 把记忆从「存得下」升级到「记得对、用得上、会进化」。来源为 2026 年公开资料与官方文档。

## 0. 一句话结论

2026 年头部产品的记忆已经从「用户说一句记住就存」进化到**三层自进化闭环**：
① 自动回忆（相关记忆在会话开始时主动注入，不靠用户追问）；② 空闲自整理（会话结束/
每日闲时后台归纳、压缩、结构化入库，官方叫「自动做梦 / Dreaming」）；③ 记忆生命周期
（过时修订、高频提升、过期清理）。gaea 有存储与检索底座，缺的是**自动注入、后台
自整理、生命周期管理**这三块——它们共同把记忆从「档案库」变成「会进化的上下文」。

## 1. 竞品矩阵：记忆系统

| 产品 | 分层/形态 | 记忆怎么写入 | 记忆怎么用 | 可蒸馏优点 |
|---|---|---|---|---|
| WPS 灵犀专业版 | 四层：个人（身份/偏好）→ 专家（行业知识）→ 团队（协作经验）→ 自进化 | 对话与文件自动沉淀；「自动做梦」空闲时段归纳 | 后续对话自动带入；夜间算力整理：清理过期信息、提升高频资料检索优先级 | ① 空闲自整理（做梦）；② 记忆生命周期（过期清理/高频优先） |

## 2. 可蒸馏的优点清单（映射到 gaea）

1. **自动回忆注入（用得上）**：Claude MEMORY.md 前 200 行默认注入、WPS 记忆自动带入、
   Codex 记忆加载——「相关记忆主动进上下文」而不是等用户/模型想起来才检索。gaea 现在
   只有 recall_reminder 提示 + memory_search 被动检索。
2. **空闲自整理（会进化）**：WPS「自动做梦」、ChatGPT Dreaming、Codex 后台会话总结——
   会话结束后/每日闲时把对话与文件归纳成摘要、事实、偏好入库，并去重、结构化。
   gaea 有 compact/compress 与 fact 去重基建，但没有「会话结束 → 自动提炼入库」的闭环。
3. **记忆生命周期（记得对）**：WPS 夜间清理过期信息/高频优先、ChatGPT Dreaming 修订
   过时记忆、Kimi 写入前二问——记忆要能过期、修订、排频，而不是只增不减。
   gaea facts 有稳定 slug 去重，但无时间衰减/冲突修订/高频提升。
4. **可控与透明（敢让 AI 记）**：Copilot 设置里查看/删除、Kimi 记忆指令逐条管理、
   ChatGPT 记忆开关——用户对「AI 记住了什么」有完全控制。gaea MemoryPanel 已能查看/
   编辑/删除，缺「来源会话溯源」「一键不再记住」「记忆开关」。
5. **指令层与回忆层分离（可靠性）**：Codex「AGENTS.md 别赌记忆」——规则进静态层，
   自动总结进回忆层。gaea 文档记忆（AGENTS.md 分层）正是静态层，事实/画像应为回忆层，
   二者职责需在提示词中显式区分。
6. **从成功任务提炼方法论（沉淀）**：千问办公组织级 Skill；gaea「沉淀为技能」已有人工
   触发闭环，可深化为「任务成功后自动提取可复用步骤」的候选推荐。

## 3. gaea 现状盘点（基于代码，2026-08-10）

### 已具备
- **文档记忆（静态指令层）**：`internal/gaea/memory` 读取 AGENTS.md / TIANXUAN.md /
  CLAUDE.md（user / ancestor / project / local 四层，@import 递归，本地覆盖最高优先）；
  新项目默认落 AGENTS.md（跨工具约定）。
- **事实底座（回忆层雏形）**：SQLite（`%APPDATA%\gaea\Hephaestus.db` facts 表，按项目
  slug 隔离）；fact_add/list/clear 会话级工具 + 侧栏面板 + 一键沉淀长期记忆（稳定 slug
  去重、preference → 用户画像分类映射，后续对话自动加载）。
- **remember / knowledge**：remember（type=user/episodic/procedural）+ memory_search；
  knowledge_add/knowledge_search（知识库）。
- **会话压缩**：compact/compress 提取关键文件与事实（compact_summary.go 已能从消息提取
  文件路径与事实），为「自动做梦」提供了现成原料。
- **记忆面板**：MemoryPanel（查看/编辑/快速添加/候选项）+ 办公记忆库 OfficeMemoryLibrary
  + 用户画像 ProfileLibrary + 聊天记忆 WhisperMemoryLibrary。
- **提示词纪律**：偏好/项目事实主动 remember；「沉淀为技能」闭环（助手消息 → 技能文件
  → 热加载）。

### 缺失（本轮差距）
- 无「自动回忆注入」：会话开始时不主动加载画像/高频 facts/项目记忆进上下文，靠模型
  主动 memory_search（recall_reminder 只是提醒，不是注入）。
- 无「空闲自整理（自动做梦）」：会话结束/闲时没有后台把对话归纳成摘要/事实/偏好入库。
- 无「记忆生命周期」：facts 无时间戳衰减/冲突修订/高频提升；旧事实被新事实覆盖时无
  修订链。
- 无「记忆来源溯源」：面板能看事实内容，但看不出是哪次会话/哪条消息沉淀的。
- 无「记忆开关/隐私分级」：无法一键关闭记忆或标记敏感信息不记。

## 5. 设计决策与强化清单（映射 gaea）

### P0 记忆自进化核心（先做）
1. **自动回忆注入**：会话开始时把「用户画像（ProfileLibrary facts）+ 项目记忆
   （AGENTS.md 已加载）+ 高频/近期 facts」压缩成一段「记忆上下文」注入系统提示词，
   并标注来源与置信度（事实带时间戳）。落点：复用已有 facts/画像存储，新增
   `buildMemoryContext()`（前端 MemoryPanel 展示注入摘要），对标 Claude MEMORY.md
   前 200 行 / WPS 记忆带入。
2. **空闲自整理（自动做梦）**：会话结束（turn_done）后进入后台任务，复用 compact/
   compress 的提取逻辑把本轮对话归纳为：① 新事实（fact_add，走稳定 slug 去重）；
   ② 用户偏好（remember type=user）；③ 踩坑/方法（remember type=episodic）；
   ④ 可复用工作流候选（供「沉淀为技能」）。对标 WPS 自动做梦 / Codex 会话总结；
   写入频率受控（非实时写，避免噪音，Kimi 二问思路：先过滤再入库）。
3. **记忆生命周期**：facts 增加 created_at / last_used_at / source_message；
   ① 冲突修订：同 slug 新值覆盖时保留旧值修订链；② 高频提升：使用计数参与注入排序；
   ③ 过期清理：超过 N 天未使用且被用户「不再记住」的候选清理（仅提示，不自动删）。
   对标 WPS 夜间整理 / ChatGPT Dreaming。

### P1 深化
4. **记忆可控与溯源**：MemoryPanel 每条事实显示来源会话/消息，可跳转；新增「不再记住」
   与「记忆开关」（会话级/全局）；对标 Copilot/Kimi。
5. **检索与压缩注入**：facts/画像向量化（本地 embedding）或退化为「关键词 + 时间 +
   高频」的轻量排序，注入预算 ~500-800 token（对标 Supermemory 压缩注入）。
6. **方法论自动候选**：任务成功后自动检测「步骤可复用」的信号（多次同类任务），在
   「沉淀为技能」入口给出候选，对标千问办公组织级 Skill 的个人版。

### 明确不做
- 团队共享记忆、组织级 Skill 权限（个人工具定位）；
- 云端记忆存储/跨设备同步（本地优先）；
- 自动删除用户记忆（只提示候选，删除必须用户确认）。

## 6. 落地优先级建议

- **本轮优先（P0）**：① 自动回忆注入（画像 + 高频 facts → 记忆上下文）；② 空闲自整理
  （会话结束后台归纳 → facts/preferences/技能候选）；③ 记忆生命周期（时间戳、冲突修订、
  高频排序）。
- **其次（P1）**：记忆来源溯源与「不再记住/开关」；轻量向量检索与压缩注入；
  方法论自动候选。
- **明确不做**：团队共享记忆、云存储、自动删除。

## 7. 结论

gaea 的记忆底座（文档记忆四层 + facts + remember/knowledge + compact + MemoryPanel）
已经覆盖「存得下」；与 WPS 灵犀「自动做梦」、ChatGPT Dreaming、Claude Auto Memory、
Codex Memories 的差距集中在「记得对、用得上、会进化」：**自动回忆注入、空闲自整理、
记忆生命周期**三件事。三者都复用现有 compact/facts/画像/技能基建，本地完成、零外部
依赖，符合 gaea「个人生产力工具、本地优先」的定位——做完这三项，gaea 就从「每次都要
重新交代背景」升级为「越用越懂你」。
