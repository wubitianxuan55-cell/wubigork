## 0. 阶段论点（三句，说完即止）

1. **形态收口**：任务空间制以收窄口径落地——多入口统一任务收件箱（纯同步），
   板块从「导航容器」降级为「任务视图」，兑现 nextgen §10 的版本重定义。
2. **复利层**：在陈述性记忆之上补程序性记忆——技能结晶（演示式录制 +
   journal 历史蒸馏），做本地可审计、跨应用的空位（调研 §5.1）。
3. **信任地基**：记忆质量可评测 + 路由学习（含本地模型与单任务成本归因），
   为前两者提供「可信、可归因」的底座，顺带闭合 nextgen 底座五件套中
   「本地-云自动路由+成本仪表」的在册项。

办公主角位不变：7.2/7.3 首先落在书斋；进度/造价维持确定性引擎样板，不加旗舰。

## 1. 7.1 信任地基（先行，两刀）

### 7.1-1 记忆质量可评测（在册开放增量，证据加强）

- **范围**：三脑记忆域（Hephaestus/hermes/项目 StoryMemory）建立评测基线，
  对齐物 BEAM 与 LongMemEval-V2（V2 的「经验习得」方向与 7.2 技能域同源，
  评测基建两用）。复用 `docs/retrieval-eval-set.md` 与 gaea_retrieval_eval.go。
- **刀面**：评测集（分域题集+期望答案）→ 跑批 runner（本地零外部依赖）→
  基线数字落档 → 纳入 CI 防退化（阈值告警不阻断）。
- **出口判据**：①三域各有召回/精度基线数字并落档；②评测可在 CI 一键跑；
  ③经验习得题集 ≥ 20 题（供 7.2 复用）；④数字进 releases 文档。

### 7.1-2 路由学习（nextgen「本地-云路由+成本仪表」收口）

- **范围**：模型中心补遥测→归因→建议回路。卖点按调研定位：可解释、可归因、
  本地模型参与（不是省钱——定价战已使其失效）。
- **刀面**：①每任务（按功能绑定键）落账 token/成本/时长/引擎/成败，接既有
  journal/事件日志；②单任务成本归因视图（对照 Bionic 被批的反例）；③改绑
  建议生成（规则优先：同功能下按 成本×质量 评分差超过阈值才提议，宁少勿扰）；
  ④本地引擎（Ollama/Herdsman 类）与云端引擎同池参与建议。
- **出口判据**：①任务级账目覆盖全部功能绑定键；②归因视图可查任意会话/任务
  成本；③建议仅在评分差超阈值时出现且可一键采纳/忽略；④本地引擎出现在
  建议候选中（有真实被采纳样本）。
- **边界**：不自动改绑（建议制，采纳是用户动作）——「作者是上帝」同款纪律。

## 2. 7.2 技能结晶（复利层，双入口，两刀）

### 7.2-1 演示式录制（已验证形态：Record a Skill / Record & Replay 对位）

- **范围**：书斋办公域。用户演示一遍任务（会话回放形式）→ 系统合成
  SKILL.md 草稿（frontmatter+步骤+注意项）→ 用户审阅修订 → 入 skills/ 库。
- **刀面**：①会话→技能草稿生成器（复用 transcript/journal 数据，LLM 辅助
  结构化，模板走 prompts RTCO 管道）；②技能审阅 diff UI（右栏面板注册表
  现成）；③与既有 skill 加载器（frontmatter applies_to）零缝对接。
- **出口判据**：①录制的技能可在新会话被按需加载并复跑成功（抽样 ≥ 80%）；
  ②全流程可审可改可删；③不写死任何领域规则（通用机制红线）。

### 7.2-2 journal 历史蒸馏（差异化空位，调研 §5.1）

- **范围**：书斋 journal 审批链为源。识别重复 ≥ N 次的任务模式 → 提示用户
  「这个流程已重复 N 次，结晶为技能？」→ 确认后走 7.2-1 同一审阅管道。
  **一期限 work 空间**；play 侧（小说写作模式结晶）二期另议——play 不蒸馏
  进 work，各自空间内结晶各自技能。
- **依赖**：7.1-1 的评测（结晶技能的复用成功率要有可信度量）。
- **出口判据**：①模式识别只提示不打扰（用户明确拒绝后该模式静默）；②结晶
  技能被实际调用 ≥ 5 次且成功率可见；③审计链完整（哪次历史、谁确认、哪版）。
- **威胁计时器**（不进判据，进周报观察）：Letta Mods/Bionic Skills 的逼近
  速度——若其发布历史挖掘式，差异化窗口收窄，优先级上调。

## 3. 7.3 任务空间制·收窄版（形态层，两刀，渐进不重写）

### 7.3-1 多入口统一任务收件箱（空白位，调研 §5.2）

- **范围**：意图中枢/微信/语音/Ctrl+K 四入口已汇同一内核（v4.5 在册），
  补「任务」为持久实体与统一收件箱视图。**纯同步**：任务只在会话/页面存续
  期间推进，关闭即停（昼夜运转拍板）；无定时/监控/后台执行。
- **刀面**：①任务实体（space 维度必带——work/play 隔离沿 boards/space.ts，
  跨空间仅显式）；②收件箱视图（状态机：待处理/进行中/已完成/已放弃）；
  ③入口接线：四入口的指令除即时执行外可「存为任务」；④任务↔来源板块
  双向跳转。
- **出口判据**：①任意任务可从四入口任一创建并在收件箱追踪；②任务详情可
  跳回来源板块与源会话；③空间隔离零泄漏（play 任务不出现在 work 收件箱，
  除显式跨门）；④零常驻进程（应用关闭=一切停止，可验证）。

### 7.3-2 板块降级为任务视图（渐进，最后落）

- **范围**：首页 ModuleLauncher 与 CommandRail 的信息架构重构：收件箱成为
  第一界面，板块入口降为「能力的视图」（manifest 驱动机制不变，不动
  pageRegistry 注册表结构——形态合并引擎零改动原则）。
- **依赖**：7.3-1 稳定运行一个零功能周周期后再动——用户 2026-09-17 提前拍板解锁；**v4.332.0 已落**（任务优先首页+能力视图+回退开关双位；缺省 classic 渐进）。
- **出口判据**：①收件箱+最近任务成为首页首屏；②既有 14 板块全部入口无损
  （藏≠删）；③回退开关（设置里可切回经典首页）。
- **形态标志**：此刀合入的 release = 阶段七的「层跃升」版本（nextgen §10
  口径；版本号继续 v4.x 周度列车，是否跳号由用户拍板）。

## 4. 7.4 闲庭并行线（在册项清欠，不新增候选）

按既有规格推进，与 7.1-7.3 并行排刀（周度列车轮转，非阻塞依赖）：

- **小说 t6**：提示词工坊 → 按 06-prompt-workshop 蒸馏规格落地为
  「生成配方系统」（prompts/*.json 用户可编辑/可版本/按书切换——同时兑现
  技能化红线在生成侧的口径）。
- **小说 t7**：前端统一接线（分析 V2/伏笔面板/标注高亮/重写建议的消费面）。
- **GenerationGate 闭环编排收口**：写前契约→AI 味闸→评审→修复→审批→结算
  串成主轴（revolution 文档刀 7/8 未落部分）；**全书体检=触发式全量编译**
  （作者点按，跑完出报告——无常驻、无夜间）。
- **轻语**：监管口径知悉（拟人化新规 07-15 施行；纯本地个人工具义务链不同，
  不触发备案线），产品动作零；承接位优势靠既有本地人格记忆自然持有。
- **绘梦**：画室规格按 `gaea-dream-studio-nextgen-2026-09.md` 阶段一走，
  一致性技术选型对齐调研共识（Qwen-Image-Edit 系+LoRA 金标准+PuLID 精修层）。
- **真机走查欠账**：每刀附一条走查记录（阶段门硬条件，见 §5）。

## 6. 排序与依赖

```
7.1-1 记忆评测 ──┬─→ 7.2-2 历史蒸馏
7.1-2 路由学习 ──┘   （7.2-1 演示式无依赖可先行）
7.3-1 收件箱 ─→ 稳定一个零功能周 ─→ 7.3-2 板块降视图
7.4 闲庭线：独立列车，与上并行
```

推荐首刀 = **7.1-1 记忆评测基线**（门槛最低、是 7.2-2 的硬依赖、闭合在册
开放增量）；次刀 7.2-1（演示式，无依赖且已验证形态）。每刀三问照常：
是不是通用机制（领域内容进技能）/能不能下个版本就撤/用户三分钟内感知到什么。

## 7. 挂起与口径项

- **挂起待拍板**：候选⑤可自证创作过程（人机边界记录/创作留痕导出）——
  资产现成（闸门/journal/快照），但定位敏感（为平台审查自证的隐私悖论），
  待用户拍板定位后再入册。
- **口径项**（无刀）：⑥「可审计主权」作为对外表述口径（证据链/journal 的
  可验证性），不产生功能；成人向「永不分发/社区/变现」为永久硬边界（调研
  §3.4 刑事执法活跃期）；「不做 MCP 大全」维持（调研 §2.5 数据佐证）。
