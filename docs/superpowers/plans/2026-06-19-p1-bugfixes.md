### Task 1: Bug 1D — 修复 json.Marshal / io.ReadAll 静默吞错误

### Task 2: Bug 1A — SSE 流检查 finish_reason 防止 goroutine 死锁

**Files:**
- Modify: `internal/ai/types.go:26-29`
- Modify: `internal/ai/client.go:207-214`

**Interfaces:**
- Consumes: Task 1 的修改（同一个 client.go）
- Produces: `ChatDelta.FinishReason string` 新字段；流式读取现在在收到 `finish_reason` 后正确结束

- [ ] **Step 1: 在 ChatDelta 中增加 FinishReason 字段**

将 `internal/ai/types.go` 第 26-29 行的：
```go
type ChatDelta struct {
	Role    string `json:"role,omitempty"`
	Content string `json:"content,omitempty"`
}
```
改为：
```go
type ChatDelta struct {
	Role         string `json:"role,omitempty"`
	Content      string `json:"content,omitempty"`
	FinishReason string `json:"finish_reason,omitempty"`
}
```

- [ ] **Step 2: 在流式读取中检查 finish_reason**

将 `internal/ai/client.go` 第 207-214 行：
```go
if len(choice.Choices) > 0 {
    content := choice.Choices[0].Delta.Content
    if content != "" {
        chunks <- SSEChunk{Content: content}
    }
    // finish_reason 不为空表示结束
    // (xAI 实现中 finish_reason 在 delta 里出现表示流结束)
}
```
改为：
```go
if len(choice.Choices) > 0 {
    delta := choice.Choices[0].Delta
    if delta.Content != "" {
        chunks <- SSEChunk{Content: delta.Content}
    }
    if delta.FinishReason != "" {
        chunks <- SSEChunk{Done: true}
        return
    }
}
```

### Task 4: Bug 1C — 章节编号下限：后端强制 OrderIndex>=1 + 前端放宽保存条件

**Interfaces:**
- Consumes: 无跨任务依赖
- Produces: `SaveNode` / `AddNode` 现在保证 `OrderIndex >= 1`；前端 `handleSave` 允许 chapterNum >= 1

- [ ] **Step 1: 后端 SaveNode 强制 OrderIndex >= 1**

在 `internal/outline/outline.go` 的 `SaveNode` 方法开头（第 253 行之后）加入：
```go
func (a *Agent) SaveNode(node types.OutlineNode) error {

		node.OrderIndex = 1
	}
	of, _ := a.pm.ReadOutlines()
```
做法：在 `of, _ := a.pm.ReadOutlines()` 之前添加 3 行验证。

用 edit_file 精确匹配：
```go
old: func (a *Agent) SaveNode(node types.OutlineNode) error {
	of, _ := a.pm.ReadOutlines()
new: func (a *Agent) SaveNode(node types.OutlineNode) error {
	if node.OrderIndex < 1 {
		node.OrderIndex = 1
	}
	of, _ := a.pm.ReadOutlines()
```
