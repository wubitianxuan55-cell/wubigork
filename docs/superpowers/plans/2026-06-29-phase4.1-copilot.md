# Phase 4.1 — AI 协写革命 实施计划

> **Goal:** 实现 Cursor 式 AI 写作体验：Ghost Text 内联补全、Cmd+K 命令编辑、Inline Diff 审查、Beat-to-Prose 管道

**Architecture:** 后端新增 `internal/ai/copilot.go`（Ghost 补全+Cmd+K 编辑+Beat生成）和 `internal/app/copilot_handler.go`（Wails 绑定）。前端新增 4 个编辑器组件。现有 ChapterPage 通过渐进式集成接入。

**Tech Stack:** Go 1.22+, React 18 + TypeScript + Ant Design 5, 零新依赖

## Global Constraints

- 所有 AI 调用走现有 `ai.Client`，不创建新的 HTTP 客户端
- Prompt 使用现有模板引擎或内联构建
- 前端组件纯 TypeScript + React，不引入新 npm 包
- 键盘快捷键不与应用现有快捷键冲突
- SSE 流式优先，长操作必须可中断
- 向后兼容：所有新功能可选，v3 项目不受影响

## Task 1: 后端 Copilot API

**Files:**
- Create: `internal/ai/copilot.go`
- Create: `internal/ai/copilot_test.go`

### GhostComplete — 内联补全

```go
// GhostComplete 流式返回光标后的补全建议（Ghost Text）
// currentText: 光标前的文本（用于上下文），cursorPos: 光标位置（字符数）
// 返回 SSE chunk 流，前端实时显示 ghost text
func (c *Client) GhostComplete(ctx context.Context, model string, currentText string, styleProfile string) (<-chan SSEChunk, error)
```

### CmdKEdit — 命令编辑

```go
// CmdKEdit 根据自然语言指令编辑选中文本
// selectedText: 用户选中的文本，instruction: 自然语言编辑指令
// 返回编辑后的文本
func (c *Client) CmdKEdit(ctx context.Context, model string, selectedText string, instruction string, styleProfile string) (string, error)
```

### Beat/Prose — Beat-to-Prose

```go
// Beat 一个叙事节拍
type Beat struct {
    ID          string `json:"id"`
    Description string `json:"description"` // 简短动作描述
    Order       int    `json:"order"`
}

// GenerateBeats 从大纲/上下文生成章节级 Beat 列表
func (c *Client) GenerateBeats(ctx context.Context, model string, outlineNode string, prevSummary string) ([]Beat, error)

// GenerateProseFromBeat 从单个 Beat 生成流式 Prose
func (c *Client) GenerateProseFromBeat(ctx context.Context, model string, beat Beat, context map[string]string) (<-chan SSEChunk, error)
```

## Task 2: Wails Handler 绑定

**Files:**
- Create: `internal/app/copilot_handler.go`

8 个 Wails 绑定方法：
- `GhostComplete(currentText, cursorPos)` → 触发流式事件 `ghost-stream`
- `CmdKEdit(selectedText, instruction)` → 返回编辑后文本
- `GenerateBeats(outlineNodeID)` → 返回 Beat 列表
- `GenerateProseFromBeat(beatID, chapterNum)` → 触发流式事件 `beat-prose-stream`
