# 方案编写板块重设计 P8 — UI 工作台 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「6 个平铺 Tab」重构为三栏工作台：左侧项目/方案树（含检查分数徽章）＋ 中间文档工作区（流程步骤条 + Tab）＋ 右侧 AI 上下文面板（招标要点/规范引用/检查报告/复核清单）；去除 Office 页 emoji 标签与 whisper-theme 依赖；补齐单人复核清单并持久化。

**Architecture:** 后端为 Proposal 增加 `CheckSummary`（fail/warn/total）与 `ReviewChecklist`（复核项 Done 状态），SchemaV7 落库；CheckAll 自动写入摘要；前端 OfficePage 改为三栏布局（左侧项目方案树 + 中央 Tabs + 右侧 Drawer 上下文），检查分数徽章、复核清单勾选、来源定位复用现有组件。

**Tech Stack:** Go 1.26 + modernc.org/sqlite + React/TS/AntD + Wails v2

```go
// CheckSummary 最近一次检查摘要
type CheckSummary struct {
	Failed    int    `json:"failed"`
	Warnings  int    `json:"warnings"`
	Total     int    `json:"total"`
	UpdatedAt string `json:"updatedAt"`
}

// ReviewItem 复核项
type ReviewItem struct {
	ID    string `json:"id"`
	Label string `json:"label"`
	Done  bool   `json:"done"`
}
```
