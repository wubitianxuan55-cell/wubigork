# 角色卡「详情档案」重设计 Implementation Plan

**Goal:** 把角色库详情的 `CharacterLibEditor` 长表单重设计为「档案册详情视图」，保持全部字段与保存语义不变，并让档案卡整卡可点击进入详情。
**Architecture:** 就地重写 `CharacterLibEditor`（Props 不变 + 可选 `isCurrentPersona`），新增独立 CSS 与 Vitest 组件测试；`CharacterCard` 增加可选 `onClick` 与键盘支持；列表页接线。
**Tech Stack:** React 18 + TypeScript + antd 5 + Vitest 3 + @testing-library/react（沿用既有设施）。
**Spec:** `docs/superpowers/specs/2026-08-07-角色卡详情重设计-design.md`
