# Phase 1: wubigork MVP 实现计划

> **Goal:** 可演示的最小创作闭环 — 新建项目 → 世界观/角色对话 → 手写大纲 → 流式生成章节 → 自动摘要

**Architecture:** Wails v3 桌面端，Go 后端直接读写文件，React 前端三栏布局，xAI Grok SSE 流式驱动

**Tech Stack:** Go 1.26, Wails v3, React 18, TypeScript, Ant Design 5, Vite

## Global Constraints
- Go 1.26.3+
- 不引入数据库、消息队列、事件总线
- 文件即真相，无缓存层
- 流式优先（SSE）
