# 绘梦面板重设计 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将绘梦页重构为 Studio Console 风格（分区控制面板 + 结果舞台 + 历史胶片），保留全部功能。

**Architecture:** 只动 UI 层。`ImageGenPage` 保持全部状态与 API 契约，渲染层拆为 `components/imagegen/` 下的 ControlPanel（含 5 个 Section）、ResultStage、HistoryRail；样式沿用内联 + CSS 变量，新增少量 index.css 动画类并纳入 `gaea-raf-degraded` 禁用清单。

**Tech Stack:** React 19 + antd 6 + @ant-design/icons + TypeScript + Vite/Wails。无新依赖。

---

## 文件结构

- 修改 `frontend/src/pages/ImageGenPage.tsx`：重组渲染层，状态与回调保持原样。
- 新增 `frontend/src/components/imagegen/`：
  - `ui.tsx` — 通用小组件：`SectionBlock`（分区容器+标题）、`PickerGroup`（图标选择器组）、`StatusDot`、`ActionButton`。
  - `ControlPanel.tsx` — 5 分区聚合（提示词/参数/引擎/系统/生成）。
  - `ResultStage.tsx` — 画廊 + 骨架屏 + 空态 + 错误横幅。
  - `HistoryRail.tsx` — 历史胶片。
- 修改 `frontend/src/index.css`：新增 `img-stage-enter` 等动画类 + `gaea-raf-degraded` 禁用规则。
