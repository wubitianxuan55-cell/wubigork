## P0 · 造价数据库闭环补齐（建议 v3.1.1，1–2 天）

> 现状盘点：costproject（测算项目/明细/版本/沉淀）、costref（分位数指标/复盘笔记）、
> 15 个新绑定（GaeaCostProject* / GaeaCostEstimate* / GaeaCostNote* / GaeaCostIndicators）
> **全部就绪且有 Go 测试**，但 CostLibraryPage 前端仅覆盖 概览/成本条目/价格源/价格仓库
> 四个导航，**测算项目与造价参考没有 UI**——后端能力目前只能经办公 agent 工具触达。

1. **测算项目 UI**（最大缺口）：CostLibraryPage 增「测算项目」导航——
   项目列表（条目数/合计/版本数 Summary）→ 项目详情（明细行编辑：引用成本库单价/
   手动填价、数量×单价自动算金额）→ 版本保存/回看/对比/恢复 → 「沉淀」回成本库按钮。
   绑定已就绪，纯前端 + vitest（列表/明细/版本/沉淀交互）。
2. **造价参考与复盘笔记 UI**：「造价参考」指标浏览（科目/一级分类分位数表格，实时聚合）；
   「复盘笔记」CRUD（结论/边界/风险/证据/可信度/有效期/复核状态 + 引用计数）。
3. **实机走查**：办公右侧 CostLibraryPanel 新接线验证（本次发布已接线，需真实数据走查）；
   《市政成本测算手册》二期（其他专业手册导入回归）。
4. **工具链路评测**：cost_indicators / cost_search / cost_save 在办公 agent 的真实用法
   走查，确认「数据库就是数据库」收口成立（对标/沉淀由 agent 承担）。

## P2 · 路线图 3.2.0 起步（板块生态 · 记忆起步）

> 见 docs/2026-08-15-gaea3-vision-roadmap.md：V3 节奏 = 3.2.0 受控自主；V4 = 记忆统一层。

1. **记忆统一层（V4）**：三脑/多库记忆（whisper 记忆 / office 事实 / knowledge / 用户画像）
   归并视图与统一检索（GaeaUnifiedSearch 已铺路），记忆生命周期（归档/清理）产品化。
2. **受控自主（3.2.0）**：goal gate 深化（目标验收自动追踪产品化）、审批流收敛、
   子代理分工可见性产品化（v3.0.8 分工面板已有雏形）。
3. **板块插件化边界（V8 声明式装配）**：只做启动期声明式装配，不做运行期热替换；
   工具级 MCP 热增删保留例外（现状已支持）。
