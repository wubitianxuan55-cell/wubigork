## 刀 A · tsconfig strict 全开

实测数据（`npx tsc -p tsconfig.app.json --strict --noEmit`）：

- 总量 **112 处**：TS18048 possibly-undefined 73 / TS2345 实参不匹配 14 / TS2322
  不可赋值 8 / TS2532 6 / 其余 11 处零星；其中 noImplicitAny 子集 80 处。
- 分布集中：`stores/appStore.ts` 22、`gaea/components/CostLibraryView.tsx` 12、
  `gaea/components/memoryhub/GraphView.test.tsx` 10、`pages/HomePage.tsx` 8、
  `components/TTSPlayer.tsx` 7，其余 1-6 处/文件。
- 配置现状：`tsconfig.app.json` 无 strict/noImplicitAny，`noUnusedLocals/Parameters`
  亦为 false（本次不动这两项，只开 strict）。

修复原则：

1. **修真类型，不撒 as any**——与 eslint「any 已全仓清零」纪律一致；unknown 收窄优于断言。
2. possibly-undefined 主力（73 处）按语义处理：有不变式保证的补非空断言+注释，其余补收窄。
3. 测试文件（GraphView.test 等）同样修，不放宽配置。
4. 开启后 `tsc -b` 进入既有验证门禁，防止回退。

## 刀 B · Go context 传播缺口（6 处）

工具内部弃用父 ctx 自建 `context.Background()+timeout`，用户取消后后台检索照跑：

| 位置 | 现状 |
|---|---|
| `tool/builtin/knowledge_search.go:126` | 语义检索 60s 自建 ctx |
| `tool/builtin/knowledge_search.go:158` | 本地精排 15s 自建 ctx |
| `tool/builtin/cost_tools.go:153` | 语义检索 60s 自建 ctx |
| `tool/builtin/cost_tools.go:232` | 精排 15s 自建 ctx |
| `tool/builtin/readfile.go:339` | 自建 ctx |
| `agent/stop_gate.go:81` | `judgeGoal(context.Background())`——Cancel 期间 goal 判定照跑 |

修复原则：从父 ctx 派生（`context.WithTimeout(parent, ...)`），保留取消传播；
函数签名无 ctx 的沿调用链穿参，不全局存 ctx。
