# P4+P5+P6 合并优化 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended).

**Goal:** 性能优化(prompt单例+扫描+client)、前后端一致性(类型+参数+速度+payload)、配置外部化(ClientID+目录+timeout)

**Architecture:** 3子系统10项优化，7个Task独立可执行。

**Spec:** `docs/superpowers/specs/2026-06-19-p4-p5-p6-design.md`

## Global Constraints

- 最小改动原则
- wails build 每次通过
- 不改架构，只优化现有路径

---

### Task 1: P4a — prompt.NewEngine 单例化

**Files:** `app/app.go`, `chapter/chapter.go`, `outline/outline.go`, `worldview/worldview.go`, `character/character.go`, `analysis/analysis.go`

- [ ] **Step 1: app.go 创建单例 engine**
  - 在 `New()` 中：`eng := prompt.NewEngine("prompts")`
  - 传给各 agent 构造函数，替换内部的 `prompt.NewEngine(a.promptDir)`

- [ ] **Step 2: 修改 chapter.go**
  - `New()` 签名加 `eng *prompt.Engine` 参数
  - 删除 `promptDir string` 字段和内部 `prompt.NewEngine` 调用
  - 用传入的 `eng` 替代

- [ ] **Step 3: 修改其余 4 个 agent** (outline/worldview/character/analysis)
  - 同上：加 `eng` 参数，删本地 NewEngine

- [ ] **Step 4: wails build + commit**

### Task 2: P4b — 章节扫描优化 + P4c — 冗余 client

**Files:** `chapter/chapter.go`, `outline/outline.go`, `project/project.go`, `app/app.go`

- [ ] **Step 1: project.go 添加 ReadAllChapterSummaries()**

- [ ] **Step 2: chapter.go/outline.go 替换无界循环**

- [ ] **Step 3: app.go 消除冗余 client 创建**
  - `New()` 中不创建 client，统一在 `Startup()` 创建

- [ ] **Step 4: wails build + commit**
