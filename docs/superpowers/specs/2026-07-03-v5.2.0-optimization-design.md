# wubigork v5.2.0「凝形」优化设计

> 基于 v5.1.0 前后端审计，修复 48 个问题中的 24 项高影响问题。
> 三轮迭代：Bug 修复 → 工程质量 → 性能与体验。

## Phase 1：Bug 修复（10 项）

### B1 — Z-Image 工作流尺寸参数修复
**位置**: `internal/ai/image_comfyui.go` `buildZImageWorkflow()`
**问题**: width/height 参数被忽略，EmptyZImageLatentImage 用固定 ratio/size
**方案**: 根据传入 width/height 映射到 Z-Image 的 ratio 参数（如 1024×1024→"1:1"，896×1152→"3:4"），size 保持 "medium"

### B2 — Context cancel 泄漏
**位置**: `internal/ai/copilot.go:44`
**问题**: `_, cancel := context.WithTimeout(...)` 后 `_ = cancel` 丢弃 cancel func
**方案**: 改为 `defer cancel()`

### B3 — io.ReadAll 错误忽略
**位置**: `internal/ai/image_comfyui.go:288,344`
**问题**: `respBody, _ := io.ReadAll(resp.Body)` 忽略错误
**方案**: 检查 error 并返回，添加错误日志

### B4 — os.MkdirAll 错误忽略
**位置**: `internal/export/export.go:126`
**问题**: 目录创建失败后后续写入静默失败
**方案**: 检查 error 并返回

### B5 — NovelsDir 硬编码
**位置**: `internal/config/config.go:100`
**问题**: 默认为 `D:\AI\xiaoshuo`，跨系统不可用
**方案**: 改为 `~/wubigork-novels`（用 os.UserHomeDir 解析）

### B6 — CancelGhost 空实现
**位置**: `internal/app/copilot_handler.go:70`
**问题**: CancelGhost 不取消正在进行的生成
**方案**: 在 GhostComplete goroutine 中 check ctx.Done()，CancelGhost 调用 cancel

### F1 — 事件监听器无清理
**位置**: `frontend/src/layouts/MainLayout.tsx:194-213`
**问题**: `window.runtime.EventsOn('xai-output', ...)` 无 cleanup
**方案**: useEffect 返回 cleanup 函数调用 EventsOff

### F2 — 静默吞异常
**位置**: 全站 40+ 处 `catch (_) {}` / `catch (err) {}`
**问题**: 错误完全丢失
**方案**: 替换为 `catch (err) { console.error('[Component] operation:', err) }` 或 toast 提示

### F3 — loadOutlines 重复
**位置**: `ChapterPage.tsx:162-169`, `OutlinePage.tsx:97-104`
**问题**: 两处相同实现
**方案**: 提取到 `src/api/outlines.ts`（与 F4 合并）

## Phase 2：工程质量（8 项）

### F4 — API 抽象层
**位置**: 新建 `frontend/src/api/`
**方案**: 
- `api/outlines.ts` — loadOutlines, saveOutline, deleteOutline
- `api/characters.ts` — loadCharacters, saveCharacter, deleteCharacter
- `api/chapters.ts` — generateChapter, streamChapter, saveChapter
- `api/config.ts` — getConfig, setConfig
- `api/image.ts` — generateImage, getImageBackendInfo

### F5 — Wails 类型声明
**位置**: 新建 `frontend/src/types/wails.d.ts`
**方案**: 声明 `App` 接口，为 `window.go.app.App.*` 提供类型。消除 `@ts-ignore` 和 `any` 类型

### F6 — TTS 配置持久化
**位置**: `internal/config/config.go` Save()
**方案**: 新增 `tts_port`、`tts_backend`、`tts_speed` 的 Save case

### F7 — ComfyUI 模型文件名配置化
**位置**: `internal/ai/image_comfyui.go` + `internal/config/config.go`
**方案**: 在 configFile 中新增 `ComfyUIModel` (flux/zimage 各自的 unet/clip/vae 文件名)，工作流构建时从配置读取

### F8 — Save() 用常量替代字符串
**位置**: `internal/config/config.go`
**方案**: 定义 key 常量（如 `KeyAPIKey`, `KeyModel`），Save 和 Load 使用常量

### F9 — safeGo 工具函数
**位置**: 新建 `internal/util/safego.go` 或加到现有 `util/util.go`
**方案**: `func SafeGo(fn func())` 封装 goroutine + panic recover + 日志

### F10 — getPM nil 检查提取
**位置**: `internal/app/` handler 文件
**方案**: 在 app.go 添加 `func (a *App) requirePM() (*project.Manager, error)` 辅助方法

### F11 — 删除废弃文件
**位置**: `internal/ai/context.go`
**方案**: 直接删除

## Phase 3：性能与体验（6 项）

### F12 — 巨型组件拆分
**方案**:
- `OutlinePage` (1210行) → 提取 `OutlinePanel`, `ThreadPanel`, `VolumePanel`, `useOutlines` hook
- `ChapterPage` (1166行) → 提取 `ChapterEditor`, `AIAssistSheet`, `NextChapterWizard`, `useChapterStream` hook
- `CharacterPage` (734行) → 提取 `CharacterDetail`, `CharacterPortrait`, `useCharacters` hook

### F13 — useMemo/useCallback 优化
**方案**: 为所有页面组件的 event handler 和 computed 值添加 useCallback/useMemo

### F14 — 内联样式 → CSS 模块
**方案**: 提取 ChapterPage 70+ 处和 OutlinePage 的内联 style 到独立 CSS 模块

### F15 — setTimeout 清理
**方案**: 组件卸载时 clearTimeout，用 useRef 存储 timer ID

### F16 — 移动端占位端点
**位置**: `internal/mobile/handlers.go:48-53`
**方案**: 对接实际 project.List() API，替换硬编码 JSON

### F17 — console.error 统一
**方案**: 创建 `src/utils/logger.ts`，提供可开关的日志函数
