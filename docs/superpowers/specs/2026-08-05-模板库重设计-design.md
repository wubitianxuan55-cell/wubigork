# 绘梦模板库重设计 — 结构化模板库设计文档

> 日期：2026-08-05 ｜ 状态：已调研，直接实施 ｜ 依据：网上调研结论 + 绘梦 Studio Console 视觉体系

## 1. 目标与范围

将「AI 绘梦」的图片模板库从「一段长文字的集合」升级为「可检索、结构化、按创作流程组织的模板库」：

- 数据模型：模板增加 `description`（用途说明）、`size`（推荐画幅）、`tags`（维度标签），提示词内部按「风格 → 主体 → 环境 → 光线 → 构图 → 质量」结构化书写。
- 分类重构：从 6 类 41 个扩为 7 类 70+ 个，去掉 emoji 标签，按创作意图/风格/视角/光影/应用场景组织，分类配主题色便于辨识。
- UI 重设计：分类筛选 + 关键词搜索 + 卡片（标题/描述/标签/画幅徽标/自定义操作），移除硬编码靛蓝，复用 Studio Console 视觉手性。
- 兼容旧自定义模板（localStorage 旧数据无需迁移即可读取）。

非目标：不改后端调用；不引入新依赖；不动其他页面。

## 2. 调研结论（2026-08-05 网上调研）

- **提示词结构最佳实践**（sivolko/ai-image-prompts-library）：风格定义 → 主体 → 环境 → 技术规格（画幅）→ 质量/细节；强调具体材质、光线、纹理。
- **结构化模板管理**（VigoZhao/AI-Visual-Prompt-Cookbook）：每个风格 = `prompt_template + negative_prompt + 示例 + 锚点`，可检索目录。
- **可视化浏览与一键套用**（Midjourney Style Explorer / Leonardo presets）：卡片浏览、分类过滤、点击即用，是最有效的模板消费形态。
- **分类配色与持久化**（PromptFill / OpenPromptStudio）：分类用颜色区分，提示词按片段组装，自定义内容持久保存。

结论：模板库应「结构化存储 + 分类/搜索 + 卡片预览 + 一键套用」，分类承载创作决策路径。

## 3. 数据模型

```ts
export interface Template {
  label: string            // 名称（无 emoji）
  description?: string     // 一句话说明用途
  prompt: string           // 结构化提示词
  negative?: string        // 负面提示词
  size?: string            // 推荐画幅：1:1 / 16:9 / 9:16 / 3:4 / 4:3 / 2:3
  tags?: string[]          // 维度标签：风格/光影/构图/用途
}

export interface CustomTemplate extends Template {
  id: string
}

export interface TemplateCategory {
  id: string               // 稳定 id
  label: string            // 中文名
  color: string            // 分类主题色（hex）
}
```

`size` 语义为「建议画幅」，选中模板时仅作为提示展示（可选联动，暂不自动改画幅，避免打断用户选择）。

## 4. 分类设计（7 类，去 emoji，各配主题色）

| id | 分类 | 主题色 | 说明 |

## 5. UI 重设计（TemplatePickerModal）

- 弹窗宽度 560 → 680，保持透明底 + 统一圆角。
- 顶部：搜索输入框（按 label/description/tags 匹配）+ 分类 pill 行（分类前带主题色圆点，选中态用主题色描边与淡底）。
- 卡片网格：`minmax(170px, 1fr)`；卡片 = 标题 + 描述（2 行截断）+ 标签 chips（最多 3 个）+ 画幅徽标（右侧小字）+ 自定义模板的操作按钮（编辑/删除）。
- 交互：hover 提升描边与背景；点击卡片套用并关闭；「我的模板」分类底部保留虚线新建卡。
- 分类配色不硬编码靛蓝，统一走 `var(--color-primary)` 与分类主题色。
- 空态：无匹配结果时显示提示文案与清空搜索按钮。
