# 角色库「人物档案卡」重设计

日期：2026-08-07
状态：方向已确认（方案 A：竖版档案卡）

## 背景与目标

角色库当前是功能性的卡片网格：信息齐全但视觉偏“工具列表”，缺少角色收藏与陪伴感的表达。本次重设计把每张卡片改造成一张“人物档案卡 / 设定卡”，用编辑排版质感呈现角色的立绘、元数据、弧线与五维，同时保持现有功能与信息架构不变。

## 设计基调

- 沿用应用现有 gaea 深色玻璃 M3 体系，不引入新字体、新色系、新依赖。
- 主色保持 `--gaea-glow`（酸橙绿，UI/操作强调）；粉色 `#f472b6` 继续作为“人格 / 陪伴”语义色（立绘占位、雷达、可聊天标识）。两种颜色为应用既有语义，不改动。
- 质感关键词：档案册、发丝线、编号感、克制动效。

## 范围

### 做
- `CharacterLibraryPage.tsx`：列表区卡片整体重设计；头部工具栏与分页做轻量整理。
- 新增独立卡片组件（`components/characterlib/CharacterCard.tsx`），保持列表页可读。

### 不做
- 不改 `CharacterLibEditor` / `CharacterMemoryModal` 的功能与字段。
- 不改接口、不改数据字段、不改路由与导航标签。
- 不改分页逻辑（每页 24 条）与筛选逻辑。

## 卡片结构（档案卡）

```
┌──────────────────────────────┐
│ NO.001   [内置]        [可聊天]│   ← 档案眉：编号 + 类型 + 可聊天标记
│ ┌──────────────────────────┐ │
│ │                          │ │   ← 立绘横幅 4:3
│ │       立绘 / 首字占位       │ │      渐变底 + 光泽
│ └──────────────────────────┘ │
│  角色名                       │   ← 大字号展示
│  主角 · 女性 · 23 · 存活        │   ← 发丝线元数据行
│  「弧线一句话」                 │   ← 引言式弧线（最多 2 行截断）
│  #剑修  #女主                  │   ← 索引式标签
│ ──────────────────────────── │
│  [五维雷达]          [操作…]    │   ← 底部：雷达 + 操作（悬停浮现）
└──────────────────────────────┘
```

### 档案眉
- 左上：档案编号（如 `NO.001`，按列表序号生成，等宽数字感、小字距）。
- 右上：类型标签（内置/自定义/助手）+ 可聊天标记（粉色小点 + 文案）。
- 用发丝线（1px 半透明边框）与正文分隔。

### 立绘横幅
- 4:3 横向横幅，圆角统一。
- 有 `portraitUrl`：覆盖显示图片；无图：深色渐变底 + 角色名首字（或人形图标）的占位。
- 悬停时一道柔和高光扫过（`prefers-reduced-motion` 下关闭）。

### 档案正文
- 角色名：较大字号（约 20px）、粗体，单行截断。
- 元数据行：`定位 · 性别 · 年龄 · 状态`，小字号、次级色、发丝线上下分隔；缺省字段不显示占位。
- 弧线：作为引言展示（若存在），最多两行截断，用引号或前置竖线表示“档案摘录”。
- 标签：索引式小条目（`#标签`），最多 3 个。

### 底部
- 左：五维雷达（`TisorRadar`，尺寸约 54px，粉色），仅可聊天角色显示。
- 右：操作按钮组（编辑 / 设为当前人格 / 记忆 / 项目关联 / 删除），保持现有功能；默认淡出、卡片悬停时浮现（键盘聚焦也显示）。
- “当前人格”状态：卡片加粉描边 + 角落“当前”标记；已加入项目：显示“已加入”小标记。

## 版式与网格

- 响应式列：`xs=1 / sm=2 / lg=3 / xl=4`，间距 14px。
- 卡片内部用纵向留白节奏：眉 12px → 立绘 → 正文 14px → 分隔 → 底部 12px。
- 卡片高度不强制统一，由内容决定；底部操作区用 `margin-top: auto` 对齐。

## 排版

- 不引入新字体，沿用现有字体栈；通过字号层级（16 / 13.5 / 11 / 10.5）与字距（档案眉、微标签使用 `letter-spacing: 0.06em`）实现档案质感。
- 数字（编号、年龄、五维数值）保持等宽渲染观感（`font-variant-numeric: tabular-nums`）。

## 色彩与圆角

- 卡片背景沿用玻璃变量 `--gaea-glass-bg` / `--md-sys-color-surface-container`，边框用 `--md-sys-color-outline-variant`。
- 悬停边框、当前人格描边统一用粉色 `#f472b6`；操作强调用 `--gaea-glow`。
- 圆角体系：卡片 16px、立绘 12px、标签/按钮全圆角（pill）。全页遵守这一套，不混用。

## 动效

- 悬停：卡片上浮 `translateY(-3px)` + 边框提亮 + 操作区浮现（180ms）。
- 按下：`scale(0.98)` 触感反馈。
- 立绘光泽扫过：仅悬停一次，300ms。
- 全部动画在 `prefers-reduced-motion: reduce` 下关闭。

## 状态

- 加载中：骨架卡片（占位块与最终卡片同形，不显示旋转 spinner）。
- 空态：档案册空页样式（“尚未归档任何角色” + 新建/导入按钮），保留现有入口。
- 错误：沿用现有 `message` 提示，不新增阻塞层。
- 当前人格 / 已加入项目：卡片级标记。

## 无障碍

- 按钮保持可访问名称（icon 按钮有 `title` / `aria-label`）。
- 文字对比度满足 WCAG AA（正文 ≥4.5:1，大字号 ≥3:1）。
- 键盘聚焦可见（沿用现有 `:focus-visible` 描边）。
- 操作区在 `:hover` 与 `:focus-within` 时都可见。

## 改动文件

- `frontend/src/pages/CharacterLibraryPage.tsx`（列表渲染改用新卡片组件）
- `frontend/src/components/characterlib/CharacterCard.tsx`（新增）
- `frontend/src/components/characterlib/character-card.css`（新增，档案卡样式独立文件，优先 class 而非内联堆叠）

## 验收标准

- 列表页在 4 种响应式宽度下布局正确，卡片视觉为档案卡风格。
- 现有功能（搜索、筛选、可聊天开关、导入/同步、新建、编辑、设人格、记忆、项目关联、删除、分页）全部可用。
- 加载骨架、空态、当前人格、已加入项目、悬停操作区可见。
