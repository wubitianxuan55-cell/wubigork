# P4+P5+P6 合并优化 设计

> 性能优化 + 前后端一致性 + 配置外部化，三个独立子系统合并为一个计划。

**目标:**
- P4: prompt 单例化（5→1次加载）、章节扫描优化（无界循环→目录扫描）、冗余 client 消除
- P5: TS 类型补全、SaveCharacters 参数修复、流速度标注、done 事件 payload 扩展
- P6: Client ID/小说目录/timeout/temperature 从硬编码移到配置文件

**涉及文件:** app/app.go, chapter/chapter.go, config/config.go, ai/client.go, ChapterPage.tsx, types 等

## P4 性能优化

### 4a — prompt.NewEngine 单例化

**现状:** app.go 中 5 个 agent（chapter/outline/worldview/character/analysis）各自调用 `prompt.NewEngine("prompts")`，每次都 `loadAll()` 读 4 个 JSON 模板文件。

**修复:** app.go 中创建一次 `promptEngine`，注入各 agent 的构造函数。

```go
// app.go New() 中
eng := prompt.NewEngine("prompts")

// 注入
a.chapterAgent = chapter.New(a.client, a.pm, a.cfg, eng)
a.outlineAgent = outline.New(a.client, a.pm, a.cfg, eng)
// ...其他 agent 同样
```

各 agent 构造函数加 `eng *prompt.Engine` 参数，去掉内部的 `prompt.NewEngine` 调用。

**影响文件:** app/app.go, chapter/chapter.go, outline/outline.go, worldview/worldview.go, character/character.go, analysis/analysis.go

### 4b — 章节摘要扫描优化

**现状:** `chapter.go:55` 和 `outline.go:94` 中 `for i := 1; ; i++ { ReadChapterSummary(i) }` 无界循环，对 N 章做 N 次独立文件读取。

**修复:** 用 `ioutil.ReadDir` 扫描 `chapters/` 目录，收集所有 `*-summary.json` 文件，按编号排序后批量读取。

```go
func (m *Manager) ReadAllChapterSummaries() ([]types.ChapterSummary, error) {
    entries, err := os.ReadDir(filepath.Join(m.projectDir, "chapters"))
    if err != nil {
        return nil, err
    }
    var summaries []types.ChapterSummary
    for _, e := range entries {
        if strings.HasSuffix(e.Name(), "-summary.json") {
            // parse and append
        }
    }
    sort.Slice(summaries, ...) // by chapter number
    return summaries, nil
}
```

### 4c — 冗余 client 消除

**现状:** `app.go New()` 创建 `ai.NewClient(cfg)`，然后 `Startup()` 中又替换一次。

**修复:** `New()` 中不创建 client，`Startup()` 中统一创建。

## P5 前后端一致性

### 5a — TS OutlineNode 类型补全

```typescript
// ChapterPage.tsx 中补充：
interface OutlineNode {
  id: string; parent_id?: string; title: string; summary: string
  status: string; order_index: number
  key_points?: string[]; characters?: string[]; scene_ideas?: string[]
  emotion?: string; chapter_file?: string
  children?: OutlineNode[]
}
```

### 5b — SaveCharacters 参数修复

**现状:** `app.go SaveCharacters(cfJSON string)` 接收前端传来的 JSON 但忽略，改用 `characterAgent.GetCharacters()` 重新从文件读。

**修复:** 反序列化 `cfJSON` 参数，用它更新角色数据，而不是重新读文件。

### 5c — 流速度标注

**现状:** `streamSpeed = total/elapsed` 显示平均速度。

**修复:** 标签从 `{streamSpeed}字/秒` 改为 `均{streamSpeed}字/秒`，明确是平均值。

### 5d — done 事件 payload 扩展

**现状:** 只发 `summary.Summary` 字符串。

**修复:** 发送完整 `ChapterSummary` 结构（含 key_events, characters_appeared, emotion_tone, quality_estimate）。

## P6 配置外部化

### 6a — Client ID 移到配置文件

从 `config.go` 硬编码 → `~/.wubigork_config.json` 中的 `xai_client_id` 字段。如果文件/字段不存在，fallback 到环境变量 `WUBI_XAI_CLIENT_ID`。

### 6b — 小说目录可配置

已有 `WUBI_NOVELS_DIR` 环境变量支持。增加到 config 文件的 `novels_dir` 字段，优先级：config 文件 > 环境变量 > 默认值。

### 6c — timeout/temperature/MaxTokens 可配置

```json
{
  "http_timeout_seconds": 180,
  "default_temperature": 0.7,
  "max_tokens_ratio": 3
}
```

保留硬编码默认值，config 文件可覆盖。
