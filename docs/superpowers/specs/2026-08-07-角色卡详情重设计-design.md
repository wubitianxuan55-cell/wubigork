# 角色卡「详情档案」重设计

日期：2026-08-07
状态：方向已确认（档案册详情视图）

## 背景与目标

角色库列表已在上一步重设计为竖版「人物档案卡」。点击卡片或“编辑”后弹出的详情仍是一个功能齐全但偏工具化的长表单（`CharacterLibEditor`）：三段堆叠（基础/小说/聊天）+ 纯 antd 控件，缺少与档案卡一致的“档案册”质感。本次把详情改造成一张展开的「角色档案页」：立绘做主角，身份信息与五维放在左侧“身份栏”，小说与聊天设定作为“卷宗正文”分区，保持全部字段与保存语义不变。

## 设计基调

- 沿用 gaea 深色玻璃 M3 体系；粉色 `#f472b6` 为人格/陪伴语义色，酸橙 `--gaea-glow` 为操作强调色。
- 质感关键词：档案册、卷宗分区、立绘主角、发丝线、编号感。
- 详情与档案卡共用同一视觉语言（圆角 16/12、发丝线 1px、pill 标签），形成“卡片 → 展开详情”的连续体验。

## 范围

### 做
- 重写 `CharacterLibEditor` 为档案详情视图：档案眉 + 立绘横幅 + 左侧身份栏 + 右侧卷宗正文 + 底部操作条。
- 档案卡整卡可点击进入详情（编辑/设人格等操作按钮点击不触发）。
- 列表页传入“当前人格”状态，详情眉显示徽标。

### 不做
- 不改任何数据字段、接口、保存逻辑、后端。
- 不改 `CharacterMemoryModal`（状态/记忆/追踪保持独立入口）。
- 不改分页/搜索/筛选逻辑。

## 详情结构（档案页）

```
┌────────────────────────────────────────────────┐
│ 角色档案 · NO.001   [内置] [可聊天] [当前人格]   ✕ │  ← 档案眉
│ ┌────────────────────────────────────────────┐ │
│ │             立绘横幅 16:9                   │ │  ← 渐变覆盖 + 光泽
│ │       角色名（大字）  ·  定位 · 状态          │ │
│ └────────────────────────────────────────────┘ │
│ ┌─────────────┬──────────────────────────────┐ │
│ │ 身份栏        │ 卷宗正文                      │ │
│ │ 立绘 URL 编辑 │ 小说设定                      │ │
│ │ 性别 · 年龄   │  性格 / 背景 / 外貌 / 身材     │ │
│ │ 定位 · 状态   │  动机 / 弧线 / 备注           │ │
│ │ 标签（可编辑） │ 对话样本                      │ │
│ │ 五维雷达+滑块 │ 聊天设定                      │ │
│ │ 可聊天开关    │  口吻指南 / 行为规则 / 情感逻辑 │ │
│ └─────────────┴──────────────────────────────┘ │
│ 项目引用 / 通道信息               [取消] [保存]   │  ← 底部操作条
└────────────────────────────────────────────────┘
```

### 档案眉
- 左上：`角色档案 · NO.xxx`（新建时 `新建档案`），等宽数字、小字距。
- 右上：类型标签（内置/自定义/助手）+ 可聊天小点标记；当前人格时追加粉色“当前人格”徽标。
- 关闭按钮在眉右端，悬停可见描边。

### 立绘横幅
- 16:9 全宽横幅，圆角 12，深色渐变底 + 右侧粉色辉光；无图时用角色名首字占位（与档案卡一致）。
- 角色名大字（约 26px）与 `定位 · 性别 · 年龄 · 状态` 元数据行叠在横幅左下，带轻微遮罩保证可读性。
- 悬停一道柔和光泽扫过（`prefers-reduced-motion` 关闭）。

### 左侧身份栏（约 260px，与正文发丝线分隔）
- 立绘 URL 输入（带实时缩略图）。
- 性别 / 年龄 / 定位 / 状态四个紧凑字段（两列小网格）。
- 标签输入（逗号分隔，实时渲染为 pill）。
- 五维雷达（约 140px，粉色）+ 5 条滑块（T/I/S/O/R）。
- 可聊天开关（说明文字同现状）。

### 右侧卷宗正文
- 分区标题小号大写感 + 发丝线分隔：
  - 「小说设定」：性格 / 背景 / 外貌 / 身材体型 / 动机 / 角色弧线
  - 「对话样本」：每行一条
  - 「备注」
  - 「聊天设定」：口吻指南 / 行为规则 / 情感逻辑
- 文本域统一玻璃质感（现状样式保留），行数微调让纵向节奏更稳。

### 底部操作条
- 左侧：被 N 个项目引用（有则显示）；assistantId 通道信息（有则显示，次级色小字）。
- 右侧：取消（ghost）→ 保存（主色 pill，loading）。

## 版式与间距

- 弹窗宽度 880px；正文最大高度约 74vh，纵向滚动。
- 左右两栏 260px + 弹性；身份栏与正文之间用发丝线分隔。
- 内部节奏：眉 12px → 横幅 16px → 两栏 16px → 操作条 12px；字段间距 8-10px。

## 排版

- 不引入新字体；字号层级：横幅名 26 / 分区标题 12.5 / 标签与元数据 10.5 / 正文 12.5。
- 数字保持等宽观感（`font-variant-numeric: tabular-nums`）；档案眉与分区标题 `letter-spacing: 0.06em`。

## 色彩与圆角

- 背景沿用玻璃变量；横幅渐变用粉色系（与档案卡占位一致）。
- 圆角体系：弹窗 16、横幅 12、输入与标签 pill；操作按钮 pill。

## 动效

- 打开：弹窗默认淡入缩放（antd），不新增自定义入场。
- 横幅光泽扫过：仅悬停一次，300ms；reduced-motion 下关闭。
- 保存 loading：按钮内 spinner。

## 状态

- 新建：眉显示 `新建档案`，横幅显示首字占位，保存后按返回值刷新列表。
- 保存中：按钮 loading，禁止重复提交。
- 保存失败：沿用 `message.error`。

## 无障碍

- 立绘编辑、开关、滑块、文本域均有可访问名称（label 或 aria-label）。
- 整卡可点击后，卡片需 `role="button"` + `tabIndex={0}` + Enter/Space 键盘触发；操作按钮 `stopPropagation` 且保留原 title。
- 文字对比度满足 WCAG AA；`prefers-reduced-motion` 降级。
