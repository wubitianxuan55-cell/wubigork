# 角色详情：一键随机补齐 + 生成剧照

日期：2026-08-07
状态：方向已确认（库作用域 AI 补齐 + 智能 prompt 剧照）

## 背景与目标

角色详情档案视图已上线（2.18）。本次在详情里增加两个高频能力：
1. **一键随机补齐**：AI 根据角色名与已有设定，只填充空缺字段（性格/背景/外貌/身材/动机/弧线/定位/状态/标签等），已有内容一律保留。
2. **生成剧照**：按角色的外貌/身材/气质/标签构建智能 prompt，调用现有图片生成管线出图，结果写入立绘横幅（保存后才落库）。

关键约束：角色库是全局资产，不依赖“已打开小说项目”。补齐与剧照都必须能脱离项目工作（有项目时借用题材/世界观做上下文）。

## 范围

### 做
- 后端新增两个库作用域方法：`CharacterGenerateFill(chJSON)`、`CharacterGeneratePortrait(chJSON, model)`。
- 详情组件新增「随机补齐」按钮（小说设定分区标题行）与「生成剧照」按钮（立绘横幅右上）。
- 补齐为“只填空字段”合并语义；剧照生成后仅写入表单，由用户检查后随保存落库。

### 不做
- 不改角色库数据模型与保存逻辑。
- 不自动保存补齐/剧照结果（保留用户审阅）。
- 不触碰小说项目侧的 `GenerateCharacters` / `GenerateCharacterPortrait` 老接口。

## 交互

### 随机补齐
- 位置：卷宗正文「小说设定」分区标题右侧（闪电图标 + 文案）。
- 点击后 loading；调用 `CharacterGenerateFill(当前表单 JSON)`。
- 后端：`character-generate-single` 模板 + 世界观/题材（有项目时）+ 当前已有设定摘要 → LLM（novel 功能级路由）→ 解析 JSON → 只把“当前为空且生成非空”的字段写回。
- 返回合并后角色 JSON；前端回填表单并提示「已补齐 N 处空缺，检查后保存」；无空缺时提示「没有空缺字段需要补齐」。
- 名称为空时不发起调用。

### 生成剧照
- 位置：立绘横幅右上角玻璃 pill 按钮。
- 点击后 loading；调用 `CharacterGeneratePortrait(当前表单 JSON, 模型=空默认)`。
- 后端按字段构建中文 prompt（名称/性别/年龄/外貌/身材/气质/标签 + 构图与质量约束），negative 防文字/水印/肢体畸形；复用 `GenerateFreeImage` 管线（ComfyUI/xAI/Herdsman/Ollama 自动恢复与落盘逻辑）。
- 返回图片 data URL / 远程 URL；前端写入 `portraitUrl` 并刷新横幅预览；用户保存后落库。
- 名称为空时不发起调用。

## 状态与异常

- 两个按钮各自独立 loading，可同时进行（补齐走 LLM、剧照走图片管线）。
- 失败用 `message.error` 展示后端返回原因；成功提示“检查后保存”，强调未自动落库。

## 无障碍

- 两个按钮带文字与 `title`，可访问名称明确；loading 态禁用重复点击。
