## 2. 逐项施工卡

### T6 · 上下文碎片契约（半天，A 批第一刀）

- **目标**：注入上下文带上 `Role / Kind / Markers / Provenance` 四件套。
- **改哪里**：`internal/gaea/prompt` 与 `contextview` 的注入入口；新增 `internal/gaea/context/fragment.go`。
- **依赖**：无。**这是全批的地基**，T7/T9/T11 都读它的字段。
- **硬验收**：① 同一 `Kind` 的片段连续三轮都能被 `MatchesText` 命中；② 工具输出片段即使由框架代写
  `Prov == ProvTool`；③ 带 user 角色但 `Prov == ProvHarness` 的片段**不能**作为授权证据。
- **回退**：字段只增不改，`Prov` 缺省 `Unknown`，老逻辑照旧。

### T7 · 章节化 + 快照差分（1–1.5 天）

- **目标**：上下文按稳定 `Kind` 分章节，每轮只渲染变化。
- **改哪里**：`contextview` 加章节表与 `RenderDiff`；`prompt` 按章节装配。
- **依赖**：T6。**分批**：① 章节表 + 只加可观测（不改行为）② 快照 + diff。
- **硬验收**：① 连续三轮无变化 → 后两轮该章节**零片段**；② 有变空 → 恰好一条移除通知；
  ③ `Previous.Kind==Unknown` 且当前非空 → 替换通知 + 内容。
- **回退**：开关 `context.sections.diff`，关时走原拼装路径。

### T8 · 工具面预算三层（1.5–2 天，含 T5）

- **目标**：目录只发差分、检索才给全量、描述按预算裁。
- **改哪里**：新增 `tool/catalog.go`（name→hash 差分）、`tool/search_index.go`、`tool/budget.go`。
- **依赖**：T7（章节化提供「工具章节」这个容器）。
- **硬验收**：① 三轮工具集不变 → 工具部分上下文逐字节相同；② 注册 40 个工具首轮只下发 ≤12 个，
  `tool_search` 命中后本轮出现目标 schema 且能成功调用；③ 预算收紧 50% 时工具名全保留、只有描述被截。
- **回退**：`tools.schema_budget.enabled`、`tools.search.enabled` 双开关，默认关。

### T9 · 压缩三形态（1–1.5 天）

- **目标**：新增「不摘要、直接换窗口」形态，并补两种触发原因。
- **改哪里**：`agent/compact.go` 加 `newWindowCompact(reason)`；`hook` 加 `PostCompact`。
- **依赖**：T6（按 `Kind` 决定重注入）、T10 可选（压缩前审批策略重注入更好）。
- **硬验收**：① 压缩后历史里**无摘要占位消息**但有 `ContextCompaction` 起止事件；
  ② `input_goal_ids` 压缩前后一致；③ `window_number` 单调递增；
  ④ 切到更小窗口模型时**先压缩再请求**（用事件顺序断言）。
- **回退**：`compact.new_window.enabled` 默认关；关时只有原有摘要式压缩。

### T10 · 审批七态 + argv 前缀规则 + 追认（2–2.5 天）

- **目标**：七态落地、规则按 argv 前缀匹配、拒绝可追认。
- **改哪里**：`permission`（`GrantScope` 三态 + `ArgvRule`）、`control/controller_approval.go`（七态 + 快照）。
- **依赖**：无（但 T11 依赖它）。
- **硬验收**：① 「记住这条命令」后 `git status` 放行，而 `git status; rm -rf /tmp/x` **仍要审批**；
  ② `Session` 放行在 `/new` 后失效、`Persistent` 仍生效；③ 超时 → `TimedOut` 且**不产生 deny 账本**；
  ④ 拒绝理由出现在下一轮模型上下文；⑤ 追认后同一动作执行一次且账本记「追认 + 原理由」。
- **回退**：`permission.argv_rules.enabled` 默认关；关时回落 glob 规则（现有行为）。

### T11 · Guardian 自动评审（4–5 天，最大一件）

- **目标**：动作级评审，`allow/deny` + 风险/授权三档 + 理由；失败回落用户流程。
- **改哪里**：新增 `internal/gaea/guardian`（contract/budget/decision）；接 `internal/ai` 与 `controller_approval`。
- **依赖**：T10（七态与追认）、T6（归属判定）。
- **硬验收**：① 6 条样例文本（严格 JSON / 散文包裹 / 缺 risk / 缺 rationale / 空 / 非 JSON）解析结果符合预期；
  ② 超时/预算超限 → 返回错误且**不产生拒绝账本**；③ `Prov != User|DeveloperInstructions|AgentsMd`
  的片段不能支撑 `allow`；④ 连续 3 次 deny → 请求中断回合一次。
- **回退**：`guardian.enabled` 默认关；关时审批仍是纯人工。

### T12 · 记忆四护栏（2 天）

- **目标**：脱敏、背压门、基线差分、锁位置。
- **改哪里**：`memory/{sanitize,gate,baseline}.go`。
- **依赖**：无。
- **硬验收**：① 12 条假密钥写入后按原文 grep 全表零命中；② 5 条含 `key`/`token` 字样的普通文本不误伤；
  ③ 限流中整理被跳过且事件为 `skipped: rate_limited`；④ 差分超阈值（删除 >10% / 修改 >30%）被拦下且原记忆未改。
- **回退**：脱敏常开（低风险）；差分与背压各带开关。

### T13 · 执行语义（双缓冲 + 双闸门）（2 天，含 T2）

- **目标**：长命令边跑边看，输出不重复、截断可解释。
- **改哪里**：新增 `proc/session.go`、`proc/headtail.go`、`proc/env.go`；`agent/batch_executor.go` 接双闸门。
- **依赖**：无。
- **硬验收**：① 连续三次 `Drain` 内容互不重叠且拼接等于 `Transcript()` 前缀；② 超限时**只有一个**省略标记
  且字节数等于实际丢弃量；③ `yieldMS=100` 在 ≈100ms 返回（±30%）且进程仍活；④ 进程退出后 100ms 内拿到收尾输出。
- **回退**：`proc.session.enabled` 默认关；关时走现有「跑完取结果」。

### T14 · 技能 RRF（1–1.5 天）

- **目标**：词法 + 字符两路融合，确定性排序。
- **改哪里**：新增 `skill/{lexical,ngram,fuse,select}.go`。
- **依赖**：无。
- **硬验收**：① 同查询 100 次结果逐元素相同；② 覆盖 3 个不同词的文档排在只覆盖 1 词的前面；
  ③ 8 KiB 查询不报错且 `query_truncated=true`；④ 中文技能名在中文查询下能进 top-3。
- **回退**：`skill.rrf.enabled` 默认关；关时用现有匹配。

### T15 · 角色数据化（可选，1.5–2 天）

- **目标**：席位/角色从代码搬到文件，支持角色级配置覆盖。
- **改哪里**：`internal/pantheon` 加载层；新增 `agents/<role>.md` 或 `agents.toml`。
- **依赖**：无（但 T10/T11 的「按席位不同策略」需要它才完美）。
- **硬验收**：① 新建角色文件即在 UI 出现；② 删除后不残留注册；③ 角色 `description` 出现在 spawn 引导里；
  ④ 角色级配置覆盖只影响该席位。

## 4. 共同纪律（每条都适用）

1. **先跑基线记数字**，改完只许持平或增加用例；不为过测试放宽生产逻辑。
2. **新能力默认关闭**，关时与现状逐字节等价；每个 T 都有自己的开关名（见各节）。
3. **不新增外部依赖**；技能检索用现有 `bm25`/`textsim`，脱敏用标准库 `regexp`。
4. **只做后端与单测**，本批不涉及前端改动；不跑 `wails build` / `smoke.ps1`。
5. **一处只改一次**：同一语义不要在两个包里各实现一份（尤其「章节渲染」与「上下文拼装」）。
6. **机制可照抄，文案自己写**：提示词、通知文案、拒绝理由都不能从逆向产物直接搬。
