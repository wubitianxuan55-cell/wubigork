# 中文网文去 AI 味（novel-deslop）

## Overview

去味引擎是 gaea 内核的**通用机制**（确定性替换/打分/分词，零 LLM 零网络），
**词表是领域知识资产**——默认表随构建内置，本目录的 `words.json` 可整体覆盖它，
改词表不需要改代码、不需要重新安装。

## 机制三层

1. **词表替换**（去味第一梯队）：`replacements` 表（AI 高频词 → 平实替代表，
   如「眸光流转→目光流转」「缓缓→慢慢」），按词长降序全局替换。原则：不改
   情节与语义，只把「AI 腔」换成更口语化的写法；等价映射难免语境误差，作者
   可在结果上再手改。
2. **标点归一**：连串省略号/感叹号收敛（………→……，！！→！）。
3. **规则打分**：`blacklist` 黑名单词（与替换表同源）参与 AI 味评分（规则 9），
   另含句长分布、衔接词密度等统计维度。分数未改善则不落盘（宁缺勿滥）。

## 如何改词表（覆盖文件）

在当前工作区建 `.gaea/skills/novel-deslop/words.json`（与内置表同 schema）：

```json
{
  "replacements": {"眸光流转": "目光流转", "缓缓": "慢慢"},
  "blacklist": ["眼帘", "轻叹", "眸光"]
}
```

- **整体替换，不合并**：想增条目把内置默认表抄进来再加（内置表见构建源
  `internal/novelstyle/words.json`）。
- 覆盖文件放好后重启 gaea 生效（每进程懒加载一次）。
- 也接受 `.agents` / `.agent` / `.claude` 惯例目录（`.gaea` 优先）。

## 判定纪律

- 替换后评分未降低 → 不落盘（重写只降不升）。
- 词表是保守基线：宁漏勿误，拿不准的词先进黑名单观察，再决定是否加替换映射。
