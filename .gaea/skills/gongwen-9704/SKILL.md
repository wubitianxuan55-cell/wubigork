# 中文公文规范（GB/T 9704-2012）

## Overview

公文规范分层检查：**红头要素**（文本层，看内容有没有）、**排版细则**（排版层，
看格式对不对）、**页码**（页脚层）与**红头字色**（字色层）。先取事实，再对照本文件
的规则表逐项判定，最后逐项给修复建议。

## Workflow

1. **红头要素**：读文档文本（docx 可经 GaeaDocumentLint 绑定或 docx 技能取文本），
   对照下方「红头要素表」检查七项是否齐备。
2. **排版细则**：对本目录脚本运行
   `python scripts/docx_layout.py <文档.docx>` 取排版事实 JSON，
   对照下方「排版细则表」逐项判定。
3. **修复**：每项不合格给出**带实测值**的修复建议（如「上边距实测 25.4mm，应 37mm」）；
   用户同意后可用文档编辑工具就地修改。判定口径见下方「判定纪律」。

## 红头要素表（文本层）

| 要素 | 要求 | 缺失时的修复建议 |
|------|------|------------------|
| 发文机关标志（红头） | 首行为机关全称或规范化简称 | 补红头字（红色小标宋） |
| 发文字号 | 机关代字〔年份〕序号号，如 ×发〔2026〕3号；**年份用六角括号〔〕不用方括号[]** | 标题下方补发文字号 |
| 公文标题 | 发文机关+事由+文种（关于××的通知/报告/请示） | 补全三要素 |
| 主送机关 | 正文开头顶格称谓行，如「各市、州人民政府：」 | 补主送机关 |
| 成文日期 | 阿拉伯数字，如 2026年8月29日（2012 标准起不用汉字数字） | 落款补成文日期 |
| 印章/盖章位 | 成文日期上加盖发文机关印章（或标注盖章位） | 补盖章位说明 |
| 版记 | 抄送、印发机关与印发日期 | 文末补版记 |

## 排版细则表（排版/页脚/字色层，对照 docx_layout.py 输出）

| 检查项 | 规范值 | 判定方法（对 JSON 字段） |
|--------|--------|--------------------------|
| 页边距 | 上 37 / 下 35 / 左 28 / 右 26 mm（±2mm 容差） | margins.*_mm 逐边比对；缺 pgMar = 无法核验，建议补页面设置 |
| 公文标题字号 | 二号 = 22pt（size_half_pt=**44**）；字体建议小标宋 | 找「关于…文种」且 ≤60 字的段落；字体名不作硬判定（变体多） |
| 正文字体字号 | 三号 = 16pt（size_half_pt=**32**），仿宋（仿宋_GB2312/FangSong） | 对非标题非层级标题、≥4 字段落做多数票；主体不符才报 |
| 行距 | 28~30 磅固定值（line_twips=**560~600** 且 line_rule=exact/atLeast） | 多数段落符合即视为符合（行距常在样式层统一） |
| 首行缩进 | 2 字符（first_line_chars=**200**，或 first_line_twips=**560~720**） | 多数段落比对 |
| 层级标题字体 | 「一、」黑体；「（一）」楷体（三级及以下不查） | 按段落前缀找；字体字段缺失不判（宁缺勿误） |
| 页码（页脚层） | 4号半角宋体阿拉伯数字（size_half_pt=**28**），数字左右各放一条一字线，如「— 1 —」；单页码居右空一字、双页码居左空一字 | footers[] 有 has_page_field=true 且 size_half_pt=28 且 text 呈一字线包数字即符合；「版心下边缘之下」「单/双页码空一字」脚本取不到 → 注「不适用」不误报；footers 为空或无 PAGE 字段 = 无页码，建议补页码 |
| 红头字色（字色层） | 发文机关标志为红色大字（红色系 FF0000/C00000 等），字体建议小标宋 | colors[] 有红色系 val 且 max_size_half_pt 明显大于正文（≥44），sample 与首行机关名对得上即认为有；colors 为空 = 不适用（红头或为图片/艺术字，脚本看不到，宁缺勿误） |

换算备查：1mm≈56.6929 twips；字号半磅值 44=22pt(二号)、36=18pt(小二/三号误用常见)、32=16pt(三号)、28=14pt(四号)。

## 判定纪律

- **容差内即符合**：边距 ±2mm 内不报；多数票口径下少数段落偏差不报。
- **不适用 ≠ 缺失**：无公文标题/无层级标题/正文不足时，该项注「不适用」，
  不计入不合格。
- **实测值进建议**：每条不合格写明实测值与规范值，让用户能直接改。
- **宁缺勿误**：字体名变体多（仿宋_GB2312/仿宋/FangSong），匹配不上就不硬判，
  把疑点写给用户。
