## 两处收尾

### ①上下文清单面板（v4.434 可见性欠账 + 档位生效面）
- `NovelContextInventory` 自 v4.434 首发以来**零前端消费**——「同样信息量下
  prompt 更短」一直不可量化不可看。本刀补 `ContextInventoryPanel`（rail 质检组
  「上下文清单」）：区段/字数/说明/预览四列表 + 合计尾注，按当前激活章 dry-run。
- Go 侧清单**恒列「成人向工艺区段」行**：档位注入发生在模板槽（BuildUserPrompt），
  v4.434 清单只列编译区段——作者设了档位无处确认生效。explicit/sensual 带正文
  预览与档位名；未启用空正文+设置入口引导（如实回显而非隐藏）。

### ②建档同址选档位（刀1 留池「建档时选档位」关账）
- `CreateNovelModal` 加「本书定位」三态 Radio（与创作页 Select 同口径同值）——
  题材/文风在建档时选，定位同址才可发现；创作页入口保留（改档仍走
  UpdateProjectMeta）。
- HomePage 建档成功后 `UpdateProjectMeta(title, genre, style, mature)` 落盘；
  **失败只降级为空档位不阻断创建**（默认空即合法态，warning 如实带出）；
  默认空档位零额外调用（存量流零变化）。
- 导入流（ImportNovelModal）暂不加——拆书导入的档位需求待真机反馈（留池）。
