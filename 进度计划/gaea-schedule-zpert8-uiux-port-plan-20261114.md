## 1. 当前基线与边界

已落地：

- S1 检查器 18 条规则；
- S2 检视、拉直、前锋线；
- S3 点-箭持久化；
- S4 视图/图面承载位；
- S5 要求完成与预警状态机。

当前主要缺口：

1. “视图”仍只是 `project.views` 的数据承载位，横道界面没有消费；
2. 列定义仍是单一静态注册表，宽度已对齐斑马真实 ViewDB，但没有 9 个内置视图；
3. 分组只支持关键、模式、里程碑 3 维，斑马工作视图定义了 14 维；
4. 横道仍是单工具栏，未形成“视图 / 编辑 / 格式 / 大纲 / 插入 / 高级”的命令层；
5. 表格与网络图是切页，不是同屏双栏；
6. 缺少右舷预警/检查泊靠面、双标尺、统一就地编辑弹层和五图模式矩阵。

本计划**不重写** CPM、AOA、数据保存和既有分析视图；全部采用增量接线。

## 2. 目标体验

打开进度板块时，用户看到的不是“功能按钮集合”，而是：

```text
视图档案（计划编制 / 进度管控 / 期间 / 资源 / …）
  ├─ 列：按视图显示、真实列宽、可响应式收纳
  ├─ 行：14 种分组维度、折叠/汇总、筛排序
  ├─ 图：表格与横道/网络同屏或切换
  └─ 右舷：预警、检查、里程碑可直接定位
```

四个体验原则：

1. **视图优先**：先选工作目的，再决定列、分组、筛选和图样式；
2. **密度优先**：默认表格只露出当前视图需要的列，把空间让给图；
3. **就地处理**：检查结果一行一条，可从右舷直接跳到任务；
4. **令牌适配**：同一结构在亮色、暗色和窄窗口中可用，不硬编码斑马色值。

### W1 · 视图、列、分组（本轮）

交付内容：

1. 建立 9 个内置横道视图：
   计划编制、进度管控、期间计划、期间进度报告、资源、工程量计划、
   进度对比分析、计划变动分析、里程碑列表；
2. 每个视图保存列集合、排序、分组、筛选和图类型；
3. 计划编制默认列按斑马真实宽度：索引 40、工作名称 200、工期 100、
   前置 90、计划开始/完成各 110；gaea 用 WBS 列承接“分区”语义；
4. 分组扩展为 14 维：
   工期、总时差、负责人、里程碑、关键工作、工作分类、工作名称、
   工作部位、执行状态、资源名称、前置数、后置数、自定义、排程模式；
5. 负责人/工作部位/自定义分别落到既有 `text2/text1/text3` 自定义槽，
   不新增破坏性数据字段；项目自定义列名优先用于组头；
6. 旧 `chatPrefs` 读取时保留原列显隐，不强制迁移；新建/复位使用计划编制视图；
7. 手动改列、分组或排序后自动进入“自定义”状态，避免假装仍等于内置视图。

实施结果（2026-11-14）：

- 9 个视图与 ViewDB 真实列宽已接入；
- 默认表头改为 `分区 / 标记 / 工作名称 / 工期(工日) / 前置工作 /
  计划开始 / 计划完成`；
- 分区用 WBS 根编号转罗马序号，星标/菱形分别承接分组与里程碑；
- 14 种分组已接线，资源/关系/自定义槽均有纯函数覆盖；
- 宽视图固定 730px 表格核并允许横向滚动，为右侧检查面和时间画布留空间。

验收：

- 纯函数测试覆盖 9 个预设、列宽、显隐、14 种分组、资源/链接派生；
- GanttView 验证默认计划编制列、视图切换、旧偏好迁移；
- `tsc -b`、目标 ESLint、schedule 回归全绿；
- 亮/暗主题下表格列不挤压、画布不被过宽表格挤没。

### W2 · 命令工作台

- 把“文件 / 计划 / 资源 / 管控 / 视图”收成命令注册表；
- 每条命令具备稳定 `id`、分组、标签、快捷键、禁用原因、执行动作；
- 视图切换、列设置、分组、筛选、打印都从命令表生成；
- 先实现命令搜索与快捷键提示，不做用户自定义功能区。

验收：新增命令不再散落在 `SchedulePage`/`GanttToolbar` 条件分支中；
同一条命令可从菜单、工具栏和快捷键调用，并使用同一禁用理由。

### W3 · 双栏与右舷

- 表格与网络图同屏，表格显隐、分隔比例可调；
- 右舷提供“预警信息”与“检查发现”，每条含严重度、任务名、原因、动作；
- 点击条目定位任务、展开折叠祖先、必要时切换图模式；
- 无异常时显示空态，不保留假数据装饰。

验收：布局在 1440/1100/880 三档不横向溢出；右舷可键盘关闭和重开；
表格/图纵向行对齐，前锋线跨双栏时 y 坐标同源。

### W4 · 图面专业密度

- 双标尺：工程标尺（年月日）+ 进度标尺（周）；
- 图上显示四开关：节点时间、工期、六参数、起止时间；
- 五图模式矩阵逐步接线，先做时标逻辑图、逻辑网络图、横道网络图；
- 命中区顺序固定：列头 → 画布 → 单元格 → 状态栏 → 分隔条 → 行头；
- 行反查用行高前缀和 + 二分，不照搬斑马的 O(n) 累加。

### W5 · 交互一致性

- 统一日期、日期区间、数值、文本四类就地编辑弹层；
- 文本/数值/日期/枚举/异常标记五类列过滤器；
- 右键菜单按命中类型追加，不写死整份 QMenu 顺序；
- 格式刷、树形拖动、升降级先只做横道表格内，不扩到分析视图。

### W6 · 输出与外观

- 打印先做“按纸张布图”和预览，不追完整 28 项；
- 图例/图签使用 SVG 组件和主题令牌，不搬斑马位图；
- 增加护眼与黑白两个显示预设，复用 gaea 主题令牌；
- 主题验收覆盖浅色、暗色及至少两套色相。

## 4. 数据契约

视图统一使用既有 `SchedView`：

```ts
{
  id, name, kind,
  cols?, hide?, groupBy?, filter?, sort?, renderMode?
}
```

规则：

- `kind` 是页面级视图；横道内置预设当前都落 `gantt`；
- `hide` 是当前 UI 的直接写入口，`cols` 保留给未来列序快照；
- `groupBy` 顺序即层级顺序；
- `filter`/`sort` 必须可序列化，计算逻辑不进入视图快照；
- 内置预设不写入项目文件；用户“另存视图”才进入 `project.views`；
- 本地偏好只记住“当前选中的视图 id 与已被用户覆盖的显隐状态”。

## 6. 风险与回退

| 风险 | 处置 |
|---|---|
| 默认视图变窄导致旧用户找不到列 | 列菜单常驻；旧 `ganttHide` 保留；“计划编制”只收起分析列 |
| 真实列宽变大挤压画布 | 默认表格宽度取当前视图列宽和，不取全列宽；分隔条可拖 |
| 分组依赖资源/链接造成性能下降 | 一次构建 task id→资源名/前置数/后置数索引；行序列纯函数 |
| 自定义槽语义被固定成负责人/部位 | UI 显示项目自定义列名；未命名时用中性括号说明 |
| 视图切换污染编辑历史 | 视图状态仍属本机偏好，不进项目 undo 历史 |

## 7. 本轮 Definition of Done
