## 1. 当前基线与边界

已落地：

- S1 检查器 18 条规则；
- S2 检视、拉直、前锋线；
- S3 点-箭持久化；
- S4 视图/图面承载位；
- S5 要求完成与预警状态机。

当前主要缺口：

1. “视图”仍只是 `project.views` 的数据承载位，横道界面没有消费；
2. 列定义仍是单一静态注册表，宽度已对齐斑马真实 ViewDB，但没有 9 个内置视图；
3. 分组只支持关键、模式、里程碑 3 维，斑马工作视图定义了 14 维；
4. 横道仍是单工具栏，未形成“视图 / 编辑 / 格式 / 大纲 / 插入 / 高级”的命令层；
5. 表格与网络图是切页，不是同屏双栏；
6. 缺少右舷预警/检查泊靠面、双标尺、统一就地编辑弹层和五图模式矩阵。

本计划**不重写** CPM、AOA、数据保存和既有分析视图；全部采用增量接线。

## 2. 目标体验

打开进度板块时，用户看到的不是“功能按钮集合”，而是：

```text
视图档案（计划编制 / 进度管控 / 期间 / 资源 / …）
  ├─ 列：按视图显示、真实列宽、可响应式收纳
  ├─ 行：14 种分组维度、折叠/汇总、筛排序
  ├─ 图：表格与横道/网络同屏或切换
  └─ 右舷：预警、检查、里程碑可直接定位
```

四个体验原则：

1. **视图优先**：先选工作目的，再决定列、分组、筛选和图样式；
2. **密度优先**：默认表格只露出当前视图需要的列，把空间让给图；
3. **就地处理**：检查结果一行一条，可从右舷直接跳到任务；
4. **令牌适配**：同一结构在亮色、暗色和窄窗口中可用，不硬编码斑马色值。

### W1 · 视图、列、分组（本轮）

交付内容：

1. 建立 9 个内置横道视图：
   计划编制、进度管控、期间计划、期间进度报告、资源、工程量计划、
   进度对比分析、计划变动分析、里程碑列表；
2. 每个视图保存列集合、排序、分组、筛选和图类型；
3. 计划编制默认列按斑马真实宽度：索引 40、工作名称 200、工期 100、
   前置 90、计划开始/完成各 110；gaea 用 WBS 列承接“分区”语义；
4. 分组扩展为 14 维：
   工期、总时差、负责人、里程碑、关键工作、工作分类、工作名称、
   工作部位、执行状态、资源名称、前置数、后置数、自定义、排程模式；
5. 负责人/工作部位/自定义分别落到既有 `text2/text1/text3` 自定义槽，
   不新增破坏性数据字段；项目自定义列名优先用于组头；
6. 旧 `chatPrefs` 读取时保留原列显隐，不强制迁移；新建/复位使用计划编制视图；
7. 手动改列、分组或排序后自动进入“自定义”状态，避免假装仍等于内置视图。

实施结果（2026-11-14）：

- 9 个视图与 ViewDB 真实列宽已接入；
- 默认表头改为 `分区 / 标记 / 工作名称 / 工期(工日) / 前置工作 /
  计划开始 / 计划完成`；
- 分区用 WBS 根编号转罗马序号，星标/菱形分别承接分组与里程碑；
- 14 种分组已接线，资源/关系/自定义槽均有纯函数覆盖；
- 宽视图固定 730px 表格核并允许横向滚动，为右侧检查面和时间画布留空间。

验收：

- 纯函数测试覆盖 9 个预设、列宽、显隐、14 种分组、资源/链接派生；

### W4 · 图面专业密度

- 双标尺：工程标尺（年月日）+ 进度标尺（周）；
- 图上显示四开关：节点时间、工期、六参数、起止时间；
- 五图模式矩阵逐步接线，先做时标逻辑图、逻辑网络图、横道网络图；
- 命中区顺序固定：列头 → 画布 → 单元格 → 状态栏 → 分隔条 → 行头；
- 行反查用行高前缀和 + 二分，不照搬斑马的 O(n) 累加。

实施结果（2026-11-14 第二刀）：

- **双标尺**：新增纯模块 `timescale.ts`（六档 fov / 单位间隔集 / 自动联动
  0.04..0.4 且 ×0.5 收尾 / 像素唯一出口 `pos[i]=Σ step×scale×2.4`），
  `GanttTimeline` 重写为「上行工程标尺（年-月跨列段 + 日/周刻度线）+ 下行进度
  标尺（周/星期）」两行常驻，总高 `GANTT_RULER_H=40` 只定义一次（画布表头、
  表格表头、`--sched-ruler-h`、覆盖层顶部同源）；窄窗（`dayW<8`）降级只画月段
  与周号；今日/竣工竖线跨两行穿透。
- **刻度线疏密**：读 `networkStyle.tickLines`（不画/小刻度/大刻度），图面样式
  面板直改；样式走新建 `gantt/ruler.css`，零硬编码色值。
- **图上四开关**：`networkDisplay.ts` 唯一解析入口（缺省=节点时间/工期开、
  六参数/起止时间关，即旧观感）。AOA 消费：节点内 ES/LS、箭线工期标签、
  节点旁六参数块、实工作箭线「计划开始→完成」；PDM 消费：六格 ES/EF、
  工期与搭接标签、框下六参数与起止。零回归锚点用例：四开关全缺省 vs 不落
  `networkStyle`，`sched-aoa` innerHTML 逐字相等。
- **图面几何**：dotStyle（圆/矩形）、nodeRadius、arrowStyle（实心/空心）、
  headHeight、lineWidth 已消费；半径贯通 `aoaLayout.edgeSegs /
  assignChannels / summarySegs` 与 `networkExport`（箭线端点不再插进节点或
  悬空，导出与视图同口径）。`namePos` 已解析、渲染待下刀。
- **五图模式矩阵**：时标逻辑图（保留时间轴与关键色、压掉工期装饰）、横道网络
  图（同一横道几何上加重关系线并在折线中点标「FS+2」类标签）已接线；
  单代号/双代号/逻辑网络图沿用原实现。
- **未做**：命中区顺序（gaea 各区是独立 DOM 节点，天然分层；统一命中分发器
  应与右键菜单同刀）、PDM 半径（改 NODE_W/H 会破现有分层布局）、行反查二分
  （当前行高定值，无 O(n) 问题）。

第三刀（2026-11-14，W4/W5 余项 + 图面参数补齐）：

- **命中区优先级**：新增 `hitRegion.ts`（六区顺序 列头→画布→单元格→状态栏→
  分隔条→行头、`pickHitRegion` 取最高、`hitRegionChain` 自限深度上溯
  `data-hit`，不读 DOM 文本）。GanttView 由「每行各自右键」收成**单一

  捕获阶段拦下子模块 Dropdown；行容器声明 `row-header` 当兜底、单元格声明
  `cell` 自然覆盖——这是优先级表能同时满足列头/单元格/行头的关键取舍。
- **统一右键菜单**：新增 `hitMenu.ts`，12 项结构操作固定序 + 画布/列头/分隔条/
  状态栏四套区域菜单；可用性复用 `commandRegistry.scheduleCommandDisabledReason`，
  没有后端能力的项（解组/格式刷/文字颜色/插列/列设置/列宽自适应/分区/图面样式）
  **如实禁用并写明原因**，不做假动作。既有两条右键用例零改动通过。
- **图面参数补齐**：新增 `networkLayout.ts` 作为 `namePos / hideUnimportantLink /
  stagger / layerHeight1-2 / density` 的唯一解析与变换入口；AOA 消费名称排布
  （auto/horizontal/vertical）、隐藏非关键非虚关系线（图例给真实计数）、错层
  （仅自动布局）、层高约束、密度系数（列距/行距同源，时标线性不破）；PDM 消费
  名称排布与隐藏非重要搭接。三条「缺省零回归」锚点：节点坐标数组逐字相等。
  图面样式面板补上密度/层高/错层/隐藏非重要线四个控件（此前是「能写不生效」）。
- **列筛持久化**：新增 `colFilterPrefs.ts`（归一 + 稳定签名 + 原型链键防护）与
  `chatPrefs.ganttColFilters`（键名/版本不变，旧偏好零迁移）；GanttView 初值只读
  一次、变更按签名去抖单点落盘、首帧不写盘不覆盖偏好；视图切换不动列筛（列筛与
  列集正交）。诚实收窄：只持久化 `COL_FILTER_KIND` 已登记列，自定义字段列的
  条件会话内生效、重启丢失。
- **常量单源**：`ganttUtil` 的 `WEEK_TIER_BELOW / WEEKDAY_LABELS` 改为从
  `timescale.ts` re-export，消除第二份漂移源。
- **门禁**：schedule + 页面回归 **76 文件 / 991 例** 全绿；`tsc --noEmit` 0、
  改动面 ESLint 0；`npm run build`（tsc -b + Vite）**42.71s 通过**。
  未提交、未构建 Wails、未装机。
- **仍未做**：PDM 节点半径（会破 NODE_W/H 分层）；状态栏区 `data-hit`（在
  SchedulePage 外壳，随外壳刀接）；异常标记/进度滞后两类列过滤器（需先有列）。

### W5 · 交互一致性

- 统一日期、日期区间、数值、文本四类就地编辑弹层；
- 文本/数值/日期/枚举/异常标记五类列过滤器；
- 右键菜单按命中类型追加，不写死整份 QMenu 顺序；
- 格式刷、树形拖动、升降级先只做横道表格内，不扩到分析视图。

首版实施结果（2026-11-14）：

- **就地编辑族**：`inplaceEdit.ts` 纯语义层（日期严格合法日、区间开闭与顺序、
  数值 step 对齐 + min/max 夹取、文本 trim/maxLen、空=清空与显式
  `emptyAs:'zero'`）；`InplaceEditField` 按逆向 §15.2 六步手感（padding 0、
  继承字体、左对齐垂直居中、打开全选、Enter 提交 / Esc 取消 / blur 提交）。
- **表格接线**：双击 名称/工期/进度/计划开始/计划完成/自定义字段 → 同一弹层，
  提交走既有 `onUpdateTask`；**旧单击直编路径保留**（老用户与既有测试零回归）。
  计划开始在自动行上双击会锁成手动（ZPert「改开始=锁定」口径）。
- **列级筛选**：`GanttFilter` 增可选 `colFilters`（文本包含 / 数值比较 /
  日期区间 / 枚举集合 / 空值），三参调用逐字不变；表头每列「▼」按
  `COL_FILTER_KIND` 出对应编辑器，激活态高亮；GanttView 接第 4 参
  （startDate/calendar）——日期列筛不再 fail-open。功能区「编辑 → 列筛选」
  提供说明与「清除全部」（`column-filter-clear` 信号）。
- **验证**：新增 `inplaceEdit` 25 例、`GanttTable` 7 例、`InplaceEditField` 9 例、
  列筛 11 例、横道网络图/列筛接线 3 例；schedule + 页面回归 **71 文件 / 901 例
  全绿**，前端全量 **522 文件 / 4694 例** 通过，`tsc --noEmit` 0、ESLint 0、
  `npm run build`（tsc -b + Vite）41.21s 通过。

- **按纸张布图**：`pageLayout.ts`（A4/A3/A2 × 横竖、mm→px@dpi、页边距、等比适配

  六个 `--sched-*` 领域色，不碰主题令牌；每档分「屏上深底 / 纸面白底」两套值，

### 右键真动作补批（2026-11-14，第六刀）

### 树形拖动（2026-11-14，第七刀）

- **纯计划器 `moveRow.ts`**：两级大纲下的三种落点 `before / after / inside`；拖分区时
  整棵子树一起搬（紧邻连续 `level 1` 行）；「之后」按目标子树末尾算，不会把目标分区分家。
- **拒绝规则**（给原因、不落库）：拖到自己身上、拖进自己的子树、分区塞进分区、工作塞进
  工作、跨级同级移动、`inside` 目标不是分区。
- **表格接线**：行容器 `draggable` + `dragover` 三区判定（上 25%/中段/下 25%），落点提示
  `.sched-drop-before/after/inside`（insert 线 / 淡色整行），drop 后落 `store.moveRow`
  一次历史可撤销；画布窗格不传拖放属性，手势零变化。
- **测试**：纯函数 9 例（含子树落点与纯性）+ 集成 2 例（before 改序、inside 变子工作）。

## 4. 数据契约

视图统一使用既有 `SchedView`：

```ts
{
  id, name, kind,
  cols?, hide?, groupBy?, filter?, sort?, renderMode?
}
```

规则：

- `kind` 是页面级视图；横道内置预设当前都落 `gantt`；
- `hide` 是当前 UI 的直接写入口，`cols` 保留给未来列序快照；
- `groupBy` 顺序即层级顺序；
- `filter`/`sort` 必须可序列化，计算逻辑不进入视图快照；
- 内置预设不写入项目文件；用户“另存视图”才进入 `project.views`；
- 本地偏好只记住“当前选中的视图 id 与已被用户覆盖的显隐状态”。
