做法

两张不含 Logo 与文字的底片由 gaea 自己的生图产出：星际日出、人间山谷。底片负责「像不像电影」，实时动效层负责「活不活」：镜头推进并带上下视差（远处的天动得慢，近处的地面动得快），1.6 秒起朝日出俯冲、穿过一片暖白落到山谷。之后日出辉光呼吸，星点在暗天区闪烁，湖面用水平涟漪扰动倒影并泛粼光，城市灯火闪烁，光柱脉动，巨行星前飘过薄云，远岸有雾。

新 Logo 是生图模型在纯洋红底上画的玻璃 G，键掉底色后成为透明标，可以独立点火、光扫、被轨道彗星前后环绕。

现状最弱的一环

Logo、字标、进度条都烤在位图里，整段只有一次 1050ms 的整幅交叉淡变——画面里没有任何东西能单独动。

相对现状的变化

  • 两张静帧淡变 → 连续运镜一镜到底，画面里的光、水、灯火、星都在动。
  • Logo 是独立图层：可点火、光扫、被彗星环绕；换标不用重新出图。
  • 字标、标语、进度是真 DOM 文字：任意分辨率清晰，可走现有三语文案。
  • 资产体积：两张原画 PNG 合计 3,296,174 字节（约 3.3 MB）→ 两张底片 WebP 合计约 232 KB，加标与语音共约 387 KB。
  • 原画里的 G 与应用图标不是一个字形；新标是生图出的玻璃 G，共两个候选，页面上可切换。

保留

  • 语音仪式：两句语音 0.00s / 1.596s 起，4.00s 结束并收束；换景点仍是 1.596s。
  • ESC 跳过、左下声音开关（PLAY / AUDIO / MUTED）、退出时长 0.52s。
  • 进度节奏 68% → 72% → 100%。
  • 原画文案：GAEA、YOUR INTELLIGENT WORK ASSISTANT、EMPOWER YOUR INTELLIGENCE、SMARTER · FASTER · TOGETHER；状态文案「正在启动 · 连接智能世界…」。
  • 构图与叙事：上 Logo、中字标、下进度；星际 → 人间。

可调参数

  • 页面控件：曝光、运镜幅度、氛围层（星点、涟漪、灯火、飘雾的强度）、Logo 候选。
  • CSS 变量：--accent --gold --type --space --radius --motion。
  • 本文件单文件自包含，约 567 KB。

代价与边界

  • 底片是 1280×720：大窗口和高 DPI 屏上会偏软，落地前建议出 2K 底片或做一次超分。
  • 新 Logo 和应用现有图标不是同一个字形。要不要把它升为全局品牌标，由你定。
  • 底片是单帧：没有真 3D 视差，上下视差是近似；巨行星、城市不会自己转动。
  • 着色器每帧开销没有在目标机上实测，我只做了无头浏览器逐帧截图核对。
  • 进度百分比是按时间演示的，落地时要接真实启动事件（现有实现同样是固定 68 / 72）。
  • 需要 WebGL2；拿不到时降级为一张静态海报帧。
  • index.html 的静态首屏现在直接贴原画。改造后要换成轻量静态层（深空底色 + 标），否则 JS 接管前会先闪一下旧原画。
  • 底片与 Logo 由生图模型产出：同一提示词再跑一次得不到同样的图，这张效果图里的资产就是最终要用的那两张。
