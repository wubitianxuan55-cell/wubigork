## P1A: LLM 驱动记忆模块（3 新文件）

### `memory_fact_extract.go` — 事实抽取
对齐 ackem `factExtractor.ts` + `prompt/memory-fact-extract.ts`：
- `FactExtractor` 结构体：`Extract(userMsg, companionMsg, turnIndex, sessionID, llm)` → `FactExtractionResult`
- 完整的 25 子类定义 prompt（IDENTITY/SOCIAL/DAILY_LIFE/PURSUITS/INNER_WORLD/TEMPORAL）
- weight 规则（0-3）+ confidence 归一化（0-1）+ 拒绝抽取清单
- `parseExtractionSalvage()`：双层 JSON 抢救解析

### `memory_consolidator.go` — 记忆整合
对齐 ackem `consolidator.ts`（对标 MemGPT core memory reflection）：
- `MemoryConsolidator.Consolidate()`：取 raw 层事实 → LLM 寻找跨事实模式 → 生成 consolidated 洞察
- 参数：最多输入 30 条、最少 8 条触发、最多 5 条洞察、权重 2.5
- `subcategoryToDomain()`：25 子类→5 领域映射
- 整合 prompt：模式发现 + 关联关系（temporal/entity/event_chain/emotion_peak/self_reference/thematic）

### `memory_contradiction.go` — 矛盾检测
对齐 ackem `contradictionDetector.ts` + `prompt/memory-contradiction.ts`：
- `ContradictionDetector.Check()`：单对检测（新旧事实 → LLM 判断）
- `ContradictionDetector.CheckBatch()`：批量检测（3-5 对一次 LLM 调用）
- 5 种关系：strong_conflict / weak_conflict / complement / reinforce / unrelated
- 4 种 action：keep_new / keep_old / merge / flag
- 时间衰减逻辑：旧事实 >30 天信任新事实，<7 天信任旧事实

## P1B: 分发系统填实（2 文件）

### `dispatch_router.go` — 重写
从 81 行骨架扩展为完整的 210+ 行分发路由：
- 复杂任务检测 → plan 模式（15 种中文指示词）
- 内置候选匹配（天气/提醒/搜索/笔记/计算）
- LLM 精判：候选列表 → LLM → matched/confidence → 阈值决策
- 人设乘数：deredere=1.15, tsundere=0.90, kuudere=1.25, genki=0.85
- 阈值：≥0.85 auto_invoke, ≥0.60 ask_invoke, 否则 silent

### `candidate_collector.go` — 新增
对齐 ackem `candidateCollector.ts`：
- `collectDispatchCandidates()`：关键词精确包含匹配
- `collectSemanticDispatchCandidates()`：token/bigram 语义评分（中文分词 + 重叠率）
- `mergeDispatchCandidates()`：去重合并（上限 5 候选）
- `tokenize()`：中文标点分割 + bigram 双通道
- `scoreCandidateEntry()`：name/summary/keywords/scenarios/habits 综合评分
