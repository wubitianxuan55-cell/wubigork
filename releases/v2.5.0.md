# gaea v2.5.0「全界面科幻视觉重设计 · 绘梦多模态 · 角色库模型绑定」发布说明（2026-08-08）

> 本版本把设置、首页、聊天欢迎屏、小说、绘梦五大板块统一为「玻璃 HUD + 单一强调色」
> 设计语言，并补齐绘梦的图生图/文生视频、模型中心绑定同步与角色库独立绑定。

## 一、全界面视觉重设计

- **设置面板**：左侧竖排导航改为顶部平铺分类磁贴（吸顶、可切换），修复 flex 宽度收缩 bug
- **首页**：语音交互中枢升级为视觉主角——HUD 角标框、雷达脉冲环、声谱均衡条、遥测读数、聆听/回复扫描光带
- **聊天欢迎屏**：普通模式 VoiceChatOrb / 角色模式 CompanionAvatar 双科幻欢迎屏，建议卡补齐键盘可达
- **小说板块**：顶部二级导航平铺，统一玻璃面板/节点树/纸面化编辑面，设定页改左右双栏
- **绘梦**：三模式导航 + 科幻上传区，视频结果支持播放与历史胶片

## 二、绘梦多模态（后端 + 前端）

- **图生图**：ComfyUI LoadImage + VAEEncode + 低 denoise 重绘工作流，参考图上传/拖拽 + 重绘幅度滑块
- **文生视频**：LTX-Video 标准工作流（LTXVLoader → LTXVConditioning → LTXVSampler → SaveAnimatedWEBP），
  分辨率/时长帧率预设，帧数自动归一化为 8 的倍数
- 输出解析扩展到 images/gifs/videos，视频按正确 MIME 返回；新增 `GenerateMedia` Wails 绑定

## 三、模型中心与角色库绑定

- 功能绑定面板实时同步（监听 `feature-model-changed` 事件），其他页面改绑定即时刷新
- 聊天合并轻语、办公合并方案（office+gaea 双写），删除重复行
- 新增角色库 LLM 绑定（`func_characterlib_*`），角色生成/补全走独立绑定
- 角色库剧照独立后端/模型（`portrait_backend` / `portrait_model`，空=跟随绘梦），
  模型中心新增「角色库剧照」设置卡；删除小说卡剧照标签

## 四、视觉识别管线

- vision 技能默认模型切换为 Qwen3.6-35B-A3B-Uncensored-HauhauCS-Aggressive-Q4_K_P-2
- 修复 PowerShell 5.1 编码：脚本转 UTF-8 BOM + 改用 .NET HttpClient（请求/响应中文均正常）
