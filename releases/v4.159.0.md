# v4.159.0 · 进度计划画布手感：滚轮缩放 + 双代号行距自适应（2026-09-08）

> 用户实测反馈（附截图）：进度计划板块画布无法用鼠标滚轮放大缩小，查看不方便；双代号网络图生成效果差——「行距太小，全部挤在一起，整体又矮又长，严重不协调」。两根因都定位到代码：前者=三块画布（横道/单代号/双代号）只有按钮缩放、无任何 wheel 处理；后者=AOA_ROW_H 写死 74px（节点含上下时间标注占 ~56px，行间只剩 18px 空隙）且行距不随时标宽度自适应（时标图宽度被工期锁定，低并行度长计划天然 20:1 扁长条，再被自动适配压到 0.5 下限雪上加霜）。零绑定 599。

## ① 三块画布滚轮缩放

- **新共用钩子 `schedule/wheelZoom.ts`（useWheelZoom）**：普通滚轮=以光标为锚缩放（deltaY<0 放大 ×1.2，clamp [0.1,2]）；Shift+滚轮=放行原生横向滚动。锚定原理：记下「光标下的图面坐标」，缩放提交后的 useLayoutEffect 回写 scrollLeft/Top——直接同步回写会被旧内容尺寸钳制（setState 尚未重渲染）。监听器原生挂载 `{passive:false}`（React 合成 onWheel 是 passive，preventDefault 无效）。applyZoom 走 ref 中转（视图每渲染重建回调，免监听器反复拆挂）。
- **双代号 AoaView / 单代号 PdmView**：接入 useWheelZoom；图例栏加操作提示「滚轮缩放 · Shift+滚轮横移」；图例 `flex-wrap: wrap`（截图里模式/缩放按钮被右缘裁剪）。PdmView 三处缩放入口（自动适配/适配全图/步进）统一走 applyZoom 保持 zoomRef 镜像；并补 `clientWidth<=0` 自动适配防护——对齐 v4.143「jsdom 0 宽不误适配」既有纪律（0 宽使 min() 取负值把 zoom 压到 0.2 下限）。
- **横道 GanttView**：Ctrl/Cmd+滚轮缩日宽（×1.35，MS Project 口径；普通滚轮保持滚动行——表格行滚动手感不能破坏）。光标下日期锚定：dayG=(scrollLeft+px)/旧日宽，缩放提交后 layout effect 回写 scrollLeft=dayG×新日宽−px。dayWRef 镜像现值供监听器直读；zoomStep/fitToWindow/滚轮三入口统一 setDayWAt（floor 保留全览「宁窄勿溢出」语义）。缩放按钮 title 注明「画布上 Ctrl+滚轮同效」。
