## 论点（诊断，全部带代码证据）

写一章时模型的"意图输入"只有一句 `plot_req`（模板五槽位，`create_chapter_handler.go:85-91`）；
承载意图的 `ChapterPlan` 自 v4.278 落库后**零消费**；`StoryThread` 字段全仓**只有读取没有
写入**——大纲规划实际以**空主线**为输入，主题每次临时编；生成单位是整章 blob（v4 场景是
事后物化单场景）；分析九维里只有伏笔/角色状态/记忆三条回流；写前契约只查大纲空字段且明写
「不阻断」；质量门全是写后报告。

**结论：长篇写不好不是句子问题，而是结构、意图、状态三者没有闭环。**

## 落地

- **故事主线写入路径修复**：`outline.Continue/ExpandNode` 回收 `story_thread`（非空才覆盖，
  空/缺字段不擦除已有主线）；提示词输出契约补漏（`outline-continue`/`outline-expand` 必须
  回传主线）——否则"回收"只是等模型自愿多输出。
- **`chapters/plans.json` 契约与落盘**：复用 `types.ChapterPlan` 七字段，原子写；缺失=空正常态；
  损坏=报错且**不覆盖**。偏差档落 `analysis/plan-deviation/NNN.json`（同上三态）。
- **计划生产（AI 提案）**：`NovelChapterPlanPropose` = 故事主线 + 本章大纲节点 + 前文窗口 +
  已有章 key_events + 本章 analysis-v2 摘要 → 七字段 JSON；**不落盘、零规则兜底**；生成后本地
  再校验，不过即报错、**不返回半成品**。
- **作者审批落盘**：`NovelChapterPlanSave` 齐备性 + 跨章去重，S1/S2 即拒并点名
  「与第 N 章重复：<事件>」（归一化含全半角/空白/CJK 标点差异）。
- **写前硬闸**：`novelgate.PlanContractIssues`（纯函数）+ `planPrecheck`（唯一判据来源）。
  缺计划 → 拒绝生成且**模型调用 0 次**、不建节点、不落盘。`CreateChapter` 八参签名不变，
  新增 `CreateChapterWithOverride` 第九参显式覆盖（默认关）。
- **生成注入**：模板新增 `chapter_plan`(P0) 与 `outline_points`(P1) 槽位 + must 约束；
  大纲节点 `KeyPoints`/`Emotion` **此前零进入 prompt**；两段纳入既有预算口径。
- **写后偏差**：未达成关键事件（归一化 + 2-gram 覆盖阈值 0.6）/ 结尾类型不符 / 情绪漂移 /
  跨章重复 + 一句话 summary + 下一章计划建议（仅建议，不落盘）。
- **摘要写回护栏**：模型漏输出 `---CHAPTER_SUMMARY---` 时不得清空大纲节点 Summary——否则同章
  下次预检会被 `outline_summary_empty`(S2) 拦下，硬闸把显示问题放大成自锁。
- **前端**：`ChapterPlanCard`（硬闸横幅 + 缺失清单 + 草案进编辑态 + 保守式保存 + 偏差报告，
  带 seq 守卫防迟到响应错位）；CreatePage 生成前过闸，弹窗三选「取消 / 仍然生成（跳过硬闸）/
  立即生成计划草案」，脏保护先于过闸。

## 观察池

- **跨章去重的第二来源**：`PlanContractIssues` 只看 `plans.json`，「已写但没有计划条目」的旧章其
  `ChapterSummary.KeyEvents` 不参与去重（根因：`ChapterSummary` 无章号、批量读接口不暴露章号）。
  不猜章号糊过去；修法=给 `internal/project` 加带章号的批量摘要读接口，随刀2 做。
- 刀2 场景卡与逐场景生成 · 刀3 故事层骨架（主题/弧线/节拍/支线/未解问题） · 刀4 质量收敛闭环 ·
  刀5 风格学习回灌 · 刀6 上下文编译器 · 刀7 评测基线（`baseline.json` + `promptSetHash` + 夹具）。
- 主脑意图 `novel.create_chapter` 维持被硬闸拒绝（这是本刀的产品行为：没有抓手不开写，
  错误消息指路补计划）；后续刀可让 agent 走「先 Propose/Save 再生成」。
