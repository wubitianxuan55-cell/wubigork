## 论点

意图中枢/微信/语音/Ctrl+K 四入口自 v4.5 起已汇同一内核（intent.Parse →
routeIntent 能力执行层）；本刀补「任务」为**持久实体**与**统一收件箱视图**：
四入口的指令除即时执行外可「存为任务」→ 状态机追踪（待处理/进行中/已完成/
已放弃）→ 任务详情跳回来源板块。**收件箱是清单不是调度器**——任务只在被
打开/被操作时读写（零常驻判据：无轮询、无定时器、无后台事件），关闭即停
（昼夜运转拍板）。空间维度必带：work/play 隔离沿 boards/space.ts，收件箱
面板按当前空间严格过滤，跨空间仅显式（本刀不做移动/复制）。

## 落地

### ① 新纯包 `internal/taskinbox`（零 IO 表驱动，先例 skilldistill）

- `Status` 四值状态机：`CanTransition` 只认 pending→doing→done、
  pending|doing→abandoned 四条合法迁移；终态不接受任何迁移，同值恒 false。
- `NormalizeTitle`（TrimSpace→空报错 `ErrEmptyTitle`→120 rune 截断）、
  `ValidSpace`（仅 work|play）、`ValidSource`（ctrlk|palette|voice|weixin|
  inbox 五来源）、`ParseTaskID`（"ti-"+12 小写 hex 残渣防御）。
- `FilterBySpace`（''=全部，GaeaTaskList 变参先例口径）+ `Sort`（状态组序
  pending<doing<done<abandoned → 组内 UpdatedAt 降序 → ID 升序稳定——收件箱
  =行动优先）。
- 测试 9 函数约 104 断言：状态机全矩阵/JSON camelCase 形状逐字钉死/残渣
  防御/排序稳定。

### ② intent 扩展 + 状态文件 + 执行层（B 线）

- `internal/intent` 新动作 **save_task**：`存为任务X / 记个任务X / 帮我添加
  一个任务X / 任务：X / 待办：X` 首尾锚定两式正则，排在提醒分支之后
  （「提醒我存个任务明天开会」归提醒位——让位守卫）；空标题不命中坠回聊天
  （宁漏勿误）。+9 表用例。
- `internal/app/gaea_task_inbox.go`：状态文件 `<DataRoot>/task_inbox.json`
  （`{version:1,tasks:[]}` camelCase，route_suggestions 同款容错读 +
  temp+rename 原子写）。四绑定（OfficeB +4）：
  - `GaeaTaskInboxList(space)`：FilterBySpace+Sort，损坏文件回空表；
  - `GaeaTaskInboxSave(reqJSON)`：id 空=新建（pending、ti-+12hex
    crypto/rand、超 500 条拒绝）；id 非空=只改 title/note——**Source/Action/
    Target/Session/CreatedAt 不可变（来源审计链）**；source 缺省兜底 inbox；
  - `GaeaTaskInboxSetStatus(id,status)`：ParseStatus+CanTransition，同值
    短路成功零落盘；
  - `GaeaTaskInboxDelete(id)`。
- 执行层 `execSaveTask`：语音/微信走 `routeIntentModeForAssistant` →
  space=`gaeaEffectiveSpace()`（归一，空/非法回退 work）、source 按
  assistantID 区分 weixin/voice、reply=「已存入任务收件箱：<title>」（语音
  TTS/微信回推天然可用）；**Ctrl+K/命令面板不走此路径**——dry-run 预览照常
  命中，前端点「存为任务」直接调 Save（带 shell 空间更准，两路来源可区分）。
- 测试 9 函数：状态文件往返（camelCase 形状钉死含禁 created_at 泄漏）/
  容错读/校验矩阵/500 上限/状态机守卫/空间过滤排序（"WORK" 大写不泄漏）/
  voice·weixin 双例/空间回退/dry-run 零落盘。
