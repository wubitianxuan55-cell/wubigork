## 核心改动 — 稳定性加固 + 架构瘦身 + 测试防线

v1.1.0 在 v1.0.0（品牌重塑）之后完成三大类质量工程：

### 一、稳定性修复（产品体检发现，3 批提交）
- **21 处 goroutine 无 recover 防护**（`0b65c87` + `711c576`）：
  桌面应用（Wails）中 goroutine panic 会直接崩溃整个程序。全量扫描确认修复后
  0 处遗漏（含带参数形式）。最严重：`controller.runGuarded` turn 执行 panic 时
  复位 running 状态 + Emit TurnDone error，杜绝前端永久"生成中"
- **SSE 流式发送阻塞泄漏**（`7b95c65`）：`parseStreamEvents` 的 channel 发送无
  select+ctx.Done 保护，ctx 取消后消费者退出时 goroutine + HTTP 连接永久阻塞
  （对话 hang 类问题根因），全部改为安全发送

### 二、架构整理（死代码清理，5 批提交，净删 902 行）
- gaea 模块：删管理命令功能组（-177 行）、Reasonix 模糊编辑移植（-337 行）、
  宪法文件（连带 toml 依赖）
- 其他模块：剧照旧实现、世界观上下文、章节迁移、7 处未使用字段/别名
- 测试死代码 3 处 + 前端死代码 hook + .tmp 废弃备份
- staticcheck U1000 从 84 处降到 25 处（全部为有意保留：whisper 对齐 ackem
  的移植代码 + ComfyUI 活跃迭代相关）

### 三、测试防线建立（5 批提交，+1900 行测试）
| 模块 | 覆盖率 | 会话前 |
|------|--------|--------|
| modelengine | **97.1%** | 0% |
| office/proposal | **35.6%** | 0% |
| ai | **24.0%** | 7% |
| whisper | **16.8%** | 13.1% |

测试暴露并修复 3 处真实产品缺陷：
- `GenerateSection` 漏设 `Status="completed"`（前端无法感知章节生成完成）
- `UpdateSection` 找不到章节静默失败（用户输入静默丢失）
- `RemoveRawFile` 索引越界静默容忍
