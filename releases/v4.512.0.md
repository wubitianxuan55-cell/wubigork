# v4.512.0 · 流式滚动手势化：运行中强拉退役，滚轮上滚=显式暂停跟随（2026-10-21）

> 用户指令「继续」（前端优化迭代续轮）。v4.510 修好的「回到底部」按钮
> 在流式生成时形同虚设——v2.13.5 起 Transcript 在运行中强制拉底，用户
> 根本无法上翻阅读。本轮根修强拉的原始病因，让「跟随 / 暂停 / 回底」
> 组成完整交互闭环。

## 病史与根因

- **v2.13.5（2026-08-12）**：修「卡住没输出假象」加了运行中强拉底部
  （`if (!stick && !running) return`）。假象根因=布局扰动误杀 stick：
  折叠卡收起时浏览器滚动锚定/夹紧（scroll anchoring）产生**程序性
  scroll 事件**，旧 onScroll 在不贴底时无条件 `stick=false`——跟随被
  误关，界面看似冻住。
- **代价**：流式生成期间每次内容更新都把视图拽回底部，用户上翻阅读
  被反复打断；v4.510 修复了回底按钮的可见性，但运行中它点了也没用
  （下一拍又被拉走）。

## 根修：stick 清除权收归滚轮上滚手势唯一

1. **onScroll 只恢复不清除**：贴底（<80px）才 `stick=true`；不贴底的
   scroll 事件不再碰 stick——布局扰动（锚定/夹紧调整）杀不死跟随，
   v2.13.5 的冻住假象无法复发；
2. **新增 onWheel**：`deltaY<0` 且容器真实可滚（内容超一屏）时
   `stick=false`——上滚=用户显式暂停；短会话不足一屏的无效上滚不产生
   暂停态（防贴底视角被无声冻结）；
3. **scrollToBottom 只认 stick**：运行中强拉退役（外层守卫+rAF 内层
   守卫独立拦截，任一在位即保暂停语义）；
4. **按钮态自愈**：内容变化效应在暂停态重算「回到底部」显隐——上翻
   后内容持续增长不触发 scroll 事件，按钮不再依赖滚动事件才出现。

完整闭环：流式生成 → 滚轮上滚暂停（视图停在阅读位置）→ 回底按钮
常驻 → 点击或滚回底部恢复跟随；新提问自动回随（onNewQuestion 原有
stick=true 语义保留）。

## 回归测试（+3，`Transcript.interaction.test.tsx`）

jsdom 伪造滚动几何（scrollHeight/clientHeight 固定 + 可写 scrollTop
观测落底赋值）：

- **上翻暂停不拽回**：wheel 上滚 + 滚到中部 + 流式新 chunk → scrollTop
  停在阅读位置。反向变异验证：摘掉双守卫复现强拉 → 该测试必红；
- **布局扰动杀不死跟随（v2.13.5 回归钉）**：无手势的中部 scroll 事件
  + 流式新 chunk → 自动补拉回底。反向变异验证：恢复旧「不贴底即清除」
  语义 → 冻住假象复发 → 必红；
- **回底点击恢复跟随**：暂停态点「回到底部」→ 落底。

变异过程注记：双守卫各自独立拦截——只摘外层或只摘内层测试仍绿，
两处全摘才红（守卫冗余是特性不是事故）。
