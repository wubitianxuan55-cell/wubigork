## 交付明细

### ① 浏览器续刀（internal/gaea/browser + 工具层，零新增绑定、前端零改动）

- **空闲 TTL 自动关停**：`Options.IdleTTL`（0=禁用保持 MVP 常驻；`Default()`
  默认 10min；`GAEA_BROWSER_IDLE_TTL` 秒数可覆盖，注入式解析可测）——Ensure
  成功路径持 mu 刷新 `lastActive`（一次埋点覆盖全部工具），once 守护 watcher
  goroutine（ticker=TTL/4，defer recover）到期调现成 `teardownLocked()` 自动
  回收进程+清临时 profile；Shutdown 幂等停 watcher；到期后任意 browser_* 调用
  经 Ensure 自动重拉（天然闭环）。
- **多标签页**：Manager 重构 `conn+pageID` → `tabs map[string]*Conn` +
  `activePageID`（懒 dial，每次 Page.enable）；`/json/list` 全量 target 为真源。
  新方法 `ListTabs/NewTab/SwitchTab/CloseTab`——切换/新建置 epoch=0，旧 refs
  诚实失效（guardEpoch 天然兼容）；关 active 自动切剩余 tab，最后一个关闭整体
  回收。
- **新工具 ×3**：`browser_tabs`（只读，`[active] #n title (url)` 清单）、
  `browser_new_tab`（url 必填）、`browser_switch_tab`（tab_id 必填）；`browser_close`
  加可选 `tab_id`（有→只关指定标签，无→保持现语义逐字节不变）。compact 两表
  同步补 3 条目；全部 work 空间、envelope 结构化返回、留痕零特判自动可查。
- 测试：fake devtools 改有状态（/json/list 真源 + /json/new 追加 + /json/close
  移除），+8 测试（TTL 自动回收/零禁用/env 解析/列表/新标签切换/切 tab 后 ref
  失效/关标签切换/关最后一个整体回收）。

### ③ Verifier 产品化（证据链翻成 UI，纯前端、零新增绑定、后端零改动）

- **证据卡「三步展开」**（DeliverablesPanel 就地，不新增板块）：
  - 卡面：无 `baselinePath` → 回滚按钮禁用（title「无基线快照，无法回滚」）；
    有 opsJson → tool 徽标旁「可复核明细」小徽标；整卡点击展开（aria-expanded）。
  - 第 1 层「声明↔实况」diff：opsJson 单格 op（set_value/set_formula/replace）
    为声明列，`app.GaeaPreview(target)` 现取当前工作簿逐格值为实况列，视觉对齐
    XlsxPreview 规划审阅卡（before 删除线 → after，公式 `fx =` 前缀）；比对口径
    同后端（数值容差 1e-9 / 去空白 / 公式去前导=与空白），✓/✗/跳过标注 + 脚注
    「前端近似比对，权威结论以复核为准」；预览不可用降级「仅声明回放」。
  - 第 2 层「操作回放」时间线：序号 + type 徽标 + applyOne 风格中文描述 + 影响

    beforeSummary 文本块。

- **`lib/verifyDiff.ts` 纯函数**（parseOps/buildCellIndex/compareCell/buildVerifyDiff/
