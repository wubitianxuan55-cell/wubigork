## ① 纠错建议生成器（advice.ts scheduleAdvice，确定性零 LLM）

| 类 | 检出 | 建议动作 |
|---|---|---|
| 悬空引用 | 关系指向不存在的任务（删任务未级联） | 删除悬空关系或补回误删任务 |
| 负搭接 | lag<0（DCMA 第 2 点） | 改 0/正 lag；提前开工用 SS+正滞后 |
| 孤立任务 | 双侧皆无关系（不在任何路径上，工期失真） | 挂接实际前后任务 |
| 冗余搭接 | 直达关系被间接路径覆盖 | 删直达（总工期与关键线路不变，注明） |
| 循环依赖 | CPM 拒绝+cycle 点名 | 打断环中最晚加的关系 |

**收口教训**：单侧缺失占比提示首版误报多链工程（每链各有合法首尾）——单侧缺失判定**归 dcmaAudit 第 1 点**（首末豁免+5% 门槛已有准确实现），advice 不另立第二套判定；本文件只出确定性建议（孤立/负搭接/悬空/冗余），与 DCMA 互补。

**出口判据「样例工程可复现」**：7 任务 5 关系样例（含四类问题）四类建议齐出+每条带具体动作；**同一工程两次调用结论逐字一致**（确定性测试）；健康链路零建议。

## ② what-if 推演（whatif.ts whatIfDuration，纯本地）

`whatIfDuration(project, taskId, delta)`：任务工期 ±N 天 → computeCpm 重算 → 与基线对比：

- 总工期 delta（正=推迟）与推演总工期；
- 关键线路变化：新进关键任务 / 脱离关键任务；
- 里程碑拒推（工期恒 0）/ 负 delta 钳 0 / 任务不存在与零工期计划如实 `ok=false`；
- **原计划不被修改**（推演=只读对比快照，零服务零 LLM——出口判据「推演纯本地」）。

推演八例：关键任务延长等量推迟 / 压缩到脱离关键（关键线路重组）/ 非关键任务浮动内总工期不变（浮动的定义）/ 钳 0 / 拒推。
