- **后端 +1 绑定**：`GaeaPptxSlideText(rel)` 走 pptxedit.LocateText（纯 Go 零 python，比读侧更可靠）——每页**段落全文**列表。动机：大纲 texts 是 200 rune 截断预览，直接当替换 target 必匹配失败（apply 单段落精确匹配、宁拒不误改）；段落粒度即 target 粒度，天然对齐。测试锁「rels 逆文件名序=页码序随 sldIdLst」与 300 rune 长段全文不截断。
- **PptxOutline 两级导航**：页条目可展开文本框清单（既有截断预览），点条目/「编辑此页」→ 编辑面板；页锚点滚动/composer 插入/不可用降级全保留（未接线宿主下编辑入口不渲染、退化纯文本，向后兼容）。
- **PptxEditPanel**（P1=xlsx 同款 Plan→Apply）：载入段落全文（失败诚实降级+重试）→ 段落单选（页码+序号）→ 预设四动作（润色/精简/翻译/扩写）+自定义指令（附加约束「短句化、长度相近防文本框溢出」拼进 instruction，GaeaOfficeEditText 复用零改动）→ 双栏对比（docxTextDiff LCS 句级整块着色，诚实标注「句级对比（无字符级高亮）」）→ 应用（后端错误原样透出；成功用返回的新 PreviewResult 刷新预览+静默重拉段落）→ 常驻标注「PPT 格式不支持修订标记，应用即生效，可恢复到应用前版本」。
- **FilePreview** pdf 分支右栏挂面板（DocxQueuePanel 宿主形态先例，与大纲卡同排；换文件自动收起）。

## 刀3 结构化对比（版本时间线第四种 kind）

- **lib/pptxTextDiff.ts**：JSZip 解 `ppt/slides/slideN.xml`（文件名自然序=显示层近似，注释明示后端为 sldIdLst 放映序）→ 层1 页级（整页签名 LCS 页对齐：相等页为锚、锚间余页按位配对 changed）→ 层2 段落级（changed 页直接复用 diffDocxParagraphs，算法零改动）→ 层3 字符级不实现，行结构预留 index 交 ChangesDiff 改蓝配对白得。全程结构化 `{ok:false, reason}` 降级（坏 zip/无 slides 目录），不伪造。
- **versionCompare kind:"pptx"**：照 xlsx 接法注册，字段与 VersionXlsxDiff 严格对齐；**取数通道偏离 docx**——GaeaPreview 对 .pptx 渲染成 PDF 逐页缩略且基线快照是 `.before` 扩展名（Preview 按扩展名分派对它落 unsupported），docx 的 Preview-dataUrl 通道两侧都拿不到原始字节，故改走既有 `GaeaAttachmentDataURL`（字节精确、任意路径可读）。
- **VersionTimeline**：PptxCompareBody（与 Xlsx 同构：页级摘要+每差异页 hunk，红绿行+相邻 del+add 改蓝配对+字符高亮）；DiffStatChip 纳入 pptx；解包失败维持 unsupported 原文案。
