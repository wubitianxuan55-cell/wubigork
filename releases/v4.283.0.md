# v4.283.0 — 书源取书 t2：书架「在线搜书」入口（搜索→候选→目录预览→范围下载→进度→入书架）（2026-09-14）

## 来源

续 v4.282 发布线里的 t1（书源取书→拆书导入后端四绑定，非版本刀随 v4.282.0 exe 入产）。规格 [`docs/gaea-novel-booksource-import-2026-09.md`](../docs/gaea-novel-booksource-import-2026-09.md) §5 的既定下刀：**t2（前端，版本刀）**——把 t1 的四个 `NovelBookSource*` 绑定接成书架上一条用户可用的取书链：搜书 → 候选表（来源/可导入标注）→ 目录预览 → 范围选择 → 后台下载（进度条 + 可取消）→ 完成直接入书架并打开。

## 落地

### ① 入口：书架工具条「在线搜书」

书架工具条在「导入小说」旁新增「在线搜书」（与文件导入并列的另一半取书入口）；不新增板块、不动原罪任何文件（规格 §4 硬隔离声明照旧）。

### ② `BookSearchModal`（自包含流程 Modal）

- **候选表**：`NovelBookSourceSearch` 同表呈现书源聚合命中与泛搜索候选，逐条标注来源与 `kind`（书源/网页搜索）；**`hasRule` 是唯一可导入通道**——规则命中给绿色「可导入」+「选书」按钮；免规则候选标注「免规则 · 正文不可解析」+「仅参考」禁用按钮（引擎边界：正文必填，fail-closed 在 t1 已锁死，UI 不假装能下）。
- **告警不静默**：各书源/搜索引擎的失败进 `warnings` 如实直显（Alert，前 2 条 + 溢出计数）。
- **目录预览**：`NovelBookSourceToc` 总章数 + 首 8 末 4 截断样例（truncated 时注明）；书名预填候选标题。
- **范围下载**：起止章 InputNumber（默认全本，钳制在 [1, total]），实时候节数；题材/文风沿用 `GENRE_OPTIONS`/`STYLE_OPTIONS` 多选。
- **进度与取消**：`NovelBookSourceImport` 起跑拿 `jobId` → 订阅 `novel-import-progress:<jobId>`（events.ts 新增 `BOOK_IMPORT_PROGRESS` 常量 + `bookImportProgressChannel()` 频道助手，`subscribe()` 统一封装）；进度条按引擎每 20 章节流的 `progress` 事件更新（`done/total 章`）；「取消」走 `NovelBookSourceImportCancel`（取消请求本地记账，`context canceled` 类失败事件如实转写为「已取消导入」不冒错）；`error` 终态在面板内直显失败原因（含未取到章数）并保持可重试；`done` 终态若带失败章清单（引擎重试穷尽、不占位），message.warning 提示「N 章下载失败，未入库」。
- **导入期间关闭受锁**（与文件导入 Modal 同款），关闭/卸载必退订事件。

### ③ 报告面收口（v4.279 报告的共享化）

`frontend/src/utils/novelImportReport.ts`：`formatImportSuccess` / `formatImportWarnings` / `SPLIT_STRATEGY_LABELS`（**补 `booksource: '在线书源'` 映射**——t1 导入报告 `SplitStrategy="booksource"`、编码留空的线上形状）。文件导入（HomePage 原内联逻辑）与在线导入共用同一份文案与告警摘要；完成即 `openProject` + 刷新书架 + 报告直显，与文件导入同款。

### ④ dev mock 诚实空态

`gaea/lib/mock/novel.ts` 补四方法：搜索返回空候选 + 「浏览器 mock 模式需要真实网络与规则目录」warning（不编造候选）、目录空态、导入如实抛错、取消返回 false——浏览器 `?mock=` 模式可用但不假装能搜书。

**边界照旧**：不做断点续传/EPUB 导出/反爬对抗（规格 §6）；规则策展数据不出厂（模板 disabled 不被拾取）；本刀零新绑定（绑定面 654、spaceBindings 锁 476 均不动）。
