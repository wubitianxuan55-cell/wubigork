# v4.387.0 — ComfyUI 未运行自动拉起：原罪插图/绘梦生成连接被拒自愈

> 用户报障「原罪生图失败，插图失败：ComfyUI 提交失败…connectex: No connection could be made」。两层根因：**环境层**=ComfyUI 服务没跑，且其 standalone-env 落后于仓库 requirements（comfy-aimdo 0.4.13<0.5.5、comfy-kitchen 0.2.28<0.2.35 等，起都起不来）；**产品层**=gaea 生成链只对「孤儿实例 [Errno 22]」自动恢复，服务压根没跑时直接以 connectex 原始错误失败——原罪插图页没有任何恢复入口（绘梦页才有启动按钮）。Go 1 文件+测试，绑定面 712 零变更。

## 落地

1. **`ensureComfyUIRunning` 助手 + 生成链接线**（`internal/app/image_handler.go`）——
   - 生成失败且错误含「连接 ComfyUI 失败」（dial 连接被拒的既有包裹文案）且 backend=comfyui 时：`ensureComfyUIRunning()`（未运行→`StartComfyUI` 拉起→`/system_stats` 就绪轮询，有界 120s）成功后重试一次（本轮一次，`comfyBooted` 闸）。
   - 就绪判定与 WarmComfyUI/isComfyUIRunning 同口径；未配置安装路径/启动失败/等待超时一律返回 false——**原始错误如实上抛，不吞错不换错**。
   - 并发拉起竞态由 StartComfyUI 既有端口占用守卫兜底：第二个调用方拿到「端口已被占用」后转入就绪等待而非放弃。
   - 原罪插图（sin_illustrate 工具/SinIllustrate）与绘梦页生成共用 `generateImageInternal` 一条链，一处接线双板块受益。
2. **环境修复（用户本机，随本刀处置）**——
   - ComfyUI 仓库更新后 standalone-env 未跟上：`pip install comfy-aimdo==0.5.5 comfy-kitchen==0.2.35 comfyui-embedded-docs==0.5.11 comfyui-frontend-package==1.52.7 comfyui-workflow-templates==0.11.62`（requirements.txt 钉版精确补，刻意不 `pip install -r`——避开 torch 行重解析把 ROCm 特制 torch 换成 PyPI CUDA 版的风险）。
   - 修复后以 gaea 同配方拉起（standalone-env python + `--windows-standalone-build`，日志同 `~/.gaea/logs/comfyui.log`）：~30s 就绪，`/system_stats` 200（ComfyUI 0.36.0）。用户当前会话重试插图即恢复。

## 坑

1. **ComfyUI 仓库更新不自动升级 python 环境**——requirements.txt 钉的 comfy-* 系包会随前端/内核更新前进，standalone-env 里的旧版导致 `ModuleNotFoundError`/`AttributeError`（本轮先爆 aimdo 的 storage 缺失、修完又爆 kitchen 的 int8_attention 缺失——**过期是一族的，逐包补不如按钉版一次补齐**）。症状识别：起不来+import/attribute 错 → 对照 requirements.txt 与 `pip list | grep comfy`。
2. **修复 python 环境别用 `pip install -r requirements.txt`**——torch 无钉版行会让 pip 重解析，ROCm/DirectML 特制 torch 可能被 PyPI 通用版顶掉（GB 级下载+后端失效）；只显式装钉版的 comfy-* 包。
3. **错误文案是重试路由的锚**——「连接 ComfyUI 失败」是 dial 层包裹（image_comfyui.go:128/707），只有服务不可达才出现；服务在但卡死是别的错误形态，不进自动拉起分支（避免误杀正在运行的实例）。新增错误分支时先确认文案唯一锚定目标场景。
4. 测试里成功路径必设 ImageSaveDir 指临时目录——否则走 saveToNovelImages 撞装配态 nil（既有先例同法）。

## 升级说明

- ComfyUI 未运行时发起生图（绘梦/原罪插图/角色立绘走同链的生图部分）会自动拉起并等待就绪（最长 2 分钟）后重试一次；首次冷启动生图会多等一段启动时间，属预期。
- 仍要求设置里配置过 ComfyUI 安装路径（本机默认已写死 `C:\AI\ComfyUI\ComfyUI`）；未配置时行为与旧版一致（如实报连接错误）。
