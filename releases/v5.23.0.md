## 主要改动

### 🔧 TTS 朗读修复（Herdsman API 文档对照）

根据 `herdsman-api-docs-2026-07-26.md` 修复了 5 个问题：

| # | 问题 | 修复 |
|---|------|------|
| 1 | URL 双 `/v1`：`baseURL + "/v1/audio/speech"` → `/v1/v1/audio/speech` | 改为 `baseURL + "/audio/speech"` |
| 2 | `response_format: "mp3"` 不是有效参数 | 已移除 |
| 3 | 非流式响应是 JSON `{audio_url: ...}`，不是二进制 | 解析 JSON → GET audio_url 下载音频 |
| 4 | voice 硬编码 `"aiden"`，有效值为 `Cherry`/`Ethan`/`zh-CN-YunxiNeural` | 按模型匹配正确 voice |
| 5 | `qwen3-tts` 不是有效模型名 | 改为 `qwen3-tts-customvoice`/`voicedesign`/`voiceclone` |

### 🗑️ VoxCPM 彻底移除

- 删除 `internal/tts/client.go` + `client_test.go`
- 新增 `internal/tts/util.go`（保留 `SplitSentences` 函数）
- 重写 `tts_handler.go`：移除 `StartTTSServer`/`StopTTSServer`/`getOrInitClient`/`autoStartTTS`/`resolveTTSBinary`
- `GetTTSConfig`/`SaveTTSConfig`/`GetTTSStatus` 改为空存根
- 移除 ModelCenterPage 的 VoxCPM 配置面板
- 移除 TTSPlayer/ChatPage 的 voxcpm 引擎标签

### 🔊 TTS 4 级兜底链

```
TTSSpeakBase64:
  1. 用户选中的模型（模型中心点「启动」）
  2. Herdsman 已知 TTS：edge-tts / qwen3-tts-customvoice / qwen3-tts-voicedesign
  3. Edge TTS（在线，免费，无需配置）
  4. Windows SAPI（系统自带，离线）
```

### 🎤 语音聊天 Hook 修复

`useVoiceChat.ts`:
- 修复 setState resolver 模式（改用 transcriptRef）
- 修复重复 `r.onend` 赋值
- 修复 stop/start 竞态条件（stoppedRef）
- 浏览器不支持 SR 时显示明确提示

### 🚀 引擎自动激活

- Ollama / Herdsman 默认 `Enabled: true`
- `Startup()` 三引擎全部 `TestConnection`
