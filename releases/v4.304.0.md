## 落地

- **重写引擎**（新 `internal/rewrite`，纯规则零 IO）：
  - `NormalizeRequest`：来源校验（custom 需指令/analysis_suggestions 需索引/mixed 至少其一）、字数缺省 3000 钳 [500,10000]、未知 focus 丢弃、mode 缺省 whole（MuMu schemas/regeneration.py 同参）。
  - `BuildModificationInstruction`：四段固定顺序（改进问题〔仅选中建议，越界静默跳过，MuMu L129〕/自定义要求/重点方向〔五选映射，未知丢弃〕/保留元素〔结构/对话/情节点/性格逐条展开〕）。
  - `CleanRewriteOutput`：8 个常见前缀剥离（命中即 break，MuMu L5131）+ 成对引号剥离（rune 级，「」『』“”）。
  - `ComputeDiff`：篇幅变化/百分比 + 相似度——difflib.SequenceMatcher 以本地 `textsim.Similarity`（CJK 二元组 Dice）替代，纯本地无依赖（码内注明）。
- **版本库**（project 层，契约路径 `rewrites/<chapterNum>/`）：`index.json` 只存索引（时间倒序、**无全文下发**，防 MuMu 式 1.74MB 全量推送）；全文按 `<id>.json` 按需读；Save 自动生成 ID（`rw-<chapter>-<unixnano>`）；Update 同步全文与索引。
- **六个绑定**（NovelB 门面，672→**678**）：
  - `NovelChapterRewrite(chapterNum, reqJSON)`：归一 → 从 analysis-v2.json 取该章建议（建议来源缺分析显式报错「该章节暂无分析结果」）→ 构建修改指令 → RTCO 模板 `rewrite-chapter`（原全文+指令+前文衔接参考；`{word_count}` 占位复用既有替换器）→ LLM 重写（温度 0.7 对齐 MuMu L92，10 分钟超时）→ 清理/空结果放弃 → diff → 版本落盘（completed，**不自动落章**）。
  - `NovelListRewriteVersions`（索引）/ `NovelGetRewriteVersion`（全文对比）/ `NovelApplyRewriteVersion`（写回正文+applied，幂等）/ `NovelDiscardRewriteVersion`（discarded，快照保留可再应用）/ `NovelRestoreRewriteVersion`（OriginalContent 写回+RestoredAt/RestoredFrom 审计——仅 applied 可恢复）。
- **诚实范围声明**：场景级工程（正文按场景存储）的章显式拒绝「下一刀支持」；partial 局部重写（字符区间+前后文衔接）下刀。
