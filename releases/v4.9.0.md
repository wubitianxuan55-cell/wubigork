- **时间锚点「重访那一天」**：锚点写路径接线（策略从定义变生产）+ 纪念日

  把情节/锚点记忆重述成故事（输入复用确定性回放：摘要+情绪+原文对话；
  第一人称/称「你」/≤300 字）；锚点策略刻度对齐（提取 0-1 ↔ 策略阈值）。

### 图谱三维度（c48b096 / cbea022 / 4f2debc，审计 §C 欠账收口）

- **情绪维度**：`Triple` 增情绪三字段（EmotionLabel/Intensity/Valence），
  事实提取 `attachEmotion` 落图（效价派生正/负/中），`AddTriple` 保留情绪
  （`Add` 兼容旧调用）；BASIC_PROFILE 主语实体化；**hermes.db 迁移
  V13→V14**（knowledge_triples +3 列，存量安全）；前端图谱边按情绪着色 + 图例。
- **因果维度**：`extractCausalTriples` 从事实摘要确定性提取 {因, 导致, 果}
  （因为/由于…所以…、X导致/引发/造成Y、X让我/使我Y 四类模式，直接式剥离
  连接词）；ingest 与文档导入（fact_landing）双路径接线入图。
- **关联入图**：`GaeaWhisperGraphSubgraph` 并入 AssocIndex 关联边——事实
  Subject → 实体节点，类型映射中文（event_chain→因果、temporal→时间、
  entity→同实体、emotion_peak→情绪相似、self_reference→自我、thematic→
  主题），边权重=strength，只并入与子图连通者（与 KG 边去重）；前端因果边
  琥珀色虚线 + 图例。

### 跨事实因果推断「为什么」（5d23081，审计 §C 深度补口）

- `GaeaWhisperCausalExplain(entity, personalityID)`（539→540，MemoryB/play）：
  用户问「为什么<entity>」时**确定性**收集证据——KG「导致」三元组（实体在
  因/果侧）+ event_chain 关联（涉及实体的事实对，各截断、上限 8 条），再以
  当前人格口吻（Label + VoiceGuide）让 LLM 人话化（只用证据/不编造/证据不足
  诚实说明/≤200 字）。无证据时零 LLM 调用，直接诚实回退文案。
- 图谱面板「解释因果」按钮 + 结果区；证据=确定性规则，LLM 只做人话化。

### 首页重构「星枢指挥所」+ 两段式启动动画（c2270fe）

- **启动默认首页**：MainLayout 每次启动从首页（manifest.isHome）落地，不再
  恢复上次页面；会话内跨空间切换仍按空间恢复最后页面。
- **启动动画（两段式）**：index.html 静态启动屏（JS 加载期遮罩，纯 CSS）→
  `BootSplash` React 组件接管（旋转光环 + gaea 徽记 + 分步状态文案：
  核心→引擎→记忆→就绪 + 实时进度条）；进度/卸载全 timer 驱动，WebView2
  rAF 节流（gaea-raf-degraded）与 prefers-reduced-motion 全降级。
- **首页**：Hero 中轴（公告 pill + 巨幅标题 + 中央命令条 [AI 内核 orb / 打字 /
  语音 / 发送 / ⌘K] + 语音状态行 + 快捷 chips）+ AI 状态细条（真实遥测 4 列）+
  能力矩阵 Bento（办公 4×2 旗舰大卡 + 板块瓦片，manifest 驱动，断点 6/4/2/1；
  旗舰卡双类提权防同特异性覆盖）+ 门廊 + 底部信息条；全部交互元素焦点环。
- **i18n**：en/zh/zh-TW 三语 `home.*` + `boot.*` 共 17 键（DictKey 编译期锁死）。
- 语音晶核收进命令条 orb（呼吸/波纹/辉光三态）；规格同步
  `design-system/gaea/pages/home.md`（v3）。

### 工程化与修复（9c9973c / 1d17b24 / f146931 / fdf878e / e5a3597 / 59273f6 / 5773098）

- **构建冒烟自动化**：build.bat 真实退出码 + 产物新鲜度守卫（构建前删旧
  exe、被常驻实例锁定显式报错）+ 默认自动冒烟（.tmp 临时副本 → smoke.ps1，

  spacer 保滚动条总高，冻结行常驻；小表逐字节不变。
