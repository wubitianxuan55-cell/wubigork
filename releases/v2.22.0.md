> 规划：docs/superpowers/plans/2026-08-14-gaea长期规划-阶段5-运行纵深.md

## 背景痛点（均有实测证据）

- 本地模型冷启动 TTFT **15.2s**（v2.19 实测）、换模 ~8s、herdsman local_concurrency=1，
  日常每次切模型/冷启动都在等（无保活/预热/预加载）；
- 进程崩溃/被杀后，进行中 turn 无中断痕迹：重启后会话列表看不出哪个没做完，
  恢复会话也不会提示「上次中断在哪里」（只有 transcript 本身）。

## T5-3 本地模型调度纵深

- **保活 keep-warm**：每 5 分钟对 catalog Running 的本地模型发轻量 SSE 探针
  （max_tokens=8，防 herdsman 卸载空闲模型）；探针失败自动降级跳过该模型直至重新运行；
  开关 `keep_warm_enabled`（~/.gaea_config.json 持久化，模型中心「本地调度」设置区）。
- **启动自动预载**：启动后后台预载功能绑定（gaea→office→chat 优先级）的第一个
  herdsman 模型（installed 且未 running 时 start --wait），首次对话不再等冷启动；
  开关 `auto_preload`。
- **换模预计等待**：GaeaModelSwitchEstimate——herdsman 目标模型 hot/cold/download/
  unknown 四态预估（cold 提示实测约 15-20 秒），前端模型切换器选本地模型时弹确认。
- **KV 缓存命中率 KPI**：gaea 侧调用记录上报 cache hit/miss token（DeepSeek/OpenAI
  两种 usage 风格归一），「本地 vs 云端」统计卡新增缓存命中率（全局 + 云端/本地拆分）。

## T5-4 中断续跑

- **任务级**：v2.21.0 已交付（tasks 表 running→queued 重启续跑）。
- **agent 会话级**：每轮 turn 在 session sidecar（<session>.state.json）标记 running/
  完成 + 最后进度摘要；进程被杀残留 running=true → 会话列表显示「未完成」徽标；
  恢复会话自动注入「上次中断于 <摘要>，请先总结进度再继续」并清除标记。
- **轻语长流程**：任务计划持久化到 whisper_data（重启不丢），
  WhisperTaskPlanStatus/Resume 恢复入口（前端轻语面板可一键恢复进行中计划）。

## 明确不做（本刀）

- 多模型同时保活/预载（local_concurrency=1 互踢，只保活 running、只预载一个）；
- 不动 herdsman 本体；不做空闲换模预测（数据不足，留待后续）。
