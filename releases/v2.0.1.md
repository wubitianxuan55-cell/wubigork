# gaea 2.0.1「三脑底座」

> 发布日期：2026-08-07 ｜ 基线：v1.21.0（`9093930`）

## 版本摘要

在 v1.21.0 基础上迭代，不重写、不迁移数据：

- **P0 基线加固**：frontend/package.json 纳入版本控制；`scripts/ci.ps1` 全量闸门；E01–E24 评估集重建 + 首批自动化回归（E01/E06/E11）；修复 3 处历史测试失败与测试污染
- **P1 模型路由**：`routeModel` 降级链（功能绑定 → 全局活跃 → 首个可用引擎），novel/whisper 调用收敛，模型中心展示"当前生效"
- **P2 三脑记忆**：`BrainStore` 统一访问（主脑画像+知识 / 左脑方案 / 右脑轻语 hermes.db，零迁移），`brain_links` 跨脑关联索引，记忆中枢三脑检索
- **P3 主脑助手**：`ModuleRegistry` + `RunModule` + `MainBrainChat`（可选编排入口，不经由模块直达路径）
- **P4 模块互联**：方案生成自动注入跨脑记忆；3.0 模块协议文档（`docs/gaea2/module-protocol.md`）

## 安装

1. 下载 `gaea.exe`（见校验和文件）。
2. 如被 Windows SmartScreen/SAC 拦截：右键 → 属性 → 解除锁定。

## 校验和

```powershell
Get-FileHash gaea.exe -Algorithm SHA256
```

与 `SHA256SUMS-v2.0.1.txt` 对比。

## 数据

现有 v1.x 数据（whisper_data / novels / office / 用户配置）零迁移直接可用。建议发布前运行 `scripts/backup.ps1` 备份。
