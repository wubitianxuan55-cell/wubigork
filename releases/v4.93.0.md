## 变更

### 刀A（SubagentThread）
- `status === "failed"` 时追问输入框上方显示恢复提示条
  （`data-testid=agent-recover-hint`）：「本次运行已失败。在下方输入新
  指令，可基于该子代理已有的上下文续跑」。RunFollowUp 对 failed ref 的
  续跑能力 v4.64 已有（MarkRunning 复活 transcript），此前**入口不可
  发现**——失败用户无从知晓还能续跑。completed/running 不显示。

### 刀B（diffHighlight.ts 新 + ChangesDiff 接线）
- `parserForPath(path)`：按扩展名选 Lezer parser（ts/js/jsx/tsx/py/json/
  css/html/md；模块级缓存实例）；go 等未装语言 → null（整行原样，诚实）。
- `highlightLine(text, path)`：单行 parse → `highlightTree` +
  `classHighlighter` → tok-* 类片段（含未着色间隙补齐）；空行/超长
  （>600 字）单片段原样；parse 异常 catch 回退。
- `ChangesDiff` 增可选 `path` prop：非配对行与 ctx 行走语法着色；**配对
  行维持字符级高亮**（语义信息优先于装饰）；未传 path 行为不变。
- `ChangesPanel`（按文件路径）与 `GitPanel`（按展开文件）接线。
- `changesdiff-tok.css`：tok-* 语法语义色板（hex-exempt：深色调校，浅色
  主题下饱和色可辨识；未列出的 tok-* 类自然回落继承色）。
- i18n 三语 +1 键（`subagent.recoverHint`）。
