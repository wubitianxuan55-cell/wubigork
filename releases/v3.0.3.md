# gaea v3.0.3 发布说明

> 2026-08-16 · 小说/绘梦/模型中心/角色剧照四项体验修复与重设计

## 变更

### 小说板块

- **设定页「应用到设定」**：设定 Agent 的 AI 回复气泡新增手动应用按钮——AI 输出无法自动解析时，可一键把回复（优先提取 ````markdown` 代码块）覆盖到设定编辑器，解决“有时无法自动解析”的兜底问题。
- **创作面板字号调节**：正文编辑器新增 A−/A+ 字号调节（12–24px），本地记忆上次设置。
- **默认写作技能 story-deslop**：创作页「写作技能」默认选中去 AI 味润色技能，可手动切换/清空。
- **剧情构思后台化**：点「构思剧情方向」不再弹阻塞式弹窗，AI 在后台构思（顶部轻提示），完成后弹出分支确认弹窗；构思中防重复触发。

### 模型中心

- **右侧面板「统计与资源」修复**：
  - 内存恒 0：`GlobalMemoryStatusEx` 结构体尺寸错误（多写一个 uint64）导致 API 失败，已修正为 64 字节标准结构，实测内存正常返回。
  - CPU 短间隔轮询被清零：改为返回上一次采样值，不再归零。
  - GPU 识别：跳过 Todesk/虚拟显示器等虚拟设备，从注册表读取 AMD/Intel 真实显存总量（NVIDIA 仍走 nvidia-smi），并加 15s 缓存；显存占用未知时前端只显示总量不再误导。
  - 调用统计趋势时间轴：修复「今日」串入多天数据（改为只取当天小时桶）、「7天/30天」标签带小时（改为按天聚合、只显示日期）。
  - 统计加载失败不再静默显示“暂无记录”，改为错误提示 + 重试；资源块加载/失败可见，30s 常驻刷新 + 手动刷新按钮。

### 绘梦

- **模板库重设计**：内置 7 类 79 个 + herdsman 嵌入式模板库 12 类 152 个合并为 19 类 231 个模板（新增 `scripts/gen-herdsman-templates.mjs` 生成器，herdsman 库更新后一键再生成）；新增「全部模板」入口，分类冲突自动加 `hm-` 前缀防覆盖；模板选择面板参考 herdsman「灵感示例」重做（横向滚动分类页签 + 三列卡片网格，卡片为圆角方底图标 + 标题 + 描述）。
- **生成进度显示**：ComfyUI 后端通过 WebSocket 订阅实时进度（兼容新版 `progress_state` / 旧版 `progress`），显示「全部: N% · 当前节点: 采样中」进度条；非 ComfyUI 后端降级为不定态流光动画。
- **单张图片铺满画布**：生成单张结果时 object-fit contain 全画布展示（不裁剪），多张保持网格。

### 角色剧照

- **远程剧照本地化**：角色剧照若为远程 URL（xAI 临时生成图，会过期导致裂图），保存时自动下载到本地 `portraits/` 目录；启动时迁移历史遗留远程剧照；助手记录同步本地路径；小说项目角色同样支持远程下载落盘。
- **裂图兜底**：无法加载的剧照显示角色名首字占位，不再出现破图图标。
