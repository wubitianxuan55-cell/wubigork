# v4.276.0 — 绑定面 JSON 形状普查：造价参考/复盘笔记/会话组价价格带断链修复（2026-09-13）

## 来源

「优化完善gaea」：后端优化两遍扫描（v4.245–v4.253）与 UX 线六刀（v4.271–v4.274）
收官后，换镜头做**结构性静态普查**——把 v4.269 五算走查抓到的「Go struct 缺
json 标签 → Wails 线上序列化输出 PascalCase → 前端 camelCase 契约读空」这一
bug 类从「走查撞见一处修一处」升级为**全仓 AST 闭包扫描**。

## 普查方法

扫描器（go/ast，.tmp/jsonscan）：解析 `internal/`+`shared/` 全部 struct 定义 →
从绑定面（`internal/app` 中 App 全部导出方法，Wails 全量绑定、门面只是命名空间）
签名类型出发递归展开嵌套字段（slice/map/pointer）得**序列化可达闭包** → 与
「含无 json 标签导出字段」的 struct 求交。

结果：全仓 327 个缺标签 struct 中，**绑定面可达仅 7 个**——三个输出方向真断链、
四个输入方向（Go Unmarshal 大小写不敏，存量兼容不炸）。

## 修复（5 文件补 camelCase 标签，逐字段对齐前端类型定义）

| 类型 | 出口 | 影响 | 判定 |
|---|---|---|---|
| `cost.PriceBand` / `cost.BandSource` | GaeaCostCompose 的 `band` 字段（v4.191 起） | 会话组价价格带卡全空、证据表 IQR 离群判定 NaN 失效 | **真断链** |
| `costref.Note` | GaeaCostNoteList | 复盘笔记视图 validUntil/refCount/updatedAt 全读空 | **真断链** |
| `costref.Indicator` | GaeaCostIndicators | 造价参考视图（标题/均值/分位）全读空 | **真断链** |
| `event.AskAnswer` | GaeaAnswer 入参 | 输入方向，Unmarshal 大小写不敏不炸 | 防御补齐 |
| `chat.ChatMessageInput` | ChatAppendMessages/ChatImportTopic 入参 | 同上 | 防御补齐 |
| `tts.TTSParams` | GaeaTTSVoiceParams 返回（前端暂无消费点） | 同上 | 防御补齐 |

输入方向本不炸，一并补标签的理由：**形状锁定的唯一真源**应落在 Go 定义上，
而非依赖 Unmarshal 的大小写宽容。

## 连带抓出：useChatVoice PascalCase 发送点

的 v4.269 形态互为镜像）。调用点改 camelCase，形状与类型契约一致。
