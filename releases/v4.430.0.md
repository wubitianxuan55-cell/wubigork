## 论点（规格 §1.3/§1.4 的正面解）

- `SceneMeta` 坐标齐、工艺缺：能说「戏在哪、谁在看」，说不了「戏要干什么、怎么算
  写成了」——生成单位因此只能是整章 blob（模型即兴决定场景数量/边界/目标，
  `rebuildScenesFromBlob` 事后物化单场景，v4「场景制」生成侧不成立）。
- 场景级重写此前不存在（局部重写对场景章禁、整章重写伤全部场景）。

## 落地

### 数据契约
- `SceneMeta` 扩 6 创作学字段（全 omitempty 旧档零迁移）：`Goal`（这场戏要什么）/
  `Conflict`（谁·什么阻挡）/`Turn`（价值翻转）/`Outcome`（结果必须改变状态）/
  `Sequel`（余波 reaction·dilemma·decision）/`ExitHook`（退出钩子）。
- `SaveSceneMeta` 白名单 patch 扩 6 字段，**指针语义**：未传=保留旧值（旧客户端
  /其他调用方不抹卡），传空串=清除（编辑面所见即所存）。
- `OutlineNode.SceneRefs` 接线（G10 死契约启用）：逐场景生成完成按章号递归找节点
  回写场景 ID 列表（定点合并纪律）。

### 生成链（Go）
- **卡注入与衔接**：`GenerateScene` prompt 升级——卡字段非空注入「本场景卡（工艺
  约束，正文必须落实）」区段，并注入**上一场衔接**（前场 Outcome/ExitHook 非空时）；
  无卡场景 prompt 与旧版逐字节一致（零回归，测试钉死）。手动单场景路径不上闸。
- **整章按场景卡逐场景生成**（`NovelChapterScenesGenerate(chapterNum, allowMissingCard)`，
  新流事件通道 `scene-gen-stream`）：按 Order 逐场生成**每场完成即落盘**；写前闸=
  卡缺 Goal 或 Conflict 拒绝并点名场景与缺失字段（allowMissingCard 显式跳过——刀1
  覆盖语义复刻）；任意一场失败即停（已完成保留+如实报错）；全部完成 Stitch→
  WriteChapter blob（读路径零变化）+ SceneRefs 回写 + 大纲标记；复用
  chapterGenMu 同章互斥（与整章生成不并发）与 CancelCreateChapter 取消。
- **场景级重写解禁**（`NovelSceneRewrite(chapterNum, sceneID, instruction)`）：
  快照先行 + 卡字段/前场衔接进指令 + rewrite-chapter 模板 + 写回该场景 + 版本库
  mode=scene 留痕（Original/New=整章前后 Stitch，回滚安全）+ Stitch→blob 同步；
  **他场一字不动**（字节级测试钉死）。局部重写仍禁场景章（选段↔场景映射维持观察池）。
- **AI 拆场景卡**（`NovelSceneCardsPropose(chapterNum)`）：章计划（刀1 资产）+
  大纲节点 + 前章摘要 → 2-5 张卡骨架；**提案不落盘**（确认制），前端审批后走既有
  CreateScene+SaveSceneMeta 落卡；既无计划也无大纲节点时诚实拒绝（AI 无从拆卡）。

### 前端（ChapterEditor）
- ⓘ 场景信息弹窗扩 6 卡字段（目标/冲突带必填标注），保存走指针语义 payload。
- 弹窗内新增「AI 重写本场景」区块（指令输入+执行，重写历史可恢复）。
- 场景区工具条：「按卡生成全章」（闸拒绝时弹「跳过缺卡」确认）+「AI 拆场景卡」
  （提案审批弹窗，列表可编辑，确认逐张建场景+存卡）+ 逐场景进度行
  （scene-gen-stream 事件：每场完成/跳过/终态收口后整体重拉回喂）。

## 验收对照（规格刀表刀2 行）
