# v4.507.0 · 办公输出细节轮四：bash 折叠行首行化+词界截断+超宽行预览截断（2026-10-19）

> 细节续刀（接 v4.503~v4.506）。用户截图实锤：bash 类工具行仍显示一大串——四处病灶在 `lib/tools.ts` 单源一次收口。

## ① bash 折叠行首行化（主病灶）

多行命令（heredoc / `python -c` / 管道续行）此前整条压平进单行折叠行——
换行被 CSS nowrap 压成空格，几百字符的脚本全糊在一行。新增
`commandHeadline()`：取首个非空行 + 行内连续空白压单空格 + 64 字符词界截断，
折叠行只显 `$ python -c "` 这样的可读标题；完整命令仍在展开态的 `$` 命令块
里，信息不丢。`subjectOf` bash 分支改走此函数——单卡折叠行与 ToolGroup
组行同源同口径。

## ② 词界截断（残词根除）

硬 `slice` 截断把「# 编码」切成「# b.」这样的残词。`truncateSubject()`
优先回退到截断点前最后一个空格（空格位于 <60% 处则不回退——中文/路径串
常态，避免为凑词界丢掉大半内容）。ToolGroup 组行 cap 换用该函数且幂等
（`…` 结尾的已截串不再二次截）。

## ③ grep/glob 主体瘦身

检索行此前暴露整条正则 + 绝对路径（`^施\s*工|… , D:/新工作/…`）。现在
正则截 32 字符、路径只留 basename：`^施\s*工|… @ 周报.md`；pattern 缺失
回退 path（历史口径不变）。

## ④ 超宽行预览截断

单条超长行（`[Image: source: C:\Users\…\xxx.png]` 绝对路径占位、base64、
长 JSON）此前原样上屏，几行就能占满 12 行输出预览。`boundedOutput` 新增
`TOOL_OUTPUT_LINE_CAP=160`：preview 侧逐行截断加 `…`，`full` 保持原文；
新增 `lineFolded` 计数，ToolCard 展开钮条件改为 `preview !== full`——
纯长行场景（无行数折叠）也出「展开完整输出」按钮看原文。与 v4.506 的
ANSI/CRLF 清噪同一条 boundedOutput 管线，store 原文不动。

## 实弹

办公对话流里多行脚本命令只显首行标题；grep 行不再整串正则+全路径；带
`[Image: source: …]` 等超长路径行的工具输出预览不再被占满，展开可见原文。
