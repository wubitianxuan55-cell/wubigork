## 恢复内容（从 v5.22.0 重建至 v5.27.0+）

本版本合并了 v5.23.0 ~ v5.27.0 所有发布内容，并修复了多个回归问题。

### v5.23.0 — TTS 修复 + VoxCPM 移除
- TTS: Herdsman API 5 个修复（URL/JSON/voice/模型名）
- VoxCPM: 删除 client.go/client_test.go，重写 tts_handler.go
- TTS 4 级兜底: 用户选中 → Herdsman → Edge TTS → SAPI
- useVoiceChat 3 个 Bug 修复
- 引擎自动激活: Ollama/Herdsman 默认 Enabled

### v5.24.0 — DeepSeek 引擎
- 后端: engine.go + config.go + model_engine_handler.go + app.go
- 前端: engines.ts (setDeepseekKey/getDeepseekKeyStatus) + ModelCenterPage 卡片
- 章节续写: maxContinues 2→20

### v5.25.0 — 绘梦重构
- GenControls: CardPicker 替代 Select（模型/尺寸/数量卡片平铺）
- TemplatePickerModal: 新增模板弹窗（分类 pill + 自适应网格）
- ImageGenPage: 双栏布局 + 通用引擎启停（comfyui/herdsman/ollama）
- xAI 图片: 非 ComfyUI 后端清空 size 参数
- PromptPanel: 模板弹窗入口按钮，移除内联模板 Tag

### v5.26.0 — ComfyUI ROCm + Z-Image + LoRA
- Z-Image: ZImagePowerNodes → 标准 KSampler + EmptyLatentImage
- LoRA: types.go Lora 字段 + image_handler.go lora 参数
- GetSystemStats: 新增 memTotal/memUsed
- TQDM_DISABLE=1: 修复 Windows AMD ROCm [Errno 22] tqdm flush 崩溃

### v5.27.0 — Krea2 模型集成
- 后端: buildKreaWorkflow (UNET krea2 + CLIP qwen3vl_4b + VAE ae)
- 前端: ImageGenPage/ModelCenter/GenButton Krea2 集成
