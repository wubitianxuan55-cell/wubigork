# v4.394.0 — 绘梦·扩图（outpaint）：画布加边，模型补全新区域

> 2026-09-23 发布。来源：用户指令「继续」（画室线既定刀序：T3 编辑力第三件）。
> 本刀 = 图像域长期规划 T3「扩图」；v4.393.0 观察池销号。规格：
> `进度计划/gaea-outpaint-20260923.md`。绑定面 **714 零变更**。

## 病根

扩图（把画布向指定方向扩大、新区域由模型按指令补全、原图保持）是市场标配
（即梦「扩图」/Nano Banana Pro outpaint/PS 生成式扩展），gaea 编辑三件套已落两件
（指令编辑双档 v4.327+v4.392、蒙版局部重绘 v4.393）但扩图缺位——横图补竖构图、
特写拉远景这类高频需求无处落。

## 落地（经济路线：零引擎改动）

扩图 ≡ 合成大画布（原图锚定+新区域填中性灰）+ 灰度蒙版（扩边环白）——正是
v4.393 已全链打通的 edit+mask 请求形态，OpenAI 兼容与 ComfyUI 两个后端**零改动**
即可消费。新代码集中在合成器与交互：

1. **internal/ai `image_outpaint.go`（新）**：`ComposeOutpaint(initImage, expand)`
   纯函数——四边百分比（0–200 钳制）→ 画布 `orig×(1+(L+R)/100)`、原图锚点
   `(origW×L/100, origH×T/100)`、新区域填中性灰 128（对噪声初始化最中性）；
   蒙版=原图区黑（保留）+扩边环白（重绘，四矩形互补合成）；画布 >4096² 拒绝
   （防 base64 传输爆炸——ComfyUI 分支会重标到 1MP 档，上限只约束合成输入）。
   `OutpaintToSquare(w,h)` 补正方数学（长边不动、短边均分差额）。JPEG 原图兼容
   （image.Decode 格式无关）。
2. **internal/app**：`mode=outpaint` + `expand{left,top,right,bottom}` →
   `ComposeOutpaint` 合成后**转换为 edit 请求**下发（imgReq.Mode="edit"+
   合成画布+合成蒙版）——ai 层 fail-closed（mask 仅 edit）天然满足；结果 mode
   回显 outpaint；comfyui 元数据沿用 qwen-image-edit；扩图清空请求 size
   （画布尺寸即输出尺寸，防 OpenAI 端强制重设）。fail-closed 三门：缺原图拒 /
   用户 mask 与扩图蒙版互斥拒（先于通用 mask 门给定向文案）/ 合成失败如实上抛。
3. **前端**：InstructionEditModal 范围 Radio 三态「全图/局部（涂选）/**扩图**」；
   扩图态=6 预设 chips（左/右/上/下 50%、四边 25%、补正方〔前端按源图宽高比算〕）
   +四边 InputNumber（0–200）+虚线扩边框预览（按扩展比例 padding）+扩展量合计
   读数；零扩展 warning 不触发生成。
