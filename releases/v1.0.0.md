# gaea v1.0.0 — 品牌重塑 · 盖亚

> **wubigrok 正式更名 gaea**（盖亚，大地女神）——一个不断完善的本地多功能 AI 助手。
> 全新品牌视觉：翡翠球体 + 破土嫩芽 + 灵感星芒。

## 品牌重塑

- **产品定位升级**：从「小说创作 Agent」→「多功能 AI 助手」（对话 / 轻语 / 小说 / 绘梦 / 模型引擎 / 工程办公 / 微信助手）
- **全量品牌替换**：窗口标题「gaea · 多功能 AI 助手」、应用名/产物 `gaea.exe`、UI 显示、文档、导出署名（EPUB/HTML）、图片下载前缀、日志文件名
- **新 logo 三件套**：`frontend/public/favicon.svg`（48x48）、`build/appicon.svg` + `build/appicon.png`（1024x1024）
- **Go module 重命名**：`github.com/wubigork/wubigork` → `github.com/gaea/gaea`（233 个文件 import 同步）
- **版本重新起算**：v5.x → **V1.0.0**（versioninfo.rc / wails.json info / CHANGELOG）

## 数据兼容（老用户零丢失）

| 数据 | 新路径/键 | 旧回退 |
|------|----------|--------|
| 配置文件 | `~/.gaea_config.json` | `~/.wubigork_config.json` |
| 登录 token | `.gaea_token.json` | `.wubigork_token.json`（免重新登录） |
| 项目标记 | `.gaea/`（v4 检测双向） | `.wubigork/` |
| 轻语聊天记录 | `gaea_whisper_topics` 等 | `wubigrok_*` 旧键 |
| 对话话题 | `gaea_chat_topics` | `wubigrok_chat_topics` |
| 主题/绘梦模板 | `gaea-theme` / `gaea-image-templates` | `wubigork-*` 旧键 |

- 内部 provider 注册名 `wubigrok` 保留（bridge provider 引擎兼容），UI 显示名全部为 gaea
- 图片默认保存目录 `Pictures\wubigork` → `Pictures\gaea`（老图留在旧目录）
