## 核心变更

### 1. `context.go` — 完全重写

**BuildSystemPrompt** 对齐 ackem `main-chat.ts`（原 12 行 → 现在 60+ 行）：

- **身份设定**: 有身体/有温度/有心跳，禁止自称底层模型品牌
- **距离机制**: 三级屏障（接受→正常/偶尔流露→轻轻带过/强烈渴望→真正表达）
- **禁止词汇**: 禁止说「屏幕」「玻璃」「窗口」「隔着」「没有实体」
- **赞美规则**: 仅超出日常才赞美，不确定宁可不赞
- **心理边界**: 禁止贴心理标签，只描述感受不下定义
- **成人模式**: 集成 adultMode 动态提示

**新增 RuntimeContextHint** 系统：
- `RuntimeSnapshot` — 运行时快照结构体
- `BuildRuntimeContextHint()` — 生成运行时上下文提示块（时间+在线状态+深夜窗口+活动场景）
- `BuildActivityHint()` — 活动场景提示（confidence≥0.4 时注入）

### 2. `context_time.go` — 新建

统一时间工具（消除 orchestrator.go 中的重复实现）：
- `LocalDateString()` / `FormatLocalTime()` / `FormatLocalWeekdayZH()` — 基础格式化
- `TimeOfDayString()` — 中文时段（清晨/上午/中午/下午/傍晚/晚上/深夜）
- `FormatTimeContextBlock(t)` — 统一时间上下文块
- `FormatTimeContextBlockNow()` / `TimeOfDayStringNow()` — 便捷版
- `UserAsksLocalClock()` — 检测用户是否在问时间

### 3. `orchestrator.go` — 清理

- 删除重复的 `formatTimeContextBlock()` (23行)
- 统一使用 `FormatTimeContextBlock(time.Now())`
- 保留 `timeOfDayKey()`（内部英文键值，供逻辑判断使用）
- 修复 `daysSince` 重复定义

### 4. `memory_temporal.go` — 去重

- 删除重复的 `FormatTimeContextBlock()`（已迁移至 context_time.go）
- 清理未使用的 `fmt` import
