## 坑

- **Transcript onFeedback 接线一次丢失**：批量编辑脚本在最后一处断言
  崩掉后整体不写盘，重做时只补了 props 声明、漏了 ctx/调用点——真机
  按钮不渲染。教训：**批量接线后必须从调用点正向全链 grep 复核**
  （App→Transcript→TurnBlock→ctx→AssistantMessage 五环）。

  （`args:[] received 0 expected 1`）——调用点显式传 `""`，Go 侧空串
  语义（不过滤/当前会话）已核实安全。
