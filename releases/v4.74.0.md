## 视觉改造（功能零删减）

记忆页由「头部卡 + 快速添加卡 + 分段卡 + 搜索 + 内容」的平铺堆叠，重组为：

1. **Hero 卡**：记忆标题 + 「N 条已保存 · M 个文件」摘要 + 记忆/晨报预载开关；
2. **三枚统计小卡**：事实 / 文档 / 建议 数量一眼可读（ctx-tile）；
3. **快速添加卡**：作用域 + 一句话记忆 + 保存路径（保留）；
4. **单张视图大卡**：事实/文档/建议分段（紧凑胶囊 TabButton）与搜索框、
   类型筛选、内容列表、归档收纳在同一张卡内，操作路径更连贯。

细节：TabButton 去掉 flex-1 拉伸改为内容自适应胶囊；事实搜索框改内嵌
卡片底并聚焦高亮；FactCard 补卡片底色。
