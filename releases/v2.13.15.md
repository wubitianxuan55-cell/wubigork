# gaea v2.13.15「删除方案编写，办公板块收敛为单一入口」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.15.exe](gaea-v2.13.15.exe)（Windows x64，约 31.6MB）

办公板块下线「方案编写」二级分支，收敛为单一「通用办公」入口。

## 变更

1. **删除方案编写模块**：移除前端方案编写页面、后端 proposal/db 两个包、
   全部 Proposal* 绑定方法、方案模块注册、方案库相关设置卡片。
2. **去除办公二级导航**：办公板块不再有「通用办公 / 方案编写」切换，
   直接承载通用办公工作台。
3. **左脑记忆适配**：三脑检索中的「左脑办公记忆」数据源从方案库改为
   办公记忆 facts（Hephaestus.db），记忆中枢的检索与图谱不受影响。

历史方案数据（office.db）保留在本地不删除，仅不再被读取。

## 验证与发布

- go build 通过；Brain/Module/Office 定向测试通过；前端 tsc + 128 例全过；wails build 通过
- 产物 gaea-v2.13.15.exe（约 31.6MB），桌面端同步；git tag v2.13.15
