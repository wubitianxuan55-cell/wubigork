## 缺口

进度页有工期/浮时/关键线路，造价域有预算成本，但两边从未合账：项目进行到
一半「按计划该花多少、干了多少活、实际花了多少」没有一体视角。

## 落地（computeEvm 纯函数，frontend/src/schedule/evm.ts）

- **PV 计划价值**：任务预算成本按【基线】起止线性分摊到数据日期
  （里程碑基线完成点整额兑现；无基线行的任务不计入——不在基线口径内）；
- **EV 挣值**：任务预算成本 × 完成率（progress/100）；
- **AC 实际成本**：来源=手工录入（本机无自动实际成本面，口径注直出）；
  未录入 → CPI/CV = null，诚实 n/a 不伪造；
- **SPI** = EV/PV、**CPI** = EV/AC、SV/CV 偏差同出（正=好）；
- **BAC** = 当前任务预算合计（固定成本+资源分配，复用 v4.122 computeCosts
  成本 rollup，CPM 未过 fail-closed 同口径）；
- **evTop** = EV 来源 Top5（挣了哪些任务的值，transparency）；
- 无基线 / CPM 断裂 → ok=false + 原因，不伪造三数。

## UI
