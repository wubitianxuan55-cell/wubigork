# gaea v2.6.2「xAI Grok TTS 接入」发布说明（2026-08-08）

> 本版把「我们的 xAI」真正接进语音：模型中心可选 xAI（Grok）云端 TTS，
> 语音对话与朗读优先走云端 Grok 音色，避开本地 qwen3-tts 声码器 CPU 慢速问题。

## 一、xAI Grok TTS 接入

- **实测可用**：`POST https://api.x.ai/v1/tts`（OAuth token 复用登录态），
  同一句「好的，晚安。」约 1.4~2.4 秒返回 128kbps MP3，快于本地 qwen3-tts 的 2.7~3.3 秒。
- **模型中心可选**：xAI 引擎内置 `grok-tts` 语音模型（启动与刷新模型列表时自动保活），
  在「功能绑定 → 聊天语音」选择引擎 `xAI` + 模型 `grok-tts` 即可绑定；
  也可在「语音模型」页一键设为全局语音合成。
- **音色选择**：设置面板/聊天设置新增 xAI 音色列表——
  经典 5 个（Eve / Ara / Rex / Sal / Leo）+ 旗舰 21 个（Lumen / Castor / Atlas / Orion 等），
  存 `~/.gaea_config.json` 的 `tts_voice`，无效音色自动回退 `eve`。
- **路由优先级**：聊天语音绑定 → 全局 TTS → 自动路由（引擎扫描 → Edge → SAPI）；
  流式朗读在选中 xAI 时同样优先走云端。

## 二、验证

- `go build ./...`、`go test ./internal/{tts,modelengine,app}/...` 全绿（含新增 xAI TTS 单测）；
- `tsc --noEmit` + `vite build` 通过；
- 直连 `api.x.ai/v1/tts` 实测：HTTP 200、`audio/mpeg`、1.2 秒有效音频；
- `wails build` 成功：`build/bin/gaea.exe`（约 37.9MB）；校验和：`releases/SHA256SUMS-v2.6.2.txt`

## 三、使用提示

- 需要已登录 xAI（模型中心右上角「登录 xAI」），TTS 计入账号用量；
- 若希望最省事，聊天语音绑定 `Herdsman → edge-tts` 仍是最快路径（约 1.4~2.2 秒）；
- 重启桌面 `gaea.exe` 后生效。
