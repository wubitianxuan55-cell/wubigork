## 变更

### HTML 沙箱预览
- **Go**（gaea_preview.go）：`.html/.htm` 显式分支 → `kind=html`，原文
  `readPreviewCapped` 截断读（口径与 markdown 同款）；此前落 textExts 按
  纯文本展示。
- **前端**（SandboxedHtml.tsx 新组件）：
  - `sandbox="allow-scripts"`，**刻意不给 allow-same-origin**——文档运行
    在不透明源，无法触碰宿主 DOM/localStorage/cookie，无法向上导航；
  - Chromium `csp` 属性（WebView2 支持）：`default-src 'none'` 禁一切
    网络与外链资源，只放 `style-src/script-src 'unsafe-inline'` 与
    `img/font/media data: blob:`——README 级独立报告可看，外链探针与
    追踪脚本无网可用；
  - `referrerPolicy="no-referrer"`；顶条如实标注沙箱语义；
  - FilePreview / FilePreviewModal 双消费点接线（截断提示沿用既有样式）。
- i18n 三语 +1 键（`preview.sandboxNote`）；SandboxedHtml 用**非响应式
  t()**（DocxPreview 同款先例——FilePreview jsdom 测试不包 LocaleProvider，
  useT 会抛错）。

### 外链协议分流
- `lib/browserPolicy.ts` 增 `classifyExternalLink` 纯函数（与地址栏
  normalizeBrowserUrl 同族，语义不同：外链点不开 webview）：
  - http/https → `{kind:"open"}`（loopback 拒——渲染文档不得探测本机
    服务，沿地址栏先例）；
  - mailto/tel → open（交系统处理器，无 webview 风险，办公文档常见）；
  - javascript:/data:/file:/blob:/vbscript:/相对路径/锚点/空值 → blocked。
- 接线三处：Markdown 渲染链接（react-markdown a 分支；此前任意 href 直接
  openExternal）、价格源面板/价格仓库两处数据驱动 URL（防御性一致）。
  blocked 一律 no-op 不交给系统。
