## 缺口

委托式完成至今是「单回合单账本」：跨格式长链（读 N 报表→透视→嵌图表→出 Word→导
PDF）要模型一回合烧完——中途无法插手、一步失败全链重来、产物验收只能等回合结束。
链条需要成为一等公民：规划出任务图、节点分波执行、每节点独立跑/重跑/改向/验收。

## 架构（五层）

```
dag_plan 规划工具（work 空间；PersistWrite=子代理注册表自动剔除，防嵌套派生）
  → 存储  .gaea/work/dag/<id>.json（workspace 本地，与 journal/rollback 同域，删档即弃）
  → 执行  拓扑分波（波内顺序=产物归因窗口单调不重叠）；每节点=一次 TaskTool.RunNew
          全新子代理会话（headless 闸+过滤工具集+transcripts 落盘，自动进既有子代理树；
          文本增量走 gaea-subagent-text 与追问同路）
  → 控制  GaeaDagList/Get/Run/NodeRun/NodeSteer/NodeAccept/Cancel（绑定 613→620）
  → UI    任务中心「办公流水线」区（run 卡+节点卡；running 轮询自校正；?mock=1 可走查）
```

## 关键口径

- **节点产物**=运行窗口前后 Journal 证据卡 ID 集合差、Target 过滤工作区路径。主对话
  同期写盘会并入——UI 口径注诚实呈现，不造精确归因。
- **验收=人拍板**：GaeaDagNodeAccept→办公记忆库 Save（save 路径自动落 memory_events
  成 5.1 图谱实体，6.2 项目本体自然吃到）。重跑把 accepted 退回 done=验收失效诚实降级。
- **终止级联**（roadmap §16）：GaeaDagCancel→run ctx→在跑节点子代理随之取消→未起跑 skipped。
- **fail-closed 全链**：runner 未接线（引擎未构建）/依赖成环/悬空依赖/空链，拒绝即报错。
- **重启中断懒清扫**：List/Get 时发现 running 无在途执行→诚实置 failed「应用重启中断，重跑续接」。
- **steer=续跑管道**：走 RunFollowUp（PrepareContinue 拒 running；followUpClaims 每 ref 单飞）。
