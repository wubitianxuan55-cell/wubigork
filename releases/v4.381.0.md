# v4.381.0 — dsh 蒸馏第四弹：锚定式 token 计量（压缩触发时机去漂移）

> dsh 留池 ②锚定式 token 计量（`packages/llm/token-meter`）单独一版精修——这是压缩/溢出恢复之后 compression 域的最后一块精度拼图。全 Go，绑定面 711 零变更，单刀版。

## 病根与口径

- **病根**：mid-turn（工具轮间）压力用「全量字符 × 全局比率」估算。比率虽自上次真实 usage 校准（tokPerChar），但整个表面按线性缩放重算——比率漂一点，全表面跟着漂，压缩触发时机（high-water）随之漂移：**早触发=白砸缓存前缀（真金白银），晚触发=靠溢出自愈兜底（延迟+风险）**。
- **上游口径（dsh token-meter）**：压力 = 上次真实 usage 锚点 + 当前表面的**有符号差值**；per-message 估价缓存让差值只统计新增/删除/改写的消息——锚点里那部分消息的估价逐字不变，**剪枝/压缩重写后估计不再漂移**。

## 落地（单刀）

1. **锚定压力表**（新文件 `internal/gaea/agent/tokenmeter.go`）：
   - per-message 估价 memo（FNV-64 键 = role+content+toolcalls，与 msgChars 同一记账面——ReasoningContent 不回传 API 不入账）：同一消息逐次取同一值，锚点和当前和里的「未变消息」逐项相消——**差值不漂移的全部前提**。
   - **落锚点**：maybeCompact 收到真实 usage（PromptTokens>0）时落锚。落锚时机有讲究：此刻会话表面恰为刚被 answered 的请求（新 assistant/tool 结果尚未入账），锚点无系统偏差。LastPrompt 回退路径不落锚（不是真实值）。
   - **估压**：有锚 = anchorReal + (estNow − anchorEst)，差值为负（删得多估得狠）钳非负；无锚（首个真实 usage 之前）= 裸字符估算（旧口径逐字节不变——midTurnMaybeCompact 本就等首锚后才工作）。
   - 压缩重写性质：老消息被摘要替换 → 压力按「删锚点估价、加新估价」**精确**移动（锚点语义下重写不引入漂移，这正是上游「剪枝/压缩重写后估计不再漂移」的性质）。
2. **接线**：EstimateContextTokens 委托计量表（midTurnMaybeCompact / compactIfOver 内部复核 / force 检查全部过同一口径）；恒装配、无配置面——首个真实 usage 到手后自动生效，无锚行为与旧口径一致。

## 测试与门禁

- Go 新增 +5：锚定核心性质（比率源漂移下未变消息不重算、新增/移除精确移动、重复读取零漂移）/压缩重写精确移动/负差值钳非负/无锚回退旧口径/maybeCompact 真实 usage 落锚而 LastPrompt 回退不落锚。
- go build/vet 0 + gofmt（触碰文件）+ 全量 ci.ps1 绿 EXIT=0 + 版本漂移闸 OK@4.381.0。绑定面零变更。

## 坑

1. **锚点时点要对齐「刚被 answered 的请求面」**——maybeCompact 在 session.Add(assistant) 之前调用才无系统偏差；挪到入账后就差一整轮（会高估）。
2. **新消息按「当前」比率估、老消息按「锚点时点」比率消**——这是刻意的：新消息用当下最好的知识估，未变消息用锚点值消（重算就是漂移回流）；memo 键只含内容不含比率，比率演化不影响一致性。
3. **sync.Mutex 不可重入**——anchor/estimate 持锁调 sumEstLocked/mesgEstLocked 内部无锁变体；外层复用锁内助手时别再走公开方法（死锁高发形态）。

## 升级说明

- 无配置变更、无接口变更：首个真实 usage 到手后 mid-turn 压力自动切换为锚定口径（采样轮后的触发本就用真实 usage，不受影响）。
- 可感知效果：长工具链任务中压缩触发时机更贴真实水位——更少「没到阈值就压缩」的缓存浪费与更少「冲过窗口靠溢出自愈」的来回。
