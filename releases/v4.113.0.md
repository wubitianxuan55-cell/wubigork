### agent 工具三件套（internal/gaea/tool/builtin/schedule_tools.go，4 例）

计划文件（`进度计划/当前计划.gsched.json`）= 板块与 agent 的**共享资产**，三工具入 `Workspace.Tools()`（workDir+写根绑定，进程 cwd 默认实例同注册）：

- **schedule_get**（只读）：任务表（ES/EF/LS/LF/TF/FF/关键标记）+搭接+日历+总工期全景。
- **schedule_apply**（写）：双通道二选一——`project` 整计划（生成/重排）/ `ops` 增量（对话式调整）。**纪律**：快照 StageBaseline+证据卡 RecordChange（tool=schedule_apply，work 空间）+写根 confine；环依赖/悬空引用/非法字段整批拒绝、错误原文回传；回执强制带写入后总工期与关键数（模型必须核对——「成功≠正确」）。
- **schedule_analyze**（只读）：质检 findings（孤立任务/空分组/多条并行尾巴无收口/缺里程碑，斑马「AI 计划检查」的确定性子集）+关键链/近关键/里程碑叙事数据（「AI 分析报告」的底座，LLM 润色在其上）。

分工口径（调研结论）：**AI 只产结构化字段，可行性与环检测由确定性 CPM 引擎裁决**。

### 板块文件化与同步（前端）

- 绑定：GaeaScheduleLoad/Save=轻量 IO（校验+原子写在 Go 侧；**无证据卡**——UI 自动保存不刷 Journal，证据卡只属于 agent 的 apply）。
- store 刀4 化：挂载水合（**文件为准**；文件不存在则 localStorage 旧数据自动迁移上文件）→ 编辑防抖 800ms 自动保存 → focus/15s 可见轻扫回读 agent 改动（未保存变更/失败态不覆盖，宁守勿冲）。
- 状态栏同步指示器：读取计划…/改动待保存…/保存中…/已保存 HH:MM · agent 可读写/保存失败（hover 见错误原文）。
- mock 走查态：mockScheduleFile 会话内存 + `window.__mockScheduleFile` 钩子（模拟 agent 外部写），mock Save 走真实 CPM 纯函数回执。
