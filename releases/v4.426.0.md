## 论点（三个系统性缺口，全部读码确证）

1. **「切故事」边界只有 selectStory 一个口有收尾，新建/删除/清空三个口裸奔。**
   v4.423 给 selectStory 装了完整收尾（后端取消旧流 + 本地解绑 + 脏草稿确认），但 createStory
   直接改 activeId：发送中点「新建」→ 旧流在后台跑完白烧 token、新故事 Composer 被旧流
   `sending=true` 锁死、cancel 按钮调 `SinCancel(activeIdRef)` 取消的是新故事（无在途流）而非
   旧流——按钮态与真实流态彻底脱节；「新建」还绕过 `confirmSwitchThen` 脏草稿确认，是
   v4.423「切故事清草稿+脏上报」的漏网入口。同族：`saveCast` 保存闭包绑定发起故事，
   在途切换后 `setCastIds` 把 A 故事的生效清单写进 B 故事的面板状态（用户再点「带入故事」
   就把 B 覆盖成 A，后端无 baseline 比对=不可恢复）；`useSinNotes.save` 回填绕过读路径的
   live 守卫，切故事后面板显示 A 的底稿。
2. **插图「不落库出图」一族烧算力且产物丢失。** 流式中间态（messageId=0）手动按钮可点、
   手动停止/超时/报错的残行（messageId 恒 0）照样触发自动出图——`SinIllustrate` 对
   `messageID<=0` 只生成不回写，图片在重开/导出时退回占位，每次重进重烧一次 GPU；
   超时路径还把已流出的正文整段替换成超时文案、且不调 `SinCancel`（后端继续跑完整轮）。
   取消竞态：生成中点取消后，迟到的 rejection 把空闲态翻成红色「插图失败」+全局 notice
   （用户主动取消被呈现为失败）。
3. **工具产物链半截：sin_illustrate 的图进不了导出、轨迹参数无闸、产物跨调用重复携带。**
   工具实例整回合复用而 `arts` 只增不减——「再画一张」第二次调用的轨迹重复携带第一张，
   落库按 toolN 编 cue 时同一张图占两个键；`sinAttachIllustration` 落库回写从不校验
   messageID 归属话题（本板块唯一 fail-open 写口）；MD/EPUB 导出只认正文标记的数字 cue，
   工具图整批消失且 caption（结构注释声称「导出替代文本」）落库即丢；首轮任意错误
   （断网/401/5xx）被误判成「模型不支持工具」——假 notice + 静默关工具重试，错误归因失真。

## 落地

**前端（10 文件 + 1 新增模块）**

- `useSinStory`：抽 `teardownStream()` 收尾原语，`createStory` 前置调用（与 selectStory 同口径：
  后端取消旧流 + 解绑 + 复位 sending）；`cancel()` 取消目标改 `streamTopicRef || activeIdRef`
  （在途流归属优先）；超时路径改「先 `SinCancel` 保留残稿落库、已流出正文不动、提示走 notice」
  （不再整段覆盖正文）；`loadMessages` 读失败不再清空现有视图（切故事场景由 selectStory 先行
  清空，瞬时失败不吹掉正在读的长故事）；`reloadMessages` 流中跳过（整表替换会打断流式行）。
- `useSinCast`：`saveCast` 归属校验（在途切换不回填旧清单）+ 失败返回 `{ok,message}`（历史实现
  无 catch：chip 不动、选择器照关、unhandled rejection=假成功）。
- `useSinNotes`：`save` 回填归属校验（保存已成功落发起故事，照实返回 ok，仅跳过回填）。
- `SinIllustration`：手动/重试按钮 `disabled={!ready || messageId<=0}`（title 给原因：等本段写完/
  未落库不保存）；自动出图加 `messageId>0` 闸（残行降级手动）；取消置 `cancelledRef`，
  迟到 rejection 保持空闲态不进错误样式。
- `OriginalSinPage`：新建按钮接 `confirmSwitchThen`（脏草稿确认）；角色保存统一 `handleSaveCast`
  （成功才关选择器，失败 notice）；重命名空输入保留原标题（不再静默改「新故事」）；导出按钮
  disabled 透传 ToolbarButton（导出中/空故事按钮看着可点却无响应的根除）。
- `SinSidePanel`：底稿冲突「覆盖」确认在切故事后命中归属守卫时给 `message.info` 回声
  （显式破坏性选择不再静默无事发生）。
- `sinBookDownload.ts`（新）：书源下载会话模块级单例——面板挂在手风琴卡里，点其它卡即卸载，
  进度/toast/jobId 不再随卡丢失（v4.423 观察池立案项）；done 终态 toast 模块级长驻；
  `startDownload` 起跑闸防双击双 job；假取消后照常刷新成书清单。
- `SinProcessCard`：工具产物缩略图加载占位（固定最小高度防跳动）；顺带修复——流式 result 帧
  携带的 `artifacts` 此前在 `applyToolFrame` 被丢弃，流中过程卡不出缩略图，现全链贯通。
- `Composer`（共享组件）：含空格路径附件注入改 `@"..."` 引号形式（裸 `@token` 在第一个空格处
  截断，「C:\Users\John Doe\a.txt」这类路径静默失效；不含空格路径保持裸形式，办公解析口径零变化）。
- `StoryStream`：流式光标无效 `aria-label` 改 `aria-hidden`（span 无 role 时标签不被读屏播报）。

**Go（13 文件）**

- `sin_tool_illustrate`：Execute 入口重置 `arts`（轨迹只带本次产物）；`sinAttachIllustration`
  增 topicID 归属校验 fail-closed（跨话题/跨板块写 extra 根除）。
- `sin_handler`：首轮降级重试加 `sinErrSuggestsNoTools` 判据（错误串含 tool 才降级，断网/401
  不再谎报「不支持工具」）；失败零正文（default 分支 + 空回复分支）照常落库用户指令（镜像零正文
  取消口径，重开故事不留「说过的话凭空消失」）；收尾轮仍冒工具调用改可见化——如实下发
  dispatch/result 帧（错误态）且 assistant 回合与未执行 tool 结果照协议接回上下文（下一轮模型
  看得见自己刚说过什么，不再从同一条收尾令从零重写=正文重复根因）；MD 导出补工具产物附录
  （caption 作替代文本，工具图不再从导出消失）；识图前发「正在解析 N 个图片附件」notice、
  解析完即清（N×90s 串行识图首帧前不再干转）。
- `sin_tool_loop`：轨迹 `Args` 2000 rune 闸（sin_notes 类写工具参数是大段正文，事件帧/落库
  extra/重放不再被撑爆；喂给模型执行的原始参数不受影响）。
- `sin_export_epub`：历史零正文行跳过（不占回数、不消耗指令引块）；连续多条用户指令逐条入引块
  （失败轮重发的历史不再只留最后一条）；退化标题（如「///」净化后为空）回退默认名不再整单失败；
  工具产物附录同 MD 口径。
- 原子写统一：`saveSinNotes`/`saveSinCast`/`sinWriteFileAtomic`/成书 TXT 四处固定名 `.tmp` 换
  `fileutil.AtomicWrite`（CreateTemp 唯一临时名+失败清理——双开壳并发保存同一文件互踩同一名
  临时文件的根除，残渣不再留目录）；书源 EPUB 写出改唯一临时文件+rename（崩溃不留半截、
  并发导出不双写同路径）。
- `sin_file_refs`：`@"..."` 引号 token 支持（含空格 Windows 路径）；`io.ReadFull` 读满（单次
  Read 允许短读=静默少注入的根除）+ 空文件按空内容（io.EOF 不再当读取失败）；`sinTrimPartialUTF8`
  共享助手。
- `sin_tool_book`：成书节选同口径（读满 32KB + rune 边界回退，多字节字符不再被劈成乱码尾巴）。
- `sin_tool_export`：`sinExportFileName` 加 Windows 保留设备名避让（stem=CON 一类打到 DOS 设备
  而非磁盘；`sanitizeDirName`（小说导入共用）同刀，书名来自远端站点不能假定是善意文件名）。
- `sin_refs`：参考图转 data URL 加 8MB 上限（无闸整读把几十 MB 原图 base64 塞进生成请求体，
  超限跳过该参考走 fallback 链）。
- `booksource/chapter`：下载进度语义改「已处理/总数」（成功+失败）——旧口径有失败章时末次到不了
  total，进度条卡在 N-1 后瞬跳完成观感像中断；失败明细仍走 Failed 清单。

## 观察池

- 跨实例族（多开壳）：sinRuns 互斥是进程内的（双开对同一话题双写交错落库）、话题 id 毫秒级撞名、
  messageID 靠「最后一条 assistant」启发定位（可改 AppendExchange 返回 id）——单用户桌面端权重低。
- Delete/Clear vs SinStream 残余 TOCTOU 窗口（takeSinRun 后、删除前插入 register——需跨进程锁）。
- 画廊缩略图 base64 常驻内存无上限（需自定义协议直读或 LRU）。
- sin_insight 轨迹/上下文/节点详情三口各自全量折叠+extra 双重解析（可共享一次 fold）。
- 附件识图有界并发（当前串行，提示已加）。
- illustration merge 无 per-message 锁、sinExportUniquePath stat-then-write（既有立案）。
- ChatTabs 主页签 role="tab" 语义（办公共用组件，改动波及面另批）；sin 手风琴 aria-controls 配对。
- 设定卡链与流内插图不同队列（进度互串/取消互杀——需统一入 illustrationQueue）。
- 工具图 caption 升级 extra.illustrations 值结构 {path,caption}（当前画廊描述靠轨迹反解，已可用）。
- sin 正文接 novelstyle rewrite 链（写后去味，需拍板成人向 whitelist 语义，v4.424 立案）。
- 真机观察：解释腔出现率、工具误用率（需用户闲置窗口）。
