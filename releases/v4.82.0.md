## 规格（双源蒸馏规划 阶段二.5 2.5d）

来源：`docs/gaea-dsh-better-sidebar-long-term-distill-plan-2026.md` §5
2.5d——Trend step brief 跳转、设置中心默认（粒度/模式/排序）。

| 规格 | 状态 |
|------|------|
| 趋势 brief「输入」行跳转浏览器对应用户消息 | 🆕 Go fold 锚点 seq + 前端联动 |
| 趋势 brief「回复」行跳转浏览器对应工具交换 | 🆕 结果到达锚结果节点，未到退化 assistant 节点 |
| 粒度/模式/排序默认持久化 | 🆕 localStorage 单键 JSON（gaea.context.prefs） |
| 设置中心默认入口 | 🆕 办公分组「上下文页偏好」卡 |

**边界（如实）**：dsh 的「hover 联动浏览器预览」不做——浏览器默认全收起，
hover 驱动展开会反复抖动；点击跳转是明确意图，语义更诚实。2.5e `/context`
弹层与 Agent Network 会话跳转仍待拍板。

## 变更

### Go（internal/gaea/contextview）
- `RequestRecord` 增 `BriefUserSeq/BriefRespSeq int64`（brief 行在浏览器
  里的跳转锚点=对应 `SurfaceNode.Seq`；0=无锚点，前端不渲染跳转）。
- fold 跟踪锚点：user 消息/assistant 消息取事件自身 seq（节点同 seq）；
  工具交换在**结果到达**时锚到结果节点（来源 chip+全文，跳转价值高于派发
  事件——派发事件本身没有浏览器节点），结果未到前保持 assistant 消息锚。
- 三处同拍：applyHeader 组装、applyUsage 关闭（header 先于消息时的
  brief 刷新路径）、closePending 估算关闭，锚点与 brief 文本同源刷新。

### 前端
- `lib/contextPrefs.ts`（新）：上下文页偏好读写——单键 JSON + 逐字段
  校验，损坏值单字段回落默认（模式对齐 subagentPrefs）。
- 趋势卡（ContextView.tsx）：粒度/模式初值读偏好、变更写回；StepDetail
  「输入/回复」brief 行带锚点时渲染为跳转按钮（hover 提示 + 下划线）。
- 浏览器树（context/inspector.tsx）：`focus` 跳转——展开目标组（含分页
  全量「显示全部」）、`scrollIntoView` 滚动进视图、高亮 3s 自动清除；
  归档组同款支持；锚点无对应节点诚实不跳；分类内排序初值读偏好/写回。
- 文件活动卡：排序三胶囊初值读偏好/写回。
- 设置中心（components/settings/ContextPrefsPanel.tsx 新文件，办公分组
  挂载）：「上下文页偏好」卡四行 Radio 选择——趋势卡粒度/趋势卡模式/
  上下文浏览器排序/文件活动排序；选项文案复用 `contextview.*` 既有键
  （不另造口径）；脚注如实标注「切换在上下文页重新打开后生效」。
- i18n 三语 +11 键（`settings.context.*` ×10 + `contextview.briefJumpTip`）；
  dev mock 补 briefUserSeq/briefRespSeq 锚点 + user(seq 5)/assistant(seq 6)
  节点 + ContextNodeDetail 对应样例。
