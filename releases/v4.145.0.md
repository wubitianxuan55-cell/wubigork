## 1. Go GaeaScheduleProjectCopy(rel, name)

- 流程：源文件 `schedule.Load` 全套校验（坏文件 fail-closed）→ 新名 trim 非空 → `SafeSlugName`（冲突加序号，同 Create 口径：登记条目与目录游离文件都算占用）→ **深拷贝仅改 name 落新文件**（任务/搭接/资源/分配/基线槽/AOA 布点/日历随行，`schedule.Save` 全套校验落盘）→ 索引显式登记（未归档，UpdatedAt=now）。
- **指针不动**：文件级动作语义，同归档——复制品是快照，用户自行切换打开（Create 才自动切指针）。
- 回执 = `ScheduleProjectsResult`（current+projects），前端取回执刷新即可。
- 错误口径：空名/源文件不存在/源文件损坏/非法 rel（.. 逃逸、后缀）全部拒绝并诚实报错。

## 2. store copyProject(rel, name)

- rel 是**当前工程**时先 `flushDirty()`——拷的是已存盘内容，在途未落盘编辑不进副本（诚实口径）；非当前工程直接拷盘上文件。
- 成功：回执列表直接入缓存（不另发请求）；返回 true。失败：只落 syncError 返回 false（fail-closed，绝不半写）。

## 3. 管理面板 UI

- 每行新增「复制」按钮（含归档行——归档工程同样可复制快照）→ 弹窗取名：默认原名+「-副本」，空名禁用确认键；失败弹窗不关（syncError 由状态栏指示器诚实展示），成功关弹窗、列表即时出现副本行。
- 弹窗内文案说明口径：「复制为独立工程文件入注册表（含基线/AOA 布点/日历），副本打开后改动互不影响——签证『调整1→调整2』迭代可先复制再改，基线漂移直接对比」。
