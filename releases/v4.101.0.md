## 线 C：小说一致性深检误报缓解（CheckConsistencyDeep）

- **误报分类盘点**（机制两类：规则层 graph.CheckConsistency 正则 + AI 状态卡深检本地五类比对）：①位置/物品精确字符串比对（「青云宗」vs「青云宗后山」误报瞬移）②角色别名/称谓对不上台账 ③时间粒度差异（「三年后/翌日」误报倒流）④全半角/标点变体 ⑤无中生有类告警过重。
- **缓解四件**：
  1. deepNormalizeText 归一化（全角→半角/空白剥离/包裹符剥离/小写/去首尾标点，幂等）+ deepNormContains（针长≥2 rune，台账相等优先→唯一包含→歧义不命中）；
  2. deepAliasResolver 别名归一（项目无 alias 字段——grep 证实，采用 canon 名单=角色+lorebook 人物 + 唯一包含 + 称谓前后缀剥离表 30 项；候选不唯一即放弃，宁对不齐不错并）；
  3. 置信度/原因分类：confidence(high/medium/low)+reason(wording/granularity/alias/unexplained)；UI 三档（冲突红/疑似金/提示蓝）+原因徽标；同区域细化→info、粗粒度时间→warning（双精确仍 error）、别名参与→medium、无中生有分「明确交代过丢失=error」与「无交代消失=warning 且只报一次」；**只降不升、零静默吞告警**；
  4. 单条忽略+记忆：consistencyIgnore.ts（localStorage 项目级上限 500 丢最旧、指纹=category|entity|location|reason 不含漂移 description、读写全 try/catch）；忽略条目计数横幅保持可见+一键恢复；全忽略显示可恢复空态而非「全部通过」。
- gate 消费方（novel_gate_handler）读取键不变；绑定面零变化（payload 是 map）。目标测试：Go 13 个 FP 用例 ok + vitest 25/25 + NovelSettingPage 回归 11/11。
