## 交付明细

### ① 子代理完整 transcript 查看器（新绑定 +1）

- 新绑定 `GaeaSubagentTranscript(sessionPath, ref)`：读取
  `<sessionDir>/subagents/<ref>.jsonl` 全量消息（role/name/content/reasoning/
  toolCalls/toolCallId）；ref 校验 sa_ 前缀 + 仅安全字符（防路径穿越）；
  读取失败返回错误（查看器区分「没有」与「读不了」）。gen_bindings 重生成，
  绑定面 545→546，bindingNames.ts 同步。
- 前端：Agent 网络详情面板增「查看完整 transcript」按钮 → 消息流（角色徽标
  + 推理块 + 工具调用 + 结果，可滚动、可收起）。

### ② 轨迹 Overview 投影 + 轮次跳转 + 折叠控制

- 轨迹标签顶部新增「轨迹概览」投影条：每轮一根柱，柱高 ∝ 记录密度，
  含工具调用高亮、报错轮标红，hover 显示「第 N 轮 · X 条记录 · Y 工具调用」，
  点击平滑滚动到该轮并展开。
- 「收起全部 / 展开全部」控制：长会话可整体折叠成轮次索引，再点概览跳转；
  新回合（实时刷新）默认展开，不被旧折叠态吞掉。

### ③ 迁移/兜底会话趋势补齐（诚实估算）

- `ToLogEntries` 每回合合成 `request_header`：system = 真实 system 消息拼接，
  tools = 该轮 assistant 实际用到的工具名集合（schema 未知，只给名字的最小
  诚实形状）；顺序与运行期一致（user 消息先落、header 随后）。迁移/兜底
  投影的旧会话从此有系统/工具分类估算与 header 轨迹记录。
- `contextview` 新增回合末估算关闭：turn_done 时未收到 usage 的待完成请求
  用当前估算构成落一条 `estimated` 记录（刷新到回合末构成）——旧日志与不报
  用量的提供方都有趋势柱；前端步骤详情显示「估算构成（无用量记录）」，
  不伪造 promptTokens 等用量数字。
