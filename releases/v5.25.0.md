## 主要改动

### 🎨 绘梦页面全面重构

绘梦（图片生成）页面从单列布局升级为专业双栏工作台，大幅改善交互体验。

| 模块 | 改动 | 效果 |
|------|------|------|
| 左栏布局 | 新增 `overflowY: auto` + 根容器 `flex:1` 约束 | 控制面板独立滚动，永不裁剪 |
| 引擎选择 | `Radio.Button` → 卡片平铺 | 4 引擎一目了然，点击即选 |
| 模型选择 | `Select` 下拉 → 卡片平铺 | 所有模型直接可见 |
| 尺寸选择 | `Select` 下拉 → 卡片平铺 | 7 种尺寸横向展开 |
| 数量选择 | `Select` 下拉 → 卡片平铺 | 1~4 紧凑排列 |
| 模板选择 | 内联 Radio + Tag → 弹窗 + 分类卡片网格 | 按类浏览，hover 预览 prompt |
| 快捷模板按钮 | 新增 `📐 选择图片模板` 按钮 | 一键打开模板弹窗 |

**新增组件**:
- `CardPicker` — GenControls 内联卡片选择器
- `TemplatePickerModal` — 分类 pill + 自适应网格模板弹窗

### 🔧 通用引擎启停

| 改动 | 旧 | 新 |
|------|-----|-----|
| 支持引擎 | 仅 ComfyUI | **comfyui / herdsman / ollama** |
| 状态检测 | `getComfyUIStatus` | ComfyUI 用 `getComfyUIStatus`，herdsman/ollama 用 `testEngineConnection` |
| 启停按钮 | 仅 ComfyUI 顶栏 | 左栏通用启停卡片（绿色=运行中，灰色=未启动） |

| 顶栏状态 | ComfyUI Tag | 本地引擎显示 🟢已连接(N模型)/⚫未连接，云端显示 ☁️云端 |

### 🐛 xAI 图片生成修复

**根因**: `ImageGenerationRequest` 包含 `size` 字段，直接序列化发送给 xAI。xAI API 不接受 `size` 参数，返回 400 `"Argument not supported: size"`。

**修复**（双层保护）:

| 位置 | 修复 |
|------|------|
| `internal/app/image_handler.go` | 非 ComfyUI 后端统一清空 `imgReq.Size` |
| `internal/ai/client.go` `generateImageXAI` | xAI 专属路径清空 `Size`/`Negative`/`Seed` |

**验证**: 真实 xAI API 调用测试（HTTP 200，5.6s 返回图片 URL），单元测试覆盖序列化正确性。
