## C 类纵深补课（按审计 §E 价值排序）

### Mood→TTS 闭环（审计点名「听得出她今天低落是原料非成品」）

- 新增 `voice.MoodToVoiceDescription(mood [4]float64)`：把 whisper 长期心境
  4D EWMA（Aff/Sec/Aro/Dom，-100..100）映射为**连续韵律**中文指令（低沉/
  温暖/不安/平缓/轻快/柔和顺从/略带强势，阈值与 `MapEmotionLabel` 同量纲）。
- 语音自动 TTS 读 Mood：`WhisperChatFn` 第三返回值透传心境；中性轮次
  （CALM_RATIONAL/空标签）由长期心境主导韵律，强情绪标签轮次仍由标签静态预设
  主导（本轮反应 > 长期基调）；Mood 全中性返回 "" 回退 v4.3d 及以前路径。
- 回归：`TestMoodToVoiceDescription`（6 场景）+ `TestManager_MoodDrivesNeutralTurnProsody`
  （低落中性轮次 → 低沉平缓；强情绪不被 Mood 覆盖；未播种回退冷静平淡）。

### Verifier 通道 B 真视觉 diff + 失败回 Plan（审计 ①/②）

- **像素级视觉 diff**（页数对比 → 像素差异率 + 页数联合判定）：soffice 转
  before/after PDF → poppler pdftoppm 逐页渲染 PNG → 纯 Go 归一化网格像素
  比对（无新依赖）。阈值：≤2% pass；>2% 且页数未变 warn（内容/数据大改，
  预期内）；>20% 且页数变化 fail（版式大改，A 通道无法解释）。渲染链任一环
  不可用降级 warn（仅结构复核），不误判。审计产物（PDF + 逐页 PNG）落
  `.gaea/work/journal/verify/<id>/` 并随 verdict 记录路径。
- **覆盖面扩展**：有基线快照的写盘记录（xlsx_apply / edit_file / write_file /
  multi_edit / edit_lines / move_file）都可复核，不再只对 xlsx。
- **失败回 Plan**：DeliverablesPanel 证据卡内联复核结论（通过/警告/未通过
  徽标 + 通道详情常驻展示）；xlsx_apply 复核未通过时出现「重新规划」按钮
  （回办公面板重跑规划），回滚按钮同卡可用。
- 回归：`TestPixelDiffRatio`（相同/半图/等比缩放/缺失文件）+ `TestRunVisualDiffVerdicts`
  （pass/warn/fail/降级四态，seam 注入）。

### 询价异常检测 + 价格预测 + OCR 报价单自动入询价库（审计 ①/②）

- **调差异常分级**：`AdjustSuggestion.Level` 正常(<5%)/关注(5-15%)/异常(>15%)
  （与五算对比同口径），前端调差面板按级着色徽标。
- **价格预测**：`costinquiry.PredictNext` 对同标题询价序列线性回归下期价
  （≥2 数据点，斜率/截距最小二乘），建议行展示「预测下期 ¥x」+ 置信说明。
- **OCR 飞轮反向接线**：`GaeaCostImportApply(rows, inquirySource...)` 变参；
  前端对 PDF/图片报价单（pdf_text/pdf_scan/image）确认导入时传 "OCR报价"，
  后端事务提交后按 (title,spec,source,supplier) **幂等**写入询价库（重复导入
  同单只刷新价格不新增行）。xlsx/csv 导入不写（旧行为零变化）。
- 回归：`TestPredictNextAndLevel` / `TestUpsertBySourceKeyDedup` /
  `TestSuggestAdjustmentsLevelAndPrediction` / `TestCostImportApplyWritesInquiryPoints`。

  活跃写库，gaea 直写有锁/Schema 漂移/数据竞争三类风险，且设计上「只读联动」
  已是产品定位；如需「gaea 侧角色资产可写」，应在 gaea 自有库建角色资产表并
  与 life.sqlite3 只读联动，而不是写 Herdsman 的库（下轮评审）。
- **Verifier 通道 A 仍以摘要比对为主**（xlsx 公式重算零错误为结构闸），引用级
  完整性检查待 docx/office 转换包接入后深化。
- **Mood 韵律尚未进前端手动朗读**（EmotionSpeakSelector 为显式标签选择，
  属用户主动控制，不自动叠 Mood——设计如此，注明）。
