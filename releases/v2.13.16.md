# gaea v2.13.16「办公板块铺满窗口 + 顶部标签删除 + 底栏只显示本地模型」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.16.exe](gaea-v2.13.16.exe)（Windows x64，约 31.6MB）

通用办公三个显示细节优化。

## 变更

1. **删除顶部「办公」二级标签**：办公板块不再有独立的标题栏，模块直接由
   通用办公工作台承载（MainLayout 直接挂载 GaeaPage，移除 OfficeHubPage
   及 office-hub / office-page 遗留样式）。
2. **底栏只显示本地模型**：底部状态栏的「已启用模型」只列出本地引擎
   （herdsman / ollama / cosyvoice / ComfyUI），云端引擎（xai、deepseek、
   opencode-go/zen 等走 API）不再展示；「已启动模型过多」报警同样只统计
   本地模型，不受云端引擎影响。
3. **通用办公铺满窗口**：全屏 / 最大化时界面不再留白——此前内容区对办公页
   保留了 8px / 16px 内边距，现与聊天页一致铺满整个窗口。

## 验证与发布

- tsc 通过；前端 128 例全过；wails build 通过
