## 关键修复（真实缺陷）

- 来源定位器：仅“折叠空白”不匹配“原文有空格/摘录无空格” → 改为字符级忽略空白匹配；修复中文 byte/rune 偏移混用越界
- 目录导入：局部变量指针陷阱导致子章节丢失 → 内部节点树构建后物化为值树
- WordTarget 未落库：P1 sections 表无字数列 → SchemaV4 补列
- 批量单元：曾把有子级的章也作为生成单元 → 只生成叶子；续写顺序需稳定 Index
- 素材命名冲突：同一秒内中文标题 slug 相同 → 纳秒级唯一
- 规范检索误杀：knowledge.Search 丢弃“查询词含空格不连续”的条目（砷条文被丢）→ SearchSpecs 自主令牌评分选候选

## 记忆与知识体系更新

- 规范条文、素材、历史方案统一存记忆中枢（Hephaestus.db knowledge 表），不再散落硬编码（SoilRemediationKB 同步入库，保留为兜底）
- `spec_query` 工具优先读记忆中枢；方案完成后可一键归档回写，同类方案生成自动注入参考
- 模板库落库 office.db（方案工作流专属配置，不混入通用知识）
