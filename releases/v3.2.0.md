# gaea v3.2.0 发布说明

> 2026-08-26 · 任务可见性：C1 任务实时输出 + C2 子代理活动行（v3.2.0 第一刀）

## C1 任务实时输出（GaeaTaskOutput）

办公长任务（价格抓取、批量抓取、语义索引）一旦卡住，用户看不到「它在干什么」。
本版让任务中心看得见实时输出：

- **后端输出环形缓冲**（tasks 包）：`Progress.Output(line)` 逐行追加，按任务 id 累积
  （200 行 / 64KB 上限，超限丢弃最旧行并置截断标记）；只回放不消费游标（对齐插件
  jobs-routes 纪律）。三个消费者全部接上时间戳输出：价格抓取（源名/URL/候选数）、
  批量抓取（逐源 ✓/✗）、语义索引（逐批进度与失败行）。
- **新绑定 `GaeaTaskOutput(taskID) → { tail, truncated }`**（绑定面 496 方法，+1）。
- **任务中心输出 dock**：任务行可点击选中 → 底部共享输出面板（pre 等宽回放、运行中
  2s 轮询 + 自动尾随滚动、截断标注「输出过长已截断（仅保留最近 200 行/64KB）」、
  可关闭）；终态任务仍可点开复核。
- **结束态细分 `stopping`**：取消运行中任务 → 条件置「停止中」（WHERE status='running'
  防覆盖终态竞态）→ 传播取消 → handler 退出终态 cancelled；前端「停止中」琥珀色
  旋转徽标 + 取消按钮文案「停止中…」；重启续跑把 stopping 一并恢复为 queued
  （取消途中崩溃不丢任务）。

## C2 子代理活动行（lastText / lastTool）

分工面板之前只能看到「谁在跑、跑了多久、几次工具调用」，看不到「此刻在干什么」：

- **后端**：`summarizeSubagentTranscript` 从 transcript 尾部派生 `lastText`（最后一段
  assistant 文本，截断 160 字）与 `lastTool`（最后一次工具调用 name + 结果首行，截断
  80 字、单行化），随 `SubagentRunView` 下发（零新增 RPC）。
- **前端**：运行中的子代理卡片显示两行活动线——「● 正在：…」（脉冲指示点）+「⚙
  工具名: 结果头」（等宽），随既有 5s 轮询刷新。
- 父子拓扑按候选清单建议暂不做（subagent meta 无父子记录，退化为「活动行 + 扁平列表」）。

## 修复

- **数据备份计划路径来源统一**（TestGaeaDataBackup* 隔离缺陷）：`dataBackupPlan` 此前
  混用 `DataRoot()`（尊重 GAEA_DATA_ROOT）与 `MemoryUserDir()/UserConfigPath()/
  SessionDir()/ArchiveDir()`（永远指向真实用户目录）——GAEA_DATA_ROOT 测试隔离时 zip
  会混入真实 Roaming/gaea 数据且产生相对路径穿越条目。统一从 `config.DataRoot()`
  派生全部条目（未设置 env 时 DataRoot == MemoryUserDir 等，生产行为不变）。
