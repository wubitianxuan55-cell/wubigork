# v4.73.0「记忆迁入主区标签页 · 记忆界面卡片化」

> 发布日期：2026-09-04 ｜ tag：`v4.73.0` ｜ 基线：v4.72.0 ｜ 绑定面 **561
> 零变更**（纯前端，Go 零改动）。

## 背景

用户点名：左侧面板「记忆」入口删除；主区「上下文」旁新增「记忆」标签页；
记忆界面整体重设计。记忆不再是浮层抽屉，而成为与对话/轨迹/上下文平级的主区
视图，布局与上下文页保持同一套卡片语言。

## 变更面

### 入口
- Sidebar：删除展开态与折叠态的「记忆」按钮（保留知识库 / MCP 与技能）；
- ChatTabs：新增「记忆」tab（对话/轨迹/上下文/记忆），type 收敛加 memory；
- 命令面板「记忆」与 `/memory` 斜杠命令：由开抽屉改为切主区记忆 tab；
- 历史 localStorage 选中 memory 可恢复；Esc 抽屉路由不再管记忆。

### 记忆界面（MemoryPanel → 主区卡片墙）
- 头部卡：记忆标题 + 「N 条已保存 · M 个文件」摘要 + 记忆/晨报预载开关；
- 快速添加卡：作用域下拉 + 一句话记忆 + 添加，保存路径就地提示；
- 分段标签卡：事实/文档/建议改为胶囊分段控件（TabButton 重设计）；
- 事实条目独立小卡（补卡片底色），文档/建议/归档沿用其既有卡样式；
- 外层由 drawer 浮层改为主区滚动页（滚动收敛根容器，无双滚动条）。

### 技术
- useDrawers 移除记忆状态；memView 上移到 App 层，写操作后统一 re-fetch；
- tab 激活「记忆」时自动拉取新鲜快照；drawer 相关死代码（closeMemory/
  onClose/drawer 外壳）删除。
