## 定位

「继续」= 欠账池收刀：v4.48.0 留下的两条青鸟侧候选线并行子代理执行（文件
所有权互斥：A 线 = WeixinPage 三件套；B 线 = characterlib Go+前端五文件），
主代理审 diff + 统一门禁收口。

## ① 编辑已有助手（A 线）

- 通道详情操作区新增「编辑」（aria-label `编辑 X`；核心锚点 gaea 不渲染——
  禁删禁停亦禁改）。
- 编辑弹窗：名字 Input（预填现名）+ 人格选择器。原 wx-pk 双栏 JSX 抽成同文件
  组件 `PersonaPickerPanel`（opts/query/sel/onQuery/onPick），新增/编辑两流
  共用 personaOpts（加载 effect key 改 `addOpen || editOpen`）。
- 语义细节：编辑流选中态 openEdit 时预填为当前 personalityId；自定义角色 id
  不在加载选项里时**保留原值不重置**（详情面板显示占位提示「当前人格不在可
  选列表中——将保留原设置」），只有用户点选才改变。
- 保存：`{ ...viewOf(row), name（空则原值）, personalityId: editSel || 原值,
  portraitUrl: 新选带立绘选项 ? 新立绘 : 原值 }`——立绘契约空值不覆写，绝不
  传空串；enabled/wxToken 等经 viewOf 完整透传。成功 message + 重拉两路数据。

## ② 角色卡一键创建青鸟助手（B 线前端）

- 角色库 custom 角色卡动作区新增「创建青鸟助手」（RobotOutlined，Popconfirm
  确认「以「X」为人格创建青鸟助手？」）→ WhisperAssistantSave 直建**未绑定**
  助手（id `wx_*`、name=角色名、personalityId=角色 id、enabled=true、
  portraitUrl 透传）→ 提示到青鸟板块扫码绑定 → onAssistantCreated 回调刷新
  角色列表。assistant/builtin 卡不显示（builtin 属轻语预设、assistant 已是
  镜像行）。

## ③ 镜像守卫（B 线 Go，真隐患修复）

- **隐患**：EnsureAssistants 对 Get(pid) 命中行无条件覆写 Name/Kind/AssistantID/
  ChatEnabled——v4.48 起助手 personalityId 可指向 custom 角色，下次启动该
  custom 角色会被镜像覆写（名字被冲成助手名、kind 翻成 assistant）。
- **修复**：命中行 `Kind == KindCustom` → 整行 continue（不改任何字段、不设
  AssistantID、不翻 Kind）；builtin/assistant 命中覆写与未命中新建影子行行为
  逐字不变；微信通道配置仍以 assistant 记录为唯一事实源。
- 用例：custom 角色被指向后字段原样保留（Kind/名字/无 AssistantID）+ 镜像
  行为不回归（builtin 命中覆写、未命中新建）。
