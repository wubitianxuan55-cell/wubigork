## 收口两刀

### ① 归档指针统一回显

`archived` 此前只在机械摘要回落路径出现，LLM 摘要成功路径不带——作者/agent 拿不到原文位置。`compact()` 现在统一注入：

```
Full transcript of the folded region: <archive-path>
```

原文永不丢，摘要只是视图（与小说线 8.3 组装器「正文永不压缩」同一口径）。无 ArchiveDir 时不出指针行（无路可指不伪造）。

### ② 压缩阈值暴露配置

`[agent]` 新增三键（TOML）：

```toml
[agent]
compaction_soft_ratio = 0.6   # 预警通知水位
compaction_ratio      = 0.75  # 触发压缩（调研建议 75%）
compaction_force_ratio = 0.88 # 强制压缩（调研建议 88%）
```

- 0 值 = 内置缺省 0.5/0.8/0.9（**不改内置缺省——存量实证优先**；调研建议的 75%/88% 经配置即达成）。
- 非法值（越界 [0,1] / soft≥ratio / ratio≥force 顺序破坏/水位重叠）**整组回落缺省**——部分信任的配置比全缺省更难排查。
- boot 两处 `CompactionConfig` 装配收编 `compactionConfig(cfg)` helper（主代理+技能子代理同源）。
