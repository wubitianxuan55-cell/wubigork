# v4.160.0 · 双代号分级横幅：一级/二级分区布局（2026-09-08）

> 用户以真实上报件《重庆干休所网络进度计划（开工）.pdf》为标杆反馈：双代号「一级、二级没有分级展示，比较混乱」，且文字/线宽/大小/线路布局都应是适配过的。解析标杆图（PyMuPDF 渲染逐象限目检）提炼其画法规律，照此重构双代号布局。零绑定 599。

## 标杆图（PDF）画法解析

- **每个分部工程一条横幅**：分部汇总线=横幅顶部通长线（分部名蓝色粗体标在线上），该分部的全部二级工序在横幅内左→右流动；
- **跨分部关系一律虚工作竖向衔接**（从上游带完成事件竖直引到下游带开始事件），分部内部才用 FS 链式合并事件；
- **交替底纹分带**（浅蓝/浅灰）、关键线路红色粗线贯通、自由时差绿色波形线、顶部工程标尺+月/日、底部星期/工程周。

## 本刀实现（v4.142 分级汇总箭线的布局层重构）

- **band 归属**：一级分组行（level 0）=一条横幅（bandLabels 按文档序）；事件归成员任务最小 band（跨组共用界点归前组，后组经衔接线接入）；组前未分组叶任务并入头部合成横幅；组后叶任务并入最后分组横幅（与 groupKids 轮廓语义同口径）；全无分组行=单一横幅（退化=旧行为）。
- **band 内保序打包**：沿用 layerByTime 全局重心行序为带内相对序（同列节点行号必不同，打包不产生同行冲突），band 间留 1 行空档容纳下一横幅顶部汇总线，y 首行预留半个行距；v4.159 行距自适应改为按打包后总行数计。
- **汇总箭线=横幅顶通长线**：新纯函数 `summarySegs(a,b,yTop)`（三段正交：竖起→横贯→竖落；退化同列直连），AoaView 与 networkExport 同口径接线；分部名在线上居中（bold）、工期在线下；归属带取两界点较大 band。
- **跨横幅不合并事件**（关键）：FS/SS lag=0 的链式合并限**同带**；非首横幅的无前置任务自设开始事件+START 虚工作补入。否则后学分部工作挂前学分部事件→任务边跨带穿行、名称标注压字（目检实锤：26 事件时「脚手架搭设」标签压「管沟土方开挖」）。重构后 34 事件/42 边，时间参数/关键判定零变化（0 工期虚工作不改变正逆推）。
- **交替底纹**：视图 SVG rect（`data-testid="sched-aoa-band-N"`）与导出 SVG 同步垫底（带顶=带内最小 y−ROW_H/2，带底=最大 y+ROW_H/2）。
