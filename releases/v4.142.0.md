## 1. 分级双代号重做（aoa.ts）

- **活动网络剔除分组行**：`acts = tasks.filter(t => t.level > 0)`（与 PdmView 同口径）——分组是汇总口径不是工作；搭接引用分组行按无效丢弃（UI 本就不允许建）。
- **汇总箭线**：轮廓配对（扁平大纲：level 0 行的子级=其后连续 level>0 行）→ 每分组取子级 startOf 中**事件最早时间最小**者为开始界点、endOf 中**最大**者为完成界点（时间并列取编号小者稳定）；产出 `kind:'summary'` 边（from=开始界点、to=完成界点、dur=界点时间差、taskId=分组 id、critical=false）。
- **不扰动计算**：汇总箭线只 append 到展示边集、不进 raws——正推/逆推/浮时/编号（i<j）全部只由二级工作决定；AoaEdge.kind 扩为 `'task'|'dummy'|'summary'`；taskEdge 登记分组 id（图面点击/选中联动可用）。
- **渲染**（AoaView+networkExport 同步）：深色粗线（--sched-group，同横道汇总条色）+深色箭头 marker+分组名加粗在线上、界点时间差在下方；无波形切点（汇总横跨子网络，波形无义）；导出图例加「一级汇总（界点衔接二级）」；图例注明口径。
- **测试**（aoa.test.ts 分级三件）：汇总箭线恰一条/共享界点事件/不新增事件（事件 es、ls 与纯二级网络逐项一致）/不扰动总工期；空分组无子级不出箭线、仅分组行=空图；跨分组搭接连成一张图、S/T 各恰一个、G1/G2 界点时间差 5/6。
- **边界（如实）**：分组行链入搭接本就被 UI 禁止；跨分组子网络若无搭接，仍经 START/END 虚工作汇成一图（一始一终规则）。

## 2. 横道列头压缩错位修复（GanttView+schedule.css）

- 根因：`.sched-gantt-row` 是 flex 容器、cell 无 `flex-shrink:0`；列头行直接挂在表格窗格（宽=effW）下而**不在** leftW 包裹层内——容器窄于列合计时列头被压缩，与数据行（有 leftW 包裹）永久错位。
- 修：列头行显式 `width: leftW` + `.sched-gantt-cell{flex-shrink:0}`——表格收纳时多余列被 `overflow:hidden` **裁剪隐藏**（用户期望口径），任何状态下列头与数据行逐像素对齐。

## 3. 双代号缩放/全览（AoaView）

- 长计划时标展开：141 天 × 110px/天 ≈ 1.55 万像素宽且此前无缩放——根本读不了。镜像 PdmView 刀E 范式：`scrollRef+zoom+touchedRef`，**首帧自动适配一次**（min(视宽/图宽, 视高/图高, 1.5)），−/＋ ×1.2 步进、全览按钮、百分比读数。
- 手动布点拖拽：屏幕位移 ÷ zoom 折算回图面坐标（zoomRef 同步），吸附/提交口径不变。
- **坑：TS2448**——useEffect 闭包引用其后才声明的 w/h 直接编译错；图面尺寸派生（wEarly/hEarly）提前到钩子前。
