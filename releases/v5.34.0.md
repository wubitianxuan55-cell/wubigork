## 后端 — 轻语语音管道

### 新增 `internal/asr/` — ASR 语音识别客户端

| 文件 | 说明 |
|------|------|
| `herdsman_asr.go` | HTTP 非流式 ASR，对接 Herdsman `/v1/audio/transcriptions`，支持 base64 + multipart |
| `herdsman_asr_stream.go` | WebSocket 流式 ASR，PCM16/16k 实时推送 → JSON 结果 |

### 新增 `internal/voice/` — 语音管道编排

| 文件 | 说明 |
|------|------|
| `voice_manager.go` | 状态机 idle→listening→thinking→speaking + RMS VAD + 打断机制 |
| `voice_config.go` | VoiceRuntimeConfig：VAD/PTT/Off 模式，静音/打断阈值，输入通道 |
| `emotion_voice_map.go` | 9 种 L2 情绪 → TTS 参数映射 + 29 种人格修饰 |

### 新增 Wails API

`internal/app/voice_handler.go` — 12 个 Voice* 端点：
`VoiceStart` `VoiceStop` `VoicePushAudio` `VoiceSetMode` `VoiceSetInputChannel`
`VoiceApplySettings` `VoiceGetSettings` `VoiceCancelTTS` `VoiceSetPTTActive`
`VoiceHealth` `VoiceRestartService` `VoiceGetState`

6 个前端事件通道：`voice:state` `voice:transcript` `voice:reply` `voice:tts-audio` `voice:tts-speak-text` `voice:tts-speak-cancel`

## 前端 — 语音管道

### 重写 `useVoiceChat.ts`

浏览器 SpeechRecognition → 后端 Voice* API 驱动：
- 麦克风 → AudioContext(16kHz) → ScriptProcessorNode → float32ToInt16 → VoicePushAudio
- 后端事件监听：voice:state / voice:transcript / voice:reply / voice:tts-audio
- AudioContext 播放 TTS，speechSynthesis 浏览器 fallback
- PTT 模式 + 打断机制

### ChatPage.tsx

- `onTranscript` → 用户消息 / `onReply` → AI 消息
- 打断按钮（AI 说话时显示）
- 状态文字："正在聆听..." / "AI 回复中..." / "准备中..."
- STT 标签: Herdsman whisper
