## 项目侧（本书 characters.json）

- **数据面**：`types.Character` 增 `ProtagonistRelation`
  （json `protagonist_relation`，2-8 字短语）——项目级字段。两路保护：
  GenerateProjectCharacterFill（库投影链路）与 CharacterSyncProject（库→项目
  物化）都按 ID 回带原值，补全/同步不清掉已生成关系。
- **生成**：新模板 `prompts/character-relation.json`（角色摘要 + 主角锚点 +
  已用关系避重 + 世界观四槽；输出 `{"relation":"2-8字"}`；must 禁把性格/剧情
  走向写进 relation）+ `GenerateProjectProtagonistRelations(mode, name)`：
  `all` 全部（除主角本人，覆盖重写）/ `missing` 剩余全部（只补空白）/ `one`
  个人（点名）。无主角卡诚实指路；主角本人友好报错；逐角色
  `protagonist-relation-progress` 进度。
- **消费**：`characterSummaryLine` 名册行注入「·与主角：X」（非空才渲染，
  旧数据零变化）——分支构思、章节计划、正文生成的角色名册自此携带关系。
- **UI**（角色面板）：头部「AI 主角关系」Dropdown（全部〔覆盖须确认〕/
  剩余全部）；角色详情抽屉「AI 主角关系」个人钮（主角本人隐藏）+ 关系
  Tag 展示 + 进度行。
