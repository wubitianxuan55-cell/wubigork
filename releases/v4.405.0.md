# v4.405.0 — WS 载入阶段进度可读化（排队/载入可见）

> 2026-09-23 发布。v4.404.1 分诊后续（用户拍板）。纯 Go 1 文件+前端 1 标签，
> 绑定面 **717 零变更**。规格：`进度计划/gaea-ws-load-progress-20260923.md`。

## 病根

20 分钟冷载期间界面零反馈：WS 只处理带 value/max 的 progress 事件，载入
阶段 value/max 恒 0 被 `Max>0` 过滤整段丢弃——用户无法区分「慢慢载入」和
「卡死」。

## 落地

1. **executing 事件**（节点开始执行，无百分比）：node 名经 nodeClasses 映射
   透出——载入模型/VAE 等阶段显示「当前节点: 加载模型」+不定态进度条+用时
   增长；node=null（整单结束）忽略。
2. **status 事件**（queue_remaining）：前有任务时显示「排队中（前有任务）」
   ——排队不再隐形。
3. **progress_state max=0 兜底**：优先报带进度节点；全无 max 退报 running
   节点名，不再整段丢弃。
4. 后端维持 class_type 契约不发中文，可读化由前端既有 COMFY_NODE_LABELS
   承担（+1 条「queue」标签）。
