## 变更

### Go
- `gaea_ui_contextview.go`：`GaeaSubagentContextView(sessionPath, ref)`——
  `ValidRunRef` 校验 → `sessionDirForPath` 定位会话目录 → 子代理
  transcript（`subagents/<ref>.jsonl`）经 `ReadLogRepaired` 直接读取
  （子代理 transcript 无 legacy 投影语义，不走 ReadEntriesFor 的路径派生）
  → 与主上下文同一 `FoldTimeline` 折叠。ref 非法诚实报错；transcript
  缺失返回空快照（前端空态）。

### 前端
- `ContextView`：增 `fetchTimeline`（自定义数据源，缺省仍走当前会话的
  `app.ContextView()`）与 `onViewSubagentContext`（透传 AgentRadial）。
- `AgentRadial`：增 `onViewContext` prop——sa_ 节点下方渲染「查看上下文」
  可点文字（`data-testid=agent-view-context-<ref>`，点击 stopPropagation
  防误触开对话）；无回调不渲染。
- `ContextModal`：增 `fetchTimeline`/`title` 透传（子代理态标题
  「子代理上下文 · <ref>」）。
- `App`：`ctxModalRef` 状态——主上下文页径向图「查看上下文」→ 记录 ref
  并打开弹层（fetcher=该子代理）；徽标与 /context 打开的主会话弹层
  ref=null（走当前会话）。关闭弹层即清 ref。
- 绑定三件套同步（bindingNames/spaceBindings 数量锁 277→278/bridge）。
