## 根修：绘梦板块整页崩（走查实证 P0）

- **症状**：进入绘梦板块整页崩进 ErrorBoundary——「页面渲染出错：Cannot read
  properties of undefined (reading 'toFixed')」（mock 与真机同构可复现）。
- **根因**：`GetSystemStats` 绑定契约是 `Partial<SystemStats>`（facade 类型即如此），
  api 层 `getSystemStats` 零归一化直透消费方；ControlPanel 的 `memUsed.toFixed()`
  在字段缺失/非数值时抛 TypeError，整页连坐。
- **根修**：api 缝合处归一化——数值字段 `statNum` 收窄（非有限数→0）、gpuName 非
  string→空串、null/非对象→null，消费方零改动拿到全字段。
- **测试**：新增 `api/image.test.ts` 五例（缺字段补默认/全字段透传/非数值收 0/
  null 与非对象→null/绑定抛错→null 契约不变）。

   重试成功退场）。
3. **schedule 亮色主题交互态不可见**（审计 Top2）：拖拽虚线 `rgba(255,255,255,.9)`
   与前锋线点描边 `#fff` 亮色白底画布上消失。拖拽虚线/前锋线点描边改
   `--md-sys-color-on-surface`（跟主题）；缩放手柄白芯加深色描边双保险（跨主题
   蓝/红/汇总条上均可见）；竣工线/前锋线 hex 收进 `--sched-deadline/--sched-front`
   令牌块（暗档原值零变化，亮档 violet-700/amber-700 加深治白底可见性）。
4. **MemoryHub 检索命中标签亮主题近不可见**（审计 Top3）：tailwind
   `text-sky-300/pink-300/emerald-300/violet-300` 暗底浅色系用于亮主题；迁移
   hub.css `.hub-hit-tag--*` 领域编码色类（暗档原值/亮档 -700 深色两档锁定，
   先例 schedule `--sched-*`）；检索失败标题 `text-red-400`→

6. **aria 补齐包**（审计 #2 类）：ToolbarButton 组件级加 `ariaLabel`（缺省回落
   title，五处消费点自动达标）；灯箱上一张/下一张、sin 删除故事、chat 发送、

   ModelCenterPage 分区按钮 `aria-selected`（非法角色上的 ARIA 状态）→
