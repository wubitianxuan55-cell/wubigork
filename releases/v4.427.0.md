## 清账九项

### 前端

1. **设定卡链入串行队列**（v4.426 立案）：`SinCastPanel` 生成设定卡改走 `illustrationQueue`
   （与流内插图/画廊重生成同一条队列）——此前三条链各自直发 ComfyUI，进度互相串台（两条
   进度条跳同一个百分比）、任一侧取消误杀另一侧的任务。排队中显示「前面还有 N 张」（不再
   错拿别人的 ComfyUI 进度）；取消按 token 制导：排队只摘自己的队位，在跑才中断后端。
2. **画廊/产物图内存上限**（v4.426 立案）：新模块 `sinThumbCache.ts` 给缩略图/大图/过程卡
   产物三处 data URL 读取统一加 16 条 LRU 缓存（热图留缓存、冷图重读盘）；面板收起时卸载
   卡体（`visible` 门控）——不再以 display:none 常驻整批缩略图。底稿草稿在面板 state、书源
   下载会话在模块单例，收起/重开均不受影响。
3. **ChatTabs 主 tab 语义**（v4.426 立案，办公共用组件双板块受益）：容器补 `role="tablist"`，
   主 tab 补 `role="tab"` + `aria-selected` + roving tabindex（仅选中项在 tab 序），
   ←/→/Home/End 键盘导航覆盖主视图与动态会话 tab。原罪页签条对读屏不再是三个无名按钮。
4. **sin 手风琴 aria 配对**（v4.426 立案）：五卡 `id`/`aria-controls`/`aria-labelledby` 全配对，
   ArrowUp/Down 竖向循环导航。
5. **Composer 排队跨故事清空提示**（v4.423 立案）：`key=activeId` 重挂会静默丢弃排队消息——
   补可选 `onQueueDrop` 回调（卸载时队列未清空如实上报条数），原罪页接 notice「排队的 N 条
   消息已随故事切换清空」。办公不传零影响。

   N 张图 = N×90s 首帧前干等；进度提示（v4.426）照旧。
9. **插图回写读-改-写锁 + cfg nil 守卫**（v4.426 立案）：`sinAttachMu` 串行化
