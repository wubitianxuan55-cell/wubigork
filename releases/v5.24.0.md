## 主要改动

### 🆕 DeepSeek 模型引擎接入

模型引擎中心新增 **DeepSeek 云端** 引擎卡片，支持通过 API Key 连接 DeepSeek 模型。

| 功能 | 说明 |
|------|------|
| 🔑 API Key 配置 | 输入 `sk-...` 格式 Key，持久化到 `~/.wubigork_config.json` |
| 🔍 模型拉取 | 通过 `GET /models` 获取可用模型列表 |
| 💬 Chat 调用 | `POST /chat/completions`，OpenAI 兼容格式 |
| 🔛 启停开关 | 控制引擎启用/禁用 |
| 🟢 状态指示 | 显示脱敏 Key（`sk-****abcd`）+ 未配置引导链接 |

**DeepSeek API 端点**: `https://api.deepseek.com`
**默认模型**: `deepseek-v4-pro`
**支持模型**: `deepseek-v4-pro`, `deepseek-v4-flash`
