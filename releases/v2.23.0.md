## 背景痛点（均有代码实证）

- costimport 只支持 xlsx/csv（costimport.go 实证）：PDF/图片报价单、票据无法本地识别入表，
  只能手工录入（2026-08-10 架构审查 P2 #9/#10，搁置至今）；
- 供应商比价靠人工翻抓取记录：无同品多源并排视图；
- 检索双入口：办公搜索面板（关键词 + 文件语义）与记忆中枢跨库语义搜索分开，
  一个查询要跑两个入口；检索质量从无量化（受控测评只测模型速度）。

## T5-5 成本库进料闭环（唯一能力补全项，属既有成本库模块内）

- **PDF/图片报价单本地识别入表**（GaeaCostImportVisionPreview）：
  - PDF 文本提取（docmd）→ 扫描件本地 OCR（OvisOCR2 → Windows OCR 兜底）；
    图片（png/jpg/jpeg/webp/bmp）直接本地 OCR；
  - 文本 → 表格线启发式解析（名称/规格/单位/价格表头行），回退整行解析；
  - AI 字段归一化走本地通道（sensitive_local 强制本地，数据不出机；不可用自动降级
    规则解析并在 message 注明）；
  - 复用 costimport 候选预览/确认流程（无确认不落库纪律不变），Preview.source 标记
    识别来源（pdf_text/pdf_scan/image）；
- **供应商比价**（GaeaCostCompare）：同品多源并排——库内现价/price_fetch 抓取候选/
  cost_price_history 历史快照三源聚合，相对现价跳幅 diffPct（复用 DetectAnomalies 算法），
  前端比价弹层按跳幅着色（≥20% 红 / >5% 琥珀 / 否则绿）。

## T5-6 检索统一与质量回归

- **统一检索入口**（GaeaUnifiedSearch）：一次调用同时出关键词命中 + 跨库语义命中
  （GaeaSemanticSearch 已跨 cost/knowledge/office/file，v2.18），前端办公搜索面板
  「跨库」模式单框出两组结果；原绑定保持兼容；
- **检索质量受控测评**（GaeaRetrievalEvalRun）：真实业务查询集
  （docs/retrieval-eval-set.md，造价/工程办公域 10-15 条 + 预期命中标注）→ 逐条
  Recall@10 → 汇总 recall@10，门槛 0.8；模型中心「检索质量」区一键运行 + 明细表；
  补上「受控测评只测速度、不测召回」的缺口。
