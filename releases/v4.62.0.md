## A · 子代理逐 token 流式（P1 销账）

- **event 包新增 `SubagentText`**：Text=增量块；SubagentRef="sa_..."（前端
  路由到对应会话 tab）；ParentToolID=父 task 调用 ID。**wire-only**：
  EventLogSink 有意不落主会话日志——增量全文已由 SubagentMessage 收尾 +
  子代理自身 transcript 落盘承载，逐块落主日志只会膨胀体积、污染恢复/派生
  重放。
- **task 路径**：subSinkFor 增 refSrc 闭包（subSink(ctx, run) 三调用点），
  持久化子代理的内层 Text 增量转标 SubagentText 透传父 sink；无 ref（临时
  子代理/测试）维持既有有意丢弃，防过程噪音进主聊天。
- **run_skill 路径**：RunPersistedSubAgent（run 在函数内创建、外部 NestedSink
  拿不到 ref）在 sink 外层 refTextSink 注入 ref；subSinkFor 见 SubagentText
  只补 ParentToolID 透传。两条路径殊途同归。
- **wire 映射**：gaea_handler 增 `subagent_text`（text/subagentRef/parentId），
  对齐 SubagentMessage 的 wire 形态；主聊天 reducer 对未知 kind 整条丢弃，
  流式不会误入主对话。
- **前端 SubagentThread**：挂载期常开订阅（按 subagentRef 匹配本会话），
  增量进流式缓冲，以「正在打出的字」实时行渲染（MemoMarkdown streaming，
  同主对话语言）；**快照接管 reconcile**——每次 transcript 拉取成功后，若
  快照尾条已含缓冲开头（快照追上流）或快照长过了缓冲基线（新消息已落盘），
  缓冲清空交给权威渲染，天然消除第二轮文本接尾问题；断流由既有 3s 轮询 +
  工具边界补拉兜底。
- 测试：Go agent 包 4 用例（转标/无 ref 丢弃/父 ID 打点/refTextSink）+
  session 包 1 用例（免落盘、inner 照收）；vitest SubagentThread 流式用例
  （ref 路由/逐块追加/他人会话隔离/快照接管清缓冲）。

## B · Word 修改队列（Genspark Send N edits 式）

- **纯逻辑 docxAnnotationQueue.ts**：队列状态机（条目增删改查/同摘录同指令
  归一化去重合并/状态迁移白名单，done 终态重跑须重新入队）；摘录归一化 +
  locateExcerpt（空白收敛坐标映射回原文；多处命中取第一处但 unique=false
  如实上报；找不到返回 null 绝不猜位）；runQueue 串行编排——每条执行前对
  **最新文档全文**再定位（前一条替换后位移以真实写回结果为准），定位不到
  skipped、生成/写回失败 failed 继续下一条，结束给 QueueRunSummary。
- **DocxPreview 集成**：框选工具栏「加入队列」（预设动作/自定义指令皆可，
  与单条「生成→应用」并存零功能删除）；队列侧栏（与目录侧栏同交互档次：
  条目摘录缩略+指令+状态徽标+错误/歧义说明、单条移除/重试、执行进度 n/m、
  结束汇总）；「执行全部」逐条走既有 OfficeEditText → DocxApplyEdit →
  DocxAcceptChanges(accept=true) 通道——**修订制兜底不变**，写回即修订，
  逐条自动接受避免待定修订堆叠干扰下一条定位（接受失败不回滚，可手动处理）；
  与单条框选即改互斥（两边写同一份文档）。
- 走查受限口径：jsdom 集成测试全程确定性驱动（stub 框选 + 真实 zip 重建
  docx 供再定位），覆盖实机 ?mock=1 做不到的批量链路（真实 docx 与 AI 通道
  缺席）；2 用例含「幽灵摘录 skipped 且生成通道零调用」的防错位断言。

## C · xlsx/docx 版本结构化对比（收 unsupported 欠账）

- **docxTextDiff.ts**：两侧段落序列（extractDocxParagraphs，jszip+DOMParser
  同 docxOutline 套路）做段级 LCS diff；表格每格按独立段落计（聚合会把
  「改一格」放大成「改整表」）；段内改写如实呈现为相邻 del+add 对；空段落
  参与差异（版面结构不被吞）。
- **xlsxCellDiff.ts**：sheet 按名对齐（新增/删除整表如实标记，不逐格罗列）；
  同名 sheet 单元格按 ref 对齐 add/del/change（公式串当文本如实比较，不做
  求值语义）；输出按行号→列号自然阅读序；每 sheet 变更列表超上限截断但
  计数不失真（truncated 标记）。
- **versionCompare.ts**：compareVersionWithCurrent 按扩展名分派 text/docx/
  xlsx；docx 取数经 app.Preview dataUrl、xlsx 经 Preview 结构化 body JSON；
  结构不可信（抛错/kind 不符/无 dataUrl/body 非 JSON/解包失败）整体降级
  unsupported 宁漏勿误；一侧 size 0 照常 diff 并标 contentMissing。
- **VersionTimeline.tsx**：docx 走既有行级 diff 块（附段落序号列，折叠/
  展开全部沿用）；xlsx 独立对比体（sheet 分组 + 单元格表 + 整表增删徽标 +
  「仅展示前 N 条」提示——数据已截，不提供展开）；text/unsupported 渲染
  路径不变；diffstat 芯片消费两类新结果。
