# v4.4.0「触点」· 微信遥控器一期：离线代办 (2026-08-30)

> git tag `v4.4.0`；基线 v4.3.2（双翼·中庭）。本版为路线图 §10.4 v4.4「触点」
> 第一刀：**微信从「能聊天」升级为「能接活的遥控器」**。个人小号 ClawBot iLink
> 通道已具备扫码登录/长轮询/文本收发（此前只做被动问答），本版补齐「任务化」
> 第一档——**离线代办**：在微信里对助手说「提醒我 …」，桌面端解析建提醒、
> 到点经微信回推。官方元宝等云端助手做不了桌面常驻定时回推，这是桌面 agent
> 独有的差异化能力。

## 微信主动推送通路（clawbot.go）

- `Server` 新增最近活跃会话记忆（`lastFromUser`/`lastContextTokn`，handle 收到
  消息时更新）+ `LastPeer()` / `Push(text)`——向最近一次发来消息的会话主动
  回推文本。个人小号单用户场景足够；多联系人由多助手实例隔离。
- `Push` 在无活跃会话（启动后无人发过消息）时报错，由上层决定重试/标记失败。
- httptest 注入 ILinkURL 校验：sendmessage 请求体的 to_user_id/context_token
  与文本 item（type 1）精确命中（3 测试）。

## 离线代办提醒域（weixin_reminder.go）

- **中文时间解析** `parseReminderWhen`（表驱动 20 用例）：
  - 相对时长：「30分钟后」「2小时后」「三个小时后」「2天后」；
  - 日期前缀 + 时刻：「明天早上9点」「明晚8点半」（明早/明晚/今晚预处理拆词，
    避免段词被日期前缀吞掉）「后天十点」（中文数字含「十」进位：十=10、
    二十三=23）「全角冒号 14：30」；
  - 裸时刻：「18:30」「下午三点」「明天9点15分」。无段词按字面解释（不做
    「2点半猜下午」玄学启发式），确认回复带完整时间供用户纠正；
  - 显式「今天 + 已过时刻」返回 stale，回确认询问不误设；裸时刻已过顺延明天。
- **事项提取** `stripReminderText`：剥离触发词（提醒我/记得/叫我…）与时间表达，
  「提醒我 30分钟后 喝水」→「喝水」。
- **任务路由** `tryWxReminder`：消息含「提醒/叫我」即接管——解析成功落盘回
  确认（「好，已设提醒：喝水（9月1日 10:30）——到点我用微信叫你」）；解析失败
  回格式提示（不坠入闲聊）；其余消息照常走 `WhisperChatWithSearch`。
- **持久化**：`<whisperDataRoot>/weixin_reminders.json`，重启恢复；done 不重推。
- **到点回推**：20s ticker 扫描 pending 且到期 → `wxPushFn`（默认
  `weixinServers[assistantID].Push`，测试注入）→ 成功标 done；连续失败 ≤5 次
  重试，超限标 failed 不再推送。
- **配置**：`remindersEnabled` 开关（默认开），`weixin_task.json` 持久化；
  关闭后路由不接管、ticker 空转。

## WeixinPage 落地（书房触点）

- **扫码绑定流**：`WhisperWeixinGetQR`（dataURL 二维码）→ 2s 轮询
  `WhisperWeixinQRStatus`（waiting/scanned/confirmed；need_verifycode 时输入
  手机配对码走 `WithCode`）→ confirmed 后 `WhisperAssistantSave` 更新核心助手
  gaea 的 WxToken/WxBotID/WxUserId（upsert，后端自动重拉通道）。
- **通道状态**：助手列表运行中/会话过期/未绑定徽标 + 过期 Alert（引导重扫码）；
  可见时 5s 轮询（pollingGate，keepAlive 隐藏空转）。
- **离线代办面板**：提醒列表（待触发/已推送/推送失败 Tag + 触发时间 + 重试
  计数 + 微信下达来源）+ 手动新建（事项 + DateTimePicker → RFC3339）+ 删除 +
  回推开关。
- **板块挂载**：`builtins.go` weixin 板块 `Page:"WeixinPage"`、`inMenu=true`
  （rail + 首页左翼书房格自动派生——双翼由 manifest 派生的既定设计）；
  `LAUNCHER_DESC` 补文案；main.tsx 注册 lazy 页面。

## 已知边界（如实记录）

- **回推目标 = 最近活跃会话**：到点回推走助手最近一次收到消息的会话；若建提醒
  后有人在其他会话给同一小号发消息，回推会落到后者（个人小号单用户场景可接受）。
- **微信会话过期期间**（-14）回推失败并按重试计数处理，重新扫码后恢复。
- **图片/文件卡片未做**：iLink 协议文本 item 已验证，图片消息收发格式待探明
  （v4.4.1 触发生图/办公任务回推文件时一并处理）。
- LLM 意图路由（触发已有能力的通用任务化）留后续刀；本版触发词路由 + 聊天
  fallback 已覆盖提醒场景。
