## Step 1 app 层接线 —— 会话事件日志运行时「日志即真相」（a9254c8）
- **Resume→Restore**：Controller.ResumeFromDisk 事件模式下先 DetectLegacy→MigrateLegacyToLog 再 LoadWithFormat("event") 走 checkpoint + log tail 重放；legacy 模式保持原 LoadSession+Resume
- **Save→日志**：session.Save 事件模式双写（legacy 镜像逐字节同旧行为 + 确保事件日志存在/迁移）；新增 LoadWithFormat / AppendUserMessage / AppendSystemMessage / LastLogSeq / NewFromRestore
- **模型调用前 flush（fail-closed）**：executor.SetCheckpointFlusher + FlushCheckpointFailClosed——写检查点失败中止回合，绝不带着未持久化状态调用模型；回合后 Snapshot 内 flushCheckpoint 刷新压缩后消息投影 + 已消费 log seq（压缩→checkpoint）
- **回退开关**：session.log_format="legacy|event"，gaeaBuildController 注入 SetLogFormat；legacy 零行为变化
- 新增 2 测试文件（event_mode_test.go / controller_eventlog_test.go，含压缩后 checkpoint 可恢复）
