## UI 面（线 B/C/D 新组件 + 主代理布局收口）

v4.67 的双栏+tab 驾驶舱按用户意图改为 **dsh 全宽网格仪表**（信息全部同屏）：
- **行1 四仪表卡**（context/cards.tsx）：上下文统计 4×2 八格 ｜ Token 统计
  （SVG 环形缓存命中% + 缓存输入/未缓存输入/输出三分解，requests 汇总）｜
  耗时统计（环形活跃时长 + 模型等待/模型生成/工具执行/其他开销分解 + tools
  top3；数据未就绪诚实全「—」）｜ 会话信息（会话名/空间/模型/窗口/请求数）。
- **行2 双列**：当前上下文宽卡（大数字 + 分段条含**灰色空闲窗口段** + pct
  大字 + 工具结果占比标注 + 图例）｜ 上下文浏览器（context/inspector.tsx
  ContextBrowserTree：六分类**折叠组** + 项数徽标 + 行内搜索 + 归档组 +
  >200 项分页）。
- **行3-5**：趋势图（保留）→ 步骤详情就地联动 → 事件流 ∥ 文件活动聚合树
  （ContextBrowserTree 同文件 FileActivityTree：按文件聚合 + 读写次数徽标 +
  按次数/最新/路径三排序 + 路径过滤）。
- **行6**：Agent 网络径向树（context/AgentRadial.tsx：SVG 中心主 agent 占用
  环 + 子代理放射节点 + 彩色连线 + 单/双圈布局；数据走 agentNetworkStore）。
- **底部**：会话汇总条（会话徽标+水位+请求数+累计费用+七分类图例）+ 估算
  口径页脚（对齐 dsh 页脚语义）。
- i18n 收口：cards/inspector/AgentRadial 全部 t() 化（三语 +47 键）；
  删除 v4.67 的 inspector tab 与旧 ContextBrowserCard/FileActivityCard/
  ContextHeader 死代码。
