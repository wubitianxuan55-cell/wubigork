# v4.75.0「右侧任务面板卡片化：子代理独立卡 · 运行状态」

> 发布日期：2026-09-04 ｜ tag：`v4.75.0` ｜ 基线：v4.74.0 ｜ 绑定面 **561
> 零变更**（纯前端）。

## 背景

用户点名右侧任务面板「看上去就是一个文件树」，并提供参考截图：每个子代理
应有自己的标题、卡片与运行状态。本版将 AgentTree 从单行紧凑树行升级为
参考图同构的子代理卡片流（不复制其代码高亮细节，只取信息架构）。

## 技能参考

- ds-vision-skill：读取参考截图，确认「独立卡片 + 标题 + 状态/角色 + 实时
  动作 + 耗时/token 指标」结构；
- redesign-existing-projects：审计发现卡片背景与面板同色、行间距不足导致
  视觉上仍是列表；按「表面抬升 → 分组 → 状态反馈」修正；
- gaea MASTER 设计体系：语义令牌、antd 图标体系、reduced-motion。

## 视觉改造（功能零删减）

- 每个子代理（含主 agent）是独立圆角卡片：表面抬到 surface-container-high，
  卡片间距 gap-2，父子层级用缩进保留；
- 卡片标题行：任务名 + 状态胶囊（进行中/已完成/失败，语义色）；
- 指标行：模型徽标 / ⚙工具数 / 实时已用或总耗时 / ≈tokens / 错误数；
- 运行中卡片：glow 语义描边 + 「正在：…」+「⚙ lastTool」实时动作预览；
- 已完成/失败卡片：有分工回答摘要时展示摘要块；
- 主 agent 根卡：主色弱化底 + 状态胶囊，视觉上为整棵树的「头卡」；
- 交互不变：展开/收起子树、点击卡片标题区打开子代理对话全面板。
