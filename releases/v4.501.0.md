## 蒸馏口径（取道不取器）

官方模板是 subgraph 包裹的 UI 图（含 ResolutionSelector / 提示词改写支路 /
MarkdownNote），展开后蒸馏为 API 图：

```
UNETLoader(qwen_image_2.1_turbo_int8_convrot) → [LoRA 链] → QwenImage21Cache(auto/default)
  → CFGGuider(cfg 1.0) ─┐
CLIPLoader(qwen3vl_8b_int8_convrot, type=qwen_image) → TextEncodeQwenImage21
  （单节点双编码：输出 0=正 / 1=负 conditioning；负向词透传）──┤
EmptyLatentImage(请求宽高) + RandomNoise + KSamplerSelect(euler)
  + ManualSigmas(官方 8σ 表) → SamplerCustomAdvanced → VAEDecode → SaveImage
```

- **负向词透传**：该族模板原生带 `negative_prompt` 输入（同一 TextEncode 节点双出
  conditioning），与 krea2/z-image「txt2img 负向恒 ZeroOut」的历史口径不同——按模板
  如实透传 `req.Negative`。
- **步数不开放**：官方 σ 表（`ManualSigmas` 9 值 = 8 步）按 turbo 权重蒸馏，步数参数
  不进工作流（同 flux 固定 4 步的先例）；Warmup 空跑与真实生成共用同一构建器。
- **官方可选件不接**：`TextGenerate` 提示词改写支路（PE 模型
  `qwen3.5_9b_*_pe_t2i` 另需 9.5GB，模板默认 `switch=false` 直通原文——绘梦的提示词
  由上层 LLM 组织）；`image_qwen_image_2_1_turbo_image_edit` 模板不接——指令编辑/
  参考编辑仍单引擎走 Qwen-Image-Edit 2511（`buildQwenImageEditWorkflow`）。
- `TextEncodeQwenImage21.resolution` 只作用于参考图重标，本工作流不传参考图，保持
  模板默认 1024（latent 由 EmptyLatentImage 按请求宽高给出）。
