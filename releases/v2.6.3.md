# gaea v2.6.3「CosyVoice2-0.5B 本地音色克隆接入」发布说明（2026-08-08）

> 本版把刚下载的 CosyVoice2-0.5B 接进模型中心：本地跑一个 OpenAI 兼容 TTS 服务，
> 「功能绑定 → 聊天语音」可绑定 CosyVoice2，支持 7 个内置音色 + 参考音频零样本克隆。

## 一、CosyVoice2-0.5B 本地部署

- 模型已下载至 `C:\Users\wubi\CosyVoice2-0.5B`（约 5.2GB），服务跑在 `http://127.0.0.1:8010/v1`
  （CosyVoice v2.0 代码 + Python 3.11 venv，服务脚本 `C:\AI\cosyvoice\server.py`）
- 内置音色表 `spk2info.pt` 由 edge-tts / qwen3-tts 参考音频零样本克隆生成：
  中文女、中文男、英文女、英文男、日语男、粤语女、韩语女
- 服务接口：`POST /v1/audio/speech`（OpenAI 兼容）、`GET /v1/models`、
  `GET /v1/audio/info`（音色列表）、`POST /v1/voices`（上传参考音频注册新音色，持久化）

## 二、gaea 接入

- 模型中心新增「CosyVoice2 (本地)」引擎（`cosyvoice`），内置 `CosyVoice2-0.5B` 语音模型；
  「语音模型」页可直接设为全局语音合成，「功能绑定 → 聊天语音」可选择绑定
- 设置面板/聊天设置新增 CosyVoice 音色选择器（实时从 `/v1/audio/info` 拉取）；
  无效音色自动回退「中文女」，`tts_voice` 持久化
- 语音管线走 HerdsmanTTS 兼容客户端（OpenAI `/v1/audio/speech` + data URI 解码），无需新增协议

## 三、实测

- 直连服务：`好的，晚安。` 合成 6.5s → 0.92s 音频（RTF 6.8x，PyTorch CPU）
- gaea 客户端端到端：38KB wav + 7 音色列表正常
- `go build` / `go test ./internal/{tts,modelengine,app}/...` 全绿；`tsc` + `vite build` 通过
- `wails build` 成功：`build/bin/gaea.exe`；校验和：`releases/SHA256SUMS-v2.6.3.txt`

## 四、使用提示

- 需要先启动 CosyVoice 服务：运行 `C:\AI\cosyvoice\start_cosyvoice.bat`（开机后需手动启动，约 10 秒加载模型）
- 速度预期：比 qwen3-tts（约 3s）和 xAI/edge-tts（约 1.4~2.4s）慢，适合追求音色克隆/本地离线的场景；
  后续可尝试 ONNX + DirectML 优化声码器与流解码
- 上传参考音频可注册自定义音色（`POST /v1/voices`），注册后重启服务仍保留
