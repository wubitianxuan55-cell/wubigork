## 🎙️ 语音聊天功能

- **粒子光球**（VoiceChatOrb）：80 粒子 Canvas 动画，音量驱动扩散/光晕/脉冲环
- **语音输入**：浏览器 SpeechRecognition API，实时识别中文
- **静音检测**：2 秒无语音自动发送
- **模型链路显示**：语音界面显示 🎙️STT → 💬LLM → 🔊TTS 当前模型

## 🔊 AI 消息朗读

- 每条 AI 回复右下角新增 🔊 朗读按钮
- 点击直接 TTS 播放，播放中显示 loading
- 后端 `TTSSpeakBase64` 直连 Herdsman TTS（qwen3-tts-customvoice）
- 新增 `internal/tts/herdsman.go` — Herdsman TTS 客户端

## 🏗️ 模型中心重构

- 侧边栏新增「引擎管理」tab，引擎开关独立管理
- 模型自动分类：LLM / TTS / STT / Image（按 ID 关键词识别）
- 非 LLM 模型卡片不显示误导性「启动」按钮
- 图片区自动发现图片模型（zimage-turbo 等）
- 模型状态从 API 真实读取（不再写死 running）

## 🚀 三引擎自动刷新

- 启动时 xAI + Herdsman + Ollama 三个引擎自动刷新模型列表
- Ollama / Herdsman 默认启用
