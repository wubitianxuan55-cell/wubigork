## 论点

gaea 的 20 个 `prompts/*.json` 是「磁盘 + embed 兜底」的只读两层——用户改不了
（改了也会被下次发版覆盖）；占位符只有 `{word_count}` 一处硬编码字符串替换；
模板保存零校验（MuMu §9.3 同型缺陷：裸 `str.format()` 缺变量即崩）。
本刀补齐 t6 域核心缺口：**全局覆盖 → 磁盘 JSON → embed JSON 三级解析**、
`{{name}}` 命名占位符渲染（缺失保留原文不抛错）、保存时真校验（error 阻断 /
warn 提示）、小说创作间「提示词工坊」面板。

对 MuMu 的升级与裁剪（规格 §1/§2）：

- 升级：覆盖存储走 `<DataRoot>/prompt_overrides.json`（taskinbox 同款容错读 +
  原子写，不上 SQLite 三表）；校验保存时做真；`{{name}}` 语法避免 JSON 字面花括号
  炸链路；列表接口零正文下发（MuMu 1.74MB 全量下发教训 §9.2）。
- 裁剪：云端社区工坊三表/审核流/X-Instance-ID 信任模型整域不做（单机无多租户）。
