# v4.515.0 · 弹层键盘可达轮：回退菜单与图表菜单补齐 ARIA 菜单模式（Escape+方向键漫游）（2026-10-21）

> 弹层的键盘可达性：既有 20+ 处 Escape 覆盖良好（Composer 三菜单/工作区

## 缺口与落地

- **①回退菜单（UserMessage，办公板）**：v4.510 修好锚定与死键后菜单
  首次真正可用，但只有鼠标路径（点击开/外点关）——Escape 无响应、无
  菜单语义。补齐：
  - Transcript 外点守卫效应扩展 keydown 监听：Escape 与外点同状态关闭
    （document 级，覆盖焦点在触发钮/菜单项两态）；
  - 菜单容器 onKeyDown 方向键漫游聚焦（roving focus）：↑↓ 循环 +
    Home/End；
  - `role=menu` / `role=menuitem` + 触发钮 `aria-haspopup="menu"` /
    `aria-expanded` 契约；菜单项本就是真实按钮（Tab 可达）。
- **②XlsxPreview 图表菜单**：`role=menu` 却只有外点关闭（ARIA 菜单
  模式要求键盘可操作）——补同款 document 级 Escape + 方向键漫游。

## 契约同步

菜单项挂 `role=menuitem` 后覆盖隐式 button 角色——v4.510 回归测试的
作用域项查询从 `getByRole("button")` 同步为 `getByRole("menuitem")`
（结构契约锁的正是这类角色变化）。
