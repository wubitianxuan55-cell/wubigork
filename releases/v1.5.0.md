## 🎯 微信 ClawBot 通道接通（本版核心）

v5.72 实现微信通道但从未真正跑通：扫码绑定后微信发消息无回复。本版经多轮排查修复，**用户实测全链路打通**：

```
[weixin] 收到消息 from=o9cq...@im.wechat len=6   ← 微信消息收到
[whisper] WhisperChat done replyLen=75           ← AI 生成回复
（无错误）                                        ← 回复发送成功
```

### 根因链条（按修复顺序）

1. **认证头缺失**（`41d2a4a` 前的核心问题）：
   - `Authorization` 必须 `Bearer <token>` 前缀（原为裸 token）
   - 补 `iLink-App-Id: bot` + `iLink-App-ClientVersion` 头
   - getUpdates 端点全小写 `/ilink/bot/getupdates`
   - 效果：getUpdates 从"会话过期"（errcode -14 每 5 分钟一次）变为 200 正常轮询

2. **消息字段名错误**（`ea6fc2e`，最终根因）：
   - 社区 Rust SDK 用 `item_type`，**腾讯官方 openclaw-weixin 用 `type`**
   - 曾对齐 Rust 误改成 `item_type` → getUpdates 其实收到了消息，但解析不到文本，
     `handle` 静默丢弃（text=="" 直接 return，无日志无回复）——"轮询活跃但收不到"的假象
   - 对齐腾讯官方（`Tencent/openclaw-weixin` src/api/types.ts + messaging/*）后立即可用
   - client_id 格式：`{prefix}:{ts}-{hex}`（如 `gaea-weixin:1752...-a1b2c3d4`），非 base64 UUID
   - `iLink-App-ClientVersion` 是**数字编码** `buildClientVersion("2.4.3") = 132099`，非版本字符串

3. **扫码绑定流程补全**（`afd3880`）：
   - 官方状态机：`scaned`（少 n）/`scaned_but_redirect`（需重定向）/`need_verifycode`
     （手机配对码）/`verify_code_blocked`/`confirmed`/`expired`
   - `need_verifycode` 需配对码 + `verify_code` 参数二次查询（新增 `WhisperWeixinQRStatusWithCode`）
   - confirmed 返回**完整** bot_token + ilink_bot_id（可直接用于认证）

4. **会话过期可见性**（`41d2a4a`）：`Server.SessionExpired()` 透出，UI 显示"微信会话过期 · 需重新绑定"
   替代虚假的"在线"绿点

5. **防脱敏 Token**（`41d2a4a`）：前端保存含 `*` 的占位 token 用原值；后端含 `*` 拒绝

6. **助手名字注入**（`bd95f58`）：`BuildAckemCanonBlock` 名字参数化，`Orchestrator.AssistantName`，
   微信 chatFn 设置 `ast.Name`（如"峨嵋"）——AI 不再自称默认"轻语"

### 关键协议要点（已入记忆 weixin-ilink-tencent-official-fields）

- 权威参考：**腾讯官方 Tencent/openclaw-weixin**（GitHub），社区 Rust SDK（SpenserCai）字段不可靠
- 认证：`Bearer <token>` + `iLink-App-Id` + `iLink-App-ClientVersion`（数字）
- 消息：`item_list[].type`（type=1 文本）、回复带 inbound `context_token`、`from_user_id` 传空
- 扫码：状态机含 need_verifycode/scaned_but_redirect；每次扫码创建**新 bot**，旧 bot 立即失效
- 发送：`sendmessage` 200 但用户收不到 = bot 无主动发送权限，只能回复（用户先发）

### 使用说明

1. 轻语 → 人格切换 → 助手管理 → 编辑助手 → 扫码绑定微信 ClawBot
2. 若弹配对码输入框，看手机微信上的配对码输入提交
3. 绑定成功自动填入完整 Token + Bot ID，保存后通道启动
4. 微信里给该 bot（如"峨嵋"）发消息 → AI 自动回复

## 已知限制

- 一个助手 = 一个微信 bot（独立扫码绑定）
- 同人格多助手共享会话状态（不推荐；需按 assistantID 隔离 Orchestrator 才可支持）
- 并行上限：60 个人格 = 60 个互不干扰的助手
