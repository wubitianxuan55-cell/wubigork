## 落地

1. **刀1 上下文页 UI 优化**（信息层级，功能零删减）：
   - 行序重排：「当前上下文」hero 卡从行3 提到行1（进页即答「用了多少」，与
     空态头部一致）；趋势卡升至行2；Token/耗时/会话信息三仪表卡行3；
     浏览器+事件流行4；文件活动+Agent 网络行5（两者皆在时并排）；
     8 统计小卡（审计口径）下移行6；汇总条收尾。
   - 窗口未知诚实化：window=0 时 hero 百分比与汇总条显示「—」（新 i18n 键
     `contextview.windowUnknown`，en/zh/zh-TW 三份），不伪造 0%。
   - 趋势柱悬停可感知：delta 柱 hover 主色描边、堆叠柱 hover 提亮
     （brightness 1.2），对齐「hover 即有反馈」的交互底线。
2. **刀2 原罪复用**（后端折叠 + 前端原组件）：
   - 后端 `internal/app/sin_insight.go`：落库消息 + extra（reasoning/tools/
     illustrations）折叠成与办公同构的 Trajectory/ContextTimeline。
     轨迹=user 起轮、工具轨迹按 extra 还原在回复前、轮耗时按秒级时间戳诚实
     （同秒为 0 不伪造）；上下文=逐请求累计（每轮=system+角色卡/底稿注入+
     截至该轮全部落库内容，与 buildSinUserPrompt 全量前情语义对齐）、
     delta 逐类 signed、brief 锚点接浏览器跳转、工具耗时排行入 timing。
     节点编址确定性：消息 ID×10+槽位（0=user、1..8=tool、9=assistant；
     system/底稿/角色卡=1/2/3 固定槽不可展开详情，与办公同口径）。
   - 组件接缝：TrajectoryView 增 `fetchTrajectory`、ContextView 增
     `fetchNodeDetail`/`spaceOverride`/`showAgentNetwork`（原罪关闭——网络属
     办公内核会话，不订阅不拉取防串台）、ContextBrowserTree 透传
     `fetchNodeDetail`；ChatTabs 增 `tabs`（子集）/`labelOverrides`
     （原罪主签显示「故事」）/`className`。
   - 原罪页接线：中栏 ChatTabs 三页签（故事/轨迹/上下文）；轨迹/上下文页签
     不渲染 Composer；sin.css 补 `.sin-tabs`/`.sin-insight-host`。
   - dev mock 同规则内存折叠（浏览器走查三页签全可走查）。
