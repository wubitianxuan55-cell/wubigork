# v4.22.0「一次性收官 · 真虚拟化 / transcript 定位 / 晨报预载 UI」

> 发布日期：2026-08-31 ｜ tag：`v4.22.0` ｜ 基线：v4.21.0（同工作区，未打 tag）

## 背景与过程

用户要求「一次性做完」：把办公板块剩余的全部本地可做欠账一次清完，并整理
提交收尾。本刀三件事：轨迹**真虚拟化**（替换 v4.21 的分批 DOM）、transcript
消息**定位/跳转**（序号 + 搜索命中自动滚动）、晨报预载 **UI 开关**（v4.16
欠账）。

## 交付明细

### ① 轨迹真虚拟化（react-window v2 动态行高）

- 引入 `react-window` v2.3 的 `List`：扁平行流（轮次头 + 展开记录 +
  Between-turns）按**视口窗口渲染**（±overscan 12），超长会话 DOM 恒定，
  v4.21 的「首批 250 + 加载更多」分批机制退役。
- 动态行高：`useDynamicRowHeight` + ResizeObserver 实测——记录展开/收起时
  行高变化自动重排；jsdom 无布局时回落 defaultRowHeight（29px）。
- 概览跳转改走 `listRef.scrollToRow`（目标轮展开 + 平滑滚动到行）；搜索词
  变化自动回顶；收起全部/展开全部在虚拟流上照常生效。
- 测试基建：`src/test/setup.ts` 补 ResizeObserver stub（react-window 内部
  无守卫使用），全量测试不受影响。

### ② transcript 消息定位/跳转

- 每条消息带序号（#N，按原 transcript 位置）；搜索命中时自动滚动到第一条
  命中消息（`scrollIntoView`），计数仍显示「命中/总数」。

### ③ 晨报预载 UI 开关（+2 绑定）

- 后端：`GaeaMorningPreload() bool`（读 ~/.gaea_config.json morning_preload，
  默认开）+ `GaeaSetMorningPreload(enabled) error`（`internal/config.Save`
  持久化 + 内存更新 + 重建办公引擎即时生效）；gen_bindings 重生成，
  绑定面 546→548。
- 前端：记忆面板头部新增「晨报预载 开/关」胶囊按钮（与记忆开关同款交互，
  切换 toast 提示）；mock/bridge/spaceBindings/bindingNames 同步。
