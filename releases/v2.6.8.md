# gaea v2.6.8「模型中心一键启动本地 TTS 服务」（2026-08-09）

> 本地 TTS 不再需要手动运行启动脚本：gaea 启动时自动保活 CosyVoice2 / VoxCPM2，
> 模型中心点击模型的「启动」按钮也会即时拉起对应服务；「测试连接」与语音合成前兜底同样自动拉起。

## 一、实现

- 新增 `internal/app/tts_service.go`：`core.ensureLocalTTSService`（幂等）+ `mediaState.StartLocalTTSService`（Wails 绑定）
- 探测：CosyVoice2 `http://127.0.0.1:8010/v1/models`；VoxCPM2 `http://127.0.0.1:8020/v1/status`
- 拉起（隐藏窗口 CREATE_NO_WINDOW，不阻塞 UI）：
  - cosyvoice：`C:\AI\cosyvoice\venv\Scripts\python.exe server.py`
  - voxcpm：`powershell -File C:\AI\voxcpm\start_voxcpm_stack.ps1`（顺序拉起 8030/8021/8020 三层）
- 异步轮询就绪（cosyvoice ≤90s / voxcpm ≤180s），就绪/失败通过 `tts-service-status` 事件通知前端

## 二、触发点（全部幂等，已就绪零开销）

1. gaea 启动（Startup）后台保活两个本地 TTS 引擎——重启电脑后打开 gaea 即可直接用
2. 模型中心模型卡片「启动」按钮：TTS 模型（VoxCPM2 / CosyVoice2-0.5B）点击后调用
   `App.StartLocalTTSService(engineId)` 并提示「已就绪 / 正在启动（首次约 1–2 分钟）」
3. 引擎「测试连接」：对本地 TTS 引擎先 ensure，刚拉起时最多等待 8s 再测
4. TTS 合成前兜底：`tryEngineTTS` 对 cosyvoice / voxcpm 自动 ensure

## 三、验证

- `go build` / `go test ./internal/...` 全绿；`tsc -b && vite build` 通过（绑定已重新生成）
- `wails build` 成功：`build/bin/gaea.exe`；校验和：`releases/SHA256SUMS-v2.6.8.txt`

## 四、使用提示

- 打开 gaea 即可使用本地 TTS；如需重启服务，可在模型中心再次点击「启动」
- 手动脚本仍可用：`C:\AI\voxcpm\start_voxcpm_stack.ps1`、`C:\AI\cosyvoice\start_cosyvoice.bat`
