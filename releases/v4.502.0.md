## ②素材库两刀

**读侧诚实过滤**（已删除的图片不再显示）：素材库读的是 imagehub 台账
（append-only JSONL，只存路径+元数据），此前文件被删（绘梦清历史/手工清目录）
后登记仍占位（缩略失败=空瓦片）。`imageHubAssetSummaries` 现按 `os.Stat`
剔除盘上已删除的登记——素材库是登记视图，文件真相在磁盘；台账不回写。
月度用量聚合直读台账不经此函数，历史消耗口径不受删除影响。

**删除功能**（新绑定 `ImageHubAssetDelete`，661→662）：

- 语义：删盘上文件 + 移除该空间台账登记；返回
  `{ok, file_removed, removed_entries}` 或 `{error}`；
- **登记守卫**：path 必须已在指定空间台账登记，否则拒绝——绑定面不提供
  通用文件删除；
- 删除顺序 = **先文件后台账**：台账重写失败时读侧存在性过滤已把视图收敛
  正确（文件已不在 → 记录不再返回），登记残留无害；
- 文件已不在（用户手工删过）不算错——登记照样移除；
- 删行走 AtomicWrite 单源（与折叠重写同款）；坏行原样保留不趁机清洗；
- 只动本空间；其它空间若登记同一路径，其视图经读侧过滤自然隐藏。

前端：素材库详情条「删除素材」钮（Popconfirm 两步确认，危险色）→ 绑定调用
→ 本地摘除同路径全部登记+清缩略缓存+收起详情条；成功文案按 `file_removed`
双口径（「已删除并移出素材库」/「已移出素材库（文件此前已不在）」）。

绑定管线全链登记：gen_bindings 三件再生 + bindingNames.ts 手工 +
bridge/image.ts 分域签名 + spaceBindings 认领 `shared`（与 ImageHubAssets
同消费面）+ mock/imagehub.ts 实现（未登记路径同款拒绝）+ api 包装
`deleteImageHubAsset`。
