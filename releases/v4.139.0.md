## 内容（全部对齐设计 §3，无偏航）

- **文件布局（§3.1 每文件一工程+索引）**：`进度计划/*.gsched.json` 每文件一工程；注册表+当前指针落 `.gaea/schedule/index.json`（与用户资产目录分离防误删）。**索引是缓存与指针不是权威**：缺失/损坏/漂移 → 扫描目录重建（宁重建勿报错），Load 时轻扫 diff 收编游离文件（name 从文件内回填）。`internal/schedule/index.go`：LoadScheduleIndex/SaveScheduleIndex（原子写）/SetCurrentSchedule（校验+拒 `..` 逃逸）/ScanScheduleProjects/SafeSlugName（中文保留/非法字符替换/冲突 -2 序号/60 字符上限）。
- **绑定（§3.2 方案 A，+5）**：`GaeaScheduleLoad` 签名不变但改读索引 current（索引不可用回落 DefaultRelPath——老用户零感知）；`GaeaScheduleSave(projectJSON, rel)` 签名扩展——**保存永远显式带装载时的工程文件**（结构性消解「切换瞬间旧内容写进新文件」竞态），rel 空串回落当前指针（wails 缺参零值兜底）；新增 `GaeaScheduleProjects`（列表+摘要：name 必真/工期/任务数/ok/updatedAt，坏文件 Ok=false 不计）、`GaeaScheduleProjectOpen`（校验+原子切指针，不搬数据）、`GaeaScheduleProjectCreate`（slug 落盘全套校验→登记→自动切当前，**文件名此后不改**——agent path 引用稳定）、`GaeaScheduleProjectArchive`（索引标记文件不动，可反归档）、`GaeaScheduleProjectDelete`（物理删+摘除；删当前级联切剩余第一个**未归档**，无剩余回落缺省并落空工程）。
- **agent 跟随（§3.3/3.5）**：`resolveSchedulePath` 缺省分支从常量改为读索引 current——「对话改的=板块打开的」跨多工程保持；三工具 schema 零扩容（path 天然=工程）；compact 通道文案同步「缺省=当前工程」。list_projects 工具与 analyze 跨工程对比维持不做（设计 §3.5）。
- **store 切换流**：`currentPath` 状态（水合/回读均以 LoadResult.path 校正）+ `openProject`（dirty 先冲刷旧 rel → Open → 重水合：新工程新历史 past/future 清空、selectedId 置空、失败 fail-closed 原状）+ `createProject/archiveProject/deleteProject/refreshProjects`（冲刷逻辑全动作覆盖）；自动保存显式带 rel；localStorage persist 结构不变（降级为当前工程缓存，既定取舍）。
- **UI（§3.4）**：页头工程切换器 Select（未归档项、当前高亮；**仅 1 项收窄为纯显示、0 项整体隐藏——老用户零感知**）+「管理」Popover（列表 工期/任务数/归档/反归档/删除 Popconfirm「不可恢复」/新建 Input，行内改名=当前工程文件内 name 通道）；状态栏/办公预览入口改读 `store.currentPath`。
- **办公摘要卡联动（§3.5）**：「设为当前计划」从**复制内容覆盖**升级为**切指针**（ProjectOpen+notify 重水合+跳板块）——消灭多工程下两份同源文件漂移的隐患；「打开」扩展为任意计划；周报仍仅当前计划。
- **mock**：单文件内存演进为 Map+索引指针（文件=权威同构），5 个 mock 方法+`__mockScheduleFile.list()/open(rel)` 走查钩子；Delete 级联与 Go 同语义（切剩余第一个未归档）。
