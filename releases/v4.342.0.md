# v4.342.0 · t7 观察池「多章对比」最小形态：分析面板章际对比

> 2026-09-19 发布。观察池条目（v4.325 t7 收官记录）的最小可用形态；纯前端
> 两文件（ChapterAnalysisPanel + CreatePage 一行接线），零新绑定 705。

## 论点

情感曲线（v4.341）给了全书情绪节奏，但「第 5 章改完比第 3 章强了吗」这类
章与章的质量对比仍无处可看。本刀在章节分析面板内补「章际对比」最小形态：
选定对比章 → 拉其 V2 → 四维评分 + 情感强度并排差值。不做独立对比页面、
不选多章集合——对比是单章分析的附属动作，嵌在原面板语义最自然。

## 落地

1. **ChapterAnalysisPanel** 增可选 `chapterOptions: number[]`：
   - 提供（且排除本章后 ≥1 可选）时渲染「章际对比」区；缺省整体隐藏
     （CreatePage 是唯一消费方，其他挂载点零影响）。
   - Select 选对比章 → `NovelChapterAnalysisV2(cmpNum)` → 差值表：
     综合/节奏/代入/连贯 + 情感强度（rune 口径无关，纯数值）。
   - Δ 语义：四个质量维「上=好」——对比章高显绿、低显红；情感强度是节奏
     信息非好坏，中性不判色。缺字段（—）与 0 差值不着色。
   - 对比章未分析 → 行内提示「先在章节页运行分析后再对比」（不 toast）；
     V2 有数据但无 scores → 「对比章分析无评分数据」。
   - 切章/关面板重置对比态（复用既有 useEffect 锚点）。
2. **CreatePage**：`chapterOptions={flatNodes.map(tn => tn.node.order_index)}`
   （flattenTree 返回 TreeNode，章号在 `.node` 下）。

## 测试

- ChapterAnalysisPanel.test +3（共 11/11）：
  - 未提供 chapterOptions → 对比区不渲染；
  - 提供清单 → 下拉排除本章（无「第 2 章」选项）；选第 3 章 → 差值表
    渲染（7.8 vs 6.0 → Δ -1.8）且 V2 以章号 3 调用；
  - 对比章尚未分析 → 行内提示、不出表。
- antd Select 测试交互：`fireEvent.mouseDown(getByRole('combobox'))` 开下拉
  （ChapterReviewPanel 先例），dropdown 渲染在 portal 需 `findByTitle` 等待，
  选项点击可用。

## 坑

- **flattenTree 返回 TreeNode（{node, children, depth}），章号在 `tn.node`
  下**——`flatNodes.map(n => n.order_index)` 被 tsc 抓（TreeNode 无此属性），
  类型门又一次兜住了运行期 undefined。
- antd Select 的 mousedown 必须落在内层 `role=combobox` 元素上，落在根 div
  不开下拉；选项点击（`.ant-select-item-option` title）在 jsdom 可用。
