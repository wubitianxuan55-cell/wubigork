## ① diff 视图完成（观察池关账）

59cc2638 时代 ToolCard 的 diff 渲染只显示 `d.original`——两处半成品后遗症：

- **write_file 全增 diff 的 original 是空串** → 展开态一只空盒，写入内容用户
  看不到（只剩头部「N 行」摘要）；
- **edit_file 只显旧文不显新文**——改成了什么看不到。

现改为行级 ± 视图（`unifiedRows` 纯函数，复用 `diffLines` LCS 单源）：

- del 行来自 original（`- ` 前缀红）、add 行来自 modified（`+ ` 前缀绿）、
  共有行暗色——着色与 diffstat 芯片同口径；
- original 空串（write_file 全增 / edit_file 整段新增）特判全 add——diffLines
  会给空串出一行伪 del；
- 两侧各剥一个尾换行防末尾空行噪声；400 行上限折叠（`TOOL_CARD_MAX_DIFF_ROWS`，
  尾行报「… 已折叠 N 行」）；max-h-72 内部滚动；块内零行（如 content 为空）整
  块不渲染不出现空盒；
- multi_edit 逐组 label（edit N）保持。

## ② 只读工具 args JSON 盒降噪

read_file 展开态此前渲染 `{"path": …}` 三行 JSON——行内主体本就显示路径，纯噪
音。`READER_JSON_TOOLS`（read_file/ls/glob/grep/web_fetch/web_search）展开态不
再出 args JSON 盒，卡片可展开性由输出块承担。grep 的 path 字段随之不在展开态
显形（命中列表逐行含路径，信息不丢）。写类/bash/task 不受影响。

## ③ ToolGroup 组行主体截断

`bash × 3` 组行此前把**整条命令**当主体拼行（`cmd1, cmd2, cmd3`）——组行版
「一长串」。单条主体截 48 字符加省略号（与单卡折叠行截断口径一致，完整命令
仍在子卡 `$ 块`）。
