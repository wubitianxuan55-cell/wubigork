# v4.103.0「办公搜索对齐 unsloth：web_search url 直取整页 · 结果域名策略过滤 · 日期钉定」

- 发布日期：2026-09-05
- 绑定面：**584**（本刀零变更，drift PASS@584）。
- 基线：v4.102.0 + 蒸馏 unsloth 搜索工具（`clones/unsloth`，`studio/backend/core/inference/tools.py` 的 `_web_search` / `web_access_policy` / `search_images`）。

## 起因与蒸馏结论

- 用户反馈 unsloth Studio 的搜索工具“很好用”，希望 gaea 对齐其 **行为**。unsloth 源码在本环境 web 抓取被拦（github/unsloth.ai/deepwiki/jsdelivr 均解析到私网 IP），改经 `git clone` 到 `clones/unsloth` 研究真实实现。
- 结论：unsloth 搜索“好用”的本质是 **任意入口稳定出网 + 出好结果 + 带来源**——
  1. **一个工具两条路**：`web_search` 既能搜索，传 `url` 还直接抓取整页文本（无需再另调抓取工具）；
  2. 搜索结果受 **域名 allow/deny 策略**约束（`check_url_access` 逐条过滤 + `scope_search_query` 收敛查询）；
  3. 策略受限时 **过度抓取再过滤**（`max_results × _POLICY_OVERFETCH`），避免“前几条被拒 → 结果为空”；
  4. 结果末尾**引导用 `url` 取全文**；
  5. **注入当前日期**，避免按模型训练截止日假想。

## 改动（Go 内部，绑定面 584 零变更）

1. **`web_search` 新增 `url` 参数**（直取整页）：复用 `web_fetch` 的 `doFetch`（SSRF 防护 + `checkDomainPolicy` + HTML→文本抽取），搜索→取全文→引用收敛为一次调用；`url` 优先，命中即不再搜索。
2. **域名策略作用于搜索结果**：新增 `filterSearchResults`——受限时逐条 `checkDomainPolicy` 过滤结果 url（deny 优先、allow 非空须匹配），并丢弃非法/非 http(s)/无 host 结果；策略未配置时原样返回（行为零变化）。
3. **策略受限过度抓取**：`searchPolicyRestricted()` 判定 `allow_domains/deny_domains` 任一非空即受限，此时 `requested = topK × searchPolicyOverfetch(3)`，再过滤保留合规结果直到填满 topK。
4. **日期钉定 + 引导取全文**：`fetchSearchPage` 结果头部注入 `[web_search · url=… · as of <date>]`；`Schema`/`Description` 注入当前日期语义与“用 url 取全文”指引。
5. **元数据同步**：`Schema()`/`Description()` 与 `compact.go` 的 `compactDesc["web_search"]`/`compactSchema["web_search"]` 同步（去掉 `required:["query"]`、新增 `url`）。
