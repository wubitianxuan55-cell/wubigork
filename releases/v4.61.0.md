## 定位

四个未发版快照合并发布，主线是「子代理从壳到芯对齐 Codex 口径」：UI 侧会话
tab 对齐主代理 → 真实引擎 transcript 落盘接线（此前真机无数据）→ 本地模型

对照 Codex/zcode 的「父代理发任务消息」形态）；并随版收入 Word 预览目录侧栏。

## A · Word 预览目录侧栏（eb84c82c）

- **docxOutline.ts 纯解析**：解 word/document.xml + styles.xml，标题判定 =
  段落 outlineLvl（9=正文显式排除）→ 样式 outlineLvl / heading(标题) 样式名
  /id / basedOn 链继承；TOC 与页眉页脚不计标题，防「目录页/页眉同名」抢锚点。
- **DocxOutline 目录侧栏**：工具栏「目录」按钮开合，标题按级缩进计数；点击
  条目定位 + 短暂高亮锚点段落；条目右侧铅笔按钮把「请修改《文件》中《章节》
  一节：」模板插入 composer（不自动发送）。
- 纯前端，绑定面 559 零变更；vitest +8 用例（docxOutline 6 + 集成 2）。

## C · 子代理 transcript 真机接线 + 本地模型工具同 UI（1f70e06d）

- **真机接线**：boot 惰性 SubagentStore（目录随 ctrl.SessionPath 解析，与
  EventLogSink 同晚绑定时序）→ task 工具与 run_skill/专用技能派生全部真实落盘
  sa_ meta + jsonl（此前 WithTranscripts 只有测试调用）。每次运行 MarkRunning
  + ~1s 原子快照写盘（TrackProgress stop 先 final flush 再终态写；CreatedAt /
  Title / Kind 终态守恒）。技能子代理 meta.Title = 任务本体，UI 标题不被技能
  正文顶掉。顺带修复：run_in_background 后台子代理此前从不落盘。
- **本地模型工具 = 变相子代理**：tool 新增 ModelBackedTool 标记（vision /
  summarize_file 一行声明）；boot 收集集合注入主执行器；AgentRunner 在
  pre-exec 起点开 mt_ 记录（参数齐后刷新标题）、ToolResult 收尾（成败如实）、
  回合 defer 兜底失败。子代理 runner 不装配——其内部工具活动已在自身 sa_
  transcript，不重复制造噪音。
- **读端/UI**：SubagentRunView/Transcript 增加 kind/tool（旧数据 subagent
  降级）与 meta.Title 优先任务摘要；ref 校验扩展 mt_（防穿越同口径）；左栏
  会话展开子行、任务页「本地模型工具」区块、ChatTabs detail、三语字典两键；
  SubagentThread 订阅 tool_dispatch/tool_result 事件（800ms 节流）即时补拉。
- 验证：store 生命周期/惰性目录/进度 flush + app 绑定 mt_ 用例；Go 相关包绿；
  vitest 211 文件/1535 用例。

## D · 子代理入口收敛 task + run_skill 两级（aa57784c）

- 用户问「子代理是否分类过多且限制能力？Codex/zcode 简单、靠父代理任务消息」
  → 核对属实：真注册的专用包装只有 format-convert/chart-builder/doc-assemble；
  explore/research/review/security_review 只是分类/模板残留（无注册点）。
- **移除**：三办公顶层包装工具（类型+工厂+相关测试删除）；explore 等四分类
  名从子代理元工具表/批次冲突表/任务分类增配清单/compact 隐藏死代码移除。
- **保留**：三办公技能仍在内置 Skills 索引（run_skill / slash_command 按名
  调用）；四 spawn 模板前缀仍服务同名 runAs=subagent 技能的 L4 前缀缓存；
  per-skill 模型覆盖保留；persist-write 护栏与「子代理不可再派生子代理」不变。
- **提示面**：系统提示明确「子代理入口只有两级：task + run_skill，任务消息
  必须自包含」；前端能力矩阵去三包装卡、欢迎页 chips 改 run_skill 措辞。
