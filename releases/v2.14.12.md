# gaea v2.14.12「绘梦 UI 重构落地 + herdsman 生图能力修复」发布说明（2026-08-13）

> 本版完成绘梦板块 UI 全量重构（设计文档 Phase 1-2 + 视觉统一），并把 herdsman
> 生图链路修复/接通（size 契约、URL 响应转 data URL、图生图），桌面端已打包。

## 一、绘梦 UI 重构

- 左栏 300px 固定宽，可折叠分区渐进式披露：
  基础设置 / 模型与引擎 / 画幅与输出（默认展开）、高级参数（默认折叠）
- 底部常驻生成栏：主生成按钮、取消、队列摘要、预估耗时与 ComfyUI 进度
- 右侧升级为任务中心：队列 / 最近结果 / 模板资产三个 Tab，可整体收起
- 选项改下拉：引擎 / 模型（可搜索）/ 画幅 / 时长帧率改为 Select；
  修复 WebView2 下拉弹层卡首帧（popupClassName 禁用弹层动画 + getPopupContainer=body）
- 视觉统一：移除独立深黑配色，改用 gaea 玻璃 HUD 令牌，明暗主题与窄屏断点通过

## 二、herdsman 生图能力

- size 契约对齐：herdsman 按文档保留 size（此前被非 ComfyUI 分支剥除），实测 512x512 生效
- URL 响应转 data URL：herdsman 返回 `/v1/images/cache/...` 时自动下载转 base64，
  前端可显示、可落盘、历史可复用
- 图生图接入：`OpenAIImageBackend` 增加 `/v1/images/img2img`（JSON + image 字段）分支，
  绘梦图生图支持 ComfyUI / Herdsman；文生视频仍限 ComfyUI
