> 阶段八第七刀。规划判据：**采样参数经绑定面可配且有默认档；重复率对比有基准（复用病历夹具）**。规划条件「strata 采样器暴露面前置核实」已按字面执行。

## 前置核实（2026-10-15 真机+源码，三引擎分档）

| 引擎 | DRY/XTC 可用性 | 证据 |
|---|---|---|
| herdsman | **可用**（顶层键直发） | 8080 真机 POST `dry_multiplier/dry_base/dry_allowed_length/dry_penalty_last_n/xtc_probability` → 200 正常生成 |
| strata | **暂不可配**（留观察） | 引擎内核 CUDA 采样链含 DRY+XTC（`src/kernels/cuda/sampler.cu` 注释：默认链 {PENALTIES, DRY, …, XTC, TEMPERATURE}），但服务层每请求只透传 `temperature/top_p/top_k/seed`（serve/server.py:577）——键发了无效 |

## 实现

- **ai.ChatRequest** 加 `dry_multiplier/dry_base/dry_allowed_length/dry_penalty_last_n/xtc_probability/xtc_threshold` 六键（omitempty 零影响；传输层哑管道，引擎门控在 app 层）。
- **默认档** = llama.cpp DRY 缺省语义 `0.8/1.75/2/4096`（与规划给的数字一致），XTC 缺省关（激进采样，留给作者显式开）。
- **config 两键**（读写三件套齐）：`novel_dry_disabled`（一键关，*bool 三态）+ `novel_sampler_json`（全量覆盖档，**字段级合并**到默认档——只写想改的字段；坏 JSON 诚实回落默认档+warn，不静默吞配置错误）。
- **生成链接线** `applyNovelSampler`：首轮注入 DRY 键 + **四步自检段**拼 userPrompt 尾部（续写轮不重复拼——自检针对整章收尾）；sampler 流事件即时提示 + done 事件 `sampler` 回显生效状态（作者可见）。
- **四步自检**（「prompt 预设可选」的落点，`self_check` 可关）：①复读本章开头 300 字句式措辞不雷同、同一比喻不复用 ②角色名/称谓/地名与设定一致 ③伏笔动作与事实一致 ④时间线连续——采样的提示词侧配合，双保险。
- **重复率基准**：`noveltext.TrigramRepeatRate` 字符三元组重复率纯函数（非生成对比的确定性度量）——病历夹具同型语料基线断言：flavor 型复读语料 ≥0.8，healthy 型自然行文 ≤0.05。
