## 一、命名体系（希腊神话宇宙观）

- 办公 agent 改名 **Hephaestus**（火与工匠之神），轻语 agent 改名 **Hermes**（信使之神），皆 gaea（大地母神）之子女
- 提示词/子代理前缀/GaeaMeta Label/记忆三元组/生日/dossier 全链替换；板块名"轻语"保留
- 产品类型统一 **AIgaea**（"你是'Hermes'——一个AIgaea"）

## 二、三脑记忆架构（核心）

- **主脑**：新建 Hephaestus.db（SQLite，~/.config/gaea/）三表 facts/profile/knowledge + 迁移链；
  memory.Store 后端抽象（fileBackend + sqliteBackend），统一记忆 API，调用方零改动
- **左脑（办公）**：办公记忆从 Markdown 幂等迁入 Hephaestus.db facts 表（Type×Kind 保留 + profile 标记跳过）；
  新增 memory_get 工具（SQLite 无 .md 可读）；boot/controller 默认 SQLite 后端
- **右脑（轻语）**：whisper.db → **hermes.db**（按 agent 名），旧库首次打开自动迁移（含 WAL/SHM，保留备份）
- **调度路由**：remember type=user → 主脑画像（profile 表，跨 agent 共享），工作类 → 办公 facts；
  ProfileBlock 聚合画像 + 兼容旧 facts 去重；DetectConflicts 冲突检测
- **知识库 RAG**：~/.gaea/knowledge 迁入 Hephaestus.db knowledge 表（幂等迁移）；
  共享向量检索层 internal/gaea/search（TF-IDF + 中文 bigram 余弦），关键词 + 向量混合排序

## 三、记忆中枢板块（多库统一管理）
