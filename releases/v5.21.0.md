## 🎨 聊天界面全面重构

从 `ChatPanel` 嵌入式卡片 → 类 ChatGPT/Claude 的全屏沉浸式聊天。

### ChatPage 内联布局（全新）
| 改动 | 说明 |
|------|------|
| 去掉折叠/标题栏 | 聊天窗口不再可折叠，标题已在侧边栏显示 |
| 去掉外层边框 | 全屏无边无框 |
| 消息居中 | `max-width: 768px` 居中 |
| 用户气泡 | 主题色 12% 淡底 + 圆角 18px，右侧对齐 |
| AI 消息 | 纯文本左侧对齐，极简风格 |
| 悬浮输入框 | `absolute` 底部居中，20px 圆角，强阴影 |
| 复制按钮 | hover 消息时显示，绿色 ✓ 反馈 |
| 滚动条 | flex 链 `minHeight:0` 确保消息列表正确滚动 |

### 欢迎界面重新设计
- 88px 主题色渐变品牌图标
- "wubigork AI" 标题 + "你的智能 AI 助手" 副标题
- **6 张快捷建议卡片**（💬 随便聊聊 / 🔍 查资料 / 📝 写文章 / 💡 头脑风暴 / 🌐 翻译 / 🧠 解释概念）
- 点击卡片自动填入输入框，hover 上浮 + 边框高亮

### ChatTopicSidebar 优化
- 背景从 `bg-elevated` → `bg-container`，视觉更明显
- 右边框 2px 主题色 + 右侧阴影
- 删除按钮 hover 时显示（opacity 0→1 过渡）

### 动画
- 消息入场 `chatMessageIn`（淡入 + 上移 6px）
- 打字指示器 `typingBounce`（三点跳动）
- 复制按钮 hover 显示
