## 交付明细

### ① 回滚守卫统一 + write_file >8KB 恒误报修复（线A，Go；收 v4.32 欠账 + 修真 bug）

- **rollback 卡接入「手工修改」守卫**：撤销恢复（对 rollback 卡再回滚）前校验目标当前
  内容与该卡 AfterSummary 同口径一致，恢复后手改过文件则拒绝，防覆盖用户编辑。
- **write_file 守卫 >8KB 恒误报修复（真 bug）**：原守卫 `curS != rec.AfterSummary` 精确
  比较，但 AfterSummary 落库时被 RecordChange 截断到 SummaryLimit（8KB）——>8KB 且从未
  手改的文件**必然误报「已被手工修改」拒绝回滚**。改为 `evidence.ClampSummary(curS) !=
  rec.AfterSummary` 同口径截断比较。
- 守卫矩阵：editLike（edit_file/multi_edit/edit_lines）保持 Contains 前缀语义不变；
  write_file/rollback 同口径截断相等；AfterSummary 为空的旧卡跳过守卫（宁漏勿误）。
- **截断单点化**：evidence 新导出 `ClampSummary(s string) string`（字节口径 `s[:SummaryLimit]`，
  含切进 UTF-8 中间字节的历史行为，逐字节兼容），RecordChange 两处内联与 app 包
  clampSummary 全部复用。
- **已知边界（有意取舍）**：手改点整体落在 8KB 摘要窗口之外时同口径比较检测不到——与
  editLike Contains 语义同源，宁漏勿误，测试注释已钉注记。
- 测试：app 新增 4（>8KB 未手改可回滚钉回归 / >8KB 手改拒绝 / rollback 卡恢复后手改拒绝 /
  旧卡空摘要跳过守卫）+ evidence `TestClampSummary`；既有三场景（快照/撤销恢复/目标缺失）
  继续 green；两包 `-count=2` 全绿。

### ② pdf 占位比按实测精确化（线B，前端；收 v4.32 欠账「占位高为 A4 估计值」）

- pageLazy 新导出纯函数：`nextPageAspect(prev, naturalWidth, naturalHeight)`（取**首个
  有效测量**为整档比例且不被后续页推翻——同一 PDF 各页尺寸通常一致，简单确定性）与
  `placeholderAspect(measured)`（无测量回落 `LAZY_PAGE_ASPECT`）。
- FilePreviewModal 接线：页 `<img>` onLoad 读 naturalWidth/Height（图片真实像素比，与
  容器宽无关；无效值不记录），lazyPdf state 增文档级 `aspect` 字段（preview 换载荷渲染期
  重置，与 mounted/forced 同款）；占位盒 `aspectRatio` 随测量修正——消除占位→真身交换的
  高度跳与滚动条失真。存比例不存绝对高度，拖拽分割条改宽仍成立。
- 测试：pageLazy 25（+6）+ FilePreviewModal 15（+2，含 naturalWidth=0 不记录、后续页
  不同比例不推翻）；既有断言零删改。

### ③ 主区预览 pdf 懒加载对齐弹窗（线C，前端；v4.32 懒加载的补全）

- FilePreview 主区 kind=pdf 分支接入同款 IntersectionObserver 单向懒加载（复用
  lib/pageLazy 纯函数）：初始窗口前 4 页、rootMargin 800px、±1 buffer 单向只增、大纲跳转
  目标页 `addForcedPage` 强制渲染防锚点跳偏；「ref 回调登记即补 observe」真 bug 修法照搬
  （preview/loading 两次异步提交致观察集为空的坑在主区同样存在）。
- 无 IO 环境（jsdom/旧 webview）全量渲染 = 既有行为逐像素一致；embed 回退/空态/非 pdf
  分支/编辑保存逻辑逐字节未动，组件 props 零变化。
- **主代理集成追加**：主区同样接入线B 的测量比例（`nextPageAspect`/`placeholderAspect`
  接线 + onLoad），占位表现与弹窗完全一致。
- 测试：FilePreview 16/16（既有 13 用例零删改 + 新增 3：无 IO 全量降级零 IO 实例 /
  mock IO 初始窗口+buffer 扩张+不卸载+rootMargin 断言 / 大纲跳转强制渲染）。
