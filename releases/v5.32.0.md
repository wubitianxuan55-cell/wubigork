# wubigrok v5.32.0 — 角色系统全链路打通 + 剧照生成重构

**发布时间**: 2026-07-29

## 字数守卫修复
- `streamCreateChapter` 引入 `bodyText` 变量追踪纯正文
- 修复续写后字数永不超过 5000 的 bug（摘要标记导致续写内容不计入字数）
- 修复章节文件丢失续写内容的问题

## 角色系统重构（4 步全链路）
- **章节生成注入角色**：`CreateChapter` 将已有角色摘要注入 prompt，AI 保持角色一致性
- **章节完成后提取角色**：异步调用 `chapter.GenerateSummary` 提取 `characters_appeared`
- **对照去重**：按角色 Name 与已有角色对照，发现新角色
- **前端确认弹窗**：新角色弹窗支持复选框筛选 + 编辑名称合并重复称呼 + 全选
- `SaveCharactersBatch` API：批量创建角色

## 分支生成注入角色
- `BrainstormBranches` 和 `QuickBrainstormBranches` 注入已有角色列表
- `plot-branch-browser.json` 模板增加 `characters` P0 输入段
- 分支推演基于已有角色动机展开，不再凭空编造

## Skill 修复
- `CreateChapter` 改用 `skillLoader.InjectSkill()` 正确格式化注入
- 修复之前手动拼接 skill 格式不规范的问题

## 剧照生成重构
- **剧照模型选择弹窗**：点击生成弹窗 → 选模型 + 编辑 prompt → 直接调绘梦 API
- **性别问题修复**：prompt 开头前置性别标识（如"女性角色 苏婉"）
- **ComfyUI 模型列表**：`GetImageBackendConfig` 根据后端类型补充模型（krea2/z-image-turbo/flux）
- **图像后端自动恢复**：`restoreImageBackend()` 启动时从配置恢复 ComfyUI/Herdsman/Ollama
- **xAI 默认模型**：切换到 xAI 时设置 `grok-imagine-image-quality`
- 简化链路：不再走 `GeneratePortrait` 复杂流程，直接调 `generateImage`

## Backend
- `create_chapter_handler.go`: `bodyText` 变量 + `buildCharacterSummary` + `extractNewCharacters` + `extractCharactersAfterChapter`
- `plot_branch_handler.go`: 注入角色 + `pm` 初始化修复
- `image_handler.go`: `GetImageBackendConfig` + `restoreImageBackend` + xAI 默认模型
- `character_handler.go`: `SaveCharactersBatch` + `GenerateCharacterPortrait` 支持 model 参数
- `chapter.go`: `generateSummary` → `GenerateSummary` (导出)
- `character.go`: `buildPortraitPrompt` 重写 + `GeneratePortrait` 支持 model 参数
- `app.go`: `restoreImageBackend` 启动恢复

## Frontend
- `CreatePage.tsx`: 新角色确认弹窗（Checkbox + Input 编辑 + 全选）
- `CharacterPage.tsx`: 剧照生成弹窗（模型选择 + 可编辑 prompt + 直接调绘梦 API）

## 模板
- `create-chapter.json`: 增加 `characters` 输入段 + 角色约束规则
- `plot-branch-browser.json`: 增加 `characters` 输入段
