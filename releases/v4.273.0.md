## 实测发现：全局焦点环全站性失效

v4.255.0 立的全局 `:focus-visible` 环（2px glow）在六页 Tab 遍历中大面积无环：
home 7 站 / cost 5 站 / sin 6 站 / chat 1 站（memoryhub 0）。深挖（对 toolbar-btn
做 `matches(':focus-visible')` + computed 比对 + 枚举 styleSheets 匹配规则）：

- 元素 `matches(':focus-visible') === true`（键盘焦点判定正常），
- 但 computed `outline: 3px none rgb(glow)`——**outline-style 被置 none**。
- 匹配规则清单里出现一条源码中不存在的 `:focus-visible { outline: none }`
  （打包产物 tailwind-*.css，Tailwind v4.3.3 编译链路注入；`*, ::before,
  ::after, ::backdrop { outline-style: solid }` 同批）。同特异性层叠按文档序
  被它吃掉 → **v4.255 的焦点环自 v4.255 起实际只对少数自带自绘环的元素可见**。

## 修复（index.css 单文件两段）

1. 全局环升级必胜形式：`:focus-visible { outline: 2px solid glow !important;
   outline-offset: 2px !important }`——!important 是焦点环的行业标准做法
   （forced-colors 模式同款）。
2. 豁免段（antd 输入类：input/affix-wrapper/input-number/select/switch/slider/
   pagination/tabs/picker——它们有自管 border/shadow 焦点态，豁免防双环）同步
   `!important` 保持豁免有效。
3. **ant-btn 移出豁免清单**：antd Button（text/default 型）聚焦零视觉变化，
   豁免=键盘用户找不到焦点；移出后吃全局 glow 环。刻意去环的输入框
   （.chat-input-textarea 等，类+伪类特异性 (0,2,0) > :focus-visible (0,1,0)，
   同为 important 时高特异性赢）不受影响。
