## 缺口

单点 CPM 只给一个确定工期：工期风险（哪一档更可能？关键线路会不会换线？
哪些任务容易被顶掉）没有量化。6.5 用本地蒙特卡洛模拟直接给出工期分布。

## 落地（monteCarlo 纯函数，frontend/src/schedule/monte.ts）

- **种子化 RNG**（mulberry32，默认 seed=42）：同输入同结果——模拟可复现、
  跨会话可比、逐字段可测；
- **三角分布采样**：[d·(1−u/2), d, d·(1+u)]，默认不确定度 30%（工期普遍
  偏乐观的不对称先验；UI 滑杆 0–60% 可调，u=0 退化为确定值）；
- **逐次重算 CPM**（默认 200 次）：采样后计划走与页面完全相同的
  computeCpm（planFinish/日历同语义），每次记录总工期与关键任务集合；
  采样后按 id 映射重建任务表（去 O(n²)）；
- **输出**：P25/中位/P75 三档（取整）+ min/max/均值 + 10 桶直方图 +
  **关键路径稳定度**——逐任务关键出现频率降序（当前关键但频率低 = 容易
  被顶掉；计划态非关键但频率>0 = 可顶掉别人的换线候选），稳定度指标 =
  当前关键任务的平均关键频率。

## UI

（P25 绿/中位中性/P75 琥珀）+ 直方图 + 关键频率条（当前关键红点/非关键
灰点）+ 不确定度滑杆；CPM 断裂时诚实显示「无法模拟」。

## 测试（vitest +8）

先验）；零不确定度退化（三档全=20、稳定度=1）；线性链关键率全 1；并行链
计划态非关键任务频率>0 且 ≤1；直方图频数守恒=有效模拟次数；CPM 断裂
ok=false 不伪造三档；RNG 同种子同序列且值域 [0,1)。
