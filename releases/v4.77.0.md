## 变更

- App：订阅 onTaskEvent（work 空间），首个未见的新任务事件（queued/running/
  stopping）经 openTasksAuto 自动激活任务视图；沿用去抖前存在的偏好键；
- openTasksAuto：读开关（默认开）+ 视口 ≥1240px（窄屏不强制展开，避免
  workspace-pane 在窄布局被 CSS 隐藏/强制弹层）；已在任务视图则不打扰；
- 新子代理自动激活与 handleSubagentStarted 统一收敛到 openTasksAuto
  （去掉直开右栏的旧路径，窄屏同样跳过）；
- TaskCenter：running 任务按钮文案「强制终止」（tasks.forceStopBtn 三语），
  queued 保持「取消」、stopping 保持「停止中…」。
