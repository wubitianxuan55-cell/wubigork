## 定性三实锤（审计池项转为根修）

1. **停止生成在连接建立阶段显示「生成失败」**（观察池前端#7）：根因在后端——
   `create_chapter_handler.go` 的 `ChatStream` 建连返回 err 时无条件 `emit error`，
   用户在流开始前点停止（ctx 已取消）被当成失败上报。修：err 分支先判
   `ctx.Err()`，走取消落盘路径发 `cancelled` 事件（连接未建立=空稿，只发事件不写空文件）。
2. **伏笔「失败重读 × 排队写」交错窗口**（前端#4）：op1 保存失败→重读磁盘把
   `itemsRef` 覆盖回磁盘真相，排队的 op2 链任务随后执行写的是 `itemsRef.current`
   （=磁盘内容）——**op2 的改动静默丢失**。修：写链代际计数，失败重读后旧代际
   任务跳过写盘并如实提示「本项改动未保存，请重试」（窗口=同一渲染帧连点，
   `savingWrite` 的 disabled 重渲染前不生效）。
3. **设定 Agent 回填覆盖等待期手改**（前端#2）：ChatPanel 输入区等待期已禁
   （审计辨伪），但设定**编辑器**不禁——`setContent(result.worldview)` 照样覆盖
   等待期的手改正文。修：回填前比对发起快照，正文已变则不覆盖，修改稿以
   markdown 围栏附进回复走既有「应用」手动路径 + 如实提示。
