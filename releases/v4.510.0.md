## 病灶与实证

三处病灶同根：**绝对定位 UI 的包含块一路锚到滚动容器 `.transcript`**
（`position:relative` + `overflow-y:auto`），而绝对定位子元素随内容滚走。
无头 Edge 最小探针实证（temp/scroll-button-probe）：

- **①「回到底部」按钮滚走**：`absolute bottom-8` 挂在滚动容器内部，
  scrollTop=900 时按钮已滚出视口 666px（1:1 随内容平移）。该按钮恰在
  「上翻阅读」时才渲染（showScrollDown = 不贴底 && 内容超视口）——长会话
  上翻时按钮永远在视口之外，功能形同虚设；只有首屏内的短会话短暂可见
  （历轮走查都是短会话，掩盖至今）。对照组：轻语 ChatPage 的
  `.chat-scroll-bottom` 一直就是滚动容器兄弟节点的正确挂法。
- **②回退下拉锚到对话区顶端**：菜单 `absolute bottom-full` 的祖先链上
  无任何定位元素，包含块=整个 `.transcript`——菜单渲染在内容流顶端之外
  （实证 scrollTop=500 时 menuTop=-528；scrollTop=0 时仅 2px 探进视口），
  任何滚动状态下都基本不可见。
- **③外点守卫选择器落空=菜单项死键**：Transcript 的外点关闭守卫在
  document 上监听 mousedown，命中判定 `closest(".rewind")`——但 `.rewind`
  类不存在于任何元素。点菜单项时 mousedown 先触发守卫关菜单，click 落在
  已卸载的按钮上，`onRewind` 从未真正执行（真实浏览器事件序 mousedown →
  mouseup → click；`fireEvent.click` 单事件测试对此恒假绿——Message 域
  此前零测试覆盖，正是盲区）。

## 修复

- **① Transcript 外包 `relative flex` 包装层**：包装层接管弹性行
  （原 `.transcript` 直接作为 `.main` / 排期 ChatPane 的 flex 子项），
  滚动容器降为包装层子节点，「回到底部」按钮与滚动容器做兄弟——锚定
  包装层不随内容滚动，上翻时常驻视口底部。`.transcript` 自身 CSS 与
  内部结构零改动，两处挂载方（App/ChatPane）零改动。
- **②③ 回退行挂 `relative` + `rewind` 类**：`relative` 让菜单
  `bottom-full` 相对本行（打开在按钮正上方、右对齐消息列）；`rewind` 类
  是守卫选择器的命中目标——点菜单项不再误关，点菜单外任意处照常关闭。

## 回归测试（+3，`Transcript.interaction.test.tsx`）

- **FAB 兄弟挂载结构契约**：伪造滚动几何（2000/600/滚到 800）触发上翻态，
  断言按钮渲染且绝不在 `.transcript` 内部、与滚动容器同父。
- **回退菜单真实事件序**：`fireEvent.mouseDown` + `fireEvent.click` 双事件
  复现真实浏览器序，断言 `onRewind(0, "both")` 真正执行；附守卫选择器
  （`.rewind`）与定位锚（`relative`）的类契约断言。**反向变异验证**：
  摘掉 `rewind` 类该测试必红（onRewind 不被调用=真实浏览器死键复现）。
- **菜单外点关闭仍生效**：菜单外 mousedown 关菜单、回调零调用。

## 实弹
