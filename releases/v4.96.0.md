### 走查实锤并修复的两个真实缺陷（jsdom 测不出）

1. **setState updater 内副作用被吞**：onToggle 原把 `loadThumbs()` 写进
   `setOpen` updater——updater 必须纯；真实应用里父级（DeliverablesPanel
   2s 轮询）更新竞争时副作用被 React 丢弃（open 翻转成功但 phase 恒
   idle）。修复=副作用移到事件处理器本体。jsdom 单测无轮询竞争测不出。
2. **liveRef 只写 cleanup**：`useEffect(() => () => { liveRef.current =
   false }, [])` 在 React 18 开发模式 StrictMode 的 effect double-invoke
   （mount→cleanup→mount，第二个 effect 本体无事）下 liveRef 恒 false，
   dev 下组件永远「已卸载」，所有 setLoad 被门卫吞掉。修复=effect 本体
   置 true + cleanup 置 false 标准写法。生产构建与单测均不触发。
