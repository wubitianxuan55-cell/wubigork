# gaea v2.15.2「Herdsman 深挖 P1 · 模型库」发布说明（2026-08-13）

> 承接 v2.15.1，启动「Herdsman 深挖」路线图（见
> docs/superpowers/plans/2026-08-13-herdsman-deep-dive.md）。本轮落地 P1：
> 把 Herdsman 的完整本地模型目录（90 个已知模型）接进 gaea 模型中心，
> 从「只能连已存在的模型」升级为「可浏览全部可安装模型与能力」。桌面端已打包。

## 一、后端：HerdsmanModelCatalog

- 通过 `herdsman.exe skill models list --json`（RPC 到运行中的 Herdsman 桌面进程）
  拉取完整模型目录——HTTP `/v1/models` 只有 id+status，目录必须走 CLI。
- 结构化输出：name / 显示名（zh 优先）/ type / capabilities / installed / running /
  quantization / parameter_count（含 MoE 激活参数）/ file_size / llama_cpp_variants。
- 排序：运行中 → 已安装 → 其余，组内按名称；汇总 total / installed / running。
- 定位 `herdsman.exe`：优先 `HERDSMAN_EXE` 环境变量，回退默认安装路径
  `%ProgramFiles%\starwave\Herdsman\herdsman.exe`。
- 健壮性：CLI 缺失 / Herdsman 未运行时返回可读错误（前端空态引导），不阻塞模型中心；
  解析兼容 UTF-8 BOM。

## 二、前端：模型中心新增「模型库」分类

- KPI：已知模型 / 已安装 / 运行中。
- 搜索（名称 / 能力关键词，如 translation、voice-clone）+ 状态过滤
  （全部/已安装/运行中/未安装）+ 类型下拉。
- 模型卡片：中文显示名、类型、能力徽标、量化、大小（MB/GB）、参数规模、
  MoE 标记、运行/安装状态；复用模型中心统一卡片与视觉 token。
- 目录不可用时展示错误空态与「刷新目录」重试，可引导设置 HERDSMAN_EXE。
