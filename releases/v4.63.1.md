# v4.63.1「主对话子代理卡片整卡可点：单击直开子代理会话 tab」

> 发布日期：2026-09-04 ｜ tag：`v4.63.1` ｜ 基线：v4.63.0 ｜ 绑定面 **559
> 零变更** ｜ 用户点名：主对话里要有专门的子代理卡片，单击直接跳转打开
> 子代理 tab。

## 内容

- **task / run_skill 卡整卡可点**：解析出可跳转的子代理 ref（args 的
  continue_from 或结果的 "Subagent reference: sa_..." 行）时，点击卡片
  直接打开对应子代理会话 tab——与右栏任务树/左栏子行同款跳转。
- **空 ref 回退（宁缺勿错）**：并行派发初期卡片尚无 ref 时，App 侧用任务
  描述文本对唯一 running 子代理做唯一命中；0 或 ≥2 命中不可点（历史完成
  卡无 ref 同样不可点，如实）。
- **预填与自校正**：tab 的任务标题/状态/模型由 runs 缓存预填，打开后既有
  5s 轮询自动校正；运行中活动行（实时动态+用时）本身也是入口。
- 资源管理方式沿用 taskActivity 注入点模式（渲染层与跳转层解耦，App 注册
  实现，卸载即拆除）。
