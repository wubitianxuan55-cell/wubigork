# v4.365.0 — 前端性能轮：流式节流 + 后台空转治理 + 缓存统一

> 用户口径「继续」——前端换新镜头开性能审计轮（与后端性能普查对仗）：真机走查配方就绪 + 三路并行只读审计（React 渲染性能 / 长列表与流式渲染 / 桥接与数据面）。全部落「行为等价」低风险刀（最终渲染结果不变，只消除浪费），行为级大工程全部留池。前端 22 源文件 + 1 测试文件，绑定面 706 不动。

## 审计要点（三路交叉确认的三个系统性病灶）

1. **流式无节流**：聊天 delta 每 chunk 一次 setState（30~120 chunk/s → ChatPage 同频全页重渲染+吸底强制 reflow）；角色模式打字机 setTimeout(14ms)≈71 次/秒；ChatPanel 打字机 12ms/字符且每步 O(n) slice。
2. **keepAlive 后台空转**：13 页 display:none 常驻，五个 canvas rAF 循环（ParticleFlow/SoundWaveOverlay/CompanionAvatar×2/VoiceChatOrb/RelationGraph）切走后仍 60fps 绘制；DagPanel/AgentTree/useComfyTaskProgress/useImageGenQueue 计时器后台照常 setState；TaskCenter 任务事件、AIConsole xai-output（LLM 流式高频）后台照常重渲染。
3. **重复读缓存缺失**：办公消息内联图/缩略图/inspector 三处每次挂载重发 AttachmentDataURL（os.ReadFile+base64 跨桥），而 v4.361 的 usePortraitUrl 已有共享缓存；粘贴/截图图片三重 base64 往返（读盘→桥上送→再从盘读回预览）。

## 落地五线

**线1 流式节流**：useChatStream delta 改 buffer+rAF flush（一帧最多一刷，done/error/超时四条终态路径 flush 前 cancelPendingDelta 防挂起帧污染已清空文本）；角色模式打字机改 rAF 时间驱动（每 14ms 推进 step 字的节奏不变，刷新对齐显示器帧）；ChatPanel 打字机改 rAF 每帧 3 字符（频率降 ~4 倍）。
**线2 后台空转治理**：五个 canvas draw 循环加 `document.hidden || offsetParent===null` 挂起守卫（保留 rAF 链、恢复可见自动续绘，零行为变化）；DagPanel 轮询/AgentTree 每秒 setNow/useComfyTaskProgress/useImageGenQueue 秒表/SinIllustration 秒表加 hidden 跳过（时间值基于 start 计算，恢复可见自动正确）；TaskCenter onTaskEvent 加 gate（事件丢弃由轮询兜底）；AIConsole 隐藏丢事件。
**线3 渲染链**：MainLayout（根壳！）/HomePage/ModelCenterPage/AppearancePanel(8 处) 整 store 订阅改逐字段选择器——zustand 任意 set() 不再触发根壳与全部 keepAlive 页元素重渲染；MemoryHubPage 检索 hits key 从 index 改 `kind:brain:entity:i` 稳定字段。
**线4 缓存统一**：usePortraitUrl 导出 `getCachedAttachmentDataURL`（共享成功缓存+方法缺失防御）；Message.tsx/FileThumb.tsx/inspector.tsx 三处直调改走缓存；粘贴/截图落盘后直接复用内存 dataUrl 作预览（省第二次全量回读）。
**线5 AOA 几何**：nodeById/anchorById/taskNameById 查找表进 useMemo（taskName 原每边线性扫 tasks，O(E×T)/帧）；箭线几何管线（平行边计数/通道分配/分段/过桥弧）整段提升组件级 useMemo——缩放/选中态变化不再全量重算（zoom 走外层 scale 与几何无关）。四个 useMemo 全部移到 early return 之前（rules-of-hooks）。

## 坑

1. **组件 memo 化不是免费午餐**——ChatInspector 等的 props 里有内联数组/非稳定回调，memo 前必须先梳理 props 链，否则 memo 恒失效还加比较成本（本轮如实留池未做）。
2. **rules-of-hooks 是硬约束**——AoaView 有 early return（循环依赖空态），提升 useMemo 必须连同 manual/shown 计算一起移到 early return 之前，eslint 当场拦下。
3. **测试 mock 缺方法时可选链与直接调用的语义差**——原 `app.AttachmentDataURL?.()` 容忍 mock 缺方法，缓存包装直接调会让 ContextView 测试整组件崩溃（空 body 5s 超时）；共享工具函数要有方法缺失防御。
4. **整 store 订阅的代价被 keepAlive 放大**——根壳 MainLayout 粗订阅使任意 store set() 波及全部 13 页元素，这类「一个粗订阅拖全壳」的点优先级高于页面内局部粗订阅。
