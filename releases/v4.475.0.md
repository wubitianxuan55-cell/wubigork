# v4.475.0 · 首页书斋闲庭合一：双版式并一张「文书台」，全板块一屏尽收

**日期**：2026-10-09 ｜ **产物**：`releases/gaea-v4.475.0.exe`（SHA256 `1bda94d47d54f7dd…` 见 SHA256SUMS-v4.475.0.txt）｜ 冒烟 ✓ ｜ 全量 ci 绿（vitest 3792/439）

## 主旨

用户指令「优化使用，首页的书斋闲庭合一」。首页自 S2.1 双空间壳起按壳层空间分裂成两个完全不同的版式（书斋=案头卡片台 / 闲庭=游园画廊），切空间才能看到另一半板块——首页本应是「一切能力的中转」，不该是两个世界的门口。本版把首页合一：**一张「文书台」，书斋+闲庭全部板块一屏出卡**。

## 落地

- **classic 首页不再按空间分裂**：闲庭画廊版式（GardenHome/GardenBanner/GardenPoster 及 p-* 样式族，~370 行 JSX + ~330 行 CSS）随合一退役；统一台沿用案头版式 chassis（指挥卡/最近文档/侧列/能力矩阵/状态带），能力矩阵改为**全量派生**（`deriveLauncherModules` 不再传 space，space 参数随双首页摘除），旗舰收敛单一锚点 `LAUNCHER_FEATURED='gaea'`。
- **顶栏 书斋|闲庭 切换钮退役**：全应用唯一的手动空间切换入口本就在首页顶栏（v4.182 迁入）；合一后切空间完全由板块导航隐式驱动（v4.3.2c `navigateBoard` 按板块归属自动切换壳层空间），走查实证：统一台点「小说」→ rail 翻到闲庭分域。rail 顶部保留当前空间指示徽标。
- **收件箱跨空间全量**：首页任务卡计数与面板列表口径改 `scope=''`（后端 `FilterBySpace('')`=全部，Go 侧零改动）；**新建任务仍按当前壳层空间落标签**（`ValidSpace` 仅收 work|play，归属元数据不随展示口径漂移）；跨空间混合清单行内新增归属空间标（书斋/闲庭）。
- **任务优先形态同步合一**：能力 chips 全板块、收件箱同口径 `scope=''`、去 space/onSwitchSpace/activeModel 三 props（ModuleLauncher 自读 appStore.space 仅作保存标签）。
- **文案跟上合一**：`home.sub` 题辞三语改为双面口径（办公与创作同在一张台面上）；退役 `home.spaceSwitchAria/spaceSwitchHint/home.playTitle/home.playSub` 八键（三语）。
- **走查实修（本批放大既有弱点）**：能力矩阵并入闲庭板块后变高，把最近文档行（`minmax(150px,1fr)`）压到下限，空态竖排内容 ≈199px 溢出卡外、「进入办公」CTA 压到能力矩阵节标行——空态根修为**横排苗条态**（icon+文案+CTA 一行 ≈66px，flex-wrap 窄屏兜底），任何行高都放得下。

**明确不动**：壳层空间模型本体（rail 分域/事件分面 spaceBindings/每空间最后页面/keepAlive 空间剪枝/Ctrl+N 直跳小说）、搜索 scope 分域、hero 命令条/语音、状态带单行化成果（v4.474）、Go 侧零改动。
