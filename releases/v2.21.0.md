# v2.21.0「运行纵深 · 调度与异步化」（2026-08-14）

> 阶段 5 第一刀（T5-1 + T5-2）：通用任务调度器 + 批处理队列、实时文件监听。
> 规划：docs/superpowers/plans/2026-08-14-gaea长期规划-阶段5-运行纵深.md

## 背景痛点（均有代码实证）

- 价格抓取（GaeaPriceFetch/All）与文件索引重建（rebuildFileIndex，150s 超时）是**同步绑定调用**，
  页面阻塞数秒、无进度、无取消（2026-08-10 架构审查 D6，搁置至今）；
- 新文件最多等 **10 分钟**（10 分钟轮询）才能被语义检索命中；
- 进行中任务无持久状态：进程一重启全部丢失。

## T5-1 通用任务调度器 + 批处理队列

- **新包 `internal/gaea/tasks`**：持久化任务表（Hephaestus.db SchemaV8 `tasks` 表）+
  调度核心——状态机 queued → running → succeeded|failed|cancelled、进度 0-100 + 消息、
  **取消**（context 传播，running 中断 / queued 直接取消）、**自动重试**（指数退避，默认 2 次）、
  **手动重试**（Retry 重置重排队）、**重启续跑**（Startup 把上次 running 恢复 queued 重新排队）；
  进度事件经 `gaea-task` 事件通道实时推送（节流 400ms，终态必达）。
- **App 绑定**：GaeaTaskList / GaeaTaskCancel / GaeaTaskRetry（446 个导出方法 → 10 门面，
  `scripts/gen_bindings` 重新生成 + TestBindingsCompleteness 完备性兜底）。
- **首批消费者**：
  1. **价格抓取异步化**：GaeaPriceFetch / GaeaPriceFetchAll 改为提交任务立即返回；
     定时 cron（30 分钟）也走任务队列（到期源过滤在 handler 内按 cron 语义执行，已有活动任务去重跳过）；
     单源同源去重；失败明细在任务结果/消息里；单源结果含 fetchId 供前端定位 pending 记录
     （顺带修复 SaveFetch 按值拷贝导致返回记录 ID 恒为空的历史缺陷）。
  2. **文件索引重建异步化**：GaeaFileIndexRebuild 改为提交任务；分批 Ensure 报告进度
     （已索引 N/M 个文件），末批 Stale 清理；手动/轮询/监听触发共用队列去重。
- **前端任务中心**：办公右栏新增「任务」Tab（TaskCenter 组件）——活动任务（排队中/进行中）
  与历史分组、进度条、取消/重试按钮、失败原因、重试次数；gaea-task 事件实时增量刷新。
- **测试**：tasks 包 13 组（状态机/取消 running/取消 queued/手动重试/自动重试退避/重启续跑/
  Close 中断重排队/Wait/List/HasActive/payload 往返/进度节流）；App 层 6 组（单源任务流+落库/
  同源去重/一键抓取/List-Cancel-Retry 全链路/定时到期跳过/cron 去重）；
  Go 全量 **90/90 包 ok**、vet 干净。

## T5-2 实时文件监听（fsnotify 增量索引）

- **新包 `internal/gaea/filewatch`**：fsnotify 监听工作区目录树（跳过 .git/node_modules/
  dist/build/.venv/vendor/.gaea/releases/.tmp/backups）；事件**去抖合并**（2s 窗口）输出批次
  （changed/removed）；目录级变更（新建/删除目录）与**事件风暴**（>50 单文件事件）标记 Full
  → 触发全量重建任务；监听错误记录 WatchErr，调用方据此回退轮询。
- **增量索引**：删除事件直接清向量（semantic.Store 新增 Remove）；新增/修改提取正文后
  Ensure（内容感知，只重嵌变化文件）；失败自愈为全量重建任务；10 分钟轮询降级为兜底
  （监听健康时跳过）。
- **测试**：filewatch 包 5 组（增/改/删事件、跳过目录过滤、新目录 Full + 子目录监听、
  风暴合并 Full、Close 关闭通道）；真实语义索引任务流测试已更新为任务版。
- semantic.Remove 单测并入语义包全量。
