# v4.294.0 — 原罪·书源接线 t3：右栏「书源」页签——搜书→候选→目录预览→范围下载→成书清单（2026-09-14）

## 来源

sin 书源线 t3（规格 `docs/gaea-sin-booksource-distill-2026-09.md` §5；该线 t2~t5 自 DSH 并行线移交本线执行，用户拍板 2026-09-14）。t2 六绑定（`SinBookSourceSearch/Toc/Download/DownloadCancel/BooksList/BookDelete`，非版本刀 79271433）已落，本刀把它接成原罪用户可用的取书面：故事素材不必再离开原罪去别处搜。

## 落地

- **入口**：原罪右栏创作面板新增第五页签「书源」（角色/大纲/设定/插图/书源；`sinPanelState` 页签记忆兼容旧值，无计数徽标——清单自管不双向拉状态）。
- **`SinBookSourcePanel`（新，自包含）**：
  - 搜书行（关键字 + Enter/按钮）→ 候选表：**HasRule=可下载**，免规则候选标「仅参考」禁用（后端 fail-closed 边界的 UI 同款诚实）；各源失败 warnings 直显不静默；
  - 选中候选 → 目录预览（总数 + 首末样例 + truncated 注记）→ 范围选择（起/止章默认全本、钳制 [1,total]、起>终拦截）→ 「下载成书」；
  - 下载中：进度条 + done/total（进度按每 20 章上报）+ 取消（`SinBookSourceDownloadCancel`，本地立即收尾、后端中止不落盘）；**关面板不打断**（后台继续，完成后清单可见），事件订阅随下载态挂载/卸载必退订；
  - 三路事件（`sin-booksource:<jobId>`）：progress 更新 / done 成书进清单+清选中 / error 直显原因并提示可重试；
  - 成书清单（修改时间新→旧）：大小 · 时间 + 删除（Popconfirm，后端有路径护栏）。
- **dev mock 诚实空态**（`mock/sin.ts` +6）：搜索空候选+说明、目录空态、下载如实抛错、取消 false、清单空、删除 no-op——浏览器走查只验版面不假装有网。
- **事件通道登记**（`events.ts`）：`SIN_BOOKSOURCE_PROGRESS` + `sinBooksourceChannel()`，后端事件常量 24→25（头注同步）。
