# gaea v2.13.21「办公板块安全审计：封堵子代理绕过持久化写入审批」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.21.exe](gaea-v2.13.21.exe)（Windows x64，约 31.6MB）

对办公板块做了一轮安全审计，封堵最严重的审批绕过漏洞。

## 发现并修复

**子代理绕过逐条确认（严重）**：默认 `task` 子代理继承父代理的全部工具
（包括 cost_save / remember / knowledge_add / promote_session_facts /
install_skill），但运行在 headless 审批通道上（Approver 为空 → 自动放行），
可以直接静默写入成本库 / 记忆 / 知识库 / 技能文件，绕过 v2.13.19/20 的
硬性审批。修复：子代理注册表统一剔除这些持久化写入工具——它们只能由主代理
执行并逐条经用户确认；子代理专注只读研究，把结果交回主代理落盘。

**主代理遗漏的写入工具**：`forget`（删除记忆）与 `install_skill`（写入技能
文件）也纳入硬性逐条审批（任何权限级别含 yolo 都弹卡）。

## 复查结论（无新问题）

- Windows 控制台子进程全部设置隐藏窗口（含 MCP stdio 传输），不再有弹窗路径
- 知识库不注入系统提示词（仅检索）；技能索引 4000 上限、记忆索引 3000 上限
- 记忆 / 知识库 / 成本库写入均已有逐条确认

## 已知边界（按设计保留）

- yolo 权限级别对普通工具跳过确认是用户主动选择；持久化写入仍强制确认
- 子代理的 bash / write_file 在 ask 模式下仍走 headless 自动放行（研究型
  子代理需要 shell）；如需严格化可把子代理审批冒泡到主代理，另行实现
- 已写入的历史杂乱成本/记忆需在对应面板手动清理

- go build 通过；agent / control / permission 测试通过；wails build 通过
