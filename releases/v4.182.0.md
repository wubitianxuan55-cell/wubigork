## 3. 两首页各有特色（信息零删除，形态分化）

**书斋（work）「文书台」**——三栏效率台：
顶栏 + Hero 命令条（AI 打字/语音直启）+ **最近文档流水升级为主角面板**
（从右舷提升：序号/名称/路径三列行 + hover 箭头，点击进办公）+ 能力矩阵
Bento（旗舰 4×2 + 瓦片，紧凑密度）+ 右舷（遥测/写作环/会话/记忆/晨报）。

**闲庭（play）「游园画廊」**——全幅画廊（无右舷无命令条）：
居中标题行 + **会客厅旗舰横幅**（全宽渐变大卡 + 超大图标 + CTA）+ 
**板块大卡两列画廊**（松密度大卡）+ 园底信息带（创作进度环 + **继续话题**
最近会话 chips（点击进会客厅）+ 记忆脉搏 + 遥测细条三 Meter + 设置小卡）。
场景由画廊选择进入，遥测等信息单行化收于园底——两空间信息容量对等，
观感完全不同。

**零功能删除核对**：遥测/写作/会话/记忆两空间均可达（形态不同）；
晨报仅书斋（work 记忆红线不变）；最近文档仅书斋（work 语义）；
命令条语音直启为书斋形态，闲庭经会客厅卡/继续话题 chips 进对话。
