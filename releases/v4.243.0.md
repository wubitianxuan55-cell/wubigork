# v4.243.0 — 运行中 steer 直穿 + 危险操作分级审批（DAG §6 末项，绑定 627→628）（2026-09-12）

## 为什么是这一刀

DAG 设计档 §6 最后一条功能余项（roadmap §12.4 跃升 4 的后半句：「GaeaSteer 运行中
改向，危险操作分级审批」）。此前节点改向只对 done/failed 生效（续跑管道），
在跑节点只能等收跑；危险操作（覆盖/删除既有文件等）与普通写文件无差别直接执行。

## ① 运行中直穿改向

- agent 包加在跑登记 `subRunners`（ref=SessionID → *AgentRunner；
  `runSubAgentInternal` 起跑登记、defer 注销）+ `SteerSubagent(ref, text)`。
- `GaeaDagNodeSteer` 放行 running 节点：凭 node.Ref 找到在跑 runner，注入
  steer 队列——**不打断工具执行，下一回合生效**（与主对话 GaeaSteer 同机制）。
- 查无在跑登记（恰好收跑/ephemeral 无会话）如实报错，不静默转续跑。

## ② 危险操作分级审批

- dag_plan 节点参数 `risk`：normal 缺省 / high（覆盖删除既有文件、批量移动、
  全局性改动）；Validate 拒非法值。
- **执行器起跑前置闸**：dagExecute 每节点起跑前 `Risk==high && !Approved` →
  置 `StatusHold`（待审批），波收尾**链停**——下游保持 pending 不级联跳过，
  等审批后续跑。
- 新绑定 `GaeaDagNodeApprove`：hold→pending+Approved=true，**只放行不自动跑**
  （起跑仍人拍板，与整链首跑同闸）；已批准重跑不重新挂闸。
- ApplyEdit 把 Risk 计入形状比较：**风险变更=回 pending+审批归零**（新风险重新
  批）；FromRun/Instantiate risk 随模板走、approved 剥净（运行痕迹）。
