# gaea v2.12.0「稳定工程 + 成本库多级分类重设计」

发布日期：2026-08-11 ｜ 产物：[gaea-v2.12.0.exe](gaea-v2.12.0.exe)（Windows x64，约 41.5MB）

承接 v2.11.0 的四大库闭环，本轮把反复出现的「界面卡死 / 点不了 / 角色卡看不见」
系列问题系统根治，并把成本库从「单层分类 + 扁平列表」升级为「按分类分级保存 +
列表/表格双视图」，同时完成剧照文件化与记忆中枢/办公功能深化。

## 稳定性工程：WebView2 rAF 冻结根治

- **全应用弹窗关闭即卸载**：30+ 个 Modal 统一加 `destroyOnHidden + 禁用过渡动画`
  （角色面板抽卡/合并、记忆中枢成本/知识/画像/记忆/图谱/价格、小说剧情分支/AI
  编辑、绘梦、办公、聊天语音等）。根因：WebView2 冻结 rAF 时 antd 弹层关闭动画
  永不结束，全屏遮罩容器残留拦截所有点击，界面看似正常实则全部点不了
- **rAF 持续探测 + 看门狗**：探测从「启动 3 秒测一次」升级为运行期持续监测——
  每秒帧率检查 + 启动 3s 兜底 + 8s 冻结看门狗，WebView2 运行中才发生的 rAF 节流
  （失焦/后台误判）也能触发降级，降级后以 setTimeout 模拟 rAF 并禁用入场动画
- **降级名单补全**：角色库档案卡（`.ccard`）、首页启动器（`.ml-card`）、聊天气泡
  （`.chat-row`）入场动画一并禁用——修复「角色库打开后所有角色卡看不见也点不开」
  （动画卡在首帧 opacity:0）
- **前端诊断进 gaea.log**：ErrorBoundary 渲染错误、window.onerror、
  unhandledrejection、longtask、主线程心跳全部上报，下次卡死可直接定位根因；
  桌面端开启 WebView2 渲染调试端口（本地诊断用）

## 成本库多级分类重设计

- **多级分类树存储**：新增 `cost_categories` 分类树（parent_id 自引用、任意层级）
  + 成本条目 `category_path`（一级/二级/…/叶子）；旧分类字段保留兼容，既有条目
  自动按旧分类归入一级节点
- **默认分类按信息价体系**：一级 = 费用要素（人工/材料/机械/运输/检测/综合单价/
  其他）；材料按造价信息价细分三级（土建材料 → 钢材/水泥及水泥制品/砂石/装饰
  石材…、安装材料 → 电线电缆/管材管件/阀门…、周转材料），机械细分到土方/桩基/
  起重等；可随时增删改
- **分类管理**：新建/重命名/删除分类；改名自动重写该子树所有条目路径；删除有
  子分类或条目时拦截提示；搜索按分类路径含子树过滤
- **面板重设计**：左侧分类树（展开/计数/悬停操作）+ 右侧列表/表格双视图；表格
  可排序（标题/单价/更新时间）、全选、多选批量改状态/删除、价格历史；编辑表单
  用多级 TreeSelect，选到哪一级就存哪一级
- **工具升级**：cost_search / cost_save 支持分类路径（如「材料/钢材」），办公
  agent 测算引用按新分类体系检索

## 剧照文件化

- 角色剧照从内嵌 base64 改为落盘存路径（`characterlib/portraits/`），前端
  `PortraitImg` 按需读取渲染；超大内联头像（>300KB）列表/抽卡响应截断——根治
  「巨量 base64 撑爆 Wails IPC 导致界面卡死」

## 记忆中枢 / 办公深化

- 成本库：xlsx/csv 报价单导入（列映射 + AI 归一化 + 预览确认，无确认不落库）、
  价格源仓库（订阅源配置/抓取记录/一键抓取）、价格历史与 ±20% 跳幅识别
- 知识库：导入增强、版本历史、查重合并面板；画像库 CRUD；办公记忆两两查重 +
  一键合并；记忆 3D 图谱节点/筛选增强
- 后端：costimport / pricefeed / memory_hub / gaea 导入链路加固，批量测试覆盖
  （成本导入、知识导入、价格源、画像冲突裁决等）
