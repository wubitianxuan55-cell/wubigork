# gaea v2.6.4「CosyVoice2 提速 + 模型中心音色选择」发布说明（2026-08-09）

> 本版把 CosyVoice2 合成提速约 35%（短句 6.5s → 4.1s），并把音色选择直接放进
> 「模型中心 → 功能绑定 → 聊天语音」卡片——xAI / CosyVoice2 / Herdsman 绑定后即可选音色。

## 一、CosyVoice2 提速（ONNX + DirectML）

- **flow 解码器 estimator 切 ONNX + DirectML**：用模型仓库自带的
  `flow.decoder.estimator.fp32.onnx` 在 AMD 8060S 核显（DirectX 12）上推理，
  波形与 torch 路径相关性 **1.0000**（音质完全一致，仅数值舍入差异）
- **flow 采样步数 10 → 5**：flow 耗时约减半；实测短句合成 6.5s → 4.1s，
  长句 24.5s → 约 15s
- 速度分布（短句）：LLM ~4s（仍是主要瓶颈）+ flow ~1s + 声码器 ~0.2s
- LLM 优化探索结论：Qwen2-0.5B 已导出单步 ONNX（KV cache，fp32 CPU 28.8ms/步、
  DML 10ms/步），但链式推理与 torch 出现数值发散（内容相关），集成后音频失真，
  暂不启用；bf16 会破坏 EOS 采样（句子被拉满到最大长度），同样弃用

## 二、模型中心聊天语音卡新增音色选择

- 「功能绑定 → 聊天语音」绑定引擎/模型后，卡片内直接出现「音色」下拉：
  - xAI（grok-tts）：Eve / Ara / Rex / Sal / Leo + 旗舰 21 个
  - CosyVoice2：中文女/男、英文女/男、日语男、粤语女、韩语女（实时从 `/v1/audio/info` 拉取）
  - Herdsman qwen3-tts：服务端音色列表
- 选择即写 `tts_voice` 持久化，语音对话/朗读立即生效；设置面板里的音色选择同步
