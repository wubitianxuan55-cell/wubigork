## 核心变更

### P4-3 数据可迁移（本版重点）

- **一键备份**（设置 → 数据 → 一键备份）：打包全部本地数据为 zip + manifest——
  Hephaestus.db（记忆/知识/成本库/语义向量/价格源）、whisper_data（hermes.db、办公资料、
  角色库、聊天）、config.toml、sessions、archive、home 配置；
  SQLite 使用 **VACUUM INTO 一致性快照**（WAL 自动合并，运行中备份安全）；
  备份信息面板显示数据根、各条目大小与总量；
- **从备份恢复**（两阶段安全流程）：
  1. 校验 manifest → 解压到 staging → 写 pending 标记（拒绝非 gaea 备份/zip-slip 穿越）；
  2. **重启 gaea 后自动应用**——应用前先把当前数据整体移动到 `.restore-before-<时间>`
     （失败可找回原数据），再替换 staging 内容，清理标记并写恢复结果；
  重启后设置页展示恢复结果（成功/失败 + 原数据备份位置）；
  待应用恢复有醒目告警 + 可取消；
- 换机迁移：备份 zip 复制到新机 → 恢复 → 重启。注意 API 凭证（DPAPI 加密）跨机器不可解密，需重填。
