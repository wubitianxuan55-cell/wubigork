## 病根

「不满意→修」的最后一格是「只修我圈的地方」：全图编辑对已满意区域有回归风险
（模型每次重采样全图），蒙版局部重绘是 NovelAI V5/即梦/可灵全系标配。gaea 双编辑
档（OpenAI 兼容 /images/edits + ComfyUI Qwen-Image-Edit 2511）都有蒙版通道但从未
接线——前端没有涂选交互，后端请求没有 Mask 字段。

## 落地

1. **统一蒙版契约**：gaea 全链 `Mask` = 灰度 PNG data URL，**白=重绘区、黑=保留区**。
   前端画布黑底白笔刷导出，直观可预览；两端各自适配——ComfyUI 零转换
   （`ImageToMask(red)` 白→1.0），OpenAI 一处转换（`grayMaskToOpenAIMask`：
   白区→alpha=0 透明，OpenAI 语义透明=编辑区；标准库 image/png 零新依赖）。
2. **internal/ai ComfyUI 蒙版链**（尺寸对齐是本刀的技术核心）：
   `LoadImage(mask) → ImageScale(lanczos, targetW/H) → ImageToMask(red) →
   SetLatentNoiseMask(VAEEncode) → KSampler.latent_image`。**targetW/H 复刻
   `PREFERRED_KONTEXT_RESOLUTIONS` 17 档最近宽高比选择**（本机 ComfyUI 0.36
   nodes_flux.py:105 实读）——SetLatentNoiseMask 只裁剪不 resize，蒙版必须与
   缩放图同尺寸否则错位；原图尺寸经 `image.DecodeConfig` 取得，解析失败诚实报错。
   TextEncode 的 image1 保持**全图**（语义参考需全图上下文，重绘区域由 noise_mask
   限制——社区验证的 edit-model inpaint 形态）。
3. **internal/ai OpenAI 兼容**：editImage 在 Mask 非空时转换并附 `mask` multipart
   字段（与 image 同款文件名推断）。
4. **internal/app**：`mediaGenParams` +`mask` 键；fail-closed——`mask` 非空且
   `mode!=edit` → 拒绝「蒙版仅支持指令编辑模式」（img2img+蒙版留观察池不静默忽略）；
   edit 透传。
5. **前端**：新 `MaskBrushEditor`（strokes 状态驱动：显示层半透明红笔刷、导出层
   黑底白笔刷同坐标重放；指针坐标按 `getBoundingClientRect` 比例映射到自然尺寸，
   CSS 缩放显示不影响精度；jsdom 无 2d ctx 导出守卫 null 不崩；`renderMaskDataURL`
   归 `ui.tsx` 遵 react-refresh 惯例）。`InstructionEditModal` 加「范围：全图/局部
   （涂选）」切换 + 笔刷滑杆 + 清除 + 「已涂 N 笔」状态；局部未涂抹 → warning
   不触发生成。
