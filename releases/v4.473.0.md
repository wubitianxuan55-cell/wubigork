## 四刀明细

### 刀1 最近文档行重叠根修（走查实锤缺陷）

首页「最近文档」卡文件名互相叠印。根因：`.w-docs-row { flex:1 1 auto; min-height:0 }`——行被 flex 压缩到内容高以下（6 个文件 × 内容高 38px > 卡高，行收缩溢出叠印）。修复=`flex:1 0 auto; min-height:38px`：行保 flex-grow 均分富余高（文件少时仍铺满），超高交给列表内滚（`.w-docs-list overflow-y` 机制原本就在）。

### 刀2 首页顶栏模型 chip 退役（同屏双显去重）

`SpaceSwitch` 的 `ml-model-chip`（被动展示当前模型名）与壳层 strip 右上角模型 pill 同屏双显、信息完全重复，pill 恒可见。chip 退役；SpaceSwitch 的 `activeModel` prop 保留（兼容两空间首页与 TasksFirstHome 调用方）不再渲染，RobotOutlined 导入与 ml-model-chip 系 CSS 一并清。

### 刀3 strip 主题色点 7 颗 → 单钮弹出

壳层 strip（全板块常驻 chrome）右上 7 颗主题色点常驻 → 一个「当前主题色」触发钮 + antd Popover 弹层（placement bottomRight）。弹层内色点的切换行为、active 高亮、键盘可达（role=button/tabIndex/aria-label/Enter·Space）逐字保留；触发钮 title/aria 实时报当前主题名。strip 常驻控件 −6。

### 刀4 内核状态卡 CPU/MEM/GPU 仪表条退役（同屏两份去重）

首页状态卡排「内核状态」卡的三条仪表与壳层**底部恒常驻遥测轨**（CPU/内存/GPU）同屏两份。卡内独有信息全保留（已启用引擎数、本地·云端分布、ComfyUI 运行中指示）；`Meter` 组件与 ml-meter 系死 CSS 一并清。两空间首页（书斋/闲庭）同享。

**明确不动**：`ml-space-chip`（测试契约锁定）、hero 命令条、能力矩阵卡片、状态卡排其余三卡（最近会话/记忆脉搏/任务各有独有数据）、启动器 v11 布局骨架。
