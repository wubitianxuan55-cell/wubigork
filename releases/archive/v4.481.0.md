# v4.481.0 · 阶段八 8.5 变更声明+章级门禁（2026-10-15）

> 阶段八第五刀（承 v4.480.0 的 8.1~8.4）。规划判据：**门禁五类检查各有正反测试；拒收路径人可读**。与评测线互补——门禁=章级闸（本章声明的事实账可不可信），评测=阶段病历（10 章一段的体检）。

## 核心设计：生成时顺手声明，零额外 LLM

模型写正文时最清楚本章改了什么。`create-chapter` 模板 output 段新增第二标记：

```
---CHAPTER_SUMMARY---
（既有摘要）
---CHAPTER_CHANGES---
{"character_states":[{"name":"…","old":"…","new":"…","kind":"survival|"}],
 "foreshadows":[{"id":"既有ID（回收必填）","action":"planted|hinted|resolved",…}],
 "timeline":"本章时间推进（一句话）"}
```

生成链在摘要段之后切段提取（正文=第一标记之前，**流式剥离逻辑零改动**；先切段再取摘要——否则声明 JSON 会被 `Truncate(100)` 吞进摘要）。解析宽容剥 ``` 围栏。

## 五类确定性门禁（novelgate.ChangeDeclarationIssues，零 LLM 零 IO）

| # | Code | 级别 | 判据 |
|---|---|---|---|
| 1 | decl_unknown_entity | S2 拒收 | 声明角色不在角色卡（名字/别名） |
| 2 | decl_missing_reference | S2 拒收 | resolved 空引用 / 坏 ID / 引用条目已 revealed（重复回收） |
| 3 | decl_state_regression | S2 拒收 | 存活·心理两级水位章号 > 本章号（重跑低章不得覆盖高章状态——沿用 characterstate 既有水位语义单源） |
| 4 | decl_cast_mismatch | S2 拒收 | 声明变更的角色正文零提及（排除词剔除后子串匹配；排除词「老王爷」把老王从「王爷」命中域剔掉的语义如实保留） |
| 5 | decl_invalid_action | S2 拒收 | action 枚举外 / planted 缺描述 |
| — | decl_timeline_missing | S3 提示 | timeline 缺失（不拒收） |

**口径**：声明缺失/坏 JSON=软降级不计违规；拒收=声明的落库被拒（`DeclChanges` 不落盘）+done 事件 `declGate.issues` 人可读中文清单——**正文照常保存，永不因声明失效**（正文是主产物，拒的是元数据）。五类各有正反测试（规划出口判据逐类落地）。

## 价值闭环：定稿草案零 LLM 预填充

过闸声明随章节摘要落盘（`ChapterSummary.DeclChanges`，omitempty 零迁移）。`FinalizeChapterDraft` 优先消费它（`draftFromDeclaration`：角色状态→Progression 草案按名对齐 ID；伏笔→同步草案；`fromDeclaration` 标记回带）——**无 client 也照出草案**（声明路径在模型守卫之前）；缺失/空草案才回落 8.4 的 ExtractOnly 现提取（模型在写正文时最清楚改了什么，事后提取是兜底不是主路径）。

定稿确认后走 8.4 既有幂等链（Progressions Note 标记整批替换 / 伏笔 SyncForeshadows 幂等 upsert / 合账缓存）。
