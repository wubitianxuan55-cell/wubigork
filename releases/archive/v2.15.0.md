# gaea v2.15.0「模型中心 P0/P1/P2 + UI 重设计」发布说明（2026-08-13）

> 本版按市场调研（Open WebUI / Cherry Studio / Dify / Jan / Ollama 生态）系统优化模型中心，
> 补齐引擎状态联动、连接诊断、功能绑定回退态、搜索/置顶、资源占用可视化、选择器统一、
> 批量启停与统计抽屉，并对模型中心做浅色/深色双主题重设计。桌面端已打包。

## 一、模型中心 P0（可用性）

- 引擎状态 → 模型可见性联动：语言/专业/语音模型卡片区分「未连接 / 未启动」，
  未连接的模型置灰并禁用「启动 / 设为」动作，避免误选不可用模型。
- 测试连接诊断增强：后端 `EngineStatus` 新增 `latency_ms`，`TestConnection` / `RefreshModels`
  实测延迟；前端成功提示「N 个模型，Xms」，失败弹出具体原因。
- 功能绑定回退态：新增 `featureState` / `routeSourceLabel`，功能绑定卡片明确显示
  「已绑定生效 / 已绑定·停用（回退全局）/ 跟随全局默认」，并支持「重置为跟随全局」。

## 二、模型中心 P1（效率）

- 模型网格统一搜索：语言 / 语音 / 专业模型都支持按名称或模型 ID 搜索。
- 收藏置顶：模型卡片支持置顶，置顶排前，状态持久化到 localStorage（跨分区/重启保留）。
- 本地资源占用可视化：新增常驻「本地资源占用」面板，每 4 秒轮询 `GetModelMonitor`，
  展示 CPU / 内存 / GPU / 显存与本地已启动引擎、ComfyUI 运行状态。
- 模型选择器统一「按后端过滤 + 兜底」：功能绑定、聊天语音、角色库剧照共用统一逻辑，
  当前模型不在候选时自动补一条，避免表单值悬空。

## 三、模型中心 P2（维护性）

- 引擎批量启停（全部启用 / 全部禁用，禁用带二次确认）+ 「仅显示已启用」过滤。
- 「调用统计」从左侧主导航收进头部「调用统计」按钮打开的抽屉，主界面更清爽；
  抽屉打开时才轮询刷新（统计采集始终在后台进行，不受影响）。

## 四、UI 重设计（浅色 / 深色双主题）

- 使用 redesign-existing-projects / ui-ux-pro-max 两套 skill 审计现有模型中心：
  - 将模型卡片、空状态、面板、激活态等硬编码的深色背景/阴影改为 gaea 主题 token
    （`--bg-glass` / `--bg-elevated` / `--shadow-*` / `--mc-accent`），
    浅色模式下不再出现「深色卡片嵌在浅色页面」的突兀。
  - 卡片 hover 边框、激活态、阴影统一为主色与主题 elevation token。
  - 分区标题 `text-wrap: balance`，描述行高 1.6，视觉更透气。
