# v4.290.0 — 拆书导入线：角色名→角色库 ID 匹配（反推落库补全出场角色）（2026-09-14）

## 来源

拆书导入线在案欠账（v4.281 起「角色名只进预览，角色 ID 匹配另刀」）。反推条目带**角色名**（`OutlineReconstructItem.Characters`），而大纲节点 `Characters` 字段收**角色 ID**——此前名字到预览为止，落库后大纲的角色维度始终空白。本刀补上名字→ID 的最后一环。

## 落地

### 匹配：`matchCharacterIDs`（app 层纯函数）

- 精确名优先；**双向包含兜底**（反推给「林晚」、库里有「林晚儿」也命中）；
- 去重保序；未知名**静默跳过**——角色库是用户资产，不因反推编造角色；
- 角色库为空 / 读失败 → 无匹配，不影响其余合并（诚实降级）。

### 接线：`NovelOutlineReconstructApply`

命中章节点写 summary 等字段时，同步把匹配到的 ID **合并**进 `node.Characters`：既有 ID 保留在前、新增追加在后、去重——手工配置的角色不被冲掉。预览不可见该字段（不序列化），只落库生效。
