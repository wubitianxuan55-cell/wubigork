# gaea v2.14.9「聊天板块后端：原子落库 + AppendMessage 收敛」

发布日期：2026-08-13 ｜ 版本号：v2.14.9 ｜ 产物：[gaea-v2.14.9.exe](gaea-v2.14.9.exe)（Windows x64）

继续收敛聊天板块后端的消息写入路径，前端无改动。

## 后端

- `AppendMessage`：改用 `INSERT ... RETURNING id, seq`，一次拿回自增 id 与 seq，
  替代「先查 MAX(seq)+1 再插入」的两步操作，消除竞态窗口。
- 新增 `chat.Store.AppendExchange`：在单事务内原子写入「用户消息 + 助手消息」并刷新
  `updated_at`，任一写入失败则整体回滚。
- `appendChatExchange` 改走 `AppendExchange`，落库失败记录错误日志，不再静默丢弃。

## 测试

- 新增 `TestStore_AppendExchange`：验证两条消息按序落库、seq 正确，以及不存在话题时整体回滚。
