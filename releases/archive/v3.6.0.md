# gaea v3.6.0 发布说明

> 2026-08-29 · 办公板块体验收敛：文件编辑审阅制（先规划后应用）+ 原生图表 + PDF
> 统一出口 + 办公本地优先路由 + 运行中插话；对话面减负（方案模式 v1 回退、
> 任务目标撤下、用户消息 Codex 式收敛）。

## xlsx AI 编辑审阅制（Plan → Apply 两段式）

原 `GaeaXlsxEdit`（一次调用直接改文件）拆为两段，对标 Copilot in Excel 的
Plan / Show Changes 范式：

- **`GaeaXlsxPlanEdit`（规划，不落盘）**：上下文 → AI 规划操作集 → 在**原文件的
  临时副本**上试运行（合法性与真实摘要一致，副本执行失败即规划失败，原文件保持
  原样）→ 与原文件逐单元格 diff 出**变更清单**（before/after/formula，读取预算内
  截断为下界）。返回的 ops 原样带回，应用时透传。
- **`GaeaXlsxApplyEdit`（应用）**：用户在审阅卡批准后才执行（excelize 写入 →
  LibreOffice 重算公式 → 返回更新预览）。
- **新增操作类型**：`set_style`（**叠加样式**——只写需要改的字段，其余保留现有
  填充色/数字格式，`mergeStyle` 生成新样式 ID）、`merge_cells` / `unmerge_cells`、
  `set_col_width`；规划提示词补充「用户没提外观就不要擅自改样式」纪律。
- 前端 `XlsxPreview` 规划审阅卡：待应用变更清单（处数 + 截断说明）→ 批准应用 /
  取消；测试覆盖 PlanOps 试运行 / diff / 样式叠加 / 归一颜色。

## xlsx 原生图表（嵌入工作簿，非截图）

`gaea_xlsx_chart.go` 改用 excelize 在工作簿内**嵌入原生图表对象**：Excel/WPS 打开
即可见、可继续编辑（柱/线/饼），返回锚点单元格与数据供前端迷你预览——对标
Gemini in Sheets / Copilot in Excel 的「原生对象而非截图」交付标准。

## PDF 统一出口（GaeaConvertToPdf）

- 顶栏「导出 PDF」：会话成果一键导出（docx/pptx/xlsx/md/pdf 同管线；md/markdown
  不被 LibreOffice Writer 直接支持，经 docx 中转链再转 PDF——「任何文档 → PDF」
  统一出口），PDF 落 `.gaea/exports/`。
- `soffice --headless --convert-to pdf` 与重算共用 LibreOffice 依赖底座，转换使用
  **独立 UserInstallation profile**，避免与重算/用户正在打开的 LibreOffice 实例
  发生 profile 锁冲突；soffice 定位 PATH 优先 + 常见安装位置兜底。
- 文件缩略图/预览支持 pdf/docx 文本提取（文本缩略图 + UTF-8 字符边界截断防乱码）。

## 办公本地优先路由（routeOfficeLocal）

办公板块**功能级** AI 调用（Word/Excel AI 编辑、资料摘要、知识导入、记忆整理）
默认优先路由本地 Herdsman：数据不出本机、省 token；Herdsman 停用/不可用时自动
回退常规路由保证可用性。聊天主 agent（统筹规划）**不受影响**——本地小模型不足以
承担复杂工具编排，仍按模型中心绑定走。

- 配置 `office_local`（默认开启）+ 绑定 `GetOfficeLocal` / `SetOfficeLocal`；
- 安全设置面板新增「办公本地优先」开关（乐观更新、失败回滚）；
- 与既有的 `sensitive-local`（敏感级）共用 `routeHerdsmanLocal` 公共实现，source
  区分策略来源供前端与诊断展示。

## 运行中插话（GaeaSteer）

对齐豆包工作「边跑边改」：任务运行中的补充消息作为**当前回合的 guidance** 注入
agent（每步采样间隙消费，不开新回合、不打断工具执行）；未运行（无回合可插话）时
走 `GaeaSend` 排队兜底。`event.Steer` → 前端 notice 轻量回显（不渲染成独立用户
气泡）。

## 对话面减负（Codex 式收敛）

- **回退 C1 方案模式 v1**：Controller 会话 mode / `shouldPlan` / `planGate` 门控、
  `Ask.Plan` 结构化计划卡、composer 默认/方案切换器、`GaeaAgentMode` /
  `GaeaSetAgentMode` 绑定、`Agent.AutoPlan` 配置、决策日志 `auto_plan_score`
  字段全部撤下——与既有 goal/todo 闸门职责重叠（候选清单自评「计划生成短流
  价值低；执行推进已有 goal/todo 卡」），方案模式连同计划流式事件列后续观察项。
- **撤下「任务目标/验收清单」功能**：GoalCard + `GaeaRequirement` 系 8 个绑定 +
  requirements 存取层（早期「从需求到验收」工作流，使用率低、维护面大）。
- **用户消息 Codex 式收敛**：无气泡、右对齐、与助手回复同宽（对话记录更线性）；
  Kimi Work 式**超长消息折叠**（超 240 字符默认 3 行截断，展开/收起切换），
  避免长任务描述把对话撑爆。

## 修复

- **whisper 记忆写入关机排水丢任务**：排队中的任务对 chain 令牌不可见，shutdown
  末轮 drain 等不到它们 → 整批抽取被跳过（丢记忆）；补 `pending WaitGroup`
  （入队即计数，drain 等到所有已入队任务真正执行完）。
- **trajectory/contextview 空切片序列化 null**：Go nil 切片 JSON 序列化成 null，
  前端按数组消费会崩；绑定层早退路径改返回 `EmptyTimeline` / `EmptyTrajectory` /
  `EmptyAgentNetwork`（切片一律非 nil）+ 前端 TrajectoryView 归一化兜底。
- **TrajectoryView 测试负载 flaky 加固**：全量套件高负载下 jsdom 调度饿死 RTL
  默认 1s 超时（复现为偶发 2 例失败、单跑必过）；异步等待显式放宽到 5s（仍有
  上界，不掩盖真回归）。
