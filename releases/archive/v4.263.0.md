# v4.263.0 — 原罪右栏创作面板：角色 / 大纲 / 设定 / 插图（2026-09-12）

## 用户口径

「继续优化原罪板块，增加类似办公的右侧面板，可以看角色、大纲、插图、设定。」

## 改前状态

- 原罪右栏（`sin-side`，268px）是**静态说明栏**：角色卡 + 玩法 / 插图协议 / 边界三张
  固定卡；窄窗（<1180px）被媒体查询整栏隐藏。
- v4.262.0 给了模型 `sin_notes`（设定集）与 `sin_outline`（大纲）两个工具，底稿落
  `%APPDATA%\gaea\sin\notes\<故事id>.json`——但**前端没有任何读取通道**：AI 写了什么、
  改了什么，用户全程看不见。
- 插图散在正文流里，想回看某个故事出过哪些图只能从头翻。

## 落地

### ① 新绑定 `SinNotesGet(topicID)`（640→641，spaceBindings=play）

- `internal/app/sin_store.go`：返回 `SinNotesView{notes []string, outline string}`，
  只读同源便签文件（`sinNotesPath` + `loadSinNotes`）；与工具侧共用 `sinNotesMu`
  单写者锁；`sinTopicGuard` 守卫（非原罪故事/未知 id 拒绝）。
- 容错口径与工具侧一致：文件缺失/损坏 = 空清单 + 空大纲（辅助数据不阻断）。
- `gen_bindings` 再生后按纪律 `git checkout` 还原 office/cost 门面（v4.237 手工
  单参化是权威态）；`bindingNames.ts` 按 `-names` 输出手工同步；drift OK@641；
  `spaceBindings.test.ts` 分类计数锁 462→463。

### ② 右栏改办公同款标签页面板 `SinSidePanel`

四页签（页签带计数徽标，激活态 accent）：

| 页签 | 内容 | 数据源 |
|---|---|---|
| 角色 | 既有 `SinCastPanel` 原样入页签（chips + 选择/调整 + 移除） | `SinCastGet`（不变） |
| 大纲 | sin_outline 记的章节走向，pre-wrap 只读 | `SinNotesGet().outline` |
| 设定 | sin_notes 设定集，逐条卡片带 `#序号` | `SinNotesGet().notes` |
| 插图 | 本故事全部产物画廊：缩略图点开 Modal 大图 | 消息 `extra.illustrations` + 正文标记反解 caption |

- 插图画廊：`collectIllustrations`（storyText.ts 纯函数）按消息序收集全部
  `{cue → path}`，caption 从正文 `@@插图|…@@` 标记反解；本地路径经
  `readFileAsDataURL`（AttachmentDataURL 通道）转 data URL，与流内插图同口径；
  读取失败如实标「读取失败」，空路径跳过。
- 空态一律 V3Empty compact 轨道环（v4.261 归一口径）+ 引导话术。

### ③ 玩法/插图协议/边界 → 问号气泡

三段静态说明收进面板头部的问号 Popover（内容逐字保留）——版面降噪但功能不删
（UI 简化红线：简化 ≠ 删除功能）。

### ④ 面板开合与记忆

- 顶栏 PanelRight 开合钮；记忆键 `gaea.sin.panelOpen` / `gaea.sin.panelTab`
  （原罪自有命名空间，不借办公 workbench 空间键——与数据面硬隔离同口径）。
- 宽窗默认开、窄窗（≤1180px）默认收，替代原「窄窗强制隐藏」媒体查询——
  开合权交给用户，功能不以尺寸为借口消失。

### ⑤ 底稿实时性

每回合结束（`sending` true→false 沿）自动重读便签/大纲（AI 可能在回合里用工具
写了底稿）；切故事即重读；mock（`?mock=1`）补 `SinNotesGet` 与便签/大纲种子，
浏览器走查可见。
