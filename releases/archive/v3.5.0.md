# gaea v3.5.0 发布说明

> 2026-08-28 · 办公对话区标签页 + dsh-context Go 移植（上下文 / 轨迹 / Agent 网络）。
> 对话窗口上方新增 [对话 | 轨迹 | 上下文] 三标签：上下文 = 逐请求上下文构成看板，
> 轨迹 = 对齐 DSH ui-trajectory 的事件账本，Agent 网络 = 主 agent + 子代理树。

## 对话窗口三标签（对话 / 轨迹 / 上下文）

办公板块聊天窗顶部新增标签条 `ChatTabs`（localStorage 持久化）：

- **对话**：现有 Transcript（零改动）；
- **轨迹**：从会话事件日志折叠的**扁平事件账本**（对齐 DSH `ui-trajectory` 语义——
  按轮次组织、粗分割线、每条记录带类型徽标与检查器）；
- **上下文**：上下文构成看板（统计 / 当前组成 / 趋势 / 步骤详情 / 事件流 / Agent 网络）。

## `request_header` 事件（模型可见必入日志的请求头落点）

新增 `event.RequestHeader`：agent 在**每次模型请求前**把实际发送的 system prompt 与
工具 schema 写入会话日志（`request_header` 行）。这是上下文/轨迹看板 system/tools 分类
的精确数据源，也补上了「模型可见必入日志」不变量在请求头一层的缺口；旧日志无此事件时
按估算降级，不硬报错。

## 上下文标签（contextview 包 + GaeaContextView）

新包 `internal/gaea/contextview`：`FoldTimeline(entries, window, retention)` 纯函数折叠
会话日志为逐请求上下文快照：

- **六分类组成**：系统提示词 / 工具定义 / 用户消息 / 注入内容 / 助手消息 / 工具结果，
  token 估算复用仓库口径（chars × 0.25），有 usage 时按实际 promptTokens 等比锚定
  （与顶栏 ContextBar 同源）；`Referenced context:` 前缀的用户消息拆分为 inject + user；
- **趋势图**：每请求一根原生 SVG 堆叠柱，步数|轮次|全局|增量四钮（增量暂禁用，Phase B），
  压缩/剪枝 ✂ 标记，点击柱联动步骤详情卡（输入→回复 / 实际 prompt / 输出 / 缓存率）；
- **上下文事件流**：注入 / 压缩 / 剪枝筛选；压缩节点标记 gone 并计负 delta、进归档；
- 新绑定 `GaeaContextView()`（绑定面 +1），7 个折叠黄金测试。

## 轨迹标签（trajectory 包 + GaeaTrajectory）

新包 `internal/gaea/trajectory`：`FoldTrajectory(entries)` 对齐 DSH 轨迹的事件账本语义——

- **扁平记录表**：user / request-header / assistant / tool / compact / ask / approval，
  每条带 ts、durationMs、step 归属；request-header 带 change 检测
  （initial / system / tools / system-and-tools）；
- **工具记录**：dispatch + result 按 ID 合并，保留 parentId（子代理嵌套树的根）、
  running/error 状态、截断标记、耗时；
- **轮间压缩**独立成 Between-turns 区段，轮内压缩留在轮内，turn-end 带错误；
- 前端 `TrajectoryView`：统计 chips（Duration/Turns/Calls）+ 搜索框 + 类型徽标
  （ASSISTANT 紫 / TOOL 橙 / 提问 深蓝 / REQUEST HEADER / COMPACTION）+ 点击展开
  检查器（工具参数/结果、请求头、用量、耗时）；9 个折叠黄金测试 + 5 个 vitest。

## Agent 网络（FoldAgentNetwork + GaeaAgentNetwork）

新折叠 `trajectory.FoldAgentNetwork`：主 agent 为根，子代理 = 日志里拥有子工具记录
（parentId 指向它）的 task / run_skill / explore 等元工具调用（不写死工具名）；每节点
聚合子树工具调用数 / 错误数 / 估算 token / 首末时间，状态推导 running/error/completed；
`GaeaAgentNetwork` 绑定用 subagents/ meta（任务摘要前缀匹配）富化状态与模型。
前端 `AgentNetworkCard`（挂上下文页底部）：SVG 树 + 节点 token 占比环 + running 绿脉冲
+ 一级子树各一色相 + 悬停详情条；3 个折叠黄金测试 + 3 个 vitest。

## 随版并入：记忆统一层第二刀前端收尾（并行工作流）

`GaeaMemoryUnarchiveBatch` / `GaeaMemorySetRetentionDays` 的前端接线（bridge 类型、
批量恢复 / 保留期设置 UI 与 mock、生命周期测试补强）随本版一并入库（后端已在 v3.4.0 后
提交，本版完成前端侧对齐）。
