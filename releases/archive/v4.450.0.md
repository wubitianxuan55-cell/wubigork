# 分支→章节计划→生成章节 三点打通（v4.450.0）

> 用户报缺：「根据剧情分支生成章节计划后没有进行章节故事生成的按钮」。
> **绑定面 743 零变更**（NovelChapterPlanPropose 签名扩展，无新增绑定）。

## 诊断：三处真实断链

1. **计划→生成无出口**：`ChapterPlanCard` 保存计划后只回调 `onPlanSaved`，
   横幅文案是「先补章节计划，再回生成入口」——闭环最后一公里靠作者自己走回去。
2. **新章 Propose 必失败**：下一章的大纲节点自动建于首次生成；对尚未生成的章，
   `NovelChapterPlanPropose` 直接报「未找到第 N 章的大纲节点」——硬闸弹窗里
   「立即生成计划草案」点开计划卡后，作者点「生成计划草案」**必然失败**
   （先有鸡还是先有蛋）。
3. **分支内容不进计划**：分支意向（plotReq=`标题：pitch`）只流入生成 prompt；
   计划提案的输入里没有它，「根据分支生成计划」实际等于「按主线大纲生成计划」。

## 落地

- **签名扩展**：`NovelChapterPlanPropose(chapterNum)` →
  `NovelChapterPlanPropose(chapterNum, direction)`。direction=作者创作方向
  （分支意向/剧情要求），空串=既有口径；**无大纲节点 + direction 非空 → 兜底
  编译**（主线/前文摘要窗/已有关键事件/名册照常注入，chapter_outline 空槽位
  不渲染）；direction 为空且无节点仍如实报错指路（手写计划 / 跳闸生成）。
  模型缺省标题时无节点路径补「第 N 章」。
- **模板**：`prompts/chapter-plan.json` 增「本章创作方向」P0 槽位（order 3，
  后续槽位顺延）+ must 约束「出现创作方向时 key_events 与 plot_summary 必须
  落实该方向；未出现时按大纲节点推进」。
- **计划卡**：①卡头「生成本章」出口（`onGenerate`，有计划且非编辑态时出现，
  点击回传章号+计划）；②direction 横幅（来源标注「来自分支/剧情要求」）；
  ③硬闸横幅文案在有出口时改指「点右上角生成本章」。
- **CreatePage**：硬闸 blocking 时把本次 plotReq 存为创作方向种子 + 记录预检
  目标章号——「立即生成计划草案」打开的计划卡因此带着分支意向、且章号与预检
  一致（旧口径 active 停在上一章时计划卡章号差一章）。工具轨手动展开不带种子；
  切章覆盖章号让位。`handleGenerateFromPlan` 以计划情节摘要为剧情要求发起生成
  （后端生成时按章号注入本计划），缺摘要时回退叙事目标/种子并如实提示。
