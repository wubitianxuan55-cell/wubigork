# v4.271.0 — UX 线第三刀：滚动条全站单一真源（视觉降噪）（2026-09-13）

## 来源

用户指令「继续优化迭代 gaea 的前端 UI」——接续 v4.255.0（进度计划主题桥接+全站
空态统一+全局焦点环）与 v4.260.0（--radius 桥接 M3 + modelcenter 空态收敛 +
--sched-dim 修复）的 UX 线第三刀。普查先行：CDP 起壳 **26 页次（13 rail 页×明暗
两态，code=独立窗口跳过）** 巡检——横向溢出零、越界元素仅首页极光装饰球（刻意
设计）、console 错误零（仅 reload 瞬时 Wails 回调时序噪音一条）——结构层无硬伤，
问题在视觉层。

## 普查发现：四套滚动条定义并存

| 位置 | 形态 | 实际效果 |
| --- | --- | --- |
| `index.css` 33（全局） | 6px + outline-variant 中性 | 被同文件尾部覆写 |
| `index.css` 659「滚动条霓虹化」（v1.3.0 遗产） | thumb=glow 渐变 + 无效的 `opacity:0.7` | **亮青渐变粗条喧宾夺主**（chat 消息区/modelcenter 中栏/imagegen 左栏最扎眼） |
| `gaea/styles.css` 520（全局） | 10px + `--border` | 办公域旧定义 |
| `redesign.css` 253（.gaea-app-layout 作用域） | 8px + `--border`/`--bg` 描边 | 办公工作台另一套 |
| `module-launcher.css` 41（.ml 作用域） | 10px 胶囊 + on-text 14%/24% 半透明 | **形态最正确的一套** |

而 novel/sin 等用 `scrollbar-width: thin`（标准属性优先）的区域是原生细条——
同屏两态，观感割裂。根因是 v1.3.0「未来感 UI」时代的霓虹遗产从未随 v4.255/260
的令牌收敛一起清偿。

## 落地（纯 CSS，零 TS/零 Go/零绑定）

1. **全局单一真源**（index.css）：8px 中性胶囊——thumb=`color-mix(on-surface
   18%, transparent)` + 2px 透明内缩边 + 胶囊圆角，hover 提亮到 30%（取
   module-launcher 形态升全局，明暗自适应）。
2. **删霓虹化覆写**（index.css 659）：glow 渐变 thumb 退出；同段顺手清了一处
   **死规则**——v4.255 拍板的 `::selection`（color-mix primary 30%）一直被文件
   尾部 v1.3.0 的 glow 版覆盖从未生效，两处合一保留生效形态（glow 底+on-primary
   字，零视觉变化），注释指明唯一真源位置。
3. **删三处重复定义**：gaea/styles.css 全局 10px、redesign.css .gaea-app-layout
   8px、module-launcher.css .ml 10px——各留一行指回 index.css。
4. **保留**：功能性隐藏（novel-subnav/ig-mode-nav/settings-nav 导航条 `display:none`）、
   tailwind `scrollbar-thin/hidden` utility（现无消费方，显式 opt-in 档）、移动端
   隐藏断点、`scrollbar-width: thin` 散布（原生细条视觉可接受，标准化另刀）。
