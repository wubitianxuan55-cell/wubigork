# v4.183.0 · 双空间首页重排版：书斋「文书台」/ 闲庭「游园画廊」编辑部级排印

日期：2026-09-09 ｜ 类型：前端 UI 重排版 + 主题系统结构修复 ｜ 绑定面：602 零变更

## 缘起

用户反馈 v4.182 两首页「布局太 low」。定位：**同质卡片海**是模板感/廉价感根源——
书斋 = 8 张等大 Bento 瓦片 + 右舷 5 个同款玻璃小盒，缺排印层次与主次；
闲庭 = 横排表单式大卡（图标左名称右）读作设置列表而非画廊。

重排版原则：**信息零删除**（遥测/写作/会话/记忆/晨报/最近文档/全部入口两空间均保持可达），
只动形态。设计方向经 ui-ux-pro-max 双查询：书斋 = Premium refined（premium black +
金属感、Liquid Glass、editorial）；闲庭 = Bold gallery（variance 8 / density 3、大字排印、大留白）。

## 书斋（work）「文书台」——编辑部/文房排印

- **竖排空间名书脊**：masthead 左侧 `writing-mode: vertical-rl`「书斋」+ 渐隐竖线（aria-hidden，
  信息与切换器重复）；≤900px 收起。
- **大字渐变标题**：30px/800，正文色→glow 渐变 `background-clip: text`（排印主 moment）。
- **Hero 命令条**：保留 AI 打字/语音直启/⌘K 全功能，radius 18px + `focus-within` 辉光。
- **最近文档卷宗**：去卡片盒，改 hairline 报表行——等宽序号（hover 点亮为 glow）+
  名称 + rtl 路径 + hover 滑入箭头。
- **能力目录**：旗舰横带（左 accent 竖条 + 细网格纹理 + 徽记 + CTA 胶囊）+
  **目录式索引行**两列报表（等宽序号 01-05 + 徽记 + 名称 + 单行描述 + hover 箭头/辉光），
  替代等大瓦片——编辑部分级优于均质网格。
- **右栏单一仪表纵栏**：一块玻璃面板内 hairline 分节（内核状态/写作进度/最近会话/记忆脉搏/晨报），
  节头 = 小号宽字距标题；替代五个同款小盒。≤1180 落底双列、≤640 单列。

## 结构修复：M3 tertiary 角色补定义（v4.182 遗留缺陷）

v4.182 闲庭激活态用 `var(--md-sys-color-tertiary-container, fallback)`，但 tertiary 角色全仓从未定义，
暖色恒走 fallback——闲庭与书斋实际同色，「暖色分版」从未生效。本次：

- `appStore.ThemeTokens` 增 `tertiaryContainer / onTertiaryContainer`；
- 新增 `TERTIARY` 暖伴侣色表（6 预设 × 明暗，深色档=深哑容器+亮 on，浅色档=浅粉彩容器+深 on），
  `getThemeTokens` 合并注入；`App.tsx` 下发两个 CSS 变量；
- 契约测试锁定（12 套主题 tertiary 对存在且 container ≠ on）。
