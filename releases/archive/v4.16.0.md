  参数（frame URL 子串或 CSS 选择器定位）→ `Page.getFrameTree` 找 frameId →
  `Page.createIsolatedWorld` 拿 contextId → 该上下文执行既有 JS 片段；未命中报
  not_found。**真 headless Edge 真机验证 iframe 内 Read/Click/Type 全通**。
- 欠账：snapshot 不下钻 iframe（frame 模式不支持 ref，诚实报 validation_error）；
  srcdoc iframe 无 src 不支持（提示用 URL 定位）。
