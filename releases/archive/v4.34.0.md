# v4.34.0「子代理气泡恢复 · 恢复会话不再丢失子代理答复」

> 发布日期：2026-09-02 ｜ tag：`v4.34.0` ｜ 基线：v4.33.0 ｜ 绑定面 **552 零变更**（HistoryMessage 结构字段级，`wails generate module` 已刷新）

## 背景与根因（收 v4.26/v4.28 沿旧欠账「子代理气泡恢复暂缺」）

实时会话里子代理最终答复以 `subagent_message` 事件回投主区、带「子代理」徽标（v4.26；
v4.27.2 修通 wire 层），但**恢复会话后这些气泡整条消失**。根因（本刀探查钉死）：恢复链
GaeaResumeSession → ResumeFromDisk → `session.ProjectMessages`（日志→消息投影）→
GaeaHistory——**ProjectMessages 的 switch 没有 subagent_message case，条目被整条忽略**，
子代理答复在 provider History 里根本不存在。

**关键约束**：ProjectMessages 的投影结果直接喂给模型（恢复后模型可见上下文），实时运行
期模型上下文同样不含子代理答复——**不能给投影加 subagent_message**（会让恢复后的模型
上下文偏离实时语义）。因此走 **UI 侧并行投影**。

## 交付明细

### ① UI 侧锚点投影（线A，Go）

- session 包新导出（新文件 subagent_anchor.go，**projection.go 一字未动**）：
  - `KindSubagentMessage = "subagent_message"` 常量（此前 log.go 是字面量；测试双向锚定
    == KindString(event.SubagentMessage) 且 == 磁盘字面量）。
  - `SubagentAnchor{Text, Ref, ParentToolID string; AfterMsgIndex int}` +
    `ProjectSubagentAnchors(entries []LogEntry) []SubagentAnchor`——与 ProjectMessages
    逐 case 同拍的状态机镜像（user/system/assistant_started=+1；delta/text/reasoning/
    tool_call=ensurePending 才 +1；assistant_message=pending<0 时 +1 否则原地替换 +0；
    tool_result=关 pending +1），遇 subagent_message 记锚点（游标=此时已投影消息数）。
- **logOffset 对齐**（子代理抓出 brief 假设漏洞后修正）：事件日志检查点 flush 的
  Snapshot 含日志从不投影的 system 提示消息（NewSession 存 Messages[0]），恢复后
  provider History 比日志投影**多若干条**——merge 前计算
  `logOffset = len(消息) − len(ProjectMessages(entries))` 校正锚点位置；负位/越界锚点
  一律丢弃（compaction 等错位场景宁漏勿误，不阻塞后续锚点）。
- `GaeaHistory`（gaea_ui.go）末尾追加合并：读 `session.ReadEntriesFor(c.SessionPath())`
  （失败/空日志静默降级 = 原行为）→ `mergeSubagentAnchors(msgs, anchors, logOffset)` 纯
  函数插入 `{Role:"assistant", Content, SubagentRef}`；同一 K 多锚点保序。槽位换算按
  GaeaHistory 的展开规则（assistant 消息 = 1+len(ToolCalls) 条 HistoryMessage）。
- `GaeaResumeSession` 走 GaeaHistory 自动生效，零改动。
- `HistoryMessage` 加 `SubagentRef string json:"subagentRef,omitempty"`（golden 逐字节
  不变，TestGaeaHistoryGolden 通过）。

### ② 恢复徽标消费（线B，前端）

- `rebuildHistoryItems`（store.ts）assistant 分支透传 `subagentRef: m.subagentRef ||
  undefined`（空串归一 undefined）；user/tool 分支与其余逻辑逐字节未动。
- `HistoryMessage` 前端类型交叉扩展 `& { subagentRef?: string }`（wailsjs 生成物为本刀
  已刷新含字段，扩展可回收，暂留注明）；复用实时路径既有「子代理」徽标渲染（Message
  组件对同一 Item 形状已有出现/缺省两态覆盖）。
