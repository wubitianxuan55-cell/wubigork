## 二、亮态可读性（两处真实缺陷 + 一套机检契约）

1. **代码 diff 亮态不可读（真缺陷）**：`changesdiff-tok.css` 写死 One Dark 七色，而
   `ChangesDiff` 容器不设背景（继承面板）→ 亮态是浅底：实测 `.tok-typeName #e5c07b` **1.38:1**、
   `.tok-string #98c379` **1.61:1**、`.tok-operator #56b6c2` 1.89:1（文件注释自称「浅色主题下同样可辨识」被实测证伪）。
   处置=**接共享语法调色板 `--hl-*`**（单一真源 `hljs-theme.css`，本就备好「同色相深阶、白底 ≥4.5:1」浅色组并随 `data-hl` 切换），
   `ChangesDiff.tsx` 显式 import 真源（懒加载链上否则 var 未定义），文件零字面色值。
2. **亮态语义令牌下沉**（`lightFn`）：实测本预设 surface 上 `colorWarning #d97706` **2.90–3.13:1**、
   `colorSuccess #059669` 3.44–3.77:1、`colorPrimary` Jade/Rose/Amber 2.99–3.98:1，全在 AA 4.5 线下且**不只是装饰**
   （character-library.css:35 计数标签 14px、WhisperTracePanel 状态文字）。处置=按需下沉一档同色相深阶：
   warning `#92400e`、success `#047857`（Moss 自有 lime 阶保留）、Jade `#0f766e`、Rose `#be123c`、Amber `#b45309`；
   accentRgb/glow 同步跟随（CSS `rgb()` 消费方不得与 colorPrimary 漂移）。**Violet/Moss/Slate 原本达标，一律不动**。
3. **新增机检契约** `appStore.contrast.test.ts`：12 主题 × {正文/次级/主色/成功/警示}×{surface, colorBgContainer}
   全矩阵 ≥4.5:1 + 三处深阶锁值 + accentRgb/glow 跟随 + hljs 浅色组白底逐令牌 ≥4.5 + tok 文件零字面色值。
   色板若回流亮阶立即红——比注释可靠。

## 三、运行开销（每项都可数调用次数）

| 项 | 改动 |
|---|---|
| 主线程心跳 | `main.tsx` 诊断层自带 500ms 轮询**只写一个时间戳**（≈17.3 万次/天纯空转）→ 心跳戳改由既有 rAF 探测循环每帧维护（跨 IIFE 共享 `mainThreadBeatAt`），诊断层只做 8s 低频判读；rAF 降级路径补 500ms 兜底续跳（否则诊断会把已降级的正常态误报成卡死） |
| 令牌/主题对象 | `App.tsx` 的 `getThemeTokens()` 每次调用返回**新对象**且留在渲染体内 → `effTokens` useMemo 与主题 effect 依赖恒变，**每次渲染都重跑 ≈45 个 setProperty**；`ConfigProvider theme={{…}}` 内联字面量每次渲染重跑 antd 主题算法 → 两者一并 memo 化 |
| 选区监听 | `SelectionToComposer` 的 `selectionchange` 在每次光标移动/键入触发，此前**上来就物化整页选区文本** → 先判 `isCollapsed` 短路（折叠态本就 setPos(null)），连 `toString()` 都不调 |
| 记忆列表 | `WhisperMemoryList` 每次渲染 `facts.filter` + 6 域各一次（≈7N 谓词，每 fact 重算 `search.toLowerCase()` 两遍）→ 过滤/分组 useMemo + 查询词预小写（空串语义逐字不变） |

## 四、布局

- `.gsched` 摘要 chip（StatChip）：补 `whitespace-nowrap + shrink-0` —— 窄预览列里 chip 曾被压扁致**标签内部折行、一排 chip 高低参差**（"基线 N" chip 即在此排）。
- 基线槽位行（`BaselinesPanel`）：`flexWrap:'wrap'` + 工期/时间戳两处固定段 `nowrap + flexShrink:0` —— 原单行 flex 固定部分 ≈326px > minWidth 300，名称吃满剩余后时间戳被挤成行内换行、行高参差。
- 海报墙描述（`.p-poster-desc`）：`overflow:hidden` 定高卡原先**静默裁切**长描述且不给省略号（compact 变体早有 ellipsis）→ 补 line-clamp（单格 3 行 / hero 4 行）。

## 五、稳健性

- **假空态**：书架 `loadProjects()` 只 `console.error`，首页拿不到失败信号 → 「后端读失败」渲染成「书架空空如也」。
  处置=store 增 `projectsError`（只表态不抛出，调用方 await 序列零变化）+ 首页诚实错误态（原因 + 重试）。
- **最近文档过期**：首页账页只在挂载时读一次，而 v4.346 起页面常驻保活（keepAlive）→「办公里打开文档 → 回首页仍是旧快照」。
  处置=`lib/recentFiles` 增订阅通道（写入即广播 + 解析缓存保证快照引用稳定，满足 `useSyncExternalStore`），
  首页账页与办公「最近文件」条同改订阅——空态挂载后首次写入也会出现。

## 坑

1. **审计结论必须复核阈值**：印泥章被按 4.5 判死，实际是 20px/700 large text（3:1）且达标——照抄会白改品牌色。
2. **`--hl-*` 是懒加载 CSS 变量**：diff token 文件若只 import 自己，`var()` 拿不到值（回落继承色=暗色恒亮态）；接色板必须同时 import 真源文件。
3. **source-guard 测试里 `indexOf('.hl-scope-dark')` 会命中文档头注释**（该串在正文前先出现），取色块要用 `lastIndexOf`。
4. **antd 两字按钮的可访问名带空格**（「删 除」「重 试」），测试按 `/^删除$/` 找不到；要么用类选择器定位，要么放宽正则。
5. **心跳改 rAF 驱动必须处理降级路径**：probe 在 degraded 后直接 return，若不补兜底续跳，诊断层会把「已降级的正常态」每 8s 报一次卡死。
6. Windows 下 `edit` 偶发 `ReplaceFileW EIO (Win32 1175)`（文件被短暂占用），**原样重试即成功**，不是内容问题。
