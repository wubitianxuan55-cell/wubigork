# v4.297.0 — 伏笔分析驱动自动回收：三级匹配闭环 + 候选清单三层渲染（t1-P2）（2026-09-14）

## 来源

MuMuAINovel 蒸馏线 t1 伏笔域第二刀（`docs/distill/01-foreshadow-spec.md` §3.3~§3.5/§6.1，spec P2「闭环核心」）。P1（v4.293.0）打通了生成侧分层注入后，分析侧仍是短板：回收匹配只做「描述精确相等」，模型输出的 `stable_id` 大多对不上；候选清单更是把 `foreshadows.json` 整包 JSON 直塞 prompt——模型读不动 JSON 清单，更记不住该回填哪个 ID。本刀把分析侧接上 v2 契约（`types.ForeshadowHit`，v4.278.0 落库），伏笔「埋入→回收」闭环正式咬合。零绑定面。

## 落地

- **纯函数层（`internal/types/foreshadow_match.go` 新）**：
  - `WordOverlap`：字符级 n-gram 相似度（spec §3.5）——归一化（小写/去空白）后按 **rune** 切 2-gram 与 3-gram 做 Jaccard，加权 `o2*0.4 + o3*0.6`（3-gram 更精确权重更高）。
  - `MatchForeshadowByContent`：内容匹配兜底六策略加权（spec §3.4）——标题族取最大（完全相等 1.0 / 后缀剥离后相等 0.95 / 包含 0.8 / 剥后包含 0.75 / 其余 `WordOverlap*0.7`，后缀剥 `回收|揭示|解答|兑现` 只剥一次）+ 关键词命中 0.75 + 内容相似 ×0.6（取最大），引用章号 +0.15 / 分类 +0.1 / 关联角色 Jaccard ×0.1（累加）；采纳 = 严格大于当前最优且 ≥ minSimilarity（默认 0.5）——**同分取先出现者**（调用方按埋入章升序传 = 最早埋入）。
- **同步层重写（`internal/analysis/foreshadow_sync.go` 新，替代 analysis.go 旧三动作循环）**：
  - 消费 `[]types.ForeshadowHit`（type=planted|resolved；旧动词 revealed 宽容归一），回收**三级匹配**：① 精确 `reference_stable_id`（查不到**禁止回落内容匹配**，spec §1.2 原则 3「宁漏收不错收」）→ ② 内容兜底（六策略）→ ③ 跳过并记原因，**绝不新建记录**（原则 1「只有埋入会创建记录」）。
  - 状态闸门：已回收不重置（跳过原因如实区分「已在本章回收过 / 已在第N章回收」）；pending/abandoned 不可回收；hinted/partially_resolved 可回收（D15 同源口径）。回收命中即从候选池移除，同批不双吃。
  - 埋入路径**两道防重**（稳定 ID 命中〔ID 或 SourceMemoryID〕+ 同章同题分析条目）+ **每章新建上限 5**（`types.ForeshadowMaxNewPerChapter` 唯一声明，只约束新建，更新不占额度）；评分派生唯一规则 `Importance=min(Strength/10,1)`（Strength/Subtlety 0→缺省 5、>10 钳 10）；计划回收章缺失不猜值（原则 2）；`estimated_resolve_chapter` → `TargetResolveIn` 文件名映射；v2 字段齐备（source_type/source_memory_id/时间戳/AutoRemind·RemindBefore·IncludeInContext 缺省开）。
  - `SyncResult` 完整填充（修正 MuMu 缺陷 D3 静默跳过）：六类 `SkipReason.Kind`（invalid_reference / already_resolved / not_planted / no_match / limit_reached / empty_content）+ 计数 + Errors；Analyze 汇总进 slog（info 汇总行 + debug 逐条跳过 + warn 单条错误）。损坏文件放弃同步不覆盖（既有守则保留）。
- **分析侧候选清单三层渲染（`internal/analysis/foreshadow_prompt.go` 新，替代整包 JSON 直塞）**：
  - L1 本章必须回收（逐条带「⚠️ 回收时 reference_stable_id 填写: {id}」**紧邻回填指令**——分层注入第 1 层独有的关键）含埋入章/内容 ≤200/暗示 ≤100；L2 超期 ≤5；L3 其他 ≤10 + 溢出注记（「还有N个未列出」，不静默截断）；层内确定性排序（埋入章升序→ID，prompt 缓存可命中）；空态诚实说明。
  - 分层判定走 `types.ClassifyResolve` 唯一入口（D9 延续：全仓不养第二套时机逻辑）；`include_in_context=false` 不进 prompt 面（作者显式排除），但登记表同步池不受影响（数据完整性优先）；`auto_remind=false` 不在分析侧消隐（D8 只约束生成侧 L3 提醒）。
- **模板升级（`prompts/analysis-chapter.json`）**：
  - foreshadows 输出换 v2 字段（title/content/type/strength/subtlety/category 七值/is_long_term/related_characters/estimated_resolve_chapter/reference_chapter/reference_stable_id/keyword 锚点），候选清单槽位升 P1（spec P2.4 验收）。
  - 任务指令【🔴 伏笔追踪任务】+ 三条强约束（标题禁加「回收」后缀带示例 / reference_stable_id 回收必填 / estimated_resolve_chapter 埋入必填）+ 伏笔 ID 追踪自检条款（spec §6.1 逐条对齐）。
- **兼容口径**：写入口径状态仍 `revealed`（gaea wire 值不改）；`AnalyzeChapter` 返回的 foreshadows 形状变化零前端消费零破坏；其余 8 维分析（hook/conflict/emotion_curve 等）原样保留。
