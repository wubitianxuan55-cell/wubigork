# gaea v2.13.18「通用办公左侧面板重设计（参考 Codex）」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.18.exe](gaea-v2.13.18.exe)（Windows x64，约 31.6MB）

通用办公左侧面板按 Codex 会话栏的风格重设计。

## 变更

- **紧凑头部**：logo + 名称 + 「新建会话」图标按钮 + 折叠按钮，取代原来的
  大号胶囊按钮；折叠态头部自动竖排图标。
- **搜索框前置**：放大镜图标 + 柔和底色圆角输入框。
- **会话行重构**：标题与相对时间同行（等宽数字）、下方单行预览；选中态为
  左侧强调色条 + 淡色底；悬停显示删除操作；重命名/删除/历史功能不变。
- **区块统一**：分组头与后台任务/事实底座区块头统一为安静的小字大写标签，
  去掉圆点装饰；导航按钮增加按压反馈。
- 保留：会话搜索/加载更多、后台任务、事实底座（导出/沉淀/复制/清空）、
  记忆/知识库/技能入口、侧栏折叠与拖拽调宽。

## 验证与发布

- tsc 通过；前端 128 例全过；wails build 通过
- 产物 gaea-v2.13.18.exe（约 31.6MB），桌面端同步；git tag v2.13.18
