## AI 组价（v4.2a/c）

- **`cost.PriceBand` 价格带推荐纯函数**：由相似清单计算 P25/P50/P75/均值/离散度/
  离群数/置信度（样本 ≥8 高 / 4–7 中 / 1–3 低）+ 证据链快照（BandSource 溯源字段）；
  分位数口径与 costref **完全一致**（R-7 线性插值，同 Excel PERCENTILE.INC）；
  `RecommendPrice`（median/mean/p25/p75/conservative 五档）+ 中文理由文案。
- **`GaeaCostCompose`（绑定）**：清单描述 → 相似清单检索（关键词 + 本地 bge-m3
  语义召回 + rerank 精排，复用 §15 补的 cost 向量索引）→ 价格带推荐 → **LLM 人材机
  拆解**（`routeSensitiveLocal("office")` 敏感域本地化，失败降级规则参考，不阻塞）→
  建议视图（推荐价 + 理由 + 证据链 + 可编辑组件）；`GaeaCostComposeApply` 一键回写
  成本库（UPSERT，来源标注 AI 组价）。**无确认不落库**。
- **前端 ComposeModal**：测算明细行「AI 组价」按钮 → 弹窗（描述/单位预填选中行）→
  价格带卡片（样本/置信度/P25–P75/离散度/离群）+ 证据链 8 列表 + 人材机拆解
  行编辑（含量×单价自动算）→「应用」为明细行自动保存。

## 询价飞轮（v4.2b/d）

- **`costinquiry` 包**：四源归一（信息价/OCR报价/供应商比价/手动询价）询价数据点
  存储（`cost_inquiry_records`，SchemaV15 收编）+ **到期预警**（valid_until ≤
  today+days）+ **调差建议**（标题归一化匹配最新询价，|差幅|>2% 提示，按幅值排序）。
- **前端询价视图**（CostLibraryView 第三视图）：数据点列表（四源分色徽标/CRUD）+
  到期预警红色横幅 + 调差建议区（一键「更新成本库」= CostGet → 改价 → CostSave）。

## 五算对比（v4.2b/d）

- **`coststage` 包**：估/概/预/结/决五阶段值存储（`cost_stage_values`，UNIQUE
  (project_id, stage) UPSERT）+ **对比计算**（固定 5 行、环比=上一有值阶段、累计差=
  首个有值阶段、除零保护）+ **偏差特征**（相邻阶段差幅 正常<5 / 关注 5–15 / 异常>15
  三档 + 规则诊断文案，阈值常量导出）。
- **前端 FiveCalcPanel**：测算项目详情「五算对比」区——五阶段金额/日期输入保存 +
  对比表（环比/累计差/差幅着色：红升绿降 × 量级深/琥珀）+ 偏差卡片（level 徽标 +
  诊断文案），供复盘笔记 AI 诊断接线。
