# gaea v2.13.3「过程卡完成后默认展开」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.3.exe](gaea-v2.13.3.exe)（Windows x64，约 39.6MB）

工具过程卡在输出完成后默认展开，便于直接查看结果。

## 改动

- **ToolCard**：输出 ≥10 行或输出/参数 ≥2000 字符的“大过程卡”，在完成
  （done/error）后自动展开；用户手动折叠过的卡片不再自动展开
- **ToolGroup**：连续同名工具折叠组中任一成员为大卡且完成时，组默认展开
- 小卡片（read_file 等）保持默认折叠，不打扰

## 验证与发布

- tsc 通过；前端 127 例全过；wails build 通过
- 产物 gaea-v2.13.3.exe（约 39.6MB），桌面端同步；git tag v2.13.3
