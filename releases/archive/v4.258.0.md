# v4.258.0 — 原罪插图：生成进度动画 + 串行队列 + 真停止（2026-09-12）

## 为什么是这一刀

用户提「增加图片生成动画知道完成进度情况」。改前原罪插图只有一个转圈 + 「正在生成插图…」，
既没有百分比、没有阶段，也看不出「这张在跑还是排队」；而且并发提交多张时进度无法归属。
顺带发现两个自伤缺陷（见下）。

## 进度

- 抽共享组件 `GenerationProgress`（自绘梦 GenerationBar 抽出，类名与阶段名表单点维护）：
  ComfyUI 有实时百分比时显示确定态进度条 +「当前节点: 采样中」；其余后端走不定态光带 + 本地秒表，
  **不编造百分比**；
- 新轮询 hook `useComfyTaskProgress`：只在生成中轮询、读失败保留上一帧、卸载即清定时器。

## 串行队列

同板块一次只跑一张插图（图像后端单任务 + 进度单任务维度）；排队显示「排队中 · 前面还有 N 张」，
轮到时自动切实时进度。

## 真停止

- 新绑定 `SinCancel(topicID)`：中止底层流式请求，**已生成部分照常落库**（extra.cancelled），
  用户消息不丢；无在途流时如实报错（绑定 639→640）；
- 插图「取消」接既有 `CancelImageGeneration`；
- Composer「停止」从空实现改为真取消。

## 顺带修掉的自伤缺陷

1. `sending` 卡死：`deadRef` 跳过收尾 + StrictMode 双挂载 → 输入框被永久锁死；
2. 「停止」按钮是空实现（点了没反应）。
