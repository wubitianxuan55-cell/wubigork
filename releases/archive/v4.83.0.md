## 规格（双源蒸馏规划 阶段二.5 2.5b 后半）

来源：`docs/gaea-dsh-better-sidebar-long-term-distill-plan-2026.md` §5
2.5b——工具结果与图片深读的剩余半刀：图片缩略卡 + 图片 token 估算。
估算口径依据 2026-09-05 GitHub 调研核实的官方文档
（docs/market-research-2026-09-05.md / research-2026-09-05/context-observability.md）。

| 规格 | 状态 |
|------|------|
| 详情面板图片缩略卡（缩略图+文件名+点击预览） | 🆕 AttachmentDataURL 懒加载 |
| 「原始尺寸→标准档缩放尺寸」成对显示 | 🆕 Go 解码头部取尺寸 |
| 官方 patch 口径 token 估算（双档） | 🆕 ⌈w/28⌉×⌈h/28⌉ 先缩放再封顶 |
| 缺失/不可解码诚实降级 | 🆕 灰态「文件不存在」/「尺寸未知」 |

**估算口径（重点）**：Anthropic 官方现行口径为 28×28 像素 patch = 1 视觉
token，成本 = ⌈w/28⌉×⌈h/28⌉，**先按档位缩放再计**——标准档长边 ≤1568px
/ 上限 1568 tok；高分辨率档（Claude 4.7+）≤2576px / 上限 4784 tok。官方例
1000×1000 → 1296（有单测锚定）。社区旧式 (w×h)/750 是连续近似且忽略档位
缩放、系统性高估大图，弃用。gaea 识图链路面向 OpenAI 兼容端点（vision
链路不动的红线不受影响——本刀只做**展示层**估算），各供应商真实计费不同，
前端如实标注「标准档估算 + 完整口径悬停可见」，不伪造精确计费。
