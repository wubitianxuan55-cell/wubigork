## 本版是什么

用户定调两句：「清单、定额、工料机是什么关系？我让你录入的清单呢？」+「造价数据库不需要一个费用汇总表，它只是一个数据库，你可以录入**费率、清单、测算模版**，但不是把它们加起来」。

三层关系钉死：**工料机**=资源价格（基本数据）→ **定额**=每单位子目消耗多少工料机 → **清单**=工程实体的分部分项列表（编码/名称/单位/**工程量**，套定额）。V25/26/27 只落了前两层，**清单与费率没有落库**（导入模版时清单项只活在工作簿里）——本版补齐，并撤掉 v4.458 做错的「费用汇总试算面板」。

## 数据层（SchemaV28）

- **`gf_projects`**：项目（五表封面：名称/地点/工期/口径）+ **取费费率六字段**（企管/规费/利润/税率/利润基数含规费开关/控制价——全部是录入数据）。同名项目幂等更新。
- **`gf_bill_items`**：清单项——编码/名称/单位/**工程量**/工程量计算式/分部/引用定额（quota_code）/工序特征/手填单价覆盖/序。`UNIQUE(project_id, code)` 幂等；手填行 code 空自动生成 M 序号。

## 导入链

`ApplyProjectBundle` 增④**清单落库**：工程量优先取综合单价表、为 0 回退工程量计算表；费率从「费用汇总」取费区落库；重复导入清单零重复（真实产物实测：32 条清单一次落库，每条套上定额）。
