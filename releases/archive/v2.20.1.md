# gaea v2.20.1「数据可迁移·独立审查修复」（2026-08-14）

> v2.20.0 数据可迁移功能的独立代码审查补丁（子代理审查发现 3 高危 + 4 中危 + 多项低危）。

## 修复内容

### 高危（数据安全）

- **恢复重试幂等（#1）**：ApplyPending 部分失败后重试必失败（已应用条目 src 消失导致永久卡死），
  重构为两阶段：先移走当前数据到 .restore-before，再应用 staging；src 缺失视为已应用跳过，重试可成功。
- **home 配置恢复（#2）**：~/.gaea_config.json 此前从不恢复（staging/home-config 被主循环 rename 走），
  主循环排除 home-config 单独处理；并修复 zip 内相对名缺 . 前缀导致恢复到错误文件名的根因。
- **SQLite 快照数据完整性（#3）**：快照连接无 busy_timeout（常驻连接写入时立刻失败）+ 静默回退复制
  缺 WAL（已提交数据丢失），加 _busy_timeout=5000 + 重试；回退改为 wal_checkpoint 后复制；
  manifest 新增 Warnings 字段，快照失败时前端可见。

### 中危

- 恢复失败不可见（#4）：失败路径也写 .restore-result.json，前端失败告警可达；
- 已有 pending 时再次恢复可堆叠/覆盖（#5）：拒绝并提示先取消；staging 加随机后缀；Cancel 清理孤儿 staging；
- dirSize 全量递归阻塞设置页（#6）：目录大小缓存（mtime + TTL）；
- 宣称可回滚但无回滚代码（#7）：新增 GaeaDataBackupRollback（.restore-before 移回），前端失败告警加
NaN

### 低危

- #8 盘符限定路径拒绝；#9 恢复二次确认 + 只接受 .zip；#10 备份文件名毫秒+随机防同秒覆盖；
- #11 恢复前备份保留最近 2 份；#12 pending 标记原子写；#13 解压两阶段（目录先行）；
- #15 shouldSkip 精确化（只跳 .db-wal/.db-shm 与精确名）；#16 pending 错误透出；#17 前端 entries 数组校验。
