# v4.295.0 — 原罪右栏卡片化：五页签并排改手风琴卡片堆（2026-09-14）

## 来源

用户反馈「五个标签并排太多了，参考办公板块的右侧面板，进行卡片化」。v4.263 起右栏是横向页签条，书源线 t3 加到第五个后，268px 面板宽度下并排过挤。办公右侧面板的实质形态是「一次聚焦一个视图」（better-sidebar 蒸馏）——据此把页签条重组为**手风琴卡片堆**，纯版面重组，五项功能全保留（UI 简化红线：简化≠删功能）。

## 落地

- **手风琴卡片堆**：五个功能卡（角色/大纲/设定/插图/书源）卡头常显纵向排列，**一次只展开一张**——点卡头切换，展开卡高亮主题色、箭头旋转 90°；卡头带计数徽标（书源卡无计数=清单自管，避免双向拉状态）；未展开卡头 tooltip「展开×」。
- **面板头**：新增一行轻头部（「创作面板」小字标签 + 玩法/插图协议/边界问号气泡收于此处，内容原样）。
- **结构**：展开卡即滚动容器（`sin-acc-body` overflow auto），旧 `.sin-side-body` 包装层与页签条样式删除；宽度拖拽/双击复位、底稿编辑会话、画廊大图预览等行为零变化。
- **记忆兼容**：展开卡沿用 `gaea.sin.panelTab`（旧页签值直接迁移为初始展开卡，`sinPanelState` 校验白名单不变）。
- **ARIA**：卡头沿用 `role="tab"`/`aria-selected` 并补 `aria-expanded`，容器 `aria-orientation="vertical"`（纵向 tablist 合法语义；既有测试选择器零改动通过）。
