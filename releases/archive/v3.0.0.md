## 壳层革命（Constellation OS）
- 顶栏横向菜单 → 左侧**指挥轨道**（icon dock，hover 展开标签、键盘方向键导航、激活项 = 主色容器 + 左缘光条 + 呼吸 orb）
- 顶部**轨道条**（v3-strip）：面包屑 / 模型 pill / 主题点 / ⌘K 搜索 / 设置；底部**遥测轨道**（CPU/内存/GPU 实时面积 sparkline + 引擎 pods + 写作进度，可折叠展开）
- 快捷键升级 Ctrl+1~9（MainLayout.tsx + v3/foundation.css）
