# gaea v2.6.6「VoxCPM2 本地语音引擎接入」发布说明（2026-08-09）

> 模型中心新增「VoxCPM2 (本地)」引擎：本地 OpenAI 兼容 TTS 服务（127.0.0.1:8020），
> 2B 扩散式多语种 TTS、48kHz 高保真输出，内置 7 音色 + 参考音频零样本克隆 + 声音设计；
> ROCm 驱动 Radeon 8060S 核显 + TunableOp 调优，实测 RTF ≈ 2.0。

## 一、VoxCPM2 本地部署

- 模型已下载至 `C:\AI\voxcpm\models\VoxCPM2`（4.96GB，ModelScope 官方镜像），
  服务跑在 `http://127.0.0.1:8020/v1`（Python 3.12 venv + torch 2.9.1+rocm7.2.1 + voxcpm 2.0.3）
- 服务接口：`POST /v1/audio/speech`（OpenAI 兼容）、`GET /v1/models`、
  `GET /v1/audio/info`（音色列表）、`POST /v1/voices`（上传参考音频注册克隆音色，持久化）
- 内置音色 7 个（与 CosyVoice2 同源参考音频）：中文女、中文男、英文女、英文男、日语男、粤语女、韩语女

## 二、gaea 接入

- 模型中心新增「VoxCPM2 (本地)」引擎（`voxcpm`），内置 `VoxCPM2` 语音模型；
  「语音模型」页与「功能绑定 → 聊天语音」均可选择
- 设置面板/聊天设置新增 VoxCPM2 音色选择器（实时从 `/v1/audio/info` 拉取，失败兜底 7 内置音色）
- 语音管线复用 HerdsmanTTS 客户端（OpenAI `/v1/audio/speech` + data URI 解码）

## 三、性能与音质

- ROCm 核显推理 + PyTorch TunableOp 固定形状 GEMM 调优缓存（提速约 4~5 倍）
- CFG 1.5 避免长文本「生成跑飞 + 整段重试」（CFG 2.0 实测 RTF 4.8~7.8 → 1.5 后 2.0）
- 实测：7.7s 中文合成约 16s（RTF ≈ 2.0），短句 RTF ≈ 1.35；48kHz 输出无削波
- 启动预热 + 调优缓存持久化，服务重启后首个真实请求即达稳态速度

## 四、使用提示

- 需要先启动 VoxCPM2 服务：运行 `C:\AI\voxcpm\start_voxcpm.bat`
  （首次启动加载模型 + 预热约 1~2 分钟，之后重启约 30~60 秒）
- 详细技术记录：`docs/2026-08-09-voxcpm2-integration.md`
