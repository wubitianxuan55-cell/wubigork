## 根因（两个叠加）

1. **信封双层嵌套**：mt_ 输出的外层执行器信封 `{"data":{"result":…}}` 里，
   data.result 又装着工具自身信封 `{"ok":…,"message":"正文"}`。v4.62.2 的
   拆包只取一层 data.result——留下的是内层信封串，仍是 JSON 转义墙。
2. **历史转录无法自愈**：修复前落盘的 mt_ transcript 已把信封串写死，
   写端修复对旧数据无效。

## 修复

- **写端**：`unwrapModelToolOutput` 改递归拆包——每轮从 data.result /
  data.message / data.output / message / result / output 取第一个非空
  字符串字段作为新内容，直到不再是 JSON 或取不出（上限 4 层）；非信封
  形态原样返回。
- **读端**：`subagentRender.unwrapEnvelopeText` 同语义递归，SubagentThread
  渲染 mt_ 内容前先拆包——**历史转录即刻可读，无需重跑**。
