# v4.97.0「GenUI 蒸馏：回答即 UI · 办公会话面板」

> 发布日期：2026-09-05 ｜ 基线：v4.96.0 ｜ 绑定面 **579 零变更**
> 上游：dsh-genui（MIT）快照 680693e——蒸馏行为契约，不搬宿主插件机制。

## 总览

把「模型回答里的声明式 JSON 围栏 → 白名单可交互组件 + action 回传」落进 gaea：
办公与聊天板块的回答都能内嵌 ```genui（兼容 dsh-ui）围栏渲染成真实组件；
办公另增右侧「UI」会话面板，模型可 REPLACE/APPEND 原地更新。

## P1 共享内核（frontend/src/genui）

- 34 种白名单组件：布局（text/row/col/grid/card/divider/spacer）、展示（stat/badge/
  progress/keyvalue/list/table/timeline/callout/steps/avatar/copy）、轻图表
  （chart bars/line/donut，手写 SVG）、代码（code/json/diff）、交互（button/input/
  select/checkbox/switch/radio/slider/textarea/submit/tabs/accordion/quiz）。
- 守卫：未知 type 整节点丢弃（比上游更严）、200 节点/8 层、字符串/表格/选项/
  chart 点数上限、数字 clamp；幂等且流式前缀稳定。
- 流式部分解析（32 预算单次扫描）、尾随逗号标点级修复；结构性坏 JSON 红横幅退化
  代码块不猜测。
- 本地优先：table 数值感知排序、radio 组+answer 本地判卷与锁定/重做、quiz 点选即判、
  折叠/重试零往返；action 300ms trailing 防抖；无宿主 action 时按钮诚实禁用。
- 状态按「板块:会话:消息槽:内容指纹」持久化，LRU 200；password 永不落库/不进收集。
- 样式只消费全局主题令牌，聊天/办公两板块同一套内核，无 antd/tailwind 依赖。

## P2 双板块渲染缝

- 办公：Markdown.tsx code 组件 + MemoMarkdown 消息级 key + AssistantMessage；
  流式稳定前缀天然“围栏闭合即上屏”。
- 聊天：ChatMarkdown（plain 终态）与 MarkdownContent（人格/流式）双缝接入；
  action 在回合结束后以 [UI 操作] 话题内追问发出。
- 历史重放原样恢复；导出（markdown）中围栏自然退化为代码块。

## P3 模型侧

- internal/gaea/genui：Handbook/ChatRule/OfficePointer 以 go:embed 文本资产承载；
  ValidateSpec 结构校验（语法/白名单/预算/缺字段，渲染器为最终权威）。
- 新只读工具 genui_validate（init 注册，schema spec 字符串）；前端工具图标已映射。
- 内置 inline 技能 genui 进 Skills 索引（run_skill 取词）；办公系统提示词加指针；
  聊天 plain 与轻语人格统一装配点注入规则（人格带门控：气氛对话绝不输出）。

## P4 办公 UI 面板

- genuiPanel store：REPLACE/APPEND、来源+内容指纹幂等、按会话隔离、200 上限；
- 右栏第六 Tab「UI」：GenuiPanel（空态/两击清空），经 workspaceTabs + sidebarRegistry
  单点注册，按钮条/命令面板自动派生；
- Markdown 缝检测 panel:true → 投递面板 + 消息流内占位 chip；
- /panel、/panel clear、/panel <指令> 命令；面板 action 复用办公 steer/send。
