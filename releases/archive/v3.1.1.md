# gaea v3.1.1 发布说明

> 2026-08-26 · 造价数据库闭环补齐（测算项目 UI / 造价参考 / 复盘笔记）+ C4 选区转对话 + 仓储卫生

## 背景

v3.1.0 把 costproject（测算项目/明细/版本/沉淀）与 costref（造价参考/复盘笔记）的
后端与 15 个绑定做完了，但 CostLibraryPage 只有 概览/成本条目/价格源/价格仓库 四个
导航——**测算项目与造价参考没有前端入口**。本版补齐三个前端 UI，零后端改动。

## 测算项目（新组件 CostProjectsView）

- **项目列表**：左列卡片（名称/类型/状态徽标/条目数/合计/版本数），新建（弹窗：
  名称/类型/规模/工艺/备注）、删除（级联，Modal.confirm 确认）。
- **工程量清单**：行内编辑（标题/单位/数量/单价，失焦自动保存），金额=数量×单价
  实时计算；「引用成本库单价」搜索下拉（CostSearch 防抖）点击回填
  title/unit/price/categoryPath/entryName；加行/删行。
- **版本快照**：保存版本（不可变 JSON 快照 + 备注，合计展示）；版本列表按版本号
  倒序，点击查看快照明细表；「恢复此版本」= 前端编排（删现有行 → 按快照重建）。
- **沉淀回成本库**：勾选明细行（缺单价/无标题行不可选）→「沉淀选中(N)」→ UPSERT
  cost_entries（来源标注「测算沉淀：{项目名}」，引用既有条目时保留规格/地区/口径/
  有效期与人材机组成）→ 刷新库概览统计。

## 造价参考（新组件 CostIndicatorsView）

- 按科目 / 按一级分类 分组切换；表格：样本数/最小值/P25/中位数/均值/P75/最大值/单位。
- 数据 = 对「已保存版本/已沉淀」测算项目明细行的实时聚合（不落表，与后端
  GaeaCostIndicators 同口径）；空态引导「保存版本或沉淀后自动成为对标样本」。

## 复盘笔记（新组件 CostNotesView）

- 搜索（标题/结论/边界…）+ 状态过滤（全部/草稿/已确认）；卡片：标题 + 可信度徽标
  （高/中/低）+ 状态徽标 + 结论摘要（3 行截断）+ 证据 + 有效期 + 引用次数。
- 新建/编辑弹窗：结论/适用边界/风险提示/证据来源/可信度/复核状态/成本分类/项目类型/
  工艺/有效期至；删除经 Modal.confirm 确认。

## 板块导航同步

- board cost manifest Nav children：概览/成本条目/测算项目/造价参考/复盘笔记/价格源/
  价格仓库（与 CostLibraryPage MODULES 对齐）。

## C4 选区转对话（新组件 SelectionToComposer，纯前端）

- 办公板内选中任意正文（对话文本 / 文件预览 / 过程输出）→ 选区上方浮出「转为提问」
  浮动条 → 点击把选中文本以 `> 引用` 块插入输入框（可继续编辑后发送）。
- 忽略输入框/文本域/下拉/弹窗内的选区；portal 渲染 + 视口边缘收敛；不依赖后端。
