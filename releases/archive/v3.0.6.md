# gaea v3.0.6 发布说明

> 2026-08-16 · 编程板块工作台 + 办公会话回退分叉 + 顶栏工具栏迁移

## 编程板块

- **桌面内嵌工作台**：DeepSeek Harness Web（http://127.0.0.1:3080）以 iframe 内嵌
  桌面窗口，同一应用内直接使用编程工作台，无需跳出浏览器；未运行时提供一键启动
  引导视图（真实前置条件检查 + 日志查看 + 启动动画）。
- **启动引导**：GetProgrammingWebPreflight 逐项检查（harness 目录 / pnpm /
  node_modules / apps/web/dist / 端口 3080）+ 每项绿/红呈现与修复提示；启动日志
  尾部可查看（ProgrammingWebLogTail，n 钳制 [1,200]）；启动动画视图（纯 CSS
  双虚线环反向旋转 + 发光 orb + 实时等待计时），失败自动展开日志回引导视图。
- **顶栏工具栏迁移**：运行中工具栏（「Harness Web 运行中」徽标 / 运行时长 /
  URL / 刷新 / 浏览器打开 / 停止）整体移入顶栏 v3-strip（portal 进 v3-prog-host
  宿主，与聊天模式条同款模式），仅编程板块激活时自动显示、其他板块自动隐藏；
  iframe 独占工作区全高展示；宿主缺失兜底保持原布局；新增 portal 渲染用例。
- **数据源 seam 化**：ProgrammingPage 从 wailsjsCompat 直调改为 bridge app seam
  （Wails 原生走门面代理、浏览器 mock 走 makeMockApp），并修复 useVoiceChat
  cleanup 在 mock/未就绪时同步 throw 导致的首页渲染崩。
- **后端可测性**：端口探测/tasklist/taskkill/LookPath/cmd.Start/日志路径/等待超时
  全部探针注入；programming_web_test.go 16 用例（状态归属/幂等启动/外部占用守卫/
  目录与 pnpm 缺失/超时/停止三态/日志尾读/前置检查全绿与全红），零外部依赖。

## 办公板块

- **会话回退/分叉/回退点**：后端实现会话 rewind 链路（此前前端空实现）——会话级
  派生统计绑定 GaeaSessionStats + 前端恢复回填，根治恢复会话成本展示不完整。
- **右侧面板 Tab 体系清单化**：workspaceTabs 单源声明 + WorkspaceTabs 组件 +
  装配层测试；清理死绑定（移除 GaeaWorkspaceChanges/GaeaSelectTab/GaeaTabMeta）。
- **UI+功能优化**：ProcessCard 状态四态 / 思考深度三档接线 / useDrawers 收敛 /
  恢复会话状态还原 / 右侧 tabs 激活态修复；命令面板任务模板 / 领域色单源 /
  模板缓存去重。
- **mock 场景补全**：审批/提问/压缩卡三类事件流 + initBridge `?mock=` 优先，
  浏览器离线开发可用。
