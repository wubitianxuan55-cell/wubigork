# v4.48.0「青鸟：板块更名 + 人格选择器打通角色库」

> 发布日期：2026-09-02 ｜ tag：`v4.48.0` ｜ 基线：v4.47.0 ｜ 绑定面 **559 零变更**

## 定位

用户拍板两件事：①板块名「微信助手」太直白太土 → 更名**「青鸟」**（青鸟传信，
与绘梦/轻语的板名气质一致；「提醒到点回推」正是信使折返）；②上一刀评审时
确认的架构判断落地——**角色库与微信助手是引用关系不是同一实体，不合并、
要打通**：新增助手选人格从手填 ID 升级为带详情的选择器。board id（weixin）、
页面（WeixinPage）、绑定方法名全部不动，纯展示层 + 选择器改造。

## 板块更名「青鸟」

- manifest label：`internal/app/board/builtins.go` 与 `frontend/src/boards/
  manifests.ts` 同步「微信助手」→「青鸟」（后端字段优先，两端一致）。
- 意图别名表（intent.go boardAliases）新增 `{"青鸟", "weixin"}`——语音/微信
  说「打开青鸟」直达；「微信助手」别名保留兼容。
- 页内文案：strip 标题、rail aria-label「青鸟导航」、新增按钮/空态/弹窗标题
  →「新增青鸟助手」；启动器描述「青鸟传信 · 微信遥控器：扫码绑定与离线代办
  提醒」。通道文案中的「微信」（扫码绑定/微信里发消息）保留——青鸟是名字，
  微信是信道。
- wx_agent navigate 工具描述同步板块清单。

## 人格选择器（打通角色库）

- **双栏弹窗**（width 420→680）：左栏 = 搜索框（名字/标签）+ 分组列表
  （`轻语预设` = WhisperGetPersonalities，`角色库` = CharacterList chatOnly
  可聊天角色；18+ 人格（requiresAdult18）不列出——工作触点纪律）；右栏 =
  选中项详情预览：立绘（portraitUrl 图或首字占位）、名字、来源 Tag
  （轻语预设/角色库）、性别 Tag、标签 chips、口吻/人设描述（voiceGuide 或
  personality+background，可滚动）。
- **立绘回显**：选中角色库人物后 portraitUrl 随暂存对象走 Save 落库——
  轨道 26px 头像与详情 44px 头像自动用真立绘（字段既有，此前 UI 从不喂）。
- **降级安全**：默认选中 `gaea` 预设（同步初值），数据加载失败时确认流照常
  走、payload 照常 'gaea'。
- a11y：listbox/option 语义（aria-label `选择人格 X`）、focus-visible 环、
  令牌纪律零硬编码色值（wx-pk-* 样式组）。
