# v4.300.0 — t3 首刀：章节前文摘要窗口预算化 + 回退链 + 反重复约束（2026-09-14）

## 来源

MuMuAINovel 蒸馏线 t3 长程一致性域首刀（`docs/distill/03-long-range-consistency.md`）。§11.3 对照后才显形的 gaea 自身缺口：章节生成的 `prevSummary` 从大纲节点遍历**全部**前章、每章 200 rune **无累计上限**拼接——200 章的书 ≈40k rune 的 prompt 前缀，且不参与 `ctxBudgetTotal` 预算体系（该预算只覆盖伏笔+世界观区段）。本刀按 §12.1「上下文预算统一」+ §12.4-5 摘要回退链 + §12.4-6 反重复约束三件一起收口。零绑定面。

## 落地

- **最近 10 章窗口**（`buildPrevSummaryWindow`，纯函数）：只注入本章之前最近 N 章（`ctxPrevWindowChapters=10`，对齐 MuMu `chapter_context_service.py:1375`），按章号升序确定性拼接，单章摘要截断 180 rune（`ctxPrevChapterLen`，对齐 MuMu `:1408`）；无可注入内容返回空串（模板槽位按空跳过）。
- **窗口声明头**：首行「（仅含第 X～Y 章概要；更早章节的剧情同样有效，只是不在此重复）」——告诉模型这是有意的部分视图，防止把窗口外既定剧情当不存在。
- **摘要回退链**（spec §12.4-5，gaea 适配两级）：大纲节点 `Summary` → `chapters/NNN-summary.json` 的章节摘要 → 该章跳过（不占窗口位）。原实现只用大纲一个来源，章节分析产出的摘要文件从未进入前文窗口。
- **反重复约束**（spec §12.4-6，对齐 MuMu `prompt_service.py:792-805` 衔接锚点+禁止重复清单的写法）：`prompts/create-chapter.json` must 增「『前文摘要』仅作衔接参考：直接推进本章新进展，不得复述其中已完成的剧情；『前文摘要』只含最近章节，更早的既定剧情同样不得矛盾」。
- **有意取舍**（码内注明）：MuMu 的窗口上界是 SQL `chapter_number < N ORDER BY DESC` 天然容忍断档；gaea 用 OrderIndex 窗口过滤同样容忍断档（缺章不占位不占预算）。
