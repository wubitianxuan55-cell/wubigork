# gaea v2.13.4「外层过程卡完成后默认展开」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.4.exe](gaea-v2.13.4.exe)（Windows x64，约 39.6MB）

修正 v2.13.3 的实现方向（v2.13.3 误把内部工具卡自动展开，已撤回）。

## 修复

- **外层大过程卡（ProcessCard）**：运行结束（running → 完成）时不再折叠，
  默认保持展开，过程文本与过程卡直接可见；用户手动折叠过的仍尊重其选择
- **内部工具卡 / 工具组**：恢复默认折叠（read_file、bash 等单卡及连续同名
  工具组不自动展开），不打扰浏览

- tsc 通过；前端 127 例全过；wails build 通过
