## 落地

- **消息级编译摘要**（agent/compile.go）：每条消息规约成 canonical 字节串
  （role + 0x1f + 内容长度声明 + content + toolcalls）取 SHA256 前 16 hex
  ——长度前缀杜绝「A|BC == AB|C」拼接歧义；工具调用参数参与摘要。
- **相邻请求判定** `DiffMessages`：`Stable`（上一请求消息序列 = 本请求
  无改写前缀）/ `PrefixBytes`（稳定公共前缀字节数）/ `AppendCount` /
  `RewriteCount`（>0 = 压缩/rewind/重排，缓存必然失效——诚实判漂移）。
  消息级判定即字节级：消息是请求里的离散对象，逐条相等且位置相同 ⇒
  序列化后 JSON 数组前缀逐字节稳定。
- **随 RequestHeader 落会话日志（dump/diff/回放一体）**：
  `RequestHeaderInfo` 追加 compileHash / prevCompileHash / prefixStable /
  prefixBytes / appendCount / rewriteCount（追加列；prefixStable 三态指针，
  nil=未计算=首请求/旧日志）。日志即装配 dump、相邻记录即 diff、
  session.ReadEntriesFor 即回放。
- **contextview 折叠**：`RequestRecord.Prefix`（PrefixVerdict）随趋势柱
  下发，与本就存在的 CacheHitTokens 配对 = 「前缀字节级稳定 + 缓存命中
  可证」完整证据链；前端渲染按需另刀。
