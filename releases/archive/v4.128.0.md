# v4.128.0 · 进度计划基本功刀F：单代号网络图合规整改（2026-09-06）

> 用户走查实锤三连问：「单代号是所有连成一条直线吗？没有分支吗？没有关键线路吗？六序的逻辑关系适配了吗？」——审计确认：单代号视图错用了**时标分层**（列=最早时间），样例各任务开工日互不相同，16 节点被拉成一条直线，**并行分支全灭、关键线路无从谈起贯通**。本刀按 JGJ/T 121 单代号口径整改。绑定面 **588** 零变更（纯前端）。

## 根因

- `PdmView` 复用了 `layerByTime`（AOA 时标口径：列=es 去重升序）。单代号网络图表达的是**逻辑关系**而非时间比例——不同开工日的并行工作（机电预埋 vs 主体一区）es 不同即分列，重心行序又把每列单节点对齐成一行 ⇒ 整网一条直线。

## 整改内容

- **拓扑分层布局**：`layout.ts` 新增纯函数 `layerByTopology`——列=最长路径深度（不动点迭代，DAG ≤ n 轮收敛），并行分支同列并列；列内行序三轮重心（barycentric）松弛减交叉。`layerByTime` 原样保留（AOA 时标口径不受影响，11 例 aoa 测试回归绿）。
- **虚拟起点/终点节点**（JGJ/T 121：多起点/多终点时应增虚拟工作）：起点=无入边叶任务 >1 时画虚线框「起点 S」，终点=无出边叶任务 >1 时画「完成 T」；S/T 位于全图行中线，虚箭线连至各起点/终点（`sched-net-link-virtual` 虚线）。
- **关键线路贯通显示**：搭接连线在「两端均关键 **且该搭接为绑定约束**」时红色加粗——绑定=后继日期恰由该搭接决定（FS: t.es===f.ef+lag；SS: t.es===f.es+lag；FF: t.ef===f.ef+lag；SF: t.ef===f.es+lag，`isLinkBinding`）。替换旧口径（仅 FS+lag=0 变红），SS/FF/SF 关键搭接不再漏标，红线沿关键链连续可辨。
- **节点行号角标**：节点名前加 1-based 行号（Project 网络图节点带 ID 口径），与横道前置/后续「3FS+2」引用互认。
- 六格标注法（名称+ES/D/EF+LS/TF/LF）与四种搭接+时距箭线标签本就有——本刀修的是把它们摆进正确的关系图里；图例补「关键线路=红箭线贯通」说明。
