# wubigrok v5.31.0 — 图片存储修复 + 模板扩充 + UI 优化

**发布时间**: 2026-07-28

## 图片存储修复
- `OpenImageSaveDir` 兜底默认路径 `Pictures/wubigork`（即使未配置也能打开）
- `SetImageBackend` 增加 `imageSaveDir` 参数，初次保存时自动设默认目录
- 模型中心"图片生成配置"精简为"图片存储"，只保留保存目录+保存按钮
- 文件夹/图片按钮正常打开对应目录

## 图片模板扩充
从 22 个 → 41 个模板，新增 2 个类别：
- 🏷️ 产品商业（4个）：产品白底、场景展示、美妆特写、室内设计
- ✨ 万能增强（4个）：通用高质量、光影增强、细节增强、色彩增强
- 各原有类别也有扩充（奇幻生物、美食摄影、暗黑美学、极简主义等）

## Grok 优化
- 默认模型改为 `grok-imagine-image`（对齐 ComfyUI 工作流）
- xAI 内容审核错误显示友好中文提示

## UI 优化
- 绘梦三栏布局：左栏 350px + 中间画布两列 + 右侧历史 180px
- ResultGallery 固定两列 `1fr 1fr`
- HistoryStrip 竖排布局
- 模型中心图片配置默认展开

## 后端
- `image_comfyui.go`: Krea2/ZIT 对齐 Comfy-Org 官方模板
- `image_handler.go`: 图片存储逻辑修复
- `client.go`: Grok 默认模型 + 审核错误提示
