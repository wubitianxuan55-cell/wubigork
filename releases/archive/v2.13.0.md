# gaea v2.13.0「通用办公打磨 + 模型中心优化 + 本地模型实测」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.0.exe](gaea-v2.13.0.exe)（Windows x64，约 39.6MB）

承接 v2.12.0，本轮聚焦通用办公稳定性与方案写作质量：修复方案分节 100 字截断
（流式与批量两处）、docx 读取乱码、前端「运行中」假卡死；配套模型中心优化与
Herdsman/Ollama 本地模型双模式实测。

## 通用办公打磨

- **方案分节字数修复**：「生成该节」流式入口原硬编码 100 字截断，现按章节字数目标
  （`WordTarget`，缺省 800，大纲按总字数分配）循环生成，不足自动续写；批量生成
  （`GenerateSection`）同步补齐续写逻辑，长章节不再被腰斩
- **docx 读取乱码修复**：办公「读取文件」打开 .docx 时原直接返回 zip 原始字节，
  现统一走 `ConvertToMarkdown`（MarkItDown → 内置转换 → 扫描件提示），PDF 同步受益
- **运行态兜底**：前端 `turn_done` 事件丢失时不再永久卡「执行中」——停止按钮无条件
  复位本地运行态；新增 30s `GaeaRunning()` 看门狗，后端已停则自动恢复
- **待办自动收尾**：turn 正常结束但待办从未推进（0 completed / 0 in_progress）时，
  面板自动显示已完成，不再残留「0/N」；已被 agent 推进的列表保持原样
- **format_convert 落盘修复**：输出父目录自动创建（与 write_file 对齐）+ 回归测试
- **docmd MarkItDown 通道**：docx/pptx 优先走 MarkItDown，失败回退内置解析器

## 模型中心 / 底层

- 模型中心功能绑定与板块细节优化（绑定卡片、工具链展示等）
- 本地引擎思考参数透传（`enable_thinking` / `chat_template_kwargs`）与路由增强，
  思考模式行为更可控
- whisper web_search、角色画像文件化等累积修复

## 本地模型实测

- Herdsman 三模型（Hermes3.6 / Qwen3.6 LynnStyle / Qwen3.6 HauhauCS）
  20 项任务 × 思考/非思考双模式全量实测；Ollama GLM 双模式实测
- 结论：日常/识图用 HauhauCS（最快），深度推理用 LynnStyle（唯一稳定输出推理链），
  思考模式需给足 token 预算（≥4096）
- 复现：`go run scripts/test_herdsman_models.go`（支持 HERDSMAN_BASE_URL /
  HERDSMAN_MODEL / HERDSMAN_TASKS / HERDSMAN_MODE 过滤）
- 完整报告：docs/2026-08-12-herdsman-models-evaluation-report.md
