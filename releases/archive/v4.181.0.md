## 3. GLM Coding Plan 429 分诊（附带）

用户实测：GLM 引擎报 429「余额不足或无可用资源包」。根因=编码套餐资源包挂在
coding 专用端点（`/api/coding/paas/v4`）计费域，标准端点（`/api/paas/v4`）查不到
即报 429——不是 Key 坏，是端点没切（模型中心 GLM 卡片已有 std/coding 切换）。
代码改进：`glmPing` 在标准端点收到 429 时，错误信息追加分诊提示（切换端点后
重连），经引擎状态与日志直达用户。
