# v4.60.0「better-sidebar pane 化三刀 · 文件打开统一开 tab」

> 发布日期：2026-09-03 ｜ tag：`v4.60.0` ｜ 基线：v4.59.0 ｜ 绑定面 **559
> 零变更** ｜ 快照提交：d856353e（右栏 pane 化）/ cf1bf35（左栏子代理入口）/

## 定位

把 dsh-better-sidebar 的 pane 语义分三刀落进 gaea 办公板块并合并成首个未发版
快照发布：右栏工作台 pane 化 → 左栏子代理会话入口 → 文件打开语义全量统一为
右栏 pane 文件 tab；同时把「并发子代理」固化为默认执行纪律。

## A · 右栏工作台 pane 化（d856353e）

- **pane 工作台语义**：右栏无 tab = 欢迎卡；点卡片开「视图 tab」；资源管理器
  是其中一种视图 tab，视图内点文件新增「文件 tab」；同一 tab 条混排视图与
  文件 tab，可关、可 `＋` 新开、按会话持久化。
- **视图补齐**：文件 = ExplorerView；浏览器 = 地址栏 + 沙箱 iframe（URL 随
  tab 持久化，地址策略禁 javascript:/file:/loopback）；产物/任务复用既有面板
  能力。
- **任务页重做**：紧凑「子代理拓扑 + 后台任务」连续单页，去掉轨迹式重复。
- **点子代理 → 独立子代理会话 tab**：主区顶栏动态 tab（可关闭/并行切换）。
- **清理旧两级组件**：删除 WorkspaceTabs/WorkspacePanel/EditorTabs/
  lib-editorTabs 及测试。

## B · 左栏子代理会话入口（cf1bf35）

- Sidebar 虚拟滚动行模型新增 `subagent` / `subagentNote` 子行：父会话行展开钮
  懒加载该会话子代理（复用 `GaeaSubagentRuns`，**绑定面 559 不变**），loading/
  空态/失败重试行内态齐全；关闭再开走缓存。
- 子代理子行：层级缩进 + 状态点（运行脉冲/完成/失败）+ 任务摘要 + 「状态 ·
  模型 · 相对时间」；点击子行 → 复用 A 的独立子代理会话 tab。
- 当前会话运行中每 5s 刷新（与右栏分工面板同数据源同口径）。
- mock 子代理按父会话归属（c/a/d/annual-r1），历史会话不再串味；三语 +7 键。

## C · 文件打开统一开 pane 文件 tab（4a0cae7a + 6ca03e4d）

- **产物/权威登记行**（4a0cae7a）：sidebarRegistry 新增 `openPaneFileTab`
  统一入口，产物视图改挂它，files 视图 openFileTab 同步复用——点产物不再收起
  工作台弹大预览。
- **正文交互卡与变更**（6ca03e4d）：新增 `lib/paneFileOpen.ts` 模块级注入
  `openPaneFileOrPreview`（App 注册 openPaneFile，未注册回落大预览，沿用
  setTaskCardActivityProvider 模式）；正文交付卡 DeliverableCards、行内附件
  Message/InlineAttachment、FileLinkText 文件 chip、Markdown/MemoMarkdown
  文件链接、变更面板「打开文件预览」全部走同一入口。
- 效果：产物、正文、变更、资源管理器四处文件点击语义一致——右栏 tab 条
  新增/激活文件 tab，多个并存、同路径去重。

## 收口 · 习惯固化（d6246f99）

- 「并发子代理」固化为默认执行纪律：开工先拆线（2-4 路互不相交线并发子代理 +
  主代理定契约/门禁/收口）、单线超一轮也倾向派活、足迹互斥铁律、每刀回写
  记忆；写入 .gaea/AGENTS.md「执行纪律」。
