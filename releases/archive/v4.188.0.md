## 拍板内容

- 壳层书斋/闲庭 = 界面导航（`MainLayout.switchSpace`）。
- 办公引擎空间 = 办公侧栏 SpaceChip（`GaeaSpaceActivate` 写 `session.space`，
  下次引擎重建/重启生效）。
- 合并方案（切空间写 `session.space` + 安全点重建办公引擎）**作废**；展望中
  「一年后是一个开关」的画面删除。

## 实证链（行为本就满足拍板，零行为变更）

- `switchSpace` = 纯 localStorage + React 态（saveShellPage/setSpace/setPage/
  keepAlive 剪枝），零桥接调用。
- 跨空间剪枝卸载办公页：`useChatStream` 卸载收尾只退订流/收尾挂起 Promise/
  停打字机——**不 cancel 后端**；回到办公页重挂载从后端会话恢复。
- `GaeaCancel` 全仓唯一消费点 = 用户显式停止按钮（controller store）。
- 结论：切换对正在跑的办公回合零影响，后端照常跑完落盘。
