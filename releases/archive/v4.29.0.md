## 交付明细

### ① 顶栏导出收拢（App.tsx + 新 ExportMenu）

- 新组件 `components/ExportMenu.tsx`：「导出 ⌄」单钮下拉，收纳原顶栏三个常驻文字钮
  （导出 Markdown / Word / PDF）。触发钮 toolbar-btn 同款；弹层 role=menu 三 menuitem
  （图标+短文案，title 带完整描述）；点选回调收起、遮罩/Esc 收起、会话无内容整钮禁用
  （与原 disabled 语义一致）。
- **功能零删除**：md→downloadMarkdown、docx/pdf→ExportDeliverable 统一管线原样接线；
  三出口可达性由 ExportMenu.test 钉住（「三个出口逐个回调」用例）。
- 对标：Devin/Linear「新功能只进命令面板不加按钮」、VS Code 顶栏单点溢出（Customize
  Layout）。顶栏常驻操作钮 7→5，低频动作不再占最高视觉层级。

### ② 右栏 tab 窄栏自适应图标化（WorkspaceTabs + workspaceTabs.ts）

- 容器宽度 < `WORKSPACE_TAB_COMPACT_WIDTH`（420px，新常量）→ tab 文字以 CSS `hidden`
  隐藏、只显图标；`aria-label`/`title` 保留全名，角标照常渲染；宽栏自动恢复文字标签。
- 实现要点：ResizeObserver 观测 tab 条容器；无 ResizeObserver 环境（jsdom/旧内核）回退
  文字标签；`compact` 受控 prop 供测试/调用方强制覆盖。**DOM 文本保留**（textContent 不变）
  ——既有角标锁 `toBe("任务")` 全数继续通过，未改一条旧断言。
- **6 tab 集合不动**（文件/产物/变更/任务/分工/浏览器，数量锁 6 照旧）——只调呈现密度，
  不并 tab 不删入口。340px 基线宽下 6 个带字 tab 拥挤（溢出裁切）问题根治。
- 对标：Notion 数据库视图 tab 的 Icon only / Text only / both 个人级切换。

### ③ 预览头部降噪（FilePreview）

- 「打开」「定位」图标化（`title`/`aria-label` 保留，既有测试 `getByTitle("在外部程序中
  打开")` 不破）；头部按钮统一去边框（无边框 + 悬停浅底，新增 HEAD_BTN 复用）。
- **状态语义动作保留文字**：「编辑」「保存/保存中/重试」「取消」不动——编辑能力保留红线，
  FilePreview.test「编辑能力保留」锁钉住；新增用例锁「打开/定位无文字+aria-label 在」。
- 对标：Codex IDE "without an extra navigation pane" 的轻头部取向。
