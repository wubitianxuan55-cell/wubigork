# v4.390.0 — canvas 调色板集中化：resolveThemeColor 收口三份手写解析器 + 主题切换跟随缺陷根修

> 视觉池③+⑤「canvas 图表调色板集中 resolveToken」专项（v4.361 审计留池的大工程候立项项，本刀为其中可代码级收口的③+⑤，①②④仍需逐板块截图对照拍板不在本刀）。侦察发现三份手写 CSS 变量解析器各缺一块，且 RelationGraph 有一处**真缺陷**：角色色/组织色/关系色/画布底是**模块级顶层求值**——模块加载后主题切换永不重解析，亮暗切换后图谱节点停留在旧主题色。纯前端 7 文件+3 新测试（27 例），绑定面 714 零变更。

## 落地

1. **集中解析器 `resolveThemeColor`/`resolveThemeColorRGB`**（`utils/theme.ts`）——span 探针法：把颜色串写进临时 span 的 `color` 再读 computed style，**浏览器自己算**，天然支持 `color-mix()`/嵌套 `var()`/fallback 链（字符串手拆解析既不支持 color-mix 也不支持运算）；非浏览器环境/解析失败原样返回由调用方兜底。`resolveThemeColorRGB` 进一步解析为 `{r,g,b}` 元组，供需要派生半透明色的 canvas 场景拼 `rgba()`。
2. **RelationGraph 接线+真缺陷根修**——角色色/组织色/关系色/画布底/职业色全部从模块级顶层求值收进组件 `palette = useMemo(…, [darkMode])`（与 v4.350 的 canvasColors 合并为单一 palette），graphData/decoratedNodes/edges 的 memo 依赖补 palette——**主题切换后图谱全量调色板随动**；图例色块改为直接消费 `var()` 令牌串（DOM 活解析天然级联，无需解析）。
3. **GraphView（记忆 3D 图谱）背景跟随主题切换**——原实现初始化时读一次 `--bg-soft` 后永不更新；现用探针解析（引用链 `var(--md-sys-color-*)` 拿计算色更稳）+ MutationObserver 监听 `documentElement` 内联 style 变更（主应用 App.tsx `setProperty` 写令牌即触发）重读背景推给实例（`backgroundColor()` 支持运行时更新）。不引老栈 store，保持 gaea 与主应用仅经 CSS 变量耦合。
4. **CompanionAvatar（gaea 光球）接线**——删本地字符串手拆实现（不支持 color-mix；`var()` 链在 gaea 令牌场景返回非 hex 串时 hex 后缀拼接 `${color}22` 拼出非法色被 canvas 静默忽略），改探针解析+`rgba()` 拼接（`withAlpha`），color-mix 令牌可用、透明度派生恒合法。
5. **AoaView/PdmView 关键红兜底值统一**——`var(--sched-critical, #dc2626)` 两处改 `#e02020`，与令牌定义（亮色 `#e02020`/暗色 `#f04848`，fallback 取亮色——导出白底场景消费）及 UsageView 既有值一致。

## 坑

1. **canvas 测试的 jsdom 三连坑**——`offsetParent` 恒 null 触发 v4.365 后台空转治理（挂起不绘制，测试桩强制可见）；首绘走 `requestAnimationFrame` 调度（断言前等帧 flush）；ctx 桩用 Proxy 兜底任意方法 noop（逐方法列举必漏：先漏 `scale` 后漏 `createRadialGradient` 返回值）。
2. **hex 后缀拼接只兼容 6 位 hex 输入**——`${color}${alpha-hex}` 遇 rgb() 串拼出非法色被 canvas **静默忽略**（不报错、用旧色/黑色）；派生透明度一律走解析后的 rgba() 拼接。
3. **模块级求值是主题切换的隐形死角**——「挂载时解析一次」的注释看着合理，但模块加载先于首次主题写入且此后不再求值；canvas 类颜色要么进组件 memo（darkMode 依赖），要么 DOM 直接消费 var() 活解析。
4. **getComputedStyle 读 custom property 只到引用替换层**——`--bg-soft: var(--md-sys-color-surface-container, #1B2336)` 拿到的是引用替换后的串而非计算色；span 探针读 `.color` 才是终值。
5. **Edge `--screenshot` 单帧模式不跑 rAF**——canvas rAF 渲染循环的组件截图全空（DOM 部分正常），须加 `--virtual-time-budget` 让虚拟时间快进后再截。
6. **gaea 侧主题跟随不引老栈 store**——gaea 令牌全部引用主应用写入 `:root` 的 M3 令牌，MutationObserver 监听 documentElement 内联 style 变更是零耦合的跟随信号。
