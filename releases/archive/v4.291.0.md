# v4.291.0 — 拆书导入线：AI 反推大纲任务化（长书后台态，任务中心可见）（2026-09-14）

## 来源

拆书导入线在案欠账（v4.280 起历版「未做」：长书后台任务态）。AI 反推大纲是 1-3 分钟的长操作（超时上限 10 分钟），此前同步绑定一挂就是几分钟、页面关闭结果即丢。本刀把反推接进 tasks 任务队列——**任务中心可见、页面关闭不丢、轮询取结果**。

## 落地

### ① 任务化（tasks 队列）

- 新任务类型 `tasks.KindOutlineReconstruct`（"outline_reconstruct"），handler 注册进启动装配块（与 price_fetch/file_index 同列）。
- handler 跑与同步绑定**同一套反推内核**（`outlineReconstructCore`，含篇幅路由/骨架聚合/规则兜底全量语义），预览 JSON 存任务 `Result`（不透明载荷）；`Progress.Report` 上报阶段进度。

### ② 绑定（NovelB +2 → **660**）

- `NovelOutlineReconstructStart()`：提交任务（play 空间）；队列不可用显式报错（回落路径由前端处理）。
- `NovelOutlineReconstructTaskGet()`：返回最近一次反推任务状态；`succeeded` 时解析 `Result` 携带预览。
- 同步绑定 `NovelOutlineReconstruct` 原签名保留（重构出 `outlineReconstructCore` 共用内核，既有调用与测试零变化）。

### ③ 前端（`CreatePage` 反推按钮改任务化）

点击 → `Start` 入队 → 每 3 秒轮询 `TaskGet`（12 分钟上限）→ `succeeded` 取预览走既有确认弹窗 → `failed` 透出任务错误。**队列不可用/无任务时自动回落同步绑定**（老后端兼容）。反推期间页面可自由导航，任务照跑。
