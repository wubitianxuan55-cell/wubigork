# v4.141.0 · 进度计划导出预览 · 画布窗口内全览 · 周刻度

> 三件一句话：**导出前看得见**（图面弹窗内嵌所见即所得预览）、**长计划看得完**（「全览」把整计划压进画布可视宽）、**缩放看得懂**（底层刻度随日宽在「逐日号 / 自然周」间切换，月层恒在顶行——MS Project 口径）。纯前端，绑定面 **596** 零变更。

## 1. 导出预览（ExportDialog）

- `exportArtifact.ts` 新增 `svgWithViewBox(svg)`：构建器产出的 SVG 根节点只有 width/height，注入 `viewBox="0 0 w h"` 后即可被 CSS 等比缩放（`width:100%; height:auto`）；已有 viewBox 或尺寸缺失时原样返回。
- ExportDialog 内嵌 `.sched-export-preview` 预览区（弹窗 520→720）：350ms 防抖 useEffect 随 kind/签署信息/条尾标注重新构建图面并注入预览；CPM 不通过时显「计划存在循环依赖，无法生成图面」诚实态（与导出动作同 fail-closed 口径）。
- 导出 PNG/PDF/打印仍走原始 SVG（`svgToPngBlob` 自带 svgSize 读取），预览只是视图层，产物逐字节不变。
- 用例：打开弹窗 → 预览 svg 出现且 viewBox 格式正确（SchedulePage.test.tsx）。

## 2. 画布窗口内全览（GanttView）

- 日宽 `dayW` 由步进档 `[8,14,20,28]` 改**连续值**（`DAY_W_MIN=2 / DAY_W_MAX=40 / ZOOM_FACTOR=1.35`，一位小数），放大/缩小按钮 ×÷1.35。
- 「全览」`fitToWindow`：`dayW = clamp((canvasPane.clientWidth − 2) ÷ 总天数, 2, 40)`，并把 scrollLeft 回 0——整计划一眼入窗，长计划不再无限横向拉长；日宽全局单一来源，条形/依赖线/前锋线/拖拽吸附（wdOffsets）自动随动零特判。
- 拖拽/条形几何全部以 dayW 乘法表达，连续值无舍入累积问题（落点仍经 wdOffsets 吸附工作日）。
- 用例：clientWidth 注入 800 → 点全览 → 月段宽合计 ∈ (600, 800] 且回到日刻度层。

## 3. 周刻度（日月之间的底层刻度切换）

- `WEEK_TIER_BELOW = 12`：dayW ≥ 12 底层=逐日号（原口径不变）；< 12 切自然周段——`weekRuns` 按周一（getUTCDay()===1）切分、跨月不断开，段宽=7×dayW（首末段为残周）。
- 周段标注：≥44px「M/D」（周起始日）/ ≥18px「D」/ 更窄留白只画格线；title=`第 N 周（M/D ~ M/D）`（N=工程周序号）。
- 月层恒在顶行不受切换影响；非工作日底纹/今日线/竣工线在覆盖层 SVG，与刻度层解耦，切换零改动。
- 用例：zoom-out ×2（20÷1.35²≈11 <12）→ `.sched-ts-week` 出现 3 段（2026-09-07 周一起 21 天）、首段标注「9/7」、日列清空、月层保留。
