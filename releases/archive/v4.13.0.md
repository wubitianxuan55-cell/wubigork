## 背景与过程

「自动操作应用和网页」是四柱（本地小模型/长期记忆/多 agent/自动操作）里
唯一还没有执行面的柱子——此前 gaea 只有感知（screenshot/vision），没有对
外部世界的结构化操作。本刀为调研后刀序④：**CDP 控制 Edge**，走「结构化
自动化」路线（确定性选择器 + ref 机制，不做截图像素点击），permission +
事件留痕第一天挂上。执行方式：探索子代理代码地图 → 实现子代理单刀全量
实现 → 主控全绿门禁 + 真机验证。

## 交付明细

### internal/gaea/browser 包（新，4 源文件 + 3 测试文件）

- **edge.go**：msedge 三段式定位（`GAEA_BROWSER_EXE` env 不校验存在 →
  `%ProgramFiles(x86)%` → `%ProgramFiles%` → `exec.LookPath`）；启动参数
  `--remote-debugging-port=<freePort>` + `--user-data-dir=<独立临时目录>`
  （`os.TempDir()/gaea-browser-profile-<pid>`，启动前清残——**绝不碰用户
  主 profile**，无用户 cookie/登录态）+ `--no-first-run
  --no-default-browser-check`；默认**有头**（可见=可信任），LaunchOptions
  {Headless} 供测试；`proc.StartTracked` Job Object 绑定（gaea 进程死则
  Edge 全家收）；headless 才 HideWindow。
- **targets.go**：DevTools HTTP 元端点——`/json/version` 探活轮询（100ms
  间隔、20s dead-start 上限）、`/json/list` 找 type=page、无页时
  `PUT /json/new`（Edge 新版要求 PUT）、`/json/close/<id>`。
- **cdp.go**：页面级 CDP WebSocket 会话——gorilla/websocket（零新增依
  赖）；写 mu 串行 + 3s 写超时；id→pending 命令-响应匹配，readLoop 退出冲
  刷全部 pending；事件旁路通道满丢弃绝不阻塞；`Call` 默认 15s 超时；Close
  幂等。用到 `Page.enable` / `Page.navigate` / `Runtime.evaluate`。
- **manager.go**：`Ensure` 幂等（全程持 mu 防双拉起）+ **失联自愈**（先
  evaluate 健康探测，失联自动整体重拉）；`ValidateURL` 只放行 http/https
  （拒绝 file:/javascript:/data: 等，localhost 放行供测试）；Navigate 等
  loadEventFired 事件优先、readyState 轮询兜底；**ref 机制**——snapshot
  给可交互元素（a/button/input/textarea/select/[role=button]）标
  `data-gaea-ref` + `window.__gaeaRefs`，带 `__gaeaEpoch` 代数守门，页面
  跳转即整代失效、诚实报 stale_refs；Type 用 React 兼容原生 setter +
  input/change 事件派发；`Shutdown` = KillTree + 清临时 profile；
  `Default()` 单例 + `SetForTest` 注入。

### 7 个 browser_* 内置工具（tool/builtin/browser_tools.go）

| 工具 | 参数 | ReadOnly | 说明 |
|---|---|---|---|
| browser_navigate | url, timeout_secs? | false | scheme 白名单 |
| browser_read | selector?, max_chars? | true | title+url+innerText（默认 6000 字符，硬上限 50000） |
| browser_snapshot | — | true | 交互元素清单 `[#1] <a> 文字`（ref 可跨调用使用） |
| browser_click | ref?/selector? 二选一 | false | scrollIntoView 后 .click()，返回元素文本确认 |
| browser_type | ref?/selector?, text, submit? | false | React 兼容 setter；submit 触发表单提交 |
| browser_scroll | direction, amount?, selector? | false | window/容器内滚动 |
| browser_close | — | false | 关页 + Shutdown 浏览器进程 |

- 全部 work 空间（工具自声明 SpaceTag，play 空间物理过滤天然不含）；懒
  Ensure（首次任意 browser_* 调用拉起浏览器）；envelope 结构化返回
  （ok/timeout/not_found/stale_refs/validation_error/exec_error 程序化
  码，错误由 envelope 承载）；compact 描述 7 条登记（prompt token 收敛）。

### 权限门与留痕

- **分档**：browser_read/snapshot ReadOnly=true（只读档恒放行）；navigate/
  click/type/scroll/close ReadOnly=false（落入 Mode 回退——交互 ask 档弹
  卡一次、可记忆规则；headless 子代理走 headless gate）。不进 hardAskTools
  （MVP 弹卡成本控制）。
- **subject url 键**：`permission.go` subjectKeys 追加 `"url"`——授权可固
  化为 `browser_navigate(<url-glob>)` 窄规则（测试锁：不遮蔽既有键、
  allow/deny/ask 全链、会话记忆固化）。
- **留痕零改动**：工具调用经既有 ToolDispatch/ToolResult 事件进会话
  JSONL（逐行带 space）→ trajectory/agentnet 折叠 → 前端过程卡/工具分组
  自动展示——全链对工具名零特判，browser 动作天然可查可回放。

5. **窗口空间扩展（Windows UIA）**：四柱纵深下一块砖，浏览器之外的应用自
   动化。
