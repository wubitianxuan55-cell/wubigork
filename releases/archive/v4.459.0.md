## 本版是什么

用户追问「重构造价数据库在哪里 / 成本条目还是以前的、根本不是清单 / 概览是个什么玩意」——v4.457/458 把工料法落在了数据层和平行模块，板块主界面没动，落点偏差坐实。本版按用户指令「**对造价数据库进行全新设计，该删除就删除**」重造板块 IA。**零新绑定**（绑定面恒 654，drift PASS；Go 绑定与数据表全保留，旧数据零损失——删除只发生在 UI 层）。

## 新 IA：6 个顶级模块，费用汇总首屏

| 模块 | 内容 |
|---|---|
| **费用汇总**（默认落点） | 分部分项清单 + 取费链，清单测算工作台 |
| **单价分析** | 消耗定额 × 资源价现算综合单价；导入/导出五表工作簿 |
| **资源库** | 工料机主数据：现行价/基准价、调价历史、存量资源化 |
| **价格数据**（四段） | 价格源 / 价格仓库 / 询价库 / **资料条目**（旧「成本条目」整面降级归档，检索/导入/AI 解析全保留） |
| **造价参考** | 案例分位数对标（不落表实时聚合） |
| **概览**（殿后） | 工料法仪表盘 + 关联图谱双视图 |

打开造价数据库即进费用汇总工作台——五表模版「费用汇总」的软件形态。

## 概览换血（工料法仪表盘）

- **三层规模 hero**：资源 N（四类构成条：人工/材料/机械/外委）· 定额 N · 资料条目 N · 价格源 N + 口径备忘（综合单价只含人材机等四条铁律）。
- **下一步引导**：按库里最缺的一环指路——定额=0 时显眼引导「还差消耗定额 → 去导入项目表」（用户当前库正是资源 1486 / 定额 0 的状态，概览第一眼即指路）；定额就绪后「开始清单测算」。
- **空库三步**：导入项目表 → 维护资源库 → 订阅价格源。
- 旧指标（库规模/待补单价/草稿复核/最近更新）随换血消失，数据在「资料条目」段内完整可达。
