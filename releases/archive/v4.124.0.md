## 一、刀2：agent 通道（Go 侧）

### 1. ops 增量操作集扩枚举（ops.go）
- `upsert_resource`（整量新增/按 id 替换）、`patch_resource`（指针三态）、`remove_resource`（**级联删其全部分配**）、`set_assignments`（整体替换某任务分配集，set_links 同范式）；`patch_task` 增 `fixedCost`。
- op 层 fail-closed：空 id/非法类型/负值/NaN/Inf/悬空引用/集内重复/分组行禁挂分配与禁 fixedCost（拍板项 4 的 ops 通道执行）。
- **schedule_apply 回执强制带写入后总成本** `totalCost`（+ops 通道涉及任务的 `taskCosts`）；证据卡 AfterSummary 追加「总成本 X.XX 元」——「成功≠正确」纪律延伸：改了费率必须核对总成本。
- compact 通道三条 compactDesc 同步。

### 2. 三工具扩容（schedule_tools.go）
- **get**：回执增 `resources[]`/`assignments[]`/`costs{ok,total,byTask,byResource}`。
- **analyze**：成本叙事 `costs{total, topTasks≤5, byResource, unpriced[]}` + 新 finding「已分配未定价」（work 无费率且无每次使用/cost 缺金额；AI 建议层，非引擎拒绝——设计 §3.2）。
- 技能条款：schedule-edit Body 增「## 资源与成本」分节（三类口径/元-工日纪律/先建资源再挂分配/回执核对），Description 增成本触发词。

## 二、刀3：板块 UI（前端）

### 1. 资源工作表（新 ResourcePanel.tsx，页头「资源」按钮 Popover）
- 资源表：名称/类型/费率（**单位显式标注**：work=元/工日、material=元/单位、cost 隐藏费率显示「—」并联动清理无关字段）/每次使用/已分配任务数/资源成本合计（computeCosts().byResource）。
- 增（默认 work）删（Popconfirm **级联删分配**）改；类型切换联动字段显隐；无独立保存按钮——提交即走防抖自动保存既有链路。

### 2. 甘特成本列 + 行级资源 Popover
- 左表列尾「成本」列（w=72 右对齐）：叶=明细合计（含 fixedCost）、分组=子孙叶求和（groupSpan 滚动口径）；无数据/CPM 循环留空（诚实呈现）。
- 名称单元格内资源入口（**分组行不渲染**）：Popover 内固定成本输入 + 资源勾选（勾建/取消删）+ 按类型 units/quantity/amount 编辑；提交=整体替换该任务分配集。

### 3. 状态栏总成本段
- 有资源/成本数据时常驻 `总成本 ¥N`；无数据整段不显示（不留 ¥0 假象）。

### 4. store 容错口径（与 normalizeProject 同律）
- 数值负值/NaN/Inf → 丢弃字段回落 undefined（不抛错打断编辑流）；setTaskAssignments 对分组行 no-op + 悬空/重复条目清洗；upsertResource 类型切换联动清理。
- **附带必要修复**：removeTask 级联删除所删任务的 assignments——否则删任务后悬空分配会被 Go Validate 拒收、自动保存失败。
