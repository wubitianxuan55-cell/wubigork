# v4.420.0 · 计划模式手动选择：Composer 工具栏「计划」chip

> 用户拍板「计划模式不是默认模式，但可以选择手动」的落地：给计划模式一个显式的
> 手动选择入口，不再要求用户知道并输入 /plan on。前端 3 文件，绑定面 720 零变更，
> Go 零改动，零功能删除。

## 落地

- **ComposerToolbar 新增「计划」chip**（思考深度选择器右侧，ClipboardList 图标）：
  - 非默认：初始关（引擎装配前无计划回执=关，与非默认语义一致）；
  - 点击翻转：发送 /plan on（或开态下 /plan off）走既有动词链（dispatchSlash→
    政策注入/退出叙事→notice 可见回执，v4.419 已可见化）；
  - 状态推导：App 层从 store 的最近一条计划回执推导（「计划模式已开启/已处于
    开启状态」=开，「已退出计划模式/计划模式未开启」=关）——无需新绑定、无轮询，
    与引擎真实状态经回执天然同步；
  - 回合进行中置灰（引擎此时拒绝切换：cannot toggle plan mode while running）；
  - aria-pressed + title 双语文案（开/关两个 tooltip）。
- 复用既有链路零新增：动词处理、回执渲染、审批卡全部复用 v4.414/v4.419 既有面。
