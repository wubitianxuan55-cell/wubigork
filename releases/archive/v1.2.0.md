## 二、本次改动（5 批提交）

### 1. 死代码清理 + 办公板块设置写路径接通（64c31b2）
- **删除死代码**：`internal/gaea/notify` 包（2 文件）、`fileutil/atomic.go`（ReplaceFile 无引用）
- **架构洞察**：28 个 `errNotSupported` 存根不是死代码，而是"读有写无"的功能缺口——
  设置面板 6 个标签的保存按钮全部触发存根报错（gaea 引擎配置是内存注入 `SetLoader`，无持久化路径）
- **新增** `internal/gaea/config/save.go`：配置原子持久化到 `~/.config/gaea/config.toml`
- **重构** `GaeaInit`：`gaeaLoadConfig`（文件优先）+ `gaeaBuildController` + `gaeaRebuildLocked`
  （改配置 → 保存 → 重建 controller 使变更生效）
- **接通 20 个存根**：Agent 参数 / 权限 / 沙箱 / 模型设置走持久化+重建通道；
  Provider 增删改转发模型中心；OAuth 走 xAI 登录
- 回退 / 更新类改为明确错误语义，前端隐藏回退菜单

### 2. 绑定层按域拆分（20188e3 + 0771d61）
- **App 结构体从 20+ 平铺字段 → 5 个嵌入引用**（core + 4 域 State）
- 新增子服务结构体，197 个方法按域归位：
  - `writingState`（写作域 81 方法）：pm / eng / 5 子代理 / skillLoader
  - `mediaState`（媒体域 43 方法）：voiceManager / TTS / ComfyUI 进程
  - `whisperState`（轻语域 30 方法）：assistantMgr / weixin 通道
  - `officeState`（办公域 32 方法）：proposalSvc
  - `core`（共享 11 方法）：模型中心 GetEngines / SaveEngine / SetActiveEngine 等
- Go 嵌入提升保证 **Wails 绑定不变**（前端零改动），`embed_check_test` 编译期断言
- 子服务持 `app` 反向指针协调跨域调用（媒体 → 写作 / 轻语）

### 3. staticcheck U1000 全仓库清零（c9e90d3）
- gaea 引擎：删除 `AgentRunner.filteredSchemas`（54 行）、`incompleteCanonicalTodos`、
  `Controller.runTurn`（包装方法无调用）
- whisper：删除 `candidate_collector.go` 整文件（179 行纯对齐孤岛）、
  emotion_fusion 7 个未用函数、clampInt / planOverrideMinConfidence / rerankTemperature
- ai：删除 `ComfyUIBackend.buildFluxWorkflow`（18 行，已被 Z-Image/Krea 取代）

### 4. 原子写实现去重（fdaeb17）

- 5 处手写重复实现收敛：config/save、config/edit、session/save、session/branch、app/gaea_ui
