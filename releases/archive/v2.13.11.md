# gaea v2.13.11「修复记忆中枢·用户画像打不开」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.11.exe](gaea-v2.13.11.exe)（Windows x64，约 39.6MB）

修复记忆中枢「用户画像」页面打开即崩溃（白屏/无法打开）的问题。

## 问题与定位

打开「用户画像」页时，前端报 `Cannot read properties of null (reading 'length')`：
后端 `GaeaProfileConflicts()` 在没有冲突时返回 Go 的 nil 切片，Wails 序列化成
JSON `null`；前端直接读 `conflicts.length` 抛 TypeError，被 ErrorBoundary 拦截，
整个页面打不开。

## 修复

- 后端 `DetectConflicts`：无冲突时返回 `[]` 而非 null；`GaeaWhisperEpisodes`
  错误路径、`GaeaMemoryGraph` 空图同样保证非 null
- 前端 `ProfileLibrary`：conflicts / tags 统一 `?? []` 兜底，不再直接读 null
- 同步加固 `GraphView`（图谱 nodes/links）与 `WhisperMemoryLibrary`（episodes）
  的同类 null 访问
- 新增回归测试：Go 侧 DetectConflicts 非 nil 空切片；前端 null 数据渲染不崩溃

## 验证与发布

- go build 通过；memory 包测试通过；前端 tsc + 128 例全过；wails build 通过
- 产物 gaea-v2.13.11.exe（约 39.6MB），桌面端同步；git tag v2.13.11
