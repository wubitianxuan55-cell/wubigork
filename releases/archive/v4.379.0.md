# v4.379.0 — dsh 蒸馏第二弹：spill 泄洪 + 中断流结构化块保全

> dsh（deepseek-harness 0.1.6）留池再进两刀：spill 泄洪 + 中断流结构化块保全落地（留池余 7 项）。全 Go，绑定面 711 零变更（read_spill 是 agent 工具目录新增，非 App 绑定）。

## 落地（两刀）

1. **刀1 spill 主动泄洪（dsh packages/spill/spill-policy 蒸馏）**——
   - 语义：成功工具结果 ≥24KB 时，**全文先存会话泄洪库**，内联文本前置 locator 指引（`[spilled] full output (N bytes) saved as spill sp-000042 …`），模型经新工具 `read_spill(id, offset, max_bytes)` 分页取回——大结果的中段不再被截断管线销毁，经济性从「压缩时被动归档」提前到「执行时主动泄洪」。
   - **gaea 落点=捕获在压缩前**：上游泄洪对象是「最终文本」；gaea 的按工具压缩（bash 24KB 等）与全局 48KB 截断会先销毁中段，泄洪必须抢在 SmartCompress 之前保原文，预览仍交给既有压缩管线（比上游裸 head/tail 预览更聪明）。
   - **locator 前置是截断生存性的结论而非偏好**：信封是单行紧凑 JSON，超 48KB 时 selectHygieneLines 全行保留但首行被 snapToRuneBoundary **头部**截断——尾缀指引会被切掉；head+tail 多行路径下头部行同样必保。两种截断形态下前缀 locator 都必然存活（尾缀版被 TestSpillNoticeSurvivesTruncation 当场抓出）。
   - 存储取 **runner 内存泄洪库**（新叶子包 `internal/gaea/spill`）而非上游的会话磁盘 artifact：gaea 单运行时无跨进程共享需求，磁盘版唯一收益（重启幸存）不值得无主痕迹文件的卫生面；单条 4MB 上限+总量 64MB FIFO 驱逐兜住内存上界，重启清零即天然会话级。locator 过期/驱逐如实报错不静默给空串。
   - 豁免（防循环/保语义）：`read_file`（自带 offset/limit 分页+缓存，上游 read 豁免同义）、`read_spill`（取回工具自身）、`task`（子代理最终回答必须原样抵达父级）。
   - best-effort 纪律（上游原文）：库关闭/不足阈值/超限拒收/Save 失败一律零影响——泄洪绝不把成功调用变错误或藏掉内联结果。
   - 配置门：`[agent] tool_spill`（默认开，false 回旧行为=Options.Spill 不装配零行为变化）；子代理经 taskTool.SetSpill 随父配置（各持独立泄洪库）。
2. **刀2 中断流结构化块保全（dsh agent-loop step catch 蒸馏）**——
   - 终态流错误/预算阻断路径此前**只存文本**：模型已声明的工具调用从历史消失，重放/续聊丢意图。本刀把 assistant（含 calls）落库——但 assistant(tool_calls) 后必须有 tool 结果行（否则下次请求是非法历史形态，provider 拒绝），故新增 `persistInterruptedCalls` 成对补结果：流式预执行（只读工具在 ChunkToolCall 即开跑）有真实结果用真实；其余合成「stream interrupted: received but not executed」占位（WrapError 信封，与正常路径「会话 tool 结果=信封 JSON」约定一致）。ToolResult 事件照发，前端半开工具卡片得以收口。
   - **恢复路径刻意不落 calls**（会重试采样的路径）：落了就是悬空 assistant(tool_calls)，保留原「只存文本」行为是对的——两路径分流是本刀的关键辨析。
   - 真零内容不落库空历史的 v4.374 纪律不变（无文本无思考无调用仍不落库）。

## 坑

1. **信封是单行 JSON，截断按「行」选择、按「字节」裁切**——行数不超限（单行/少行）时全行保留后首行被头部裁切，尾缀内容必死；要活的内容放头部。这条对所有「结果内嵌指引」类机制都成立。
2. **混合批的执行序不是调用序**（v4.375 分区并行：不同资源键共存并行）——「先 big 泄洪再 read_spill 取回」的端到端测试放同一批会竞态假红，跨回合（跨采样轮）才有全序。
3. **agent 包测试引 builtin + builtin 引 agent = 测试期 import cycle**——生产编译不报、`go test` 才炸。共享类型下沉叶子包（internal/gaea/spill），ctx 盖章键随存储走，策略（阈值/豁免/文案）留 agent 侧。
4. **preOutcomes 存的是已包信封的 output**——从预执行捞真实结果时别假设裸文本；合成占位也要走同一信封约定，否则回放/续聊两种形态混存。

## 升级说明

- 新工具 `read_spill` 进入工具目录（system prompt 目录随新会话生效）；模型面对超大数据结果时会看到 `[spilled]` 指引并可分页取回全文。
- 不想要泄洪：`config.toml` `[agent] tool_spill = false`（旧行为：大结果被截断管线销毁中段）。
- 流中断/预算阻断后的续聊：历史里保留了模型已声明的调用与「未执行」占位，模型可按占位提示重发；不再出现「文本说要去改文件但历史无调用」的断裂。
