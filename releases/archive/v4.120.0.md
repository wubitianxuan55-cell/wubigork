### 2. 偏好持久化（schedule/chatPrefs.ts 纯函数）
- localStorage 键 `gaea.schedule.chatPrefs`：`{"collapsed":bool,"width":num}`。
- 字段级容错：坏 width 不拖累 collapsed、坏 JSON/空值回缺省、写失败（隐私模式等）静默——偏好属锦上添花不惊扰。
- 纯函数 + 可注入 storage，5 例测试（钳位/容错/合并/钳位落盘）。

### 3. 新会话二次确认
- 「+ 新会话」按钮加 Popconfirm：「新建会话？当前线程仍保留在办公板块历史中。」——防误触清屏；确认文案同时教育了线程共享语义。

### 4. 常用指令快捷条（4 chip）
- 位置：Transcript 与 Composer 之间。点击**直接发送**（与 Transcript 欢迎卡同口径），运行中禁用：
  - 分析当前计划与关键线路
  - 检查缺前置任务并推荐逻辑关系
  - 生成本周进度汇报
  - 评估能否提前 5 天竣工
- 文案与 schedule-edit 技能的三大工作流（分析/推荐逻辑/倒排校核）一一对应。

### 5. 头部副标题
- 「与办公板块共享同一条工作线程」常驻——把刀10 的核心卖点显性化。
