**口径说明**：usage 事件的 `input/output/cacheHitPrice` 字段即供应商上报的
**每 1M tokens 单价**（既有费用公式 `tokens×单价/1e6` 证实），fold 原本只
用它们累加费用、用完即弃；本刀把**最近一次非零单价**作为费率快照透出，
hover 即得明细。用户自定义价目（v4.59 user_price_in/out）作用于引擎侧计
费估算，与此处「供应商上报口径」是两层——不混算，hover 如实标注来源。

## 变更

### Go（contextview）
- `types.go`：`ContextTimeline.Rate *CostRate`；`CostRate{InputPer1M,
  OutputPer1M, CacheHitPer1M, Currency}`。
- `fold.go`：fold 状态记录最近一次非零单价（后续 usage 覆盖旧值）；
  `FoldTimeline` 组装时任一非零即挂 `tl.Rate`；无定价上报 → nil。

### 前端
- `lib/types.ts`：`ContextCostRate` + `ContextTimeline.rate?`。
- `context/cards.tsx`：SummaryBar 增 `rate` prop；成本单元格 hover title =
  `costHoverTitle(rate, costEstimate, t)`——五行明细（来源口径说明 +
  未缓存输入/输出/缓存命中 `¥X / 1M tok` + 累计费用）；无费率 →
  「供应商未上报费率（用量无定价字段），费用未估算」；币种 CNY→¥ /
  USD→$。`costHoverTitle` 为导出纯函数（可单测）。
- `ContextView.tsx`：传 `timeline.rate` 给 SummaryBar。
- i18n 三语 +5 键（`contextview.costNoRate/costRateIn/costRateOut/
  costRateCache/costRateSource`）。
- dev mock：ContextView 场景补 `rate` 样例（CNY 2/8/0.5）。
