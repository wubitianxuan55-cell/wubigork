# gaea v3.0.7 发布说明

> 2026-08-17 · 办公板块文件交互体验（P0-P2）+ 内置 prompt 模板兜底

## 办公板块 · 文件交互体验（调研 docs/2026-08-16-office-file-interaction-research.md 落地）

### P0 三件套（文件成为一等公民交互对象）

- **非图片附件 chip 化（P0-1）**：拖入/选择的 docx/xlsx/pdf 等非图片文件不再注入
  裸 `@路径` 文本，而是进入 Composer 附件栏渲染为「图标 + 文件名 + 扩展名 badge」
  chip——点击可预览、可移除；提交时仍按附件数组统一注入 `@路径`，行为零变化。
- **行内文件 chip 视觉统一（P0-2）**：新增 FileChip 组件 + lib/fileBadge 扩展名单源
  （BADGE_EXTS 从 FileMenu 收敛为单一数据源）。FileLinkText / Markdown 文件链接 /
  流式尾部 htmlFileLinks 全部升级为「图标 + 文件名 + 扩展名 badge」，与 @ 菜单同视觉。
- **最近文件快捷区（P0-3）**：lib/recentFiles localStorage 单源（@ 引用与预览共用，
  去重置顶 20 条）。文件面板顶部新增「最近」快捷条，一键回到刚看过的文件；
  预览过的文件自动记录。

### P1（会话内文件导航 + 产物版本感）

- **多文件预览队列（P1-1）**：preview store 扩展 previewList/index/navPreview 单源
  （兼容原 previewFile 字段；已在队列去重跳转、上限 50、close 清空）。App 预览状态
  全部改由 store 驱动（消除局部副本双写不一致）；预览 pane 底部新增 ← index/total →
  导航条（单文件不渲染、首末自动禁用），在多文件间来回切换。
- **产物版本时间线（P1-2）**：sessionDeliverables 保留首现顺序 + 记录同一文件会话内
  出现次数（versions）；产物面板对更新多次的文件显示「vN」徽标（Rollback 图标 +
  主色，title 说明更新次数），对标 Hermes 版本步进器。

### P2（有界渲染 + 用量透明）

- **大工具输出有界预览（P2-2）**：lib/tools.ts 新增 boundedOutput 纯函数——工具输出
  超过 60 行折叠为头部 + 「… 已折叠 N 行」提示；ToolCard 提供「展开全部 N 行」/
  「收起输出」开关，超长 bash/web_fetch/read_file 输出不再撑爆卡片（对标 QwenPaw）。
- **附件上下文占用透明化（P2-4）**：附件 chip 显示「4.0 KB」等占用（图片按 base64
  估算 / 文件取 File.size / PickFiles 后端 size 字段补前端类型），title 注明「附件
  占用（进入上下文的体量）」（对标 QwenPaw context-usage）。
