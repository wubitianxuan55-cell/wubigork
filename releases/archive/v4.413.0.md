# v4.413.0 · 良性取消日志降级（前端错误观测通道降噪）

> 观察池项落地（v4.412 真机走查收官时新挂：取消路径被全局前端错误钩记 ERROR 级）。
> Go 1 文件 +1 测试，绑定面 720 零变更。

## 背景与根因

v4.412 sin 实弹走查（2026-09-25/26）实证：用户点「取消」后 UI 已语义化 info 提示
（「已取消生成」），但桥接统一入口（frontend/src/gaea/lib/bridge/proxy.ts `invoke`）
对**所有**绑定失败无差别上报 `GaeaLogFrontendError`，Go 侧一律 `slog.Error` ——
良性取消以 `[frontend] [CharacterGenerateSheetError] … context canceled` 落进
Error 级观测通道。剧照/设定卡/绘梦三条取消链路同病；长日志分诊时
ERROR 通道的信噪比被用户正常操作稀释。

## 落地

- `internal/app/gaea_ui_extra.go` `GaeaLogFrontendError`：message 含
  `context canceled`（Go ctx.Err() 标准串，三条取消链路的公共叶子）→ 降级
  `slog.Info`；其余照旧 `slog.Error`。零绑定面变更、审计痕迹保留（INFO 级仍在册）。
- 前端零改动：proxy.ts 统一入口语义不变（仍上报、仍按原拒绝语义抛出）。

## 测试与门禁

  真实错误 ERROR，复用 slog_swallow_test.go captureLogs 基建）。
- 全量 ci.ps1 绿 + 漂移闸 OK@4.413.0。
