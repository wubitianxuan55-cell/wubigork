# v4.185.0 — 阅读页场景化：读场景拼装 · 逐场景保存 · blob 双向同步（2026-09-09）

> v4.184.0（阶段一 1A 出口刀）声明的欠账收刀：阅读页从「整章 blob 单框」
> 升级为「V4 主线章场景拼装」——展望验收面「小说新章在阅读页是场景」至此落地。

## 1. blob↔场景 双向同步（Go）

- **场景→blob 投影** `syncBlobFromScenes`：V4 且有场景时，blob = 各场景正文
  按空段拼接（无分隔线，保导出/搜索/统计可读）。挂在全部四条场景写路径：
  SaveScene / ReorderScenes / RestoreSnapshot / GenerateScene。失败只 warn——
  blob 滞后可由下一次场景写自愈。
- **blob→场景重置** `rebuildScenesFromBlob`：整章重写（CreateChapter 主线
  完成点）后删除既有场景并从新 blob 物化单场景。整章重写后旧拆分与旧 POV
  元数据不再对应新正文，重置=诚实可预期；无场景的章 no-op。
- 去味/高级去味/LLM 重写经核查**本就场景感知**（有场景走场景），无需挂钩。

## 2. 阅读页读场景（前端）

- `ChapterTabData` 增 `sceneIds` / `sceneBacked`；`IsProjectV4` 每项目探测一次
  （ref 承载结论，检测完成前打开章节无竞态；浏览器 mock/旧壳无此绑定 → 保持
  blob 模式）。
- 载入：V4 主线章 `GetChapterScenes` → 逐场景框 + id 按索引对齐；分支章/V3/
  未知/场景读取失败 → 整章 blob 单框（宁显示勿空白）。
- 保存：场景制章逐场景 `SaveScene`（blob 投影由 Go 侧同一调用内同步）；
  无 id 的框（罕见兜底）先 `CreateScene` 补建再存；分支/V3 章保持整章存不变。
- `ChapterEditor` 场景 ids 改由 tab 携带（ChapterPage 载入时一并读入），删除
  编辑器内自治拉取 effect；加场景经 onUpdate 回喂 `sceneIds`。
- 绑定面 602 零变更（全部复用既有绑定）。

## 3. 已知边界（诚实声明）

- CreateChapter 流式期间 blob 分段写入、场景库尚为旧值——最终写盘点重置场景，
  重开章节即一致；生成过程中停在阅读页的旧 tab 不自动刷新（既有行为类）。
- 浏览器 `?mock=1` 无 IsProjectV4（legacy 直调面）→ 阅读页保持 blob 模式，
  场景制链路由 vitest + Go 用例覆盖。
