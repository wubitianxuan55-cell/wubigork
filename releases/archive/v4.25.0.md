## 交付明细

### ① A3 编辑器 tab 化（文件工作台）

- **右栏内多文件编辑器 tab（EditorTabs）**：文件树行点击 / 最近文件 chip 默认
  在右栏内打开编辑器 tab（不再收面板跳主区）；`lib/editorTabs.ts` zustand
  模块级外部 store——open/close/activate、上限 12 超限 LRU 驱逐、关闭激活 tab
  激活相邻（先右后左）、localStorage 持久化（`gaea.rightPanel.editorTabs.v1`，
  损坏值兜底回空）；`openEditorTab()` 命令式入口供 App「模型主动打开」调用。
- **FilePreview 嵌入模式**：新增可选 `embedded` prop（默认 false 行为完全不变）；
  docx 保真编辑 / xlsx 结构化编辑 / md / 图片 / PDF / OCR 能力原样在右栏可用。
- **双入口保留**：文件树右键「预览」仍走主区可拖宽预览 pane（`onOpenMainPreview`
  语义分叉，缺省回退 onSelect 向后兼容）；面板纵向分栏（编辑器区 flex-3 /
  文件树区 flex-2）。
- **产物行「树中定位」（reveal）**：DeliverablesPanel 产物行新增「树中定位」→
  App `handleRevealInTree`（nonce 单调递增）→ 注册表 `revealRequest` 透传 →
  FileTree 展开父链 + 滚动定位 + 1.6s 闪烁（对标 better-sidebar revealInExplorer）。

### ② A3 变更 tab diff 化（Git 面板式）

- **行级红绿 diff**：变更面板文件行可展开，显示该文件每次写类调用的内容变化
  （最新在上）。数据构造 `lib/planDiff.ts` 纯函数 + `ChangesDiff.tsx` 三态渲染
  （复用 lib/diff.ts LCS，配色走 --add/--del 令牌，>300 行截断标注）。
- **数据源诚实评估（不伪造 diff）**：`edit_file`/`multi_edit` 有 old_string/
  new_string → 真 before/after 行 diff；`write_file`/`edit_lines` 仅新内容 →
  「写入内容预览」+ 原因说明（后端 evidence.StageBaseline 有写前快照但不经
  事件流下发，前端无从取旧内容）；`move_file` 等 → kind=none 显式标注。
- **回滚接证据链**：展开时懒加载 Journal（`GaeaJournalList`），按路径匹配
  （边界后缀 + cwd 锚定，排除 rollback 记录）取最近基线出「回滚此文件」
  （`app.RollbackRecord`，与 DeliverablesPanel 同粒度先例）；无基线诚实标注
  「暂无基线快照，不可回滚」。

### ③ B3 选区联动补全 + docx 降级

- **xlsx 选区→对话**：XlsxPreview 选中单元格 → 网格左下浮动「引用到对话」按钮
  （双击直编时隐藏，不抢占既有交互）。
- **docx 选区→对话**：框选工具栏补次级「引用到对话」入口（框选即改仍为主入口）。
- **docx 渲染失败降级**：`lib/docxText.ts` 提取 `word/document.xml` 正文段落
  （复用 docx-preview 传递依赖 jszip），降级纯文本视图 + amber 提示条（能力
  边界如实说明）；提取也失败才落错误页并展示两个错误。

### ④ 模型主动打开（sidebar_open）

- **Go 内置工具** `internal/gaea/tool/builtin/sidebar_open.go`：参数
  `{path, kind?}`（kind 缺省按存在性推断）；语义=纯 UI 动作（不读内容不落盘，
  ReadOnly 直允许不弹审批卡）；防穿越（realPath+within 同 confine.go 守门，
  防 `../`/绝对路径逃逸/符号链接走私）；工作区未设置→`no_workspace` 结构化报错；
  envelope data `{kind, path_abs, path_rel, message}`；work 空间（SpaceWork）；
  注册走 builtin 机制 + workspace.go 工作区根绑定（read_file 同款）+ compact
  描述表 2 条。Go 20 用例。
- **前端消费**：`lib/sidebarOpen.ts` 解析器（坏 JSON/失败 code 一律 null 不抛）；
  App 按工具事件 id 去重，`kind=file` → `openEditorTab(pathRel)`（右栏编辑器
  tab 已开则激活），`kind=directory` → 亮文件 tab；命中自动亮右栏切「文件」tab
  （先收主区预览，对标 handleSubagentStarted 语义）。
