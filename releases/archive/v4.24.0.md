## 交付明细

### ① A1 子代理工作台（分工面板工作台化）

- **树形实时拓扑（AgentTree）**：`GaeaAgentNetwork` 嵌套 Children 全量渲染
  （此前只画两层）；root 折叠为「主 agent」行、一级子代理恒可见、更深层默认
  收起可展开/收起；**新节点出现自动展开其父链**（本次挂载未见过的 id 即
  「新」，首轮只记基线）；节点行量化——状态色点（running 呼吸）、任务摘要、
  工具调用数、模型徽标、**耗时**（running 显示实时已用，1s tick；已完成显示
  总耗时）、token 数、错误数。
- **合并活动流（Devin 式单列 feed）**：所有 running 子代理的 lastText/lastTool
  按 updatedAt 倒序合并、上限 20 条、空态收起；与树内行预览并存（feed 在面板
  顶部一眼看清「此刻」）。
- **下钻链**：节点点击 → 详情卡（统计/回答/活动行）→「查看完整 transcript」
  → 消息流（#N 序号 + 搜索过滤）→ **工具调用行点击定位到 toolCallId 匹配的
  tool 结果消息**（scrollIntoView + data-located 高亮，收 v4.21 欠账）。
- **新子代理自动展开（可关，默认开）**：面板检测到新 ref 出现 → 回调
  `onSubagentStarted`（App 接线：亮出右栏并切「分工」tab，tab 被停用时尊重
  停用态不弹出）；偏好键 `gaea.subagentAutoOpen`（localStorage，损坏值回落
  默认开）。
- 数据源单轮询并行拉取（学 subagents.live「一次枚举整棵树」）：树拓扑 + 分工
  meta 两源按「ref 直等 → 任务摘要前缀双向」匹配（与后端 enrichAgentNetwork
  同口径）；5s 轮询（不可见门控）+ useLiveReload 事件流刷新。
- mock 对齐：`mock/core.ts` AgentNetwork 节点 id 与 SubagentRuns ref 对齐并
  带嵌套孙节点，浏览器开发/测试富化链路真实可跑。

### ② C1 权威产物登记表（后端折叠 + 前端只读）

- **后端**：`trajectory.FoldDeliverables` 纯函数从事件日志折叠写类工具落盘
  登记（路径/最近工具/来源轮次/时间/累计次数，按 path 去重、updatedAt 倒序、
  上限 200 条，Total 为完整去重数）；登记口径
  `evidence.IsDeliverableTool` = 写类 8 种（write_file/edit_file/multi_edit/
  edit_lines/move_file/notebook_edit/delete_range/delete_symbol）+ 生成/导出
  类 3 种（format_convert/chart_gen/diagram_gen，产物路径取 output 参数）；
  `ExtractDeliverablePaths` 与证据链 extractPaths / 前端 changes.ts 同源对齐
  （不收 source——move_file 交付物是 destination）；bash/screen_capture 无
  结构化路径参数，诚实不猜。新绑定 `GaeaDeliverableRegistry(sessionPath)`
  （sessionDirForPath 防穿越；无事件日志 Available=false 不报错）。
- **前端**：DeliverablesPanel「权威产物登记」可收起区（只读展示 tool 徽标 +
  路径 + 来源轮次 + 次数 + 时间，点击预览；total>200 提示「最近 N 条」）；
  补启发式（正文扩展名白名单）漏登的非常规扩展名 / 生成导出类产物。
- 绑定面 548 → 549：gen_bindings 重生成（office 152 方法）+ bindingNames/
  bridge/mock/spaceBindings/types 同步；drift PASS（549）。
