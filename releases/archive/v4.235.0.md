## 崩溃与根因

- **现象**：首页点「进入办公工作台」→ 错误边界整页接管：`Cannot read
  properties of null (reading 'length')`，办公板块完全不可用。
- **归因链**：用户机器上 `DagTemplateStore.List()` 遇**模板目录不存在**
  → `return nil, nil` → Go nil slice 经 Wails JSON 序列化成 **`null`** →
  前端 `setTpls(null)`（类型标注非空但边界没挡）→ `tpls.length` 炸。
  测试/mock 给的都是 `[]`，所以全绿——经典 Go nil slice ↔ JSON null 陷阱
  （v4.210「物化≠投影 nil↔[] 漂移」同族，这次是跨语言面）。
- **修复（双侧归一）**：① Go：`dag.Store.List` 与 `dag.TemplateStore.List`
  的 `os.IsNotExist` 分支返回 `[]Run{}, nil` / `[]Template{}, nil`
  （目录不存在=空集语义，非 null 哨兵）；② 前端：DagPanel 三处绑定返回
  边界 `?? []` 归一。③ Go 用例强化：空目录 List 断言**非 nil**（原先
  `len(ts)!=0` 对 nil 也过，拦不住本崩溃）。
- **真机复验**：重建壳重进办公工作台——正常渲染、错误 0、「办公流水线」
  区在位。
