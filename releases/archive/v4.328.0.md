## 论点

场景插图此前是纯文生图：角色一致性只靠外貌文字描述（刀 B 建成的参考槽
没有接到配图链），风格句写死（数字油画/电影级光影）。本刀把参考图与
风格槽贯通到 GenerateSceneIllustration。

## 落地

- **签名扩展**（v4.139 Save 先例）：`GenerateSceneIllustration(chapterNum,
  optsJSON)`——空串零行为变化，**绑定面 705 不变**；opts=
  `{"characterIds":[...], "style":"..."}`。
- **参考路由（按后端能力，刀 B 口径）**：角色 `PortraitURL` → data URL
  （本地路径读盘转换，8MB 上限；无立绘诚实跳过）；comfyui/herdsman 附
  RefImages（img2img，SceneRefDenoise=0.6——结构引导优先兼顾场景重排）；
  其它后端不附参考，返回 `refNote` 诚实降级提示，绝不静默丢参考。
- **风格槽**：非空替换风格描述（16:9 构图固定保留）；空=默认风格句。
- **chapter.Agent**：+`GenerateSceneIllustrationV2`（refs/style 参数），旧
  签名委托零变化。
- **前端 ChapterIllustration**：弹窗加风格输入 + 角色勾选（至多 8 个展示）
  + refNote 浅色说明行。**修复引入期发现的挂载效应 bug**：run 依赖选项后
  改选项会自动重跑（每次键入触发生成）——didMountRun ref 守卫恢复
  「打开即一次」语义。
