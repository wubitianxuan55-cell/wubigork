指出「计费快变」确定性：GLM Coding Plan 已改积分制（非高峰五折、旧模型名

## 交付明细

### GLM 价格表补全（internal/modelengine/stats.go）

- 原状：`modelPricing` 仅 glm-4.7 一条 → GLM 全系用量实际未被计价，成本
  仪表对 GLM 静默失真。
- 现状：按官方定价页 docs.z.ai（2026-08-31 核实，**USD/百万 token**，折
  CNY 走既有 `usd_cny_rate` 机制）补：glm-5.3/5.2/5.1 = $1.4/$4.4、glm-5 =
  $1/$3.2、glm-4.7/4.6 = $0.6/$2.2、glm-4.5-air = $0.2/$1.1、
  glm-4.7-flashx = $0.07/$0.4、glm-5.3-flash = $0.15/$0.5（列表价；50% 限
  时优惠至 2026-09-09，注释注明）、glm-4.6v = $0.3/$0.9、glm-asr-2512 =
  $0.03/MTok；免费档 glm-4.7-flash/4.5-flash/4.6v-flash 计 0。
- 诚实不入表：glm-5-turbo（显式置空，挡 `glm-5` 前缀误匹配）、glm-4-long、
  glm-tts、embedding-3、rerank、glm-image、cogview-4（官方 $0.01/张，非
  token 口径）等——无法核实的保持不计价，不编造。国内 bigmodel.cn 定价页
  为 JS 渲染无法取得 CNY 原价表（见欠账）。

### 编码套餐积分口径（billing_mode="coding_points"）

- glm 引擎走 `/api/coding/` 端点的调用：EstimatedCost 恒 0、不进
  TotalCost，`ModelUsageStats` 新增可选字段 `billing_mode` 标记口径；
  summary 聚合以 `glm@coding` 键单列（Tokens 计入、费用 0）——编码套餐按
  「积分」计费不按 token 扣费，token 统计仅供参考。
- 同桶混合窗口（切换端点家族的边缘场景）以最近一次调用口径为准（代码注
  释说明）；`ModelStatsSummary` 新增 `engines` 按引擎聚合（加法字段，旧
  model_stats.json 兼容，Version 2 不动）。

### 模型别名注记（仅 coding 家族）

- 官方 coding-plan 概览（docs.bigmodel.cn，2026-08-31 核实）原文：调用
  GLM-5.2/GLM-5.1 自动切换至 GLM-5.3，调用 GLM-5-Turbo/GLM-4.7 自动切换
  至 GLM-5.3-Flash——4 条别名（`glm_alias.go`），**边界：仅 coding 端点成
  立**，std 端点旧名仍独立计价、不注记。
- `ModelInfo` 加可选字段 `alias_of` 下发（请求模型名**不改写**，服务端自
  行切换）；记账归一在 `Manager.RecordCall`（coding 家族 glm-5.2 的用量落
  glm-5.3 价格桶）；前端模型卡「自动切换」小标记 + title 全文说明。

### GLM 目录数据驱动（glm_catalog.json + 覆盖文件热更新）

- 22 个模型 ID 从 `glmStaticModels()` 硬编码迁入 `glm_catalog.json`
  （`//go:embed`），新测试逐字锁定「一个不增不减不改」；签名不变，两处调
  用点（TestConnection / fetchModels）经 `m.glmCatalogModels()` 包装获得
  端点家族上下文（别名注记在目录源头生效）。
- 覆盖文件：config 新键 `glm_catalog_path`（照 `usd_cny_rate` 先例：Key
  常量 + configFile 字段 + saveSetters + app.go 启动注入；非密钥项不涉反
  射测试），mtime 变更自动重读（同 ID 替换 + 新 ID 追加），坏 JSON 静默回
  退内嵌——智谱目录快变时无需重编译。

### 前端（modelcenter）

- `api/engines.ts` 类型同步 `alias_of` / `billing_mode` / `engines` 三可

  `@coding` 行显示「glm（编码套餐）·积分内」；旧数据无 engines 字段整块
  不渲染）。

## 欠账清单（如实列示）

1. **本地-云端自动路由 v1**（T0 缺口②本体）：目标函数=本地优先→缓存命中
   最大化→峰谷错峰；本刀只交付了计价真实性地基。
2. **Context Compiler 前缀稳定策略化**（T0 缺口③）：固定系统提示词/记忆段
   前缀吃各家 0.1× 缓存价，本刀未动装配排序。
3. **国内 CNY 原价表**：bigmodel.cn 定价页 JS 渲染抓取失败，现表为 z.ai
   官方 USD 价 + 汇率折算；取得 CNY 原价后可替换（值域不变）。
4. **目录覆盖文件无 UI 入口**：`glm_catalog_path` 需手改配置文件；是否值
   得加绑定待真实使用反馈。
5. **glm@coding 混合窗口口径**：同模型同桶 std/coding 混跑时以最近一次口
   径为准，极端场景可能短暂错标（已注释）。
