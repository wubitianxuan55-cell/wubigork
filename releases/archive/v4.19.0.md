## 背景与过程

续 v4.17.0（事件日志数据源接通）+ v4.18.0（文件活动/增量模式/实时刷新）的
「继续完善」第三刀：上下文标签页最后一个页脚占位（「上下文浏览器将在后续
阶段接入」）收掉，补 `/context` 命令与 Agent 网络节点点击详情。三件事互不
相交，一并落地。

## 交付明细

### ① 上下文浏览器（surface 节点 + 归档，页脚占位移除）

- 后端 `contextview` 折叠补全**系统/工具节点**：request_header 的 system
  prompt 与工具集合只在「构成变化」时入 nodes（初版 + 变化版各一条，每步
  重复不刷屏）；节点文本 = 预览（300 字），全文仍在日志 request_header 行。
  nodes 因此覆盖全部六分类，与「模型可见节点」的文档语义对齐。
- 前端 `ContextBrowserCard`（上下文标签、文件活动下方）：活跃/归档双页签
  （归档 = 被压缩移出的节点，带「已压缩」标记）+ 六分类过滤 chips + 节点
  行（分类色点 + ≈tokens + 文本预览，超长可展开/收起，展示最近 60 条）。
- 页脚占位整行移除——上下文标签不再有任何「后续阶段接入」字样。

### ② `/context` 命令（斜杠菜单直达上下文看板）

- 后端内置命令 + i18n（zh/en）：`GaeaCommands()` 增 `context`（描述「打开
  上下文看板」），斜杠菜单可发现、可补全。
- 前端 `classifyComposerCommand` 增 `context` 分类，`App.handleSend` 拦截
  `/context` → 切到上下文标签（不发给模型）；CLI 等未拦截路径走控制器
  未知斜杠 Notice，诚实不猜。

### ③ Agent 网络节点点击 → 子代理详情（固定面板）

- `AgentNetworkCard` 增 `sessionPath`（App 从 currentSessionPath 注入）；
  点击子代理节点 → 拉 `SubagentRuns(sessionPath)`，按任务摘要前缀匹配
  （与后端 enrichAgentNetwork 同口径）→ 固定详情面板：状态/模型/工具调用
  数/更新时间 + 活动行（lastText/lastTool）+ 最后回答摘要；无会话路径或
  匹配不到时回退节点自带统计。点击主 agent 节点同样可固定（root 统计）。
- 悬停提示文案更新：「悬停查看节点详情 · 点击节点固定子代理详情」。
