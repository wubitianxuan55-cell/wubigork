## 变更

### lib
- `changes.ts`：`EDIT_TOOL_NAMES`（edit_file/edit_lines/multi_edit/
  notebook_edit/delete_range/delete_symbol）、`WRITE_ONLY_TOOL_NAMES`
  （write_file/move_file）——与 `WRITE_TOOL_NAMES` 划分完整无交叠；
  `READ_TOOL_NAMES`（read_file/grep/vision/format_convert，对齐后端
  contextview.fileActionByTool 的 read 白名单；ls 列目录无文件语义不入层）；
  `buildSessionReads(items)`（读取聚合，vision 的 image_path 键在列）；
  `categoryOf(path)` 扩展名分桶（文档/表格/图片/代码/其他）。
- `planDiff.ts`：`buildChangeCalls(items, tools = WRITE_TOOL_NAMES)` 工具集
  参数化（默认值不变，既有调用零破坏）。

### ChangesPanel
- 三层派生：items 为权威源（store 回退与 App sessionChanges 同源）；prop
  `changes` 在 items 为空时回退为「变更」合并层（历史恢复场景兼容）。
- 折叠态：写入/编辑默认展开（保持原「行常驻可见」行为）、读取默认收起
  （读取量大降噪）；层头计数随筛选联动。
- 类型 chips：横贯三层过滤；chip 计数=并集文件数（去重）；过滤后全空显示
  「该类型暂无文件」诚实提示。
- 行内 UI 保真搬运：写/编辑行的 diff 展开、「打开预览」、证据链回滚、
  「不构成变更」标注逐项未动；读取行为轻量行（文件名+相对路径悬停+
  「读 N 次」，点击直接 onOpenFile）。
