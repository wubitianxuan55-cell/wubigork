用户拍板（2026-08-31）：右侧面板**不收纳**轨迹/上下文，反而要把右面板重造为
**DSH-better-sidebar / Codex 式「运行工作台」**（子代理拓扑、浏览器、文件编辑器
等实时操作面）；其现有「状态显示」类内容迁到主区轨迹/上下文旁边。规划稿
`docs/gaea-office-upgrade-plan-2026-09.md`（v2）。

本刀 = 规划 §三A0「框架先行」+ §三A4「统计迁移」。对标物为本地实装的
dsh-better-sidebar v0.18（`~/.dsh/profiles/web/node_modules/`，学其交互形状与

互斥），主代理集成 + 统计迁移收口。

## 交付明细

### ① Tab 注册表（蒸馏 better-sidebar registerTab 服务化理念）

- 新建 `lib/sidebarRegistry.ts`：`SIDEBAR_REGISTRY` 类型化注册表（id/label/
  icon/group/order/defaultEnabled/keywords/render），**元数据复用 workspaceTabs
  清单（单一数据源）+ render 接线**；右栏渲染与命令面板派生全部改走注册表。
- 新增面板 = 清单加一项 + RENDERERS 补一条，按钮条/设置卡/命令面板零改动；
  面板组件本体不感知注册表（框架与 tab 内容解耦），为后续 A2 浏览器观察窗 /
  A3 编辑器 tab 留平等挂载点。

### ② 工作台外壳三件套（对标 better-sidebar）

- **全局宽度键**：右栏左缘拖拽手柄（复用 preview-resizer 的 pointer 形状），
  280–720px 钳制；宽度是布局偏好而非会话内容——最后一次拖拽胜出、跨会话
  即时跟随（落 `layoutPreferences` blob `workspacePanelWidth`，对应其
  `dsh-sidebar:v1:width`）；会话记录仅随存快照兜底。
- **声明式设置**：tab 条尾部齿轮 → 弹层卡片列表，每 tab 一张卡（名称 + 独立
  开关），停用即从按钮条隐藏（整组停用隐藏主 Tab），至少保留一个启用面板
  （最后开关锁定）；启用集全局键 `gaea.rightPanel.v1:tabsEnabled`
  （booleanMapOf 式净化：坏值逐项丢弃）；停用面板不进命令面板（prefs 门控）。
- **会话记录 v2**：`gaea.rightPanel.v1:<sessionKey>` 扩为 JSON
  `{v,tab,enabled,width}`——v4.22 裸 id 旧值照常可读（向后兼容），坏 JSON/坏
  字段逐项兜底（sanitizeState 式），激活 tab 被停用时收敛到第一个启用面板。

### ③ 主区「概览」tab（A4 迁移：统计 → 轨迹/上下文旁边）

- `ChatTabs` 第 4 个 tab「概览」（Gauge 图标，与既有三 tab 同为文件内文案）；
  新建 `components/OverviewPanel.tsx` 承载原右栏 StatsPanel（props 透传，
  StatsPanel 本体零改动），挂主区 `.main` 满高自滚动。
- **右栏统计下线**：清单/注册表/`WorkspaceTabId` union 全量移除 stats；
  v4.22 旧存储值 `tab:"stats"` 按设计的宽容 sanitize 收敛回「文件」（新增
  迁移回归用例钉住）；分析组随之消失，右栏收敛为 3 主 Tab×7 面板。
- 命令面板新增「概览面板」项（承接原「统计面板」入口语义）；
  chatTab 持久化恢复白名单加 `overview`。
