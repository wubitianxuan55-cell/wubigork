## 落地

- **新 `gaea/components/CodeCollapse.tsx`（双板块共享）**：>30 行的块级
  代码默认收起——`max-height: 380px` 裁剪 + 底部渐隐 + 「展开全部（N 行）/
  收起」胶囊钮；≤30 行零包装直通（无 DOM 开销）。折叠态保留横向滚动。
- **主题/文案适配**（跨 chunk 共享的两个约束）：
  - 渐隐色由调用方显式传（`fade`）：gaea 板块默认 `var(--bg)`；聊天线
    ChatCodeBlock 传 `#0b0e14`（hex-exempt 恒暗面板同色）——聊天 chunk
    加载不到 gaea/styles.css 令牌，不能用 CSS 变量跨 chunk 假定。
  - 按钮用全局 M3 令牌（App.tsx 主题 effect 写 :root）内联样式；文案由
    调用方注入 `labels`（gaea 走 useT 三语 `msg.codeExpand/msg.codeCollapse`，
    聊天线与其既有硬编码中文一致）。
- **新 `useTOptional()`**（lib/i18n）：无 LocaleProvider 时回退 zh 直译而
  不抛错——Markdown 是被裸渲染的共享组件（测试/mock 面板/独立挂载），
  用 useT 会让全部裸渲染用例连坐抛错；运行态恒有 Provider，真实三语不受
  影响（zh 静态字典恒可用，v4.177 回退链先例）。
- **顺带修 LocaleProvider context value 不稳定**（真回归，实验三步定位）：
  value 原先每次渲染造新对象——Markdown 经 useTOptional 成为 context 消费者
  后，en chunk 就绪的 forceRender 把 Markdown 拖进重渲染级联，ReactMarkdown
  整树重解析落在弹层中间态上，**MemCitationChip 弹层被撕掉**（CI 4 例挂、
  隔离跑稳定复现；HEAD stash 二分+三步实验锁定）。修复=value useMemo 化
  （deps: locale/pref/setPref/tt），消费者只在语言真变时重渲染。
