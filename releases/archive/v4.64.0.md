# v4.64.0「Side Chat 式追问：子代理会话 tab 内可持续提问」

> 发布日期：2026-09-04 ｜ tag：`v4.64.0` ｜ 基线：v4.63.4 ｜ 绑定面
> **559 → 560**（+GaeaSubagentFollowUp）｜ 用户点名补上 dsh 的 Side Chat
> 式追问。设计对标 dsh-better-sidebar Side Chat（README #286）。

## 行为

- 子代理会话 tab（sa_ 运行）底部新增追问输入框：对已完结的运行追加提问，
  后端复用 task 工具的 continue_from 管道继续运行——**子代理带着此前的
  完整工作记忆回答**，无需重新交代背景。
- 发送即乐观上屏用户气泡；追问后台运行（绑定即刻返回），文本增量实时
  流式打字（gaea-subagent-text 专用通道），工具与正文经 ~1s 快照轮询
  回来后清除乐观态；追问期间 tab 保持 3s 轮询、状态点自校正。
- 守卫（后端拒绝，前端同步禁用）：运行中的子代理不可追问；mt_ 本地模型
  工具是单次调用没有线程，不提供追问；主对话回合运行中先等回合结束。

## 实现

- `agent.TaskTool.RunFollowUp`：复用 continue_from 管道
  （PrepareContinue 校验 running/mt_/跨空间 → MarkRunning + TrackProgress
  ~1s 快照 → runSubSession → SaveCompleted/SaveFailed）。
- `agent.FollowUpSink`：只放行文本增量（转 SubagentText 专用流式通道），
  产出留在子代理会话内、不进主对话账本——Side Chat 语义：线程对主对话
  不可见。
- boot Options `EmitSubagentText` / `OnFollowUpReady` 把追问执行器交宿主；
  App `GaeaSubagentFollowUp` 绑定（后台 goroutine 即刻返回 + 同 ref 并发
  去重 + 主回合运行中拒绝）。
