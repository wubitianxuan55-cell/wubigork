# v4.409.0 — 图像生成内存压力预检（iGPU 冷载预期管理）

> 2026-09-25 发布。观察池「iGPU 压力预检」（v4.404.1 起四版在册）。Go 1 文件
> +3 挂点+前端 1 util+App 全局订阅，绑定面 **717 零变更**。

## 背景

v4.404.1 分诊实录：iGPU 共享内存架构下权重换出后冷载 20.5 分钟，客户端误报
超时。等待可见性与取消已收（v4.405~v4.408），缺的是提交时对「这单可能很慢」
的预期——本刀补齐。

## 落地

1. **预检逻辑**（internal/app/imagegen_pressure.go）：提交时读系统物理内存
   （复用既有 GlobalMemoryStatusEx 原生采集），可用 < 总量 15% 或 < 4GB 命中
   → WARN 落日志 + `imagegen:pressure` 事件（文案如实：「系统可用内存偏低
   （X GB / 共 Y GB）——本地模型可能需冷载，本次生成等待会明显变长」）。读
   不到静默跳过；只提示不拦截。
2. **挂点**（仅 comfyui 后端）：绘梦两提交口 + 角色库 attachComfyProgress
   （剧照/设定卡共用）。
3. **前端**：App 全局订阅一次 + 2 分钟节流提示（绘梦/角色库/sin 全覆盖，
   连续提交不刷屏）。
