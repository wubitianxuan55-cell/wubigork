# gaea v2.11.0「通用办公大优化：四大库能力闭环 + 本地语义检索栈」

发布日期：2026-08-10 ｜ 产物：[gaea-v2.11.0.exe](gaea-v2.11.0.exe)（Windows x64，约 40MB）

承接 v2.10.1 的开工前/交付/记忆自进化，本轮把「成本、知识、办公记忆、工作区文件」
四大库按同一套模式做成完整闭环，并打通全部本地的语义检索栈（bge-m3 + BM25 +
bge-reranker-v2-m3，零 token）。

## 成本库打通与功能深化

- cost_search / cost_save 内置工具：办公 agent 测算前查成本库、完成后沉淀回库
  （同名 UPSERT），cost-estimate 模板升级为「先查后沉淀」
- 办公右侧「成本库」Tab：浏览/搜索/筛选/一键结构化引用；产物面板「沉淀到成本库」
- 导入 xlsx/csv + AI 归一化（预览确认，无确认不落库）；编辑/删除/批量操作
- 价格源订阅 + 手动/定时抓取（四川造价信息网实测 24 行解析）+ 价格历史 +
  单期跳幅 ±20% 异常识别（红色徽标提示）

## 知识库大优化

- 导入 md/txt/docx/pdf/xlsx/csv + AI 多主题拆分（预览确认）
- 批量管理 + 审核流（草稿 → 现行、审核人留档）+ 版本历史（内容变化自动留档）+
  批量导出 Markdown
- 查重（CJK 二元组 Dice）+ 相似条目一键合并

## 办公记忆 / 工作区文件

- 办公记忆：两两查重 + 一键合并（自动做梦产生的同名变体可归并）
- 工作区文件语义索引：md/txt/csv/docx/xlsx/pdf/pptx 提取正文（pptx 零依赖解 zip），
  bge-m3 向量化 + 内容感知增量重建 + 10 分钟自动维护；搜索面板「语义」模式、
  记忆中枢统一搜索并入「语义·文件」命中

## 本地语义检索栈（四库统一）

- 子串召回 →（不足时）bge-m3 语义召回 → BM25 排序 →（>8 条）bge-reranker-v2-m3 精排，
  任一层失败自动降级；跨库统一语义检索（成本/知识/办公记忆）
- Herdsman bge-m3 / bge-reranker-v2-m3 实测端到端通过，全部本地零 token

- go test 全量 + go vet 干净；前端 111 例全过，tsc 与 vite build 通过
- 真实 Herdsman 语义召回（「打桩设备 台班价」→ HP300）、精排、四川价格源抓取实测通过
