## 2. 双层时标水平化（GanttView + schedule.css）

- 根因：`.sched-gantt-datehead{flex-direction:column}` 把「每天一列」的列头纵向堆叠——时间轴竖排。旧实现月份标签塞在日列内第 1 天格。

## 3. MPP 二进制导入（主刀）

- **解析器** `internal/schedule/mpp.go`（蒸馏 ProjectLibre 内嵌 MPXJ，只读零搬运；字节级规格经真实样本逐字节实证）：
  - 容器：OLE2/CFB，`github.com/richardlehane/mscfb` 深度优先遍历+已知布局状态机重建语义键。**坑：工程目录流名带前导空格**（`"   19"`/`"   112"`/`"   114"`）；mscfb 的 Name 不含 `` 前缀（`CompObj`→`CompObj`）。**无压缩**——网传 DirIndex/LZW 属另一内部布局，本仓库真实文件均为直接命名流。
  - 版本探测：CompObj skip28→len+应用名（`Microsoft Project 14.0`）→len+格式串（`MSProject.MPP9/12/14`）；应用主版本号数字回溯（15/16=2013+，切换链接 lag 偏移）。
  - 五原语：Props（头16字节 uint16 条目数@12，条目 size/key/attr+奇对齐，口令 XOR mask=0xFF-加密码）；VarMeta9（8字节条目 uid3+type1+off4）/VarMeta12/14（12字节，magic 允许 0）；Var2Data（offset 处 i32 size+数据，UTF-16LE NUL 结尾）；FixedMeta（条目 47/37/34/10，count=(len-16)/条目，头内计数不可信）；FixedData（meta 偏移定位行，任务 cap768）。
  - 业务解码：任务（9/12 偏移一致：OutlineLevel@40/Duration@60 十分之一分钟/Milestone=FixedMeta byte8&0x20/PCT@122；14 自成一套：Duration@42/PCT@90/Name=var14；8字节行=null；删除位 flags&0x02；幻影行=行长≤75%×**字段表最大偏移 264**（9/12）——**不是** 768 拷贝上限，首版用 768 把真行全跳）；搭接=TBkndCons 20字节行（constraintID 严格递增去重、类型 0=FF 1=FS 2=SF 3=SS、lag 有符号十分之一分钟@16、2013+ 移 @14）；资源（Var 键 1 名称、MaxUnits@44、材料标签→材料资源启发式）；分配（MPP9 定长 142/14=110/12 meta 定位；**删除判定=meta 首字节非 0**——int32 全非零口径会误杀真行）；日历（每周 7×60 字节：flag==1 缺省周一~五，否则段数>0 即工作日；props 键 37753736 兜底）。
  - 模型映射：UniqueID 作任务 id；两级大纲压平（有活子=分组行）；Summary 按「有子任务」重算（文件不带该位）；工期/时距按文件 minutesPerDay 换算工作日（四舍五入，负 lag 对称）；搭接/分配按 uid 回链、断链丢弃；工程开始日期取 Props 键 37748738。**不映射（诚实告知）**：约束日期、日历例外、费率、MPP14 Fixed2Data 顺序键——导入后全 auto 按搭接 CPM 重排。
  - fail-closed：打开口令保护直接报错；魔数/版本/名称解码失败均明示版本号。
- **绑定**：`GaeaScheduleImportMpp(mppBase64) → 计划 JSON`（`internal/app/gaea_schedule_mpp.go`，OfficeB 委托，与 xlsx 门面同构）；绑定面 595→596，gen_bindings 再生成+bindingNames.ts 同步+drift PASS@596。前端 `api.importScheduleMpp`（fileToBase64 与 xlsx 共用）；mock 诚实抛「需桌面端」。

  - `New Product.mpp`：43/37/8/28，83 天（MPXJ 蒸馏规格的 37 搭接、8 资源全对上）。
