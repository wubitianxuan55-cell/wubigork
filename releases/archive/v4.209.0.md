## 落地

**零新结构零新绑定**（绑定面 608 不变，drift PASS）——结论复用 v4.158 的
`ComposeCheck` 通道，前端 ComposeModal 的 Checks 渲染自动承接，前端零改动。

- **`cost.CheckContentBaseline` 纯函数**（contentband.go）：
  - 匹配键 = 标题归一精确相等（全角→半角/去空白/小写）+ 单位归一相等
    （含双方都空）；一方缺失一律不比——kg 与 t、未知与已知不可比，宁缺勿误
    （与导入链「带码未命中宁新增勿误配」同一哲学）。
  - 分位带 = 池内同键含量 P25/P75（R-7，与 priceband/costref 同口径）；
    q>P75 偏高 warn、q<P25 偏低 warn，带内静默（降噪）；P25==P75（同值
    退化带）按 ±5% 容差判带外。
  - 同键样本 < `MinContentSamples`(3) 不比对；目标行 Quantity<=0 跳过
    （非法行归 CheckComposeComponents R2 管）。
  - 文案自带口径：「含量 420 高于同类 5 例边界 315（+33.3%），核对工艺口径
    或损耗」。
- **接线**（gaea_cost_compose.go）：`composeChecks` 汇总金额自洽 + 含量对照
  两层；对照池 = 相似条目本身的组件明细（检索相似条目就是「同类」的口径，
  与价格带同池；逐条 Get，失败/无组件跳过，池空该层静默）。Checks 随视图
  展示 + Apply 留痕自动承载。
