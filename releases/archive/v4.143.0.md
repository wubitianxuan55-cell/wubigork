# v4.143.0 · 双代号显示路径优化：长线分行走通道 · 可读优先适配

> 对照参考（斑马进度 / MS Project / 网络图范例）的核心差距：**别人的图是布局分行分道方便查看，缩放只是辅助；我们此前是把整图无脑缩到 10% 塞进窗口，线全部重叠、行长距离贴着节点中心线横穿**。本轮修显示路径与适配语义。纯前端，绑定面 **596** 零变更。

## 1. 同行长箭线走行间通道（assignChannels）

- `aoaLayout.ts` 新增纯函数 `assignChannels(edges, nodeById)`：跨 >1.5 列（dx > AOA_COL_W×1.5）且同行（|dy|<2）的边判定为「长跳线」，让出节点中心线；通道基准 y = 行 y + AOA_ROW_H/2（行间空档），x 区间重叠者按处理序（x1,x2 升序）依次 +12px 层号，非重叠共享层——长跳线互不重合、也不横穿中间列的节点圆。
- `edgeSegs` 增 `channelY` 参数：同行长边若有通道，走五段正交路径（短出水平→下行→通道水平→上行→短入水平），标注（名称/工期）挂通道中线；短边与未分配边保持直连——链式箭线笔画不破坏（参考斑马：同链相邻节点直连）。
- AoaView 与 networkExport（导出图面）同源调用；通道水平段仍由 segsToPath 既有逻辑切波形（自由时差可视化不丢）。

## 2. 交叉削减加深

- `layout.ts layerByTime` 重心松弛 2→4 轮（左右交替），长计划分层更稳。

## 3. 可读优先适配

- AOA 自动适配（首帧/图面尺寸变化）：下限 **0.5**——装不下就横向滚动（斑马/Project 同口径），绝不把整图无脑缩到看不清；「全览」按钮（显式动作）下限 0.3。
- 缩放下的手动布点：拖拽屏幕位移 ÷ zoom 折算回图面坐标（zoomRef 同步），吸附/提交口径不变。
- jsdom 兜底：clientWidth=0（测试/未布局）跳过适配，不误触发缩放污染拖拽用例。
