## 变更

### Go（internal/gaea/contextview）
- `FileActivity` 增 `Added/Removed int64`（行级增量）与 `Hits int64`
  （grep 命中行近似；写入端截断时为下界）。
- `fileDeltaFromArgs(tool, args)`：从写类工具参数**确定性**提取——
  write_file `{content}`→+行；edit_file `{old_string,new_string}`→−/+行；
  multi_edit `{edits:[…]}` 逐条求和；edit_lines `{new_content,start_line,
  end_line}`→+new 行/−(end−start+1) 行。非 JSON/缺键/类型不符一律零值
  （诚实不猜）。
- `recordFile` 增 dispatchID 参数 + `fileByDispatch` 映射（dispatch id →
  files 下标）：grep「参数带路径、结果无路径」的调用在结果阶段按 id 回填
  命中数；LRU 淘汰重建时映射一并作废（防陈旧下标串行）。

### 前端
- `lib/types.ts`：`FileActivity.added/removed/hits`。
- 文件活动卡（context/inspector.tsx）：
  - 文件行 ±徽标（路径聚合合计；绿 +增 / 红 −减，hex-exempt 增量语义色
    与趋势/详情 delta 同款）；
  - 「N 次操作」展开层：逐次操作行（工具 chip + 该次 ±行/≈命中数 + 时间），
    操作行「完整调用」按钮懒加载 `GaeaContextNodeDetail(seq)` 跳转到对应
    工具结果——`NodeDetailPanel` 自 v4.80 NodeRow 抽出为浏览器/文件活动
    共享组件（原文/渲染切换在面板内自持）；
  - `useNodeDetails` hook 抽出懒加载缓存状态机（两卡共用）。
- i18n 三语 +2 键（`contextview.filesOps` / `filesHits`）；dev mock files
  数组补 ±/hits 样例 + ContextNodeDetail 增 seq 12 样例。
