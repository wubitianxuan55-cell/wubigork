# gaea v2.13.2「办公过程文件落盘规范」

发布日期：2026-08-12 ｜ 产物：[gaea-v2.13.2.exe](gaea-v2.13.2.exe)（Windows x64，约 39.6MB）

针对「任务完成后工作区根目录堆满二级产物、与源文件混杂」的问题，确立统一落盘规范。

## 落盘规范（办公 agent 执行纪律新增章节）

- **过程/中间文件**（提取的文本、OCR 页图、脚本 .py、临时图表/截图、调试输出、
  中间表格等）一律写入 `.gaea/work/<任务名>/`，目录不存在先创建；禁止写到
  工作空间根目录或与源文件混放；源文件保持原位、不移动不覆盖
- **最终交付物**（报告 docx/md/pptx/xlsx、成品图表）写入 `.gaea/exports/`，
  或按用户明确要求写到指定位置
- 正文始终给出相对工作区的可点击文件链接

## 配套

- 引擎启动时自动创建 `.gaea/work/` 与 `.gaea/exports/`
- `.gitignore` 增加 `.gaea/work/`，过程文件不入库

## 验证与发布

- go build / go vet 干净；wails build 通过
- 产物 gaea-v2.13.2.exe（约 39.6MB），桌面端同步；git tag v2.13.2
