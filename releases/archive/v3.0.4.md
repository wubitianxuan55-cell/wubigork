# gaea v3.0.4 发布说明

> 2026-08-16 · 办公板块能力加强 + 小说阅读体验重构 + 角色库闭环修复

## 变更

### 办公板块

- **任务目标 → 验收清单闭环**：任务目标升级为真正的目标工作流——目标文本 +
  逐条验收标准（添加/勾选/双击编辑/删除），全部勾选自动推导「已验收」，
  一键验收 = 全选/全不选；恢复会话时把目标写入 agent goal gate，回合结束未
  达标自动继续工作（模型判定），默认关闭不改变既有行为。
- **目标卡与待办卡拆分重设计**：底部提示区拆为两张独立卡片——任务目标卡
  （会话锚点，始终展开）与待办卡（**默认折叠**，折叠态显示当前任务摘要；
  展开后「未完成在前 / 已完成收尾」分组、当前任务高亮 + 左缘光条、进度条
  渐变、全部完成全绿）。
- **文件交互市场调研**：`docs/2026-08-16-office-file-interaction-research.md`
  完成竞品对标（QwenPaw / Proma / Hermes / 微信读书等），产出 P0/P1/P2 落地
  建议，为下一轮文件交互优化提供依据。

### 角色库

- **补齐支持五维人格**：一键补齐 / 随机补齐按补全后的性格生成五维人格
  （T/I/S/O/R，0-100），不再停留默认 50；五维骰子改为 AI 按性格生成（本地
  兜底）；「全部随机」同样包含五维。
- **加入项目可选小说**：从「写入当前打开的小说」改为弹窗选择任意小说
  （书架项目列表 + 当前项目快捷项），后端校验目标必须在书架目录内；新增
  CharacterAssociateTo 绑定。
- **加入后小说面板立即可见**：加入时物化进目标小说 characters.json（按 ID
  幂等合入，保留既有角色/组织/关系）；小说面板读取自愈——旧版只写关联表
  未物化的角色自动补齐，已加入却看不见的角色重开面板即出现。

### 小说阅读体验（P0 + P1 全量落地）

- **面板铺满 + 排版可调**：修复阅读面板窄条（根容器 flex + 去掉 46rem 限宽）；
  Aa 面板提供字号（14-24）/ 行距（紧凑/标准/宽松）/ 版宽（窄/标准/铺满）/
  主题（跟随/米黄/护眼绿/夜间）/ 亮度（70-120%）/ 自动滚屏速度，全局持久化。
- **正文排版**：按空行分段、首行缩进 2em、两端对齐、章节标题居中大字；顶部
  阅读进度条 + 每章滚动位置记忆（切章/退出/重开恢复）。
- **书签 / 划线 / 想法**：图钉书签（当前滚动位置 + 段落摘录，列表跳转/删除）；
  划词工具条四色高亮 + 想法，高亮按摘录文本回渲染，本章批注面板定位/删除。
- **AI 伴读**：章节顶部「AI 摘要」折叠卡（按章缓存、失败重试）；划词「问书」
  （摘录引用 + 提问 + AI 回答）；后端 NovelReadingAsk（summary/ask，novel
  功能路由，正文 9000 字截断）。
- **朗读同步**：阅读页脚听书，逐句高亮当前句 + 平滑滚动居中，停止自动清除。
- **全文搜索**：放大镜弹层搜全书（标题 + 正文，防抖 300ms，一章一命中带
  ±40 字片段），点击打开章节阅读模式并定位首个命中。
- **导出合并**：删除「导出」标签页，导出功能移入阅读页脚弹窗（TXT/MD/EPUB）。
- **项目上下文不跨板块残留**：切到绘梦/办公/聊天等板块时，顶栏面包屑与底栏
  遥测不再显示小说标题/进度/章数/字数（仅项目锚点板块展示）。

### 书架

- **网格统一**：移除首卡双列放大，全部卡片固定等高，不再大大小小。
- **导入成品小说**：TXT / Markdown / EPUB 一键导入——按「第X章 / Chapter N /
  序章 / 楔子 / Markdown 标题」切分章节（TXT 支持 GBK/GB18030 编码兜底，
  EPUB 按 spine 顺序读正文去 HTML），自动生成大纲 + 章节文件并打开；同名目录
  自动加序号；新增 ImportNovelBook 绑定。
