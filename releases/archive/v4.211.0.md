## 缺口

v4.210 落地后，悬空 [MEM:] 键不触达、不入图、可追溯，但仍随回复原文发出——
用户会在答案里看到验证不到的引用徽标键。真·「发出前」需要改写最终文本：
直接在事后改 session 会与 UI 已渲染的流式增量脱节。

## 落地（闸点 = stream() 收尾）

- **agent 定稿钩子**：`Options.FinalizeText` / `SetFinalizeText`（nil = 不改写，
  子代理与 headless executor 缺省）。stream() 每轮收尾在 **Message 全文事件
  发出前**应用：改写值随 Message 事件发出（前端 store 的 message 分支本就
  整泡替换——既有语义，零新事件形态、前端零改动），并作为 stream 返回值进
  session 历史 / TurnResult 摘要 / 归档——幻觉键到不了持久层。流式增量原样
  透传，由 Message 重渲染收敛。
- **剥离纯函数**：`memory.Store.StripDanglingCitations(text, space)`——命中键
  原样保留；悬空键（含大小写变体）连同紧邻的一个前导空白整处剥离；**不
  Touch**（触达职责仍在回合收尾 touchMemoryCitations，两路分离防双记）；
  space 语义同读端隔离器（work 会话把 play 键当悬空）；零值 Store 整体跳过
  （记忆未装配时绝不误剥）。
- **boot 装配闭包**：记忆总闸开 + Hephaestus.db 可用才注入；被剥离键当场落
  dangling cite 事件（AppendCiteEvents）——v4.210 的悬空可观测性不丢
  （定稿后历史文本已无悬空键，回合收尾不会再重复记）。
- **空间作用域**：闭包捕获装配时会话空间（与 sysprompt 装配、
  SessionSpace 同源），引擎随会话重建，无跨会话串味。
