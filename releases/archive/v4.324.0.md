# v4.324.0 · t6-C2 提示词工坊第二刀：模板包导入导出（content_hash 三态）

> 2026-09-16 发布。规格书：`进度计划/gaea-prompt-bundle-t6c2-20260916.md`。
> 蒸馏依据：`docs/distill/06-prompt-workshop.md` §6.4（三态算法）+§11.4（社区分享裁剪为本地包）。
> 前置：v4.323.0 t6 首刀（三级解析/五绑定/工坊面板）。

## 论点

首刀的覆盖表（`<DataRoot>/prompt_overrides.json`）是只有一份的本地状态——
换机/重装没有搬运手段；内置基线升级后也没有「哪些该转自定义/哪些该回落
内置」的对账工具。本刀补**模板包导出/导入**：全量快照明文 JSON 包 +
MuMu §6.4 三态导入算法。

## 三态算法（MuMu §6.4 对齐 + gaea 两道闸）

| 包行 IsCustomized | 基线 | 内容比对 | 动作 | 统计 |
|---|---|---|---|---|
| false | 存在 | canonical JSON 相同 | 删本地覆盖行（回落内置） | kept_system_default |
| false | 存在 | 不同（内置升级） | 写覆盖行保住包内容 | converted_to_custom |
| true | 已知键 | — | 直接写覆盖行 | created_or_updated |
| 任意 | 未知键 | — | **跳过不建行**（gaea 闸） | skipped_unknown |
| 写行路径 | — | Validate error 级 | **整行跳过不阻断整包**（gaea 闸） | skipped_invalid |
| 包内重复键 | — | — | 跳过，首见生效（gaea 闸） | skipped_duplicate |

对 MuMu 的升级：导入真校验（MuMu 导入零校验、云端人工审核当唯一闸门——
单机没有审核链，坏模板会直接毒化生成链路）；去重。裁剪：未知键不建行
（工坊 V1 不支持自建新模板键，与 Save 拒「未知模板键」同口径）。

## 落地

- **线 A** `internal/promptstore/bundle.go`（零 IO 纯函数）：
  `ContentHash`（sha256(TrimSpace)[:16]）+`SameTemplate`（canonical JSON
  逐字比对，map 键序不干扰）+`BuildBundle`（names×覆盖表×基线闭包→包；
  覆盖行存在（无论启停）取覆盖行 Content 保真备份）+`ImportBundle`
  （三态决策+合并，入参不改写、结果恒非 nil）。
- **线 B** `gaea_prompt_store.go` +2 绑定：`PromptBundleExport`（回 JSON
  字符串）/`PromptBundleImport`（坏 JSON·version!=1 报错；Applied 才原子
  落盘+失效覆盖缓存；空包/全跳过不落盘不算错）。NovelB 门面 +2。
- **线 C** 工坊面板顶栏两钮（空态也可见——导入正是空环境的恢复路径）：
  导出=Blob→`saveExportBlob` 双门（壳内 GaeaSaveFileAs 系统另存为/浏览器
  a[download]，v4.162 先例）；导入=双门选文件（壳内 `pickFileAsFile(['json'])`
  系统对话框+后置校验/浏览器动态 input，SkillModal 刀C-3 同款）→三态结果
  Modal（统计一行+逐行 action 中文 Tag，skipped_* 红/橙标+原因）→applied
  后刷新列表与当前选中键。

## 关键裁决

- 导出范围=引擎 Names() **全量**（含内置行）——备份语义（MuMu 43 全量同款）。
- 导入**不信包内 version**（防倒退）——Version 走本地 Upsert 自增，包值仅快照展示。
- 哈希只是导出侧冗余诊断；对账用内容逐字比对（MuMu 同口径不用哈希）。
- 绑定面 701→703（NovelB 121→123）；PromptBundle* 挂 *App 被默认路由
  CoreB——gen_bindings 显式覆盖表 +2 点名归 novel（v4.323 同款坑当日复现即修）。

## 测试与门禁

- Go：promptstore 三态矩阵 10 分支+round-trip 内核+canonical 稳定+BuildBundle
  统计与停用行保真；app 导出→清状态→导入覆盖逐字节回魂（引擎 Get 生效）、
  kept 删覆盖行、防御四例（空串/坏 JSON/version!=1/空包）。
- 前端：面板导出 Blob 断言/导入结果弹窗逐行+applied 刷新/取消不触发；契约 +2。
- 门禁：go build/vet 全过、tsc -b 零错、eslint 足迹零告警、vitest 全量 3143 例
  （首跑 PptxEditPanel 1 例环境 flaky 复跑绿）、drift OK@703、版本三处 4.324.0。

## 出口对照（规格 §7 全过）

- 导出的 JSON 包在干净环境导入后覆盖层逐字节回魂（生成链路同效果）；
- 内置升级场景（改基线后导入旧包）三态各分支测试钉死；
- 坏模板行不落盘且整包其余行正常导入（信任边界）；
- 绑定面 703 三处同步（Go 门面/bindingNames/bridge 接口）；
- 壳内导出落盘/导入选文件走系统对话框（双门，不走死通道）。
