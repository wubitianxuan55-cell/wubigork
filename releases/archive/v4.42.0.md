# v4.42.0「微信智能体 v1：LLM 工具调用派发」

> 发布日期：2026-09-02 ｜ tag：`v4.42.0` ｜ 基线：v4.41.2 ｜ 绑定面 **557 零变更**

## 定位（用户拍板）

「gaea 收到微信消息后应该自己派发任务给各个功能板块，把结果返回微信」——
关键词/正则意图路由是落后形态（v4.41.x 两轮真机补丁皆是它的账：正则追不完
自然口语，模型没工具只能嘴上幻觉）。本刀把微信链升级为**智能体架构**：

```
微信消息 + 工具清单[7 板块能力] → LLM 决策（调工具 or 直接回复）
   ↓ 本地执行工具 → 结果喂回模型（多轮，上限 4）
最终回复 + 产物卡片 → 回推微信
```

## 架构与实现

- **新增 `wx_agent.go`**：工具 schema 表 7 个（navigate_board / generate_image /
  edit_image / create_reminder / send_latest_file / query_status / read_screen），
  **exec 适配层零改动复用**现有意图执行函数（工具参数 → 构造 intent.Intent →
  直调 execXxx；产物绝对路径进 cards 并以文本喂回模型）。
- **循环**：`ai.Client.ChatStream`（Tools 透传，流式 tool_calls 解析是既有管道）
  → 消费 Done 块拼完整 assistant 消息 → 有工具调用则执行+tool 结果回填下一轮；
  轮数上限 4，ctx 60s 上限（clawbot 无外层超时）。参数坏 JSON 以错误文本喂回
  模型同轮自纠，不 panic。
- **人格与记忆**：LockTurn 持锁窗口内 PreLLMTurn 取 SystemPrompt（与 whisperChat
  同锁语义）；回合成功后 WM.Push+FinalizeTurn+记忆落库，**失败 CloneFullState
  快照回滚**防一条消息双计数。系统指令含行为铁律：动作必须经工具、没有工具就
  如实说做不到。
- **能力门 `wxAgentAvailable`（宁缺勿滥）**：app 就绪 + 非离线 + routeModel("chat")
  模型在目录 Caps 含 "tools"（查不到=不含）——不满足则整条链回落既有行为
  （routeIntent 正则 → 聊天），零回归。
- **回调顺序**（whisper_state.go）：文件直通、tryWxReminder 快路径保留 →
  **agent 优先**（cards 逐张 SendFileCard，末张 caption；失败降级文本）→
  routeIntent 正则降为兜底 → 未命中聊天（反幻觉引导保留）。
- 已知口径：send_latest_file 经模型原文过 intent.Parse，保留 v4.41.2
  modify_and_send 诚实护栏（「改完再发」绝不冒发旧产物）。

## 真机验证指引

任意自然语言派发均应直达能力：「帮我画一张……」「看看现在什么状态」「把产物
发给我」「九点提醒我……」「打开绘梦」；没有工具可做的事模型会如实说做不到
（不再幻觉）。出站文件卡实测仍用「把产物发给我」。
