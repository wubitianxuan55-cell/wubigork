# v4.388.0 — 原罪插图独立生图绑定：功能绑定卡新增「原罪插图」后端/模型选择

> 用户反馈「原罪的功能绑定卡片内增加生图模型选择，这么多模型为什么没有候选，只能使用 comfyui？」——两层答案：①原罪生图此前**没有独立绑定**，跟随全局生图设置（本机全局后端=comfyui），模型中心「功能绑定」里的原罪卡只绑**故事文本模型**；②生图候选其实一直在（剧照卡同款 `imageModelOptionsFor`：xAI 两个 / ComfyUI 三件 / 各引擎目录里的图像模型），只是原罪没有入口。本轮镜像「角色库剧照」先例给原罪插图补上独立绑定。Go 6 文件+前端 9 文件，绑定面 712→714（+2）。

## 落地

1. **`GetSinImageConfig`/`SetSinImageConfig` 绑定（+2）**——`sin_image_backend`/`sin_image_model` 配置键（空=跟随全局生图设置，任一项可单独回退：只换模型不换后端也行）；shelf 热更新 case 同步。
2. **生成路由**——
   - `buildImageClientFor(backend, featureLabel)` 从 buildPortraitClient 通用化（角色剧照改薄包装，行为零变化）：comfyui/herdsman/ollama/glm/xai 五后端构建独立客户端，**不改变绘梦全局后端**。
   - `generateImageInternal` 加 override 通道（`clientOverride`+`backendOverride`）：进度回调/尺寸参数裁剪/ComfyUI 自动恢复与自动拉起（v4.387）分支全部按**生效后端**判定，不再硬读全局配置。
   - `SinIllustrate`：级联 `sinImageBinding`（绑定>全局），参考槽能力判定（sinRefPlan）改用生效后端/模型（绑了 Herdsman 就按 Herdsman 判 img2img）；绑定后端≠全局后端时构建独立客户端传入，相同后端复用全局客户端（模型差异由 model 参数承担）。sin_illustrate 工具走同一入口自动受益。
3. **模型中心「功能绑定」新增「原罪插图」卡**（镜像剧照卡）——后端下拉（跟随全局/xAI/ComfyUI/Herdsman/Ollama/GLM）+ 模型下拉（跨引擎候选：引擎目录图像模型过滤 + ComfyUI 内置三件 + 当前值兜底）；原罪故事卡注释补「插图生图模型在下方卡独立绑定」。

## 测试与门禁

- Go +4 组：级联契约四态（全空回退/只绑后端/只绑模型/双绑全覆盖）/ GetSinImageConfig 空与如实回读 / buildImageClientFor 分支（xai·comfyui 构建成功不拨号、ollama 禁用报错点名功能、ComfyUI 地址缺失报错）/ override 通道（override 客户端调用=1 且全局客户端零触碰——绑定路由的核心契约）。
- 前端：BindSection +1（原罪插图卡渲染+保存动作+已绑定态显示），基础 mock 补新字段；spaceBindings 锁 535→537；bindingNames 再生 714。
- 全量 ci.ps1 绿 EXIT=0 + 版本漂移闸 OK@4.388.0。

## 坑

1. **`config.Save` 直写真实 `~/.gaea_config.json`，无测试隔离钩子**——绑定 Set 的 roundtrip 测试不能真调（同 hub*Store 系真实面坑）；测读映射与纯函数级联（抽 `sinImageBinding` 助手），Set 落盘由冒烟与真机覆盖。
2. **种子引擎目录恒 Enabled**——`NewManager` 种子 ollama/herdsman 都带 BaseURL 且启用，测「未启用」分支须先 `SaveEngine` 禁用（v4.386 语义管线坑的同族）。
3. **override 客户端的后端语义要跟到底**——只换 GenerateImage 调用点不够：进度回调、size 参数裁剪、ComfyUI 自动拉起/恢复分支原来都读 `a.cfg.ImageBackend`，漏一处就是「换了客户端没换行为」的隐性错位（本刀把四处判定统一到 backendType）。

## 升级说明

- 模型中心「功能绑定」多一张「原罪插图」卡：不绑定=与升级前完全一致（跟随全局生图设置）；绑定后原罪插图（含 sin_illustrate 工具）用选定的后端+模型出图，绘梦页与角色剧照不受影响。
- 绑 Herdsman/Ollama/GLM 云端生图即可脱离 ComfyUI；绑 ComfyUI 时继续享受 v4.387 的自动拉起。
