> 差距清单第一项（docs/gaea-schedule-gap-vs-project-2026-09.md #1，对标真实上报件与 Microsoft Project 官方「PDF/XPS 输出」）。纯前端，绑定面 **588** 零变更。

## 内容

- **ganttExport.ts 纯函数图面构建器**：一套公式独立出上报图面 SVG（发布物不随工作台交互态漂移，与 GanttView 同几何口径但独立实现）——
  - 标题带：图名（缺省 `工程名　施工进度计划横道图`）+ 编制单位/编制日期（空字段诚实省略）；
  - 表格：上报 6 列（序号/任务名称/工期(天)/开始/完成/前置，EXP_COLS 图面专用列宽；前置 Project 式 `2SS+5,4FS` 引用；分组 ▲ 粗体+汇总行）；
  - 图面：自然日双行时标（月/日）+ 非工作日底纹 + 关键红/非关键蓝/手动灰条 + 分组黑汇总条 + 里程碑菱形 + 总时差尾 + 四型搭接正交依赖线（ganttLinkPath 复用）+ 目标竣工紫虚线 + 今日绿线；
  - 图脚：图例（6 项）+ 图签三格（编制人/审核人/批准，空值留白=签章位）。
  - fitText CJK 全宽/半角 0.55 截断估算；XML 转义；循环依赖 fail-closed 抛错。
- **imgPdf.ts 最小 PDF 封装**：单页 PDF 1.4 + JPEG XObject（DCTDecode 直嵌），MediaBox 72/96 换算，xref 偏移逐字节对齐——零第三方依赖。用例解析 xref 验证每个偏移落在对应 obj 头、startxref 指向 xref 段。
- **exportArtifact.ts DOM 管线**：SVG → Blob URL → Image → canvas（2 倍超采样白底）→ PNG / JPEG→PDF / 隐藏 iframe 打印（系统打印「另存为 PDF」即 PDF 文件）。
- **exportMeta.ts**：签署字段持久化（gaea.schedule.exportMeta，字段级容错同 chatPrefs 范式）。
- **SchedulePage ExportDialog**：工具栏「导出图面」按钮 → 弹窗（5 字段 + 导出 PNG / 导出 PDF / 打印三出口；成功/失败回执行）。
- **ganttCols**：`GANTT_REPORT_KEYS` 上报 6 列预设 + `colsByKeys`（本版导出图面固定按上报口径；列显隐预设进工作台为后续观察项）。
