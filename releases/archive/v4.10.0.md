## 交付明细

### GLM 引擎（2371b0c → d93ff5f，模型中心）

- **接入**：智谱 OpenAI 兼容端点 `https://open.bigmodel.cn/api/paas/v4`；
  `EngineGLM` 类型 + 预置引擎卡（Label「GLM 云端」，默认模型 glm-5.3 旗舰）
  + key 全链路（config `glm_api_key` DPAPI 加密落盘 + 旧明文迁移 → 启动
  注入 → SetGlmKey/GetGlmKeyStatus 绑定 → 前端 Key 卡片）。
- **官方文档纠偏（a1ba6dd，核心教训）**：智谱官方**没有 /models 模型列表
  端点**——此前测试连接/刷新模型永远失败。重写：模型目录改为静态清单
  （锚定官方「模型概览」：glm-5.3/5.2/5.1/5/5-turbo、glm-4.7 系含免费
  flash、glm-4.6/4.5-air/4-long、多模态 5.3-flash/4.6v、glm-tts/glm-asr/
  embedding-3/rerank 共 18 条）；Key 校验改走最小 chat ping（max_tokens=1
  真实验证），错误体按官方 `{"error":{code,message}}` 原样透出。
- **地址防呆（d870f9d）**：真机实测用户把 Key 粘进地址框——云端引擎隐藏
  地址编辑框（改为仅本地引擎可编辑）；SaveEngine 拒绝无 http(s) 前缀地址
  （错误不回显原值防 Key 二次泄漏）；LoadState 忽略存量脏地址（重启自愈）；
  fetchModels 友好错误。
- **保存白名单（d93ff5f）**：saveSetters 登记 glm_api_key；反射覆盖测试
  锁死「所有 `*_api_key` 字段必须有 Save setter」，此类错误永久绝育。
- **路由与治理**：云端属性 IsLocal=false——全局离线模式自动跳过、用量统计
  cloudEngineSet 自动归类、GaeaSetProviderKey 支持 glm/zhipu/bigmodel。
