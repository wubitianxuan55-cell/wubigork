# v4.231.0 — AI 输出渲染对齐同类产品第二刀：聊天线（伴侣/流式）代码块高亮（2026-09-12）

> 接 v4.230.0 同方向续刀：办公板块代码块已着色，聊天线（ChatPage 伴侣页
> plain/companion 两模式）还是纯文本——本刀对齐，并顺带扩高亮语言白名单。

## 缺口

- ChatPage 两个模式的代码块都无着色：plain 终态 `ChatMarkdown` 纯文本；
  companion/流式 `MarkdownContent` 经 genuiAdapter 覆盖件后非 genui 代码
  只落裸 `<code>`（连复制按钮都没有，仅 `.md-content pre` 半透明底）。
- `.hljs-*` 规则与 `--hl-*` 调色板都在 `gaea/styles.css` 里，而该文件**不在
  ChatPage 加载范围**（只被 Gaea/CostLibrary/MemoryHub/Schedule 四个 lazy
  chunk 引用）——聊天 chunk 拿不到高亮样式。

## 落地

- **色值单一真源迁出**：`gaea/styles.css` 的 hljs 三块（暗色调色板/浅色
  覆写/`.hljs-*` 令牌规则）整体迁到新 `src/gaea/hljs-theme.css`，重构为
  「双常量组」结构：`--hl-dark-*` + `--hl-light-*` 常量 → `:root` 兜底暗色、
  `:root[data-hl="light"]` 跟主应用明暗。styles.css 留指针注释。迁出前已核
  tailwind 桥接（`--color-hl-*`）零页面级消费方、全仓无第二处 `.hljs` 定义。
- **HlCode 组件共享化**：自 `gaea/components/Markdown.tsx` 抽出为
  `gaea/components/HlCode.tsx`（hljs-theme.css 随它 import 随用随载），
  Markdown.tsx 改引；vite 自然把它 hoist 成办公/聊天两 chunk 的共享异步块。
- **新 `components/ChatCodeBlock.tsx`**（聊天线两模式共用）：语言标签+复制
  头部 + 暗色面板 + HlCode。面板维持「行业标准暗色专用色、不随主题」的
  在册决定（hex 同行豁免标记照旧），故根节点挂新 `.hl-scope-dark` 类——
  元素级把 8 个令牌钉死暗色组，**令牌随面板不随应用主题**（浅色主题下
  面板依旧暗色，暗色调色板对比度不受 data-hl 翻转影响）。
- **接线两处**：`ChatMarkdown.tsx` 块级分支换 ChatCodeBlock（本地
  CodeBlockHeader 移入）；`chat/genuiAdapter.tsx` 非 genui 块级代码同走
  ChatCodeBlock（外层 `data-genui-host` 让 GenuiPre 透传，不落
  `.md-content pre` 默认底）——companion/流式与 plain 终态同款面板。
- **白名单 22→27**：+ruby/php/kotlin/perl/lua（AI 输出常见通用域，各数 KB
  独立微 chunk）。

## 测试

- vitest +4：`ChatMarkdown.genui.test.tsx` +2（plain 终态暗面板
  `.hl-scope-dark` + 异步 `.hljs-keyword`；companion 经覆盖件走同一面板）、
  `codeHighlight.test.ts` +1（新白名单直通）、既有 genui 两例零变更。
- **坑**：向测试文件追加代码时经 python heredoc 写入，`\x60` 在非 raw
  字符串里提前变成真反引号，产出的 JS 直接语法错——**给源文件追加内容
  一律走 Edit 工具，别用 shell 内联脚本拼代码**。
- eslint `no-raw-hex` 豁免标记必须与 hex 同行（行尾 `// hex-exempt`），
  提行注释不豁免——ChatCodeBlock 照旧格式补回。
