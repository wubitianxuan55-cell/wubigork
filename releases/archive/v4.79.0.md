## 变更

### Go（internal/gaea/contextview）
- `types.go`：`RequestDelta{Items, Tokens, ByCat []CatDelta, Approx, First}` +
  `CatDelta{Cat, Items, Tokens}`；`RequestRecord.Delta *RequestDelta
  json:"delta,omitempty"`（无 delta 的旧数据 JSON 形态不变）。
- `fold.go`：`snapshotSurface()` 在请求组装点（request_header，与 Category
  同拍——delta 与分类构成永远自洽）聚合活节点 surface：system/tools 取最新
  header 整体估算（节点只在变化时入列且旧头不回收，逐条聚合会重计历史头），
  user/inject/assistant/tool 活节点逐条聚合；`attachRequestDelta()` 与上一
  快照差分——ByCat 只含有变化的分类、按 |tokens| 降序（并列按名称稳定排序，
  与 Tools 排行同纪律）；`applyCompaction` 记 compactMark，两次快照间发生过
  压缩 → Approx=true。旧日志无 header 的退化路径在 usage 关闭时同拍快照。

## 边界（有意不做，dsh 逐步回放不照搬）

dsh-context 的浏览器逐步回放 = 客户端重放全事件流并展示每步 surface 节点
列表。gaea 是 Go 权威折叠 + wire 快照：逐请求节点列表会让 wire 载荷爆炸
（数百节点 × 200 请求保留窗）。本刀交付**聚合级**逐类 delta（项数/token），
节点列表仍只展示当前 surface——蓝图 design-system/gaea/pages/context.md
「对比上一步（v4.79 起）」已成文该折中。
