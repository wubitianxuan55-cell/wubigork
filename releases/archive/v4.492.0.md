### ParseQuantLevel（modelengine/quant.go 纯函数）

llama.cpp GGUF 命名法全覆盖：

| 系列 | 例 | 档位 |
|---|---|---|
| 标准 Q | Q2_K / Q3_K_M / Q4_K_P / Q5_0 / Q6_K / Q8_0 | Q 后数字 |
| I 系列 | IQ1_S / IQ2_XS / IQ3_M / IQ4_XS | IQ 后数字 |
| 全精度 | F16 / BF16 / FP16 / F32 | 16/32 |

- 分词保留下划线（量化标记本身含 `_`：Q4_K_P 切断会丢档位后缀——测试抓）；
- 混合标注取**最低档**（保守：按最差档警告）；
- 模型名无标记 `known=false` **不警告**——宁漏勿误，不凭空猜测未标注模型。
