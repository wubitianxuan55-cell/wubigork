## 落地

### 数据契约（story_spine.json，项目根与 outline.json 平级）
- **Theme**：控制理念（正命题）+ 反论最强陈述——M12 报告制，永不做闸门。
- **Arcs**：人物弧线 `want/need/misbelief` + 水位点（chapter + stage
  setup/provoke/escalate/proof + note）——M3 可编辑形态。
- **Beats**：结构节拍位（hook/first_plot_point/midpoint/second_plot_point/climax +
  自定义），绑章号 + planned/hit。
- **Threads**：支线开关表（MICE 类型 + 开启章/最后推进章/四态/闭合章）——M6 简化。
- **OpenQuestions**：未解问题池（问题/提出章/open|answered/回答章）——M8 简化。
- 校验：确定性整单拒绝（章号非负/枚举/重复 ID/缺名点名），文件缺失=空骨架。

### 结构体检（NovelStoryHealth，七维度确定性零 LLM）
支线遗忘（>10 章未推进，active 比 parked 更急）/ 未解问题超期（>15 章）/
节拍滞后（planned+3 容差）/ 中段塌陷（分析 V2 强度中段均值 < 全书 75%，缺数据
如实跳过）/ 弧线水位覆盖（最后水位 < 进度 1/3）/ 终局未闭合（进入 climax 前最后
15% 仍有 active 线程或 open 问题）/ 主题缺失。零 spine=空报告不算错。

### 生成注入（故事层切片）
`CreateChapter` 与 `NovelChapterScenesGenerate` 注入同源切片：本章绑定的节拍位 /
活跃线程 / 未解问题（「不要无意中回答，也不要遗忘」）/ 主角弧线最近水位点。
**空 spine 零注入**（零回归，测试钉死）；切片不挤占伏笔/文风/世界观预算，独立追加。

### AI 提炼骨架（NovelStorySpinePropose，提案不落盘）
从故事主线（刀1 资产）+ 大纲 + 最近章摘要提炼主题/弧线/节拍/支线/悬念初稿；
**提案只填表单，落盘必须走「保存」**（确认红线同族）；主线为空诚实拒绝。

### 前端
CreatePage rail 新「故事骨架」面板：主题两行 + 弧线/节拍/支线/问题四张可编辑表
（行内增删改）+「AI 提炼骨架」（填表单不落盘）+「结构体检」（七维度报告按严重度
渲染）+「保存骨架」。
