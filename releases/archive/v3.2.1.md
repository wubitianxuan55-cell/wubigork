## C5 工作区内联编辑（GaeaWriteFile）

办公用户常要快速改一个 txt/笔记/markdown（对话摘要存 memo、微调脚本、改配置），
之前只能「外部打开」或用记忆文档编辑器。现在预览即编辑：

- **后端 `GaeaWriteFile(rel, content) error`**（绑定面 497，+1），安全四重校验：
  1. 相对路径（拒绝绝对路径与 `..` 穿越）；
  2. 必须落在**可写根**（WriteRoots = 工作区 + allow_write 配置）内；
  3. **文本扩展名白名单**（md/txt/csv/json/toml/yaml/xml/html/css/脚本/源码等 30 种，
     避免经 UI 写回二进制）；
  4. 内容 ≤ 2MB + 仅允许编辑已存在文件。
  **原子写**：同目录临时文件 → fsync → rename，失败保留原文件。
  用户显式保存 = 用户意图（非 agent 自动写，不走审批；agent 写仍受工具权限面约束）。

- **FilePreview 编辑模式**（仅 markdown/text 且未截断时显示「编辑」——截断内容不完整，
  写回会丢数据）：
  - 标题栏「编辑」切换 → 等宽 textarea + **脏标记**（琥珀色脉冲点，修改即亮）；
  - 保存状态机：保存中（转圈禁用）/ 失败（按钮变「重试」+ toast 错误）/ 成功自动
    **重读预览**；
  - **Ctrl/Cmd+S** 快捷键保存；
  - 脏状态下退出编辑弹**内联「放弃修改/继续编辑」确认条**（放弃后退出编辑）。
