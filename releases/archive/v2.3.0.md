# gaea v2.3.0「界面焕新 · 办公整合」发布说明（2026-08-07）

> 在 v2.2.0 基础上迭代一轮 UI/UX：角色库、首页、办公板块全面重设计；办公双模块合并为独立二级导航；随机生成能力补全（含人格）。本次为纯前端 + 后端小接口扩展，无数据迁移。

## 一、角色库界面重设计
- 列表页升级为「档案墙」：立绘主导（4:5）、底部身份覆盖、档案眉（编号/类型/可聊天）、加载骨架屏、组合空状态、分页
- 颜色统一：去掉每张卡多色硬编码，全部跟随主题强调色 `--gaea-glow`（兼容 6 套主题预设与深浅色）
- 详情（相卡面板）重设计：随机生成工具条（随机补齐/全部随机）+ 每个字段旁 ↻ 骰子单独随机 + 五维本地随机
- 角色命名：28 个内置角色配中文人名（gaea 保留原名），见 CHANGELOG

## 二、随机生成完善
- 新增 `CharacterGenerateRandom(chJSON, fields)`：`all` 全量重随机（含性格，姓名不变）或按逗号分隔字段随机
- 修复“人格无法随机”根因：旧接口只补空缺字段；新接口支持强制重生成
- 标签/对话样本数组归一化；性别/定位/状态/年龄本地即时随机（不消耗 AI）

## 三、首页 AI 中枢启动器重设计
- 单一主题强调色、玻璃档案化卡片、hover 光晕 + 箭头、焦点环、入场错峰动画
- 兼容「减弱动态」与 WebView2 rAF 降级模式

## 四、办公板块整合
- 合并「办公 + 方案编写」为独立二级导航：智能办公（gaea 工作台）/ 方案编写（投标套件）
- 二级模块注册表 `OFFICE_MODULES`，后续新增办公模块只需追加一项
- 移除顶层重复的「方案编写」入口与首页重复卡片；Ctrl+1~4 快捷键重排

## 五、智能办公 / 方案编写整层重设计
- 智能办公：对话区铺满面板（修复全屏“缩成一团”），正文行宽约束，玻璃面层统一（侧栏/顶栏/消息/输入框/滚动条）
- 方案编写：胶囊式标签导航；左侧「项目与方案」为唯一列表入口（移除重复「方案列表」标签页）；隐藏与标签页重复的步骤条，消除层层标题
- 移除窗口顶部流光扫描条（scanline-top / scanSweep）
