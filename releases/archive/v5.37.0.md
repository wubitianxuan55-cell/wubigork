## P2: 向量存储/语义搜索

### `vector_search.go` — 新建
对齐 ackem `vectorStore.ts` + `semanticSearch.ts` + `factEmbeddingCache.ts`：

- **`CosineSimilarity(a, b []float64) float64`** — 纯函数，对齐 ackem 唯一出处
- **`TfidfIndex`** — TF-IDF 稀疏向量索引
  - `Build()`: 中文分词（≥2字符词 + CJK bigram）→ TF-IDF 向量化
  - `Search()`: 余弦相似度搜索，支持 topK + minScore 过滤
  - IDF 平滑公式：`log((1+N)/(1+df)) + 1`
- **`SearchBySemantics()`** — Jaccard 字符集语义搜索
  - 双通道：`charJaccard`（字符集）+ `keywordJaccard`（关键词 ×1.2 加权）
  - 取 max，过滤阈值 0.12，topK=5
- **`tokenizeForTFIDF()`** — CJK 标点分割 + bigram 双通道
