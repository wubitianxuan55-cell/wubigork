## 一、ResizableDrawer 手写弹层可访问性收口（v4.349 审计确认的三缺）

对照 ApprovalModal 先例补齐三件：

1. **dialog 语义**：`aside` 加 `role="dialog"` + `aria-modal="true"` + `aria-label`（新
   可选 prop；两调用方传现成 i18n 标题——CapabilitiesPanel「MCP 与技能」/HistoryPanel「历史」，
   缺省退 resize 键）。阻断式弹层此前对读屏是匿名区域。
2. **Esc 关闭**：document keydown Esc → 退出动画关闭；输入可编辑目标内不劫持（与
   ApprovalModal 同纪律）。此前唯一关闭路径是鼠标点击遮罩。
3. **焦点管理**：打开时记录 `document.activeElement` 并聚焦抽屉容器（`tabIndex={-1}`，
   Tab 流从内容第一个可聚焦元素继续）；卸载时还原焦点到打开者（元素已消失 try 兜底）。
   此前开不聚焦关不还焦，键盘用户关闭后落回 `<body>` 迷路。

测试：`ResizableDrawer.test.tsx` 新建 4 例（Esc 关闭经退出动画/普通按键不关/dialog
三件套/开聚焦+卸载还原）。

## 坑（本轮新增）

1. **effect 引用 useCallback 声明的顺序**：Esc effect 插在 `handleClose` 声明之前——
   effect 回调虽延迟执行，依赖数组 `[handleClose]` 是渲染期即时求值，TDZ 直接 ReferenceError。
   effect 一律放在其依赖声明之后。
2. **React KeyboardEvent（合成事件）没有 `isContentEditable`**（那是 DOM Event 的
   HTMLElement 属性）——div onKeyDown 里判可编辑目标要 `(e.target as HTMLElement).isContentEditable`，
   或干脆不判（遮罩场景 Esc 无副作用）。
3. **审计清单要逐点核对再动手**：v4.349 池的「~8 处」里 RailItem/FactCard 已在此前
   轮次变成 button——照单全收会重复改。清单是快照不是现状。
