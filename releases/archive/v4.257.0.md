# v4.257.0 — 原罪三刀：硬隔离 · 模型卡片 · 角色库接入（2026-09-12）

## 为什么是这一刀

v4.256.0 交付原罪板块后，用户追加三条口径：

1. 「原罪需要与办公板块硬隔离」
2. 「原罪在模型中心有单独的功能绑定卡片」
3. 「原罪能够使用角色库内容」

## ① 硬隔离（数据/记忆/模型路由/工作区四面）

- **插图产物改落原罪自有目录**：`<用户配置目录>/gaea/sin/art`——不写办公工作区
  `.gaea/`、不依赖办公 ImageSaveDir 与小说项目目录。为此把绘梦生成链的「产物归属」
  参数化（`generateFreeImageProvenanced`：sourceBoard + saveDir），绘梦侧行为逐字节不变。
- **台账单条登记**：改前原罪插图会先由生成链内部登记（source=imagegen）再被调用方
  补登记一次（source=sin）→ 画室同一张图两条记录；现在登记只在生成链内发生一次，
  来源正确记为 `sin`（space=play）。
- **工位检索硬边界**：`wssearch` 改前只跳 `.gaea/play/exports`，play 分区其余子目录
  （画室台账、章节配图、原罪产物）会漏进办公关键词检索面；现在**整个 `.gaea/play`
  判定为噪音**（工位搜索搜不到乐园内容，S2.1 验收红线）。`fileindex` 本就整目录跳过 `.gaea`。
- **无记忆面**：原罪不读也不写办公记忆（Hephaestus facts）与轻语记忆；故事上下文
  只有本次故事的历史消息 + 已选角色。
- **模型路由独立**：`routeModel("sin")`（功能绑定 → 全局 → 兜底），办公换模型不影响原罪。
- **角色选择自存**：`<用户配置目录>/gaea/sin/cast.json`。

## ② 模型中心独立卡片

`FEATURES` 增 `{ key: 'sin', label: '原罪' }` + 卡片图标/说明；后端 config 三键
（`func_sin_engine/model/enabled`）与功能绑定映射同步。走查确认：模型中心 → 功能绑定
列出「原罪」卡（未绑定 → 跟随全局默认）。
