## 🔧 XAI 登录修复（模型中心）

### 问题
模型中心 XAI 登录：浏览器显示"登录成功"但实际未生效，日志反复报 `HTTP 401: 未登录 xAI`。

### 根因
1. **Wails RPC 超时中断 Login** — `Login()` 同步阻塞等待 OAuth 回调（最长 5 分钟），Wails RPC 默认超时更短，超时后 token 保存/engineMgr 更新等操作被中断
2. **EnsureToken bug** — `client.go:170` token 文件不存在时，`store.Load()` 返回 `(nil, nil)`，变量 `err` 被覆盖为 nil，`return err` 错误返回 nil → `GetLoginStatus()` 误报 true

### 修复（4 文件）

| 文件 | 变更 |
|------|------|
| `internal/app/auth_handler.go` | `Login()` 异步非阻塞：goroutine 执行 OAuth + 日志 + `xai-login-success/failed` 事件 |
| `internal/ai/client.go` | `EnsureToken` 用独立变量防覆盖，nil-token 返回明确错误 |
| `frontend/src/stores/appStore.ts` | `login()` 轮询模式 75×4s=5min，超时抛中文错误 |
| `frontend/src/pages/ModelCenterPage.tsx` | 按钮 loading + `message.error` 提示 + 登录后自动 `loadAll()` |
