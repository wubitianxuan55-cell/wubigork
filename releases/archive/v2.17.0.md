# gaea v2.17.0「安全与架构收敛」发布说明（2026-08-14）

> 长期规划阶段 2（docs/superpowers/plans/2026-08-14-gaea长期规划-herdsman底座加固与工程门禁.md）：
> S2-1 ~ S2-4 安全收敛 + 绑定面架构拆分。原则不变：先止血、再门禁、后纵深。

## 一、S2-1 · Herdsman LAN 风险处置（前端联动）

- 全局安全横幅 `SecurityBanner`：应用启动即调用 `App.HerdsmanSecurityCheck()`（H0-4）检测
  herdsman config.yaml 的 `api.lan_accessible`；为 true 时在顶栏下方展示醒目警告（端口 +
  中文处置指引 + 配置路径），支持「重新检测」「本次忽略」（忽略状态按会话 localStorage）。
- 设置页新增「安全」分类（SecurityPanel）：敏感域本地化开关、Herdsman 局域网暴露实时检测
  （成功/暴露/未检测三种状态 + 指引）、WebView2 远程调试说明。
- 行为约束不变：gaea 仅提示，绝不代改 herdsman 配置。

## 二、S2-2 · gaea 自身安全开关

- **WebView2 远程调试默认关闭**：此前 `WebviewDisableRendererCodeIntegrity: true` 会连带开启
  `127.0.0.1:9333` 远程调试端口（Wails v2.13 源码行为）。现在需要调试时以
  `GAEA_WEBVIEW_DEBUG=1` 启动才开启（并打印醒目日志），默认不再暴露调试端口。
- **HTTP 调试桥接一次性 token**：`GAEA_HTTP_PORT` 启用桥接时自动生成 32 位十六进制 token
  （或 `GAEA_HTTP_TOKEN` 显式指定），启动日志打印；`/api/rpc` 与 `/api/stream` 必须携带
  （`Authorization: Bearer` / `X-Gaea-Token` / `?token=`，SSE 用查询参数），`/api/health`
  保持开放；CORS 放行 Authorization 头。前端桥接层（api/bridge.ts + runtimePolyfill.ts +
  httpToken.ts）自动透传 token（URL ?token= → window.__GAEA_HTTP_TOKEN → localStorage）。
- 动机：本机浏览器页面（DNS rebinding/CSRF）无法再无授权驱动 gaea 内核。

## 三、S2-3 · App 绑定面拆分（架构收敛）

- 429 个导出方法（App + core/writingState/mediaState/whisperState/officeState 全部提升方法）
  按板块拆为 **10 个绑定门面**：`CoreB` / `OfficeB` / `MemoryB` / `CostB` / `ModelB` /
  `VoiceB` / `ChatB` / `NovelB` / `ImageB` / `CharlibB`，方法体零改动（纯委托 `b.a.X(...)`）。
- 生成器 `scripts/gen_bindings`（go/ast 解析 → 分组映射 → 生成门面 + manifest + 测试）；
  `App.NewBindings(a)` 供 main.go 绑定。
- **测试兜底**：`TestBindingsCompleteness` 反射断言 App 完整方法集与门面并集全等
  （不多、不少、无遗漏），跑在 internal/app 全量单测里。
- 前端单点适配：`gaea/lib/bridge.ts` 的 `realApp()` 改为按方法名路由到对应门面；
  `api/bridge.ts` 为旧调用点补 `window.go.app.App` 兼容代理；旧
  `wailsjs/go/app/App` 导入统一改指 `src/wailsjsCompat`（重导出新门面模块，27 处）。
- wailsjs 已重新生成（`wails build` 自动清理旧 App.js）。

## 四、S2-4 · 敏感数据本地通道

- 新增「敏感域本地化」开关（默认**开启**，`~/.gaea_config.json` 的 `sensitive_local` 持久化，
  `App.GetSensitiveLocal` / `App.SetSensitiveLocal`）。
- 成本/报价类 AI 操作（`GaeaCostImportAIParse` 等）经新路由 `routeSensitiveLocal`：开关开启时
  强制路由本地 Herdsman（商务数据不出本机，source 标记 `sensitive-local`）；herdsman
  停用/不可用时自动回退常规路由（功能绑定 → 全局 → 兜底），功能可用性不受影响。
- 设置页「安全」面板可一键切回云端。
