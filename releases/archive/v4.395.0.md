# v4.395.0 — 绘梦·编辑历史变体簇：ParentID 链 + 溯源，回到任一变体继续改

> 2026-09-23 发布。来源：用户指令「很好，继续」（画室线既定刀序：T3 编辑力第四件，
> 不依赖新权重）。本刀 = 长期规划 T3「编辑历史形成变体簇」；T0 契约 AssetMeta 的
> `ParentID` 预留位激活。规格：`进度计划/gaea-variant-chain-20260923.md`。
> 绑定面 **714 零变更**。

## 病根

编辑三件（指令编辑/蒙版/扩图）落地后编辑行为天然成链 A→A'→A''，但链不可见——
台账（v4.98）有登记无关系字段，前端结果与历史无变体标识，用户改三轮后无法回到
第 2 版继续分叉。「回到任一变体继续改」的编辑面天然支持（任何画布图可发起编辑），
缺的是**关系数据与呈现**。

## 落地

1. **关系键 = 台账 `parent_id`**（激活 T0 预留位）：编辑/扩图请求带 `sourcePath`
   （源图 file_path，前端 GenResult 已有），app 层按 path 在台账同空间查最近条目
   id 作 ParentID（`imageHubAssetIDByPath` 倒序扫描，台账 2000 条/空间线性可接受）；
   查不到留空=诚实断链（源图非 gaea 产物/跨空间，不造假）。旧 JSONL 无字段反序列
   化零值空，向后兼容。
2. **登记链路**：`recordImageHubGeneratedAsset`/`recordImageHubGeneratedFor` +parentID
   参数（chapter/portrait/bookcover 三处生产调用点传 ""；sin 同）；meta/view 双侧
   加 `parent_id` 字段（视图透出供建链）。
3. **imageItem 回传** `asset_id`/`parent_id`：登记后按 path 反查自身 id 回填
   （运行态闸关闭时查得空=字段空，不影响主流程——测试态天然零值）。
4. **前端**：GenResult/MediaParams 透传（`sourcePath` 提交、`asset_id/parent_id`
   接收）；InstructionEditModal 编辑产物带 parent_id 时 meta 行出「变体」徽标+
   「溯源」按钮。
5. **新 `VariantChainModal`**：拉 `imageHubAssets`（既有只读绑定，零新绑定）建
   id→entry 映射，沿 parent_id 上溯（防环上限 64 代）得根→…→当前正序链；每项
   缩略图（`readFileAsDataURL` 懒加载、失败留空位）+第 N 代/源图/当前标记+模型/
   时间/指令摘要；「用到画布」把任一祖先并入画布=**回到该变体继续改**；链断
   （祖先缺档/导入图）如实 Alert 标注。
