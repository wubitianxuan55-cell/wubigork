## A 线：壳层左缘修复（MainLayout.tsx 单点）

- **根因**：`.v3-rail-dock` 是 `position:fixed; left:0; z-index:200` 的全高
  浮层热区，完全脱离布局流；壳层右列容器从 x=0 起铺，rail 滑出（实际占
  x∈[8,54]）直接盖住各板块最左列首字符（padded 页 16px 左 padding 恰好把
  文字送进覆盖带）。
- **修复**：右列容器（顶栏/横幅/内容/遥测的共同父级）预留
  `padding-left: var(--v3-rail-w)`（48px，让声明后零消费的宽度令牌真正落
  地）+ 280ms 同曲线过渡；悬停展开 176px 的「浮层覆盖」交互原样保留（不动
  z-index/transform，不改建模式）。
- 回归面：全板块（首页 bento 栅格自适应重排、聊天 full 布局、微信三分区、
  造价、遥测轨道）随容器右移，内部比例不变；judge 确认 01/02/03/04 内容
  起点均 ≥56px、首字符完整。

## B 线：创建青鸟助手深链直通绑定

- **链路**：角色卡「创建青鸟助手」→ `WhisperAssistantSave`（wxToken 空=
  未绑定）→ `setWxFocusAssistant(id)` 落 sessionStorage → `emitFrontend
  Event(NAVIGATE, {page:'weixin', crossSpace:true})` → WeixinPage 两条路接
  焦点（lazy 首载=挂载读取兜事件先于订阅；keepAlive 已挂载=页内 NAVIGATE
  监听）→ 选中新通道 → 无 token 则复用既有 `startBinding` 直开扫码弹窗。
- **新模块 `pages/wxFocus.ts`**：sessionStorage 焦点传递（读后即清；why：
  导航后 WeixinPage lazy 挂载，事件先于订阅，内存单例会丢）。
- **收口修复（真集成缺口）**：角色库在乐园（play）、青鸟在工位（work），
  原 NAVIGATE 走壳层 S2.1 同空间守卫会被**静默丢弃**（单测盖不住壳层段，
  走查实锤）。MainLayout 新增显式 `crossSpace` 分支：带标记=用户显式跨空间
  意图，走 `navigateBoard` 换空间路径（saveShellPage+setSpace）；不带标记
  维持同空间语义不变（effect 置于 navigateBoard 定义后，避 deps TDZ）。
- **降级**：已绑定只选中不开扫码；id 不在列表先补拉一次再放弃；sessionStorage
  不可用静默只损失自动聚焦；读后即清不影响正常新增流。
