## 指令中枢架构

```
入口层                    解析内核              能力层                 回传
─────────               ─────────            ──────────            ────────
语音(VoiceChatText/ASR) ─┐                  ├ navigate → emit 事件 → 壳层跳转(切空间)
微信文本(现有通道)      ─┼→ intent.Parse ──→ ├ generate_image → mediaState → TTS 播报
命令面板(S4.6 留位)     ─┘   (规则引擎)      ├ status → 引擎摘要
                                            └ reminder → 离线代办复用
未命中 → 原对话管道（轻语聊天，零行为变化）
```

- **一个路由入口** `App.routeIntent(text) (reply, handled)`——任何入口命中即得到
  回复文本与副作用（事件/任务启动）；未命中 `handled=false` 透传原管道。
- **零新增 Wails 绑定**：执行结果走事件（`gaea-intent-navigate`）与入口自身回传
  通道（语音 = TTS 播报），绑定面 530 不变，漂移防线不动。

## S4.1 · `internal/intent` 解析包（纯函数，可独立复用）

- 四类意图：**navigate**（打开/进入/切换到/看看 + 板块别名；「回/去 + 首页」强搭配）、
  **generate_image**（画/生成 + 描述）、**status**（什么模型/引擎状态）、
  **reminder**（含「提醒/叫我」，时间解析在执行层）。
- 板块别名表：中文产品词汇表（绘梦/画室/生图→imagegen；造价数据库→cost 等），
  长别名优先贪婪匹配，值 = board manifest id；执行层再校验 id 在当前动态清单
  中存在（被过滤的板块按未命中处理）。
- **宁漏勿误纪律**：闲聊「画得不错」「画了半天」「这张画过好几次了」绝不触发生图
  （字符类排除口语续接）；「打开文件管理器」不命中导航（别名必须命中）；纯闲聊
  「今天天气怎么样」不接管。21 命中 + 8 误判防线表驱动测试。
- LLM 兜底分类器留接口位：后续作为宽匹配 Capability 挂 Router 尾部，规则优先
  保证高频指令零延迟。

## S4.2 · 能力执行层（`intent_router.go`）

- **navigate**：manifest 校验 → `emit("gaea-intent-navigate", {board, label})` →
  「好，已打开绘梦。」
- **generate_image**：`mediaState.GenerateFreeImage(描述, 默认参数)` 异步启动 →
  「好，开始生成：…。完成后到绘梦板块查看。」；失败如实播报错误。
- **status**：GetModelMonitor 同源摘要——「当前状态：Herdsman（本地）；…；
  ComfyUI 图像后端运行中。」
- **reminder**：复用离线代办（v4.4.0）中文时间解析与 JSON 持久化，`source=voice`；
  语音当面指令不受 remindersEnabled 开关静默拦截（开关约束微信文本路由）；
  到点仍走微信回推。

## S4.3 · 语音通路（JARVIS 一档）

- `mediaState.setWhisperChatFn` 注入闭包内**先过 routeIntent**：命中 → 能力执行 →
  回复文本走 voice 管道既有流程（thinking 态 → 流式 TTS 播报 → 恢复监听，含
  barge-in 打断）；未命中 → 原 `WhisperChatWithSearch` 轻语对话。
- **voice 包零改动**——分流点选在 app 层注入的回调处，语音指令天然继承全部
  管道能力（打断/流式/事件）。

## S4.4 · 前端导航

- `events.ts` 新增 `INTENT_NAVIGATE`（后端事件 22→23）；MainLayout 订阅 →
