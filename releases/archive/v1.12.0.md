## 修复的 bug（真实运行时缺陷）

- 轻语记忆系统与 hermes.db 完全断开：事实/情节只写内存重启即丢，记忆中枢轻语库/归档永远空（LoadFactsFromDB 一直返回空）→ 三表持久化打通
- KnowledgeGraph/EpisodicStore 无锁数据竞争：异步 goroutine 写 + 主流程读 → Go map 并发写读 fatal / slice append 丢数据 → 加 sync.RWMutex
- KnowledgeGraph.Query 误命中：遍历全局 entityIdx 给所有三元组加分（图谱越大误命中越多）→ 匹配三元组自身 subject/object
- restoreWhisperState 早期返回：companion_state/chat_history 无行时提前 return，事实/情节永不加载

## 记忆链路全景（v1.12.0 后）

```
对话 → AfterTurn（LLM 事实抽取/三元组/情节生成）→ hermes.db 三表持久化
     → restore（重启恢复）→ buildTierBBlock（事实/图谱/情节/关联扩散/触发词/回忆注入提示）
     → 记忆回声 → 情绪状态调制
     → 记忆中枢展示（事实列表 + 情节时间线 + 三元组图谱）
```
