## 线1 SQL/存储层（1 P0 + 3 P1）

1. **分类改名 substr 字节/字符错位（P0，中文路径必现数据损坏）**（`internal/gaea/cost/cost.go` SaveCategory）：重写子树条目路径用 Go `len()`（字节数）喂 SQLite `substr`（按 UTF-8 字符计数）——中文分类路径下子树后缀整段截断，条目被静默重挂到改名节点本身（如「人工/普工/混凝土浇筑」改名「人工」→「人工费」后只剩「人工费/普工」前缀行侥幸正确，深层行直接丢路径）。修法=偏移改 `utf8.RuneCountInString(oldPath)+1` + 精确行（直接子条目）单独替换并同步 `category` 叶子名（原实现漏同步）+ 节点与条目两写包同一事务（原 `_, _ =` 丢错且 autocommit 半写）。**同函数连带修**：①换父不移名完全不重写子树路径（门控只在 `name != oldName`，拖拽换父后条目从树上消失）→ 门控改 `|| parentID != oldParent` ②环检测缺失（挂到自己的子孙下 → `Categories()` 的 resolve 递归无环保护栈溢出）→ SaveCategory 拒绝挂祖先链节点 + resolve 加 onPath 环截断 ③分类名含 `/` 拒绝（名称是路径分隔符语义字符，「A/B」名会让 LIKE 前缀重写命中 newPath 自身）。
2. **rows.Err() 缺失批量补齐（P1/P2 共 17 处）**：迭代/扫描错误被静默吞掉返回「看似完整」的部分数据——记忆事实/三元组/情节恢复主路径（queryFacts/LoadTriplesFromDB/queryEpisodes）、成本库主检索语料（Search/componentsOf）、**测算明细 ListItems（直通 SaveVersion 的「不可变版本」JSON 快照，静默丢行=版本快照永久缺明细）**、日记/习惯/轮次/价格源/阶段值/知识历史/分类树计数等辅助读路径。有 error 返回→上抛，无→slog.Warn 留痕。对照组 characterlib 全带 rows.Err，证明是遗漏而非风格。
3. **每写一条事实全量重建 FTS（P1，O(N²)）**（`memory_facts.go` Insert/Update/Delete ×3 + `episodes.go` Insert）：单条写以 `RebuildFactsFTS` 收尾（DELETE 全表→全量读→逐条单条 INSERT Exec），批量写 O(N²) 且 DELETE 与重插各自 autocommit、中途失败=索引空窗（搜索静默退化为 LIKE）。修法=**接上已存在却无人用的增量助手** InsertFactFTS/DeleteFactFTS/InsertEpisodeFTS（增量失败降级全量重建，最终一致兜底）；全量重建（RebuildFactsFTS/RebuildEpisodesFTS）改为读入内存后事务内清空+批量重插；DeleteAllEpisodes 直接整表删 FTS（全空场景免零行重建）。
4. **配刀**：`schema_v15.go` 补 `idx_facts_session`/`idx_episodes_session`（V12 给 turn_traces 补过同款，facts/episodes 漏；每会话恢复触发的等值过滤此前全表扫）+ `UpsertFactEmbeddings`/`DeleteStaleFactEmbeddings` 事务化（逐条 autocommit=部分向量集）+ 5 处 COUNT 裸 Scan 收错 + `pricefeed.GetSource` 全表捞改 `WHERE id=?` 点查 + 知识版本历史 4 处弃错改 warn（历史写成功正文失败时重试会产生重复历史行）。

## 线3 读侧收口（5 P1 + 2 P2）

**核心结论：写侧与删侧防线完备（withinWriteRoots/sanitizeChatFilename/safeZipRel 等护栏齐全），读侧是系统性短板**——「任意路径→base64/正文返回前端」的读口共享同一缺口。

9. **GaeaReadFile（P1）**：无任何路径约束（写端 GaeaWriteFile 有完整防线，读端是没上锁的孪生兄弟），穿越/绝对路径可读任意文件且无大小上限。修法=对齐写端口径（拒绝对路径/.. 穿越 + withinWriteRoots + 2MB 截断）。
10. **GaeaAttachmentDataURL（P1）**：任意绝对路径读盘转 base64 无限制。修法=新增 `withinReadRoots` 根白名单（工作区+应用数据根——剧照 portraits/绘梦资产/附件 uploads 均落在这两根内）+ 32MB 上限。
11. **GaeaReadFileB64（P1）**：「仅限用户对话框所选文件」契约只存在于注释。修法=**Pick 登记机制**（GaeaPickFiles 成功时登记路径，读取时校验 fail-closed；唯一调用链 pickFile.ts 零破坏）。
12. **GaeaPreview/resolvePreviewPath（P1）**：相对路径 `..` 穿越 Join 直通；image/docx 分支整文件读入 base64 无上限。修法=相对路径拒穿越（绝对路径分支保留——附件/素材预览有合法用途）+ image/docx 32MB 封顶。
13. **快照/场景 sceneID 穿越（P1，唯一写越界点）**：`snapshot.snapDir` 与 `scene.contentPath/metaPath` 把前端可控 sceneID 直接 Join——`..\evil` 在项目目录外 MkdirAll+写文件。修法=入口白名单校验 `validSceneID`（[a-z0-9-_]，合法 ID 由 sanitizeSlug 生成不误伤）。
14. **上下文看板 sessionPath（P2）**：GaeaContextView/NodeDetail/AgentNetwork 三个只读口显式路径未过 sessionDirForPath（同族 Delete/Stats 均过）——任意目录符合命名约定的 JSONL 可被解析回传。修法=resolver 内补校验，非法视为未传走既有回退分支。
15. **CreateProject（P2）**：可在任意位置 MkdirAll 写脚手架。修法=书架目录 containment（对齐 DeleteProject HasPrefix 护栏）+ 目标已存在拒绝。

## 坑

1. **Go/SQLite 长度语义差是中文环境的必炸点**——`len()` 字节数喂按字符计数的 SQL 函数，ASCII 测试全绿、中文数据必坏。凡「偏移/截断」跨语言边界一律 rune 计数或 Go 侧完成。
2. **增量助手存在却没人用**——InsertFactFTS/InsertEpisodeFTS 写好后单条写路径没接（可能当时先跑通全量版图省事），性能债埋了数月。接线时补「失败降级全量重建」兜底保最终一致。
3. **同一函数连改三刀要一次想全**——SaveCategory 的 substr/换父/事务/环/分隔符五个问题是同一次改写收口的；分开修会互相打架（门控变了重写条件也变）。
4. **读侧防线不能照抄写侧**——写侧可全白名单，读侧有合法绝对路径用途（附件/素材/预览），收口=「根白名单 + Pick 登记 + 尺寸封顶」组合，且逐绑定核对前端真实调用链防误伤。
