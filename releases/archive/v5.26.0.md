# wubigork v5.26.0 发布记录

**发布日期**: 2026-07-27
**构建**: `wails build` → `C:\AI\wubigrok\build\bin\wubigork.exe` (14.1 MB)

## 主要改动

### 🚀 ComfyUI AMD ROCm 全面打通

wubigrok 与 ComfyUI 本地生图全链路打通，支持 AMD Radeon 8060S (Strix Halo / RDNA 3.5) ROCm 原生加速。

| 项目 | 旧 | 新 |
|------|-----|-----|
| PyTorch | 2.4.1+cpu (无 GPU) | 2.9.1+rocm7.2.1 (AMD 原生) |
| 生图模型 | Flux Fill (inpainting → 马赛克) | Z-Image-Turbo (文生图) |
| 速度 | 5-10 分钟/张 | ~10s/张 (1024×1024 6步) |
| VRAM | 无 | ~100 GB (共享系统内存) |

### 🎨 LoRA 多选支持

| 模块 | 改动 |
|------|------|
| `frontend/src/components/GenControls.tsx` | 新增 LoRA 多选卡片组件（复选框风格） |
| `frontend/src/pages/ImageGenPage.tsx` | 6 个 Z-Image LoRA 选项，仅 ComfyUI 后端显示 |
| `internal/ai/image_comfyui.go` | 多 LoRA 链式调用（动态节点 ID，逗号分隔） |
| `internal/ai/types.go` | `ImageGenerationRequest` 新增 `Lora` 字段 |
| `internal/app/image_handler.go` | `GenerateFreeImage` 新增 `lora` 参数 |
| `frontend/src/api/image.ts` | `generateImage` 新增 `lora` 可选参数 |

### 🔧 后端修复

| 修复 | 文件 | 内容 |

| SetImageBackend 扩展 | `internal/app/image_handler.go` | 新增 `herdsman`/`ollama` 分支 |

### 🖼️ Z-Image 标准节点工作流

| 对比 | 旧工作流 | 新工作流 |
|------|---------|---------|
| 模型 | `flux1-fill-dev` (inpainting) | `z-image-turbo-fp8` (文生图) |
| CLIP | DualCLIPLoader + T5 | CLIPLoader lumina2 + Qwen3-4B |
| VAE | ae.safetensors | z-image-qwen.safetensors |
| 采样 | 20步 + LoRA | 6步 euler simple cfg=1.0 |
| 自定义节点 | Flux + ZImagePowerNodes 均无法工作 | **零依赖标准节点** |

### 🤖 Krea2 模型环境就绪

Krea2 本地模型基础设施已搭建：
- UNET: `redcraft23INT8INT4FP8_30Krea2.safetensors` (12.5GB)
- CLIP: `qwen3vl_4b_krea2.safetensors` (5.7GB, Qwen3-VL-4B FP8)
- ComfyUI 原生 Krea2 节点可用
