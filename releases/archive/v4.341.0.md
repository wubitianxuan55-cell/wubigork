# v4.341.0 · t7 观察池「情感曲线图形化」：全书体检面板情感弧线折线

> 2026-09-19 发布。观察池条目（v4.325 t7 收官记录）；纯前端单文件
> （BookHealthPanel），零新绑定 705、零新依赖（纯 SVG，不引图表库）。

## 论点

逐章分析 V2 的情感弧线（`emotional_arc: {primary_emotion, intensity, curve}`）
此前只有单章面板消费——作者看不到全书情绪节奏（起伏是否单调、高潮点在哪）。
本刀把情感强度曲线上到全书体检面板：体检本来就是「作者点按 → 全书视角」的
容器，数据源现成（逐章 analysis-v2.json 在盘上），只差读取与呈现。

## 落地（BookHealthPanel 单文件）

1. **情感曲线区**（逐章表与伏笔 findings 之间）：默认折叠为「生成曲线」按钮
   + 数据源说明——按需触发，不随体检自动跑（N 章 = N 次 V2 读盘 RPC，交给
   作者决定）。
2. **逐章读取**：遍历体检报告 chapters 的章号 → `NovelChapterAnalysisV2(num)`
   ；命中 `emotional_arc.intensity`（数值，钳 0-10）收集 `{num, intensity,
   primary_emotion}`；缺档/无弧线/报错跳过并计数（后端缺档只报「尚未分析」
   不触发重建，循环安全）。
3. **纯 SVG 折线**（`EmotionCurveSvg`）：x=章号线性、y=强度 0-10 反转；
   0/5/10 三条参考线（5 虚线）；相邻点直连——未分析章的间隙以长段如实呈现
   不做插值；数据点圆点带 `<title>` tooltip（章号 · 主导情绪 · 强度）；
   viewBox 自适应宽度。
4. **诚实不足态**：可绘制 <2 章时提示「可绘制的章不足（需 ≥2 章有情感弧线
   数据；本次拿到 N 章，M 章跳过）」；跳过数 >0 时折线下方计数说明。
5. 「重新体检」重置曲线（章数可能变化，需重新生成）；按钮态「生成曲线/刷新」。

## 坑

- **数据点数与跳过数的断言要按报告章数编排**：2 章报告里跳过 1 章后只剩
  1 个点，走「不足」分支而非折线分支——测试期望必须与数据可用性一致。
- 未分析章的 V2 绑定报「尚未分析」错误且**不触发重建**（重建是标注绑定
  NovelChapterAnnotations 的行为），逐章循环安全不引爆 LLM。
