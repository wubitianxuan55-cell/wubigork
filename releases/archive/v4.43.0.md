# v4.43.0「小说板块优化四刀：生成上下文 · 分支收账 · 搜索定位 · 一致性修复」

> 发布日期：2026-09-02 ｜ tag：`v4.43.0` ｜ 基线：v4.42.0 ｜ 绑定面 **557 零变更**

## 定位

小说板块自 v4.3.1 后进入维护态（v4.38-v4.42 连续五刀全在微信/模型中心），本次
专项摸底（含死代码/半闭环/薄实现盘点）后收四条互不相交线，全为生成质量与
既有功能闭环，**零 UI 结构变更、绑定面零变更**。

## 四刀

- **① 章节生成上下文增强**（create_chapter_handler.go）：生成 prompt 追加
  「未回收伏笔（创作约束）」「世界观要点」两区段（读 foreshadows.json /
  worldview.json，含旧 worldview.md 兜底，读失败静默跳过绝不阻断生成）；
  角色卡性格 20→60 rune 并补身份/目标/关系要点（无增补字段输出与旧版逐字
  节一致）；前文摘要 100→200 rune、续写尾部 500→1500 rune。全部区段受
  4000 rune 总预算双层截断（区段 1600 封顶 + 拼装层均分），prompt 不爆炸。
  该角色卡函数被分支生成共享，格式向后兼容。
- **② 分支链路收账**（plot_branch_handler.go）：修两处不闭环——
  Brainstorm/QuickBrainstorm 分支结果持久化到 `<项目>/branches.json`
  （fileutil.AtomicWrite 原子写，按 nodeID 存最近会话 + quick 键），ApplyBranch
  改读存储结果按原样应用，**主路径零 AI 重调**（旧数据无持久化才回退现场
  重生成，返回 applied_from + branch_note 注明可能与预览不一致）；
  syncCharactersFromOutline 从日志 no-op 变真同步（大纲角色幂等物化进
  characters.json，保留既有角色/组织/关系，失败只记日志不阻断）。
- **③ 全文搜索升级**（novel_search_handler.go + ChapterPage 阅读面板）：
  每章返回全部命中（单章 20/总 300 上限，统计不受上限影响）+ 位置字段
  （paragraph_index 与阅读渲染器切段语义逐一对齐 / char_offset / match_len）；
  前端结果列表「共 N 处 · M 章」+ 点击命中跳章滚段定位（Range 包临时高亮
  span，2.6s 自动清除；定位失败降级全文首中），回车即搜 + 请求序号防慢响应
  覆盖。纯函数抽出 novelSearchUtils.ts 配 15 个 vitest 用例。
- **④ 一致性规则两 bug**（internal/graph/consistency.go，保持纯规则）：
  分支章节（NNNa.md 等）纳入扫描且告警带 Branch 标记（跨章结论分线统计，
  分支出场不并入主线依据）；章节断档不再 break 停扫（1,2,5 存在时第 5 章
  告警出得来），单章读失败 continue 不中断。
- **死代码清理**（无 UI 变化）：删除零引用未挂载组件 PlotBranchModal /
  NextChapterModal / BranchSelectorPanel / hooks/usePlotBranch（活入口是
  CreatePage 自带 BranchWizardModal）+ 孤儿 api/search.ts（③改走直连后无人
  引用）；wails.d.ts 分支注释改指后端源。
