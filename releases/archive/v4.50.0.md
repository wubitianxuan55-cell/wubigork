## 定位

用户点名「造价数据库优化，核心是化繁为简」。简化 ≠ 删功能（红线）：平级
8 模块收敛为 6，全靠**归并**（价格源+价格仓库+询价库 → 价格数据）与**降级**
（知识图谱 → 概览的分析镜头），每个旧入口都可达。设计蓝图
`design-system/gaea/pages/cost.md`。judge 视觉验收两轮：首轮 3 must_fix →
修复后复核 **overall pass（7/7 重拍图）**。

## IA 重组（CostLibraryPage）

- **导航 8→6**：概览 / 成本条目 / 测算项目 / 价格数据 / 造价参考 / 复盘笔记。
  旧平级「价格源」「价格仓库」「询价（藏在成本条目）」「知识图谱」不再是
  顶级模块。
- **概览双视图**：导航右端「数据概览 | 关联图谱」双胶囊（role/aria-current），
  图谱从平级模块降为概览的分析镜头（渐进披露）；非概览模块右端显「回到概览」
  （纯文字，第一轮 judge 指出 RefreshCw 图标读作「刷新」有歧义，改文字）。
- **价格数据三段同域**（role=tablist 胶囊）：价格源 / 价格仓库 / 询价库。
  询价飞轮（v4.2 四源归一：信息价/OCR报价/供应商比价/手动询价）本就是价格
  数据域，此前埋在「成本条目」第三个无文字 icon 视图里，本轮升格一等子页；
  段头附四源归一说明行。
- **概览降噪**：快捷入口 7→4（导入资料/新建条目/价格数据/测算项目），纯导航
  重复项（价格仓库/造价参考/复盘笔记）走模块导航；空库三步引导、库规模
  hero、数据健康、最近更新原样保留。
