# v4.259.0 — 原罪插图：角色一致性锚定（文本锚点 + 图像参考槽）（2026-09-12）

## 为什么是这一刀

上一刀（v4.258）把生成进度做完后，原罪仍缺一环：**角色选进来了，但插图里的人不一定是她**。
本刀接上绘梦既有的 T2 角色参考槽，让「角色库 → 故事角色 → 插图人物」闭合成一条链。

## 落地

- **文本锚点（所有后端受益）**：画面描述没写到角色外观时，自动补
  「人物锚点（名字）：外观；身材」（≤120 rune），已写过不重复；
- **图像参考槽（仅 ComfyUI / Herdsman 图生图）**：取角色参考图（`referenceImages`
  优先，其次剧照）走 `mode=img2img + refImages + refMethod=img2img`（denoise 0.65），
  与绘梦 T2 参考槽同一条链路，不新增第二条生成实现；
- **锚定谁**：提示词点名的角色优先；都没点名且故事只选了一个角色 → 用那个；
  多角色未点名 → 不锚定（防参考图互串）；
- **能力门控**：`sinRefPlan` 明确「哪些后端×模型能用参考图」，不能用就跳过并给原因
  （不硬塞——硬塞会让整单报错）；
- **回退**：参考图那条路失败 → 自动退回纯文本重试一次并标记 `ref_fallback`，
  插图不因参考图而失败；
- **可见**：caption 显示「角色参考：<名字>」/「已补外观锚点」/「参考图不可用 · 已按纯文本生成」。

## 为什么不做 ipadapter / pulid

`ai/image_comfyui.go` 里这两条一致性方法尚未实现（`comfyResolveRefMode` 会如实报错）。
本刀沿用「已实现的那条路」，不假装支持未实现的算法。
