## 改动

### `internal/office/pptxedit` 新包（与 docxedit 同构）

- **slide 序映射**：`ppt/presentation.xml` sldIdLst（Token 模式下 r:id 的属性命名空间解析为 URL 可靠匹配——struct tag 的 URL 属性匹配不可靠，见 v4.106 实测坑）→ `ppt/_rels/presentation.xml.rels` Id→Target → 页码（1 起、放映顺序）→ part 路径；rels 缺失/映射缺失/包内缺文件均结构化报错。
- **DrawingML 段落解析**：a:p 段落 / a:r run / a:t 文本（原始字节区间）+ a:rPr 区间；blocker=a:br/a:tab/a:fld。**实测修正：a:fld 内的 a:t 没有 a:r 包装**（真实形状 `<a:fld><a:rPr/><a:t>1</a:t></a:fld>`）——该文本可见、进拼接文本、但记 blocker 不可编辑（页码类字段是渲染时生成的，改了也会被覆盖）。表格 a:tbl/组合形状内的 a:p 自然覆盖。
- **LocateText**：按页码返回各页段落文本（agent 定位目标用）；空段落不返回。
- **ApplyTextReplace(path, slideIdx, target, replacement)**：目标在页内首个命中；跨 run 文本可命中（拼接文本定位，rune 偏移）；精确匹配优先、折叠空白兜底；blocker 区间命中即拒绝（防破坏版式）。重建：新文本挂在最后受影响 run、继承其 a:rPr 原字节（天然保字号/字体/颜色）；完全覆盖的非最后 run 整体省略；部分覆盖 run 保留未受影响前/后缀（各自 rPr）。
- **原子写回**：zip 条目顺序原样保留、临时文件 + os.Rename；未触及条目（母版/主题/动画/媒体）字节零扰动（测试锁定）。

### App 层（`internal/app/gaea_pptx_edit.go` 新增）

- `GaeaPptxApplyEdit(rel, slideIdx, target, replacement)`：落盘前基线快照（`.gaea/work/rollback/pptx-*.before`，Verifier 通道 B 可复核）→ `pptxedit.ApplyTextReplace` → Journal 证据卡（`Tool=pptx_apply`、play 空间不落、写失败静默——对齐 appendXlsxEvidence 口径）→ 返回 `GaeaPreview` 新预览（PNG 逐页，前端直接重渲染）。
