## 交付明细

### ① A2 浏览器观察窗（受控页面观察 tab）

- **Go 观察面**：browser 包新增 `Manager.Observe()`——CDP
  `Page.captureScreenshot`（jpeg q70 + optimizeForSpeed，页宽 >1280 等比缩，
  尺寸取不到退化视口截图）+ 当前 URL/title；**浏览器未运行 →
  `Available=false` 且绝不拉起**（观察是被动动作）。绑定
  `GaeaBrowserObserve`（browser.Default() 单例同源，seam 可测）。
- **前端「浏览器」tab**：右栏 running 组第 6 tab（注册表清单+render 各一条）。
  BrowserPanel：URL/标题行 + 截图（内置 zoom 放大）+ 帧龄 + **操作时间线**
  （browser_* 工具记录倒序上限 20，参数摘要，err 红点——对标 Playwright Trace
  Viewer Actions 列表）+ 权限静态行「只读观察 · 写入操作需批准」+ **自动弹出
  胶囊开关**（`gaea.browserAutoOpen` 默认开；App 接线：新 browser_* 工具出现
  → 偏好开且 tab 未停用 → 自动切浏览器 tab）。轮询 2.5s（可见门控 +
  available 门控 + in-flight 防重叠，未运行退化为手动刷新）。
- 实时帧流 / 人工接管 = 远期（起版为截图步进流，调研结论一致）。

### ② B1 文件版本时间线（产物 vN 徽标可点 → 逐版本 + 预览 + 恢复）

- **零 Go 改动**：完全长在既有证据链上——`GaeaJournalList`（ChangeRecord 带
  baselinePath 写盘前整文件快照）+ `RollbackRecord`（恢复=写回基线并追加新
  证据卡，「恢复=新增版本」）+ `GaeaPreview` 绝对路径分支（基线在工作区内
  可直接预览）。
- **前端**：产物行 versions 徽标可点 → 内联 VersionTimeline（时间/工具/轮次/
  状态列表，`groupVersionsByPath` 按 target 聚合倒序过滤无快照卡）；每版本
  **预览**（openFilePreview(baselinePath)）与**恢复**（RollbackRecord + 重拉
  时间线纳入新生成的证据卡）；顶部说明「恢复会把该文件写回所选版本」。对标
  Notion 版本史/Claude Artifacts rewind；预览即护栏，不做二次确认弹窗。
- 留白：单版本文件暂无时间线入口（仅 vN≥2）；RollbackRecord 写回前不快照
  当前内容（严格「不丢当前态」待后端补写前快照）。

### ③ B2/C3 pptx 大纲卡 + 逐页预览 + 页级指令

- **Go**：新绑定 `GaeaPptxOutline(rel)`——python-pptx 逐页结构化大纲
  （标题占位符回退、正文文本框 200 字/条截断 ≤40 条/页、shapeCount；失败
  结构化不 panic，python-pptx 缺失提示 pip 安装）；`GaeaPreview` 加 .pptx
  分支——soffice→PDF（缓存 `.gaea/cache/pptx-preview/<hash>` 7 天 TTL）+
  poppler 逐页 PNG（≤60 页/64DPI，超出 Truncated）→ `kind="pdf"` + Pages[]
  复用前端既有 PDF 渲染；pdftoppm 缺失回退整本 PDF embed；soffice 失败
  结构化错误。真机冒烟通过（3 页 deck 逐页+二次全缓存命中）。
- **前端**：pptx 预览 = 逐页缩略铺页 + **PptxOutline 大纲侧栏**（第 N 页·
  标题·正文摘要），点页条目 scrollIntoView 滚动到对应页；每条「**针对第
  N 页修改**」按钮 → composer 插入指令模板（显式页码通道，对齐 Copilot PPT
  两通道结论）。python 依赖缺失 → 仅 PDF 预览 + 诚实提示。
