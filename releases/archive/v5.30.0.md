# wubigrok v5.30.0 — 绘梦 UI 重构 + 双模型官方工作流对齐

**发布时间**: 2026-07-28

## 绘梦 UI 重构

三栏布局：
- **左栏 350px**：控制面板（Prompt、参数、LoRA、引擎），可滚动
- **中间 flex:1**：画布固定两列，图片 280px 宽
- **右侧 180px**：历史记录竖排缩略图，可滚动

## Krea2 Turbo + Z-Image-Turbo 双模型

两个模型都对齐 Comfy-Org 官方工作流模板（`image_krea2_turbo_t2i.json` / `image_z_image_turbo.json`）

### Krea2 Turbo
| 组件 | 配置 |
|------|------|
| UNET | `krea2_turbo_fp8_scaled.safetensors` (13GB) |
| CLIP | `qwen3vl_4b_fp8_scaled.safetensors`, type=krea2 |
| VAE | `qwen_image_vae.safetensors` |
| Latent | EmptyLatentImage |
| Negative | ConditioningZeroOut |
| Sampler | CFG 1.0, 8步, euler/simple |
| 速度 | ~60s |

### Z-Image-Turbo
| 组件 | 配置 |
|------|------|
| UNET | `z_image_turbo_bf16_完整版_效果最好.safetensors` (12GB) |
| CLIP | `z-image\qwen_3_4b.safetensors`, type=lumina2 |
| VAE | `z-image-qwen.safetensors` |
| Latent | EmptySD3LatentImage |
| Negative | ConditioningZeroOut |
| Sampler | CFG 1.0, 8步, res_multistep/simple |
| AuraFlow | ModelSamplingAuraFlow shift=3 |
| 速度 | ~34s |

## LoRA 完整支持

8 个 LoRA，前后端贯通：
- Krea2: Turbo加速, MysticXXX v3
- ZIT: 细节增强, 3D卡通, 氛围光影, 极致写实, 女帝风格, NSFW

后端 `injectLoraNodes()` 动态插入 LoraLoaderModelOnly 链。

## 关键修复

- Krea2 CLIP 必须含 visual 键（detect_te_model 识别 QWEN3VL_4B）
- VAE 必须用 qwen_image_vae（不能用 ae.safetensors）
- AMD ROCm 用 standalone-env/python.exe 启动 ComfyUI
- 13GB redcraft23 是 FP8 版（能用），12GB 是 INT8 混合版（AMD 崩）
