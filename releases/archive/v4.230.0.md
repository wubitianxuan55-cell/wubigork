# v4.230.0 — AI 输出渲染对齐同类产品首刀：聊天代码块语法高亮（2026-09-11）

> 用户方向「优化 gaea 的 AI 输出效果对齐同类产品」。现状盘点后最大可见短板=
> 聊天代码块零语法着色；本刀补齐，入口体积零增。

## 缺口

- 办公板块聊天代码块一直是纯 `<pre><code>`，AI 输出的 Go/SQL/Python/Bash
  片段黑白一片——ChatGPT/Claude/DeepSeek 类产品的代码块全部着色。
- 有趣的考古：`styles.css` 里 hljs 令牌主题（`.hljs-*` 十组规则 + `--hl-*`
  八色调色板，注释「highlight.js token theme (mapped to palette)」）**早已
  预铺**，`lang.ts` 头注「no highlight.js dependency」是当年刻意留的懒缝——
  CSS 等了高亮器很多年，本刀把它接上。

## 落地（懒加载缝，入口体积零增）

- **新依赖** highlight.js ^11.12.0；**新 `gaea/lib/codeHighlight.ts`**：
  - core + 22 语言白名单（go/bash/sql/yaml/powershell/typescript/python/
    c·cpp·csharp/java/rust/json/xml/css/markdown/diff/ini/makefile/nginx/
    dockerfile）全部动态 import，独立 async chunk（mermaid 566KB 同款先例）。
    构建审计：`registerLanguage` 在入口 chunk **0 命中**，hljs 核心 21KB
    独立 chunk，语言语法各自微 chunk 按需拉。
  - **未注册语言回退纯文本**不硬造（brainfuck 等诚实降级）；围栏语言别名
    归一复用 `lang.ts` ALIASES（编辑器/工具卡同源表）；`toml` 无官方语法
    借 ini 着色（节+键结构一致；展示标签仍显示 toml）。
  - hljs 产出自带转义、仅 `hljs-*` span；插入前再过统一消毒层 DOMPurify
    兜底（class 白名单保留，脚本标签不成活——有测试锁）。
- **Markdown.tsx** 代码块接 `HlCode`：首帧纯文本立现（不挡渲染），高亮
  就位后整体换着色 HTML；调用点=稳定分段（MemoMarkdown 段签名缓存），
  流式增长中的尾部走简易 HTML 不经此处——**无逐 delta 重高亮**。
- **明暗双调色板**：暗色=既有 One Dark 系（styles.css `:root` 兜底，原值
  不动）；浅色 `:root[data-hl="light"]` 同色相深阶（白底对比度 ≥4.5:1，
  暗色淡色阶在浅背景 <3:1 不可用）。`data-hl` 由主 App 主题 effect 内联
  挂载——**刻意不 import gaea/lib**：那会把 sanitize/universe 消毒链拖进
  主入口 chunk。`darkMode` 为 store 派生的实际明暗（system 档跟随 OS 实时
  切换），明暗切换即时生效。

## 坑

- hljs 类名是运行时 `hljs-` + scope 拼接，**产物 JS 里没有 "hljs-keyword"
  字面量**——bundle 归属审计不能 grep 类名，要用 `registerLanguage` 特征串。
