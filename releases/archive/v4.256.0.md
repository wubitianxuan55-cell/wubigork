# v4.256.0 — 闲庭新板块「原罪」：对话式图文混杂故事创作（2026-09-12）

## 为什么是这一刀

用户提「在闲庭增加一个单独的功能板块，复用办公的组件，主要用于与 AI 对话，
可以生成图文混杂的 H 故事小说，板块取名原罪」。此前闲庭只有聊天/小说/绘梦/
角色库：小说板块是「项目 → 设定 → 章节」的结构化创作，绘梦是纯出图，聊天是
陪伴对话——**「边聊边写、写完就配图」这一形态没有落点**。本刀补这块。

## 形态

闲庭一级板块 `sin`「原罪」（layout=full）：左「故事」架 + 中故事流/输入器 +
右「玩法 · 插图协议 · 边界」三卡。

## 复用办公组件（用户口径的正面落地）

- 输入器 = 办公 `Composer`（附件、粘贴表格转 Markdown、截图/裁剪、识图、OCR、
  输入历史、高度记忆全继承）；
- 正文渲染 = 办公 `Markdown`（与办公消息同一条渲染链：本地文件链接、代码折叠、
  mermaid、genui、消毒与 URL 白名单）；
- `ToolbarButton` / `EmptyState` / `LocaleProvider` + 办公三件套样式；
- **零新建聊天组件**，且不改办公组件本身（原罪只做消费方）。

## 后端

- 会话复用统一聊天存储（话题 `mode=sin`）：与聊天板块同表不同域，双向隔离
  （`SinTopicsList` 只见 sin；`ChatTopicsList` 过滤 sin），跨板块操作 fail-closed；
- 文本 = 现有流式通道 + 新功能级路由 `sin`（模型中心新增「原罪」绑定，
  可单挂长上下文/无审查本地模型；未绑定回退全局）；
- 插图 = 绘梦图像后端同一条生成链，产物登记 `space=play / source_board=sin`，
  路径回写消息 `extra.illustrations`（重开不重生成）；
- `SinExportMarkdown` 导出图文混排 Markdown。

## 插图协议

模型在需要配图处另起一行输出 `@@插图|画面描述@@`（一轮最多 2 张）；前端按出现
次序编号（0 起）就地生成并嵌进正文流。正文原样落库（可回溯），导出时才做
标记 → 图片替换；未生成的标记导出为「（插图未生成：…）」占位，不静默吞掉。

## 内容边界

成人内容口径零新立（沿用 `docs/ADULT_MODE.md`：个人非商用桌面应用、默认开启）；
系统提示词写死四条硬边界（全员成年/禁止真实在世人物/合意基调/用户叫停即停），
并有专项测试锁定。
