## 落地

- **新 `gaea/lib/mathText.ts`（跨板块共享）**：自 gaea Markdown.tsx 提取
  `normalizeMath`（\(...\)/\[...\] → $ 定界符归一 + \| 转 \vert）、
  `hasMathContent`（CSS 懒注入门控）、`ensureKatexCss`（KaTeX 样式 link
  懒注入）——Markdown.tsx 改引共享库，行为零变化。
- **ChatMarkdown（plain 终态）**：管线加 `remark-math` + `rehype-katex`，
  text 先过 normalizeMath；有数学内容才注入 KaTeX CSS。
- **MarkdownContent（companion/流式）**：同款管线（remark-math +
  rehype-katex + normalizeMath）；GenUI 覆盖件路径不受影响（components
  照旧完全尊重调用方）。
- 零新依赖（remark-math/rehype-katex 已在仓）、零新 chunk（katex 模块与
  样式经既有共享 chunk 复用）、无 Go 改动、绑定 625 不变。
