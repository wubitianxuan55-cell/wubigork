# gaea v2.14.0「办公板块会话化升级：项目分组 + 会话生命周期 + 任务目标 + 变更面板」

发布日期：2026-08-13 ｜ 版本号：v2.14.0

本轮把「通用办公」从“扁平会话列表”升级为“按项目聚合的会话工作台”，并补齐
会话生命周期（置顶 / 归档 / 恢复）、任务目标（需求→验收）、文件变更可观察性，
同时修复记忆图谱三元组被成本节点挤掉、会话删除注册表清理不完整、App 层
toast 静默失效等问题。

## 新能力

- 侧边栏「项目」分组：当前工作区置顶，其余为最近打开过且有会话的工作区；
  会话按“当前 → 置顶 → 最近”排序，分组内超过 50 条自动截断，前端提供
  「显示更多」展开剩余会话。
- 会话生命周期：活跃会话支持置顶（`.pinned.json`）与归档（移入
  `<sessions>/archive/`，可恢复）；侧边栏「已归档」分组支持一键恢复。
- 任务目标（需求→验收）：会话首条用户消息自动锚定为任务目标，随会话持久化；
  顶部待办栏展示“进行中 / 已验收”状态，可一键标记验收完成或重新打开。
- 文件变更面板（右侧「变更」标签）：汇总本会话 `write_file` / `edit_file` /
  `multi_edit` / `move_file` 等工具实际改动的文件及次数，点击行直接打开预览；
  路径提取覆盖 `path` / `file_path` / `notebook_path` / `paths` / `edits` /
  `source`+`destination` 等常见参数形态。
- 恢复会话保留工具过程：`GaeaHistory` 现把历史消息中的工具调用还原为
  `tool` / `tool_result` 事件，恢复旧会话后过程卡与「变更」面板仍然可见。
- 专注模式：顶栏 `Aim` 按钮或 `Ctrl+Shift+F` 一键收起侧栏与右侧面板，只留
  对话和输入区（状态持久化）。

## 修复

- 会话删除：清理标题、任务目标、置顶三处注册表时不再提前 return，三者会全部
  清干净（此前标题命中后任务目标/置顶会残留）。
- 记忆图谱：轻语事实与三元组提前到成本条目之前入图，成本库很大时不再挤掉
  “t:用户 / t:辣 / t:程序员”等语义关系节点（修复 `TestGaeaMemoryGraph_WhisperTriples`）。
- App 层 toast 静默失效：`ToastProvider` 上移到 `main.tsx`，归档/置顶/恢复、
  导出 Word 等 App 层回调的提示现在能正常弹出。
- 恢复历史会话时补齐“整轮完成但待办仍显示 0/N”的收尾逻辑。
- 移除重复的 `Ctrl+Shift+H` 快捷键分支；`WRITE_TOOL_NAMES` 收敛为
  `lib/changes.ts` 单处定义。
