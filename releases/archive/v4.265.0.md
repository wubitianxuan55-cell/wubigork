# v4.265.0 — 原罪画廊重新生成入口（2026-09-13）

## 用户口径

v4.263.0 发布说明列的下刀候选清账：流内插图卡本有「重新生成」，右栏画廊却只能看。
本刀把同一能力带进画廊。**零 Go 改动、零新绑定**（drift 维持 641）——`SinIllustrate`
（641 面既有）本就是全链路：角色锚点 + 参考槽门控 + 退回纯文本重试 + 台账登记 +
`arts[cue]=path` 覆盖回写；重生成 = 同一入口按 `(messageId, cue)` 再调一次。

## 落地

### ① 条目定位

`collectIllustrations` 条目扩 `messageId/cue`（SinIllustrate 回写槽），画廊条目从
「只能看」升级为「可操作」。

### ② 入口两处

- **缩略图悬浮钮**：默认藏、hover/focus 显形；生成中变「重新生成中…」状态条 +
  缩略图调暗 + 挡重复点击；正文无标记 → prompt 空不出钮（SinIllustrate 拒空提示词）；
  回合 sending 中禁用（防与在途插图互踩）。
- **大图 Modal footer 同款钮**；重生成成功后预览自动跟到新条目（key 同 path 新）。

### ③ 执行纪律与刷新

页面回调与流内**同一 `illustrationQueue` 串行**（一次一张）→ `SinIllustrate` →
`reloadMessages()`（useSinStory 新暴露）刷新画廊与流内。

### ④ 外部换图采纳

`SinIllustration` 记 `extPathRef`：pathProp 变化且**自身不在生成中**才采纳新路径——
防「画廊新图/流内旧图」不同步，也防顶掉自己在途产物。

### ⑤ 失败口径

失败如实 notice，**原图保留**（回写只在成功路径发生）；`persisted:false`
（图已生成但回写失败）同样提示，不静默。
