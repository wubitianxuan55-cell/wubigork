## 一、后端架构重构（3 提交，-526 行）

### 1. HTTP client 统一（核心）
- `internal/gaea/netclient` + `sysproxy` 提升为**共享层** `internal/netclient`
- 新增 `netclient.NewSimpleClient(timeout)` 便捷构造（克隆默认 transport + 直连 + 总超时）
- **老栈 14 文件 22 处裸 `&http.Client{Timeout:X}` 全部收敛**到统一封装
  （ai×3、modelengine、tts×2、asr、auth×2、weixin×2、office、whisper、app×2、billing）
- SSRF 防护 3 处自定义 Transport（plugin/ssrf、webfetch、websearch）属安全特例保留
- 新增单元测试 `TestNewSimpleClientTimeoutAndTransport`

### 2. 工具函数收敛
- 删除 `office/types.go` 零调用死代码（Itoa/TruncStr/ContainsAny，-26 行）
- asr/whisper 手写 `trimSpace`/`lastIndexOf`/`itoa` 全部替换标准库
  （顺带修复 itoa 负数返回空串的 bug）

### 3. 配置系统整合
- 删除 gaea config 零消费者 `ComfyUIConfig` 死域（与老栈 config 完全重复，-49 行）
- 删除零消费者 `Statusline/Notify/Serve/LSPConfig/LSPServer` 类型与字段（-114 行）

### 4. AI 调用通道统一
- 删除 `provider/stream_client.go`（gaeaW 遗留独立 HTTP 层，零生产引用）
- AI 通道唯一化：前端 → gaea agent → provider(bridge) → ai.Client → modelengine 路由

## 二、前端两套 UI 体系统一（7 提交，-6300+ 行）

> 目标「再无新旧之分」：办公板块（gaeaW 移植）与主应用两套体系合一。

### 1. 死组件清理
- gaea 侧删 7 个零引用组件（含 ErrorBoundary/Lightbox 同名重复，-734 行）
- 老栈删 29 个废弃组件 + 4 个死 hook/util + gaea 7 个死代码（-4879 行）
- gaea highlight.ts 删除（-171 行）+ 移除 highlight.js 依赖

### 2. 令牌层统一（单一主题源）
- gaea styles.css 核心颜色 → 引用老栈 M3 令牌（`--md-sys-color-*`）
- 删除全部硬编码 data-theme 变体段（light/warm/ice/forest/earth/noir）
- 删除 gaea 独立主题系统 theme.ts；ThemeSwitcher/Settings 改调老栈 darkMode
- **双向联动**：老栈/gaea 任一暗亮切换 → 同一令牌链路

### 3. 图标体系统一
- 66 个 lucide 图标 → `@ant-design/icons`（新建 gaea/icons.ts 兼容层）
- 40 文件迁移，lucide-react 依赖移除

### 4. 布局壳 antd 化
- `.app/.layout` → antd `Layout`；右侧面板 → antd `Drawer`
- Tooltip → antd Tooltip
- 功能面板（对话流/审批/记忆/设置）按**分层原则**保留自绘
  （antd 无对应物，强行替换=重造轮子；颜色已令牌统一）

### 5. 死样式清理
- 删除 `.app`/`.workspace-panel-resizer`/`.workspace-panel` 样式族（-690 行）
- styles.css 1604 → 1252 行
