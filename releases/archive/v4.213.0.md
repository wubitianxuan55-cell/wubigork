# v4.213.0 — 5.3 首刀：记忆生命周期三态（固化/衰减/归档）（2026-09-11）

> 阶段五「记忆OS + 上下文编译」5.3 首刀。域内基线：
> docs/gaea-memory-graph-51-design-2026-09.md §5.3。

## 缺口

生命周期只有「活跃/归档」两态 + 90 天保留期一刀切：重要的记忆没有「固化」
保护（归档超期即被硬删），久未使用的记忆没有「衰减」可见性（用户不知道哪些
记忆正在被遗忘）。5.3 出口判据中「蒸馏 no-op 转真实合并」（做梦 2.0
DistillMerge）与「预取可关闭」（晨报预载开关）此前已落地——本刀不重复建设。

## 落地

- **固化（SchemaV19 facts.pinned）**：
  - 免疫衰减归档、**豁免保留期硬删**（CleanupArchived `AND pinned=0`）——
    「90 天一刀切」的替代核心：用户明示保留的事实永不被自动清理；
  - 晨报/预载排序加权（morningRecencySort 固化组优先，组内仍按时间序）；
  - 与 archived 正交：手动归档仍可作用于固化条（用户是老板），pinned 保留；
  - Save 覆盖（remember 工具重写正文）不丢固化态（ON CONFLICT 不触 pinned）；
  - 已归档不可 pin（固化只作用活跃集合，明确报错）；文件后端不支持=诚实
    报错（对齐 space_id 先例，绝不静默假成功）。
- **衰减（纯函数，非存储列）**：
  - `memory.DecayScore`：半衰期 30 天指数衰减（30 天未用 0.5 分、90 天
    0.125 分），下限 0.01；固化恒 1.0；无活动时间戳=无衰减证据=满分
    （存量行诚实不造数）；
  - `memory.LifecycleOf`：固化 / 活跃 / 衰减（闲置 > 60 天）三分类；
  - 「衰减有留痕」：评分输入（save/touch 事件）自 v4.210 起逐条落
    memory_events，状态动作（pin/unpin/archive）同日志留痕——衰减不是
    定时任务，是可追溯的状态视角。
- **三态可查（绑定 609→611）**：
  - `GaeaMemoryLifecycle`：固化列表 / 衰减列表（评分升序=最久未用在前，
    带评分与闲置天数）/ 活跃计数 / 归档计数 / 保留期 / 衰减阈值下发；
  - `GaeaMemoryPin(name, pinned)`：固化切换，落 pin/unpin 事件；
  - 前端 OfficeMemoryLibrary 事实 tab 生命周期统计行（固化/衰减中/活跃/
    归档 + 保留天数 + 最久未用提示）+ FactCard 固化锁（aria-pressed）与
    「固化」徽标。
