- 基线：v4.109.0 + 市场调研（GitHub gantt-planing-react / ArrowDiagramGenerator + 斑马进度「一表双图」口径，见会话调研）。

## 板块定位（对齐调研拍板口径）

「进度计划」一级板块（工位空间，menuOrder 12）：一套任务表数据驱动三种视图自由切换——
横道图（甘特）/ 单代号网络图（PDM 六格图）/ 双代号网络图（AOA），「一表多图实时联动」，
不改变表格做计划的习惯；三视图共享同一 store 与同一份 CPM 结果。

## 改动

### 引擎层（frontend/src/schedule/ 纯函数，27 用例钉死）

- **cpm.ts**：关键路径法引擎。FS/SS/FF/SF 四种搭接 + 时距（可负）；Kahn 拓扑（环检测 fail-closed，
  报环上任务名不静默）；正推 ES/EF、逆推 LS/LF、总时差 TF、自由时差 FF、关键工作标记；
  里程碑按 0 工期参与。15 例（链路/并行/四搭接/负时距/混合/自环悬空过滤）。
- **aoa.ts**：双代号转换引擎（刀1 最难件）。PDM→AOA：教材口径的安全合并（唯一 FS(lag=0)
  前置且完成事件干净→共用完成事件；唯一 SS(lag=0) 同理）+ 其余补虚工作（虚箭线按搭接类型
  自动插入、同向去重）+ 一始一终（多起多终汇 START/END）+ i<j 拓扑编号 + 事件时间正逆推
  （关键线路含关键虚工作，红色虚线）+ 时标分层布局（列=事件最早时间）。11 例（教材链式/
  菱形虚工作/并行起算/SS 合并/SS 时距/结构不变量三例/循环拒绝/空图/里程碑）。
- **layout.ts**：时标分层布局（layerByTime），单代号/双代号共用；列内重心两轮松弛减交叉。

### 视图层（SchedulePage + 三视图）

- **SchedulePage**（pages/，PageRegistry 注册 + 前后端 manifest 双侧接线）：工程名/开工日期/
  Segmented 三视图切换/添加任务·分组/里程碑切换/删除（分组级联）/示例工程/清空；
  循环依赖 Alert 提示。
- **GanttView**：左侧任务表（大纲缩进、行内改名/改工期、前置关系 Popover 编辑器：类型+时距）
  + 右侧时间轴条形图（月/日双行表头、周末底纹、今日线、缩放四档）；关键工作红条、分组黑色
  汇总条（子孙滚动）、总时差虚线尾巴、里程碑菱形、进度内条、FS/SS/FF/SF 搭接箭线。
- **PdmView**：单代号六格节点（名称 + ES/工期/EF + LS/总时差/LF），搭接箭线带类型+时距标注，
  关键红色。
- **AoaView**：双代号经典画法——圆圈事件（圈内编号、上最早/下最迟时间）、实工作箭线（工期
  标注+任务名）、虚工作虚线（时距标注）、关键线路（含关键虚工作）红色加粗。
- **store.ts**：zustand + persist（localStorage `gaea.schedule.v1`）；分组行判定/子孙集合
  （descendantIds）供级联删除与前置选项过滤。
- **sample.ts**：示例工程「办公楼施工」20 行（5 分组+里程碑，SS/FF/时距混合搭接），
  CPM/虚工作/时差三视图演示自证数据。
