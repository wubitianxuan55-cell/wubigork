## 🆕 新增模块（8 个 Go 文件）

### 1. 关联冷启动 `association_cold_start.go`
- **双路径建边**: embedding 相似度优先，文本重叠兜底
- **孤儿优先**: 无关联的事实优先建立新边
- **新事实种子**: ingest 单轮新增事实自动与库内 active 事实建边
- **兜底弱边**: NOTE 或单条新事实 → 最近邻弱边连接

### 2. 记忆自编辑 `memory_self_editor.go`
- **批量矛盾检测**: 复用 ContradictionDetector，≥2 对一次 LLM 调用
- **自主决策**: reinforce → 合并强化 / conflict → keep_new/keep_old/merge/flag
- **编辑日志**: 记录每次自编辑操作（最多 200 条，保留最近 100 条）

### 3. 会话事实过滤 `session_facts.go`
- **防跨会话泄漏**: 按 sessionID 过滤，构建快照时仅使用当前会话事实
- **摘要提取**: SummariesForSession 按限制返回摘要列表

### 4. 自动巩固策略 `auto_consolidation_policy.go`
- **三条件触发**: 轮次门槛(≥20) / 强制触发(≥60) / 有意义事件密度(>40%)
- **raw 事实计数**: 统计未整合的 raw 层事实数

### 5. 时间锚点策略 `temporal_anchor_policy.go`
- **四类锚点**: fuzzy / recurring(周年/生日) / milestone / relationship
- **智能写入**: 高权重+高情绪 → 必然写入；recurring → 降低门槛
- **锚点记录**: 含情绪快照 + 关联事实 ID

### 6. 特殊日期情绪偏移 `temporal_context_modulator.go`
- **8 种特殊日期**: ackem_birthday / birthday / first_met_anniversary / holiday_spring / holiday_valentine / holiday / milestone
- **覆盖周日曲线**: 特殊日期的情绪偏移远大于周日忧郁

### 7. 用户事实守卫 `user_fact_guard.go`
- **问句检测**: 用户问伴侣问题时不写入 BASIC_PROFILE
- **自述验证**: 生日/姓名仅在用户明确自述时写入
- **二次过滤**: LLM 抽取后过滤，防止伴侣信息污染用户档案

### 8. 程序化习惯 `procedural_habits.go`
- **持久化存储**: 线程安全 + 归一化键
- **已建立判定**: 出现次数 ≥3 → 已建立习惯
- **习惯列表**: 列出所有已建立习惯（去重）

## 🔧 管线集成（5 文件修改）

### orchestrator.go
- **结构体**: 新增 `SelfEditor *MemorySelfEditor` + `ProceduralHabits *ProceduralHabitStore`
- **周日情绪偏移**: PreLLMTurn 中应用 `ComputeWeekdayMoodBias`

### post_chat_turn.go

- **用户事实守卫**: LLM 抽取后调用 `FilterExtractedUserFacts` 二次过滤

### params.go
- **新参数组**: 自编辑(SelfEdit) / 冷启动(ColdStart) / 程序化习惯(Habit)
