# gaea v3.1.0 发布说明

> 2026-08-26 · 造价数据库「一级板块 + 综合单价架构 + 测算项目」· 办公蒸馏（右侧面板/文件工作台）· 初始化死锁修复

## 一级板块「造价数据库」（参照 zaojia-database 蒸馏）

- **升为一级板块**：成本库从记忆中枢二级分类提升为独立板块「造价数据库」（board cost，
  `CostLibraryPage`，指挥轨道 MenuOrder 5，导航：概览/成本条目/价格源/价格仓库）；
  记忆中枢成本二级入口移除（避免双入口，记忆图谱节点保留琥珀色）。
- **架构定稿（市场调研驱动）**：调研陕西蜘蛛网工程成本平台确认公开内容全部为
  「综合单价分析」（人工费+材料费+机械费+管理/利润/税金→综合单价），与《市政成本
  测算手册》同构；决策：记录=综合单价子目、资源库层保留不强制关联、费率入库仅展示
  追溯。调研文档 `docs/market-research-2026-08-cost-architecture-zonghe-danjia.md`。
- **综合单价=一级、人材机=二级组成**（SchemaV12/V13）：`cost_entries` 增人工/材料/
  机械合计 + 管理/利润/垫资/税率（仅展示不参与计算）；新建 `cost_entry_components`
  组成行表；Save 组成行整组替换、导入事务写库全链路。
- **价格三要素与溯源**（SchemaV9）：region / price_date / price_type / valid_until /
  source_row，`cost_price_history` 同步地区与口径——每个数字可追溯「哪个地区、什么
  口径、哪一期」。
- **默认分类树重构**：综合单价 → 专业（道路/交通/绿化/电力/给水/暖气/雨污/照明/其他）
  → 分部。
- **《市政成本测算手册》整本导入**：专有表头触发解析（多专业表→分部行→子目行），
  「综合单价分析」文本解析为人材机组成行（损耗系数表达式入 note 保留）；实测 8 张
  专业表 **234 条全部命中**，通用报价单导入不受影响。

## 测算项目 + 造价参考（新包 costproject / costref）

- **测算项目与沉淀闭环**（SchemaV10：cost_projects / cost_estimate_items /
  cost_estimate_versions）：测算项目容器（类型/规模/工艺/状态）+ 明细行（引用成本库
  单价或手动填价，数量×单价自动算金额）+ 不可变版本快照（回看/对比/恢复）；「沉淀」
  把明细行 UPSERT 回 cost_entries，「沉淀即调用」闭环。App 绑定 GaeaCostProject* /
  GaeaCostEstimate* 系列。
- **造价参考与复盘笔记**：对已保存版本/已沉淀明细行实时聚合 样本数/极值/P25/P75/
  中位数/均值（指标不落表避免双写）；复盘笔记沉淀「判断」（结论/适用边界/风险/证据/
  可信度/有效期/复核状态 + 引用计数）。
- **cost_indicators 办公 agent 工具**：只读聚合对标（测算前引用依据），测算/对标由
  办公 agent 承担——「数据库就是数据库」收口。

## 办公蒸馏（dsh-better-sidebar，两轮）

- **C3 会话级布局持久化**：右侧面板子 Tab 按会话记忆（`gaea.rightPanel.v1:<sessionKey>`），
  切会话/新建/恢复各自恢复关注点；无会话回退全局 key 兼容旧值。
- **C6 运行域活动角标**：useRunningBadge（TaskList 基线 + gaea-task 事件增量），
  运行组未激活时显示活跃任务计数（99+ 封顶）。
- **C7 预览队列 chip 化**：PreviewNavBar 升级为文件 chip 条（basename、点击切换、
  × 关闭、中键关闭 VS Code 语义）；store 增 navTo / closePreviewAt。
- **文件工作台资源管理器**（FileTree 升级，纯前端零后端）：行悬浮 @引用 / 右键菜单
  （预览·外部打开·在文件夹中显示·复制相对路径+已复制反馈）/ 展开态按 cwd 持久化 /
  树内搜索接 GaeaFileSearch 工作区递归搜索。
- **删除完成轮大过程卡**：Transcript 统一交替语义（正文独立显示、过程单独小卡），
  不再整轮合并成大卡。
- **UI 紧凑化**：GoalCard/TodoCard 默认折叠（折叠态一行）；修复 Tailwind v4
  `max-w-[--maxw]` 方括号语法不生成 CSS → 统一 `max-w-(--maxw)` 括号语法，四处卡片
  宽度与输入框对齐。

## 修复

- **办公板块初始化死锁（工作空间/新建会话不可用的根因）**：`GaeaInit` 持 `ga.mu`
  初始化时经 `resumeLastSession → syncGoalForSession` 对同一把非重入互斥锁二次加锁，
  工作区存在会话时办公板块首次打开即永久卡死。修复：`syncGoalForSession` 显式接收
  控制器不再内部取锁 + 两个回归测试；`persistWorkspaceLocked` 同步更新磁盘
  `sandbox.workspace_root`。

## 决策：V4.0 dsh化 正式废弃（2026-08-26）

- gaea 改造成 DSH 插件体系（独立工作空间 `C:\AI\gaea-v4`）经用户验证判定失败；
  删除工作空间内 V4.0 文档，`C:\AI\gaea-v4` 与 `~/.dsh*` 工作空间外文件一律不动；
  继续 V3 迭代（本版本为 V3 板块生态里程碑）。
