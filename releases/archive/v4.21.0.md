# v4.21.0「长会话与 transcript · 增量渲染 / 消息搜索」

> 发布日期：2026-08-31 ｜ tag：`v4.21.0` ｜ 基线：v4.20.0（同工作区，未打 tag）
> ｜ 绑定面 546 → 546（零新增绑定，纯前端）

## 背景与过程

续 v4.20.0 之后剩余的两条欠账：轨迹超长会话的渲染量（原「虚拟滚动」欠账）
与子代理 transcript 只读无搜索。本刀用**增量渲染 + 滚动续载**达成与虚拟滚动
相同的实际目标（DOM 有界），并给 transcript 加消息搜索；顺带修正 ChatTabs
里「轨迹暂占位」的过期注释。

## 交付明细

### ① 轨迹增量渲染（长会话 DOM 有界）

- 轨迹渲染从「逐轮整体渲染」改为**扁平行流**（轮次头 + 展开的记录行 +
  Between-turns），按批渲染：首批 250 行，滚动到底部自动续载下一批，
  或点「加载更多（剩余 N 条）」；搜索词变化回到首批。
- 概览跳转（v4.20）同步增强：跳转时把目标轮之后的可见区一并扩到视口内，
  不会再出现「跳过去了但记录还没渲染」。
- 收起全部/展开全部在平行流上依旧生效（折叠 = 记录行直接不进流）。

### ② 子代理 transcript 消息搜索

- transcript 查看器头部增搜索框：按正文/推理/工具名/参数/结果过滤消息，
  计数显示「命中/总数」，无匹配时空态提示；搜索词与展开状态互不干扰。

### ③ 过期注释清理

- `ChatTabs.tsx` 头注释「[轨迹] …（暂占位）」更新为 v4.17-v4.21 实际能力
  （事件账本：概览/搜索/折叠/增量渲染）。

## 验证

- 前端：tsc -b 0；eslint 0；vitest 872/872（+2：超长会话增量渲染与加载更多、
  transcript 搜索过滤）。
- Go 全量（含 app 绑定面 546）不变，cached 全绿；drift PASS（546）；
  版本四处统一 4.21.0。

## 欠账

- 增量渲染是「分批 DOM」而非 react-window 真虚拟化：渲染量有界（首批 250、
  按需续载），但已渲染部分仍是真实 DOM。子代理 transcript 仍为只读消息流
  （搜索已补，跳转/引用定位未做）。
