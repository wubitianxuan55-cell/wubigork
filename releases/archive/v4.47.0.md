# v4.47.0「微信助手星枢化：通讯枢纽工作台」

> 发布日期：2026-09-02 ｜ tag：`v4.47.0` ｜ 基线：v4.46.0 ｜ 绑定面 **559 零变更**

## 定位

UI 重构刀：微信助手管理台从 v4.4 的「三卡堆叠」（介绍卡 + 连接卡 + 提醒卡 +
怎么用卡，860px 竖排）升级为 Constellation OS「通讯枢纽」工作台。**功能面与
v4.4 逐项对齐零删减**（红线：简化界面≠删除功能）——多助手管理（人格 Tag/
状态徽标/启停/删除/逐助手扫码绑定 + 新增流）、离线提醒（全局开关 + 手动新建 +
列表）、使用说明、会话过期警示全部保留。ui-ux-pro-max 技能检索（Real-Time /
Operations 台模式、live badge 无障碍、焦点环、内容防跳动）+ 项目设计系统
（MASTER v2「星枢 Constellation OS」+ memoryhub hub.css 轨道语言先例）落地。

## 布局

- **顶部细条 `.wx-strip`**（40px 玻璃 + 1px 高光线）：WechatOutlined + 板块名
  + 一句话定位（原整卡介绍收敛为副标语，完整说明移指南视图）+ 通道遥测 meta
  （等宽数字 `3 通道 · 1 运行中 · 提醒 开`，role=status 单一原子播报）+ 刷新。
- **左通道轨道 `.wx-rail`**（196px，v3-panel）：通道组 = 每助手一条 rail item
  （antd Avatar 26 + 名字 + 状态字 + 状态点，aria-label `通道 X` + aria-current）；
  「+ 新增微信助手」dashed 项；「支持」组 = 离线提醒（pending 数徽标进
  aria-label）+ 使用指南。激活态 = primary-container 底 + 左缘 `--gaea-glow`
  光条（对齐 hub-rail 语言）。
- **主区 `.wx-main` 三视图**（rail 点击驱动）：
  1. **通道详情** `ChannelDetail`：身份头（Avatar 44 + 核心/人格 Tag + 扫码
     绑定/删除操作）→ 会话过期内联 Alert → 键值卡三张（通道状态 Tag /
     微信绑定 / 启停 Switch，核心助手禁删禁停照旧 Tooltip）→ 小贴士。
  2. **离线提醒**：标题 +「到点回推微信」全局 Switch → 新建行（Input +
     DatePicker + 创建）→ `wx-rem-item` 行（状态 Tag / 文本 / 来源 / 重试 /
     等宽时间 / 删除，hover 柔光）；空态保留微信口令提示。
  3. **使用指南**：三张 `wx-guide-card`（设提醒：示例句等宽 `wx-cmd` chip ×3 /
     收提醒 / 聊天）+ 边界说明脚注——原 Descriptions 文案全量保留。

## 状态语义与交互细节

- **三重传达**：`channelStatusOf` 四态——运行中（success 发光脉冲，
  prefers-reduced-motion 关动画）/ 会话过期（warning）/ 已停止（次级 62%）/
  未绑定（虚线空心点）；轨道状态字 + `title` + 详情区完整 antd Tag 同口径。
- **扫码绑定流**：Modal 内新增 `wx-qr-steps` 三步指示（扫码→确认→完成，
  当前步发光）；240px `wx-qr-frame` 二维码容器（加载中占位不再裸 div）；
  相位文案/配对码分支/错误分支逐字保留。新增助手 confirmed 落库后主区直接
  落在新通道（`setSelectedId(qrTarget.id)`）。
- 所有自定义控件显式 focus-visible 环（`--gaea-glow`）；令牌纪律零硬编码
  色值（color-mix 派生，语义色双回退 `var(--color-success, var(--md-sys-color-success))`）。
