# v4.494.0 · 阶段十 10.3 session-reference（2026-10-15）

> dsh 021 P2-B 取道。原案：跨会话 @提及 = host 文件发现 + 结构化引用请求 + 快照注入（label 取最新标题）。

## 语法与语义

```
@会话:<标题或文件名关键词>    （英文同义 @session:<关键词>）
```

- **显式前缀**避免与既有 `@<路径>` 文件引用语义撞车；classifyRef 中前缀优先于 exists 检查（无前缀的未知 token 不误判为会话）。
- 匹配：标题注册表（`.titles.json`）包含匹配优先 → 文件名包含次之（大小写不敏感）；**唯一命中才解析**——多命中列出候选（宁缺勿误，让作者精确化），零命中人可读报错。

## 快照注入（结构化投影，非原始 JSONL）

会话文件是原始事件日志 JSONL，直接注入是乱象。投影口径与 sessionquery 的 indexableContent 一致：

- 头部：`<referenced-session title="最新标题">`（titles 注册表——dsh 原案「label 取最新标题」）；
- `user_message` 全文 / `assistant_message` 512 rune 截断 / 其余 kind（tool_result 等）折叠不投影；
- 尾部 32KB 截断并注明（快照是视图不是全文，原文随时重新精确引用）。

## 坑（测试抓）

**List 双文件形态**：会话要被 `session.List` 收录需**主 .jsonl 用旧格式行**（role/content——previewSession 按它数轮次，turns=0 的会话被跳过）；事件日志在 **`.gaea-log.jsonl`**（kind/payload——ReadEntriesFor 优先读它投影）。测试种子须写双文件。另：resolveSessionRef 直接调用时 token 带前导 `@`（sessionRefKey 需剥）——wired 路径经 parseRefTokens 已剥，两路径不一致被测试抓。
