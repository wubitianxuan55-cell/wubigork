# gaea v2.10.1「开工前 · 交付收尾 · 记忆自进化」

发布日期：2026-08-10 ｜ 产物：[gaea-v2.10.1.exe](gaea-v2.10.1.exe)（Windows x64，约 40MB）

## 开工前（任务发出后、AI 动手前）

- **开工前计划卡片**：非简单任务先生成开工计划（步骤 + 将读资料 + 将用工具 + 待确认点），
  以卡片询问「确认执行 / 先调整」，确认才执行；`auto_plan` 可在配置关闭
- **@ 文件引用增强**：跨目录搜索工作区文件 + 最近使用文件优先 + 扩展名徽标
- **工作区资料概览**：右侧「资料」面板按 文档/表格/演示/PDF 分组，最新在前，
  一键 @ 引用为对话上下文

## 交付收尾（成果出来后）

- 对话内所有文件引用可点击预览（mdast 插件识别绝对/相对/裸文件名；代码块/公式不误判）
- 助手消息尾部「交付文件」卡片：缩略图/图标 + 文件名 + 复制路径 / 预览 / 打开 / 定位
- 右侧「会话产物」面板：本次会话交付文件清单 + 溯源跳转到生成它的消息
- 预览内编辑 docx/xlsx 后自动标「已更新」并刷新文件树
- 粘贴表格即数据：CSV/TSV 自动识别，发送时转 Markdown 表格

## 记忆自进化

- **自动做梦**：轮次成功后后台归纳对话 → 提炼稳定事实/偏好/踩坑笔记写入长期记忆
  （按 name 去重、宁缺毋滥、失败静默），整理结果聊天内通知
