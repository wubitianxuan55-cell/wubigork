# gaea v2.18.0「数据与成本纵深·首轮」发布说明（2026-08-14）

> 长期规划阶段 3（docs/superpowers/plans/2026-08-14-gaea长期规划-herdsman底座加固与工程门禁.md）：
> D3-1 ~ D3-3 首轮落地——让本地向量索引、调用分流与模型测评「看得见、用得上」。

## 一、D3-1 · 持久化向量索引（跨库统一检索补齐「资料」）

- **跨库统一语义检索并入工作区资料**：`GaeaSemanticSearch` 命中范围从 成本/知识/办公记忆
  扩展为 成本/知识/办公记忆/**文件**（kind=file）。文件向量由文件索引 cron（每 10 分钟
  增量重建）维护，检索时直接读持久化向量、不再扫描工作区。
- **索引状态可见**：新增 `GaeaSemanticIndexStatus`（semantic_vectors 各 kind 向量条数），
  `semantic.Store.Counts()`；记忆中枢检索可感知索引健康度（embedding 未配置/存储不可用
  给出明确提示）。
- 数据契约不变：向量持久化在 Hephaestus.db `semantic_vectors`（SchemaV5），Ensure 增量
  向量化（内容变更自动重嵌），Search 只嵌 query。

## 二、D3-2 · 分流统计面板（本地 vs 云端节省对比）

- 后端 `GaeaUsageOverview`：打通两套记录——
  - **云端**：经 gaea 调用云端引擎（xai/deepseek/opencode-*）的次数/token/**估算费用**
    （复用模型中心既有定价表与 USD→CNY 折算）；
  - **本地**：herdsman `model_stats/events.jsonl` 全量遥测（含 herdsman UI 直接调用，
    不重复计 gaea 侧 herdsman 记录）+ 其他本地引擎（ollama/cosyvoice）；
  - **节省**：参考单价取用户云端实际混合单价（总费用/总 token；无云端用量回退
    deepseek-v4-flash 官价 ¥1.5/MTok），`本地 token × 参考单价` = 若走云端的等价花费。
- 前端：模型中心「调用统计」顶部新增「本地 vs 云端 · 节省对比」卡（云端费用 / 本地 token /
  已节省金额 + 口径说明）。

## 三、D3-3 · 测评产品化（模型中心「受控测评」）

- 复用 herdsman `/api/benchmarks` 异步测评（多模型 × 变体 × 上下文长度 × 并发，逐 case
  采集 TTFT/TPS/token、二次请求缓存命中），后端 `GaeaBenchmarkList/Start/Detail/Export`：
  - 发起（POST）契约对齐 runs.json config（model_names/variants/context_sizes/
    cache_reuse_mode/warmup/repeat/concurrency/request）；
  - 明细与报告从 `model_benchmark/runs.json` 读取（含逐 case ttft avg/p95、token、
    cached_tokens、二次耗时），`GaeaBenchmarkExport` 导出中文 Markdown 报告。
- 前端新增模型中心「受控测评」分类：任务预设（蒸馏自 2026-08-12 的 120 组对照测评方法学，
  常识/公文/翻译/代码/逻辑/数学/摘要/JSON/创意/长文 10 项）、自定义提示词、温度/max_tokens、
  上下文 4K~32K（覆盖长上下文）、并发 1/2/4（覆盖并发专项）、历史运行列表（KPI：用例/
  TPS/TTFT/耗时）+ 一键导出报告；运行中每 8s 轮询刷新。
- **真实端到端验证**：对运行中的 herdsman 发起单模型小测评（POST 202 + id），约 40s 完成
  （succeeded，TTFT 119ms、60 token），runs.json 正确写入。
