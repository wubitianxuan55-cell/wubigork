## 权限升级请求（自 v3.7.0「下一阶段候选」挂账，本次独立落地）

- 新工具 `request_permission{tool, subject?, reason}`：reason 必填、headless
  Never-Ask 降级、六形态结果文本；PermissionRequester 经 ctx 盖章（仿 Asker
  纪律）；boot 直注 ask 同路径 = work/play 均可见（shared 元工具语义）。
- **硬纪律三闸**：deny 规则硬拒先行（不弹卡）；hardAsk 拒绝升级（yolo 同
  拒）；批准只写 grantedRules 会话 glob 规则表——真实调用仍走 Gate.Check
  短路口，规则满足才自然放行，**不绕闸门**。
- 五决策接线：allow_session/allow_once=会话规则、persist_allow=走
  PersistAllowRule 持久化、deny/abort=拒绝继续、timeout=拒绝+Notice。
- 审批卡 request 形态：标题「模型申请放开权限」+ 规则串 tool(subject) +
  reason 原文块（缺失显式标注）；普通审批卡逐字节不变；三语 +5 键。
- 关键机制补全：granted map 原为精确 key，glob 规则（bash(go build*)）经
  会话规则表（permission.RuleMatches，与策略文件同语义）才可匹配后续真实
  调用——TestRequestPermissionGrantFeedsNormalGate 钉死「覆盖→免弹卡放行；
  不覆盖→照常弹卡」。零新增 Wails 绑定。

## 已知竞态/flake 全治理（v3.8.0/v3.9.0 挂账清账）

- **Cancel 被 succeeded 吞掉的窄窗竞态（真生产 bug）**：worker 收尾
  userCancel 判定后读 ctx.Err() 与 Cancel 的 cancel() 之间的窗口，handler
  返回 nil 的任务落入 succeeded 分支——违背「用户取消必须胜过 succeeded」
  设计意图（Cancel 返回 nil 承诺终态 cancelled）。修复：userCancel 单独
  即取消（Close 中断路径不受影响）。×10 压力绿；此前两代理 ×3 绿/稳定失败
  的双向矛盾即此竞态间歇性实证。
- **stubGate 竞态（测试基建，v3.8.0 挂账）**：测试桩 checked 切片被并行
  批次（最多 8 路）+ 流式预执行 goroutine 并发 append → 加锁 + 持锁快照。
- **filewatch 风暴测试负载抖动（v4.8.1 门禁实测）**：根因=高负载下 fsnotify
  投递跨过 100ms 合批窗把单批劈多批（Full=单批>50 语义下合法地永不 Full）。
  修复：合批窗 1s（10 倍余量）+「排空到 Full 或 deadline」条件等待。
  本次全量门禁实战首验通过。
- **ProgrammingPage 负载 flake（v3.9.0 挂账）**：按 TrajectoryView 先例
  显式 5s 超时 28 处；负载下 ×3 全绿。
- Cancel flake 挂账核查：v3.2.0 条件原子 UPDATE 已修的部分确认保留，本次
  补的是其上层的收尾判定窗（上条）。

## Realtime S2 事件环骨架（方案 a，设计 docs/gaea-v482-realtime-s2-design.md）

- **16k→24kHz 协议硬伤根治**：OpenAI Realtime pcm16=24kHz vs gaea 全链路
  16k——Resample16kTo24k 定点线性插值纯函数（8 例保真测试，误差 0.0077%）。
- **事件常量 +7**（response.done/.created、audio_transcript.delta/.done、
  input_audio_transcription.completed/.failed、buffer.committed），解析
  骨架零改动只扩白名单；TurnControl 可选接口（commit/clear/create/cancel）
  不进主接口——断言失败 fail-closed 回拼接管线。
- **voice_manager 事件泵**：realtime 分支旁路本地 VAD/RMS 打断（防双源
  冲突，以服务端 speech_started 为准）；barge-in 三联（停播 +
  CancelResponse + ClearBuffer）；delta 聚合 → done 冲洗 24k WAV → 复用
  前端播放环零改动；PTT 释放映射 Commit。
- **前端死门打通**：browserASRAvailable 门（WebView2 恒有 Web Speech API
  → PCM 从未进后端）在 realtime 模式强制推送旁路 + 抑制本地识别防双输入。
- **五重降级护栏**：未注入=逐字节老路（双层守护测试）、TurnControl 断言
  失败拒绝激活、Dial 失败本轮回退、协议 error 降级、断开收口。31 新测试
  + 既有 41 voice/realtime 用例全绿 = 拼接管线零回归。
- **真机欠账（如实记账）**：端到端延迟/AEC 回声误打断/打断手感/真实格式
  怪癖/gpt-realtime instructions 落位——需真 key 真机验证；-race 本机无
  gcc 未跑（CI ubuntu 为最终裁决）。
