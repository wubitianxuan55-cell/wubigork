## 🆕 新增模块（6 个 Go 文件）

### 1. 用户活动检测 `user_activity.go`
- **8 类关键词分类**: 出游/学习/工作/娱乐/社交/健康/休息/日常
- **三时态判断**: future/present/past（基于时间标记词）
- **工作日启发式**: 工作日 9-18 点默认推断"工作"
- **游戏模式优先**: gameActive=true → 直接判定"娱乐·进行中"

### 2. 用户存在检测 `user_presence.go`
- **4 级参与度**: active_now(≤20分) / recently_active(≤120分) / idle(≤480分) / likely_away
- **消息片段加载**: 最近 5 条用户消息（每条≤160字）
- **与 WorkingMemory 联动**: 从最近交换中提取用户文本

### 3. 前台窗口感知 `foreground_state.go`
- **3 种专业场景**: meeting(Zoom/Teams/腾讯会议) / presentation(PPT/Keynote) / focus(专注模式)
- **健康抑制**: 会议/演示/专注场景自动抑制健康提醒
- **全局快照**: 进程级单例，支持启用/禁用轮询

### 4. 运行时上下文构建器 `runtime_context.go`
- **统一入口**: BuildRuntimeContext 聚合用户/陪伴/时间/活动
- **6 段时段划分**: morning/forenoon/afternoon/evening/night/late_night
- **陪伴在场**: CompanionRuntimeContext（active/quiet/sleeping）

### 5. 运行时提示格式化 `runtime_hints.go`
- **FormatRuntimeContextHint**: 完整运行时上下文 → LLM 可注入说明块
- **参与度感知回复**: active_now → 提示在线 / idle → 提示暂离
- **用户最近消息**: 内含最近 5 条用户发言供 LLM 参考

### 6. 习惯→活动推断 `ctx_habits.go`
- **CTX-B2 最小化**: 从程序化习惯推断工作/休息/日常
- **正则匹配**: workHabitRE / restHabitRE 匹配已建立习惯
- **高置信度回退**: 习惯推断(0.72-0.78) > 关键词推断时使用习惯结果
