## 一、本刀内容

### 1. 锚点键（aoa.ts，事件业务身份）
- `AoaNode.anchor`：START→"S"、END→"T"、其余=全部成员键（`end:<taskId>`/`start:<taskId>`）字典序最小者——跨拓扑变更稳定（改工期/名称/开工日全保；增任务新事件自动落位；删任务失配清理；合并翻转代表多存活），稳定性分析 5 例单测钉死。

### 2. 纯函数层（aoaLayout.ts，新）
- `snapPt`：半格吸附（55×37），拖拽中预览即吸附位（所见即所得）。
- `normalizeAoaLayout`：结构归一（坏形键丢弃/坐标取整/键数上限 5000）。
- `applyPins`：命中锚点→手动位，未命中→自动位（混合共存，返回新 graph）。
- `prunePins`：提交时以当前图锚点集剪枝失配键（pins 不膨胀）。

### 3. 持久化（TS↔Go schema 镜像）
- `SchedProject.aoaLayout?: { pins: Record<string,{x,y}> }`——整数像素，旧文件零迁移（无字段=自动布局）。
- Go `AoaLayout{Pins map[string]AoaPt}` + `*AoaLayout omitempty`；Validate 结构 pass-through（坐标 0~100000、键数上限、空键拒绝）——**镜像铁律约束引擎口径，布局数据不属引擎口径，Go 维持无 aoa.go**（设计 §4.4 语义边界）。
- 保存链路：setAoaPins → project → 防抖 800ms 自动保存 → agent 回读，殊途同归。

### 4. AoaView 交互（对齐横道刀9 纪律）
- 双模式 Segmented「布局：自动/手动」+ 手动态「重置布局」；开关是视图态（mode 不入文件），默认 pins 非空→手动；切自动不删 pins（临时看时标）。
- 拖拽布点：window 监听三件套、节点跟随+吸附坐标 tip、未移动不提交、Esc 取消；**自动模式拖拽=自动转手动**（「不骗人」先例）；提交即剪枝失配键。
- 手动模式明示「自由坐标，时间参数不受影响」（时间参数仍全量显示于节点上下）。

### 5. 测试（+15）
- aoaLayout.test.ts 9 例：锚点稳定性 5（链式合并/菱形/改字段全保/增任务保位/删任务幸存锚点稳定）+ snapPt/normalize/applyPins/prunePins 4。
- AoaView.test.tsx 6 例：拖拽提交+自动转手动/未移动无操作/Esc 取消/混合落位（pins 非空默认手动）/重置布局/提交剪枝。
