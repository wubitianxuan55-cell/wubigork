## 背景

v4.439 把成人向口径带进了正文/重写/收敛/计划/场景五段，但编制链还有两段上游
没接：**大纲生成**（章级事件在哪排亲密戏——大纲层不排，正文层只能即兴）与
**角色生成**（欲望线/关系张力的种子——角色卡没有欲望线素材，直白档的亲密戏
就成了无源之水）。本刀补齐后成人向口径贯通
大纲→计划→正文→重写→收敛→场景全链。

## 落地

### maturecraft 包抽取（文本单一源）
工艺文本自 internal/app 抽为 `internal/maturecraft`（正文向 Craft / 计划向 Plan /
大纲向 Outline / 角色向 Character 四组纯函数 + 档位归一），app / outline /
character 三个 agent 共用；app 七处调用点换装，**文本逐字节未动，行为零变化**。

### 大纲链五路注入（新增 OutlineSection）
纪律内容：**欲望线是一等叙事线**（与主线/权力线并行，章节要点显式写出每章关系
位移：靠近/越界/退缩/占有/破裂，不留到正文即兴）；亲密章节要点带节拍与功能
（张力起点→位移落点，禁「感情升温」）；**张力要有对手性**（障碍：旧怨/身份/
权力/第三者/自我——无障碍的靠近不构成节点）；整章让位给亲密戏须同时推主线。

- Continue → `outline-continue` 槽
- ExpandNode → `outline-expand` 槽
- Chat / ChatNode（对话式大纲助手同口径）→ `outline-chat` / `outline-chat-node` 槽
- GenerateOutlineWithDialogue（新书向导，内联 system）→ writerSystem 追加

### 角色链两路注入（新增 CharacterSection）
纪律内容：主要角色背景与动机可含欲望线与亲密张力来源（禁忌/旧情/占有/亏欠，
为亲密戏供材）；关系条目标注张力类型与边界；硬线：不生成涉未成年的欲望设定、
不生成美化胁迫的关系。

- GenerateCharacters → `character-generate-batch` 槽
- GenerateSingleCharacter → `character-generate-single` 槽
- **全局角色库级调用无书级档位，槽天然零渲染**——同模板双消费方（项目级
  character_handler 注入 / 库级 charlib_gen_handler 不传键）无串扰。

6 个模板 JSON 同步加 `mature_craft` P1 槽（order=90）；空档位零渲染，非成人向
项目逐字节零变化。
