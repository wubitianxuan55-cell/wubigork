# v4.26.0「对话流式重造 · 对齐 Codex」

> 发布日期：2026-09-01 ｜ tag：`v4.26.0` ｜ 基线：v4.25.0 ｜ 绑定面 549 → 550（+1：GaeaResyncEvents 事件序号防线补拉）

## 背景与根因

用户报告：**「办公板块的对话，每次输入完等半天对话窗口都没有反应，但轨迹面板又在工作中」**。
主代理探查（事件流逐环节定位）+ 子代理调研（Codex/Claude Code/Cursor 流式工作态，
`docs/research-2026-09-01/codex-streaming-ux.md`），根因六连：

1. **子代理长跑静默**：task 工具的 subSink 有意丢弃子代理 Text/Reasoning
   （task.go 原 :598-621），主窗只挂一张 task 运行卡，子代理文字只进右栏分工面板。
2. **预处理窗零事件**：GaeaSend → GaeaInit/ResolveRefs/ProcessFirstTurn/记忆
   Compose（controller.go :418-501）→ agent_run.go 才 Emit TurnStarted——数秒到
   数十秒无任何事件。
3. **Wails 事件流吞件**：gaea-event 密集到达丢件（store.ts 旧注释认账，仅
   turn_done 有兜底）；轨迹面板读磁盘日志（GaeaTrajectory）不受害——「轨迹在动、
   对话窗静默」的直接解释。
4. **Retrying 隐身**：agent_run 发 Retrying 但 gaea_handler 转译表无映射→前端
   按 unknown 丢弃。
5. **phase 空 seam**：事件常量/日志/转译/前端 reducer 全就绪，全仓零发射点。
6. **TTFT 静默**：turn_started 不产生 item、ProcessCard 需 processItems>0，
   首 token 前唯一反馈是顶部细条「准备中」。

## 交付明细（三并行子代理线 + 主代理集成）

### ① 工作态头部行（WorkHeader，渲染线）

- turn 激活期常驻：spinner + 当前阶段文本 + 已用时（1s tick）+ 步数（与
  ProcessCard 同口径）；**items 为空也渲染**——从发送那一帧起窗口不空。
- 完成后转 Codex 式耗时行「已完成 · 用时 1m23s · 7 步」（对标 Codex IDE
  "Worked for 6m 53s"）；锚定最后一轮用户消息之后，自订 store 不依赖父级重渲染。
- StreamingIndicator 收敛为兜底（「连接中…」≤5s →「仍在等待事件… 可切轨迹
  面板查看」>5s）。

### ② 后端事件接线（Go 线）

- **预处理阶段 phase 事件**（发射点选 controller/agent 既有 sink，最小侵入）：
  正在启动引擎（wire-only，会话日志尚不存在）/ 正在解析 @引用与附件 / 正在装配
  首轮上下文 / 正在检索记忆 / 思考中（每次模型调用前）；转发层 200ms 同文案节流。
- **Retrying/compaction 转译**：统一转成 phase（「正在重试 (n/m)」「正在压缩
  上下文…」「压缩完成」），磁盘日志格式不变（EventLogSink 在上游按原 kind 落盘）。
- **phase 收编渲染**：phase 进过程卡，最新一条运行中进 WorkHeader 头部防重复。

### ③ 子代理活动回投主回合（Codex 2026-08 "Report completed sub-agent activity
on parent turns" 同款）

- 新事件 kind `subagent_message`：task 子代理**完成时**把最终答复原文回投父
  sink（ref=sa_ 引用、parentId=父 task 工具调用）；中途进度不回投（并行/重试
  防刷屏，父模型本就只消费最终答复，模型上下文零影响）。
- 前端：message 透传 `subagentRef`（更新分支整体替换防徽标黏连），assistant
  消息带「子代理」徽标；task 卡 running 时实时 lastText/lastTool 单行预览
  （App 5s 轮询 GaeaSubagentRuns 注入 taskActivity；派发期 args 无 ref，空 ref
  回退唯一 running 分工）+ 完成卡结果摘要（此前恒为空串）。

### ④ 事件序号防线（seq + 增量补拉，根治吞件）

- gaea-event payload 顶层全量带 `seq`（转发层原子递增，per 会话；新建/恢复/
  分叉/rewind 归零，前端五处会话切换点同步 reset）。
- 跳号检测（首件不判缺/乱序忽略/gap≥1 触发）→ 新绑定 `GaeaResyncEvents(afterSeq)`
  从当前会话磁盘日志折叠对话项全量快照 `{seq, items}`（user/assistant/tool/notice
  四类，未知 kind 容错跳过；流式 delta 已合并为单 assistant 条目）→ 前端整体
  替换 items（running/turnActive/approval/ask 不动；缺口期间本地流式的最后一条
  assistant 自动续上 streaming 不劈气泡；坏快照静默保底）。
- 频控：5s 冷却门 + 在途去重；未挂 fetcher 整条防线旁路（现网行为不变）。
- **golden 逐字节不变**（TestGaeaHistoryGolden/Replica/EventLogRoundTrip 原样
  通过）；旧日志无 subagent_message 行，读端跳过未知 kind。

### ⑤ 重复工具折叠 + 杂项

- 过程卡内连续同类非 running 工具折叠为「已调用 X · N 次」（Claude Code 式），
  点开展开；run 含 running 则不折叠。
- 顺带修复：`weixin_reminder_test.go` 预置时间炸弹（固定基准时刻过期必炸），
  改取真实时钟 +1h。
