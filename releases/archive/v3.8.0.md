# gaea v3.8.0 发布说明

**版本**：v3.8.0「双空间内核 · 工位/乐园 + 质量地基」｜2026-08-29
**一句话**：工作与娱乐隔离（双空间）从规划到内核落地——会话/记忆/任务/产物/模型/工具/权限/护栏全按空间装配、互不干扰；同步完成审计 P0/P1 质量地基与长期规划定稿。

## 一、双空间内核（阶段 1，S1.1-S1.5）

### S1.1 空间维度（`5c24d16` `0722aeb` `76f565e` `5c9fc4e`）
- **SchemaV14**：facts/tasks 加 `space_id`（`NOT NULL DEFAULT 'work'` 旧数据自动回填）+ 空间索引；`UNIQUE(project,name)` 未动。
- **会话目录分区**：`sessions/work|play/`；旧平铺文件按 work 兼容读取（零搬迁）；事件日志/checkpoint/分支 meta 带 space 自描述（旧行降级 work，恢复时空间不一致 fail-closed 拒绝）；`space.mode` 开关仿 `log_format` 三件套可整体回退。
- **子代理空间继承**：ctx 注入 + 后台任务补注 + fail-closed 防穿越（前瞻 meta 校验）。
- **产物路径分区**：`.gaea/play/exports`（work 恒现状路径）；`GaeaSpaceList/Active/Activate` 挂 CoreB（绑定面 499→502）。

### S1.2 记忆空间隔离器（`819d7ff` `f0187a2` `53d621d`）——「不干扰」红线最硬实现
- **写侧盖章**：remember 工具、dream 管线（指纹 `sha256(space+"\0"+input)` 防跨空间 no-op 误判）、显式记忆建议、审计 DreamAuditEntry 加 Space 列；play 会话 dream 只写 play 记忆、notes 不写 work AGENTS.md。
- **读端隔离**：GetInSpace/TouchInSpace、citations 限定（跨空间键=未知键静默）、`GaeaUnifiedSearch` scope 参数（brain work 滤右脑 / semantic 只滤最终 hits 防 Stale 误删 / keyword+files 共享面 / wssearch 噪音补 play exports）。
- **前端**：hub 搜索 + 工作区面板 scope 切换（默认当前空间 + 显式「全部」）。

### S1.3 模型 profile + 工具标签（`f8612d0`）
- `[space_profiles.<space>]` 配置段（7 功能域键）；桌面 play 域走既有 bridge_feature（零新增绑定）。
- 工具装配期物理过滤：work 33 / play 1（image_gen）/ shared 13 + MCP 默认 shared（spec 层滤热插拔）；不改 executeOne，子代理 ActiveSchemas 对齐不破坏。

### S1.4 任务分账（`5ccaa7a`）

## 二、质量地基（阶段 0）

- **并发/安全**：S0.1 回合级 map 并发加固（turnMu，修复"两个 read_file 并行即崩"）；S0.2 Registry RWMutex + suspended 幽灵名；S0.3 gate atomic.Pointer；S0.4 retry_until 走统一门控（堵审批绕过 shell）；CI 新增 `-race` 并发门禁（ubuntu job）。
- **文件编辑脊柱**：S0.6 edit_file 工具层——grep / edit_file / multi_edit / edit_lines / move_file 五工具（编码保真 GB18030/UTF-16、原子写、compact schema、名单全对齐：stale 守卫/循环检测/缓存失效/证据台账自动生效）。
- **隔离岛**：knowledge TF-IDF 索引缓存（写路径失效+指纹兜底）；office 原子写；secure 非 Windows AES-GCM（dpapi: 外层协议兼容）；tasks 输出 LRU 淘汰。
