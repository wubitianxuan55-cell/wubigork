## 内容

- **多级撤消/重做（store.ts）**：快照式历史（past/future 上限 50，不入持久化——撤销史是会话态）；**文本编辑合并窗口**——同 (kind,id) 连续编辑 800ms 内只压一次栈（打字/调数不逐键入史，undo 一次回整段编辑前）；整体替换（导入/示例/清空）强制压栈；外部回读/水合走 setState 直改天然不入史；关键判定 minFloat 相对比较不受影响。工具栏撤销/重做按钮（禁用态随历史）+ **Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z**（输入控件聚焦时不抢）。
- **任务筛选（ganttFilter.ts 纯函数 + GanttView）**：全部/关键/手动三模 + 名称文本包含（不区分大小写）**两遍法**——分组名命中=强制展示整支（树搜索直觉），否则分组行任一直接子孙可见才保留（分组不是关键/手动，不被叶条件误杀）；返回可见行**原索引**（行号列仍按全表序）；表格/条形/依赖线/前锋线四者同源联动（依赖线两端均可见才画，y 按可见行序）；空结果出诚实空态。仅横道参与（网络图=逻辑图语义，不筛选）。
- **行右键菜单（GanttView + antd Dropdown contextMenu）**：表格行与条形行都可右键——在下方添加任务/添加分组/设为(取消)里程碑（仅叶）/删除；删除有 undo 兜底。
- **进度编辑入口（ganttCols +1）**：15 列（+进度 56px，可隐藏）；叶任务 InputNumber 0-100，group 留空（汇总唯一口径=子孙求和）；条形进度覆盖与前锋线按 progress 绘制（既有）；**缺省隐藏**（chatPrefs 默认 ganttHide=['progress']，列菜单可开；存量数据无 ganttHide 字段时回落缺省隐藏集）。
