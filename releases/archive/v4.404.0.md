## 病根

质量读数，一致性闭环缺读取侧。

## 落地

1. **文字锚点方案 v1**：视觉 LLM 拿图对照角色文字设定（Appearance/Figure）
   打分——复用既有 vision.RecognizeImage 单图链路零改动；无外观字段降级为
   通用形象评审仍可用。
2. **后端**：`CharacterScoreConsistency(chJSON, image)`——image 收本地路径
   或 data URL（data URL 经临时文件走既有链，用后即删）；远端 URL 如实拒绝；
   返回规范化 `{"score":0-100,"summary","issues"}`；解析围栏容错+score 钳位+
   issues 清洗；坏回复报错带原始返回前 200 字符。视觉调用走 seam 可注入。
3. **前端**：参考图列表每张图加「评分」钮→Modal.info 呈现分数+总评+不一致
   点；**score<60 提示补参考**（「建议补充不同角度/光照的参考图后再生成」）
   ——评分驱动补参考 v1；评分单飞（进行中禁其他评分钮）。
