# v4.27.0「右侧面板对齐 Codex · 子代理对话实时下钻 / 对话与上下文完善」

## 主线

延续 v4.26「对齐 Codex」方向，本轮把右侧面板、对话输出、子代理交互、上下文标签
四个面整体打磨到 Codex 式体验。纯前端改动（Go 零变更、绑定面零变更）；规划中
的 v4.27「浏览器与版本」（A2 观察窗+B1 版本时间线+B2 pptx+C2/C3）顺延至后续版本。

## 一、右侧面板（文件工作台）

- **点文件后预览占满整个右栏**：此前文件树点开只在右栏顶部 3/5 弹预览、底部
  2/5 文件树常驻（预览被挤压成小窗）；现在编辑器/预览占满全高，文件树收敛为
  头部「文件」按钮切换的 260px 侧栏（打开第一个文件自动收起，浏览时点开）。
- **宽度放开**：右栏上限 720 → 1600，拖拽按「视口 − 侧栏 − 400 对话区」动态
  钳制（聊天区永不消失）；首次打开文件自动抬升到 560px 舒适宽度（不覆盖已拖宽
  偏好，写全局键跨会话跟随）。
- **编辑器 tab 文件类型图标**：docx 蓝/xlsx 绿/pptx 橙/pdf 红/图片紫/代码灰，
  与文件树同一套图标语言（新共享助手 `lib/fileIcon.tsx`，树/tab 单源一致）。
- **树内高亮当前编辑文件**：编辑器激活 tab 优先、主区预览兜底。
- 内嵌 markdown 预览限 860px 居中（宽面板下正文可读）。

## 二、右侧面板标签扁平化

- 删除「资料」「成本库」两个面板（组件 + 测试移除，git 历史可恢复）。
- 取消两级 Tab（分组 + 二级小标签）：剩余面板平铺为一级 **文件/产物/变更/任务/
  分工**；运行计数角标按任务/分工两个面板下发（任一激活视为已读）。
- 旧持久化值（materials/cost）经 `isWorkspaceTabId` 自动收敛回默认「文件」，
  不报错不崩。

## 三、对话输出

- **用户消息去气泡**：右对齐纯文本（此前实现与「无气泡」注释相悖，带背景块）。
- **回合分隔线**：第 2 轮起用户消息上方加细分隔线 + 「第 N 轮」小标（三语文案）。
- **助手消息复制**：正文下方常驻「复制」→ 剪贴板 + 「已复制」反馈；流式中不渲染。
- **编辑类工具 diffstat 芯片**：`edit_file`/`multi_edit` 行内 `+N−N`（绿增红删），
  multi_edit 摘要保留「N 处修改」。

## 四、子代理对话实时下钻（对齐 Codex 点击子代理）

- 分工面板树中**点击子代理 → 全面板对话视图**（`SubagentThread`，替代旧树内
  10px 窄卡）：头部返回/任务标题/状态徽标/模型/消息数/手动刷新。
- 消息流 Codex 式：system 弱化居中 / user 右对齐 / assistant 正文 + 可折叠
  「思考」块（运行中最后一段带呼吸点）/ tool 调用与结果小卡。
- **实时显示**：运行中每 3s 轮询（页面不可见门控空转）+ 事件驱动刷新
  （turn_done 立即、运行中事件节流）；running→done 自动收尾刷新并停轮询；
  运行中自动跟随底部 + 底部「实时刷新中…」提示。
- AgentTree 节点点击转 `onOpenThread` 回调（root 不响应）；状态由分工轮询
  实时派生（进行中/已完成/失败）。

## 五、上下文标签完善

- **总览头部**：水位条分色（正常主色 / ≥70% 琥珀 / ≥90% 红）+ 已用/窗口 +
  缓存命中率 + 预估费用 + 刷新按钮 + 运行中状态点；接近上限给出压缩/新建建议。
- 「当前上下文」构成卡同水位警示；**空态引导**替代全零卡片。
- **文件活动行可点击** → 右侧打开该文件预览（目录行不可点）。
- 步骤详情补「占窗口 N%」；**趋势图悬停柱显示六分类构成详情条**（不用点开）。
