## 落地

- **类型与确定性 ID**（新 `internal/types/story_memory.go`）：`StoryMemory` 字段子集对齐 §12.1（ID/ChapterNum/ChapterFile/Type/Title/Content/Importance/IsForeshadow/RelatedCharacters/Tags/TextLen/CreatedAt）——**无 Position 字段**（MuMu 的 chapter_position 依赖 keyword 偏移标注〔t4-C4 未落地〕，不引入恒 0 死字段，§5.1 D11 原则）。`StoryMemoryID` = `<MMM>-<type>-<ordinal>` 确定性编排（§12.2），同章重提取产出同 ID=幂等前提。五类类型常量 + is_foreshadow 三值（0 普通/1 埋下/2 回收，MuMu :47 口径）。
- **提取规则表**（新 `internal/analysis/story_memory.go`，纯函数零 IO，`ExtractStoryMemories`）：六类规则逐条对齐 MuMu `plot_analyzer.py:305-486`——
  1. `chapter_summary` 必有一条：summary → 前 3 条推进点拼接 → 正文前 300 字（三级回退链，全空跳过不造数），固定 importance **0.6**；
  2. `hook`：strength **≥6** 入库，importance=min(strength/10,1)；
  3. `foreshadow`：**全部**入库（planted=1/resolved=2），strength 缺省语义 5（与 t1-P2 埋入同步同口径）；
  4. `plot_point`：importance **≥0.6** 入库，原样；
  5. `character_event`：每个角色差分一条（状态迁移+心理变化+关键事件），固定 **0.7**，related_characters=[角色名]；
  6. `conflict`：level **≥7** 记为 plot_point 类，importance=min(level/10,1)。
  正文兜底为**纯截断**（MuMu content[:300] 是存储截断，展示省略号不入记忆正文）。门槛常量唯一声明，改门槛=改常量。
- **按章落盘**（`project.ReadChapterMemories/WriteChapterMemories`）：`memories/MMM-<n>-memory.json` 每章独立文件，**整章替换写**=重分析幂等且天然规避 MuMu D1「重分析不清旧数据」（文件级先删后写同批完成）；空 items=删除该章记忆文件（重分析后无合格记忆不留陈旧档）；缺文件=空文件正常态。
- **接线**（`Analyze` 主链）：persistAnalysisV2 之后 `persistStoryMemories`（容错注入：失败只记日志不影响分析返回；成功记 slog「章节记忆已登记」）。
