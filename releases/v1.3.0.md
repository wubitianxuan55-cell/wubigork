## 五批未来感 UI 改造

### 1. 设计系统（三令牌 + 未来感 CSS 层）
- `appStore.ts` 12 套主题新增 `glow`（霓虹光晕）/ `glassBg`（玻璃表面）/ `auroraBg`（深空星云渐变背景）三令牌，`App.tsx` 注入 CSS 变量
- `index.css` 未来感层（+307 行）：`.gaea-bg` 背景层（赛博网格 + 星点 + 漂浮光球）、`.md-glass` 玻璃拟态、`.neon-card` 霓虹渐变描边、`.live-dot` 发光状态点、`.scanline-top` 流光扫描线、霓虹滚动条/选区

### 2. 框架层
- 顶栏：玻璃拟态 Header + logo 光晕 + antd Menu 霓虹选中态 + 品牌字霓虹
- AI 中枢首页（ModuleLauncher）：玻璃状态条「AI 中枢在线」+ 真实模型胶囊 + 8 张霓虹渐变描边卡片
- 模态框全局玻璃化（blur 28 + saturate 160）；主题色块升级发光胶囊；页面切换过渡 + 霓虹加载态
- 弹层全局玻璃化（Dropdown/Popover/Select/Tooltip/Picker）；页内 Tabs 霓虹选中态；AI 控制台标题霓虹

### 3. 聊天界面（灵魂界面）
- AI 消息玻璃气泡 + 3px 霓虹左缘身份线；用户消息主题渐变实色气泡 + 发光
- 输入栏玻璃拟态 + 聚焦霓虹描边；发送按钮霓虹 glow；话题侧栏玻璃化

### 4. AI 真实感 + 绘梦
- 首页 AI 状态条接入真实模型名（activeModel prop）；底栏状态条玻璃 + 霓虹进度条 + 发光状态点
- 绘梦控制面板玻璃化；结果画廊卡片 hover 霓虹描边发光

### 5. 设置中心（整合全部设置参数）
- `SettingsPage` 从 135 行简陋页重写为 7 分组 Tabs 一站式设置中心
- 新增 `src/components/settings/`：AppearancePanel（主题发光选择器+明暗）/ WorkspacePanel（小说+图片目录+Skill）/ EnginePanel（激活模型+推理强度+引擎编辑）/ VoicePanel（语音开关/音色/模式/阈值+健康检测）/ ImageGenPanel（绘梦后端/URL/目录）/ OfficePanel（办公模型/Provider/Agent 摘要+跳转）/ SystemPanel（配置信息+v4 迁移）
- `api/settings.ts` 补 5 个封装（getActiveModel/voiceHealth/getVoiceSettings/applyVoiceSettings/gaeaSettings）
- 设置页隐藏 AI 控制台（MainLayout 两处条件排除 settings）
