# v4.401.0 — 设定卡模板矩阵 + 多参考锚定（T2 角色资产 v2 第二刀）

> 2026-09-23 发布。v4.400 首刀观察池头名（多姿势/分张）+ qedit 三图槽既有
> 能力的自然消费（多参考）。规格：`进度计划/gaea-char-sheet-v2-20260923.md`。
> 绑定面 **716 零变更**（CharacterGenerateSheet 签名扩展 chJSON+variant）。

## 病根

首刀两缺口：①只出「三视图并排」一张模板——并排每个视图只有约 1/3 分辨率，
单视图模板每张完整分辨率可单独作参考；站姿以外（坐/动态）无资产覆盖。
②qedit 工作流三图槽（image1/2/3）只喂了 image1——角色参考图有多张时
一致性浪费。③顺手坐实 v4.400 布局 bug：剧照/设定卡两按钮同用
`.cd-hero-gen`（absolute top:12 right:12）同点位**重叠**。

## 落地

1. **模板矩阵**：`charSheetVariantBody` 六模板（triptych 三视图并排=默认 /
   front / side / back 单视图分张 / sitting 坐姿 / action 动态姿势），共用
   尾巴（纯白背景+全身可见+专业参考图）与外观锚点（沿首刀 160 rune 截断）；
   `CharacterGenerateSheet(chJSON, variant)`——非法 variant 如实报错点名
   可选值，纯函数内未知值回落默认（绑定层守门）。
2. **多参考锚定**：参考图列表逐张收集（最多 3 张=qedit 三图槽上限），全失败
   时剧照兜底；单张读取失败/远端 URL 跳过不阻断（≥1 可用即走）。
3. **前端**：设定卡按钮升级 **Dropdown.Button**——主按钮三视图并排直达，
   箭头菜单六模板；api `generateCharacterSheet(c, variant='triptych')`。
4. **布局根修**：两按钮收进 `.cd-hero-gens` 垂直堆叠容器（absolute 定位
   上移容器层）；Dropdown.Button 组内按钮玻璃样式+合并圆角 CSS 适配。
