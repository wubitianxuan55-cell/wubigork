# gaea v2.15.4「Herdsman 深挖 P3 · 本地翻译」发布说明（2026-08-13）

> 承接 v2.15.3（P2 模型生命周期），本轮落地 P3：gaea 增加本地翻译能力——
> 优先调用 Herdsman 翻译模型（Hunyuan-MT / Hy-MT，模型目录 capability=translation），
> 未安装时自动回退「常规办公」绑定模型，全程免费/本地优先，不消耗主模型 token。
> 桌面端已打包。

## 一、后端

- `App.LocalTranslate(req)`：文本 → 目标语言翻译。
  - 模型发现：引擎缓存中找已装翻译模型（`hunyuan-mt` / `hy-mt` 前缀），
    也可显式 `model` 指定；文本翻译走 `/v1/chat/completions`
    （`/v1/translations` 是语音翻译端点，不适用）。
  - 未装翻译模型时回退「常规办公」绑定模型（`resolveRoutineTarget`），
    结果标注 `used_fallback`；都不可用则给出「请到模型库下载翻译模型」的可读提示。
  - 系统提示强制「只输出译文」，保留专有名词/数字/格式。
- 办公专业工具 `translate_text`：注入办公 agent 工具集
  （`ExtraTools`），云端 agent 可按需把翻译这类机械活卸给本地翻译模型。

## 二、前端

- 能力面板「本地专业模型」新增 `translate_text` 入口与说明。

## 四、使用方式

- 办公对话直接说「把这段翻译成英文」即可；agent 会优先走 `translate_text`。
- 想用专用翻译模型：先在模型中心「模型库」下载 `Hunyuan-MT:7B` 或 `Hy-MT1.5:1.8B`
  并启动，翻译自动升级为专用模型，不再消耗办公模型。
