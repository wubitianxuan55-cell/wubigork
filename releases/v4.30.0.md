## 交付明细

### ① 产物生成自动置前 / 角标提示（Devin Auto-open 式）

- **产物 tab 角标**：App 侧 diff 会话内新出现的产物路径（首现即新，会话切换重置基线——
  恢复会话不误标「新」），未查看的新产物数以角标显示在「产物」tab 上（激活即清零，与
  运行角标「激活即已读」语义一致；tab 被停用时不弹）。
- **面板内「新」徽标 + 高亮**：DeliverablesPanel 增 `freshPaths` prop（经 sidebarRegistry
  ctx 接线），命中路径的行显示「新」徽标（Sparkles 图标 + primary 色胶囊）+ 行背景高亮
  （data-fresh 锚点可测）；激活产物 tab 后清零，徽标消退。
- 对标 Devin Auto-open Agents Tab（面板因事件而开，非因布局而开）；产物生成不打断对话，
  只做提示（与 browserAutoOpen 自动弹 tab 的激进策略区分——产物频繁出现，提示即可）。
- 测试：DeliverablesPanel +2（freshPaths 命中行/未命中行、缺省不渲染）。

### ② 面板行级降噪（Cowork 一行式）

- **产物 / 变更 / 任务三个列表**的行级次级信息改为「悬停次行显现」：默认只显示主行
  （文件名/任务名 + 状态徽标），次级信息（完整路径、相对路径、时间/重试计数）以
  opacity 过渡在悬停时显现（group-hover，150ms）。
- **寻回路径全保留**：路径类信息 title 原样（「点击预览 <path>」等既有 title 不动），
  悬停即见；任务时间行「开始于/创建→结束/已重试 N 次」同款处理。
- 对标 Cowork「每步默认一行，点开才见详情」；本刀只做「默认一行 + 悬停次行」，不做
  折叠/展开重构（列表行点击语义已各自保留：产物=预览、变更=展开 diff、任务=选中看输出）。
- 测试：既有行级断言全数保留（文件名/徽标/状态文本不变），无旧锁改动。

### ③ 命令面板按当前视图重排（Linear 式）

- 新纯函数 `lib/paletteRank.ts`：`rankPaletteItems(items, { chatTab, rightTab })`——
  与当前视图相关的命令稳定置顶（当前激活右栏面板的 `cmd-<panelId>` 最高优先，其次
  `chatTab=overview` 时的 `cmd-overview`，其余右栏面板命令次之，模板/会话保持原序）。
- App 接线：paletteItems 构造后过 rankPaletteItems（依赖追加 chatTab/rightTab）；CommandPalette
  组件零改动（组内顺序即渲染顺序，稳定排序不改变无关项相对位置）。
- 对标 Linear「命令菜单数百动作按当前视图重排」：在「产物」面板时 Ctrl+K 第一项就是
  「产物面板」，在「概览」时「概览面板」置顶。
- 测试：paletteRank +6（无视图保序/rightTab 置顶/chatTab 置顶/优先级/模板会话保序/纯函数）。

### ④ 预览 pane「半幅 ↔ 最大化」两档占幅（VS Code Toggle Maximized Panel）

- FilePreview 头部新增最大化/还原按钮（Maximize2/Minimize2 图标，title/aria-label 语义
  完整；不传 onToggleMaximize 不渲染按钮，向后兼容）。
- App 持有 `previewMaximized` 状态：最大化 = 占满可用宽度（视口 − 侧栏 − 聊天最小 360，
  与拖拽上限同源）；还原回到进入最大化前的半幅宽度（ref 记忆）；**拖拽分割条自动退出
  最大化**（手动拖 = 放弃最大化，回半幅拖拽模式）。
- icons.ts 补 Maximize2/Minimize2（antd FullscreenOutlined/FullscreenExitOutlined 映射）。
- 测试：FilePreview +2（不传回调不渲染按钮 / 半幅↔最大化切换与回调）。

## 欠账清单

- 产物自动弹出（Devin 激进版 Auto-open tab）暂不做——产物频繁出现，自动弹 tab 会打断
  对话；如用户需要可加偏好键（gaea.deliverableAutoOpen）后续补。
- 行级降噪仅做「悬停次行显现」；Cowork 式「点开才见详情」的折叠重构未做（列表行点击
  语义已各自占用）。
- 命令面板按视图重排仅覆盖 chatTab/rightTab 两维；会话列表/任务模板的个性化排序未做
  （Linear 的 per-view 收藏级重排留远期）。
- 预览最大化未持久化（重启回到用户拖拽宽度，与「半幅=用户偏好、最大化=临时态」语义
  一致）；最大化宽度未随窗口 resize 实时重算（拖拽退出后重进即新值）。
- 沿旧（v4.28 及更早）：A2 帧流/接管/动态权限卡；B1 单版本无入口+恢复不先快照当前态；
  B2 真编辑 pptx 远期；FilePreviewModal pdf 仅标签；子代理气泡恢复暂缺/中途进度不回投/
  WorkHeader 历史轮耗时/窄栏适配/tasks flaky。
