- **右舷状态侧栏（300px）**：内核状态（活跃模型 / 已启用引擎 本地·云端 /
  CPU·MEM·GPU 三表，≥85% 转 warning 色，色+数值双传达 / ComfyUI 运行徽标）·
  项目写作进度（conic-gradient 进度环）· 最近会话 · 记忆脉搏 · 做梦晨报
  （仅 work 空间，双空间红线不变）。
- **v3 五段并三段（零删除）**：
  - 快捷 chips → 删（四个入口与 Bento 瓦片同目标，收敛进矩阵一级面）；
  - AI 状态细条 + 底部信息条 → 合并进右舷四面板（系统状态并入内核遥测，
    ComfyUI 徽标化，晨报移入侧栏）；
  - 门廊（编程/设置横条）→ 编程带「独立窗口」徽标、设置，瓦片化编入矩阵
    尾部（aria 复用 progEntry）。
- **响应式**：≤1180 侧舷下落为底部双列网格 + 旗舰整行单行化（**内容
  padding-left 78px 横向排布，修复标题与左上图标叠压**——judge must_fix）；
  ≤640 侧舷单列；≤480 全单列。焦点环 / reduced-motion / ui-reduced-motion /
  gaea-raf-degraded 全降级链保留。
