# gaea 2.1.0「二代完善」

> 发布日期：2026-08-07 ｜ 基线：v2.0.1

## 版本摘要

在 v2.0.1 基础上迭代六轮，聚焦 2.0 代内的体验与正确性完善，不重写、不迁移数据：

- **模型中心完善（2.1）**：引擎状态持久化（`whisper_data/engines.json`，启停/BaseURL/默认模型/模型列表/连接状态重启恢复）；`GetEngines` 固定顺序；修复 `active_engine_id` 只存不读（重启回退 xai）；连接状态徽标 + 上次检查时间；DeepSeek Key 脱敏修复
- **功能级模型启停（2.2）**：FeatureModelBar「启停」改为功能级开关 `func_*_enabled`——此前会误关整个引擎影响所有功能；模型中心「功能绑定」新增启用开关；`routeModel` 增加启用门控
- **Cmd+K 编辑引擎路由（2.3）**：小说编辑器 AI 改写走 `routeModel("novel")`，不再用全局 `cfg.Model` + 活跃引擎
- **OAuth 回归（2.4）**：`DiscoverEndpoints` 配置化（`OIDCDiscoveryURL`/`XAI_OIDC_DISCOVERY_URL` 生效）；换 token 加 15s 超时；E04（500/403）与 E13（referrer=wubigork）回归
- **前端 E 系列核对（2.5）**：E16/E22/E23/E24 已核实修复，新增 `scripts/frontend-e-check.mjs` 静态回归守卫接入 CI
- **小说链路审计（2.6）**：角色注入剥离剧照 base64（`types.PromptView`，E02）；5 个写作 agent 未绑定时回退按活跃引擎解析默认模型（E03）

## 安装

1. 下载 `gaea.exe`（见校验和文件）。
2. 如被 Windows SmartScreen/SAC 拦截：右键 → 属性 → 解除锁定。

## 校验和

```powershell
Get-FileHash gaea.exe -Algorithm SHA256
```

与 `SHA256SUMS-v2.1.0.txt` 对比。

## 数据

现有 v2.0.1 / v1.x 数据（whisper_data / novels / office / 用户配置）零迁移直接可用。建议发布前运行 `scripts/backup.ps1` 备份。
