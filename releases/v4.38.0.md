# v4.38.0「目录通用化 · DeepSeek/xAI/Zen 官方元数据入册」

> 发布日期：2026-09-02 ｜ tag：`v4.38.0` ｜ 基线：v4.37.1 ｜ 绑定面 **557 零变更**

## 背景与依据

用户指出 v4.36.0 元数据目录只覆盖 GLM——模型中心是统一引擎控制台，元数据应覆盖全部内置云端引擎。调研子代理对三家官方页核实（2026-09-02，全部官方原文、多页互证），同时暴露**内置定价表（CCSwitch 预设）已过时**：deepseek-chat/reasoner 官方 2026-07-24 停用、grok-4/grok-3 系已不在官方 models 页、deepseek 现行官方价与内置表差 3 倍+（内置为旧 CNY 谷价口径）。

## 交付明细

### ① 通用目录（model_catalog.json + catalog_models.go）

- 顶层 `{"version":1,"updated":"2026-09-02","engines":{deepseek,xai,opencode-zen}}`，条目 schema 与 GLM 目录一致；25 条目（deepseek 3 / xai 7 / opencode-zen 15，含 3 免费系）。
- loader 懒解析一次，version≠1 拒收回退无目录态；无覆盖文件/无远程拉取（GLM 专属热更新链路不动）。
- **opencode-go 不进目录（拍板决策）**：订阅制（$10/月，额度 $12/5h·$30/周·$60/月）无按量售价，官方 per-model「参考价」是内部计量口径非售卖价，展示会误导——Go 引擎维持现状，引擎级「订阅制」徽标留欠账。

### ② 估算单源化扩展（stats.go）

- `estimatePrice` 目录优先层扩展至 deepseek/xai/opencode-zen（精确→最长前缀，带价才用），无价回退内置表；ollama/herdsman/opencode-go/custom 行为逐字节不变。
- 估算值修正对照（1M in+1M out ×7.2 汇率，旧→新）：deepseek-v4-flash 3.0→**12.672** CNY（CNY 旧谷价口径→官方 USD 峰价）；deepseek-v4-pro 36.0→38.016；xai grok-4.5/4.6 129.6→**57.6**；grok-4.3/4.20 系 →**27.0**；grok-build-0.1 0→**21.6**（新增计价）；zen 的 claude-opus-5/sonnet-5/haiku-4.5/gemini-3.1-pro/kimi-k3/qwen3.7-max 等 8 模型从**未计价→新增计价**。claude-opus-4-8/gpt-5.5/gemini-3-pro/kimi-k2 等仍走内置表逐位一致（回归锁）。

### ③ 动态列表元数据 enrich（engine.go）

- fetchModels 非 GLM 公共出口接 `enrichCatalogMeta`：动态 /models 列表按 id 归一化匹配目录（`opencode/` 前缀、日期后缀变体均命中），只填空字段不覆盖引擎返回值；GLM 静态目录分支无双重 enrich。落盘 JSON 自动含元数据（测试断言）。
- **数据口径**：deepseek/xai 峰谷双价取峰值入表（谷价/缓存价进 price_note）；xai ≥200k/zen 272K 分档填第一档、高档进 note；官方未逐模型标注的能力（xai caps/zen caps/ctx）一律不填（宁缺勿滥）；官方已停用模型（deepseek-chat/reasoner、grok-4/3 系）不加条目，自定义引擎旧名走内置表兜底。
- 前端零改动：ModelInfo 元数据经 B 刀透传链自动呈现在 deepseek/xai/zen 模型卡（上下文/价格/免费徽标）。
