## 变更

### Go（gaea_git.go 新）
- 执行 `git` CLI：`exec.Command` 参数列表（无 shell 注入面），仓库锚定
  `gaeaCwd()`（工作空间配置 → 进程 cwd 回退）；git 未安装/非 Git 仓库
  包装为面板可读的诚实错误（`gitError`）。
- `GaeaGitStatus`：`status --porcelain=v1 -b` → 分支 + ahead/behind +
  X/Y 两列展开（staged/untracked/deleted/modified/renamed 布尔）。
- `GaeaGitDiff(path, staged)`：`diff --no-color [--cached] -- path`。
- `GaeaGitStage/Unstage`：`add --` / `reset -q HEAD --`（unstage 不动
  工作区；首提交前无 HEAD 的 git 报错原样透出）。
- `GaeaGitDiscard`：`checkout -q --`（破坏性，前端两击确认）。
- `GaeaGitCommit(message)`：空说明拒绝；只提交暂存区（**不代 add**）；
  成功后 `rev-parse --short HEAD` 取短 hash（取不到不回滚提交）。
- `GaeaGitLog(limit)`：`--pretty=format:%h%x1f%s%x1f%an%x1f%at%x1e`
  （\x1f 字段分隔、\x1e 记录分隔），上限 200。

### 前端
- `workspaceTabs.ts`：追加 `git` 一级 Tab（v4.53 合并后首个新增；
  按钮条/命令面板/设置卡从清单自动派生）。
- `GitPanel.tsx`（新）：三分组文件行（状态字母徽标+文件名+悬停路径）+
  暂存/取消暂存/丢弃（ConfirmButton 两击 3s 确认态）+ 行内 diff
  （`buildGitDiff` 解析 unified diff → 复用 `ChangesDiff`；未跟踪文件
  诚实提示无 diff 语义）+ 提交区（暂存计数、说明必填、按钮解禁逻辑、
  成功清空+刷新）+ 提交历史折叠懒加载 + 非 Git 仓库空态 + 手动刷新。
  GaeaGit* 调用全部可选守卫（`?.`+Promise.resolve，无后端环境不抛）。
- `planDiff.ts`：`buildGitDiff`（hunk 头/增删/上下文行解析，`\ No
  newline` 跳过，`diff --git` 取文件对作 hunk label；空/不可解析降级

- 绑定三件套：bindingNames.ts +7（字母序）、bridge.ts（AppBindings 接口
