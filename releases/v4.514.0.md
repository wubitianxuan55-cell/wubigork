## 病灶

轻语 ChatPage 仍是旧语义：`onListScroll` 不贴底即清除跟随 + 无手势
判定。与办公板 v4.512 根修后的行为分叉，且同类病灶在此同样存在：

- **布局扰动误杀跟随**：折叠/人格条出现/图片加载引起的浏览器滚动
  锚定调整产生**程序性 scroll 事件**，被旧语义误判为用户上翻——流式
  跟随被误杀（「卡住没输出假象」同类）。轻语打字机 ~70 renders/s 的
  高频内容路径让扰动窗口更密集；
- **无手势暂停语义**：暂停/恢复完全由 scroll 事件位置驱动，与办公板
  v4.512「滚轮上滚=显式暂停」的交互模型不一致。

## 落地

- **新建 `utils/followScroll.ts` `useFollowScroll` hook**（手势语义与
  办公板 Transcript v4.512 对齐）：
  - `onScroll` 只在贴底时恢复跟随，不贴底只刷新按钮态——布局扰动
    杀不死跟随；
  - `onWheel`：`deltaY<0` 且容器真实可滚才清除跟随（短会话不足一屏
    的无效上滚不产生暂停态）；
  - `follow()`：内容变化时调用——贴底跟随落底；暂停态自愈「回到底部」
    按钮显隐（上翻后内容增长不触发 scroll 事件）；
  - `rearm()`：程序性回底（切话题/发送/清空），不立即滚动、随下一次
    内容变化落底；
  - `scrollToBottom()`：「回到底部」按钮——恢复跟随并立即落底。
- **ChatPage 改接**：五处 `stick=current=true; setAtBottom(true)` 双行
  收敛为 `rearm()`；跟随效应走 `follow()`；消息区挂 `onWheel`；
  `isNearBottom` 改由 hook 消费（本体 import 摘除）。

## 测试（+5，`followScroll.test.tsx`，几何伪造手法同 v4.512）

- 滚轮上滚=暂停：`follow` 不拽回 + 按钮态自愈（**反向变异验证**：
  恢复旧「不贴底即清除」语义该测试必红）；
- 无手势 scroll 事件（布局扰动）杀不死跟随：`follow` 自动补拉回底；
- `scrollToBottom` / `rearm` 恢复跟随（rearm 不立即滚动、下次 follow 落底）；
- 短会话（内容不足一屏）无效上滚不产生暂停态；
- 下滚/零位移滚轮不清除跟随。
- 全量 vitest 452 文件 / 3918 例绿（3913 + 5）；tsc -b 0；eslint 0
  （五处 useCallback 补 `rearm` 稳定依赖）；零 Go 改动、零绑定变更。
