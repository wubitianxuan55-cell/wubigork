## 统一检索后端收口（hub 搜索 4 绑定 → 1 绑定）

记忆中枢「三脑检索」此前在 **前端并行拼装 4 个绑定**（`BrainSearch` + `WorkspaceSearch` +
`SemanticSearch` + `FileSemanticSearch`，`MemoryHubPage.runSearch`），每次检索 4 次 RPC、
三组降级语义在前端各写一遍。本轮把聚合逻辑**下沉到后端**：

- `GaeaUnifiedSearch` 返回视图扩展为四组：`keyword`（工作区全文）+ `semantic`（跨库语义，
  成本/知识/办公/资料）+ **`brain`（三脑命中，新增）** + **`files`（文件语义，新增）**；
- hub 搜索改为**单次 `app.UnifiedSearch(q, topN)`**，四组映射回原有 HubSearchHit 渲染
  （徽标/预览/@ 引用交互零变化）；三脑未装配（`a.brain==nil`）时 brain 组空数组不报错，
  embedding 不可用时 semantic/files 降级为空的既有语义不变；
- `WorkspaceSearchPanel` 跨库模式零改动（只读 keyword/semantic），其语义徽标补上 file kind
  （后端本就返回，此前前端类型漏声明）。

**验证**：`TestGaeaUnifiedSearch_Combined` 扩展 brain/files 断言 + 新增
`TestGaeaUnifiedSearch_BrainNil`；空 query 四组均返回空数组。

## 记忆生命周期产品化（归档 tab 修复 + 恢复能力补齐）

两个真实缺口（基于代码侦察）一并闭环：

1. **归档 tab 永远空白（缺陷修复）**：前端 `OfficeMemoryLibrary` 归档 tab 读
   `view.archives`，但后端 `GaeaMemory()` 的结构体**根本没有 archives 字段**——归档列表
   实际永远空白，只有「清理超期归档」按钮孤零零可用。改为 `GaeaMemoryArchivedList`
   **分页加载**（每页 50 + 加载更多，含 total 展示）。
2. **无恢复（Unarchive）能力（能力补齐）**：memory 包注释声称「误归档用户仍可在 90 天内
   恢复」，但 `Store` 只有 `Archive`（软删），**没有 `Unarchive` 方法、没有绑定、没有 UI**——
   恢复路径实际不存在，误归档的唯一出口是 90 天后被硬删。本轮补齐全链路：
   - memory 包双后端 `Unarchive`：sqlite 置 `archived=0`；file 后端从 `.archive/<ts>-<name>.md`
     移回主目录并重建索引行；未归档/已被清理的事实返回明确错误；
   - 新绑定 `GaeaMemoryUnarchive(name)`（绑定面 497 → **498**，+1）；
   - 归档 tab 每条目「恢复」按钮（Rollback 图标 + 恢复中态），成功后刷新列表并提示。
3. **保留期下发展示**：`MemoryArchivedPage` 新增 `retentionDays`（= `memory.ArchivedRetention`
   90 天），归档 tab 顶部展示「归档保留 N 天，超期可清理」；清理确认弹窗文案跟随真实保留期
   （此前硬编码 90）。

**验证**：memory 包 `TestUnarchiveSQLite` / `TestUnarchiveFileBackend`（归档→恢复→活跃列表
出现 + 二次恢复报错 + 清理硬删后恢复报错）；app 层 `TestGaeaMemoryUnarchive` +
`TestGaeaMemoryArchivedList_RetentionDays`；vitest 归档 tab 分页/保留期/恢复交互 3 用例。

## 修复：绑定漂移脚本单条差异静默放行（质量 bug）

`scripts/check-bindings-drift.ps1` 用 `$diff = Compare-Object ...` 后判 `$diff.Count -gt 0`，
但 **PowerShell 5.1 下单条差异时 `$diff` 是单个 PSCustomObject（无 `.Count` 属性），
`$null -gt 0` 为 False → 单条绑定漂移静默放行**。本轮实测复现：`GaeaMemoryUnarchive`
加入 Go 侧后脚本仍报 OK。修复：`@()` 强制数组化（`@(Compare-Object ...)`），单条差异
也能检出。顺带把脚本改回 **UTF-8 带 BOM**（edit 过程中 BOM 丢失导致 PS 5.1 解析中文注释
报错——AGENTS.md 既有编码规范）。
