# gaea v3.0.8 发布说明

> 2026-08-17 · 办公板块「表格可交付 + 会话产物打包 + 多智能体分工」+ 界面收敛

## 办公板块 · 表格可交付（调研 docs/market-research-2026-08-office-table-agent-and-package.md 落地）

### P0-1 会话产物一键打包 Zip
- 右侧「会话产物」面板新增「打包下载」按钮：本次会话全部交付文件打成一个 zip 放进
  `.gaea/exports/gaea-会话产物-<stamp>.zip`，完成后 toast 反馈 + 文件管理器定位。
- 安全：只接受工作区相对路径（拒绝绝对路径与 `..` 穿越），缺失/目录静默跳过，
  zip 内保留相对路径结构防同名覆盖。
- 后端 `GaeaZipDeliverables` + Go 测试（空列表/存在过滤/目录跳过/穿越拒绝）；
  前端 DeliverablesPanel Archive 按钮（zipping 态）+ 组件测试。
- 对标 Kimi 工作空间「可下载 Zip」/ WorkBuddy 会话产物集中打包。

### P0-2 表格「选中区域 → 一键图表」
- XlsxPreview 新增「图表 ▾」入口：把选中区域（`A1:B6` 或单单元格 `B2` = 表头到选中行，
  空 = 自动取前两列数据行）的数据提取为「标签列 + 数值列」→ matplotlib 生成 PNG 落
  `.gaea/exports/` → 产物自动进预览队列。选中数据即出图、不离开预览。
- 后端 `GaeaXlsxChart`（复用 crosslink.GenerateChartPNG）+ Go 测试（自动/显式区域/
  单单元格数据装配 + 校验 + smoke 标记）；前端 XlsxPreview 图表入口 + 组件测试。
- 对标千问表格 Agent / ChatExcel / GLM in Excel 的「可交付」表格体验。

### P1 产物缩略图增强
- FileThumb 从「仅图片缩略图」升级为内容缩略图：xlsx 渲染前 3 行 × 前 3 列迷你表格、
  md/txt 渲染前几行文本摘要、图片保持 dataURL；加载失败静默回退类型图标。
- 已接入 DeliverableCards 与「会话产物」面板，零新后端绑定（复用 GaeaPreview
  结构化数据）。对标豆包 PPT 首屏缩略图 / AutoGPT MIME 插图。

### P2-1 多智能体分工可见
- 右侧面板「运行」组新增「分工」子面板（SubagentsPanel）：展示当前会话派发的全部
  子代理「谁在干什么」——状态徽标（进行中/已完成/失败）、任务摘要（transcript 首条
  user 消息）、模型、工具范围、工具调用次数、时间与耗时，点击展开最后回答摘要；
  运行中的子代理每 5 秒轮询刷新。
- 后端 `GaeaSubagentRuns`（读 `<sessionDir>/subagents/` 的 meta + transcript 派生，
  路径经 sessionDirForPath 防穿越，无目录返回 available=false）+ Go 测试。
- 对标 WorkSwarm 蜂群 / QClaw V2 多 Agent / 飞书 aily「同事」的团队化分工。

## 界面收敛（用户决策：不堆功能，优化现有）

- **右侧面板 Tab 收敛为 4 个主标签**：7 个子面板按「文件域 / 成果域 / 运行域 /
  分析域」归入 4 个主 Tab——文件（文件/资料）、成果（产物/变更）、运行（任务/分工）、
  分析（统计）。第一级只显示 4 个组名，第二级小 Tab 切换组内子面板；功能全保留、
  层级清晰。workspaceTabs 重构为 WORKSPACE_GROUPS + 扁平兼容导出，App.tsx 渲染分支
  与命令面板零改动。（对照 v2.13.12 删除成本库/搜索标签的同类收敛。）
- **Excel 编辑器工具栏收敛**：① 顶部 10 个常驻按钮收敛为「行操作（选中才显示）+
  重算公式 + 图表 ▾ 下拉」（图表 5 动作收进一个菜单）；② 选中单元格布局重排为
  「公式栏（写值/公式）在上、AI 编辑（自然语言指令）在下」——两个输入框逻辑分层，
  AI 编辑从两行大块收成单行紧凑（预设 + 输入框 + 执行 + 关闭），预设点击回填指令
  并有激活态。原则：**入口按上下文收敛，不按功能铺开**。
- Word（DocxPreview）检查后确认已是收敛形态（框选才浮出底部操作条、修订接受/拒绝
  按需显示），未改动——不为了对称而改。
