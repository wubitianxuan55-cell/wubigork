## 本版是什么

v4.457 把造价库重塑为工料法三层（工料机资源 → 消耗定额 → 综合单价核算输出），留下三项「后续可做」。本版把三项全部收口——**全部零新绑定**：19 个 Workcost 绑定中此前 UI 未接的部分（取费 `WorkcostProjectFees`、定额 CRUD `WorkcostQuotaSave/Get/Delete`、显式路径导出 `WorkcostProjectExport`、目录选择 `PickDirectory`）全部接通，绑定面恒 654。

## ① 取费汇总面板（工料机第三子视图 WorkcostFeePanel）

费用汇总表的软件化形态，补齐工料法第③层的 UI 面：

- **分部分项清单**：从定额库选行（综合单价按当前资源价**现算**回填）或手填行（外委包干类）；单价可手改 = 项目级调价；行级增删，直接费 = Σ(工程量 × 综合单价) 每行收敛到分（与 Go 侧 Round2 导出口径一致）。
- **取费链**：四费率（默认 10%/2%/7%/9%，费率 0 = 显式不计取）→ 直接费 → 企管 → 利润 → 规费 → 税前合计（含措施费/暂列金额）→ 增值税 → 含税总造价；**利润基数含规费开关**对齐两份实测产物的真实口径差异（百锦路不含 / 市政道路含）；招标控制价对照（差额/利用率，超 100% 显形）。
- **试算不落库**：清单与费率是草稿（localStorage 持久化，刷新不丢），不写数据库——定稿走「导出五表」活公式工作簿。与「无确认不落库」红线一致。

## ② 定额管理面（QuotaModal）

此前定额只读+导入，本版可维护：

- **新建/编辑/删除（二次确认）**：定额头（编码/名称/专业/章节/单位）+ 工料机含量行（类别/资源编码/名称/单位/含量/损耗%，行级增删）。编码编辑态锁定——它是定额的稳定锚点（改址不改引用）。
- **资源搜索回填**：含量行可从资源库搜索回填编码/类别/名称/单位——resourceCode 对上资源库锚点，资源调价才能传导到引用它的综合单价。
- **编辑先取全量**：`ListQuotas` 是轻量查询不含含量行，编辑必须先 `QuotaGet` 取全量——直接拿列表对象编辑会把含量行清空（本版避开的坑）。保存后 `composeTick` 强制重算当前选中（selected 编码不变时核算 effect 不会重跑）。
- 空名含量行拦截保存；含量 0 是合法占位（实测模版「技术工/带班 ×0」）。
