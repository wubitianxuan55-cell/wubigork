## 关键修复（真实缺陷）

- 扫描件“伪转换成功”：convertPdfToMD 无页面文字时返回仅页眉 → 改为明确错误并触发 OCR
- 解析 TotalWords 合并丢失：mergeParseResults 未合并标量 → 大纲字数预算回退错误
- 覆盖检查解析失败：extractJSON 对顶层数组截取错误 → 支持数组与对象包裹
- 阶段闸门语义反转：目标阶段当门槛 → 改为“有招标文件且未解析才拦截生成”
- Stage 未落库：proposals 表无列 → SchemaV6
- 导入环（proposal↔builtin）：规范索引抽离 specdata 共享包

## 完整工作流 E2E（自动化）

```
建项目 → 招标文件 → 解析（totalWords=120000、来源定位）→ 大纲（字数预算合计=120000）
→ 单章生成 → 批量生成 4/4（断点续写）→ 合并装配编号 → 全面检查 13 项
→ 导出 MD → 归档记忆中枢 → 同类参考注入 ✅
```
