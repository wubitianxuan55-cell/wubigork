## Realtime S1：配置落盘 + DPAPI key + key 入口 UI（兑现 S0 注释）

- **后端**：config 三键六处注册（realtime_provider/realtime_model/
  realtime_api_key）——provider 非空仅允许 openai（非法值 Save 拒绝）；
  API Key 存储口径 = secure.EncryptString DPAPI 密文（仅本机可解）。
  `realtimeRuntimeCfg()` 解密助手：initVoice 在 voice.NewManager **之前**
  注入三项（接线位置有测试守护——曾放 NewManager 后只改局部副本）；解密
  失败 Warn + Key 置空降级不崩；VoiceHealth.realtimeReady = 配置了 provider
  且 seam 构造成功。未配置=零值=现拼接管线零变化。
- **设置入口**（零新增绑定）：VoiceApplySettings 扩 realtimeProvider/
  realtimeModel/realtimeAPIKey 三键——Key 明文进内存（本进程实时用）+ 密文
  落盘；凭据保存失败**返回错误**（不复用 TTSVoice 仅告警先例：静默丢 key
  会让「已配置」假象带到下次启动）；空串=清除。VoiceGetSettings 加
  realtimeProvider/realtimeModel/realtimeHasKey——**明文 Key 永不出后端**
  （测试断言全 map 无泄漏）。
- **VoiceSettingsPanel「实时语音（实验）」段**：供应商下拉（关闭/OpenAI
  Realtime）+ 模型 + 密码框 Key（已配置提示、不回显明文、输入新值才下发）+
  保存后回读 hasKey。
- 测试：config 往返 + 非法 provider 拒绝；wiring 3 例（明文就位/解密失败
  降级/未配置零变化）；apply 往返（内存明文/落盘密文可解回/hasKey/无泄漏/
  清除）。
