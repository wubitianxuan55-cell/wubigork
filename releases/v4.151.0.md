## 2. 三工具与技能

- **schedule_get**：taskView 增 `durationUnit`（omitempty，wd 不出=旧客户端零噪音）；描述补「durationUnit=cd 表示日历天，等效工作日跨度=cpm 行 ef−es」。
- **schedule_analyze**：Analysis 增 **`cdTasks` 清单**（id/name/duration 自然日数/span 等效工作日跨度/anchor 锚点日期=es 所在工作日）；描述补「混排计划先讲这组」；qualityChecks 增防御 finding：cd 任务涉非 FS 搭接（闸在 Validate/apply，正常不发生，疑旧口径残留时提示改 FS）。
- **schedule_apply**：回执「写入后总工期 X 天**（工作日）**」统一补词；描述补 project 通道任务字段 durationUnit 与 patch 支持项。
- **schedule-edit 技能**：工期分节增段——自然日定时工作用 `durationUnit:'cd'`（数值=自然日数；搭接仅 FS；成本按等效工作日跨度 ef−es 计=元/工日不因日历天放大）；定额/合同工期禁误标 cd。汇报口径节补「总工期 X→Y 天（工作日）；混排计划先讲 cdTasks 清单」。**锚点锁 35→37**（+「日历天」「cdTasks」）。
- compact.go：三工具 compactDesc 同步（schedule_apply 带 durationUnit、analyze 带 cdTasks、get 带 cd 口径）。
