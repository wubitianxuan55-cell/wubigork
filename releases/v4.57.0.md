# v4.57.0「设置中心化繁为简：删四补一 · 界面语言入口」

> 发布日期：2026-09-03 ｜ tag：`v4.57.0` ｜ 基线：v4.56.0 ｜ 绑定面 **559 零变更**

## 定位

用户点名刀：优化设置中心——删除不要的，增加需要的。删除前逐项 grep 核真伪
（零交互卡 / 重复信息 / 零消费导出），红线不破：**不删任何活功能**，只删
纯展示冗余与死代码；新增项为基础设施早已就绪而 UI 缺口的能力。

## 删（四项，全部零功能损失）

1. **绘梦「当前绘梦后端」纯展示卡**：与其正下方后端下拉展示同一份
   backend/model 状态，信息完全重复；删除后下拉即唯一现状出口，desc 注明
   「当前生效值已回填到下方」。
2. **小说「角色剧照」零交互说明卡**：整卡只说「无需单独配置」；一行并入
   「小说存储目录」desc（portraits/ 跟随目录），删卡不删信息。
3. **关于「系统信息」→「存储路径」**：引擎 / API 地址 / 推理强度三行与
   「模型」分组（当前模型 + 推理强度）及模型中心重复；收敛为仅存唯二路径
   行（Token 存储 / 图片保存目录），desc 指明运行态信息去向。
4. **api/settings.ts 七个零消费死导出**：getTTSConfig / getTTSStatus /
   saveTTSConfig / startTTSServer / stopTTSServer / migrateProjectToV4 /
   voiceHealth——全仓 grep 零调用方（TTS 完整面板走 VoiceSettingsPanel 直连
   绑定，不经此 API 层）；连带清理 TTSConfig/TTSStatus 死 import。

## 增（一项）+ 修（一个真坑）

- **通用分组新增「界面语言」切换**（ AppearancePanel 导出 LanguagePanel）：
  跟随系统 / 简体中文 / 繁體中文 / English。i18n 三语字典与
  `setPref`（localStorage `gaea-lang`，即时生效整树重渲染）在 S2.2b 已全量
  就绪，但全应用**没有任何切换入口**——此前只能靠 OS 语言探测或手改
  localStorage。desc 如实注明覆盖范围（壳层文案即时切换；各板块面板暂以
  中文为主）。搜索关键词同步（语言/英文/繁体/language）。
- **修 ImageGenPanel 回填缺口**：load() 此前只回填 backend/model，不回填
  comfyui_url / image_save_dir——comfyui 后端下用户直接点保存会把已存 URL
  清空（假空串覆盖）。补齐两字段回填 + 用例锁「comfyui 回填已存地址/目录，
  保存不丢配置」。
