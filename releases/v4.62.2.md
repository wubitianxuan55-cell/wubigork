# v4.62.2「修复：对话标签页实时输出失聪（EventsOff 连坐炸订）」

> 发布日期：2026-09-04 ｜ tag：`v4.62.2` ｜ 基线：v4.62.1 ｜ 绑定面 **559
> 零变更** ｜ 热修复：用户实机报告的三个问题全部收口。

## 症状（用户实机报告）

1. 主对话「思考中 0 步」全程无过程显示（流式/工具卡/阶段全无）；
2. 任务中心恒「暂无任务」；
3. 本地模型工具（mt_）标签页输出是一团带字面 
 的转义墙。

## 根因①（主因）：EventsOff 连坐炸订（v4.61.0 引入）

wails 的 `EventsOff(channel)` 语义 = **注销该通道上全部监听者**。v4.61.0 给
SubagentThread（子代理/本地模型工具标签页）新增了 gaea-event 订阅（工具边界
即时补拉），其卸载清理走 `EventsOff("gaea-event")`——**用户从子代理标签页
切回对话标签页的瞬间，主对话 store 的订阅被连带炸掉**，此后本会话内：
实时流式文本、工具卡、阶段、task 卡全灭（0 步），只剩轮询类面板（任务树/
GaeaSubagentRuns）、30s 看门狗与 turn_done 后的 reconcileFinalAnswer RPC
兜底（所以最终答案仍会出现，「已完成 · 用时 0s」即看门狗本地翻转）。
实锤链：会话账本 306 条事件完整落盘（后端无恙）+ 前端零报错 + wails v2.13
runtime 源码确认 EventsOff 全清语义、EventsOn 本返回按监听者注销函数。
昨天 v4.60.0 无该订阅，故「昨天还好好的」。

### 修复

- 新增 `lib/wailsEvents.ts`：`subscribeWailsEvent` 一律采用 EventsOn 返回的
  **按监听者注销函数**；前端事件订阅禁止 EventsOff（全局清炸）。
- bridge 的 onEvent / onSubagentText 全部接入。
- 回归测试 3 例：一个注销不连坐另一个 / 从不调用 EventsOff / 旧运行时
  void 返回值安全降级。

## 根因②：mt_ transcript 信封转义墙

本地模型工具的 ToolResult.Output 是 JSON 信封串
（{"ok":true,...,"data":{"result":"正文"}}），原样落 transcript → 会话 tab
渲染出字面 
 转义墙。修复：落盘前 `unwrapModelToolOutput` 拆出 data.result
正文（非信封形态原样返回绝不猜），Go 回归测试覆盖信封/自由文本/破损 JSON/
空白 result 四形态。

## 根因③：GaeaTaskList 变参绑定

Go 侧 `GaeaTaskList(space ...string)` 变参经 wails 是**必填参数**，前端
`TaskList()` 零参调用被 RPC 拒绝（"received 0 arguments, expected 1"，
gaea.log 自 09-03 起反复报）→ 任务中心恒空。修复：TaskCenter /
useRunningBadge 传 `[]`，AppBindings 签名对齐（`space?: string[]`）。
