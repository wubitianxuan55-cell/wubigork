# v4.150.0 · 双工期口径刀1：任务级工期单位（模型+引擎，TS↔Go 镜像）（2026-09-08）

> 拍板池最后一项欠账启动实施（docs/gaea-schedule-dual-duration-design-2026-09.md，推荐项全采纳）：混凝土养护、干燥期等**自然日定时**工作此前只能录工作日——28 个工作日的养护横道跨度 ≈40 天、竣工日期双双失真。本刀落数据模型与引擎层：`task.durationUnit?: 'wd'|'cd'`（缺省 wd=现状口径，**旧文件零迁移零行为变化**），cd=日历天按自然日走、引擎完成边界 ceil 吸附到工作日。设计刀序四刀之本刀1，绑定面 **597 零变更**；刀2 agent 通道 / 刀3 板块 UI / 刀4 mspdi 互通按序待续。

## 1. 模型（types.ts ↔ types.go 同构）

- `DurationUnit = 'wd' | 'cd'`；`SchedTask.durationUnit?`（Go `DurationUnit` + `UnitWd/UnitCd` 常量，json `durationUnit,omitempty`）。`duration` 恒为「当前单位下的数值」，单值无双源；与 mspdi `Duration+DurationFormat(7/8)` 语义 1:1。
- fail-closed 双道闸分工同现状：**Go Validate 拒绝落盘**（枚举非法 / 分组行禁 cd=汇总唯一口径为子孙求和 / 里程碑禁 cd=effDur=0 口径不动 / cd 数值上限 3650 与 calendar 扫描同源 / **cd 搭接仅 FS**——SS/FF/SF 涉 cd 引入对 dur 的不动点迭代，按欠账矩阵 v1 后逐格放行）；**TS normalizeProject 容错回落**（违规一律丢弃字段回 wd，不抛错打断编辑流）。

## 2. 引擎换算（calendar/cpm 纯函数对，测试互为镜像）

- `calendar.ts`/`calendar.go` 新增 **`cdToEf`**（正推：边界=es 所在工作日+cd 自然日，**ceil 吸附**到首个 ≥边界 的工作日序号——边界落周末/节假日顺延，恰为工作日即当日；26/27/28cd 在整周工作制下同 ef=20，吸附折叠）与 **`cdLatestStart`**（逆推：最大 s 使 fwd(s)≤lf，镜像回退+有界双侧校正，性质 `fwd(ls)≤lf<fwd(ls+1)` 用例钉死；平段取最大 s；负时差极端截 0）。
- `computeCpm` 增可选 ctx `{ calendar?, startDate? }`（Go 先例式双入口 `ComputeCpmCal`/`ComputeCpmPlanCal`，`ComputeCpm/ComputeCpmPlan` 委托）：**快路径铁律**——任务表无 cd 任务时分支全短路，既有 18+ 用例零改动全绿（逐位等价用例钉死）；有 cd 而**缺开工日期 → ok=false**（错误原文明示「缺开工日期无法计算日历天任务」，不静默）；cd 涉非 FS → 引擎层同样拒绝（Validate 之外防直接调用）。设计文档 §3.2.2 原文「calendar 缺失也 fail-closed」细化为**日历缺省回落周一~五**（与全部 wdToDate 读点同口径，Load 后恒已归一），仅 startDate 缺失 fail。
- 逆推 FS 上界统一为 `to.ls − lag`：wd 后继与旧式 `to.lf−durTo−lag` 逐位相等，cd 后继的 ls 已按日历换算必须用 to.ls 才诚实。

## 3. 成本与基线换源（拍板项 3/4）

- **成本**：work 分配工期换源 `effDur(task)` → **cpm 行等效工作日跨度 ef−es**（wd 任务两值恒等有 pin；cd 任务=养护窗口内工作日数——**周末不记工日**，与「元/工日」费率天然自洽；28cd×100 元/工日=2000 而非 2800）。material/cost/fixedCost 不随时长不受影响。
- **基线**：快照行 dur 与漂移 now.dur 同换源等效跨度；漂移仍在工作日空间——日历变化导致 cd 等效跨度变化时 durDrift 如实呈现（诚实口径非 bug）。
- 倒排/gschedSummary/摘要卡零改动（全工作日口径，cd 任务贡献吸附后的工作日边界）。
