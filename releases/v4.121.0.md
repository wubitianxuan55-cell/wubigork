## 一、本刀内容

### 1. 办公侧计划摘要卡（gaea/components/ScheduleFileCard.tsx，新）
- 办公文件预览打开 `.gsched.json` 不再裸吐 JSON 文本：解析为摘要卡——总工期/工作/关键/搭接/里程碑 chips + 开工·竣工日期（复用 wdToDate 工作日换算）+ 基线漂移行 + 目标竣工倒排行（超期红/富余绿/压线达成），循环依赖显式告警（工期/关键不可算），空计划提示。
- **原始 JSON 开关**保留文本视图（能力零删除，默认摘要视图）。
- 解析失败回落原文本视图（宁回落勿误报）——非工程形状/坏 JSON 行为与旧版完全一致。

### 2. 板块互跳（联动不并板）
- 摘要卡「在进度计划中打开」：`navigate` 事件到 schedule 板块（白名单+同 work 空间校验既有机制）。
- 进度板块页头新增「办公侧查看」按钮（ToolOutlined）：预置 `usePreviewStore.openFilePreview(当前计划路径)` + navigate 到 gaea——office 未挂载也落地（zustand 全局态先置，挂载即渲染预览），keepAlive 已挂载则经订阅即时响应。
- **当前计划限定**：跳转/周报两个动作只对 `进度计划/当前计划.gsched.json` 提供（板块绑定的是当前计划，其余 .gsched.json 跳转会误导）；其余计划文件只读摘要，卡上明示「非当前计划文件」。
- 路径常量 `SCHEDULE_FILE_PATH`（schedule/gschedSummary.ts）与 Go `internal/schedule/project.go DefaultRelPath` 镜像。

### 3. AI 进度周报一键（摘要卡按钮 → 共享工作线程）
- 「AI 进度周报」按钮：把周报指令发进与办公板块共享的**同一条工作线程**（schedule_get → 周报 docx → 回路径）。

- 审批挂起/内核未就绪禁用（与 Composer disabled 同语义）；失败 toast 不静默。

### 4. 纯函数层（schedule/gschedSummary.ts，新）
- `isScheduleFilePath`（后缀识别，大小写不敏感、双分隔符兼容）+ `parseSchedSummary`（JSON→normalizeProject→CPM/基线漂移/倒排校核汇总；任何失败返回 null）。
