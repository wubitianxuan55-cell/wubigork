## 1. 知识库 PDF 导入乱码根修（90b6fce3）

- **根因**（「福建省环境监测行业指导价」实弹定性，body=80007 字节 PDF 原始
  字节实证）：图片型 PDF（Chrome/Skia 100 个 /Image + CID 子集字体）BT/ET
  文本提取注定为空 → 兜底 `extractRawText` 把压缩流垃圾（可打印 ASCII + 随机
  汉字）当正文；旧闸 `cjk>=5` 被 0.37% 密度的随机汉字骗过，OCR 回退被短路。
- **修复**：`internal/docmd/pdf.go` meaningfulText 双闸=①符号垃圾闸（含 3+ 连续
  ASCII 符号的行占比 >30% 判垃圾；实弹 56% / 真文本 0%）②密度闸（汉字 ≥5 且
  占比 ≥2%；实弹 0.37% / 真中文 ≥20%），英文支线口径不变。守卫
  `pdf_meaningful_test.go` 三例。坏条目已读图转录回写。

## 2. Unlimited-OCR-2 计入 gaea 平台（0f3064e1 + 3b251a63）

- **uocr2 引擎**（`internal/docmd/ocr_uocr2.go`）：镜像 ovis 编排口径——常驻
  python 服务（`server.py`，默认端口 8138，模型加载完才监听=应答即就绪）按需
  拉起 + 失败短冷却 + Job Object 杀树；`GAEA_UOCR2_DIR/PY/PORT/URL` 可覆盖。
  协议 `GET /health` + `POST /ocr`（422=截断 fail-closed 同 ovis 口径）；
  `<PAGE>/<BLOCK>/<FORK>` 结构标记由 Go 侧 `uocr2CleanText` 清洗（可单测）。
- **auto 链 uocr2→ovis→tesseract**（2026-10-29 拍板：质量优先——版式/表格还原
  最好，福建指导价整页 23 行×5 列全对含跨行备注，60s/页 CPU；OvisOCR2 快约 5 倍
  作次选，`GAEA_OCR_ENGINE=ovis` 一键换挡）。kind 域钉子注释同步（取值域=
  本地引擎 uocr2/ovis/tesseract，远端 herdsman 链仍刻意不入域）。
- **多页批识别**：seam 增 `PageBatchOCRProvider` 可选接口；server 增
  `/ocr_batch`（`infer(crop_mode=True)` 多页逐页 gundam 切片 + ngram window
  1024；`infer_multi` 是 base 模式兼容入口无切片不保真，不走）；`ocrPDFRange`
  链首引擎 ≥2 页按 `ocrBatchWindow=5` 分窗（官方 SGLang 默认 10 取半控重试
  成本），批失败/页数不齐/含空文本**整窗回退逐页**，容错语义与纯逐页一致。
  价值实测：跨页表格正确续排（页 2 表格从第 24 行续、页码 2/15 识别）；
  2 页批 155s vs 单页 60+95s 同量级但白赚跨页上下文。保真前置实验=2 页批 vs
  单页金标逐字一致（base 模式 1024 全局视图对 300dpi 密排页有失真风险故不用）。
- **断连自愈**：uocr2/ovis provider 对称 `dropBaseIfTransportErr`——传输层
  错误（*url.Error，服务中途消亡/重启）清缓存 base 让下页重新探测/拉起，
  长驻 gaea 进程不再打死地址；HTTP 状态错误（服务活着）不清。
- **清洗器加固**：GPU bf16 数字噪声实测偶发 `<FORK>` 缺失坐标正文粘连——
  含 `<BLOCK>` 无 `<FORK>` 的行整行剥掉（宁缺勿把坐标碎片漏进知识库正文）。
- **核显加速（opt-in）**：TheRock gfx1151 轮子 stamp 0502（rocm7.13.0a20260502）
  HIP JIT comgr 报 `__float2bfloat16` 重定义冲突=不可用（留档）；老 stamp
  **rocm7.12.0a20260128（venv-rocm2）JIT 过**：单页 42.4s vs CPU 60.4s（1.4x）、
  批量 2 页 78.3s vs 149.8s（**1.9x**）。定性 opt-in（`GAEA_UOCR2_PY` 指向
  venv-rocm2；Go 默认仍 CPU，防 alpha 轮子上主链 + 与 herdsman 显存共存），
  须同款 `torch/distributed/tensor` stub（TheRock Windows 轮子缺
  `_distributed_c10d`，transformers 4.52 顶部 import 会炸）。
