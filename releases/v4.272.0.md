# v4.272.0 — UX 线第四刀：窄窗响应式收口（遥测条 + Composer 工具行）（2026-09-13）

## 来源

「继续优化迭代前端 UI」续刀。上一刀（v4.271.0）普查在标准窗口（1264×760）做的是
静态视觉；本刀换镜头做**窄窗响应式**：CDP `Emulation.setDeviceMetricsOverride`
900×600 复跑 13 rail 页巡检。结果：布局自适应面整体健康（办公右栏窄窗自动收起、
各面板 min-w-0/truncate 到位），抓到两处真硬伤。

## 硬伤与修复

### ① 底部遥测条右缘截断（全站，home/chat/novel/imagegen/cost/sin 均现）

900px 下两个引擎 pod（超长模型名 chip，white-space:nowrap）把右侧 CPU/内存/GPU
数值挤出视口（内存/GPU 被切）。

修复（foundation.css + MainLayout.tsx）：
- `.v3-engine-pod` 加 `max-width: 240px + min-width: 0 + flex-shrink: 1`——窄窗
  **先截断 pod**（模型名次要）；pod 文本包 `.v3-pod-text`（inline-flex 容器上
  text-overflow 不生效，须内层 span truncate）出省略号。
- `.v3-tele-key/.v3-tele-value` 加 `flex-shrink: 0`——系统遥测数值（右缘组）
  不被压缩。挤压优先级：pod → 工程名（已有 ellipsis）→ 遥测数值（完整保）。

### ② sin composer 工具行按钮竖排折字（原罪/办公共享组件）

右栏打开时 composer 容器约 320px，权限组（询问/自动/YOLO）+思考组（快速/标准/
深度）按钮无 nowrap 被 flex 压缩，「自动」「快速」两字竖排成条。

修复（ComposerToolbar.tsx，办公+原罪两处共享受益）：
- 外层工具行 `flex-wrap: wrap`（窄容器折成两行而非挤压）。
- 权限/思考按钮组 `shrink-0` + 按钮 `whitespace-nowrap`——按钮永不竖排字。
