## 落地

### 1. 角色库「Cast Wall」玄墨化（character-card/library/detail 三份 CSS 视觉重画）

档案卡恰是 v11 复盘点名手法重灾区（卡顶 glow 渐变 wash ×21 处消费 +
1px 描边 + inset 顶亮线 =「线框感/镀金」三连；9~11px 微字满卡）：

- **描边退场**：卡面 glow 渐变 wash、`::after` v3-edge 顶高光线、inset
  顶亮线全部退役；分层改纯色面（`--color-bg-container` 比 surface 亮一
  档）+ 投影令牌（`--shadow-sm/md`）；亮态补 v11.3 同款补偿（卡线升一档
  + ink 派生静息影）；
- **金色点睛纪律**：类型旗标/可聊天文案/占位首字/标签 pill 全部中性墨化，
  金收敛到点睛位——编号等宽数据值、可聊天活性点、hover 边与进入钮；
  当前人格 primary 实底保留（强语义），彩影退役改中性影；
- **排印三档**：名字 17px·650 / 档案眉标签 10px·宽字距 / 标签 10.5px·
  0.04em——消灭 9/9.5px 微字；节标改玄墨 eyebrow 款（11px·700 宽字距+
  渐隐尾线）；
- **装饰动效退役**：光泽扫过（sheen）塑料感手法移除（类名保留结构零动）；
  网格 gap 16→14px 对缝；
- **走查实修**：无立绘占位面原用 surface-container-high 与卡面同向太近
  （暗色下第三张卡轮廓难辨）——降一档回 surface-container 形成图框感，
  三处占位（卡占位/inspector 头像/档案册 hero）统一。

### 2. 微信青鸟工作台玄墨化（weixin-page.css）

- **氛围层降权**：通讯波纹双 radial+星穹网格叠层降透明（0.4→0.22 /
  0.32→0.16），近实底不再与内容层抢戏；
- **顶条去玻璃**：玻璃 blur+v3-edge 底线退役，改纯色面（bg-container 亮
  一档）+ 近无底边线；
- **卡面统一**：键值栅格/提醒条/指南卡/扫码框/人格选择器列表全部改玄墨
  纯色面+投影令牌+近无边；命令示例 chip 改玄墨 kbd 款（中性墨 mono，
  glow 底金边退役）；
- **金色点睛**：标题/指南/空态图标章中性墨化，金只留激活轨道左缘细线、
  pending 徽记、当前相位点、hover 点亮；激活态光效（glow 光条/发光点/
  脉冲辉光）全部退场；
- **激活语义保留**：轨道/chip/列表激活仍用 primary-container 底（全站
  轨道语言一致），仅光效退场。

### 3. 红线遵守
