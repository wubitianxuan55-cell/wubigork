> 用户指令「继续」。刀8（v4.429 挂池疑点关账+半成品接线）。**绑定面 740→741
> （+1：NovelGhostSuggest）、零功能删除。**

## 背景：疑点实为死代码

筹备 v4.429 挂池项「GhostText 受控值疑点待真机」时读码发现：GhostText 是
**半成品死代码**——v4.425 只建了 UI 壳（悬浮定位/Tab 接受/Esc 取消），但
①无请求触发（注释宣称的 800ms 防抖请求代码不存在）、②无后端发射方（全仓
零 ghost-stream 生产者）、③唯一挂载点 `ghostEnabled={false}` 硬禁用。
「受控值疑点」无从测起——功能根本不可达。

## 落地

### 后端：NovelGhostSuggest 单发续写绑定
- 上下文取光标前文本尾部 800 rune；系统提示限定 1~2 句 ≤60 字、贴合前文
  声音节奏人称、不解释不重复不加引号。
- **成人向一行口径**：档位非空时追加「按本书尺度正常书写，不回避、不降级为
  纯爱」——完整工艺区段（615 rune）对 60 字补全是浪费，只保不降级底线。
- 输出清理（空白/包裹引号/「接续：」类前缀）；空建议与 <10 字上下文拒绝；
  单发非流式（1~2 句补全走 SSE 是过度设计，也无 ghost-stream 多实例串扰）。

### 前端：GhostText 重写
- **触发链**：所在 textarea 的 input 事件 → 立即弃旧 ghost + 800ms 防抖请求；
  焦点隔离（`document.activeElement` 校验——多场景实例同挂互不打架）；
  getCursorContext 走 latest-ref（父级每渲染新建闭包，依赖它会让 effect 每渲染
  重挂监听并作废在途请求）。
- **受控值疑点正解**：Tab 接受改走**原生 setter**（`HTMLTextAreaElement.prototype`
  的 value 描述符）+ dispatch input——React 属性钩子对直接赋值去重 onChange
  （v4.429 微实验实证收旧值），原生 setter 绕开钩子；v4.441.1 走查配方同款。
  测试以受控 textarea 真链路钉死：onChange 收到含补全的新值。
- **竞态守卫**：请求序号，新输入/新请求作废在途响应（迟到建议不显示）；
  Esc 取消；继续输入即弃。
- ChapterPage `ghostEnabled` 启用；wails.d.ts 签名 + drift LegacySurfaceNames
  认领（wailsApp 直调 legacy 面，bridge 契约零变更）。
