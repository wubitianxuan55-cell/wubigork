## 改动

### 引擎层（新增 16 用例，schedule 模块合计 42 例）

- **calendar.ts 新模块（8 例）**：工作日历纯函数——`wdToDate/dateToWd` 双向换算（周末按
  workweek 集合、节假日例外命中即跳过）、开工日为非工作日自动顺延、非工作日 dateToWd
  返回 null、早于开工日防御 null、扫描上限 3650 天防呆、normalizeCalendar 兜底非法输入。
- **cpm.ts 手动/自动双模式（+3 例，累计 18）**：manual 任务正推忽略入边、ES 锁定
  manualStart；逆推不回传约束（前置 LF 不被手动任务收小）；自身 TF/FF=0 且不标关键；
  其后继自动任务仍以 manual 的 EF 为正向约束（Project 口径的可用子集）。
- **mspdi.ts 新模块（5 例）**：MS Project XML 导入/导出——
  - 导出：Project/Calendars（DayType 1=周日..7=周六、WorkingTimes、Exceptions 假日）/Tasks
    （UID/ID/WBS/Name/IsSummary/Milestone/Duration ISO8601/OutlineLevel/Start/Finish/
    PercentComplete/Manual/PredecessorLink Type+LinkLag 十分之一分钟 4800/日）；
    分组行 Start/Finish 按子孙滚动、工期=跨度。
  - 导入：宽松容错（DOMParser parsererror/缺 Project 根/空任务 fail-closed）；Duration
    PT#H#M#S→工作日；IsSummary→分组(0)、其余一律叶(1)（顶层级叶子不误判分组）；
    Manual+ManualStart→dateToWd 工作日序号；基准日历周工作制+例外区间展开（上限 500 天）。
  - roundtrip 测试：样例工程导出→导入，任务名/层级/工期/搭接（含 SS lag 10d）/日历逐项一致。
- **types.ts**：SchedCalendar、TaskMode、SchedTask.mode/manualStart、SchedProject.calendar。

### 视图层

- **GanttView**：①日期轴改工作日历口径（列=工作日序号，日期跨周末/节假日推进，月界标记）；
  ②WBS 编码列；③模式列（自动/手动 chip 切换，手动行开始列变工作日序号输入）；④**前锋线**
  （斑马口径）：按任务完成进度在横道条上取前锋点连折线（未开始=ES、完成=EF、进行中=
  ES+进度×工期）+检查日期竖虚线+前锋点圆点，检查日期 DatePicker 可调；⑤手动任务条灰、
  不画时差尾巴；⑥统计文案改「工作日」。
- **SchedulePage**：工具栏「导入 XML」（file input+FileReader，成功/失败 Alert）/「导出 XML」
  （Blob 下载，对齐 gaea/lib/export.ts 模式）/「日历」弹层（周工作制 Checkbox 组+节假日
  Tag 列表增删）；循环依赖 Alert 与导入提示并存。
- **store.ts**：importProject（导入整体替换+归一）、setCalendar；persist merge 归一
  （v4.110 旧持久化无 calendar/mode 字段自动补缺省，partialize 落盘前归一）。
- **PdmView/AoaView**：图例补「时间单位：工作日（按日历）」口径说明。
- **schedule.css**：前锋线（橙 #f59e0b 折线/检查线/圆点）、手动条灰色、模式 chip 样式。
