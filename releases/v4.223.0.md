## 缺口

## 落地

- **internal/office/standard 新增 FormatChecker**（「GB/T 9704 排版细则」规范包）：
  - `ParseDocxLayout` 纯函数：word/document.xml 容错子集解析 → 排版事实
    （pgMar 四边、逐段东亚字体/字号半磅/行距 line+lineRule/首行缩进
    firstLineChars/对齐；run 级 rPr 优先段级缺省；表格内段落一并计入）。
  - 六项检查（容差内符合，实测值写进修复建议；数据不足=「不适用」不误报）：
    1. 页边距 上37 下35 左28 右26 mm（±2mm 容差，四边聚一条）；
    2. 公文标题字号二号 22pt（小标宋字体变体多，只作建议不参与判定）；
    3. 正文字体字号三号 16pt 仿宋（非标题非层级段多数票）；
    4. 行距 28~30 磅固定值（line=560~600，多数符合即符合）；
    5. 首行缩进 2 字符（firstLineChars=200 或 firstLine 560~720 twip）；
    6. 层级标题「一、」黑体「（一）」楷体（三级及以下变体多不查）。
- **取数口**：docxedit 新导出 `ReadDocumentXML`（薄包装 readDocx）；
  `LintDocumentWithLayout` 聚合入口（layout=nil 行为与 LintDocument 一致）；
  gaea_lint.go .docx 分支解析失败 fail-open（排版包跳过，文本层检查器照常）。
