## A 线 · ChapterPage 拆分第二步

- 第二批搬移：`applyTextHighlight` / `paraOf` / `textAtScrollTop` 逐行搬入
  `chapter/readingHighlight.ts`，ChapterPage.tsx 净减约 62 行（累计两批 ~111 行）。
- **保留 ref 包装的关键论证**：搜索定位 effect 的 interval 回调存活最长 3.6s，
  若改直调并传 effect 捕获的 readMode，存在「readMode 变化→重渲染提交→清理前」
  窗口内旧闭包误高亮风险；ref 每次渲染同步最新值，读取时机与原闭包完全一致，
  零行为差异——**可简化≠应简化**。
- 新增 14 用例（13 纯函数 + 1 书签流程冒烟锁 textAtScrollTop 接线）。
- 放弃项：`errText`（与阅读高亮无语义关联，所有权内无合适归宿，留待共享
  utils）。疑似既有缺陷单独立项：同章内重复点击搜索命中不触发定位 effect。
