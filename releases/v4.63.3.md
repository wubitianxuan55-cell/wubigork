## dsh 对照结论（源码级）

- **subagents.live 批量接口**（#298）：per-child 轮询曾造成 host 全量枚举
  O(N²) 放大；改为一次枚举整棵子代理树 + 客户端单轮询单在途。
- **0→N 自动展开 + 500ms 去抖重臂**（#314）：detectNewDirectSubagent 检测
  新子代理；派发帧与标题/状态帧分帧到达，立即判定会误触发，等快照稳定后

  客户端只收折叠结果；纯函数分层、node 可单测。

  线程内追问、可提升为顶层会话——gaea 的 follow-up 欠账照此设计。

## 本次采纳（两条快速线）

1. **共享单轮询聚合**（lib/subagentRunsStore.ts）：此前 App 两处 5s 独立
   轮询（会话 tab 同步 / task 卡 live 活动）并入每会话单定时器（5s、页面
   不可见门控、在途去重、订阅即拉、最后一个订阅者注销停表）；快照广播
   订阅者 + 非响应式快照读取。任务树/左栏子行有自有 UI 态，迁移列后续刀。
2. **新子代理 0→N 自动展开**：当前会话出现新运行 → 自动切右栏「任务」视图
   （已在则不打扰）；500ms 去抖重评估；会话切换首个快照只建基线不触发；
   偏好 localStorage `gaea.tasks.autoOpenSubagent`（默认开，置 0 关闭）。
