## ① 组价确认留痕（此前证据链确认后即丢）

- **SchemaV16** `cost_compose_records`（id/entry_name/created_at/llm_used/snapshot + entry 索引，幂等迁移；V11-V15 已被占用故顺延）：`GaeaCostComposeApply` 成功回写后存**完整 CostComposeView 快照**（价格带+人材机+证据链+校验结果）——**确认即留痕，无确认不落库红线不变**；留痕尽力而为不阻断回写。
- **GaeaCostComposeRecords(entryName)**：非空=该条目全部记录（时间倒序，同秒 id 兜底）；空=全库最近 20 条；坏 snapshot 行如实 Snapshot=nil 不整批失败。
- 前端：CostEntryModal 新增只读折叠区「组价依据（N 次）」——时间+推荐价+LLM/规则徽标，展开看价格带/人材机/证据链（来源/地区/期数/口径）；无记录零渲染，加载失败静默。证据链表抽共享组件 ComposeEvidenceTable（ComposeModal 零视觉变化迁用）。

## ② LLM 拆解合理性校验（此前无复核基线）

- 纯函数 `cost.CheckComposeComponents(comps, recommended)`：R1 金额一致性 |amount−含量×单价|>max(0.01,1%) → warn；R2 含量/单价非正 → warn（该行不再进 R1/R3 避免双重误报）；R3 全局合计 Σ>推荐价×1.05 → warn「合计已超推荐价」/ Σ<×0.5 → info「注意管理费/利润/税金口径」；恰阈值不触发。
- CostComposeView 增 `checks`，ComposeModal 行级徽标（同行归并 warn 主导）+ 全局提示行；无 checks 字段渲染零变化（向后兼容）。校验结果随留痕快照入档——回看时能看到「当时提示过什么」。
