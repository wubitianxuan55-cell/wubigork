## C 线 · 自定义引擎用户价目 v1（模型中心 + 后端）

- **链路探查**：成本折算在 `internal/modelengine/stats.go estimatedCostFor`
  （estimatePrice 三层：本地引擎恒 0 → GLM/通用目录 → 内置前缀表）；自定义
  引擎模型不在目录 → 恒不计价或撞前缀误用官方价。引擎配置持久化在
  engines.json 状态文件（非 config.toml）。
- **设计**：EngineConfig 加 `user_price_in/out *float64`（指针三态：nil=不动、
  正数=设置、<=0=清除，局部保存不误清除价目）；引擎级统一价、币种固定 CNY
  （对齐 TotalCost 口径）；`estimatePrice` 插**最高优先层**（用户价 > 目录）；
  SyncUserPrices 在 LoadState/SaveEngine/RemoveCustomEngine 后全量重建，
  锁序恒向无死锁面；零值语义=与现状完全一致（回归锁
  TestUserPrice_NoPriceUnchanged）。
- 前端：EngineSection 自定义引擎编辑表单加两个数字输入（¥/百万 tokens，
  留空=清除，负数 min=0 钳制无法入库）。
- **绑定面 559 不变 ✓**（价目走既有 SaveEngine/GetEngines 通道随结构透传）；
  Go 新增 user_price_test.go 6 测试 + 前端 +2；`wails generate module` 已重
  生成 models.ts（收口）。
- 产品口径：v1 引擎级统一价对多模型中转站是近似值；USD 服务商需自行换算
  填写（UI 已注明 ¥）。
