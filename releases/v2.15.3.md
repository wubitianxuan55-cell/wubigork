# gaea v2.15.3「Herdsman 深挖 P2 · 模型生命周期管理」发布说明（2026-08-13）

> 承接 v2.15.2（P1 模型库），本轮落地 P2：模型中心「模型库」从「看」升级为「管」——
> 卡片上可直接启动/停止/下载/卸载 Herdsman 模型，并读取 launch_records 生成
> 本机实测启动参数预设。桌面端已打包。

## 一、后端：模型生命周期 + 启动参数预设

- `App.HerdsmanModelStart(model)`：`skill models start --model X --wait`，等待冷启动
  完成（20 分钟超时）。
- `App.HerdsmanModelStop(model)` / `App.HerdsmanModelUninstall(model)`：
  `skill models stop/uninstall --model X --force`（卸载需前端二次确认）。
- `App.HerdsmanModelDownload(model)`：`skill models download --model X --wait`，
  等待安装完成（60 分钟超时）。
- `App.HerdsmanLaunchPresets()`：读取 `~/.herdsman/launch_records/*.json`，每个模型
  取最近一次成功启动的参数（context_size / gpu_layers / cache / no_mmap / mmproj 等），
  供模型库展示「启动预设」。
- 统一 `HerdsmanOpResult`（ok/status/message），CLI 错误文案透出到前端；
  长任务 CLI 独立超时，不阻塞模型中心其余功能。

## 二、前端：模型库卡片操作

- 运行中 → 「停止」；已安装未运行 → 「启动」+「卸载」（Popconfirm 二次确认）；
  未安装 → 「下载」。操作中按钮 loading、完成/失败用 message 提示并自动刷新目录。
- 有 launch_records 的模型显示「启动预设」徽标，悬停可见本机实测参数明细。
