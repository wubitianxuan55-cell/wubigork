## 论点

v4.304 落的重写版本库（rewrites/<n>/index.json + 全文快照 + 审计）只有
「刚重写完那一刻」的 RewriteModal 能操作；`NovelListRewriteVersions` /
`NovelGetRewriteVersion` 两绑定**零 UI 消费**——关掉弹窗/换会话后，历史版本
既不可看也不可用（v4.305「用户到不了的功能等于没有」同型欠账）。本刀补
「重写历史」面板：按章列全部版本 → 展开看指标与新文 → 应用/放弃/恢复原文。

## 落地

- **RewriteHistoryPanel**（frontend/src/components/novel/，antd Modal，硬编码
  中文=小说域口径）：open 拉一次列表零轮询；行=时间+模式 Tag（整章/局部/去味）
  +状态 Tag（排队中/重写中/失败/已完成/已应用/已放弃）+相似度%；**多行可同时
  展开**（Set 态，版本对比友好）；详情懒拉 GetRewriteVersion（缓存不重复拉）：
  指标行（原文字数→新文字数/相似度/AI 味分 before→after）+ 新文预览滚动区 +
  原文快照折叠（Collapse 防长文撑爆）。
- **动作镜像后端状态机门控**（前端不重复裁决只禁用）：completed→〔应用此
  版本〕（Popconfirm 显式 okText，覆盖正文确认）+〔放弃版本〕；discarded→
  〔应用此版本〕（后端明确 discarded 可再应用——MuMu 升级语义）；applied→
  〔恢复原文〕；pending/running/failed 只读留痕。动作成功→message+重拉列表，
  应用/恢复另调 onApplied（父级刷新正文，RewriteModal 同口）。
- **入口**：CreatePage rail「整章重写」后加「重写历史」（无徽标——打开才拉，
  首屏零额外请求）。
- **mock**：List 返回两条样本（applied 整章+completed 局部）、Get 返回配套全文
  样本（开发预览）；Apply/Discard/Restore 保持抛错（浏览器端无真实库，诚实）。
- **零后端改动**：绑定面 696 不动、锁数不动、gen_bindings 不跑（drift 复核
  OK@696）。
