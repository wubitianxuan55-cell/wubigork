# wubigrok v5.73.1 — 方案编写模块完善：嵌套章节全链路修复 + 手工大纲编辑 + 上传链路修复

**日期**: 2026-07-31

---

## 🐛 修复：嵌套章节（2/3 级）全链路失效

AI 大纲生成的是三级树形章节，但后续编辑/撰写/导出/检查环节只处理顶级章节，导致子章节「看得见、写不了、存不下、导不出」：

| 环节 | 问题 | 修复 |
|------|------|------|
| 章节查找（后端） | `GenerateSection`/`Polish`/`UpdateSection`/`GenerateChart` 只遍历顶级章节，子章节报「章节未找到」 | 新增 `flattenSections` 递归指针查找，全部改用 |
| 流式撰写保存 | `ProposalGenerateSectionStream` 拿到的是切片副本指针，内容写入后未落盘，刷新即丢失 | 改为指针级展平 `fSRP`，写入真实章节树后再 `Update` 持久化 |
| 前端自动保存 | `WriteTab` 防抖保存只更新顶级章节，子章节编辑静默丢失 | 新增 `updTree` 递归更新章节树 |
| 图表插入 | `ChartTab` 插入 Mermaid 只匹配顶级章节 | 改用 `updTree` |
| 导出 Word/MD | 只输出顶级章节，子章节内容全部遗漏 | 递归导出，按层级生成标题 |
| 覆盖/规范检查 | AI 检查输入只含顶级章节内容 | 递归收集全部章节内容 |

## 🐛 修复：浏览器上传招标文件无法转换

- 原实现前端用 `FileReader` 读文本后即丢弃内容，后端 `ConvertFiles` 拿到的 `Path` 为空 → 全部转换失败
- 新增 `ProposalSaveUploadedFile` API：前端以 base64 上传 → 落盘到 `office/proposals/uploads/<方案ID>/` → 转换器按真实路径处理 PDF/DOCX/TXT
- 删除方案/移除文件时同步清理磁盘文件与上传目录

## ✨ 新增：大纲手工编辑

- 三个章节树（大纲/编制/图表）均支持：**新增子章节**（+）、**重命名**（✎）、**删除**（🗑，含子章节，带确认）
- 「大纲生成」页顶部新增「新增章节」按钮，可添加顶级章节；层级上限 3 级
- 删除章节后自动重排编号

## ✨ 增强

- 流式撰写上下文补齐：方案需求、招标评分标准、核心要求、废标条款、项目概况、工期、完整大纲、前一章节内容
- 流式撰写失败时向前端发送 `error` 事件，按钮不再永久卡在「生成中」；成功后回填最终内容
- 撰写 prompt 明确章节字数与「直接输出正文、不需要标题」
- 新增 `sections_test.go` 单元测试覆盖展平/增删/重命名逻辑
