## 落地

### 1. compress.go 六幽灵清零 + tree 压缩器整族退役

核实六名（run_command / run_background / search_files / list_directory /
search_content / directory_tree）**对三面均零命中**：

- builtin 注册面：46 个 Name() 全集逐一比对，零注册；
- MCP 动态工具：名字恒带 `mcp__<server>__` 前缀（plugin.go 命名空间约定），
  裸名永不匹配——预算条目对 MCP 同名工具也非活路径；
- LSP：gaea 无独立 LSP 工具命名面。

清理：预算表摘 6 条；SmartCompress 死 case 摘除（search_content 并入
grep 的死分支、directory_tree/list_directory 整 case 删）；**compressTree
生产不可达（唯一调用方是两个死 case）→ compressTree+indentDepth+
countChildren 三函数族（~100 行）与两个专属测试整族退役**；wspath import
与注释随之收敛。

### 2. 注册面守卫（防复发，本刀核心价值）

`agent/tool_names_guard_test.go`：源级断言 agent/evidence 包全部 .go 里
