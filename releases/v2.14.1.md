# gaea v2.14.1「办公板块缺陷收口 + 测试补强 + 结构收敛」

发布日期：2026-08-13 ｜ 版本号：v2.14.1 ｜ 产物：[gaea-v2.14.1.exe](gaea-v2.14.1.exe)（Windows x64，约 31.7MB）

承接 v2.14.0，本轮以稳定性与可维护性为主：收口办公板块若干交互缺陷，
把前端用例从 138 提升到 179，并对办公前端做第一轮结构收敛。

## 缺陷收口

- 会话恢复 / 重命名失败不再静默：统一接入 App 层 toast 提示。
- 归档会话「永久删除」补二次确认，避免误删不可恢复数据。
- 欢迎页「最近会话」改为从项目分组派生跨项目最近会话，不再受旧扁平列表
  分页截断影响；点击会自动先切到对应工作区再恢复。
- 文件变更面板补「N 个文件 · M 次」汇总，并按最近改动倒序展示。
- 侧边栏搜索扩展到最近工作区的已归档会话。
- 会话删除时三处注册表（标题/任务目标/置顶）全量清理，补回归测试。

## 测试补强

- 前端用例 138 → 179（46 个测试文件）：
  - `store.ts` reducer / applyEvent（历史重建、turn 收尾、跨轮文本不覆盖）
  - `ChangesPanel`（排序 / 汇总 / 空状态）
  - `useSessionManager`（刷新 / 失败 onError / 乐观删除）
  - `Sidebar`（项目分组渲染 / 置顶 / 归档恢复）
  - `classifyComposerCommand` / `slashQueryOf` / `atMentionOf`
  - `relativeTime` / `startOfDay`
  - `extractChangedPaths` / `buildSessionChanges`
  - `filterProjectGroups`（含归档）
  - `summarizeServerError` / `summarizeSkillDescription`

## 结构收敛

- `App.tsx` 抽出状态组件（`AppStatus.tsx`）与 `buildSessionChanges`。
- `Composer.tsx` 抽出斜杠命令解析与 @ 引用解析。
- `Sidebar.tsx` 抽出相对时间与项目分组搜索过滤。
- `CapabilitiesPanel.tsx` 抽出错误摘要 / 技能描述摘要。
- `main.tsx` 前端诊断改静态 import `bridge`，收敛动态/静态混用 chunk 告警。
