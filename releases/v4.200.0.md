# v4.200.0 — 办公会话排队：单条/全部插话与停止 + 发送中锁定（2026-09-10）

> 带着活来更真：回合进行中排好的下一句，要能改、能删、能立刻插进当前回合，
> 也能整列取消；真正派出的那一条要看见「发送中」，期间不能误触。

## 缺口

Composer 已有运行中入队（Clock）+ 逐条撤回编辑 + 逐条取消，但：

- 排队项不能单条/全部 **Steer**（只能等当前回合结束再当新回合发出）；
- 「全部取消」没有（停止钮会连当前回合一起停）；
- 回合结束后出队瞬间条目从列表消失，没有「发送中」态，编辑/删除/插话没有锁。

## 落地

纯前端，绑定面 **608 零变更**，Go 零逻辑改动（仅版本三处）。

- 队列项升级为 `{id, text, status: pending|sending}`（`composerQueue.ts` 纯函数）；
- 列表头：**全部插话**（运行中才出现）/ **全部取消**（只清队列，当前回合继续）；
- 行内：撤回编辑、单条插话、单条取消（既有 X）；
- 当前回合一结束，队首标 **发送中** 再 `onSend`；派出期间整列锁定——不可编辑、删除、Steer；
- 输入行 Esc/停止仍停当前回合并清空队列（与既有 handleCancel 同口径）。
