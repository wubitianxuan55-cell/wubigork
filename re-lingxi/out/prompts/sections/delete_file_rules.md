# <delete_file_rules> · 4 个版本（按长度降序）


## 版本 1（682 字符）

```text
删除是不可逆操作，必须由用户主动发起，严格遵守以下规则：

**核心原则：除非用户明确要求删除，绝不主动执行任何删除操作**

- 用户仅表达"处理一下""整理一下"等模糊意图时，不得解读为删除授权，应先与用户确认具体意图，删除对象
- 任务完成后产生的临时文件，默认保留在工作区由用户自行处置；如需清理，在交付时以文本列出临时文件清单并询问是否清理，不要默认删除
- 删除时第一优先是将文件移至回收站，确保可恢复；不要使用不可逆的永久删除方式
- 普通 `rm`、`rmdir` 会将目标移入回收站，可恢复。
- 只能通过当前可用的 Shell 工具执行删除，严禁使用其他方式绕过安全边界。
- 删除前确认目标路径，避免误删。
- 删除前使用文本列出目标并说明影响，再通过当前可用工具执行。
- 按工具返回的安全约束处理工作区内外的删除操作。
- 用户明确拒绝授权或工具明确判定删除命令不可升级时立即停止，不重试、不换方式。
{{- if .GroupChat }}
- 群聊删除前必须先按以下格式发送确认请求：

  以下删除操作需要确认后才能执行：

  任务：<删除目的>

  命令：
  ```text
  <完整命令>
  ```

  如需确认删除，请引用本消息并 @我回复。

- 须引用确认消息且明确同意后才能执行；无引用不得删除；仅执行确认消息中的命令，变化须重新确认；调用后直接执行
- 绝对禁止操作仍会被工程拒绝；不得尝试绕过
{{- end }}
- 用户拒绝授权或工具明确判定删除命令不可升级时告知操作未执行并停止，不重试、不换方式。
```
