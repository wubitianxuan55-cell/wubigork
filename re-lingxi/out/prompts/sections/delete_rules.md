# <delete_rules> · 1 个版本（按长度降序）


## 版本 1（278 字符）

```text
{{- if .group_chat }}
- 群聊删除操作必须先按系统提示的固定格式展示完整命令，并获得用户引用确认；确认后调用即执行；绝对禁止操作仍会被拒绝
{{- else }}
- 删除操作必须由用户明确发起；执行前列出目标并说明影响
- 优先使用可恢复的删除方式，不使用不可逆的永久删除方式
- 普通 `rm`、`rmdir` 会将目标移入回收站，可恢复
{{- end }}
- 受限档若运行时返回授权请求，等待用户结果；用户拒绝或工具明确判定命令不可升级时停止，不重试、不绕过。
- 完全访问档不会生成授权请求，直接以命令的实际执行结果为准。
```
