# gaea 板块蓝图 · pantheon 众神殿（议事厅 / 立题卷）

> 页面级规范覆盖 `MASTER.md`。本版为 2026-10-31「首页重设计」后的当前态；
> 功能、数据绑定、状态机与测试契约以 `frontend/src/pages/PantheonPage.tsx`、
> `frontend/src/pages/pantheon/PantheonComposer.tsx` 为准。

## 设计判断

众神殿不是聊天首页，而是一间本机议事厅：

- **先看问题，再看席位**：首页以“立题入口 + 本机席次图”组织，不用通用 SaaS
  三卡、居中营销 Hero 或第二套仪表盘。
- **本机与边界可见**：只读运行、可入席人数、四位 Agent 的真实就绪状态都在首屏
  可读；状态同时使用文字、点位和位置表达，不只依赖颜色。
- **两段式入口**：卷首负责建立议事语境与进入动作；立题卷负责填写议题、范围、
  参与者、轮次和材料。需要展开的字段按需披露，不把表单一次全铺开。
- **金只做判断落点**：月华金用于主行动、当前状态、规则编号与收束线；正文保持
  中性高对比，不使用紫蓝 AI 渐变。

```text
下方 .pantheon-protocol 为无卡片式议事守则，与首屏共用一条收束基线。
```

## 立题结构

- 宽屏主画布 ≥980px：左侧“议题卷”承载问题、材料与补充背景；右侧“议事配置”
  纵向收束工作空间、参与席位、发言顺序与讨论参数。议题始终是唯一视觉主角。
- 窄画布：按“议题卷 → 议事配置”单列回流；材料与补充背景仍紧随议题卷，不跳到
  配置之后。工具栏自动换行，开议按钮保持 44px 高且始终留在可视区内。
- 议题使用可见 `<label>`；空值仅在失焦后显示就近错误，使用 `role="alert"`，
  开始按钮同步保持禁用。输入后错误即时解除，不使用提交后才报错的旧模式。
- 主行动只有一个：“开始讨论”。工作空间、路径、汇总人、轮次与顺序均为辅助
  配置，展开材料/背景不会改变主行动的视觉层级。
- 主输入、全部提交字段、绑定和 testid 不变；新增视觉仅使用既有主题令牌。

## 视觉令牌与工艺

| 项目 | 规则 |
|---|---|
| 底色 | 沿用天玄 / 当前主题的 `--md-sys-color-bg-layout` |
| 强调 | `--pantheon-accent` / `--pantheon-accent-strong`，不新增硬编码色 |
| 卡片 | `--pantheon-surface-raised` 实底信息面，叠加低比例金雾与 1px 内高光 |
| 标题 | 项目衬线字体栈；首屏 `clamp(35px, 3.45vw, 50px)`，负字距、两行断句 |
| 圆角 | 首页席位图 `5px 28px 5px 28px`，内部件更紧；避免全页统一胶囊 |
| 背景 | 主题色低透明径向 washes + 无障碍隐藏的“議”轮廓；不依赖外部图片 |
| 动效 | 入场 520–600ms；席位错峰 55ms；hover 位移 ≤2px；全部支持 reduced-motion |

## 响应式

- 主画布使用 `@container pantheon-canvas`，按真实可用宽度而非视口猜断点。
- ≤960px：首屏双栏改为单列，席位图落到标题下方；议事守则收为两列。
- ≤680px：标题允许自然换行，流程说明精简，守则改为单列。
- ≤640px：席位图改为单列，工具条换行，开议钮保持 44px 可视触达面。
- 375 / 768 / 1092 / 1440 实测主画布无横向溢出。
