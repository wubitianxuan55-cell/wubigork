## 2026-10-31 桌面端办公台重设计

**方向：Quiet Desk。** 保留 Constellation OS 的主题令牌与主应用导航，不再让玻璃
光效覆盖信息层。侧栏承担位置，画布承担工作，输入岛是唯一高频操作焦点。

### 视觉规则
- 桌面参数：`DESIGN_VARIANCE 5 / MOTION_INTENSITY 3 / VISUAL_DENSITY 7`。
- 信息层使用实底令牌；玻璃只保留给真正的浮层，主工作区取消 backdrop blur。
- 背景采用「静默绘图台」：画布上叠加冷色云雾、低对比 80px 工程网格与主色柔光；
  空会话达到完整层次，产生消息后自动降低网格与光晕强度。
- 单一强调色：主行动、当前会话、当前视图与工具入口统一使用主题 accent；
  其余层级依靠表面色、发丝线和排印建立。
- 圆角规则：卡片与面板 11-15px，按钮与页签 7-9px，圆形只用于发送按钮。
- 办公板块不再渲染卡片式欢迎页。新会话空态采用与参考图一致的纵向三段式：
  输入框上方是一行轻量欢迎语与居中的大标题，中间是宽幅多行命令输入岛，下方是
  三枚任务快捷胶囊；模板、技能、工具仍保留在输入框菜单，首屏不堆叠内容卡。
- 办公侧栏移除过时的「办公空间 / 娱乐空间」切换；底层空间数据保留，不做迁移。
- 顶栏 54px，视图页签 46px；桌面导航保持单行。
- 输入岛采用冷白半透明命令面、18px 圆角和蓝调环境阴影：空会话时整体在画布中
  垂直、水平居中；产生消息后回到底部。文本框默认显示四行并随内容增高，下行为
  项目、附件、截图、工具、参数和计划操作。空态强制使用自动高度，覆盖旧的持久化
  输入框高度，避免工具栏被裁切。
- 空态快捷胶囊使用可读的真实任务模板（工作周报 / 会议纪要 / 成本测算）；点击只
  预填并聚焦输入框，不直接发送，保留用户确认和执行范围调整的机会。
- 动效限 360ms 入场与 120-180ms 反馈；`prefers-reduced-motion` 全部降级。

### 实施入口
- `frontend/src/gaea/office-ui.css`：办公范围覆写与启动台视觉系统。
- `frontend/src/gaea/office-sidebar.css`：左侧工作区导航与项目树。
- `frontend/src/gaea/lib/taskTemplates.ts`：命令面板任务模板数据源。
- `frontend/src/gaea/App.tsx`：顶栏、页签、输入区语义挂点。
- `frontend/src/gaea/components/{Sidebar,Composer,Transcript}.tsx`：导航、输入与空态细节。
- `frontend/src/gaea/components/composer/*`：输入行和工具栏语义挂点。

### 左侧导航
- 顶部是工作区身份，不重复铺产品导航；显示 `gaea`、当前项目与折叠开关。
- 「新建会话」是唯一高权重动作；知识库与 MCP 技能收为双列次级入口。
- 搜索、项目小节与会话树形成连续纵向阅读轴，不再使用多层胶囊。
- 项目组头显示当前项目、会话数与「全部」入口；会话树用一条细竖线表达从属关系，
  子代理行继续向右缩进。
- 会话操作只在悬停、聚焦或展开时出现，避免常驻按钮制造视觉噪声。
- 左侧不再提供「事实底座」；交付事实仍由会话 store 与右侧产物链路承载。
- 折叠态保留工作区标识、新建、当前会话与知识/MCP 四个关键入口。
- 侧栏宽度低于 250px 时，快捷入口自动变为单列。

### 验收基线
- 1440×900、1280×800、1024×768 无横向溢出。
- 亮色与暗色均实测；正文、次要文字、占位文字与主行动卡达到 AA。
- 键盘焦点可见；空会话显示欢迎语、主标题、居中多行输入和三枚任务胶囊，消息出现
  后输入回到底部；快捷键胶囊可通过 Tab 访问且有可见焦点环。

### 2026-10-31 首页删除与办公默认启动

- 删除全局首页启动器（ModuleLauncher、首页板块胶囊与专属样式），不删除小说板块内
  的「书架」HomePage；两者不是同一概念。
- `DEFAULT_BOARD_ID = 'gaea'` 成为唯一启动落点。冷启动直接渲染办公工作台，不再
  先经过一层模块启动页，也不在顶部保留返回首页按钮。
- 冷启动固定调用一次办公 `NewSession`，再装载 meta/context；后端上一次当前会话
  不再被自动导入。新会话创建失败时保持空状态并记录日志，`onReady` 可再尝试，
  不回退到旧会话。
- 指挥轨道不再出现「首页」；全部业务板块仍保持原有入口、快捷键和深链。
- 旧后端 manifest 若残留 `home`，归一化阶段直接过滤；旧 `home` 深链 fail-closed，
  不再挂载第二个启动面。
- 任务收件箱的常驻监听从首页迁往壳层 `TaskInboxHost`，命令面板空态的
  「打开任务收件箱」保持可用；新建任务仍按当前壳层空间落标签。
