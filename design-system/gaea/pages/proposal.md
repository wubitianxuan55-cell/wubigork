# gaea 板块蓝图 · proposal 方案库「档案架」

> 页面源：`ProposalLibraryPage.tsx` + `proposal-library.css`，纯逻辑在
> `pages/proposal-library/logic.ts`。数据面：`ProposalB` 五绑定（清单 / 标题树 /
> 阅读 / 检索 / 删除）；录入与索引不在本页，走办公「方案」运行模式里的
> `proposal_save`。

## 定位

历史方案的档案架。一份方案存成三层：标题树管定位、段落管检索、小节管阅读。
本页只给人看和查，不承担录入：

- **骨架参照**：看同类历史方案的 1~4 级标题树；
- **段落取材**：按关键词或自然语言问法检索，命中回到小节并给出命中位置摘要；
- **阅读**：逐节阅读，连子节跳转。

## 视觉性格：档案架

- 三栏实底信息层，栏间细线分隔；单强调色 `--accent` 只标记当前方案、当前标题、命中词；
- 高密度但可读：清单标题 12.5px、标题树 12px；阅读正文沿用全应用 `md-content`
  的阅读排版（14px）；字数与计数统一 `tabular-nums`；
- 不叠玻璃、不做 Hero；页头只有身份与检索条。

## 信息架构

1. **页头 `pl-masthead`**：左侧身份（PROPOSAL LIBRARY / 方案库 / 一句话说明）；
   右侧检索条：输入框（回车即搜）+ 范围切换（全文 + 语义 / 只搜标题）+ 类型 / 年度 /
   层级三个下拉 + 搜索按钮。
2. **状态行 `pl-status`**：检索时给出「命中 N 条 · 路径 · 备注」与返回清单；
   非检索时给出库规模（方案数、标题节点总数）与当前方案。
3. **三栏 `pl-body`**：
   - 左栏：方案清单（标题、摘要、类型 / 年度 / 录入中标记、节点数、字数、语义索引
     进度）；检索时替换为命中卡（方案名、小节标题、标题路径、层级 / 字数 / 子节数、
     高亮摘要）。删除入口在行尾，悬停或聚焦才出现。
   - 中栏：标题树。首屏只展开到节（2 级及更深默认收起）；带箭头、字数；
     支持 ↑ ↓ Home End 移动读取、→ 展开、← 收起或回父节。
   - 右栏：阅读窗。标题路径面包屑、小节标题、字数、子节胶囊、Markdown 正文、
     上一节 / 下一节。

## 四态

- **加载**：旋转图标 + 「正在读取…」；
- **空库**：`pl-empty` 三步引导（切方案模式 → 让 AI 录入并给可复制的示例指令 →
  回来浏览检索）+「去办公板块」；
- **无命中**：明确说没有命中并给换词建议，不显示空列表；
- **读取失败**：失败态 + 原因 + 重试，明确写出「这不是空库」——失败不伪装成空库。

## 响应式与可访问性

- 按容器宽度分档（`container-name: proposal-library`），不看视口；
- `> 1180px`：三栏 300px / 34% / 余量；
- `≤ 1180px`：左栏收窄到 250px，检索条换到第二行；
- `≤ 820px`：单栏，顶部页签「方案 / 目录 / 正文」切换，默认停在目录；
- 标题树用 `role="tree"` / `treeitem`（`aria-level` / `aria-selected` / `aria-expanded`），
  焦点在可见行间游走（roving tabindex）；
- 页面提供「跳到方案库工作区」跳转链接；全部控件有 `:focus-visible` 环；
- 状态行 `aria-live="polite"`；
- `prefers-reduced-motion` 下关闭过渡与旋转动画。
