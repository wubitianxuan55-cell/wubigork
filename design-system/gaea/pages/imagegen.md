> 覆盖 MASTER。实施参考 docs/2026-08-15-gaea3-ui-design-system.md。

## 现状（facts）
- 页面：`frontend/src/pages/ImageGenPage.tsx`（310 行）+ components/imagegen/* + hooks（useImageGenQueue/History/Config）
- 可折叠分区/底部生成栏/任务中心三 Tab/玻璃 HUD；生成队列/历史/灯箱（Lightbox）
- 多后端（本地 ComfyUI：Flux/Z-Image-Turbo/Krea2 + LoRA/风格预设 + 云端 xAI）；进度事件

## 目标态
- **视觉性格：画廊工作台**——历史瀑布（创作资产）+ 参数面板（工具）+ 生成队列（状态）。
- 历史瀑布：图片卡（圆角 `--radius-md` + 悬停 `--elevation-2` + 操作浮现：下载/剧照/删除）；
  - 灯箱（Lightbox）：全屏玻璃遮罩 + 图 + 元数据（模型/尺寸/耗时小字）。
- 参数面板：折叠分区（模型/尺寸/风格/LoRA），表单走令牌；生成按钮主色胶囊。
- 生成队列/任务：进度条主色；状态色（排队=secondary / 运行=primary 脉冲 / 完成=success /
  失败=destructive），色+图标+文字。
- 底部生成栏：玻璃输入条 + 提示词 + 附加（图生图）+ 生成按钮。

## 2026-10-31 · 暗房画室 / Dream Atelier

**诊断**：首屏将提示词埋在窄左栏，中央空态与真正输入分离；空任务面板占据
220px 却只显示“没有任务”；模式与工具、生成栏与画布缺少统一视觉节奏。

**方案**：

- 模式轨道保留顶部，创作模式和工具入口用细标签与分隔线分层；窄屏允许换行，
  不依赖难以发现的横向滚动。
- 左栏改为“创作指令台”：可见的“你想画下什么？”标签、主提示词编辑面、
  描述建议和细线参数索引。模型/引擎/画幅仍渐进披露。
- 中央画布是视觉主角：空白状态使用非对称画框、轨道线与“让第一幅画，从一句话
  开始。”；图片/视频模式各有对应标题与三条描述提示。
- 历史/任务栏首次进入默认收为 50px 图标索引，点击任一入口恢复完整面板；
  队列和历史仍保留原有 tab、轮播、清空和模板功能。
- 底部生成栏只保留状态与主行动。提示词为空或图生图缺参考图时禁用生成，
  原因直接写在生成栏，不再等点击后才弹 warning。

**视觉规则**：

| 项目 | 规则 |
|---|---|
| 基底 | 当前主题的 `bg-layout` + 两组低透明径向光 |
| 主面 | 提示词卷 / 画布 / 底栏使用 4px-20px 不对称圆角 |
| 字体 | 大标题与提示词走项目衬线栈，轨道/计数走等宽栈 |
| 强调 | 单一主色 + `--gaea-glow`；不在生成页引入第二套色彩语言 |
| 动效 | 画布轨道缓慢旋转；空白画框静态；reduced-motion / rAF 降级停止动画 |
| 状态 | 空提示词、缺参考图、引擎不兼容均在唯一生成落点就近说明 |

**响应式**：

- ≥1240px：左控制台 356px，画布占据剩余宽度，任务栏收为 50px。
- 900–1240px：左控制台 320px，任务栏 50px，画布仍保有主视觉面积。
- <900px：控制台 → 画布 → 任务索引单列；底栏保持可见。
- ≤600px：模式与工具入口换行排布；提示词输入与画布均无横向溢出。

**契约**：生成模式、ControlPanel 字段、模板/角色/图生图入口、GenerationBar
状态机、队列/历史 tab、全部 imagegen 测试与绑定保持不变。

## 2026-10-31 · 模板库 / Prompt Atlas

**诊断**：原模板库把 19 个分类压在一条横向胶囊轨道里，720px 弹窗用三列
摘要卡展示 231 组内容；提示词、画幅、标签与负向词不可见，自定义编辑/删除
挤在卡片角落，选中与套用也没有中间确认层。

**结构**：

- 弹窗升级为 1120px 的“分类索引 + 模板卡网格 + 详情预览”三栏图鉴。
- 分类按「基础与风格 / 场景与视觉 / 个人收藏」分组，全部为纵向可滚动索引，
  同时保留 `role=tab` 与分类计数。
- 卡片展示分类、画幅、用途、标签与编号；单击选中，双击或详情主按钮套用。
- 右侧详情呈现完整提示词、负向词、画幅、标签与自定义操作；全库只有一个
  高强调“套用此模板”按钮。
- 顶部搜索跨名称、用途、标签和提示词；结果数量通过 `aria-live` 更新。
- 空分类、无搜索结果与“我的模板”空态各有明确下一步。

**视觉**：

- 深色模板库使用主题底色 + 单色青主光，分类色只做 5px 点与卡片左缘。
- 卡片使用 `3px 14px` 不对称圆角与低对比渐变，选中态靠边框、左缘线和光晕，
  不只依赖颜色。
- 标题/预览字符使用衬线栈，轨道、画幅、计数使用等宽栈。
- 所有可交互卡片使用原生 `button`；详情按钮、关闭、搜索均有明确标签与焦点态。

**响应式**：

- ≥841px：210px 分类栏 + 自适应卡片网格 + 304px 详情栏。
- 621–840px：分类与卡片双栏，详情横置在底部；隐藏低优先级元信息。
- ≤620px：全屏近满宽弹窗，分类改横向滑动索引，卡片单列，详情在结果下展开。
- 375 / 768 / 1092 / 1440 实测无横向页面溢出。

**契约**：`onSelect`、`onAddCustom`、`onEditCustom`、`onDeleteCustom` 不变；
「全部模板」、19 个分类、搜索与自定义新建入口保持原有可访问入口。
