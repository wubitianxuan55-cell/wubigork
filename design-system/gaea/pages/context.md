## 视觉性格：观测仪表（Observability Cockpit）

上下文标签页回答三个问题：**窗口里现在有什么（构成）→ 如何演化到这里
（过程）→ 每一类内容的具体内容（明细）**。它是开发者遥测面板而非内容页：
数据密度优先、等宽字体承载数字、六分类语义色（system 蓝/tools 橙/user 绿/
inject 紫/assistant 深蓝/tool 青）是全页唯一的强色，装饰色全部退后。
沿用星枢语言：`bg/bg-soft/border-soft/fg*` 语义令牌 + Luminous Glass；
`--gaea-glow` 只给「运行中」状态；ui-ux-pro-max dense dial（8/10）=
卡内 8-12px 间距、区块 12px 栏距；Subtle motion（150-200ms opacity/
transform，禁大面积位移动画）。

## 布局（全宽网格仪表，纵向流）

- **行1 · 四仪表卡**（grid md:2 / min-[1400px]:4）：上下文统计（8 格）｜
  Token 统计（SVG 环形缓存命中% + 缓存输入/未缓存输入/输出三分解，环心
  命中率两位小数）｜ 耗时统计（环形活跃时长 + 模型等待/生成/工具执行/其他
  分解 + tools top3）｜ 会话信息（会话名/空间/模型/窗口/请求数）。卡头
  单行：标题左 + 副注右（text-right 截断 + title）。
- **行2 · 双列**（3fr_2fr）：当前上下文宽卡（大数字 + 六分类分段条含**灰色
  空闲窗口段** + pct 大字 + 工具结果占比 + 图例 chips）｜ 上下文浏览器
  （六分类折叠组 + 项数徽标 + 行内搜索 + 归档组 + >200 项分页）。
- **行3 · 趋势卡（master-detail 单元）**：标题行（粒度 步/轮 + 模式 全局/
  增量）+ 原生 SVG 堆叠柱（✂ 压缩标记、hover 六分类构成详情条、点击钉住）+
  **请求详情内联卡内**（顶部分隔线区隔；默认选中最新请求——打开即有内容；
  钉住的选择在请求仍存在时保留、消失自动回退最新）。
- **行4 · 双列**：上下文事件（**五分类多选 chips**：全亮点一=单选、点掉=
  排除、单选再点=恢复全选；行=分类徽标+来源+轮步+Δtoken）｜ 文件活动
  （按文件聚合树：动作 chips + 路径过滤 + 三排序 + 读写次数徽标 + 点击预览）。
- **行5 · Agent 网络径向树**（SVG 中心占用环 + 子代理放射节点 + 彩色连线；
  头部 N 个 Agent / N 个运行中 / 上下文合计；空态=无子代理说明）。
- **底部**：会话汇总条（会话徽标 + 水位 + 请求数 + 累计费用 + 七分类图例）
  + 估算口径页脚。

## 交互链（v4.69 起）

- **构成图例 hover 联动**：悬停分类 chip → 该分类分段保持、其余分段与空闲
  段 150ms 淡出（opacity 0.28）；chip 微高亮；离开恢复。
- 趋势 hover = 即时六分类构成详情条（上方 HTML 条）；click = 钉住请求
  （详情内联更新）。
- 事件 chips 为多选开关（aria-pressed），非单选。
- 空态 / 错误态：空态=构成卡 + 虚线引导卡；错误条常驻顶部。
