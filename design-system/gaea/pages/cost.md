# gaea 板块蓝图 · cost 造价数据库「造价总账」

> 覆盖 memoryhub.md 中成本库相关段落。当前版以 `CostLibraryPage.tsx` +
> `cost-database.css` 为页面外壳，八模块与全部数据契约保留，重点重构信息层级、
> 分组工作面、默认清单表和概览镜头。实现源：`ui-ux-pro-max` 的
> Data-Dense Dashboard 规则 + `redesign-existing-projects` 的审计优先流程。

## 视觉性格：造价总账（Cost Ledger）

造价数据库不是营销页，也不是通用图表看板，而是长期录入、核对、追溯的本地
造价资产工作台。视觉语言采用：

- **工程账本**：细网格、编号、等宽编码、精确分隔线；
- **单一强调色**：只用主题 `--accent` 标记当前工作面、关键数字与主操作；
- **实底信息层**：卡片使用主题表面色，不叠玻璃；网格与柔光只留在容器背景；
- **高密度但可读**：表体 12px 起、表头 9.5px 起，数字统一等宽并启用 tabular-nums。

## 信息架构

顶部 `cost-masthead` 承担身份与上下文，不重复做一个大号营销 Hero：

1. 左：`COST LEDGER`、本机资产状态、造价数据库标题、工料法成本工作台；
2. 中：当前工作面名称与该模块的业务说明；
3. 右：`工程量清单 × 企业定额 × 工料机价 → 综合单价` 的计价路径。

下方导航按业务动作分为三组，八模块顺序与绑定不变：

| 分组 | 模块 |
|------|------|
| 编制 | 清单库、企业定额库、工料机库 |
| 治理 | 数据健康、对标查漏、价格数据 |
| 研判 | 造价参考、概览 |

- 模块按钮采用编号 + 图标 + 名称，激活态为浅色底、强调色边框和底部刻线；
- 概览激活时右端显示「数据概览 / 关联图谱」；其他模块显示「回到概览」；
- 价格数据内部继续使用四段矩形切换：价格源、价格仓库、询价库、资料条目。

## 主工作区

### 清单库（默认落点）

- 顶部工作簿条：`WORKBOOK 01 · PROJECT BILL`、清单库标题、口径说明；
- 视图切换使用 `aria-pressed`，保留「按明细 / 按库项归并」；
- 筛选条独立成层：项目、分部、搜索、结果计数；
- 明细改为全宽工程账表 `cost-ledger-sheet`，表头使用等宽小字，行悬停用
  accent 6% 轻洗，价格列强化 tabular-nums；
- 窄屏优先横向滚动整张表，不压碎 13 列业务字段；
- 加载、空库、无匹配、读取失败均有明确状态，读取失败不伪装成空库。

### 概览

- 左上 2/3：工料法资产总账，大号资源总数、定额/资料条目/价格源 chips、
  单强调色资源构成条；
- 右上 1/3：按库内缺口给出唯一「下一步」，并提供直达入口；
- 下方：四个工作流快捷入口 + 口径备忘 + 数据备份；
- 空库和读取失败与原有行为一致，不用装饰掩盖失败。

## 响应式与可访问性

- 页面使用容器查询，而不是只看视口宽度；
- `> 980px`：完整标题区与计价路径同排；
- `≤ 980px`：隐藏计价路径，保留标题和当前工作面；
- `≤ 900px`：导航组保持一行，工具栏换到第二行右侧；
- `≤ 760px`：页头单列、详情标题与操作分行、概览卡片纵向堆叠；
- `≤ 620px`：三个导航分组按组换行，避免横向藏入口；
- 宽表在容器内横向滚动，页面本身不产生横向滚动；
- 全部按钮保留可见 `:focus-visible` 环；
- 页面提供「跳到造价工作区」跳转链接；
- `prefers-reduced-motion` 下关闭过渡与骨架脉冲。

## 第二轮细节精修

- 计价路径改为业务准确表述：`清单项 —挂→ 企业定额 —×工料机价→ 综合单价`，
  不再把清单工程量直接乘进综合单价；
- 价格数据四段升级为标准 tab/tabpanel 语义，激活标签 `tabIndex=0`，其余
  `tabIndex=-1`，支持左右方向键、Home、End 切换；
- 清单行名称增加独立键盘按钮；定额、编辑、删除按钮补齐可读的 aria-label；
- 表格增加 caption、列 `scope`、`aria-busy`、结果计数 live region 与窄屏
  横向滚动提示；
- 空库增加「去造价参考导入项目」，无匹配结果增加「清除筛选」恢复路径；
- 加载态改为与账表结构一致的 shimmer skeleton；读取失败使用 `role=alert`；
- 数据备份、价格源、价格仓库改用统一 child toolbar、强调色、状态语义和
  toast live region；
- 项目筛选时列数变化不再依赖 `nth-child`，名称与价格列各自使用稳定语义类。

## 纪律

- 八模块、默认清单落点、价格数据四段、概览双镜头全部保留；
- 绑定面与 Go 数据层不动；
- 不引入 UI 库、图表库或网络字体；
- 组件只消费现有主题令牌，不写死色值；
- 单强调色只用于操作与工作面；人材机四类允许作为数据编码使用文字与图形双重标识。
