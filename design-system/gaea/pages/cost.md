# gaea 板块蓝图 · cost 造价数据库「数据工作台」

> 覆盖 memoryhub.md 中成本库相关段落。v4.50.0 落地（CostLibraryPage.tsx +
> CostLibraryView.tsx 重构），化繁为简：平级 8 模块收敛 6，功能零删减。

## 视觉性格：数据工作台（Data Workbench）
造价数据库 = 本地造价资产沉淀地：库规模一眼可读、条目管理高效、价格数据
同域归拢、经验沉淀可追溯。沿用 v3 玻璃面板/辉光卡语言（`v3-panel`/`v3-card`），
顶栏 + 下划线导航 + 主区的轻三分层，不做重装饰。

## 布局（CostLibraryPage）
- **顶栏（48px）**：Coins 徽标 + 「造价数据库」+ 架构标签（综合单价一级 ·
  人材机二级）+ 一句话定位 + 右侧全局快捷动作（导入文件 / 新建条目）。
- **导航（下划线指示，非胶囊）**：六模块——
  1. 概览：库规模 · 人材机构成 · 数据健康 · 关联图谱；
  2. 成本条目：分类树 + 列表/表格管理；
  3. 测算项目：报价/测算工作 · 版本留痕 · 沉淀回库；
  4. 价格数据：价格源 · 价格仓库 · 询价库；
  5. 造价参考：案例分位数对标（不落表实时聚合）；
  6. 复盘笔记：结论/边界/风险/证据沉淀判断。
- **导航右端上下文区**：概览激活时 = 「数据概览 | 关联图谱」双胶囊（图谱从
  平级模块降为概览的分析镜头，渐进披露）；其他模块激活时 = 「回到概览」。

## 概览（数据概览视图）
- hero（2/3 宽）：库规模大数 + 专业/分部/组成行/价格源 chips + 人材机累计
  金额 + `CompositionBar` 三色占比条（天蓝/翠绿/琥珀）。
- 数据健康（1/3）：待补单价 / 草稿待复核 / 可放心引用 + 引用完备度进度条。
- 最近更新（2/3）：行内 mini 人材机条 + 单价；查看全部跳成本条目。
- 快捷入口（1/3，收敛为 4）：导入资料 / 新建条目 / 价格数据 / 测算项目
  ——纯导航重复项（价格仓库/造价参考/复盘笔记）不再陈列，走模块导航。
- 空库态：三步引导卡（导入资料 → 新建子目 → 订阅价格源）。

## 价格数据（三段同域，`role=tablist` 胶囊切换）
价格数据 = 询价飞轮的承载面（四源归一：信息价/OCR报价/供应商比价/手动询价）：
- 价格源 `PriceSourcesPanel`：订阅源 + 手动/定时抓取；
- 价格仓库 `PriceSourcesRepository`：抓取记录与价格历史；
- 询价库 `CostInquiryPanel`：数据点 + 到期预警横幅 + 调差建议。
  （v4.2 起曾藏在「成本条目」第三个无文字 icon 视图里，v4.50 升格为一等
  子页并归入价格数据域——成本条目视图回归纯 库管理：列表/表格双视图。）

## 成本条目（CostLibraryView）
- 左 208px 分类树：多级增删改、子树过滤、节点计数、首载自动展开；
- 右工具条：列表/表格切换（icon+title）+ 搜索（防抖 250ms）+ 刷新 +
  导入 + 新建；筛选行：分类面包屑胶囊 + 状态胶囊（现行/草稿/已归档）+
  计数 + 批量操作（改状态/删除）。
- 表格 13 列排序表头；行操作：比价 / 价格历史 / 编辑 / 删除（`React.memo`）。
- v4.50 移除不可达死管线：`compact`（办公窄面板，无调用方）与 `onInsert`
  （插入输入框，无调用方）。

## 纪律
- 简化 ≠ 删功能：8→6 全靠 归并（源+仓库+询价 → 价格数据）与 降级
  （图谱 → 概览镜头），每个旧入口都可达。
- 绑定面零变更（559）；后端 cost/costref/coststage/pricefeed 不动。
- 零硬编码色值：只消费既有令牌与 Tailwind 语义类。
